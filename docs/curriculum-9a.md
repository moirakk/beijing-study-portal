# 北京市东城区初三上学期（9A）教材版本与章节目录

> 调研说明：以下按东城区初三上学期使用情况整理。语文、历史、道德与法治采用教育部统编教材；数学、物理、化学采用人教版；英语采用外研版。初三不再开设地理、生物，新增化学。物理使用人教版九年级全一册，9A 先按上学期常见教学进度拆分为第十三章至第十七章。
