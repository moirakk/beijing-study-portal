# 北京市东城区初三下学期（9B）教材版本与章节目录

> 调研说明：与 9A 一致，语文、历史、道德与法治采用统编教材；数学、物理、化学采用人教版；英语采用外研版。初三没有生物、地理。物理为人教版九年级全一册，9A 已覆盖第十三章至第十七章，9B 只做剩余的第十八章至第二十二章（电功率、生活用电、电与磁、信息的传递、能源与可持续发展），不与 9A 重复。语文按修订版统编教材整理：9A 已将《曹刿论战》《邹忌讽齐王纳谏》《陈涉世家》《出师表》《诗词曲五首》等文言单元前移，9B 第六单元对应古典小说单元（智取生辰纲、范进中举等），全册与 9A 无重复篇目。
