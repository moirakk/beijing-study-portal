# 北京市东城区高二上学期（11A）教材版本与章节目录

> 调研说明：高二进入选择性必修阶段。版本沿用高一结论——语文、历史、思想政治统编版；数学人教A版；英语外研版（新标准）；物理、化学、生物、地理人教版（2019 课标版）。历史高二上按北京通行进度学《中外历史纲要（下）》前半（第一至第六单元，第 1–13 课，世界古代史至近代亚非拉民族独立运动）；思想政治按必修 3《政治与法治》（北京高二上完成必修 3/4，本学期取必修 3）。物理选择性必修第一册目录（动量守恒定律、机械振动、机械波、光）与生物选择性必修 1《稳态与调节》五章、地理选择性必修 1《自然地理基础》五章均已经电子课本目录核实。语文选择性必修上册按 2019 统编版通行编号（全册 10 课 + 逻辑的力量 + 古诗词诵读）。
