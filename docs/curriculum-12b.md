# 北京市东城区高三下学期（12B）高考总复习专题目录

> 调研说明：高三下学期（12B）为高考总复习阶段，不再讲授新教材。经联网调研确认：北京东城区各科在高三上（12A）已基本完成全部选择性必修教材（语文选必下、数学选必三、英语选必三、物理选必三、化学选必3、生物选必3、历史选必1、地理选必3、政治选必1）。历史选择性必修2《经济与社会生活》、选择性必修3《文化交流与传播》与思想政治选择性必修2《法律与生活》、选择性必修3《逻辑与思维》虽在部分资料中标注为"高三"教材，但北京各校普遍在高三上（12A）或高三上期末前完成收尾，高三下进入全面总复习。因此本年级 9 科全部按**高考专题复习**组织，并将历史/政治未单独成册的选择性必修内容以"专题整合"形式纳入复习体系。
