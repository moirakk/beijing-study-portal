# 第二节 非洲

标签：#认识大洲 #非洲 #区域地理

## 一、本节定位

中图版·北京版地理七年级下册 **第六章 认识大洲 · 第二节**。运用在 [[第一节 亚洲]] 中学到的分析方法认识非洲：位置与范围 → 地形 → 气候 → 河流 → 资源与人文。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 高原大陆 | 非洲地形以高原为主，故得此称号 |
| 热带大陆 | 非洲约3/4面积位于热带，气候普遍炎热 |
| 气候对称分布 | 非洲气候以赤道为轴、南北大致对称排列 |
| 裂谷 | 地壳断裂下陷形成的狭长谷地，如东非大裂谷 |

## 三、位置与范围

- **半球位置**：地跨南北半球，赤道横穿中部；大部分位于东半球。
- **纬度位置**：大部分位于南北回归线之间，是**热带面积最大**的大洲，有"热带大陆"之称。
- **海陆位置**：东临印度洋，西临大西洋，北隔地中海与欧洲相望，东北以苏伊士运河与亚洲为界。
- 面积约3000万平方千米，是世界**第二大洲**。

## 四、自然环境知识梳理

### 1. 地形

- 地形以**高原**为主（埃塞俄比亚高原、东非高原、南非高原），称"高原大陆"。
- 地势特点：**东南高，西北低**。
- 重要地形区：东非大裂谷（世界最长陆上裂谷带）、撒哈拉沙漠（世界最大沙漠）、乞力马扎罗山（非洲最高峰，"赤道雪峰"）、刚果盆地（世界最大盆地）。

### 2. 气候

| 气候类型 | 分布 | 特点 |
|---|---|---|
| 热带雨林气候 | 刚果盆地、几内亚湾沿岸 | 全年高温多雨 |
| 热带草原气候 | 雨林气候南北两侧 | 全年高温，分干湿两季 |
| 热带沙漠气候 | 撒哈拉地区、南非西岸 | 全年炎热干燥 |
| 地中海气候 | 大陆最北端和最南端 | 夏热干燥，冬温多雨 |

- 分布规律：**以赤道为轴，南北对称**；热带草原气候面积在各大洲中最大。

### 3. 河流

- **尼罗河**：世界**最长**河流（约6670千米），自南向北注入地中海。
- **刚果河**：水量仅次于亚马孙河，流经热带雨林区，注入大西洋。

## 五、地图要素判读

1. 先找**赤道**（横穿刚果盆地和东非高原），再看气候类型南北对称展开。
2. 沿20°E经线自北向南依次经过地中海气候→热带沙漠→热带草原→热带雨林→热带草原，验证对称规律。
3. 找南北回归线穿过的位置，理解"热带大陆"的成因。
4. 在地形图上沿东非大裂谷追踪：红海—埃塞俄比亚高原—东非高原一线。

## 六、易混辨析

| 对比项 | 尼罗河 | 刚果河 |
|---|---|---|
| 世界地位 | 最长 | 水量第二 |
| 流向与注入 | 自南向北入地中海 | 自东向西入大西洋 |
| 流经气候区 | 热带草原、热带沙漠 | 热带雨林 |

## 七、背记要点

1. 非洲是世界第二大洲、热带面积最大的大洲。
2. "高原大陆"：地形以高原为主，地势东南高、西北低。
3. 气候以赤道为轴南北对称分布，热带草原气候面积最大。
4. 尼罗河世界最长；刚果河水量大。
5. 撒哈拉是世界最大沙漠；东非大裂谷是最长陆上裂谷带。
6. 非洲矿产（黄金、金刚石等）和野生动物资源丰富。

## 八、自测小题

1. 非洲有"______大陆"和"______大陆"之称。
2. 世界上最长的河流是______，注入______海。
3. 非洲面积最大的气候类型是______气候。
4. 非洲最高峰是（A. 珠穆朗玛峰 B. 乞力马扎罗山 C. 阿尔卑斯山）。
5. 非洲气候分布的突出规律是以______为轴南北对称。
6. 判断：刚果河是世界上最长的河流。（对/错）

**答案**：1. 高原；热带 2. 尼罗河；地中 3. 热带草原 4. B 5. 赤道 6. 错（最长的是尼罗河）
