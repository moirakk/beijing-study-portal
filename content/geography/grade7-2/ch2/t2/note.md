# 第二节 西亚

标签：#认识地区 #西亚 #石油

## 一、本节定位

中图版·北京版地理七年级下册 **第七章 认识地区 · 第二节**。西亚的学习主线是"三洲五海之地 + 石油宝库 + 干旱环境下的生产生活"，与 [[第一节 东南亚]] 的湿热环境形成鲜明对比。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 三洲五海之地 | 西亚地处亚、欧、非三洲交界，被里海、黑海、地中海、红海、阿拉伯海环绕 |
| 波斯湾 | 世界石油储量最集中的海湾 |
| 霍尔木兹海峡 | 波斯湾石油外运的唯一海上通道，"世界油阀" |
| 节水农业 | 干旱区采用喷灌、滴灌等技术发展的农业 |

## 三、位置与范围

- **海陆位置**：地处**亚、欧、非三大洲**交界地带，联系印度洋和大西洋，沟通里海、黑海、地中海、红海、阿拉伯海，称"**三洲五海之地**"。
- 苏伊士运河（亚非分界）、土耳其海峡（亚欧分界）都在本区边缘，战略位置极其重要。
- 注意：五海中的**里海是世界最大的湖泊**，不是真正的海。

## 四、自然环境知识梳理

### 1. 地形与气候

- 地形以**高原**为主（伊朗高原、阿拉伯高原），平原狭小（美索不达米亚平原）。
- 气候以**热带沙漠气候**为主：全年炎热干燥，河流稀少，沙漠广布。
- 干旱环境 → 水资源比石油更珍贵，多国之间存在水资源之争。

### 2. 石油宝库

| 项目 | 内容 |
|---|---|
| 地位 | 世界石油储量最大、产量和输出量最多的地区之一 |
| 分布 | 以**波斯湾**为中心，沙特阿拉伯、伊朗、伊拉克、科威特、阿联酋等 |
| 输出路线 | ① 经霍尔木兹海峡→印度洋→好望角/苏伊士运河→欧美 ② 向东经马六甲海峡→东亚 |

### 3. 干旱区的生产生活

- 农业集中于**河谷平原和绿洲**（枣椰树是绿洲代表植物）。
- 以色列发展**节水农业**（滴灌、喷灌）成效显著。
- 居民传统服饰多白色长袍，民居墙厚窗小——适应炎热干燥、多风沙的环境。

## 五、地图要素判读

1. 按"里、黑、地中、红、阿拉伯"顺时针找五海，确认"三洲五海之地"。
2. 找**波斯湾—霍尔木兹海峡**一线，画出两条石油外运航线。
3. 对照气候图确认热带沙漠气候的分布范围。

## 六、人文要点

- 西亚是**阿拉伯人**聚居区，多数居民信仰**伊斯兰教**；麦加是伊斯兰教圣城。
- 耶路撒冷被伊斯兰教、基督教、犹太教共同视为圣城。
- 长期的石油利益、水源、宗教、领土问题使西亚成为热点地区。

## 七、背记要点

1. 西亚是"三洲五海之地"：亚欧非三洲；里海、黑海、地中海、红海、阿拉伯海。
2. 里海是湖泊不是海。
3. 石油分布中心：波斯湾沿岸；外运咽喉：霍尔木兹海峡。
4. 气候以热带沙漠气候为主，水资源匮乏。
5. 农业靠绿洲与灌溉，以色列节水农业先进。
6. 居民以阿拉伯人为主，多信伊斯兰教。

## 八、自测小题

1. 西亚地处亚、欧、______三大洲交界处。
2. "五海"中实际上是湖泊的是______。
3. 西亚石油分布以______湾及其沿岸为中心。
4. 波斯湾石油外运必经的海峡是（A. 马六甲海峡 B. 霍尔木兹海峡 C. 白令海峡）。
5. 西亚的主要气候类型是______气候。
6. 判断：西亚水资源丰富，农业发达。（对/错）

**答案**：1. 非 2. 里海 3. 波斯 4. B 5. 热带沙漠 6. 错（气候干旱，水资源短缺）
