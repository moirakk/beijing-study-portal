# 第一节 东南亚

标签：#认识地区 #东南亚 #区域地理

## 一、本节定位

中图版·北京版地理七年级下册 **第七章 认识地区 · 第一节**。东南亚是学习"认识地区"的第一个案例，重点掌握：十字路口的位置、中南半岛与马来群岛的自然差异、热带农业与华人华侨。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 中南半岛 | 亚洲南部三大半岛之一，因位于中国以南得名 |
| 马来群岛 | 世界最大群岛，散布于太平洋与印度洋之间 |
| 马六甲海峡 | 沟通太平洋与印度洋的海上咽喉要道 |
| 热带经济作物 | 天然橡胶、油棕、椰子、蕉麻等热带地区特有作物 |

## 三、位置与范围

- **组成**：中南半岛 + 马来群岛两大部分。
- **纬度位置**：大部分位于热带（约10°S—25°N），赤道穿过马来群岛。
- **海陆位置**：地处**亚洲与大洋洲、太平洋与印度洋之间的"十字路口"**。
- **马六甲海峡**：位于马来半岛与苏门答腊岛之间，是欧洲、非洲与东亚之间最短海上航线的必经之地。

## 四、自然环境知识梳理

### 1. 两大区域对比

| 对比项 | 中南半岛 | 马来群岛 |
|---|---|---|
| 地形 | 山河相间、纵列分布 | 地形崎岖，多火山地震 |
| 气候 | 热带季风气候为主 | 热带雨林气候为主 |
| 河流 | 大河自北向南流（湄公河等） | 河流短促 |
| 城市分布 | 沿河设城、河口三角洲密集 | 沿海平原 |

### 2. 气候与农业

- 热带季风气候：全年高温，分**旱季、雨季**，适合水稻种植。
- 热带雨林气候：全年高温多雨。
- 东南亚是世界重要的**水稻**产区和**天然橡胶、油棕、椰子**等热带经济作物产地；泰国、越南是大米重要出口国。

### 3. 河流：湄公河

- 发源于中国（在中国境内称**澜沧江**），流经多国后注入南海，是亚洲流经国家最多的国际河流之一。

## 五、地图要素判读

1. 找"十字路口"：先定两大洲（亚洲—大洋洲）、两大洋（太平洋—印度洋）。
2. 沿马来半岛西南侧找**马六甲海峡**，理解其航运价值。
3. 在中南半岛地形图上观察"山河相间、纵列分布"：山脉与大河相间排列，南北延伸。
4. 找出赤道穿过的加里曼丹岛、苏门答腊岛。

## 六、人文要点

- 东南亚是世界上**华人、华侨分布最集中**的地区（祖籍多为广东、福建）。
- 旅游资源丰富：下龙湾、吴哥窟、婆罗浮屠、新加坡花园城市等。

## 七、背记要点

1. 东南亚 = 中南半岛 + 马来群岛。
2. 位置价值：两洲两洋"十字路口"，咽喉是马六甲海峡。
3. 中南半岛地形特点：山河相间、纵列分布。
4. 主要气候：热带季风（半岛）+ 热带雨林（群岛）。
5. 世界重要的水稻和热带经济作物产区。
6. 华人华侨最集中的地区。

## 八、自测小题

1. 东南亚地处______洲与大洋洲、太平洋与______洋之间的"十字路口"。
2. 沟通太平洋和印度洋的天然水道是______海峡。
3. 中南半岛的地形特点是______、______分布。
4. 湄公河在中国境内被称为（A. 怒江 B. 澜沧江 C. 雅鲁藏布江）。
5. 马来群岛的主要气候类型是______气候。
6. 判断：东南亚全部位于北半球。（对/错）

**答案**：1. 亚；印度 2. 马六甲 3. 山河相间；纵列 4. B 5. 热带雨林 6. 错（赤道穿过马来群岛，部分位于南半球）
