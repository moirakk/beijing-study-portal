# 共建人类地球家园·重点梳理

标签：#共建地球家园 #人口资源环境 #可持续发展

## 一、本节定位

中图版·北京版地理七年级下册 **第九章 共建人类地球家园 · 重点梳理**。本章收束全册：人类共同生活在地球上，面对人口、资源、环境三大问题，必须走可持续发展、共建人类命运共同体的道路。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 自然资源 | 自然界中对人类活动有价值的物质和能量 |
| 可再生资源 | 短期内可更新、再生或循环使用的资源（水、土地、森林） |
| 非可再生资源 | 用一点少一点、短期内不可再生的资源（煤、石油、铁矿） |
| 可持续发展 | 既满足当代人需要，又不损害后代人满足需要能力的发展 |
| 人类命运共同体 | 全人类休戚与共、合作应对全球性挑战的理念 |

## 三、三大全球性问题梳理

### 1. 人口问题

- 世界人口已超80亿；增长过快（部分发展中国家）带来资源紧张、环境压力、就业住房困难；增长过慢（部分发达国家）带来劳动力短缺、老龄化。
- 对策：人口增长应与**资源、环境**相协调，与**社会经济发展**相适应。

### 2. 资源问题

| 类型 | 面临问题 | 对策 |
|---|---|---|
| 水资源 | 分布不均、污染浪费 | 节约用水、防治污染、跨流域调水 |
| 土地资源 | 水土流失、荒漠化、耕地减少 | 保护耕地、退耕还林还草 |
| 矿产/能源 | 过度开采、面临枯竭 | 节约利用、开发新能源、循环利用 |

### 3. 环境问题

- 主要表现：**全球气候变暖**、大气与水污染、森林锐减、生物多样性减少、荒漠化。
- 环境问题**没有国界**，需全球共同治理（联系 [[主题探究：模拟联合国气候变化大会]]）。

## 四、可持续发展要点

- 内涵：经济发展、社会进步、环境保护**三者协调**。
- 个人行动：绿色出行、节水节电、垃圾分类、少用一次性用品、光盘行动。
- 国家行动：生态文明建设、"绿水青山就是金山银山"、双碳目标。
- 国际行动：《巴黎协定》、联合国可持续发展目标（SDGs）。

## 五、易混辨析

| 对比项 | 可再生资源 | 非可再生资源 |
|---|---|---|
| 更新速度 | 短期内可更新循环 | 亿万年才能形成 |
| 举例 | 水、土地、森林、太阳能 | 煤、石油、天然气、铁矿 |
| 利用原则 | 合理利用+保护培育 | 节约使用+寻找替代 |

- 注意：可再生资源若**过度利用、破坏**（如滥伐森林、超采地下水），也会退化为难以恢复的状态。

## 六、背记要点

1. 三大全球性问题：人口、资源、环境，三者相互关联。
2. 自然资源分可再生与非可再生两类，分类是常考点。
3. 可持续发展 = 经济、社会、环境协调发展。
4. 环境问题无国界，应对靠国际合作。
5. 人类命运共同体：地球是全人类唯一的家园。

## 七、自测小题

1. 自然资源按能否再生分为______资源和______资源。
2. 下列属于非可再生资源的是（A. 森林 B. 石油 C. 水）。
3. 可持续发展要求______发展、社会进步与______保护相协调。
4. 环境问题具有______性（提示：不受国界限制），需要全球合作解决。
5. 举出两个你能做到的低碳生活行为：______、______。
6. 判断：可再生资源取之不尽，可以随意使用。（对/错）

**答案**：1. 可再生；非可再生 2. B 3. 经济；环境 4. 全球（跨国界） 5. 如绿色出行、节约用电（合理即可） 6. 错（过度利用也会枯竭退化）
