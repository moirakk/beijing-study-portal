# 第二节 俄罗斯

标签：#认识国家 #俄罗斯 #资源大国

## 一、本节定位

中图版·北京版地理七年级下册 **第八章 认识国家 · 第二节**。俄罗斯是世界面积最大的国家，主线：地跨两洲的位置 → 四大地形区与主要河流 → 寒冷气候 → 资源与工业 → 交通与城市。与 [[第一节 日本]] "小而缺资源"形成对照。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 地跨两洲 | 国土横跨亚、欧两大洲（乌拉尔山一线为界） |
| 传统欧洲国家 | 俄罗斯人口、城市、工业集中在欧洲部分，历史上属欧洲国家 |
| 温带大陆性气候 | 冬季长而寒冷、夏季短而温暖、降水较少的气候 |
| 西伯利亚大铁路 | 横贯俄罗斯东西的亚欧大陆桥，世界最长铁路之一 |

## 三、位置与范围

- 世界**面积最大**的国家（约1700万平方千米），地跨**亚欧两洲**、东西两半球。
- 大部分位于50°N以北，纬度高；北临北冰洋，东临太平洋，西临波罗的海。
- 虽然亚洲部分面积大，但人口、城市、经济重心在**欧洲部分**，是传统上的**欧洲国家**。

## 四、自然环境知识梳理

### 1. 四大地形区（自西向东）

**东欧平原 → （乌拉尔山）→ 西西伯利亚平原 → （叶尼塞河）→ 中西伯利亚高原 →（勒拿河）→ 东西伯利亚山地**

- 地势特点：**东高西低、南高北低**。

### 2. 河流与湖泊

| 名称 | 要点 |
|---|---|
| 伏尔加河 | 欧洲最长河流，注入里海，航运价值高，"母亲河" |
| 鄂毕河、叶尼塞河、勒拿河 | 自南向北注入北冰洋，结冰期长，有凌汛 |
| 贝加尔湖 | 世界**最深**的湖泊 |

### 3. 气候

- 以**温带大陆性气候**为主：冬季漫长严寒，夏季短促温暖。
- 北部有寒带气候；奥伊米亚康是北半球"寒极"之一。

## 五、资源与经济

- 自然资源**种类多、储量大**：石油、天然气、煤、铁、森林（亚寒带针叶林）、水能等，是能源出口大国。
- 工业基础雄厚：**重工业发达**（能源、钢铁、机械、航空航天），轻工业相对薄弱。
- 主要工业区：莫斯科工业区、圣彼得堡工业区、乌拉尔工业区、新西伯利亚工业区。
- 农业主要分布在气候较温和的**东欧平原南部**（伏尔加河流域、顿河流域）。

## 六、交通与城市

- 交通以**铁路**为骨干：**西伯利亚大铁路**（莫斯科—符拉迪沃斯托克）沿南部山区修建（南部气温较高、矿产丰富、人口城市多，冻土较少）。
- 城市：首都**莫斯科**（最大城市）、圣彼得堡（第二大城市、波罗的海港口）、符拉迪沃斯托克（太平洋港口）、摩尔曼斯克（北冰洋不冻港，受北大西洋暖流影响）。

## 七、背记要点

1. 俄罗斯是世界面积最大的国家，地跨亚欧两洲，属传统欧洲国家。
2. 四大地形区自西向东：东欧平原、西西伯利亚平原、中西伯利亚高原、东西伯利亚山地。
3. 气候以温带大陆性为主，冬长严寒。
4. 伏尔加河为欧洲最长河；贝加尔湖世界最深。
5. 资源丰富，重工业发达，轻工业薄弱。
6. 西伯利亚大铁路沿南部修建；摩尔曼斯克是北冰洋不冻港。

## 八、自测小题

1. 世界上面积最大的国家是______。
2. 亚欧两洲在俄罗斯境内的分界山脉是______山脉。
3. 欧洲最长的河流是______河，注入______。
4. 世界最深的湖泊是（A. 里海 B. 贝加尔湖 C. 死海）。
5. 俄罗斯工业结构特点：______工业发达，______工业薄弱。
6. 判断：西伯利亚大铁路沿北冰洋沿岸修建。（对/错）

**答案**：1. 俄罗斯 2. 乌拉尔 3. 伏尔加；里海 4. B 5. 重；轻 6. 错（沿南部山区）
