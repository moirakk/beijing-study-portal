# 第二节 自然环境与地方文化景观

标签：#地方文化 #自然环境 #文化景观

## 一、本节定位

中图北京版地理八年级下册 **第五章 · 第二节**。本节说明自然环境如何影响民居、服饰、饮食、交通、民俗等地方文化景观，理解"一方水土养一方人"，为[[主题探究：“一方水土养一方人”情景剧表演]]提供知识基础。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 文化景观 | 人类在自然环境基础上创造的可见文化印记，如民居、梯田、服饰 |
| 地方文化 | 特定区域内长期形成的、与当地自然环境相适应的文化 |
| 因地制宜 | 根据当地自然条件安排生产生活方式 |

## 三、知识梳理

### 1. 自然环境影响民居

| 民居 | 分布地区 | 与自然环境的关系 |
|---|---|---|
| 四合院 | 北京 | 冬季寒冷多风沙，院落封闭、坐北朝南采光保暖 |
| 窑洞 | 黄土高原 | 黄土直立性好、气候干燥，冬暖夏凉 |
| 竹楼（干栏式） | 云南西双版纳 | 湿热多雨，架空防潮、通风散热 |
| 平顶碉房 | 青藏高原 | 石材丰富、降水少，墙厚保温 |
| 蒙古包 | 内蒙古草原 | 便于拆装搬迁，适应游牧生活 |

### 2. 自然环境影响饮食与服饰

- 饮食："南米北面"——南方湿热宜种水稻，北方较干宜种小麦。
- 口味：湘川喜辣（湿气重，辣可祛湿），山西喜酸等。
- 服饰：藏袍适应高原**昼夜温差大**（白天脱一袖散热）；南方斗笠蓑衣适应多雨。

### 3. 自然环境影响交通与民俗

- 传统交通："南船北马"——南方水网密布多行船，北方平原广阔多用马车。
- 民俗与文艺：北方秧歌高亢豪放，江南采茶戏细腻婉转；那达慕大会与草原游牧相关。
- 农业景观：南方丘陵茶园与梯田、北方旱地、青藏高原牧场，都是文化景观。

## 四、读图与技能：民居景观图判读

1. 看**屋顶**：坡度大→降水多；平顶→降水少。
2. 看**墙体与窗**：墙厚窗小→冬寒或温差大；架空通透→湿热。
3. 看**建材**：黄土→黄土高原；竹木→湿热林区；石材→高原山区。
4. 结合植被、地形背景综合判断所在区域。

## 五、易混辨析

| 对比项 | 竹楼 | 窑洞 |
|---|---|---|
| 分布 | 云南西双版纳 | 黄土高原 |
| 气候背景 | 湿热多雨 | 冬冷夏热、干燥 |
| 功能特点 | 防潮通风 | 冬暖夏凉、省建材 |

## 六、背记要点

1. 文化景观是自然环境与人类活动共同作用的产物。
2. 民居四例：窑洞—黄土高原、竹楼—西双版纳、碉房—青藏高原、蒙古包—内蒙古草原。
3. 饮食格局：南米北面；传统交通：南船北马。
4. 藏袍适应高原昼夜温差大。
5. 屋顶坡度与降水多少呈正相关。
6. 尊重和保护地方文化景观，就是保护文化多样性。

## 七、自测小题

1. "南米北面"的饮食差异主要受______条件影响。
2. 窑洞主要分布在______高原，利用了黄土______性好的特点。
3. 西双版纳的竹楼架空建造，主要是为了（A. 防寒 B. 防潮通风 C. 防风沙）。
4. 藏袍"脱一袖"的穿法适应了青藏高原______的特点。
5. 判断：屋顶坡度越大，说明当地降水越少。（对/错）

**答案**：1. 气候（降水、热量） 2. 黄土；直立 3. B 4. 昼夜温差大 5. 错
