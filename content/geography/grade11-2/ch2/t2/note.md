# 第二节 生态脆弱区的综合治理

## 概念定义

- **生态脆弱区**：生态系统抗干扰能力弱、易于退化且难以恢复的地区，多分布于**干湿交替、农牧交错、水陆交界、森林边缘、沙漠边缘**等地带。
- **北方农牧交错带**：农区与牧区的过渡地带，也是半湿润区与半干旱区的过渡地带，大致沿 400mm 年等降水量线分布。
- **土地退化**：受自然因素和人类活动影响，土地出现质量下降、生产力降低的过程，表现为土地沙化、石漠化、土壤侵蚀、土壤盐渍化、土壤肥力下降等。
- **综合治理**：针对自然与人为双重成因，采取生物、工程、经济、社会措施相结合的系统治理。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 位置 | 400mm 等降水量线两侧，半干旱—半湿润过渡带 |
| 自然原因 | ①降水量具**临界性**且**变率大**（年际差异显著）；②多大风，冬春季集中，风蚀强烈 |
| 人为原因 | ①过度开垦（降水较多年份垦荒，干旱年弃耕沙化）；②过度放牧（超载导致草场退化） |
| 危害 | 土地沙化、草场退化、沙尘暴频发、农牧业生产力下降、贫困加剧 |
| 治理原则 | 树立生态脆弱意识；强化人地协调、可持续发展观念 |

## 案例分析

**案例：北方农牧交错带的综合治理**。措施体系：①**优化土地利用结构**——宜农则农、宜牧则牧，调整为"多元、高效"利用；②**构筑防护体系**——草灌结合固沙，营造乔灌草结合的防护林（三北防护林），沙障工程固定流沙；③**以地养地，自然恢复**——退耕还林还草、封育保护，用少量水土条件好的土地建设高产农田，换取大面积退化土地的自然恢复；④**调整牲畜结构与数量**——控制载畜量，减少山羊等破坏性强的畜种，改放牧为**舍饲、半舍饲**；⑤**控制人口过快增长、提高人口素质**，生态移民减轻压力。成效：内蒙古乌兰察布等地植被恢复、沙尘减少、农牧民增收，实现生态与经济双赢。

## 典型例题

**例1（选择题）** 北方农牧交错带土地退化的根本自然原因是（　）
A. 地形起伏大　B. 降水量具有临界性且变率大　C. 河流稀少　D. 土壤贫瘠
**解析**：该带年降水量在 400mm 上下波动，湿润年宜农、干旱年宜牧，降水变率大使垦殖极不稳定，叠加大风侵蚀导致退化。选 **B**。

**例2（综合题）** 简述北方农牧交错带综合治理的主要措施。
**解析**：①优化土地利用结构，宜农则农、宜牧则牧；②构筑乔灌草结合的防护体系，工程固沙与生物固沙结合；③退耕还林还草，以地养地、自然恢复；④调整牲畜结构，控制载畜量，推行舍饲圈养；⑤控制人口增长，生态移民，发展生态旅游等替代产业，增加农牧民收入。

## 易错点

- 土地退化的**主导原因是人为**（过垦、过牧），自然原因（降水变率大、多大风）是**基础与潜在因素**。
- 农牧交错带界线**不固定**：随降水年际变化与人类活动南北摆动。
- 治理≠单纯种树：干旱半干旱区应**以草灌为主**，乔木耗水多，盲目造林反而加剧水分亏缺。
- "以地养地"是用小面积高产田置换大面积退化地休养，不是弃耕所有土地。

## 背记要点

1. 位置口诀：400mm 等降水量线，半干旱半湿润过渡，农牧交错生态脆弱
2. 成因两条线：自然（降水临界＋变率大＋大风）、人为（过垦＋过牧）——人为是主导
3. 治理五措施：优化结构、防护体系、以地养地、调畜舍饲、控人移民
4. 因地制宜原则：宜农则农、宜牧则牧、宜林则林、宜荒则荒（高考措施题万能框架）
5. 等级考视角：常以某旗县植被覆盖率变化图切入，考"成因—危害—措施"完整链条
