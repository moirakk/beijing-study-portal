# 主题探究：定向越野

标签：#学用地图 #主题探究 #地图应用

## 一、本节定位

中图版·北京版地理七年级上册 **第二章 学用地图 · 主题探究**。定向越野是借助地图和指北针，按规定顺序找到检查点并最快完成路线的运动。本探究综合运用地图三要素和等高线判读技能，在实践中学用地图。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 定向越野 | 利用地图和指北针，依次到访图上标绘的检查点，用时最短者胜的运动 |
| 定向地图 | 定向越野专用的大比例尺地图，图例细致、现势性强 |
| 检查点 | 图上用圆圈等符号标出的必须到访的地点 |
| 标定地图 | 使地图方向与实地方向一致的操作 |

## 三、探究梳理

### 1. 赛前准备：读懂定向地图

- 看**比例尺**：定向地图比例尺大（如 1∶10 000），范围小、内容详细，便于量算路程。
- 看**方向**：结合指北针或指向标标定地图，使图上北方与实地北方一致。
- 看**图例**：熟悉道路、林地、水域、建筑、陡崖等符号，识别可通行与不可通行区域。

### 2. 路线设计：用上等高线知识

| 判读任务 | 方法 |
|---|---|
| 判断坡度 | 等高线密→陡坡，绕行省力；疏→缓坡，可直接通过 |
| 避开危险 | 等高线重叠处是**陡崖**，禁止穿越 |
| 借助地物 | 沿道路、山脊线行进易于辨认位置；山谷可能有溪流 |
| 量算距离 | 图上距离×比例尺分母＝实地距离，估算时间 |

### 3. 实地行进：定位与判向

1. **标定地图**：转动地图，让指北针指针与图上北方一致。
2. **对照地物**：找出实地明显地物（路口、独立树、建筑）在图上的位置，确定自己所在点。
3. **确定前进方向**：连接现在点与下一检查点，结合"上北下南"或指向标判向。
4. **边走边核对**：经过的地物与图上逐一印证，防止偏航。

### 4. 探究结论

- 地图三要素与等高线判读不是"死知识"，而是户外定位、路线规划的实用工具。
- 科学的路线不一定是直线：**距离短≠用时少**，要综合坡度、地表状况选择。

## 四、方法与技能：最佳路线选择题解法

1. 找出起点与终点，列出可选路线。
2. 逐条比较：距离长短（量图换算）、坡度陡缓（等高线疏密）、有无障碍（陡崖、河流、沼泽）。
3. 结论常是"距离稍长但沿缓坡、道路行进"的路线更优。

## 五、易混辨析

| 对比项 | 直线路线 | 绕行路线 |
|---|---|---|
| 距离 | 短 | 较长 |
| 可能遇到 | 陡坡、陡崖、密林 | 缓坡、道路 |
| 实际用时 | 不一定短 | 常常更快更安全 |

## 六、背记要点

1. 定向越野三件宝：地图、指北针、检查点卡。
2. 定向地图比例尺大、内容详。
3. 先标定地图（图北对实地北），再定位，后判向。
4. 等高线密不走、重叠（陡崖）绝不走。
5. 河流在山谷，行进沿山脊或道路更易定位。
6. 选路线要综合距离、坡度、障碍，不能只看远近。

## 七、自测小题

1. 定向越野必备的两样工具是______和______。
2. 定向地图一般采用______（大/小）比例尺。
3. 使地图方向与实地一致的操作叫（A. 定位 B. 标定地图 C. 量算距离）。
4. 行进路线应避开等高线______（密集/稀疏）处和等高线重叠的______。
5. 甲乙两条路线，甲直线穿越陡坡，乙沿缓坡道路稍绕远，一般应选______，理由是______。
6. 判断：定向越野中距离最短的路线一定用时最少。（对/错）

**答案**：1. 地图；指北针 2. 大 3. B 4. 密集；陡崖 5. 乙；坡缓路好，省力安全，实际用时更短 6. 错
