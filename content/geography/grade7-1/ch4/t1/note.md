# 第一节 感知天气

标签：#天气与气候 #天气预报 #空气质量

## 一、本节定位

中图版·北京版地理七年级上册 **第四章 认识天气与气候 · 第一节**。本节学习天气的概念与特点、天气符号与天气预报的判读、空气质量与生活的关系，学会"看天"安排生活。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 天气 | 一个地方**短时间**里的大气状况（阴晴、风雨、冷热等） |
| 天气预报 | 对未来一定时间内天气状况的预测发布 |
| 卫星云图 | 气象卫星拍摄的云层图像，用于分析天气 |
| 风向 | 风**吹来**的方向（北风从北方吹来） |
| 风力 | 风的强弱等级 |
| 空气质量指数（AQI） | 表示空气污染程度的数值，数值越大污染越重 |

## 三、知识梳理

### 1. 天气的特点

- **短时间**：描述某一时刻或几天内的大气状况。
- **多变**：同一地点不同时刻天气可能不同；同一时刻不同地点天气差别大。
- 描述天气的词：晴、阴、雨、雪、风、雾、冷、热等（"东边日出西边雨"说的就是天气）。

### 2. 天气预报的内容与获取

- 主要内容：**阴晴、气温（最高/最低）、降水、风向风力**等。
- 获取渠道：电视、广播、网络、手机 App、气象台官网等。

### 3. 卫星云图判读

| 颜色 | 含义 |
|---|---|
| 蓝色 | 海洋 |
| 绿色 | 陆地 |
| 白色 | 云区，白色越浓云层越厚，降水可能性越大 |

### 4. 常用天气符号（要能认）

- 晴、多云、阴、小/中/大雨、雷阵雨、小/中/大雪、雾、霾、沙尘暴、台风等。
- **风的符号**：风杆＋风尾。风尾所在一端指示**风向**（风从风尾一侧吹来）；一道长风尾＝2 级，半道＝1 级；如 3 道半长尾为 7 级风。

### 5. 空气质量与生活

- 空气质量用 **AQI** 衡量：优、良、轻度污染……严重污染。
- 影响因素：自然（风、降水助扩散）＋人为（工业排放、汽车尾气、扬尘、烧秸秆）。
- 污染天减少户外活动；人人参与绿色出行、节能减排。

## 四、读图与技能:天气预报图判读三步

1. **认符号**：先读天气符号（晴/雨/雪等），注意"符号左雨右晴"表示天气转变（如小雨转晴）。
2. **读数据**：气温写法"8℃～20℃"表示最低气温 8℃、最高气温 20℃。
3. **判风**：看风杆风尾定风向风力，如风尾在北端→北风。
4. 综合应用：根据预报给出穿衣、出行、活动建议。

## 五、易混辨析

| 对比项 | 天气 | 气候 |
|---|---|---|
| 时间尺度 | 短时间（时刻、几天） | 长时间（多年平均） |
| 稳定性 | 多变 | 相对稳定 |
| 描述举例 | 今天晴转多云 | 北京夏季高温多雨 |

- 注意：风向是风**来**的方向，不是吹去的方向。

## 六、背记要点

1. 天气＝短时间大气状况，特点是"短时间、多变"。
2. 卫星云图：蓝海、绿陆、白云，白越浓雨越可能。
3. 风向是风吹来的方向；长尾 2 级、半尾 1 级。
4. 天气预报四要素：阴晴、气温、降水、风。
5. AQI 越大空气污染越重。
6. "东边日出西边雨"—天气；"四季分明"—气候。

## 七、自测小题

1. 描述一个地方短时间的大气状况用______（天气/气候）。
2. 卫星云图上白色表示______，绿色表示______。
3. "北风 6 级"中的"北"指风______（吹来/吹去）的方向。
4. 天气符号中一道长风尾表示风力______级。
5. 下列描述属于天气的是（A. 昆明四季如春 B. 明天小雨转晴 C. 北京冬冷夏热）。
6. AQI 数值越大，说明空气质量越______（好/差）。
7. 判断：同一时刻，不同地方的天气可能差别很大。（对/错）

**答案**：1. 天气 2. 云区；陆地 3. 吹来 4. 2 5. B 6. 差 7. 对
