# 第二节 气温和降水

标签：#天气与气候 #气温 #降水 #气候要素

## 一、本节定位

中图版·北京版地理七年级上册 **第四章 认识天气与气候 · 第二节**。气温和降水是气候的两大基本要素。本节学习气温与降水的观测、时间变化和世界分布规律，掌握气温曲线图和降水量柱状图的判读方法。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 气温 | 大气的温度，常用℃表示 |
| 气温日较差 | 一天中最高气温与最低气温之差 |
| 气温年较差 | 一年中最热月平均气温与最冷月平均气温之差 |
| 降水 | 从大气中降落的雨、雪、冰雹等的统称 |
| 降水量 | 一定时间内降水的多少，用毫米（mm）表示 |
| 等温线 / 等降水量线 | 气温（降水量）相同各点的连线 |

## 三、知识梳理

### 1. 气温的观测与变化

- 观测：用放在**百叶箱**中的温度计，通常一天观测多次求平均。
- **日变化**：最高气温出现在**午后 2 时（14 时）左右**，最低在**日出前后**。
- **年变化**（北半球）：陆地最热月 **7 月**、最冷月 **1 月**；海洋推迟一个月（8 月最热、2 月最冷）；南半球相反。

### 2. 世界气温分布规律

1. 由**低纬向高纬递减**（纬度因素，等温线大致与纬线平行）。
2. 同纬度**夏季陆地气温高于海洋，冬季海洋高于陆地**（海陆因素）。
3. 山地气温随海拔升高而降低，**每升高 100 米约下降 0.6℃**（地形因素）。

### 3. 降水的形成与类型

- 形成基本条件：空气中含足够**水汽**、气温下降使水汽**凝结**、凝结物增大到能降落。
- 降水的测量工具：**雨量器**。

### 4. 世界降水分布规律

| 地区 | 降水状况 |
|---|---|
| 赤道地区 | 多雨 |
| 两极地区 | 少雨 |
| 回归线附近 | 大陆**东岸多**雨，**西岸和内部少**雨 |
| 中纬度地区 | **沿海多**雨，**内陆少**雨 |
| 山地 | **迎风坡多**雨，背风坡少雨 |

## 四、读图与技能：气温曲线和降水柱状图判读

1. **看横轴**：12 个月份；**看纵轴**：左侧气温（℃）、右侧降水量（mm）。
2. **读气温**：找最热月、最冷月及数值→判断所处温度带（最冷月>15℃热带；0～15℃亚热带/温暖；<0℃温带；终年<10℃寒带）。
3. **判半球**：气温曲线呈**峰形（7 月高）为北半球**，**谷形（1 月高，7 月低）为南半球**。
4. **读降水**：看柱子高矮分布→归纳"全年多雨/全年少雨/夏雨型/冬雨型/全年湿润"。
5. **合并描述**：如"夏季高温多雨，冬季寒冷干燥"。

## 五、易混辨析

| 对比项 | 气温日较差 | 气温年较差 |
|---|---|---|
| 计算 | 日最高气温−日最低气温 | 最热月均温−最冷月均温 |
| 时间尺度 | 一天 | 一年 |

| 对比项 | 迎风坡 | 背风坡 |
|---|---|---|
| 气流 | 暖湿气流被迫抬升 | 气流下沉 |
| 降水 | 多 | 少 |

## 六、背记要点

1. 一天最高温在午后 2 时，最低在日出前后。
2. 北半球陆地 7 月最热、1 月最冷，海洋推迟一个月。
3. 气温从低纬向高纬递减；海拔每升 100 米降 0.6℃。
4. 夏季陆热海凉，冬季陆冷海暖。
5. 降水分布：赤道多、两极少；回归线东岸多、西岸少；中纬沿海多、内陆少；迎风坡多、背风坡少。
6. 气温曲线峰形北半球、谷形南半球。
7. 测降水用雨量器，单位毫米。

## 七、自测小题

1. 一天中最高气温一般出现在______左右。
2. 北半球陆地最冷月是______月，海洋最冷月是______月。
3. 山脚气温 22℃，山顶海拔比山脚高 2000 米，山顶气温约______℃。
4. 世界降水最丰富的地带是（A. 两极地区 B. 赤道地区 C. 回归线大陆西岸）。
5. 中纬度地区降水的分布特点是沿海______、内陆______。
6. 某地气温曲线 1 月最高、7 月最低，该地位于______半球。
7. 山地降水较多的是（A. 迎风坡 B. 背风坡 C. 山顶）。

**答案**：1. 午后 2 时（14 时） 2. 1；2 3. 10（22−0.6×20） 4. B 5. 多；少 6. 南 7. A
