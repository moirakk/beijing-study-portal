# 第四节 气候与人类活动

标签：#天气与气候 #人地关系 #气候变化

## 一、本节定位

中图版·北京版地理七年级上册 **第四章 认识天气与气候 · 第四节**。本节从两个方向认识气候与人类的关系：气候影响人类的生产生活，人类活动也在影响气候（全球气候变暖），树立因地制宜与低碳环保观念。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 气象灾害 | 由天气气候异常引发的灾害，如干旱、洪涝、台风、寒潮 |
| 全球气候变暖 | 全球平均气温呈上升趋势的现象 |
| 温室气体 | 能吸收热量、使大气增温的气体，主要是二氧化碳 |
| 低碳生活 | 尽量减少二氧化碳排放的生活方式 |
| 因地制宜 | 根据当地自然条件（含气候）安排生产生活 |

## 三、知识梳理

### 1. 气候对人类活动的影响

| 方面 | 表现举例 |
|---|---|
| 衣 | 炎热地区衣着单薄；寒冷地区穿皮毛厚衣 |
| 食 | 南方湿热种水稻、吃米饭；北方较干种小麦、吃面食 |
| 住 | 东南亚湿热建高脚屋防潮；北极因纽特人建冰屋；黄土高原窑洞 |
| 行 | 多雪地区用雪橇；水乡多舟船 |
| 农业 | 作物种类、耕作制度随气候而异（热带一年三熟，温带一年一熟或两熟） |
| 其他 | 旅游季节选择、工程建设都要考虑气候 |

### 2. 气象灾害及防御

- 常见气象灾害：**干旱、洪涝、台风、寒潮、沙尘暴**等。
- 防御：加强**监测预报**、修建水利工程、绿化防风固沙、收到预警及时防护。

### 3. 人类活动对气候的影响

- **不利影响**：大量燃烧煤、石油等排放二氧化碳→**全球气候变暖**；乱砍滥伐减少森林吸碳能力；城市"热岛效应"。
- 气候变暖的后果：冰川融化、**海平面上升**（威胁沿海低地和岛国）、极端天气增多、影响农业生产。
- **有利改善**：植树造林、修建水库可调节局部气候。

### 4. 应对气候变化，从我做起

- 国家层面：发展风能太阳能等**清洁能源**、节能减排、国际合作（我国提出"碳达峰、碳中和"目标）。
- 个人层面：绿色出行（步行、骑车、公交）、节约用电、少用一次性用品、爱护绿植。

## 四、读图与技能：材料分析题答题思路

1. 说明气候对生产生活影响：先指出当地**气候特征**（气温＋降水），再对应说明人们的衣食住行或农业安排。
   例：东南亚全年高温多雨→高脚屋通风防潮。
2. 分析气候变暖类材料：抓"排放温室气体→气温升高→冰川融化/海平面上升→影响人类"的因果链作答。

## 五、易混辨析

| 对比项 | 气候影响人类 | 人类影响气候 |
|---|---|---|
| 方向 | 自然→人 | 人→自然 |
| 举例 | 湿热地区建高脚屋 | 烧煤排碳使全球变暖 |
| 应对态度 | 因地制宜、顺应规律 | 节能减排、绿色低碳 |

## 六、背记要点

1. 气候影响衣食住行、农业生产和工程建设。
2. 南稻北麦、南米北面与气候（热量、降水）差异有关。
3. 常见气象灾害：旱涝、台风、寒潮、沙尘暴。
4. 全球变暖主因：燃烧化石燃料排放大量二氧化碳＋滥伐森林。
5. 变暖后果：冰川融化、海平面上升、极端天气增多。
6. 应对措施：清洁能源、植树造林、低碳生活。
7. 人与气候要和谐相处：既要因地制宜，又要保护气候。

## 七、自测小题

1. 东南亚民居多为高脚屋，是为了适应______的气候。
2. 我国"南稻北麦"的农业差异主要受______影响（A. 地形 B. 气候 C. 习俗）。
3. 导致全球气候变暖的主要温室气体是______。
4. 全球变暖可能造成（A. 海平面下降 B. 冰川扩大 C. 沿海低地被淹）。
5. 下列属于气象灾害的是（A. 地震 B. 台风 C. 火山喷发）。
6. 举出两种低碳生活方式：______、______。
7. 判断：人类活动只能破坏气候，不能改善气候。（对/错）

**答案**：1. 全年高温多雨（湿热） 2. B 3. 二氧化碳 4. C 5. B 6. 绿色出行；节约用电（合理即可） 7. 错（植树造林等可改善局部气候）
