# 主题探究：我为国货品牌作代言

标签：#人文环境 #主题探究 #国货品牌

## 一、本节定位

中图版·北京版地理七年级上册 **第五章 认识人文环境 · 主题探究**。本探究选择一个熟悉的国货品牌，调查它的产地、原料、销售范围与文化内涵，为它设计"代言方案"，在实践中体会我国经济发展、国际合作与文化自信。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 国货品牌 | 我国企业创立、拥有自主知识产权的商品品牌 |
| 产业链 | 产品从原料、生产、运输到销售的完整环节 |
| 品牌文化 | 品牌所承载的文化内涵与价值观（如老字号的传统技艺） |
| "走出去" | 中国企业和品牌开拓国际市场的过程 |

## 三、探究梳理

### 1. 选定品牌，明确任务

- 可选类型：老字号（同仁堂、全聚德）、新国货（华为、比亚迪、李宁、安踏）、家乡特产品牌等。
- 代言任务：讲清"它是什么、产自哪里、好在哪里、卖到哪里"。

### 2. 调查品牌的"地理身份证"

| 调查项目 | 地理视角 | 示例问题 |
|---|---|---|
| 产地 | 位置与自然条件 | 工厂/原料基地在哪个省区？当地气候、资源有何优势？ |
| 原料 | 资源分布 | 原料来自本地还是外地/国外？ |
| 生产 | 工业与技术 | 是传统工艺还是高新技术？ |
| 运输与销售 | 交通与市场 | 通过哪些交通方式运往全国、销往海外？ |
| 国际合作 | 全球化 | 零部件或市场是否涉及其他国家？ |

### 3. 提炼"代言词"要点

- 用地理证据夸品牌：如"产自光照充足的新疆棉区""依托便利的港口走向世界"。
- 融入文化元素：老字号的匠心传承、新国货的科技创新，体现**文化自信**。
- 联系第五章知识：品牌出海是**经济全球化**与国际合作的体现，"一带一路"为国货开拓了市场。

### 4. 展示与交流

- 形式：海报、短视频脚本、演讲词均可；要有品牌名、产地地图、卖点三要素。
- 互评标准：地理信息准确、理由充分、表达有感染力。

## 四、方法与技能：社会调查的基本步骤

1. **定主题**：选定品牌与调查问题。
2. **收资料**：查官网与新闻、访问商店、问卷访谈。
3. **理信息**：按"产地—原料—生产—运输—销售"整理成表或产业链示意。
4. **成果化**：写成代言词/海报并展示。
5. **重真实**：引用数据注明来源，不夸大编造。

## 五、易混辨析

| 对比项 | 老字号国货 | 新国货 |
|---|---|---|
| 优势 | 历史悠久、传统技艺、文化底蕴 | 科技创新、设计时尚 |
| 代言侧重 | 讲传承故事 | 讲创新实力 |
| 共同点 | 都是中国制造/创造，都可借全球化走向世界 |  |

## 六、背记要点

1. 代言四要素：是什么、产自哪、好在哪、卖到哪。
2. 分析品牌用产业链思路：原料—生产—运输—销售。
3. 产地优势从位置、气候、资源、交通找证据。
4. 国货出海体现经济全球化与国际合作。
5. 调查要真实，数据要有来源。

## 七、自测小题

1. 调查品牌产业链的基本环节：原料—______—运输—______。
2. 分析品牌产地优势时，可从位置、______、资源、______等方面找证据。
3. 华为手机零部件采购涉及多个国家，这体现了（A. 南南合作 B. 经济全球化 C. 人口迁移）。
4. 为家乡茶叶品牌代言，最有说服力的地理依据是（A. 包装漂亮 B. 当地气候温暖湿润适宜茶树生长 C. 广告多）。
5. 社会调查中引用数据应注意______。
6. 判断：只有历史悠久的老字号才算国货品牌。（对/错）

**答案**：1. 生产；销售 2. 气候；交通 3. B 4. B 5. 注明来源、真实准确 6. 错（新国货同样是国货品牌）
