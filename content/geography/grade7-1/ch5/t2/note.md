# 第二节 发展与合作

标签：#人文环境 #发达国家与发展中国家 #国际合作

## 一、本节定位

中图版·北京版地理七年级上册 **第五章 认识人文环境 · 第二节**。本节学习世界的国家和地区概况、发达国家与发展中国家的差异与分布，理解经济全球化背景下国际合作的重要性。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 国界 | 国家与国家之间的分界线 |
| 领土 | 国界范围内的陆地、领水和领空 |
| 发达国家 | 经济发展水平高、技术先进、生活水平高的国家 |
| 发展中国家 | 经济发展水平相对较低、正在发展的国家（中国属此类） |
| 经济全球化 | 世界各国经济联系日益紧密、相互依存的趋势 |
| 国际组织 | 为协调国际事务而建立的组织，如联合国、世界贸易组织 |

## 三、知识梳理

### 1. 世界的国家和地区

- 世界有 **200 多个**国家和地区，它们面积有大小、人口有多少、制度有差异，但**一律平等**，应互相尊重主权与领土完整。
- 面积居前的国家：**俄罗斯**（最大）、加拿大、**中国**（第三）、美国、巴西。
- 人口大国：印度、中国人口均超 14 亿。

### 2. 发达国家与发展中国家

| 对比项 | 发达国家 | 发展中国家 |
|---|---|---|
| 数量 | 少（20 多个） | 多（150 多个） |
| 主要分布 | 欧洲、北美洲、大洋洲（大多在**北半球北部**） | 亚洲、非洲、拉丁美洲（多在北半球**南部**和南半球） |
| 经济特点 | 技术先进，以高附加值产业为主 | 多以农矿初级产品出口为主，部分国家发展迅速 |
| 举例 | 美国、日本、英国、法国、德国、澳大利亚 | 中国、印度、巴西、埃及 |

- 位置口诀："**南北差异**"：发达国家多在北，发展中国家多在南；发达国家与发展中国家之间的经济合作称"**南北对话**"，发展中国家之间的合作称"**南南合作**"。
- 注意：**中国是世界第二大经济体，但仍是发展中国家**。

### 3. 国际经济合作

- 为什么要合作：各国资源、技术、市场各有优势与短缺，**经济全球化**使各国"你中有我、我中有你"（如一部手机的零部件来自多国）。
- 重要国际组织：

| 组织 | 主要职能 |
|---|---|
| 联合国（UN） | 维护世界和平与安全，总部在纽约 |
| 世界贸易组织（WTO） | 促进国际贸易自由化，中国 2001 年加入 |
| 国际奥委会（IOC） | 组织奥林匹克运动 |

- 中国的贡献：共建"一带一路"倡议，促进沿线国家共同发展。

## 四、读图与技能：世界政区图使用要点

1. 认颜色边界：不同国家用不同颜色区分，边界线即国界。
2. 查大国方位：俄罗斯横跨亚欧大陆北部，加拿大、美国在北美洲，巴西在南美洲。
3. 结合分布规律：判断某国属发达国家还是发展中国家，先看它所在大洲（欧洲、北美、大洋洲的多为发达国家）。

## 五、易混辨析

| 对比项 | 南北对话 | 南南合作 |
|---|---|---|
| 合作双方 | 发达国家 ↔ 发展中国家 | 发展中国家 ↔ 发展中国家 |
| 举例 | 中欧经贸磋商 | 中非合作论坛 |

| 易错点 | 正确认识 |
|---|---|
| 面积大＝发达？ | 否，俄罗斯、巴西面积大仍非典型发达国家 |
| 中国已是发达国家？ | 否，中国仍是最大的发展中国家 |

## 六、背记要点

1. 世界有 200 多个国家和地区，国家不论大小一律平等。
2. 面积前三：俄罗斯、加拿大、中国。
3. 发达国家多分布在欧洲、北美洲、大洋洲。
4. 发展中国家多分布在亚洲、非洲、拉丁美洲。
5. 南北对话＝发达国家与发展中国家的合作；南南合作＝发展中国家之间的合作。
6. 联合国维护和平，WTO 管贸易，中国 2001 年入世。
7. 经济全球化使各国经济相互依存，合作共赢。

## 七、自测小题

1. 世界上面积最大的国家是______，中国面积居世界第______位。
2. 发达国家主要分布在______洲、______洲和大洋洲。
3. 中国属于（A. 发达国家 B. 发展中国家 C. 无法确定）。
4. 发展中国家之间的互助合作称为（A. 南北对话 B. 南南合作 C. 南北差距）。
5. 以维护世界和平与安全为主要宗旨的国际组织是______。
6. 中国于______年加入世界贸易组织。
7. 判断：国家面积越大，经济就越发达。（对/错）

**答案**：1. 俄罗斯；三 2. 欧；北美 3. B 4. B 5. 联合国 6. 2001 7. 错
