# 第二节 海洋和陆地的变迁

标签：#海洋和陆地 #大陆漂移 #板块运动

## 一、本节定位

中图版·北京版地理七年级上册 **第三章 认识海洋和陆地 · 第二节**。本节学习海陆变迁的证据与原因、大陆漂移说和板块构造学说，解释火山地震的分布规律，培养"运动变化"的地理观念。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 海陆变迁 | 海洋和陆地相互转变的现象 |
| 大陆漂移说 | 魏格纳提出：大陆曾连成一块（泛大陆），后分裂漂移到今天的位置 |
| 板块构造学说 | 岩石圈由六大板块拼合而成，板块处在不断运动之中 |
| 板块交界地带 | 板块与板块的交接处，地壳运动**活跃**，多火山地震 |
| 火山地震带 | 火山、地震集中分布的地带 |

## 三、知识梳理

### 1. 海陆变迁的证据与原因

| 实例 | 说明 |
|---|---|
| 喜马拉雅山中发现海洋生物化石 | 这里曾经是海洋（沧海变桑田） |
| 我国东部海底发现古河道、人类活动遗迹 | 这里曾经是陆地 |
| 荷兰填海造陆 | 人类活动也能局部改变海陆分布 |

- 主要原因：**地壳的变动**和**海平面的升降**；次要原因：人类活动（填海造陆等）。

### 2. 大陆漂移说（魏格纳，1912 年提出）

- 灵感：**大西洋两岸**（非洲西岸与南美洲东岸）轮廓十分吻合。
- 证据：两岸古老地层相似、动物（如海牛、鸵鸟类）相似。
- 内容：两亿年前大陆是一整块"泛大陆"，后分裂、缓慢漂移，形成今天的海陆格局。

### 3. 板块构造学说

- 全球岩石圈分为**六大板块**：**亚欧板块、非洲板块、美洲板块、南极洲板块、印度洋板块、太平洋板块**（太平洋板块几乎全部是海洋）。
- 板块**内部**地壳比较**稳定**；板块**交界地带**地壳**活跃**，多火山、地震。
- 板块运动的两种方式：
  - **碰撞挤压**→形成山脉、海洋缩小。例：喜马拉雅山是亚欧板块与印度洋板块碰撞形成，还在长高；地中海不断缩小。
  - **张裂拉伸**→形成裂谷、海洋扩张。例：东非大裂谷；红海不断扩大。

### 4. 世界两大火山地震带

- **环太平洋火山地震带**（世界最主要）；
- **地中海—喜马拉雅火山地震带**（阿尔卑斯—喜马拉雅带）。
- 日本、印度尼西亚多地震，因为位于板块交界处。

## 四、读图与技能：板块分布图判读

1. 认六大板块名称与范围，注意**太平洋板块**几乎全为海洋。
2. 看箭头：**相对（→←）为碰撞挤压**，造山、缩海；**相离（←→）为张裂**，成谷、扩海。
3. 解释现象三步：定位置→找所属板块及交界→说明运动方式与结果。
4. 例：预测红海未来变化——非洲板块与印度洋板块张裂→红海将**扩大**。

## 五、易混辨析

| 对比项 | 大陆漂移说 | 板块构造学说 |
|---|---|---|
| 提出者 | 魏格纳 | 后来科学家在漂移说基础上发展 |
| 核心内容 | 大陆在漂移 | 岩石圈分六大板块并不断运动 |
| 解释能力 | 解释海陆轮廓吻合 | 还能解释火山地震、山脉裂谷成因 |

| 现象 | 板块运动方式 | 结果 |
|---|---|---|
| 喜马拉雅山长高 | 碰撞挤压 | 山脉隆起 |
| 红海扩大 | 张裂拉伸 | 海洋扩张 |
| 地中海缩小 | 碰撞挤压 | 海洋缩小 |

## 六、背记要点

1. 海陆变迁主因：地壳变动、海平面升降；人类活动是局部因素。
2. 魏格纳由大西洋两岸轮廓吻合提出大陆漂移说。
3. 六大板块：亚欧、非洲、美洲、南极洲、印度洋、太平洋。
4. 太平洋板块几乎全是海洋。
5. 板块内部稳定，交界地带活跃。
6. 碰撞成山缩海，张裂成谷扩海。
7. 两大火山地震带：环太平洋带、地中海—喜马拉雅带。
8. 喜马拉雅山＝亚欧板块+印度洋板块碰撞。

## 七、自测小题

1. 提出大陆漂移说的科学家是______。
2. 喜马拉雅山中发现海洋生物化石，说明该地曾是______。
3. 六大板块中几乎全部位于海洋的是______板块。
4. 世界火山、地震多分布在（A. 板块内部 B. 板块交界地带 C. 大洋中部）。
5. 喜马拉雅山是______板块与______板块碰撞挤压形成的。
6. 红海面积不断扩大，是因为两侧板块在（A. 碰撞 B. 张裂 C. 静止）。
7. 世界最主要的火山地震带是______火山地震带。

**答案**：1. 魏格纳 2. 海洋 3. 太平洋 4. B 5. 亚欧；印度洋 6. B 7. 环太平洋
