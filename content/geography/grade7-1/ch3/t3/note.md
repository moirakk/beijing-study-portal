# 主题探究："海底漫游"旅游路线设计

标签：#海洋和陆地 #主题探究 #海底地形

## 一、本节定位

中图版·北京版地理七年级上册 **第三章 认识海洋和陆地 · 主题探究**。本探究设想乘坐深潜器进行一次"海底漫游"，设计观光路线，综合运用海陆分布、海底地形和板块运动知识，认识神秘的海底世界。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 大陆架 | 陆地向海洋自然延伸的浅水部分，坡度缓、水深一般不超过 200 米 |
| 大陆坡 | 大陆架向外倾斜的陡坡，水深急剧加大 |
| 洋盆 | 大洋底部宽广而较平坦的主体部分 |
| 海沟 | 海洋中最深的狭长凹地，多分布在板块碰撞地带 |
| 大洋中脊 | 大洋中部隆起的海底山脉，是板块张裂、新海底诞生的地方 |

## 三、探究梳理

### 1. 认识海底地形（漫游"景点"）

| 海底地形 | 位置与特点 | 漫游看点 |
|---|---|---|
| 大陆架 | 近岸、浅而平 | 阳光可达，渔业资源丰富、可见油气开采平台 |
| 大陆坡 | 大陆架外缘 | 坡度陡增，光线转暗 |
| 洋盆 | 大洋底部主体 | 广阔幽深的深海平原 |
| 大洋中脊 | 大洋中部 | 海底"山脉"，有新岩浆涌出，是新海底的"出生地" |
| 海沟 | 大洋边缘（如西太平洋） | 海洋最深处，马里亚纳海沟深逾万米 |

### 2. 设计路线（示例思路）

- 路线：海岸出发 → **大陆架**（观鱼群与油气平台）→ 顺**大陆坡**下潜 → 穿越**洋盆** → 登"海底山脉"**大洋中脊** → 终点探秘**海沟**。
- 深度变化：由浅入深，在海沟处到达最深点——路线体现"缓→陡→平→隆起→骤深"的地形序列。

### 3. 结合板块知识解释

- **大洋中脊**处板块**张裂**，岩浆上涌冷凝成新海底；
- **海沟**处板块**碰撞**，大洋板块俯冲到大陆板块之下；
- 这印证了海洋并非亘古不变——海底也在不断"新生"与"消亡"。

### 4. 探究收获

- 海底与陆地一样高低起伏、形态多样；
- 海洋蕴藏渔业、油气、矿产等资源，要合理开发、保护海洋环境。

## 四、方法与技能：海底地形剖面示意判读

1. 从岸边向大洋方向依次辨认：**大陆架→大陆坡→洋盆（其间有中脊、海沟）**。
2. 抓深度突变点：水深骤增处是大陆坡；最深的"V"形处是海沟；洋底隆起处是大洋中脊。
3. 设计路线图时用箭头标示行进方向，并在各段标注地形名称与大致水深。

## 五、易混辨析

| 对比项 | 大洋中脊 | 海沟 |
|---|---|---|
| 形态 | 海底山脉（隆起） | 狭长深沟（凹陷） |
| 板块运动 | 张裂，新海底生成 | 碰撞俯冲，海底消亡 |
| 深度 | 相对较浅 | 海洋最深处 |

## 六、背记要点

1. 海底地形五类型：大陆架、大陆坡、洋盆、大洋中脊、海沟。
2. 大陆架浅（一般<200 米）、缓、资源丰富。
3. 海洋最深处在海沟，马里亚纳海沟是世界最深处。
4. 大洋中脊是板块张裂处，海沟是板块碰撞俯冲处。
5. 路线设计顺序：由岸及洋、由浅入深。

## 七、自测小题

1. 陆地向海洋自然延伸的浅水部分叫______。
2. 海洋中最深的地形类型是（A. 洋盆 B. 海沟 C. 大陆坡）。
3. 大洋中脊处的板块运动方式是（A. 碰撞挤压 B. 张裂拉伸 C. 静止不动）。
4. 从海岸向大洋深处，依次经过的海底地形是：大陆架→______→洋盆。
5. 世界上最深的海沟是______海沟。
6. 判断：大陆架水深一般不超过 200 米，渔业资源丰富。（对/错）

**答案**：1. 大陆架 2. B 3. B 4. 大陆坡 5. 马里亚纳 6. 对
