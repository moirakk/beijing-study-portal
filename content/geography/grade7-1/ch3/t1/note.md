# 第一节 海洋和陆地的分布

标签：#海洋和陆地 #七大洲 #四大洋

## 一、本节定位

中图版·北京版地理七年级上册 **第三章 认识海洋和陆地 · 第一节**。本节学习全球海陆分布大势、七大洲和四大洋的名称与位置，是学习世界地理的"底图"，必须做到看图能指、闭眼能画。

## 二、核心概念

| 术语 | 定义 |
|---|---|
| 大陆 | 面积广大的陆地，如亚欧大陆 |
| 岛屿 | 面积较小、四面环水的陆地，如台湾岛 |
| 半岛 | 陆地伸进海洋、三面环水的部分，如山东半岛 |
| 大洲 | 大陆及其附近岛屿的合称 |
| 大洋 | 海洋的主体部分，离大陆较远、深度大 |
| 海 | 大洋的边缘部分，靠近大陆 |
| 海峡 | 沟通两个海域的狭窄水道，如马六甲海峡 |

## 三、知识梳理

### 1. 全球海陆分布大势

- 海陆比例：**七分海洋（71%），三分陆地（29%）**。
- 分布特点：**不均匀**。陆地主要集中在**北半球**、东半球；海洋集中在南半球、西半球。
- 无论怎样划分半球，任一半球都是**海洋面积大于陆地面积**。

### 2. 七大洲

- 按面积从大到小：**亚洲、非洲、北美洲、南美洲、南极洲、欧洲、大洋洲**。口诀："亚非北南美，南极欧大洋"。
- 位置要点：
  - 亚洲、欧洲同在亚欧大陆，主体在北半球、东半球；
  - 非洲被赤道穿过中部，大部分在东半球；
  - 南北美洲在西半球，以巴拿马运河为界；
  - 南极洲纬度最高、跨经度最广，几乎全在南极圈内；
  - 大洋洲面积最小。

### 3. 大洲分界线

| 大洲 | 分界线 |
|---|---|
| 亚洲—欧洲 | 乌拉尔山脉、乌拉尔河、里海、大高加索山脉、黑海、土耳其海峡 |
| 亚洲—非洲 | 苏伊士运河 |
| 北美洲—南美洲 | 巴拿马运河 |
| 亚洲—北美洲 | 白令海峡 |

### 4. 四大洋

| 大洋 | 特点 |
|---|---|
| 太平洋 | 面积最大、最深，约占海洋面积一半 |
| 大西洋 | 第二大，轮廓略呈"S"形 |
| 印度洋 | 第三大，大部分在南半球 |
| 北冰洋 | 最小、最浅、纬度最高，大部分被海冰覆盖 |

## 五、读图与技能：世界海陆分布图判读

1. 先找**赤道、本初子午线**做参照，判断大洲所在半球。
2. 认轮廓：非洲似梯形、南美洲似倒三角、大洋洲主体澳大利亚孤悬东南、"S"形海域是大西洋。
3. 记相邻关系：太平洋被亚洲、大洋洲、南北美洲、南极洲环绕；大西洋在欧非与南北美之间。
4. 练习画**海陆简图**：用简单几何图形勾出七大洲相对位置。

## 六、易混辨析

| 对比项 | 大陆 | 岛屿 | 半岛 |
|---|---|---|---|
| 面积 | 广大 | 较小 | 不定 |
| 环水情况 | —— | 四面环水 | 三面环水 |
| 举例 | 亚欧大陆 | 格陵兰岛（世界最大岛） | 阿拉伯半岛（世界最大半岛） |

| 对比项 | 苏伊士运河 | 巴拿马运河 |
|---|---|---|
| 分隔大洲 | 亚洲—非洲 | 北美洲—南美洲 |
| 沟通海洋 | 地中海—红海 | 大西洋—太平洋 |

## 七、背记要点

1. 七分海洋，三分陆地；陆地集中在北半球、东半球。
2. 七大洲面积顺序：亚非北南美，南极欧大洋。
3. 四大洋面积顺序：太平洋＞大西洋＞印度洋＞北冰洋。
4. 亚欧分界：乌拉尔山—乌拉尔河—里海—大高加索山—黑海—土耳其海峡。
5. 亚非分界苏伊士运河；南北美分界巴拿马运河；亚洲与北美洲隔白令海峡。
6. 赤道穿过非洲中部、南美洲北部；南极洲纬度最高。
7. 世界最大岛屿是格陵兰岛。

## 八、自测小题

1. 地球表面海洋约占______%，陆地约占______%。
2. 面积最大的大洲是______，面积最小的大洲是______。
3. 面积最大的大洋是______，纬度最高的大洋是______。
4. 亚洲与非洲的分界线是（A. 巴拿马运河 B. 苏伊士运河 C. 白令海峡）。
5. 赤道横穿______洲中部（A. 非 B. 欧 C. 南极）。
6. 三面环水、一面连陆的陆地叫（A. 岛屿 B. 半岛 C. 大陆）。
7. 判断：北半球陆地面积大于海洋面积。（对/错）

**答案**：1. 71；29 2. 亚洲；大洋洲 3. 太平洋；北冰洋 4. B 5. A 6. B 7. 错（任一半球均海洋大于陆地）
