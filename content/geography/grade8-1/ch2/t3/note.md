# 第三节 气候对生产和生活的影响

标签：#中考高频 #提高 #联系实际

## 一、气候与农业生产

| 气候要素 | 对农业的影响 |
|---|---|
| 气温 | 决定作物熟制（热带一年三熟，寒带一年一熟） |
| 降水 | 决定农业类型（湿润区种植业，干旱区畜牧业） |
| 光照 | 影响作物品质和产量 |
| 热量 | 决定农作物种类（水稻喜热，小麦耐寒） |

## 二、气候与民居

| 地区 | 民居特点 | 气候原因 |
|---|---|---|
| 东南亚 | 高脚屋、竹楼 | 高温多雨，防潮通风 |
| 北极地区 | 冰屋 | 严寒，就地取材 |
| 我国南方 | 屋顶坡度大 | 降水多，利于排水 |
| 我国北方 | 屋顶坡度小 | 降水少，可晒粮食 |
| 西亚北非 | 墙厚窗小 | 炎热干燥，隔热防风沙 |

## 三、气候与服饰、饮食、交通

| 方面 | 影响 |
|---|---|
| 服饰 | 热带轻薄、寒带厚重 |
| 饮食 | 南方喜米、北方喜面；湿润区多水产 |
| 交通 | 高寒地区多冰雪交通、水乡多船运 |
| 旅游 | 夏季避暑、冬季赏雪等气候旅游 |

## 四、气候灾害

| 灾害 | 主要影响 | 典型地区 |
|---|---|---|
| 寒潮 | 剧烈降温、霜冻 | 我国北方、蒙古—西伯利亚一带 |
| 台风 | 狂风暴雨 | 我国东南沿海 |
| 洪涝 | 淹没农田、城市内涝 | 季风气候区夏季 |
| 干旱 | 作物减产、水资源短缺 | 降水变率大地区 |

## 五、要点小结

- 气候影响农业生产类型、作物种类和熟制。
- 民居、服饰、饮食深受当地气候条件制约。
- 气候灾害需了解成因、危害及防御措施。
