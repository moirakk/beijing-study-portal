# 海陆分布与变迁综合

标签：#中考高频 #提高 #综合读图

## 一、核心知识网络

```
海陆分布（七分海洋三分陆地）
    ↓
七大洲 + 四大洋 + 洲界
    ↓
海陆变迁（地壳运动、海平面升降、人类活动）
    ↓
大陆漂移 → 板块构造学说
```

## 四、对比表格：大陆漂移与板块构造

| 项目 | 大陆漂移假说 | 板块构造学说 |
|---|---|---|
| 提出者 | 魏格纳 | 众多科学家完善 |
| 核心观点 | 大陆在软流层上漂移 | 岩石圈分为板块，板块不断运动 |
| 运动机制 | 未明确说明 | 地幔对流驱动 |
| 适用范围 | 解释大陆轮廓、古生物 | 解释火山、地震、山脉、海洋 |

## 五、背记要点

1. 七大洲面积排序：**亚非北南美，南极欧大洋**。
2. 四大洋特点：**太大印北**（面积从大到小）。
3. 洲界要记牢，特别是亚欧、亚非、南北美分界线。
4. 板块交界地带 = 地壳活跃带 = 火山地震带。
