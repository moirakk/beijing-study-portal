# 第一节 海洋和陆地的分布

标签：#中考必考 #基础 #读图

## 一、海陆面积比例

地球表面约 **71% 是海洋，29% 是陆地**，概括地说“七分海洋，三分陆地”。

| 半球 | 陆地面积比例 | 海洋面积比例 |
|---|---|---|
| 北半球 | 约 39% | 约 61% |
| 南半球 | 约 19% | 约 81% |
| 东半球 | 较多 | 较少 |
| 西半球 | 较少 | 较多 |

> 💡 无论怎么划分半球，海洋面积总是大于陆地面积。

## 二、七大洲

按面积从大到小：**亚非北南美，南极欧大洋**。

| 大洲 | 面积特点 | 重要地理事物 |
|---|---|---|
| 亚洲 | 面积最大 | 喜马拉雅山脉、青藏高原 |
| 非洲 | 热带大陆 | 撒哈拉沙漠、东非大裂谷 |
| 北美洲 | 位于西半球北部 | 落基山脉、密西西比河 |
| 南美洲 | 西半球南部 | 安第斯山脉、亚马孙平原 |
| 南极洲 | 纬度最高、跨经度最广 | 冰盖、企鹅 |
| 欧洲 | 地势低平 | 阿尔卑斯山、多瑙河 |
| 大洋洲 | 面积最小 | 澳大利亚大陆 |

## 三、四大洋

| 大洋 | 面积 | 位置特点 |
|---|---|---|
| 太平洋 | 最大最深 | 亚洲、大洋洲、美洲之间 |
| 大西洋 | 呈“S”形 | 欧洲、非洲、美洲之间 |
| 印度洋 | 第三 | 亚洲、非洲、大洋洲、南极洲之间 |
| 北冰洋 | 最小最浅、纬度最高 | 北极地区 |

## 四、重要洲界

| 分界线 | 两侧大洲 |
|---|---|
| 乌拉尔山—乌拉尔河—里海—大高加索山—黑海—土耳其海峡 | 亚洲与欧洲 |
| 苏伊士运河 | 亚洲与非洲 |
| 巴拿马运河 | 北美洲与南美洲 |
| 白令海峡 | 亚洲与北美洲 |
| 直布罗陀海峡 | 欧洲与非洲 |
| 德雷克海峡 | 南美洲与南极洲 |

## 五、地图识记要点

1. 赤道穿过的大陆：**非洲大陆、南美洲大陆**。
2. 赤道穿过的大洲：非洲、亚洲、大洋洲、南美洲。
3. 本初子午线穿过的大洲：欧洲、非洲、南极洲。
4. 跨经度最广的大洲和大洋：**南极洲、北冰洋**。

## 六、要点小结

- 七分海洋三分陆地，海洋在任何半球都占主导。
- 七大洲面积口诀：亚非北南美，南极欧大洋。
- 熟记各大洲分界线，能在地图上快速定位。
