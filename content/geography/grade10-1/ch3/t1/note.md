# 第一节 水循环

## 概念定义

**水循环**：自然界的水在水圈、大气圈、岩石圈、生物圈中通过蒸发（蒸腾）、水汽输送、降水、下渗、径流等环节连续运动的过程。

按发生空间分三类：**海陆间循环**（最重要，使陆地水不断更新）、陆地内循环、海上内循环（参与水量最大）。

## 环节与人类影响表

| 环节 | 人类活动影响举例 |
| --- | --- |
| 蒸发/蒸腾 | 植树造林增大蒸腾；修水库增大库区蒸发 |
| 降水 | 人工增雨 |
| 下渗 | 城市硬化地面减少下渗；铺设透水砖增加下渗 |
| 地表径流 | 影响最大：修水库、跨流域调水、围湖造田 |

**水循环意义**：维持全球水量动态平衡；促进物质迁移和能量交换；塑造地表形态；使陆地水资源不断更新。

## 典型例题

**例 1**：用水循环原理说明"海绵城市"建设（透水砖、下凹绿地）的作用。

**解**：透水砖和绿地增加**下渗**，补充地下径流，削减地表径流，从而减轻城市内涝，同时涵养地下水、缓解热岛效应。

**例 2**：塔里木河流域的水循环属于哪种类型？其主要补给环节是什么？

**解**：属于陆地内循环为主（深居内陆，水汽难以到达海洋）；主要补给是高山冰雪融水，夏季气温高时径流量大。

## 易错点

- 参与水量最大的是**海上内循环**，与陆地关系最密切的是海陆间循环。
- 内流区（如塔里木河）也有水循环，只是以陆地内循环为主。
- 人类影响最深刻的环节是**地表径流**，其次是下渗与局部降水。
- 水资源"取之不尽"说法错误：更新有周期，超采会枯竭。

## 背记要点

1. 五大环节：蒸发—输送—降水—下渗—径流（地表、地下）。
2. 三类循环：海陆间（大循环）、陆地内、海上内。
3. 四大意义：平衡水量、迁移物质能量、塑造地表、更新水资源。
4. 高考视角：以城市内涝、水库工程为背景考查环节变化是热点，重要度★★★★★。
