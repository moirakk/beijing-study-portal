# 第二节 土壤

## 概念定义

**土壤**：陆地表层具有一定肥力、能够生长植物的疏松表层，由**矿物质、有机质、水分和空气**四种物质组成。理想土壤中矿物质约 45%、有机质约 5%、水分和空气各约 20%—30%。

**土壤肥力**：土壤供应和协调植物生长所需水、肥、气、热的能力，**有机质含量**是重要标志。

## 成土因素表

| 因素 | 作用 |
| --- | --- |
| 成土母质 | 决定矿物成分和养分状况，影响质地 |
| 生物 | **最基本、最活跃**因素，决定有机质与肥力 |
| 气候 | 湿热区风化快、淋溶强；冷湿区利于有机质积累 |
| 地貌 | 影响水热再分配与土层厚薄（坡地薄、洼地厚） |
| 时间 | 决定土壤发育程度（越久层次越分明） |
| 人类活动 | 耕作培育（水稻土）或破坏退化 |

## 典型例题

**例 1**：东北黑土有机质含量高，试从气候角度分析原因。

**解**：东北纬度高、气候冷湿：夏季草类茂盛提供大量有机质来源；冬季寒冷漫长，微生物分解缓慢，有机质大量积累，故黑土深厚肥沃。

**例 2**：热带雨林区植被茂盛，为何土壤反而贫瘠（砖红壤）？

**解**：高温多雨使有机质分解快、养分被淋溶流失快；养分多储存在植物体内，一旦植被破坏，土壤肥力迅速下降，故土壤贫瘠且呈酸性。

## 易错点

- 生物是成土**最基本最活跃**的因素，成土母质只是"物质基础"。
- 植被茂盛 ≠ 土壤肥沃（热带雨林反例）。
- 土壤颜色可指示性质：黑土富含腐殖质、红壤铁铝氧化、青（潜育）土渍水缺氧。
- 耕作层深翻、施有机肥、种植绿肥、秸秆还田是养护而非破坏。

## 背记要点

1. 四组分：矿物质、有机质、水分、空气；肥力看有机质。
2. 剖面自上而下：有机层→腐殖质层→淋溶层→淀积层→母质层→母岩层。
3. 六因素口诀：母质基础、生物核心、气候快慢、地貌再分、时间深浅、人类双刃。
4. 高考视角：黑土保护、红壤改良等结合国家粮食安全考查，重要度★★★★。
