# 第二节 大气受热过程和大气运动

## 概念定义

**大气受热过程**：太阳辐射（短波）穿过大气被削弱→到达并加热地面→地面辐射（长波）加热大气→大气逆辐射把热量还给地面（保温作用）。**地面是近地面大气的直接热源**。

**热力环流**：由地面**冷热不均**引起的大气运动，是大气运动最简单的形式。**风**：水平气压梯度力是形成风的直接原因。

## 保温与热力环流应用表

| 应用 | 原理解释 |
| --- | --- |
| 多云的夜晚较温暖 | 云层增强大气逆辐射，保温作用强 |
| 晴朗深秋易霜冻 | 大气逆辐射弱，地面散热快 |
| 海陆风 | 白天风从海吹向陆，夜晚相反 |
| 山谷风 | 白天吹谷风（沿坡上升），夜晚吹山风 |
| 城市热岛 | 市区热上升，郊区风流入市区 |

**风向规律**：高空风与等压线**平行**（气压梯度力+地转偏向力）；近地面风与等压线**斜交**（再加摩擦力），北半球右偏、南半球左偏。

## 典型例题

**例 1**：用大气受热原理解释月球表面昼夜温差远大于地球。

**解**：月球没有大气：白天无大气削弱作用，太阳辐射强，温度高；夜晚无大气逆辐射保温，热量迅速散失，温度极低，故昼夜温差极大。

**例 2**：白天海边吹什么风？画理说明。

**解**：白天陆地增温快形成低压，海洋增温慢为高压，近地面风从海洋吹向陆地，为**海风**；高空气流方向相反，构成海陆热力环流。

## 易错点

- 大气增温的直接热源是**地面长波辐射**，不是太阳辐射直接加热。
- 热力环流中先有垂直运动（冷热不均引起），后有水平运动（气压差引起）。
- 等压面凸向高空处为高压："高凸低凹"指同一水平面比较。
- 风向偏转：北半球**右**偏，南半球左偏；赤道不偏。

## 背记要点

1. 受热链条：太阳暖大地→大地暖大气→大气还大地。
2. 削弱作用三形式：吸收、反射、散射；保温靠大气逆辐射。
3. 热力环流口诀：热低压、冷高压（近地面），风从高压吹向低压。
4. 高考视角：受热过程示意图与热力环流应用（海陆风、城市风）为必考核心，重要度★★★★★。
