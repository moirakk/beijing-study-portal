# 专题九 交通运输与商业

## 核心概念 / 课标要求
交通运输方式包括铁路、公路、水运、航空、管道，各有优缺点。交通运输布局受自然、经济、社会、技术等因素影响。交通运输对聚落、商业网点布局有重要影响。商业网点布局遵循市场最优和交通最优原则。本专题要求掌握交通运输方式选择、交通线布局因素及交通对区域发展的影响。

## 知识梳理

| 方式 | 优点 | 缺点 |
|------|------|------|
| 铁路 | 运量大、速度快 | 造价高 |
| 公路 | 灵活机动 | 运量小 |
| 水运 | 运量大、成本低 | 速度慢 |
| 航空 | 速度快 | 成本高、运量小 |
| 管道 | 连续性强 | 投资大 |
| 交通影响 | 促进聚落发展 | 商业网点布局 |

## 典型例题
1. 大宗笨重货物长途运输宜选哪种方式？解答：水运或铁路，运量大、成本低。
2. 交通对聚落有何影响？解答：交通便利处聚落规模大、发展快，交通线交汇处易形成城市。
3. 商业网点布局原则？解答：市场最优（市中心）和交通最优（交通干线交汇处）。

## 易错点
1. 混淆各种运输方式的优缺点。
2. 选择运输方式时忽略货物性质与时效要求。
3. 误认为交通只影响经济，忽略对聚落和商业的影响。
4. 交通线布局忽略自然条件（地形、河流）限制。
5. 混淆市场最优与交通最优原则。

## 背记要点
1. 铁路运量大、速度快，适合大宗货物长途运输。
2. 公路灵活机动，适合短途运输。
3. 水运成本低但速度慢，适合大宗笨重货物。
4. 航空速度快但成本高，适合贵重急需货物。
5. 交通线交汇处易形成城市和商业中心。
