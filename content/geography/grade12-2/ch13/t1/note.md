# 专题十三 资源、环境与国家安全

## 核心概念 / 课标要求
资源包括自然资源（土地、水、矿产、能源）和人文资源。资源安全指资源供给满足国家发展需要。环境问题包括环境污染和生态破坏，威胁国家安全。本专题要求掌握资源分布与利用、资源安全问题、环境问题成因及保障国家安全的措施。

## 知识梳理

| 资源 | 分布 | 问题与对策 |
|------|------|------------|
| 水资源 | 南多北少 | 跨流域调水 |
| 土地资源 | 耕地减少 | 保护耕地 |
| 矿产资源 | 分布不均 | 节约利用 |
| 能源资源 | 煤多油少 | 发展新能源 |
| 环境问题 | 污染、破坏 | 治理保护 |
| 国家安全 | 资源环境 | 可持续发展 |

## 典型例题
1. 我国水资源分布特点及对策？解答：南多北少、夏多冬少；跨流域调水、修建水库、节约用水。
2. 能源安全问题如何保障？解答：发展新能源、提高能源利用效率、建立战略储备、多元化进口。
3. 环境污染对国家安全有何影响？解答：危害人民健康、破坏生态、影响社会稳定和经济发展。

## 易错点
1. 混淆资源安全与环境安全。
2. 忽略资源分布不均带来的安全问题。
3. 对策只答开发，忽略节约与保护。
4. 混淆环境污染与生态破坏。
5. 忽略资源环境与国家安全的内在联系。

## 背记要点
1. 我国水资源南多北少，需跨流域调水。
2. 能源安全需发展新能源、多元化进口。
3. 耕地是粮食安全的基础，需严格保护。
4. 环境污染危害健康、破坏生态。
5. 资源环境安全是国家安全的重要基础。
