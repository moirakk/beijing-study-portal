# 专题十二 区域地理（世界）

## 核心概念 / 课标要求
世界地理包括七大洲四大洋、主要气候类型分布、主要国家地理特征。重点区域有亚洲、欧洲、非洲、美洲、大洋洲及主要国家（日本、美国、俄罗斯、巴西、澳大利亚等）。本专题要求掌握世界海陆分布、气候类型分布规律、主要国家自然与人文地理特征。

## 知识梳理

| 区域 | 自然特征 | 人文特征 |
|------|----------|----------|
| 亚洲 | 季风气候、高原山地 | 人口稠密 |
| 欧洲 | 温带海洋性气候 | 经济发达 |
| 非洲 | 热带气候为主 | 发展较快 |
| 美洲 | 地形纵列 | 美国发达 |
| 日本 | 岛国、多火山 | 加工贸易 |
| 俄罗斯 | 纬度高、寒冷 | 重工业 |
| 巴西 | 热带雨林 | 农业发达 |

## 典型例题
1. 日本工业为何分布在太平洋沿岸？解答：岛国资源匮乏，需进口原料、出口产品，沿海交通便利。
2. 美国中部平原为何发展商品谷物农业？解答：地形平坦、土壤肥沃、机械化程度高、市场广阔。
3. 巴西热带雨林破坏有何影响？解答：生物多样性减少、全球气候变暖加剧、水土流失。

## 易错点
1. 混淆各气候类型的分布规律。
2. 忽略海陆位置对气候的影响。
3. 日本工业分布原因分析不全面。
4. 混淆主要国家的地理特征。
5. 忽略区域差异与联系。

## 背记要点
1. 热带雨林气候分布在赤道附近。
2. 地中海气候夏季炎热干燥、冬季温和多雨。
3. 日本工业分布在太平洋沿岸，进口原料出口产品。
4. 美国中部平原发展商品谷物农业。
5. 巴西拥有世界最大的热带雨林。
