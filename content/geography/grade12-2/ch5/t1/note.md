# 专题五 自然地理环境整体性

## 核心概念 / 课标要求
自然地理环境由气候、水文、土壤、生物、地貌等要素组成，各要素相互联系、相互制约，构成一个整体。某一要素变化会引起其他要素乃至整个环境的变化，即"牵一发而动全身"。本专题要求掌握整体性的表现、地理环境各要素的相互作用及人类活动对环境的整体影响。

## 知识梳理

| 要素 | 作用 | 相互联系 |
|------|------|----------|
| 气候 | 主导因素 | 影响水文、植被、土壤 |
| 水文 | 水循环 | 受气候、地形影响 |
| 土壤 | 成土因素 | 受气候、生物影响 |
| 生物 | 指示作用 | 反映气候、土壤 |
| 地貌 | 地表形态 | 影响水热再分配 |
| 整体性 | 牵一发而动全身 | 要素相互制约 |

## 典型例题
1. 黄土高原水土流失为何影响下游？解答：上游水土流失使下游河道淤积、河床抬高，影响水文与生态，体现整体性。
2. 砍伐森林对地理环境有何影响？解答：水土流失加剧、气候变干、生物多样性减少，牵一发而动全身。
3. 青藏高原隆起对气候有何影响？解答：阻挡印度洋水汽，使西北干旱，形成高原山地气候。

## 易错点
1. 混淆整体性与差异性，整体性强调要素联系，差异性强调地域分异。
2. 误认为某一要素变化只影响局部，实际影响整个环境。
3. 忽略人类活动对整体性的影响。
4. 分析问题时只罗列要素，不说明相互联系。
5. 混淆地带性分异规律与整体性。

## 背记要点
1. 整体性表现为各要素相互联系、相互制约。
2. "牵一发而动全身"是整体性的核心体现。
3. 气候是自然地理环境的主导因素。
4. 生物是自然地理环境的指示物。
5. 人类活动应遵循整体性规律，避免破坏生态。
