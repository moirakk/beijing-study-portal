# 专题十四 地理信息技术与图表判读

## 核心概念 / 课标要求
地理信息技术包括遥感（RS）、全球定位系统（GPS）、地理信息系统（GIS）。RS用于获取信息，GPS用于定位导航，GIS用于分析处理。图表判读包括等高线图、等温线图、气候图、统计图等。本专题要求掌握三种技术的区别与应用，以及常见地理图表的判读方法。

## 知识梳理

| 技术 | 功能 | 应用 |
|------|------|------|
| RS遥感 | 获取信息 | 资源调查、灾害监测 |
| GPS定位 | 定位导航 | 交通、测量 |
| GIS分析 | 分析处理 | 城市规划、决策 |
| 等高线图 | 判读地形 | 坡度、地貌 |
| 等温线图 | 判读温度 | 气温分布 |
| 统计图 | 分析数据 | 人口、经济 |

## 典型例题
1. 监测森林火灾宜用哪种技术？解答：RS遥感，可实时获取火情信息。
2. 导航定位宜用哪种技术？解答：GPS全球定位系统，提供精确位置。
3. 等高线密集处表示什么？解答：坡度陡，等高线稀疏处坡度缓。

## 易错点
1. 混淆RS、GPS、GIS的功能。
2. 忽略三种技术的综合应用。
3. 等高线判读忽略数值与疏密。
4. 等温线判读忽略影响因素。
5. 统计图判读忽略单位与趋势。

## 背记要点
1. RS用于获取信息，如资源调查、灾害监测。
2. GPS用于定位导航，提供精确位置。
3. GIS用于分析处理，支持决策。
4. 等高线密集坡度陡，稀疏坡度缓。
5. 等温线弯曲反映地形、洋流影响。
