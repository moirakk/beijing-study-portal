# 专题七 农业区位

## 核心概念 / 课标要求
农业区位因素包括自然因素（气候、地形、土壤、水源）和社会经济因素（市场、交通、政策、劳动力、科技）。农业区位选择要因地制宜、因时制宜。主要农业地域类型有季风水田农业、商品谷物农业、大牧场放牧业、乳畜业、混合农业等。本专题要求掌握农业区位因素分析、农业地域类型特征及区位选择。

## 知识梳理

| 因素 | 内容 | 影响 |
|------|------|------|
| 气候 | 光热水 | 决定作物种类 |
| 地形 | 平原、山地 | 平原宜种植 |
| 土壤 | 肥力、酸碱 | 影响作物生长 |
| 水源 | 灌溉条件 | 干旱区关键 |
| 市场 | 需求 | 决定生产规模 |
| 交通 | 运输条件 | 影响商品率 |
| 科技 | 良种、灌溉 | 提高产量 |

## 典型例题
1. 季风水田农业的区位条件？解答：气候湿热、地形平坦、水源充足、劳动力丰富、市场广阔。
2. 商品谷物农业的特点？解答：生产规模大、机械化程度高、商品率高，分布在美国中部平原。
3. 乳畜业为何分布在城市附近？解答：靠近市场，牛奶易变质需及时运输。

## 易错点
1. 混淆自然因素与社会经济因素。
2. 忽略市场对农业生产的决定性作用。
3. 季风水田农业与商品谷物农业特点混淆。
4. 分析区位时只答因素不结合具体区域。
5. 忽略农业区位因素的变化（如市场、交通变化）。

## 背记要点
1. 气候是农业区位最重要的自然因素。
2. 市场决定农业生产的类型和规模。
3. 季风水田农业分布亚洲季风区，精耕细作。
4. 商品谷物农业机械化程度高、商品率高。
5. 乳畜业靠近城市市场，大牧场放牧业地广人稀。
