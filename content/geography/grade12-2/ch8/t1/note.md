# 专题八 工业区位

## 核心概念 / 课标要求
工业区位因素包括自然因素（原料、水源、土地）和社会经济因素（市场、交通、劳动力、政策、科技、动力）。工业区位选择遵循成本最低、利润最大原则。工业地域联系包括生产联系、空间联系、信息联系。本专题要求掌握工业区位因素分析、工业区位选择及工业集聚与分散。

## 知识梳理

| 因素 | 内容 | 影响 |
|------|------|------|
| 原料 | 原料指向型 | 靠近原料产地 |
| 市场 | 市场指向型 | 靠近消费市场 |
| 动力 | 动力指向型 | 靠近能源基地 |
| 劳动力 | 劳动力指向型 | 靠近廉价劳动力 |
| 技术 | 技术指向型 | 靠近高等院校 |
| 交通 | 运输成本 | 沿交通线布局 |
| 政策 | 优惠政策 | 吸引投资 |

## 典型例题
1. 制糖工业属于哪种指向型？解答：原料指向型，因原料运输成本高、失重大，靠近原料产地。
2. 电子工业属于哪种指向型？解答：技术指向型，需高素质人才，靠近高等院校和科研机构。
3. 工业集聚有何好处？解答：共享基础设施、降低运输成本、加强信息交流、形成规模效益。

## 易错点
1. 混淆原料指向型与市场指向型。
2. 忽略工业区位因素的变化（如原料地位下降、市场上升）。
3. 工业集聚与分散的原因混淆。
4. 分析工业区位时忽略环境因素（污染工业布局）。
5. 混淆工业联系的类型。

## 背记要点
1. 原料指向型靠近原料产地，如制糖、水产品加工。
2. 市场指向型靠近消费市场，如啤酒、家具制造。
3. 技术指向型靠近高等院校，如电子、航天工业。
4. 工业集聚共享基础设施、降低成本。
5. 污染工业应布局在下风向、河流下游。
