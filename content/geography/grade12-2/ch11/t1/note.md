# 专题十一 区域地理（中国）

## 核心概念 / 课标要求
中国地理包括自然地理（地形、气候、河流、资源）和人文地理（农业、工业、交通、城市）。中国地形西高东低，呈三级阶梯；气候类型多样，季风气候显著；河流众多，长江黄河为主要水系。本专题要求掌握中国自然地理特征、主要区域差异及区域开发。

## 知识梳理

| 项目 | 内容 | 关键点 |
|------|------|--------|
| 地形 | 三级阶梯 | 西高东低 |
| 气候 | 季风气候显著 | 雨热同期 |
| 河流 | 长江、黄河 | 外流河为主 |
| 资源 | 矿产、水能 | 分布不均 |
| 农业 | 南稻北麦 | 东部季风区 |
| 工业 | 四大工业基地 | 沿海分布 |
| 区域差异 | 东部西部 | 经济差异 |

## 典型例题
1. 我国季风气候有何特点？解答：雨热同期，夏季高温多雨，冬季寒冷干燥，利于农业生产。
2. 长江中下游为何洪涝灾害多发？解答：降水集中、河道弯曲、围湖造田、上游植被破坏。
3. 我国四大工业基地分布特点？解答：集中分布在东部沿海，交通便利、市场广阔。

## 易错点
1. 混淆三级阶梯的分界线。
2. 忽略季风气候雨热同期的优势。
3. 长江黄河水文特征混淆。
4. 区域差异分析忽略自然与人文因素结合。
5. 混淆南北方农业差异。

## 背记要点
1. 中国地形西高东低，呈三级阶梯。
2. 季风气候雨热同期，利于农业生产。
3. 长江是我国第一长河，黄河含沙量大。
4. 四大工业基地：辽中南、京津唐、沪宁杭、珠三角。
5. 南稻北麦、南甘北甜反映农业地域差异。
