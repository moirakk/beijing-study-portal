# 专题六 人口与城市

## 核心概念 / 课标要求
人口增长模式分为原始型、传统型、现代型，由出生率、死亡率、自然增长率决定。人口迁移受经济、社会、政治、自然等因素影响。城市功能分区包括住宅区、商业区、工业区，城市化进程与问题密切相关。本专题要求掌握人口增长模式判断、人口迁移原因、城市功能分区与城市化问题。

## 知识梳理

| 项目 | 内容 | 关键点 |
|------|------|--------|
| 人口增长模式 | 原始型、传统型、现代型 | 三率判断 |
| 人口迁移 | 经济、社会、政治因素 | 经济为主因 |
| 城市功能分区 | 住宅、商业、工业 | 商业区市中心 |
| 城市化 | 人口向城市集中 | 发达国家后期 |
| 城市问题 | 交通、住房、环境 | 合理规划 |
| 城市区位 | 地形、气候、河流 | 河流交汇处 |

## 典型例题
1. 判断某国人口增长模式。解答：若出生率高、死亡率低、自然增长率高，为传统型；若三率均低为现代型。
2. 我国人口迁移的主要原因？解答：经济因素，东部经济发达就业机会多，吸引中西部人口迁入。
3. 商业区为何位于市中心？解答：交通便利、人流量大、地价高，付租能力强。

## 易错点
1. 混淆出生率、死亡率与自然增长率的关系。
2. 误认为发达国家人口增长快，实际多为现代型低增长。
3. 城市功能分区中工业区应位于下风向和河流下游，方向易错。
4. 混淆城市化水平与城市化速度。
5. 忽略人口迁移对迁入地和迁出地的双重影响。

## 背记要点
1. 人口增长模式由出生率、死亡率、自然增长率决定。
2. 经济因素是人口迁移最主要的因素。
3. 商业区付租能力最强，位于市中心。
4. 工业区布局在下风向、河流下游。
5. 城市化问题包括交通拥堵、住房紧张、环境污染。
