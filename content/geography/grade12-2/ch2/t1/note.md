# 专题二 大气运动与天气气候

## 核心概念 / 课标要求
大气受热过程包括太阳短波辐射、地面长波辐射与大气逆辐射。热力环流是大气运动的基本形式，形成风、气压带风带。天气系统包括锋面、气旋反气旋。气候类型由纬度、海陆、地形、洋流等因素决定。本专题要求掌握大气受热原理、气压带风带分布、天气系统判读与气候成因分析。

## 知识梳理

| 项目 | 内容 | 关键点 |
|------|------|--------|
| 受热过程 | 太阳辐射→地面→大气 | 大气逆辐射保温 |
| 热力环流 | 冷热不均引起 | 近地面高压低压 |
| 气压带 | 赤道低压、副热带高压等 | 7个气压带6个风带 |
| 锋面系统 | 冷锋、暖锋、准静止锋 | 冷锋降水在锋后 |
| 气旋反气旋 | 低压气旋、高压反气旋 | 北逆南顺 |
| 气候因子 | 纬度、海陆、地形、洋流 | 季风气候典型 |

## 典型例题
1. 冷锋过境时天气如何变化？解答：过境前晴暖，过境时大风降温降水，过境后气温降低气压升高转晴。
2. 副热带高压控制下气候特征？解答：盛行下沉气流，天气晴朗干燥，形成地中海气候夏季。
3. 我国东部季风气候成因？解答：海陆热力性质差异，冬夏季风交替。

## 易错点
1. 混淆大气逆辐射与太阳辐射，逆辐射起保温作用。
2. 冷锋降水在锋后，暖锋降水在锋前，方向易颠倒。
3. 气旋中心为低压上升气流，反气旋为高压下沉，易混淆。
4. 误认为气压带风带位置固定，实际随太阳直射点南北移动。
5. 气候类型判断忽略海陆位置与洋流影响。

## 背记要点
1. 大气逆辐射是地面保温作用的主要来源。
2. 热力环流中近地面高压对应下沉气流。
3. 冷锋符号为三角形，暖锋为半圆形。
4. 季风气候主要分布在亚洲东部和南部。
5. 地中海气候夏季受副热带高压控制炎热干燥。
