# 专题三 水循环与洋流

## 核心概念 / 课标要求
水循环包括海陆间循环、海上内循环和陆上内循环，环节有蒸发、降水、水汽输送、径流、下渗等。洋流按性质分暖流和寒流，按成因分风海流、密度流、补偿流。洋流对气候、渔场、航运、海洋污染有重要影响。本专题要求掌握水循环环节与意义、洋流分布规律及其地理意义。

## 知识梳理

| 项目 | 内容 | 关键点 |
|------|------|--------|
| 水循环类型 | 海陆间、海上、陆上 | 海陆间最重要 |
| 主要环节 | 蒸发、降水、径流 | 人类影响径流 |
| 洋流成因 | 风海流、密度流、补偿流 | 盛行风驱动 |
| 洋流分布 | 中低纬环流、中高纬环流 | 北顺南逆 |
| 渔场成因 | 寒暖流交汇、上升流 | 北海道、纽芬兰 |
| 洋流影响 | 气候、航运、污染 | 暖流增温增湿 |

## 典型例题
1. 寒暖流交汇为何形成渔场？解答：海水扰动带来营养物质，浮游生物繁盛，饵料丰富。
2. 暖流对沿岸气候有何影响？解答：增温增湿，如北大西洋暖流使西欧温和湿润。
3. 水循环中人类影响最大的环节？解答：地表径流，如修建水库、跨流域调水。

## 易错点
1. 混淆暖流寒流，暖流从低纬流向高纬，寒流相反。
2. 中低纬环流北半球顺时针、南半球逆时针，方向易颠倒。
3. 误认为所有渔场都是寒暖流交汇，秘鲁渔场为上升流。
4. 水循环环节中忽略下渗与地下径流。
5. 洋流对航运影响忽略顺流逆流速度差异。

## 背记要点
1. 海陆间循环使陆地水资源不断更新。
2. 中低纬海区大洋环流北顺南逆，东寒西暖。
3. 世界四大渔场：北海道、纽芬兰、北海、秘鲁。
4. 暖流增温增湿，寒流降温减湿。
5. 洋流顺流航行省时省燃料。
