# 专题十五 综合题答题规范

## 核心概念 / 课标要求
综合题是高考地理的重要题型，考查学生获取信息、分析问题、解决问题的能力。答题需遵循"审题—提取信息—组织答案—规范表述"的流程。常见题型有区位分析、成因分析、措施建议、评价类等。本专题要求掌握综合题答题规范，提高得分能力。

## 知识梳理

| 题型 | 答题思路 | 关键词 |
|------|----------|--------|
| 区位分析 | 自然+社会经济 | 气候、地形、市场 |
| 成因分析 | 自然+人为 | 内因、外因 |
| 措施建议 | 工程+生物+政策 | 治理、保护 |
| 评价类 | 有利+不利 | 利弊分析 |
| 特征描述 | 分布、变化 | 规律、趋势 |
| 答题规范 | 分点、术语 | 条理清晰 |

## 典型例题
1. 分析某地发展农业的有利区位条件。解答：从气候（光热水）、地形、土壤、水源、市场、交通等方面分点作答。
2. 简述某区域水土流失的治理措施。解答：工程措施（梯田、淤地坝）、生物措施（植树造林）、政策措施（退耕还林）。
3. 评价某工业布局的合理性。解答：从有利（交通、市场）和不利（污染、成本）两方面分析。

## 易错点
1. 审题不清，答非所问。
2. 答案不分点，条理混乱。
3. 使用口语化表述，缺乏地理术语。
4. 只答有利方面，忽略不利方面。
5. 答案冗长重复，要点不全。

## 背记要点
1. 答题先审题，明确设问方向。
2. 答案分点作答，条理清晰。
3. 使用规范的地理术语。
4. 区位分析从自然和社会经济两方面入手。
5. 评价类题目要利弊兼顾。

## 自测题
1. 综合题答题的基本流程是什么？
2. 区位分析应从哪些方面入手？
3. 措施建议类题目如何组织答案？
4. 评价类题目应注意什么？
5. 答题时如何做到规范表述？
