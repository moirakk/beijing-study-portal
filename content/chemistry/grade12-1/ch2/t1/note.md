# 第一节 烷烃

## 概念定义

**烷烃**：分子中碳原子之间都以**单键**相连，碳原子剩余价键全部与氢原子结合的饱和烃，通式为 $C_nH_{2n+2}$（$n \ge 1$）。

**同系物**：结构相似、分子组成相差一个或多个 $CH_2$ 原子团的烷烃互为同系物。

**烷烃的物理性质**：随碳原子数增多，熔沸点升高、密度增大；常温下 $C_1\sim C_4$ 为气态。

**烷烃的化学性质**：性质稳定，不与强酸、强碱、强氧化剂反应，但能发生**取代反应**（如与卤素在光照下）和**氧化反应**（燃烧）。

**取代反应**：有机物分子中的某些原子或原子团被其他原子或原子团所替代的反应。如 $CH_4 + Cl_2 \xrightarrow{\text{光照}} CH_3Cl + HCl$。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 通式 | $C_nH_{2n+2}$ |
| 结构 | 全部单键，饱和 |
| 取代反应 | 与卤素光照 |
| 燃烧 | $C_nH_{2n+2} + \dfrac{3n+1}{2}O_2 \to nCO_2 + (n+1)H_2O$ |
| 稳定性 | 不与强酸强碱反应 |

## 典型例题

**例 1**：写出甲烷与氯气在光照下发生取代反应的化学方程式。

**解**：$CH_4 + Cl_2 \xrightarrow{\text{光照}} CH_3Cl + HCl$，可继续取代生成 $CH_2Cl_2$、$CHCl_3$、$CCl_4$。

**例 2**：某烷烃的相对分子质量为 72，求其分子式。

**解**：$12n + 2n + 2 = 72$，$14n = 70$，$n = 5$，分子式为 $C_5H_{12}$。

## 易错点

- 烷烃通式 $C_nH_{2n+2}$，是饱和烃。
- 取代反应是烷烃的特征反应，不是加成反应。
- 甲烷与氯气取代是**逐步**进行的，产物是混合物。
- 烷烃不与强酸、强碱、强氧化剂反应。

## 背记要点

1. 烷烃通式 $C_nH_{2n+2}$。
2. 特征反应是取代反应。
3. 甲烷与氯气光照取代。
4. 常温下 $C_1\sim C_4$ 为气态。
