# 第三节 芳香烃

## 概念定义

**芳香烃**：分子中含有**苯环**的烃，简称芳烃。最简单的芳香烃是苯 $C_6H_6$。

**苯的结构**：苯分子中 6 个碳原子和 6 个氢原子在同一平面内，碳碳键是介于单键和双键之间的**特殊键**，苯环中碳碳键完全等同。

**苯的物理性质**：无色、有特殊气味的液体，密度比水小，不溶于水，易挥发。

**苯的化学性质**：苯环较稳定，能发生**取代反应**（卤代、硝化、磺化），难发生加成反应（在催化剂和高温下能与 $H_2$ 加成）。

**苯的取代反应**：苯与液溴在 $FeBr_3$ 催化下：$C_6H_6 + Br_2 \xrightarrow{FeBr_3} C_6H_5Br + HBr$；苯与浓硝酸、浓硫酸混合加热：$C_6H_6 + HNO_3 \xrightarrow{\text{浓}H_2SO_4,\Delta} C_6H_5NO_2 + H_2O$。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 结构 | 苯环，碳碳键特殊 |
| 取代反应 | 卤代、硝化、磺化 |
| 加成反应 | 与 H₂ 需催化剂高温 |
| 物理性质 | 密度比水小，不溶于水 |
| 稳定性 | 苯环较稳定 |

## 典型例题

**例 1**：写出苯与液溴在 $FeBr_3$ 催化下反应的化学方程式。

**解**：$C_6H_6 + Br_2 \xrightarrow{FeBr_3} C_6H_5Br + HBr$（溴苯）。

**例 2**：苯能否使溴水褪色？为什么？

**解**：不能。苯与溴水不反应，苯只能萃取溴水中的溴（苯层变橙红色），不能使溴水因反应而褪色。

## 易错点

- 苯环中碳碳键是**特殊键**，不是单双键交替。
- 苯能发生取代反应，难发生加成反应。
- 苯使溴水褪色是**萃取**，不是反应。
- 苯的硝化需浓硫酸作催化剂。

## 背记要点

1. 苯分子式 $C_6H_6$，含苯环。
2. 苯环碳碳键特殊，介于单双键之间。
3. 苯能取代、难加成。
4. 苯密度比水小，不溶于水。
