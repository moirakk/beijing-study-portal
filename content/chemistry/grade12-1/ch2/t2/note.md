# 第二节 烯烃 炔烃

## 概念定义

**烯烃**：分子中含有**碳碳双键**（$C=C$）的不饱和烃，通式为 $C_nH_{2n}$（$n \ge 2$），最简单的烯烃是乙烯 $CH_2=CH_2$。

**炔烃**：分子中含有**碳碳三键**（$C\equiv C$）的不饱和烃，通式为 $C_nH_{2n-2}$（$n \ge 2$），最简单的炔烃是乙炔 $CH\equiv CH$。

**加成反应**：有机物分子中不饱和键（双键、三键）断裂，与其他原子或原子团直接结合生成新物质的反应。如乙烯与溴水：$CH_2=CH_2 + Br_2 \to CH_2BrCH_2Br$。

**加聚反应**：不饱和单体通过加成反应聚合成高分子化合物的反应。如乙烯加聚：$nCH_2=CH_2 \xrightarrow{\text{催化剂}} [-CH_2-CH_2-]_n$。

**氧化反应**：烯烃、炔烃能使酸性 $KMnO_4$ 溶液褪色，能燃烧。

## 知识梳理

| 项目 | 烯烃 | 炔烃 |
| --- | --- | --- |
| 官能团 | $C=C$ | $C\equiv C$ |
| 通式 | $C_nH_{2n}$ | $C_nH_{2n-2}$ |
| 特征反应 | 加成、加聚 | 加成、加聚 |
| 使溴水褪色 | 是 | 是 |
| 使 KMnO₄ 褪色 | 是 | 是 |

## 典型例题

**例 1**：写出乙烯与溴水反应的化学方程式。

**解**：$CH_2=CH_2 + Br_2 \to CH_2BrCH_2Br$（1,2-二溴乙烷），溴水褪色。

**例 2**：如何鉴别乙烯和乙烷？

**解**：分别通入溴水或酸性 $KMnO_4$ 溶液，能使溴水或酸性 $KMnO_4$ 溶液褪色的是乙烯，不褪色的是乙烷。

## 易错点

- 烯烃通式 $C_nH_{2n}$，炔烃 $C_nH_{2n-2}$。
- 加成反应是烯烃、炔烃的特征反应，烷烃是取代反应。
- 乙烯使溴水褪色是加成，使酸性 $KMnO_4$ 褪色是氧化。
- 加聚反应中单体含不饱和键。

## 背记要点

1. 烯烃通式 $C_nH_{2n}$，炔烃 $C_nH_{2n-2}$。
2. 特征反应是加成反应。
3. 乙烯使溴水、酸性 KMnO₄ 褪色。
4. 加聚反应生成高分子。
