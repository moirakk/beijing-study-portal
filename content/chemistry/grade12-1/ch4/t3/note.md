# 第三节 核酸

## 概念定义

**核酸**：由许多**核苷酸**通过磷酸二酯键连接而成的生物大分子，是遗传信息的携带者。

**核苷酸**：核酸的基本单位，由**碱基**、**五碳糖**和**磷酸**三部分组成。

**DNA（脱氧核糖核酸）**：含脱氧核糖，碱基有腺嘌呤（A）、鸟嘌呤（G）、胞嘧啶（C）、胸腺嘧啶（T），双螺旋结构。

**RNA（核糖核酸）**：含核糖，碱基有 A、G、C、尿嘧啶（U），一般为单链。

**碱基互补配对**：DNA 中 A 与 T 配对、G 与 C 配对；RNA 中 A 与 U 配对、G 与 C 配对。

## 知识梳理

| 项目 | DNA | RNA |
| --- | --- | --- |
| 五碳糖 | 脱氧核糖 | 核糖 |
| 特有碱基 | 胸腺嘧啶 T | 尿嘧啶 U |
| 结构 | 双螺旋 | 单链 |
| 配对 | A-T, G-C | A-U, G-C |

## 典型例题

**例 1**：DNA 和 RNA 在五碳糖和碱基上有何区别？

**解**：DNA 含脱氧核糖，特有碱基胸腺嘧啶 T；RNA 含核糖，特有碱基尿嘧啶 U。

**例 2**：DNA 中碱基互补配对原则是什么？

**解**：A 与 T 配对，G 与 C 配对。

## 易错点

- DNA 含脱氧核糖和胸腺嘧啶 T，RNA 含核糖和尿嘧啶 U。
- DNA 双螺旋，RNA 单链。
- 碱基互补配对：A-T、G-C（DNA）；A-U、G-C（RNA）。
- 核苷酸由碱基、五碳糖、磷酸组成。

## 背记要点

1. 核苷酸由碱基、五碳糖、磷酸组成。
2. DNA 含脱氧核糖和 T。
3. RNA 含核糖和 U。
4. 碱基配对 A-T、G-C。
