# 第二节 蛋白质

## 概念定义

**蛋白质**：由氨基酸通过**肽键**连接而成的高分子化合物，是生命活动的主要承担者。

**氨基酸**：含有氨基（$-NH_2$）和羧基（$-COOH$）的有机化合物，是构成蛋白质的基本单位。天然氨基酸都是 α-氨基酸。

**肽键**：氨基酸分子间通过脱水缩合形成的 $-CO-NH-$ 键。

**蛋白质的性质**：①水解生成氨基酸；②具有两性（含氨基和羧基）；③盐析（加盐降低溶解度，可逆）；④变性（加热、强酸强碱、重金属盐等使蛋白质变性，不可逆）；⑤颜色反应（与浓硝酸变黄）。

**蛋白质的检验**：灼烧有烧焦羽毛气味；与浓硝酸变黄。

## 知识梳理

| 性质 | 内容 |
| --- | --- |
| 水解 | 生成氨基酸 |
| 两性 | 含氨基和羧基 |
| 盐析 | 可逆，加盐 |
| 变性 | 不可逆，加热等 |
| 颜色反应 | 与浓硝酸变黄 |

## 典型例题

**例 1**：蛋白质的盐析和变性有何区别？

**解**：盐析是加盐使蛋白质溶解度降低而析出，是**可逆**的物理变化；变性是加热、强酸强碱、重金属盐等使蛋白质结构破坏，是**不可逆**的化学变化。

**例 2**：如何检验某物质是蛋白质？

**解**：灼烧，若有烧焦羽毛气味则为蛋白质；或加入浓硝酸，若变黄则为蛋白质。

## 易错点

- 盐析可逆，变性不可逆。
- 蛋白质具有两性（含氨基和羧基）。
- 重金属盐使蛋白质变性，可用于消毒杀菌。
- 蛋白质水解最终生成氨基酸。

## 背记要点

1. 蛋白质由氨基酸通过肽键连接。
2. 肽键 $-CO-NH-$。
3. 盐析可逆，变性不可逆。
4. 蛋白质与浓硝酸变黄。
