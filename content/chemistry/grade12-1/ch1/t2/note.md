# 第二节 研究有机化合物的一般方法

## 概念定义

**研究有机物的基本步骤**：分离提纯 → 确定实验式（最简式）→ 确定分子式 → 确定结构式。

**分离提纯方法**：蒸馏（分离沸点不同的液体）、萃取（利用溶解性差异）、重结晶（利用溶解度随温度变化）、过滤等。

**元素分析**：通过燃烧法测定有机物中 C、H、O 等元素的质量分数，确定**实验式**（最简式）。

**质谱法**：测定有机物的**相对分子质量**，由质谱图中最大质荷比确定。

**红外光谱**：确定有机物中含有的**官能团**或化学键。

**核磁共振氢谱**：确定有机物中**氢原子的种类和数目**，峰数等于氢原子种类数，峰面积比等于氢原子数目比。

## 知识梳理

| 方法 | 作用 |
| --- | --- |
| 蒸馏/萃取/重结晶 | 分离提纯 |
| 元素分析 | 确定实验式 |
| 质谱法 | 确定相对分子质量 |
| 红外光谱 | 确定官能团 |
| 核磁共振氢谱 | 确定氢原子种类和数目 |

## 典型例题

**例 1**：某有机物含 C 40%、H 6.7%、O 53.3%，相对分子质量为 60，求分子式。

**解**：实验式：$C:H:O = \dfrac{40}{12}:\dfrac{6.7}{1}:\dfrac{53.3}{16} = 3.33:6.7:3.33 = 1:2:1$，实验式为 $CH_2O$，式量 30。$\dfrac{60}{30} = 2$，分子式为 $C_2H_4O_2$。

**例 2**：某有机物核磁共振氢谱有 3 个峰，峰面积比为 3:2:1，说明什么？

**解**：说明该有机物分子中有 3 种不同化学环境的氢原子，数目比为 3:2:1。

## 易错点

- 实验式是最简式，分子式是实验式的整数倍。
- 质谱法测相对分子质量，红外光谱测官能团。
- 核磁共振氢谱峰数 = 氢原子种类数，峰面积比 = 氢原子数目比。
- 分离提纯是研究的第一步。

## 背记要点

1. 研究步骤：提纯→实验式→分子式→结构式。
2. 质谱法测相对分子质量。
3. 红外光谱测官能团。
4. 核磁共振氢谱测氢原子种类和数目。
