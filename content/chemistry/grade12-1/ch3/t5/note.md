# 第五节 有机合成

## 概念定义

**有机合成**：利用简单、易得的原料，通过有机化学反应，制备具有特定结构和功能的有机化合物的过程。

**合成路线设计**：根据目标产物的结构，逆推所需原料和中间体，选择合适的反应类型和条件。

**常见官能团转化**：醇 $\to$ 醛 $\to$ 羧酸（氧化）；卤代烃 $\to$ 醇（水解）；醇 $\to$ 卤代烃（取代）；烯烃 $\to$ 醇（加成）。

**碳链增长**：通过加成、取代等反应增加碳原子数；**碳链缩短**：通过氧化、裂解等反应减少碳原子数。

**合成原则**：原料易得、步骤少、产率高、副反应少、绿色环保。

## 知识梳理

| 转化 | 反应类型 |
| --- | --- |
| 醇 → 醛 | 氧化 |
| 醛 → 羧酸 | 氧化 |
| 卤代烃 → 醇 | 水解 |
| 醇 → 卤代烃 | 取代 |
| 烯烃 → 醇 | 加成 |

## 典型例题

**例 1**：如何由乙醇制备乙酸？写出反应方程式。

**解**：乙醇催化氧化生成乙醛，乙醛再氧化生成乙酸。$CH_3CH_2OH \xrightarrow{Cu,\Delta} CH_3CHO \xrightarrow{\text{氧化}} CH_3COOH$。

**例 2**：如何由溴乙烷制备乙醇？

**解**：溴乙烷在 NaOH 水溶液中加热水解生成乙醇：$CH_3CH_2Br + NaOH \xrightarrow{\text{水},\Delta} CH_3CH_2OH + NaBr$。

## 易错点

- 合成路线设计要逆推，从目标产物反推原料。
- 官能团转化要选对反应类型和条件。
- 醇氧化成醛、醛氧化成羧酸是逐步进行的。
- 合成要遵循步骤少、产率高、绿色环保原则。

## 背记要点

1. 醇→醛→羧酸（氧化）。
2. 卤代烃→醇（水解）。
3. 烯烃→醇（加成）。
4. 合成原则：原料易得、步骤少、产率高。
