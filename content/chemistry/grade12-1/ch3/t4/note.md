# 第四节 羧酸 羧酸衍生物

## 概念定义

**羧酸**：分子中含有羧基（$-COOH$）的有机化合物。最简单的羧酸是甲酸 $HCOOH$，乙酸 $CH_3COOH$。

**羧酸的酸性**：羧酸具有酸性，能与 $NaOH$、$NaHCO_3$ 等反应。乙酸酸性比碳酸强：$CH_3COOH + NaHCO_3 \to CH_3COONa + H_2O + CO_2\uparrow$。

**酯化反应**：酸与醇反应生成酯和水的反应。乙酸与乙醇：$CH_3COOH + C_2H_5OH \xrightarrow{\text{浓}H_2SO_4,\Delta} CH_3COOC_2H_5 + H_2O$。

**酯**：羧酸衍生物，官能团是酯基（$-COO-$）。酯能发生**水解反应**（酸性或碱性条件下）。

**羧酸衍生物**：由羧酸衍生而来的化合物，如酯、酰胺等。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 官能团 | 羧基 $-COOH$ |
| 酸性 | 比碳酸强 |
| 酯化反应 | 酸 + 醇 → 酯 + 水 |
| 酯水解 | 生成酸和醇 |
| 酯基 | $-COO-$ |

## 典型例题

**例 1**：写出乙酸与乙醇发生酯化反应的化学方程式。

**解**：$CH_3COOH + C_2H_5OH \xrightarrow{\text{浓}H_2SO_4,\Delta} CH_3COOC_2H_5 + H_2O$。

**例 2**：如何证明乙酸酸性比碳酸强？

**解**：将乙酸加入 $NaHCO_3$ 溶液中，若产生 $CO_2$ 气体，说明乙酸酸性比碳酸强。

## 易错点

- 酯化反应中浓硫酸作**催化剂和吸水剂**。
- 酯化反应是酸脱羟基、醇脱氢。
- 酯能水解，碱性条件下水解更完全。
- 羧酸酸性比碳酸强，能与 NaHCO₃ 反应。

## 背记要点

1. 羧基 $-COOH$，酯基 $-COO-$。
2. 酯化反应：酸 + 醇 → 酯 + 水。
3. 乙酸酸性比碳酸强。
4. 酯能水解生成酸和醇。
