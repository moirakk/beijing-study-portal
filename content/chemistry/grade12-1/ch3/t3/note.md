# 第三节 醛 酮

## 概念定义

**醛**：羰基碳上连有氢原子的化合物，官能团是醛基（$-CHO$）。最简单的醛是甲醛 $HCHO$，乙醛 $CH_3CHO$。

**酮**：羰基碳与两个烃基相连的化合物，官能团是羰基（$>C=O$）。最简单的酮是丙酮 $CH_3COCH_3$。

**醛的氧化反应**：醛基易被氧化。乙醛能与银氨溶液发生**银镜反应**：$CH_3CHO + 2[Ag(NH_3)_2]OH \xrightarrow{\Delta} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O$；能与新制 $Cu(OH)_2$ 反应生成砖红色沉淀。

**醛的还原反应**：醛基能被还原成醇，如乙醛加氢还原成乙醇。

**醛与酮的区别**：醛基在链端，能发生银镜反应；酮的羰基在链中，不能发生银镜反应。

## 知识梳理

| 项目 | 醛 | 酮 |
| --- | --- | --- |
| 官能团 | $-CHO$ | $>C=O$ |
| 银镜反应 | 能 | 不能 |
| 与 Cu(OH)₂ | 砖红色沉淀 | 不反应 |
| 还原 | 生成醇 | 生成醇 |
| 举例 | 乙醛 | 丙酮 |

## 典型例题

**例 1**：写出乙醛与银氨溶液反应的化学方程式。

**解**：$CH_3CHO + 2[Ag(NH_3)_2]OH \xrightarrow{\Delta} CH_3COONH_4 + 2Ag\downarrow + 3NH_3 + H_2O$。

**例 2**：如何鉴别乙醛和丙酮？

**解**：分别加入银氨溶液水浴加热，能产生银镜的是乙醛，不能产生银镜的是丙酮。

## 易错点

- 醛基在链端，酮的羰基在链中。
- 醛能发生银镜反应，酮不能。
- 银镜反应需水浴加热。
- 醛基既能被氧化（生成羧酸）又能被还原（生成醇）。

## 背记要点

1. 醛基 $-CHO$，酮羰基 $>C=O$。
2. 醛能银镜反应，酮不能。
3. 醛与新制 Cu(OH)₂ 生成砖红色沉淀。
4. 醛基可被氧化、可被还原。
