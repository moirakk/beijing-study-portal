# 第一节 卤代烃

## 概念定义

**卤代烃**：烃分子中的氢原子被卤素原子取代后生成的化合物，官能团是卤素原子（$-X$，如 $-Cl$、$-Br$）。

**物理性质**：卤代烃不溶于水，密度一般比水大，沸点比相应烃高。

**水解反应（取代反应）**：卤代烃在 $NaOH$ 水溶液中加热，卤素原子被羟基取代。如 $CH_3CH_2Br + NaOH \xrightarrow{\text{水},\Delta} CH_3CH_2OH + NaBr$。

**消去反应**：卤代烃在 $NaOH$ 醇溶液中加热，脱去卤化氢生成烯烃。如 $CH_3CH_2Br + NaOH \xrightarrow{\text{醇},\Delta} CH_2=CH_2 + NaBr + H_2O$。

**消去反应条件**：与卤素原子相连的碳原子的**邻位碳**上必须有氢原子才能发生消去反应。

## 知识梳理

| 反应 | 条件 | 产物 |
| --- | --- | --- |
| 水解 | NaOH 水溶液、加热 | 醇 |
| 消去 | NaOH 醇溶液、加热 | 烯烃 |
| 官能团 | 卤素原子 | — |
| 溶解性 | 不溶于水 | — |

## 典型例题

**例 1**：写出溴乙烷在 NaOH 水溶液中加热反应的化学方程式。

**解**：$CH_3CH_2Br + NaOH \xrightarrow{\text{水},\Delta} CH_3CH_2OH + NaBr$（水解反应）。

**例 2**：写出溴乙烷在 NaOH 醇溶液中加热反应的化学方程式。

**解**：$CH_3CH_2Br + NaOH \xrightarrow{\text{醇},\Delta} CH_2=CH_2 + NaBr + H_2O$（消去反应）。

## 易错点

- 水解用 NaOH **水溶液**，消去用 NaOH **醇溶液**，条件不同产物不同。
- 消去反应要求邻位碳上有氢原子。
- 卤代烃不溶于水，密度一般比水大。
- 卤代烃是重要的有机合成中间体。

## 背记要点

1. 卤代烃官能团是卤素原子。
2. 水解：NaOH 水溶液→醇。
3. 消去：NaOH 醇溶液→烯烃。
4. 消去需邻位碳有氢。
