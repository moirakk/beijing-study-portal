# 第二节 氮及其化合物

## 概念定义

**氮气**（$N_2$）：分子中含 N≡N 三键，化学性质稳定。**氮的固定**：将游离态氮转化为化合态氮（自然固氮如雷电、生物固氮；人工固氮如合成氨）。氮元素常见化合价：$-3$、$0$、$+2$、$+4$、$+5$。

## 知识梳理

| 物质 | 主要性质 | 典型反应（条件） |
| --- | --- | --- |
| N2（0价） | 稳定，高温/放电才反应 | N2 + O2 →(放电) 2NO；N2 + 3H2 ⇌(高温高压催化剂) 2NH3 |
| NO（+2价） | 无色不溶于水，易被氧化 | 2NO + O2 = 2NO2 |
| NO2（+4价） | 红棕色刺激性，溶于水歧化 | 3NO2 + H2O = 2HNO3 + NO |
| NH3（-3价） | 极易溶于水（1:700）、碱性、还原性 | NH3 + H2O ⇌ NH3·H2O；4NH3 + 5O2 →(催化剂,Δ) 4NO + 6H2O |
| 铵盐 | 易溶、受热分解、与碱反应 | NH4Cl + NaOH →(Δ) NaCl + NH3↑ + H2O |
| 硝酸（+5价） | 强酸性、不稳定性、强氧化性 | Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2↑ + 2H2O |

**稀硝酸与铜**：3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O。浓硝酸还原产物为 $NO_2$，稀硝酸为 $NO$；常温下浓硝酸使 Fe、Al 钝化。

## 典型例题

**例 1**：如何用实验检验 $NH_4^+$？

**解**：取样加 NaOH 溶液并**加热**，将湿润的**红色石蕊试纸**靠近试管口，若试纸变蓝，则含 $NH_4^+$。原理：NH4+ + OH− →(Δ) NH3↑ + H2O，氨气是唯一能使湿润红色石蕊试纸变蓝的常见气体。

**例 2**：将充满 $NO_2$ 的试管倒立于水槽中，最终水面上升到试管的几分之几？

**解**：3NO2 + H2O = 2HNO3 + NO，3 体积 $NO_2$ 反应后剩 1 体积 $NO$，故水面上升至试管容积的 **2/3**。

## 易错点

- $NO$ 只能用**排水法**收集（易与 $O_2$ 反应）；$NO_2$ 只能用**向上排空气法**（与水反应）。
- 氨气是碱性气体，不能用浓硫酸、无水 $CaCl_2$ 干燥，应用**碱石灰**。
- 硝酸与金属反应**不生成 $H_2$**（$NO_3^-$ 的强氧化性优先被还原）。
- 铵态氮肥不能与碱性物质（草木灰）混施，否则氨挥发降低肥效。
- 实验室制氨气：2NH4Cl + Ca(OH)2 →(Δ) CaCl2 + 2NH3↑ + 2H2O，固固加热装置，试管口略向下倾斜。

## 背记要点

1. 氮价态线：$-3, 0, +2, +4, +5$；氮的固定 = 游离态 → 化合态。
2. 氨三性：极易溶（喷泉实验）、碱性（遇 HCl 白烟）、还原性（催化氧化制硝酸第一步）。
3. 硝酸三性：强酸性、不稳定性（见光分解，棕色瓶保存）、强氧化性（浓→$NO_2$，稀→$NO$）。
4. 高考视角：喷泉实验原理、铜与浓/稀硝酸对比、$NH_4^+$ 检验是高频考点；合成氨联系化学平衡与工业条件选择。
