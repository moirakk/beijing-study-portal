# 第三节 无机非金属材料

## 概念定义

**无机非金属材料**：以硅酸盐为代表的传统材料（陶瓷、玻璃、水泥）和以碳化硅、氮化硅、光导纤维等为代表的新型材料。**硅**（Si）是良好的**半导体**材料；**二氧化硅**（$SiO_2$）是酸性氧化物，是光导纤维的主要原料。

## 知识梳理

| 物质/材料 | 组成或性质 | 典型反应或用途 |
| --- | --- | --- |
| Si | 灰黑色固体，半导体 | 芯片、太阳能电池；Si + O2 →(Δ) SiO2 |
| SiO2 | 酸性氧化物，硬度大熔点高 | 光导纤维、石英坩埚；SiO2 + 2NaOH = Na2SiO3 + H2O |
| H2SiO3 | 弱酸，不溶于水 | Na2SiO3 + CO2 + H2O = Na2CO3 + H2SiO3↓（强酸制弱酸） |
| Na2SiO3 | 水溶液俗称水玻璃 | 黏合剂、防火剂 |
| 普通玻璃 | Na2SiO3、CaSiO3、SiO2 | 原料：纯碱、石灰石、石英砂 |
| 水泥 | 硅酸盐 | 原料：石灰石、黏土 |
| 新型陶瓷 | SiC、Si3N4 等 | 高温结构陶瓷、压电陶瓷、生物陶瓷 |

**特例记忆**：$SiO_2$ 是酸性氧化物却能与**氢氟酸**反应：SiO2 + 4HF = SiF4↑ + 2H2O（刻蚀玻璃）；玻璃工业：SiO2 + Na2CO3 →(高温) Na2SiO3 + CO2↑，SiO2 + CaCO3 →(高温) CaSiO3 + CO2↑。

## 典型例题

**例 1**：为什么盛放 NaOH 溶液的试剂瓶用橡胶塞而不用玻璃塞？

**解**：玻璃中含 $SiO_2$，会与 NaOH 反应：SiO2 + 2NaOH = Na2SiO3 + H2O，生成的硅酸钠有黏性，使瓶塞与瓶口黏结无法打开。

**例 2**：向 $Na_2SiO_3$ 溶液中通入过量 $CO_2$，写出方程式并说明酸性强弱结论。

**解**：Na2SiO3 + 2CO2 + 2H2O = 2NaHCO3 + H2SiO3↓（过量 $CO_2$ 生成碳酸氢钠）。由强酸制弱酸原理知酸性：$H_2CO_3 > H_2SiO_3$（碳酸强于硅酸）。

## 易错点

- $SiO_2$ 不与水反应，硅酸不能由 $SiO_2$ 直接与水化合制得，需用可溶性硅酸盐与酸反应。
- $SiO_2$ 与 HF 反应是其**特性**，不能由此说 $SiO_2$ 是两性氧化物。
- 硅是半导体用于芯片，$SiO_2$ 用于光导纤维——二者用途不要混淆。
- 高温下 SiO2 + Na2CO3 反应放出 $CO_2$，不违背"强酸制弱酸"（高温非水溶液条件，利用 $CO_2$ 挥发）。

## 背记要点

1. 硅在地壳中含量居第二（仅次于氧），自然界中只以化合态存在。
2. 三大传统硅酸盐材料：陶瓷（黏土）、玻璃（纯碱+石灰石+石英砂）、水泥（石灰石+黏土）。
3. 关键方程式：$SiO_2$ 与 NaOH、HF、$Na_2CO_3$（高温）的反应。
4. 高考视角：硅及其化合物常以材料、信息技术为背景在选择题中考查，重点是 $SiO_2$ 的"酸性氧化物特性 + HF 特例"。
