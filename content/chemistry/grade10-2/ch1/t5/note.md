# 实验活动5 不同价态含硫物质的转化

## 实验目的

1. 通过实验实现 $-2$、$0$、$+4$、$+6$ 价含硫物质之间的转化，认识**氧化剂/还原剂选择**与价态变化的关系。
2. 体会"**低价升需氧化剂，高价降需还原剂**"的转化规律，深化氧化还原反应观念。

## 知识梳理

| 转化 | 价态变化 | 所选试剂 | 反应（条件） |
| --- | --- | --- | --- |
| Na2S → S | -2 → 0（升） | 氯水（氧化剂） | Na2S + Cl2 = 2NaCl + S↓（浑浊） |
| S → SO2 | 0 → +4（升） | O2（氧化剂） | S + O2 →(点燃) SO2 |
| SO2(H2SO3) → SO4²⁻ | +4 → +6（升） | 氯水/H2O2/溴水 | SO2 + Cl2 + 2H2O = H2SO4 + 2HCl |
| SO2 → S | +4 → 0（降） | Na2S/H2S（还原剂） | 2H2S + SO2 = 3S↓ + 2H2O（归中） |
| 浓H2SO4 → SO2 | +6 → +4（降） | Cu（还原剂，Δ） | Cu + 2H2SO4(浓) →(Δ) CuSO4 + SO2↑ + 2H2O |

**产物检验**：$SO_4^{2-}$——先加稀盐酸无现象，再加 $BaCl_2$ 生成白色沉淀；$SO_2$——使品红溶液褪色（加热恢复）；S——淡黄色浑浊/沉淀。

## 典型例题

**例 1**：欲将 $H_2SO_3$ 转化为 $H_2SO_4$，下列试剂不可选的是：A. 氯水　B. $H_2O_2$　C. $H_2S$ 溶液。

**解**：选 **C**。$+4 \to +6$ 需要**氧化剂**，氯水、$H_2O_2$ 均可；$H_2S$ 是还原剂，与 $H_2SO_3$ 发生归中反应生成 S，价态反而降低。

**例 2**：向 $Na_2SO_3$ 溶液中滴加双氧水后，如何证明生成了 $SO_4^{2-}$？

**解**：取反应后溶液，先加**足量稀盐酸**（排除 $SO_3^{2-}$ 干扰，$BaSO_3$ 溶于盐酸），再滴加 $BaCl_2$ 溶液，产生**白色沉淀**，证明有 $SO_4^{2-}$ 生成。

## 易错点

- 检验 $SO_4^{2-}$ 不能用稀硝酸酸化：硝酸会把 $SO_3^{2-}$ 氧化为 $SO_4^{2-}$，造成假阳性。
- $SO_2$ 与 $H_2S$ 的反应是**归中反应**（$+4$ 与 $-2$ 归中到 $0$），不能生成更高或更低价态。
- 中间价态（0、+4）的硫**既能升又能降**，选择转化试剂时先判断价态升降方向。
- 实验中 $SO_2$ 有毒，尾气须用 NaOH 溶液吸收。

## 背记要点

1. 转化规律：价升找氧化剂（氯水、$O_2$、$H_2O_2$、酸性 $KMnO_4$）；价降找还原剂（$H_2S$、Cu 等）。
2. 归中反应典例：2H2S + SO2 = 3S↓ + 2H2O。
3. $SO_4^{2-}$ 检验规范：稀盐酸酸化 + $BaCl_2$，先排干扰后确认。
4. 高考视角：以价态坐标（价类二维图）设计物质转化路线是新高考实验探究题的常考形式。
