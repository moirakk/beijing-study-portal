# 第一节 硫及其化合物

## 概念定义

**硫**（S）：淡黄色固体，俗称硫黄，不溶于水，微溶于酒精，易溶于 $CS_2$。硫元素常见化合价：$-2$、$0$、$+4$、$+6$。**二氧化硫**（$SO_2$）是酸性氧化物，具有漂白性和还原性；**浓硫酸**具有吸水性、脱水性和强氧化性三大特性。

## 知识梳理

| 物质 | 主要性质 | 典型反应（条件） |
| --- | --- | --- |
| S（0价） | 氧化性较弱、有还原性 | Fe + S →(Δ) FeS；S + O2 →(点燃) SO2 |
| SO2（+4价） | 酸性氧化物、还原性、弱氧化性、漂白性 | SO2 + H2O ⇌ H2SO3；2SO2 + O2 ⇌(催化剂,Δ) 2SO3 |
| SO3（+6价） | 酸性氧化物 | SO3 + H2O = H2SO4（放热剧烈） |
| 稀硫酸 | 酸的通性（H⁺氧化性） | Fe + H2SO4(稀) = FeSO4 + H2↑ |
| 浓硫酸 | 吸水、脱水、强氧化性 | Cu + 2H2SO4(浓) →(Δ) CuSO4 + SO2↑ + 2H2O |

**$SO_2$ 漂白与氯水漂白的区别**：$SO_2$ 与有色物质**化合**成不稳定无色物质（加热恢复）；氯水（HClO）靠**氧化**漂白（不可恢复）。$SO_2$ 使品红褪色、不能使紫色石蕊先变红再褪色（只变红）。

## 典型例题

**例 1**：将 $SO_2$ 分别通入品红溶液、紫色石蕊溶液、酸性 $KMnO_4$ 溶液，各有何现象？体现什么性质？

**解**：品红褪色——漂白性（加热恢复红色）；石蕊变红不褪色——酸性氧化物（生成 $H_2SO_3$）；$KMnO_4$ 紫色褪去——还原性（$+4 \to +6$ 被氧化）。三种褪色原理各不相同。

**例 2**：足量铜与含 2 mol $H_2SO_4$ 的浓硫酸共热，生成的 $SO_2$ 是否为 1 mol？

**解**：不是。Cu + 2H2SO4(浓) →(Δ) CuSO4 + SO2↑ + 2H2O，随反应进行浓硫酸变稀，**稀硫酸不与铜反应**，故 $n(SO_2) < 1\ \text{mol}$。

## 易错点

- $SO_2$ 使溴水、酸性高锰酸钾褪色是**还原性**，不是漂白性。
- 浓硫酸使蔗糖变黑是**脱水性**（按 2:1 脱去 H、O），干燥气体是**吸水性**，二者不同。
- 常温下铁、铝在浓硫酸中**钝化**（发生反应生成致密氧化膜），不是不反应。
- 检验 $SO_4^{2-}$：先加稀盐酸酸化排除 $CO_3^{2-}$、$Ag^+$ 干扰，再加 $BaCl_2$ 出白色沉淀。

## 背记要点

1. 硫价态线：$-2 \to 0 \to +4 \to +6$，中间价态既有氧化性又有还原性。
2. 三大褪色原理：漂白（品红）、酸性（石蕊变红）、还原（高锰酸钾/溴水）。
3. 浓硫酸三性：吸水、脱水、强氧化（与 Cu、C 加热反应，冷时钝化 Fe/Al）。
4. 高考视角：$SO_2$ 性质多角度辨析与浓硫酸强氧化性实验是选择题高频点，价态转化贯穿工业制硫酸流程题。
