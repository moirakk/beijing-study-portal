# 实验活动4 用化学沉淀法去除粗盐中的杂质离子

## 实验目的

1. 学会用**化学沉淀法**除去粗盐水中的 $Ca^{2+}$、$Mg^{2+}$、$SO_4^{2-}$ 等可溶性杂质离子。
2. 巩固过滤、蒸发结晶等基本操作，体会"**除杂三原则**"：不引入新杂质、不减少被提纯物、易于分离。

## 知识梳理

| 杂质离子 | 加入试剂（过量） | 反应（离子方程式） |
| --- | --- | --- |
| SO4²⁻ | BaCl2 溶液 | Ba²⁺ + SO4²⁻ = BaSO4↓ |
| Mg²⁺ | NaOH 溶液 | Mg²⁺ + 2OH⁻ = Mg(OH)2↓ |
| Ca²⁺ | Na2CO3 溶液 | Ca²⁺ + CO3²⁻ = CaCO3↓ |
| 过量 Ba²⁺ | Na2CO3 溶液（兼除） | Ba²⁺ + CO3²⁻ = BaCO3↓ |
| 过量 OH⁻、CO3²⁻ | 适量稀盐酸（过滤后加） | OH⁻ + H⁺ = H2O；CO3²⁻ + 2H⁺ = H2O + CO2↑ |

**试剂加入顺序要求**：$Na_2CO_3$ 必须在 $BaCl_2$ **之后**加入（以除去过量的 $Ba^{2+}$）；盐酸必须在**过滤之后**加入。可行顺序如：NaOH → BaCl₂ → Na₂CO₃ → 过滤 → 盐酸。

## 典型例题

**例 1**：某同学按 BaCl₂ → Na₂CO₃ → NaOH 的顺序加入试剂，过滤后加盐酸。该方案是否可行？

**解**：**可行**。关键只有一条：$Na_2CO_3$ 必须在 $BaCl_2$ 之后，NaOH 的位置可任意；过量 NaOH 和 $Na_2CO_3$ 最后由盐酸除去。

**例 2**：如何检验 $SO_4^{2-}$ 已除尽？

**解**：静置后取**上层清液**少许于试管中，滴加几滴 $BaCl_2$ 溶液，若**无白色沉淀**生成，说明 $SO_4^{2-}$ 已除尽（此时溶液中已有过量 Ba²⁺ 也可直接说明）。

## 易错点

- 沉淀剂都要**过量**才能除尽杂质离子，但过量部分必须能被后续试剂除去。
- 盐酸若在过滤前加入，会溶解 $CaCO_3$、$BaCO_3$、$Mg(OH)_2$ 沉淀，使杂质重新进入溶液。
- 盐酸加"适量"：滴加至**不再产生气泡**为止；稍过量的 HCl 在蒸发时挥发除去。
- 蒸发结晶时出现**大量晶体（剩少量液体）**即停止加热，用余热蒸干，防止 NaCl 迸溅。
- 不能用 $Ba(NO_3)_2$ 代替 $BaCl_2$，也不能用 KOH 代替 NaOH（引入 $NO_3^-$、$K^+$ 新杂质）。

## 背记要点

1. 除杂三原则：不增（新杂质）、不减（NaCl）、易分离（沉淀/气体/水）。
2. 顺序口诀："碳酸钠在钡后，盐酸放最后（过滤后）"。
3. 三种沉淀剂对应：Ba²⁺→SO4²⁻，OH⁻→Mg²⁺，CO3²⁻→Ca²⁺和过量 Ba²⁺。
4. 高考视角：粗盐提纯是实验流程题经典模型，考查试剂顺序判断、离子方程式书写与"检验除尽"的规范表述。
