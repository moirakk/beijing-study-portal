# 第三节 乙醇与乙酸

## 概念定义

**乙醇**（$C_2H_5OH$，酒精）：官能团为**羟基**（—OH），无色有特殊香味液体，与水互溶。**乙酸**（$CH_3COOH$，醋酸）：官能团为**羧基**（—COOH），有强烈刺激性气味，是一元弱酸。**官能团**：决定有机物特殊性质的原子或原子团。**酯化反应**：酸与醇作用生成酯和水的反应。

## 知识梳理

| 项目 | 乙醇 | 乙酸 |
| --- | --- | --- |
| 结构简式 | CH3CH2OH | CH3COOH |
| 官能团 | 羟基 —OH | 羧基 —COOH |
| 与 Na | 2CH3CH2OH + 2Na → 2CH3CH2ONa + H2↑（平缓） | 反应更剧烈 |
| 氧化 | 2CH3CH2OH + O2 →(Cu,Δ) 2CH3CHO + 2H2O；可燃 | 已是较高氧化态，通常只燃烧 |
| 酸性 | 无（不与 NaOH、Na2CO3 反应） | 弱酸但强于碳酸：2CH3COOH + Na2CO3 → 2CH3COONa + H2O + CO2↑ |
| 酯化 | CH3COOH + C2H5OH ⇌(浓硫酸,Δ) CH3COOC2H5 + H2O | 酸脱羟基醇脱氢 |

**乙醇催化氧化机理**：Cu 在反应中先被氧化为 CuO，再被乙醇还原为 Cu（红→黑→红），Cu 作催化剂；羟基所连碳上的 H 与羟基 H 一起脱去生成乙醛（CH3CHO）。

## 典型例题

**例 1**：实验室制乙酸乙酯时，为何用**饱和碳酸钠溶液**收集？导管口为何不能插入液面以下？

**解**：饱和 $Na_2CO_3$ 溶液作用有三：**吸收挥发出的乙醇、中和/吸收乙酸、降低乙酸乙酯的溶解度**便于分层。导管口置于液面上方是为了**防止倒吸**（乙醇、乙酸易溶于水）。

**例 2**：如何用实验证明乙酸的酸性强于碳酸？

**解**：向盛有 $Na_2CO_3$（或 $NaHCO_3$）的试管中加入乙酸溶液，产生**无色气泡**（$CO_2$），依据"强酸制弱酸"证明酸性：$CH_3COOH > H_2CO_3$。方程式：2CH3COOH + Na2CO3 = 2CH3COONa + H2O + CO2↑。

## 易错点

- 乙醇与 Na 反应比水与 Na **缓和**，说明羟基氢不如水中氢活泼；乙醇不是电解质、不电离。
- 酯化反应是**可逆**反应，方程式用"⇌"，浓硫酸作**催化剂和吸水剂**。
- 酯化机理"酸脱羟基醇脱氢"，可用 $^{18}O$ 示踪：醇中 $^{18}O$ 进入**酯**中。
- 制乙酸乙酯时加料顺序：先乙醇，再**边摇边缓慢加入浓硫酸**，最后加乙酸；加碎瓷片防暴沸。
- 无水乙醇不能用作检验水的试剂，但无水 $CuSO_4$ 可检验乙醇中是否含水。

## 背记要点

1. 两大官能团：—OH（羟基）主导乙醇性质；—COOH（羧基）主导乙酸性质。
2. 乙醇三反应：与钠置换、催化氧化（Cu，生成乙醛）、酯化。
3. 乙酸两性质：弱酸性（强于碳酸）、酯化（脱羟基）。
4. 高考视角：乙酸乙酯制备实验（装置、试剂作用、防倒吸）是实验大题经典素材；官能团决定性质的思想贯穿有机推断。
