# 第二节 乙烯与有机高分子材料

## 概念定义

**乙烯**（$C_2H_4$）：最简单的烯烃，分子中含**碳碳双键**（C=C），6 个原子共平面。乙烯产量是衡量一个国家**石油化工发展水平**的标志。**加成反应**：有机物分子中不饱和键断开，与其他原子或原子团直接结合生成新化合物的反应。**聚合反应**：小分子（单体）互相结合生成高分子的反应。

## 知识梳理

| 性质 | 反应（条件） | 现象/说明 |
| --- | --- | --- |
| 氧化：燃烧 | C2H4 + 3O2 →(点燃) 2CO2 + 2H2O | 火焰明亮伴黑烟（含碳量高） |
| 氧化：被 KMnO4 氧化 | 使酸性 KMnO4 溶液褪色 | 鉴别乙烯与甲烷 |
| 加成：与溴 | CH2=CH2 + Br2 → CH2BrCH2Br | 溴水（橙色）褪色 |
| 加成：与 H2 | CH2=CH2 + H2 →(催化剂) CH3CH3 | 生成乙烷 |
| 加成：与 H2O | CH2=CH2 + H2O →(催化剂) CH3CH2OH | 工业制乙醇 |
| 加聚 | nCH2=CH2 →(催化剂) [-CH2-CH2-]n | 生成聚乙烯（塑料） |

**三大合成材料**：塑料（聚乙烯、聚氯乙烯）、合成橡胶、合成纤维。聚乙烯无毒可作食品包装袋；聚氯乙烯**有毒**不能包装食品。

## 典型例题

**例 1**：如何用化学方法鉴别甲烷和乙烯？

**解**：分别通入**溴水**（或酸性 $KMnO_4$ 溶液），使之褪色的是乙烯，不褪色的是甲烷。乙烯与溴水发生**加成**反应：CH2=CH2 + Br2 → CH2BrCH2Br。

**例 2**：除去甲烷中混有的乙烯，能否将混合气体通过酸性 $KMnO_4$ 溶液？

**解**：**不能**。$KMnO_4$ 将乙烯氧化为 $CO_2$，引入新杂质。正确方法：通过盛**溴水**的洗气瓶，乙烯被加成吸收，甲烷不反应逸出，再干燥即可。

## 易错点

- 乙烯使溴水褪色是**加成**，使酸性 $KMnO_4$ 褪色是**氧化**，原理不同。
- 聚乙烯分子中**不含碳碳双键**（双键在加聚时全部打开），不能使溴水褪色。
- 聚合反应产物是**混合物**（n 值不同），聚乙烯没有固定熔沸点。
- 乙烯的电子式、结构简式书写：结构简式必须保留双键写作 CH2=CH2，不能写成 C2H4 的"CH2CH2"。

## 背记要点

1. 乙烯结构：C=C 双键、平面形分子、键角约 120°。
2. 化学性质核心是**双键**：易加成（$Br_2$、$H_2$、$H_2O$、HCl）、易氧化、可加聚。
3. 乙烯三鉴别：溴水褪色、酸性 KMnO4 褪色、燃烧带黑烟。
4. 高考视角：加成与取代的辨析、单体与高聚物的相互推断（找双键、断双键）是有机选择题高频点。
