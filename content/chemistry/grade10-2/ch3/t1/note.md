# 第一节 认识有机化合物

## 概念定义

**有机化合物**：含碳元素的化合物（CO、$CO_2$、碳酸盐等除外）。**烃**：仅含碳、氢两种元素的有机物。**同系物**：结构相似、分子组成相差若干个 $CH_2$ 的有机物。**同分异构体**：分子式相同、结构不同的化合物。碳原子最外层 4 个电子，总形成 **4 个共价键**。

## 知识梳理

| 项目 | 甲烷（CH4） | 烷烃通性 |
| --- | --- | --- |
| 结构 | 正四面体，键角 109°28′ | 通式 CnH2n+2，碳碳单键，链状 |
| 物理性质 | 无色无味气体，难溶于水 | 随 n 增大，熔沸点升高；n≤4 为气态 |
| 氧化反应 | CH4 + 2O2 →(点燃) CO2 + 2H2O | 均可燃烧 |
| 取代反应 | CH4 + Cl2 →(光照) CH3Cl + HCl（逐步取代至 CCl4） | 光照下与卤素单质取代 |
| 稳定性 | 不与酸、碱、KMnO4 反应 | 化学性质较稳定 |

**取代反应**：有机物分子中的原子（或原子团）被其他原子（或原子团）**所代替**的反应。甲烷与氯气光照生成 $CH_3Cl$（气）、$CH_2Cl_2$、$CHCl_3$、$CCl_4$（后三者为液态）与 HCl 的混合物。

**同分异构举例**：$C_4H_{10}$ 有正丁烷、异丁烷两种；$C_5H_{12}$ 有 3 种。碳链异构体书写：主链由长到短、支链由整到散。

## 典型例题

**例 1**：下列各组物质互为同分异构体的是：A. $O_2$ 与 $O_3$　B. 正丁烷与异丁烷　C. $CH_4$ 与 $C_2H_6$。

**解**：选 **B**。A 是同素异形体（同种元素的不同单质）；B 分子式均为 $C_4H_{10}$ 而结构不同，是同分异构体；C 结构相似、相差 $CH_2$，是同系物。

**例 2**：将等体积甲烷和氯气混合光照，为何量筒内出现油状液滴且水面上升（水上集气）？

**解**：光照发生取代反应，生成的 $CH_2Cl_2$、$CHCl_3$、$CCl_4$ 为**不溶于水的油状液体**（液滴附于筒壁）；HCl **极易溶于水**，气体总体积减小，水面上升。

## 易错点

- 甲烷与氯气反应必须**光照**（黑暗中不反应），且是取代反应，不是置换反应（产物无单质）。
- 一氯甲烷之外三种氯代物常温均为液态；产物是**混合物**，无法只得到某一种氯代物。
- 同系物必须"结构相似 + 通式相同 + 组成差 $CH_2$"，如 $CH_4$ 与 $C_2H_4$ 不是同系物。
- 甲烷不能使酸性 $KMnO_4$ 溶液、溴水褪色——这是与乙烯鉴别的依据。
- $CH_2Cl_2$ 只有一种结构，正是甲烷为**正四面体**而非平面正方形的证据。

## 背记要点

1. 碳成四键；烷烃通式 $C_nH_{2n+2}$，全为单键、饱和链烃。
2. 甲烷两大反应：点燃氧化（清洁燃料）、光照取代（四步逐氯）。
3. 三个"同"辨析：同位素（原子）、同素异形体（单质）、同系物与同分异构体（化合物）。
4. 高考视角：同分异构体数目判断、取代反应概念辨析、甲烷四面体结构证据是有机入门必考点。
