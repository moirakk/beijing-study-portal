# 第一节 化学反应与能量变化

## 概念定义

**放热反应**：释放热量的化学反应（反应物总能量 > 生成物总能量）。**吸热反应**：吸收热量的化学反应（反应物总能量 < 生成物总能量）。**原电池**：将化学能转化为电能的装置，本质是自发的氧化还原反应中电子的定向移动。

## 知识梳理

| 类别 | 常见反应 |
| --- | --- |
| 放热反应 | 燃烧、中和反应、活泼金属与酸、大多数化合反应、铝热反应 |
| 吸热反应 | Ba(OH)2·8H2O 与 NH4Cl、C + CO2 →(高温) 2CO、大多数分解反应、C + H2O(g) 高温 |

**能量变化的两种视角**：宏观——反应物与生成物总能量差；微观——断键吸收能量 $E_{吸}$、成键释放能量 $E_{放}$，$E_{吸} < E_{放}$ 为放热，$E_{吸} > E_{放}$ 为吸热。

**原电池构成条件**（以铜锌稀硫酸电池为例）：①活泼性不同的两电极；②电解质溶液；③闭合回路；④能自发进行的氧化还原反应。
- 负极（Zn，氧化）：Zn − 2e⁻ = Zn²⁺
- 正极（Cu，还原）：2H⁺ + 2e⁻ = H2↑
- 电子流向：负极 → 外电路 → 正极；溶液中阳离子移向正极。

## 典型例题

**例 1**：已知断裂 1 mol H—H 键吸收 436 kJ，断裂 1 mol Cl—Cl 键吸收 243 kJ，形成 1 mol H—Cl 键放出 431 kJ。判断 H2 + Cl2 = 2HCl 的能量变化。

**解**：$E_{吸} = 436 + 243 = 679\ \text{kJ}$，$E_{放} = 2 \times 431 = 862\ \text{kJ}$。$E_{放} > E_{吸}$，反应**放热** $862 - 679 = 183\ \text{kJ}$。

**例 2**：Zn-Cu-稀硫酸原电池工作时，下列说法正确的是？A. 电流从 Zn 经导线流向 Cu　B. 正极上发生还原反应　C. $SO_4^{2-}$ 移向 Cu 电极。

**解**：选 **B**。电流方向与电子流向相反，电流从 Cu（正极）经导线流向 Zn，A 错；正极得电子发生还原反应，B 对；阴离子移向**负极**（Zn），C 错。

## 易错点

- 需要加热的反应不一定是吸热反应（如燃烧需点燃却放热）；不需加热的反应不一定放热（$Ba(OH)_2·8H_2O$ 与 $NH_4Cl$ 常温进行却吸热）。
- 原电池中"较活泼金属作负极"有例外：Mg-Al-NaOH 溶液中 **Al 作负极**（Al 与 NaOH 自发反应）。
- 电子只在**外电路**（导线）中移动，溶液中靠**离子**定向移动导电，电子不下水。
- 浓硫酸稀释、NaOH 溶解放热属于**物理/溶解过程**，不是放热"反应"。

## 背记要点

1. 判断放/吸热的两把尺子：总能量比较；键能比较（断吸成放）。
2. 吸热反应"四大金刚"：Ba(OH)2·8H2O+NH4Cl、C+CO2、C+H2O(g)、大多数分解反应。
3. 原电池口诀：负失氧（负极失电子被氧化）、正得还；电子外流负到正，阳离子内移向正极。
4. 高考视角：能量图像分析、电极反应式书写、电子/离子移动方向判断是选择题必考三件套。
