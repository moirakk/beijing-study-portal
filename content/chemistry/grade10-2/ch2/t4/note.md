# 实验活动7 化学反应速率的影响因素

## 实验目的

1. 通过对比实验探究**浓度、温度、催化剂**对化学反应速率的影响。
2. 学会运用**控制变量法**设计实验，通过气泡快慢、褪色时间等定性比较速率。

## 知识梳理

| 探究因素 | 实验方案（控制变量） | 现象与结论 |
| --- | --- | --- |
| 浓度 | 等量大理石分别加入 1 mol/L 与 0.1 mol/L 盐酸 | 浓盐酸组气泡快——浓度越大速率越快 |
| 温度 | 相同 Na2S2O3 溶液+稀硫酸，分别在热水浴与冷水浴 | 热水组先出现浑浊——温度越高速率越快 |
| 催化剂 | 两支盛 H2O2 的试管，一支加少量 MnO2 | 加 MnO2 组迅速产生大量气泡——催化剂显著加快速率 |

**关键反应**：
- CaCO3 + 2HCl = CaCl2 + H2O + CO2↑
- Na2S2O3 + H2SO4 = Na2SO4 + S↓ + SO2↑ + H2O（以出现浑浊的时间计速率）
- 2H2O2 →(MnO2) 2H2O + O2↑

**控制变量法**：每次只改变一个变量，其余条件（用量、浓度、温度、颗粒大小）保持相同，才能得出因果结论。

## 典型例题

**例 1**：探究浓度对速率的影响时，一组用块状大理石配 1 mol/L 盐酸，另一组用粉末状大理石配 0.1 mol/L 盐酸。该设计能得出结论吗？

**解**：**不能**。同时改变了浓度和接触面积**两个变量**，违反控制变量原则，无法确定气泡快慢是由哪个因素引起的。应保持大理石形状、质量相同，只改变盐酸浓度。

**例 2**：Na₂S₂O₃ 与稀硫酸实验中，如何定量比较不同温度下的反应速率？

**解**：在两只锥形瓶下各垫一张画有"×"的白纸，从混合开始计时，记录**"×"恰好被浑浊遮住的时间** $t$；$t$ 越短速率越快，可用 $1/t$ 粗略表征速率大小。

## 易错点

- 对比实验必须**只改变一个变量**，试剂用量、起始温度等其余条件严格一致。
- $MnO_2$ 是催化剂：反应前后**质量和化学性质不变**，但参与了反应历程；不能说"不参加反应"。
- 用 $H_2O_2$ 分解验证催化剂时，两试管 $H_2O_2$ 的浓度和体积必须相同。
- 温度实验中应先分别水浴至预定温度**再混合**，否则混合时温度未受控。

## 背记要点

1. 三因素结论：浓度越大、温度越高、有（合适的）催化剂，速率越快。
2. 控制变量法是实验设计的灵魂：一次只变一个量。
3. 速率的量度方法：气泡快慢、出现浑浊时间、褪色时间、收集等体积气体所需时间。
4. 高考视角：以表格形式给出多组实验数据判断变量设置是否合理、能否得出结论，是实验探究题的典型设问。
