# 第二节 化学反应的速率与限度

## 概念定义

**化学反应速率**：用单位时间内反应物浓度的减少或生成物浓度的增加表示，$v = \dfrac{\Delta c}{\Delta t}$，单位常为 $\text{mol/(L·s)}$ 或 $\text{mol/(L·min)}$。**化学平衡状态**：可逆反应中正、逆反应速率相等，各组分浓度保持不变的状态（动态平衡）。

## 知识梳理

| 影响因素 | 对速率的影响 | 说明 |
| --- | --- | --- |
| 浓度 | 增大反应物浓度，速率加快 | 固体、纯液体浓度视为常数 |
| 温度 | 升温速率加快 | 对正逆反应都加快 |
| 催化剂 | 显著加快速率 | 同等程度改变正逆速率 |
| 压强 | 增大压强（缩容），有气体参与则加快 | 恒容充惰性气体不影响 |
| 接触面积 | 固体粉碎、增大接触面加快 | 块状→粉末 |

**平衡标志判断**（对 mA(g) + nB(g) ⇌ pC(g)）：
- **等**：$v_正 = v_逆$（同一物质），或不同物质速率之比等于系数比且方向相反；
- **定**：各组分浓度、百分含量不变；颜色不变（有色体系）；
- 变量不变即平衡：若 $m+n \neq p$，压强不变可作标志；混合气体平均摩尔质量不变（组分均为气体且系数变时）。

## 典型例题

**例 1**：2 L 密闭容器中发生 N2 + 3H2 ⇌ 2NH3，2 min 内 $N_2$ 减少 0.4 mol，求 $v(H_2)$。

**解**：$v(N_2) = \dfrac{0.4}{2 \times 2} = 0.1\ \text{mol/(L·min)}$。速率比等于系数比：$v(H_2) = 3v(N_2) = 0.3\ \text{mol/(L·min)}$。

**例 2**：恒温恒容下 2SO2 + O2 ⇌ 2SO3，能说明反应达平衡的是：A. $v(SO_2) = v(SO_3)$　B. 容器内压强不变　C. $SO_2$、$O_2$、$SO_3$ 浓度比为 2:1:2。

**解**：选 **B**。A 未指明方向且同向速率之比恒等于系数比，不能说明；该反应前后气体分子数改变（3→2），压强不变说明达平衡，B 对；浓度比为系数比只是特定投料的巧合，非平衡标志，C 错。

## 易错点

- 速率是**平均速率**且取正值；同一反应用不同物质表示数值可不同，比较快慢须**换算成同一物质、同一单位**。
- 固体和纯液体不能用来表示速率，其量的改变也不影响速率。
- "浓度比等于系数比""$v(A):v(B)=$ 系数比（同向）"都**不是**平衡标志。
- 催化剂只改变速率、**不改变平衡（限度）**，不能提高转化率。
- 可逆反应转化率必小于 100%，反应物与生成物**共存**。

## 背记要点

1. $v = \Delta c / \Delta t$；速率之比 = 化学计量数之比。
2. 影响速率五因素：浓度、温度、压强（气体）、催化剂、接触面积。
3. 平衡判据"一等五不变"：$v_正=v_逆$；浓度、含量、颜色、（变量的）压强、平均摩尔质量不变。
4. 高考视角：速率计算与平衡标志判断是选择题高频点；速率-时间、浓度-时间图像分析是核心能力要求。
