# 第三节 环境保护与绿色化学

## 概念定义

**绿色化学**：从源头上减少或消除污染的化学，核心是利用化学原理**从源头防止污染**，而非"先污染后治理"。**原子经济性**：原料分子中的原子尽可能多地转变为目标产物（**加成、加聚反应原子利用率可达 100%**）。**环境问题**：酸雨、雾霾、温室效应、水体富营养化、白色污染等。

## 知识梳理

| 环境问题 | 主要成因物质 | 防治措施 |
| --- | --- | --- |
| 酸雨（pH<5.6） | SO2、NOx | 燃煤脱硫（钙基固硫）、汽车尾气催化转化 |
| 雾霾（PM2.5） | 可吸入颗粒物、SO2、NOx | 清洁能源、除尘、机动车限排 |
| 温室效应 | CO2、CH4 | 节能减排、碳捕集、开发新能源 |
| 光化学烟雾 | NOx、碳氢化合物 | 控制汽车尾气 |
| 水体富营养化 | 含 N、P 废水（水华、赤潮） | 污水脱氮除磷后排放、限磷洗涤剂 |
| 白色污染 | 废弃塑料 | 可降解塑料、分类回收 |

**关键反应**：
- 硫酸型酸雨形成：SO2 + H2O = H2SO3，2H2SO3 + O2 = 2H2SO4
- 钙基固硫：CaO + SO2 →(Δ) CaSO3，2CaSO3 + O2 = 2CaSO4
- 尾气催化转化：2NO + 2CO →(催化剂) N2 + 2CO2

## 典型例题

**例 1**：正常雨水 pH 约为 5.6（而非 7），酸雨 pH 小于 5.6，原因分别是什么？

**解**：正常雨水溶有大气中的 $CO_2$：CO2 + H2O ⇌ H2CO3，碳酸弱酸性使 pH≈5.6；酸雨则是 $SO_2$、$NO_x$ 被氧化并溶于雨水生成**硫酸、硝酸**等强酸，使 pH 进一步降低至 5.6 以下。

**例 2**：由乙烯制备 1,2-二氯乙烷有两条路线：①CH2=CH2 + Cl2 → CH2ClCH2Cl（加成）；②乙烷与 Cl2 光照取代。从绿色化学角度评价哪条更优。

**解**：**路线①更优**。加成反应原料原子全部进入产物，**原子利用率 100%**，无副产物；取代反应生成 HCl 及多种氯代物混合物，原子利用率低且产物需分离、副产物造成污染，不符合绿色化学理念。

## 易错点

- 绿色化学强调**源头预防**（防），环境治理是末端处理（治），二者层次不同。
- $CO_2$ 是温室气体但**不形成酸雨**（碳酸太弱），酸雨元凶是 $SO_2$ 和 $NO_x$。
- 酸雨在放置过程中 pH 会**继续减小**（$H_2SO_3$ 被氧化为 $H_2SO_4$）。
- 原子利用率 100% 的反应类型：**化合（加成、加聚）反应**；取代、分解、置换均达不到。
- 白色污染指**废弃塑料**污染，不是白色粉尘。

## 背记要点

1. 绿色化学核心：源头防污、原子经济（利用率 = 目标产物质量/生成物总质量 ×100%）。
2. 五 R 原则思想：减量、重复使用、回收、再生、拒用有害品。
3. 三大大气问题对应物：酸雨—SO2/NOx；温室—CO2；光化学烟雾—NOx。
4. 高考视角：绿色化学理念常与化工流程结合考查（评价路线优劣、计算原子利用率），环境情境题注重方程式与措施表述。
