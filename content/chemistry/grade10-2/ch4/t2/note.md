# 第二节 化学品的合理使用

## 概念定义

**化肥**：为作物补充营养元素的化学物质，主要有氮肥、磷肥、钾肥和复合肥。**农药**：防治病虫草害的化学品，应低毒、低残留、高效。**食品添加剂**：为改善食品品质、防腐保鲜等而加入食品的物质（须按国家标准限量使用）。**合理用药**：遵医嘱按剂量使用处方药与非处方药（OTC）。

## 知识梳理

| 类别 | 代表物质 | 作用与注意事项 |
| --- | --- | --- |
| 氮肥 | NH4HCO3、NH4Cl、尿素 CO(NH2)2 | 促枝叶生长；铵态氮肥忌与碱性肥料（草木灰）混用 |
| 磷肥 | 过磷酸钙 | 促根系发育、抗寒抗旱 |
| 钾肥 | KCl、K2SO4、草木灰（K2CO3） | 促茎秆健壮、抗倒伏 |
| 农药 | 拟除虫菊酯等新型农药 | 从高毒高残留（DDT 已禁用）向高效低毒低残留发展 |
| 食品添加剂 | 防腐剂（苯甲酸钠）、抗氧化剂、着色剂、营养强化剂（加碘盐、铁酱油） | 品种和用量必须符合国家标准，不可滥用 |
| 常见药物 | 阿司匹林（解热镇痛）、抗酸药（Al(OH)3、NaHCO3 中和胃酸） | 遵医嘱、按说明书剂量 |

**抗酸药原理**：Al(OH)3 + 3HCl = AlCl3 + 3H2O；NaHCO3 + HCl = NaCl + H2O + CO2↑（胃溃疡患者不宜用产气的 $NaHCO_3$）。

## 典型例题

**例 1**：铵态氮肥为什么不能与草木灰混合施用？用离子方程式说明。

**解**：草木灰主要成分 $K_2CO_3$ 水溶液呈**碱性**，与铵盐反应放出氨气使氮元素损失：NH4+ + OH− ⇌ NH3·H2O（受热或浓度大时放出 NH3↑），降低肥效。故碱性肥料与铵态氮肥不能混施。

**例 2**：胃酸过多的胃溃疡患者，选用 $Al(OH)_3$ 还是 $NaHCO_3$ 作抗酸药？为什么？

**解**：选 **$Al(OH)_3$**。$NaHCO_3$ 与盐酸反应产生 $CO_2$ 气体，会使胃内压强增大，有引起溃疡穿孔的危险；$Al(OH)_3$ 中和胃酸不产生气体，且其本身是不溶的弱碱，碱性温和：Al(OH)3 + 3HCl = AlCl3 + 3H2O。

## 易错点

- 尿素 $CO(NH_2)_2$ 是**有机物**氮肥，含氮量高，不是铵盐，但也应避免与碱性物质长期混放。
- 食品添加剂**合规使用是安全的**，"零添加"不等于更安全；三聚氰胺、苏丹红是**非法添加物**，不属于食品添加剂。
- "是药三分毒"：阿司匹林长期服用有副作用（如水杨酸反应），处方药必须凭医嘱。
- 农药使用并非越多越好，应适时适量，防止残留超标与环境污染。

## 背记要点

1. 化肥三要素 N、P、K：氮长叶、磷长根、钾壮秆。
2. 铵态氮肥两忌：忌碱性物质混用、忌高温暴晒（$NH_4HCO_3$ 易分解）。
3. 抗酸药两类：产气（$NaHCO_3$）与不产气（$Al(OH)_3$），溃疡患者用后者。
4. 高考视角：以生活情境（用药说明书、食品标签、施肥方案）考查化学知识的实际应用，注重信息提取与方程式表达。
