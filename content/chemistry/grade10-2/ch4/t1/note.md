# 第一节 自然资源的开发利用

## 概念定义

**金属冶炼**：把金属从矿石（化合态）中还原出来的过程，本质是 $M^{n+} + ne^- \to M$（还原）。**煤的综合利用**：干馏、气化、液化。**石油炼制**：分馏、裂化、裂解。**海水资源**：水资源（淡化）与化学资源（提取 NaCl、Br、Mg 等）。

## 知识梳理

| 冶炼方法 | 适用金属（活动性） | 实例 |
| --- | --- | --- |
| 电解法 | K、Ca、Na、Mg、Al（很活泼） | 2Al2O3 →(电解,熔融) 4Al + 3O2↑ |
| 热还原法 | Zn~Cu（较活泼） | Fe2O3 + 3CO →(高温) 2Fe + 3CO2；铝热：2Al + Fe2O3 →(高温) Al2O3 + 2Fe |
| 热分解法 | Hg、Ag（不活泼） | 2HgO →(Δ) 2Hg + O2↑ |

| 化石燃料加工 | 变化类型 | 说明 |
| --- | --- | --- |
| 煤干馏 | 化学变化 | 隔绝空气加强热→焦炭、煤焦油、焦炉气 |
| 煤气化/液化 | 化学变化 | 气化：C + H2O →(高温) CO + H2；液化制甲醇 |
| 石油分馏 | 物理变化 | 按沸点分离出汽油、煤油、柴油等 |
| 石油裂化/裂解 | 化学变化 | 裂化提高轻质油（汽油）产量；裂解获得乙烯等化工原料 |

**海水提溴/提镁要点**：提镁流程 海水 →(石灰乳) Mg(OH)2 →(盐酸) MgCl2 →(电解熔融) Mg。

## 典型例题

**例 1**：为什么冶炼铝用电解法而不用 CO 还原法？

**解**：铝**很活泼**，$Al^{3+}$ 得电子能力很弱，CO、$H_2$、C 等常规还原剂在通常条件下无法将其从 $Al_2O_3$ 中还原出来，必须用**电解熔融氧化铝**（冰晶石降低熔点）这种最强的还原手段。

**例 2**：石油分馏与裂化的本质区别是什么？各自目的？

**解**：分馏是利用沸点差异分离混合物的**物理变化**，目的是获得不同沸点范围的馏分；裂化是把长链烃断裂为短链烃的**化学变化**，目的是**提高汽油等轻质油的产量和质量**。

## 易错点

- 电解冶炼 Na、Mg、Al 用**熔融**盐/氧化物，不能电解其水溶液（水溶液电解得不到活泼金属）。
- 冶炼 Mg 用熔融 $MgCl_2$，冶炼 Al 用熔融 $Al_2O_3$（$AlCl_3$ 是共价化合物，熔融不导电）。
- 煤中不含苯、甲苯等，它们是**干馏产物**；煤的干馏、气化、液化均为化学变化，石油分馏是物理变化。
- 铝热反应用于焊接铁轨、冶炼难熔金属（V、Cr、Mn），条件是"高温"，引燃用镁条和 $KClO_3$。

## 背记要点

1. 冶炼三法对号：活泼电解、中间热还原、不活泼热分解。
2. 煤"三化一馏"：干馏、气化、液化（均化学）；石油"一分两裂"：分馏（物理）、裂化裂解（化学）。
3. 资源利用主线：可持续发展——提高原子利用率、开发新能源（太阳能、风能、氢能）。
4. 高考视角：冶炼方法选择与工业流程题（海水提镁/溴）结合考查，判断物理/化学变化是选择题常设陷阱。
