# 课题1 物质的变化和性质

## 核心概念

| 概念 | 定义 | 判断依据 |
|---|---|---|
| 物理变化 | 没有生成其他物质的变化 | 只是形状、状态改变 |
| 化学变化 | 生成其他物质的变化（化学反应） | 有新物质生成 |
| 物理性质 | 不需要发生化学变化就表现出来的性质 | 颜色、状态、气味、熔沸点、密度、硬度、溶解性、挥发性、导电导热性 |
| 化学性质 | 在化学变化中表现出来的性质 | 可燃性、氧化性、还原性、稳定性、酸碱性 |

## 知识梳理

化学变化的基本特征是有其他物质生成。化学变化中常伴随发光、放热、变色、放出气体、生成沉淀等现象，这些现象可以帮助判断，但不能作为判断依据——例如灯泡通电发光放热属于物理变化。

化学变化中一定同时发生物理变化，但物理变化中不一定发生化学变化。例如蜡烛燃烧（化学变化）时，石蜡熔化（物理变化）同时发生。

性质与变化的区别：性质是物质固有的属性，描述时常带"能""会""可以""易""难"等字眼；变化是正在发生或已经发生的过程。例如"酒精能燃烧"是化学性质，"酒精燃烧"是化学变化。

## 典型实例归类

| 实例 | 类别 |
|---|---|
| 水的沸腾、冰雪融化 | 物理变化 |
| 胆矾研碎 | 物理变化 |
| 胆矾溶液与氢氧化钠溶液反应生成蓝色沉淀 | 化学变化 |
| 石灰石与稀盐酸反应放出气体 | 化学变化 |
| 木炭燃烧、铁生锈、食物腐败 | 化学变化 |
| 石油分馏、活性炭吸附 | 物理变化 |

## 实验要点

- 观察实验的三阶段：变化前（颜色、状态）、变化中（现象）、变化后（生成物特征）。
- 胆矾研碎：蓝色块状固体变为蓝色粉末，无新物质生成。
- 加热碱式碳酸铜：绿色粉末变黑，管壁出现水珠，石灰水变浑浊，属化学变化。

## 化学方程式（拓展认识）

石灰石与稀盐酸反应：

$$
CaCO_3 + 2HCl = CaCl_2 + H_2O + CO_2\uparrow
$$

## 背记要点

1. 化学变化的本质特征：有其他（新）物质生成。
2. 发光放热等现象只能辅助判断，不能作为化学变化的依据。
3. 化学变化中一定伴随物理变化；物理变化中不一定有化学变化。
4. 描述性质带"能、易、可、会"；描述变化是过程本身。
5. 闻气体气味要用手轻轻扇动，使少量气体飘入鼻孔，切勿凑近猛吸。
