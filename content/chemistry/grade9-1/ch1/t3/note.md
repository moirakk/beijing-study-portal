# 课题3 走进化学实验室

## 核心概念

| 项目 | 要点 |
|---|---|
| 药品取用三原则 | 不能用手接触药品、不能凑近闻气味、不能尝味道 |
| 用量原则 | 未说明用量时，液体取1~2 mL，固体只需盖满试管底部 |
| 剩余药品处理 | 不放回原瓶、不随意丢弃、不带出实验室，放入指定容器 |

## 知识梳理

固体药品的取用：块状固体用镊子夹取，操作要点"一横二放三慢竖"（先横放试管，把药品放在管口，再慢慢竖起）；粉末状固体用药匙或纸槽，操作要点"一斜二送三直立"。

液体药品的倾倒：瓶塞倒放在桌上；标签朝向手心（防止残液腐蚀标签）；瓶口紧挨试管口缓慢倒入；倒完后立即盖塞并放回原处。

量筒读数：量筒放平，视线与量筒内液体凹液面的最低处保持水平。仰视读数偏小（实际偏多），俯视读数偏大（实际偏少）。

胶头滴管：垂直悬空于容器口上方滴加，不可伸入容器或接触器壁；用过后立即清洗（滴瓶上的滴管不用清洗）。

## 实验要点：酒精灯的使用

- 两查：查灯芯是否平整、酒精量是否在容积的1/4~2/3之间。
- 两禁：禁止向燃着的酒精灯添加酒精；禁止用燃着的酒精灯引燃另一盏（防止失火）。
- 一不可：熄灭时用灯帽盖灭，不可用嘴吹灭。
- 加热用外焰；给试管里液体加热时，液体不超过试管容积的1/3，试管与桌面约成45°角，管口不对着自己或他人，先预热再集中加热。

## 实验要点：仪器连接与洗涤

- 玻璃管插入橡胶塞：先把玻璃管口用水润湿，稍稍用力转动插入。
- 检查装置气密性：先将导管一端浸入水中，再用手紧握容器外壁，导管口有气泡冒出则气密性良好。
- 玻璃仪器洗净的标准：内壁附着的水既不聚成水滴，也不成股流下。

## 对比分析

| 错误操作 | 后果 |
|---|---|
| 瓶塞正放桌面 | 沾污瓶塞、污染药品 |
| 标签背向手心 | 残液流下腐蚀标签 |
| 加热前试管外壁有水 | 试管受热不均而炸裂 |
| 量筒仰视量取10 mL | 实际量取液体大于10 mL |
| 用嘴吹灭酒精灯 | 可能引起灯内酒精燃烧失火 |

## 背记要点

1. 药品取用"三不"原则：不摸、不闻（凑近）、不尝。
2. 倾倒液体：塞倒放、签向心、口挨口、缓慢倒。
3. 量筒读数视线与凹液面最低处相平；仰小俯大。
4. 酒精灯用外焰加热，盖灭不吹灭。
5. 给试管中液体加热：不超1/3、45°角、口不对人、先预热。
6. 洗净标准：水不聚滴、不成股。
