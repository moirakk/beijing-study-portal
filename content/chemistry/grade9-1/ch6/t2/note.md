# 课题2 二氧化碳制取的研究

## 核心反应

实验室制取二氧化碳：大理石（或石灰石，主要成分CaCO₃）与稀盐酸反应。

$$
CaCO_3 + 2HCl = CaCl_2 + H_2O + CO_2\uparrow
$$

## 药品选择分析

| 不选的组合 | 原因 |
|---|---|
| 碳酸钠 + 稀盐酸 | 反应速率太快，不便收集 |
| 石灰石 + 稀硫酸 | 生成微溶的硫酸钙覆盖在石灰石表面，反应逐渐停止 |
| 石灰石 + 浓盐酸 | 浓盐酸易挥发，使CO₂中混入氯化氢气体不纯 |
| 碳酸钙高温分解 | 需高温条件，装置复杂，不适合实验室 |

## 装置选择

- 发生装置：固液常温型（与过氧化氢制氧气相同）。依据：反应物状态（固+液）和反应条件（不需加热）。
- 长颈漏斗下端必须插入液面以下：防止气体从漏斗逸出（液封）。
- 用分液漏斗代替长颈漏斗的优点：可以控制加酸速率，从而控制反应速率。
- 收集装置：只能用向上排空气法。依据：CO₂密度比空气大、能溶于水（且与水反应），不能用排水法。

## 实验步骤与检验

1. 连接仪器，检查装置气密性。
2. 装入大理石（先固后液），再从长颈漏斗加入稀盐酸。
3. 向上排空气法收集（导管伸入集气瓶底部）。
4. 验满：将燃着的木条放在集气瓶口，火焰熄灭则已集满。
5. 检验：将气体通入澄清石灰水，石灰水变浑浊则是CO₂。

$$
CO_2 + Ca(OH)_2 = CaCO_3\downarrow + H_2O
$$

## 对比分析：制O₂与制CO₂

| 项目 | 过氧化氢制O₂ | 大理石制CO₂ |
|---|---|---|
| 药品状态 | 固+液 | 固+液 |
| 反应条件 | 常温（MnO₂催化） | 常温 |
| 发生装置 | 固液常温型 | 固液常温型（相同） |
| 收集方法 | 排水法或向上排空气法 | 只能向上排空气法 |
| 验满 | 带火星木条放瓶口复燃 | 燃着木条放瓶口熄灭 |

## 背记要点

1. 药品：大理石（石灰石）+ 稀盐酸；三个"不用"及原因要会解释。
2. 长颈漏斗要液封；分液漏斗可控速。
3. CO₂只能用向上排空气法收集。
4. 检验用澄清石灰水（化学方法）；验满用燃着木条放瓶口（位置在瓶口）。
5. 检验与验满的操作位置不同：检验在瓶内（通入），验满在瓶口。
