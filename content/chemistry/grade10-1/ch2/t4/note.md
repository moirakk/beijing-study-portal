# 实验活动1 配制一定物质的量浓度的溶液

## 概念定义

**容量瓶**：配制准确浓度溶液的专用仪器，瓶上标有**温度、规格（刻度线）**，只有一条刻度线。使用前须**检漏**；不能溶解、稀释（放热）、久贮溶液，不能加热。

**配制原理**：$n(\text{溶质}) = cV$ 固定不变，通过准确称量（量取）溶质并定容到指定体积实现目标浓度。

## 误差分析表（依据 $c = \dfrac{n}{V}$）

| 操作错误 | 对 $n$ 或 $V$ 影响 | 结果 |
| --- | --- | --- |
| 称量时物码放反（用了游码） | $n$ 偏小 | $c$ 偏低 |
| 未洗涤烧杯和玻璃棒 | $n$ 偏小 | $c$ 偏低 |
| 未冷却就转移定容 | 冷却后 $V$ 偏小 | $c$ 偏高 |
| 定容时仰视刻度线 | $V$ 偏大 | $c$ 偏低 |
| 定容时俯视刻度线 | $V$ 偏小 | $c$ 偏高 |
| 定容后摇匀液面下降再加水 | $V$ 偏大 | $c$ 偏低 |

## 典型例题

**例 1**：配制 250 mL 0.4 mol/L $Na_2CO_3$ 溶液，需 $Na_2CO_3$ 固体多少克？选用哪些主要仪器？

**解**：$n = cV = 0.4 \times 0.25 = 0.1\ \text{mol}$，$m = nM = 0.1 \times 106 = 10.6\ \text{g}$。仪器：托盘天平（药匙）、烧杯、玻璃棒、**250 mL 容量瓶**、胶头滴管。

**例 2**：用 18.4 mol/L 浓硫酸配制 100 mL 1.84 mol/L 稀硫酸，需量取浓硫酸多少毫升？

**解**：由稀释定律 $c_1V_1 = c_2V_2$：$18.4 \times V_1 = 1.84 \times 100$，$V_1 = 10.0\ \text{mL}$。注意：将浓硫酸沿器壁缓缓加入水中并搅拌，**冷却后**再转移定容。

## 易错点

- 容量瓶必须**规格匹配**：配 480 mL 溶液应选 **500 mL** 容量瓶，按 500 mL 计算溶质。
- 不能在容量瓶中直接溶解或稀释；溶解放热必须**冷却至室温**再转移。
- 转移时玻璃棒下端应靠在**刻度线以下**的瓶内壁上引流。
- 定容加水超过刻度线，只能**重新配制**，不能吸出多余的水。
- 仰视定容偏低、俯视偏高——画光线图理解，勿死记颠倒。

## 背记要点

1. 八步流程：计算→称量→溶解冷却→转移→洗涤→定容→摇匀→装瓶。
2. 容量瓶"三不"：不溶解、不加热、不久贮；使用前先检漏。
3. 误差分析统一用 $c = \dfrac{n}{V}$：分析操作使 $n$、$V$ 如何变。
4. 稀释定律 $c_1V_1 = c_2V_2$。
