# 第二节 氯及其化合物

## 概念定义

**氯气**（$Cl_2$）：黄绿色、有刺激性气味的有毒气体，密度比空气大，能溶于水（1:2）。氯原子最外层 7 个电子，易得 1 个电子，$Cl_2$ 具有**强氧化性**。

**氯水**：氯气的水溶液。新制氯水含三分子（$Cl_2$、$H_2O$、$HClO$）四离子（$H^+$、$Cl^-$、$ClO^-$、$OH^-$），是混合物。

**次氯酸**（$HClO$）：弱酸，具有强氧化性（**漂白、杀菌**），不稳定：$2HClO \xrightarrow{\text{光照}} 2HCl + O_2\uparrow$。

**核心方程式**：

- 实验室制法：$MnO_2 + 4HCl(\text{浓}) \xrightarrow{\Delta} MnCl_2 + Cl_2\uparrow + 2H_2O$
- 氯气与水：$Cl_2 + H_2O \rightleftharpoons HCl + HClO$（歧化）
- 制漂白粉：$2Cl_2 + 2Ca(OH)_2 = Ca(ClO)_2 + CaCl_2 + 2H_2O$，有效成分 $Ca(ClO)_2$
- 与铁：$2Fe + 3Cl_2 \xrightarrow{\text{点燃}} 2FeCl_3$（棕黄色烟，注意生成 $+3$ 价铁）

## 氯气性质一览表

| 反应对象 | 方程式 | 现象/要点 |
| --- | --- | --- |
| $Na$ | $2Na + Cl_2 \xrightarrow{\text{点燃}} 2NaCl$ | 白烟 |
| $H_2$ | $H_2 + Cl_2 \xrightarrow{\text{点燃}} 2HCl$ | 苍白色火焰，瓶口白雾 |
| $NaOH$ | $Cl_2 + 2NaOH = NaCl + NaClO + H_2O$ | 尾气吸收、84 消毒液 |
| $KI$ 溶液 | $Cl_2 + 2KI = 2KCl + I_2$ | 湿润淀粉碘化钾试纸变蓝（检验 $Cl_2$） |

## 典型例题

**例 1**：干燥的氯气能否使干燥的红色布条褪色？为什么？

**解**：不能。起漂白作用的是 $HClO$，干燥 $Cl_2$ 无漂白性；遇湿润布条时 $Cl_2 + H_2O \rightleftharpoons HCl + HClO$，生成的 $HClO$ 使布条褪色。

**例 2**：如何检验某溶液中含 $Cl^-$？

**解**：取样，先加**稀硝酸**酸化（排除 $CO_3^{2-}$ 等干扰），再滴加 $AgNO_3$ 溶液，若产生白色沉淀（$Ag^+ + Cl^- = AgCl\downarrow$），则含 $Cl^-$。

## 易错点

- 氯水的漂白是 $HClO$ 的**氧化漂白**（不可逆），区别于活性炭吸附、$SO_2$ 化合漂白。
- 新制氯水与久置氯水不同：久置后 $HClO$ 分解，几乎变成稀盐酸。
- 制 $Cl_2$ 必须用**浓**盐酸且加热，稀盐酸不反应；净化顺序先饱和食盐水后浓硫酸，不能颠倒。
- 漂白粉失效原理：$Ca(ClO)_2 + CO_2 + H_2O = CaCO_3\downarrow + 2HClO$，$HClO$ 再见光分解。
- 检验 $Cl^-$ 用稀硝酸酸化，不能用盐酸。

## 背记要点

1. 新制氯水"三分子四离子"，多重性质：酸性（$H^+$）、氧化性（$HClO$、$Cl_2$）、$Cl^-$ 沉淀反应。
2. $Cl_2$ 与碱反应通式：氯气 + 碱 → 氯化物 + 次氯酸盐 + 水。
3. 制气四流程：发生→净化→收集→尾气处理；氯气有毒，尾气用 $NaOH$ 吸收。
4. 燃烧不一定需要 $O_2$：$H_2$、$Na$、$Fe$、$Cu$ 都能在 $Cl_2$ 中燃烧。
