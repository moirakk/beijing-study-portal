# 第二节 离子反应

## 概念定义

**电解质**：在水溶液里**或**熔融状态下能导电的**化合物**（酸、碱、盐、活泼金属氧化物、水）。
**非电解质**：在水溶液里**和**熔融状态下都不导电的化合物（蔗糖、酒精、$CO_2$、$NH_3$ 等）。

**电离**：电解质溶于水或受热熔化时，离解成自由移动离子的过程。如 $NaCl = Na^+ + Cl^-$，$H_2SO_4 = 2H^+ + SO_4^{2-}$。

**离子反应**：有离子参加或生成的反应。**发生条件**（复分解型）：生成沉淀、放出气体或生成水（弱电解质）。

## 离子方程式书写四步表

| 步骤 | 内容 | 示例（$CaCO_3$ 与盐酸） |
| --- | --- | --- |
| 写 | 写化学方程式 | $CaCO_3 + 2HCl = CaCl_2 + H_2O + CO_2\uparrow$ |
| 拆 | 易溶强电解质拆成离子 | $CaCO_3 + 2H^+ + 2Cl^- = Ca^{2+} + 2Cl^- + H_2O + CO_2\uparrow$ |
| 删 | 删两边不参加反应的离子 | 删去 $2Cl^-$ |
| 查 | 查原子守恒、电荷守恒 | $CaCO_3 + 2H^+ = Ca^{2+} + H_2O + CO_2\uparrow$ |

**不拆**：单质、氧化物、气体、水、弱酸弱碱、难溶物（$CaCO_3$、$BaSO_4$、$AgCl$ 等）。

## 典型例题

**例 1**：写出 $NaOH$ 溶液与稀硫酸反应的离子方程式。

**解**：化学方程式 $2NaOH + H_2SO_4 = Na_2SO_4 + 2H_2O$；拆、删后得
$$H^+ + OH^- = H_2O$$
这也是强酸与强碱（生成可溶性盐）中和反应的通式。

**例 2**：判断 $K^+$、$Ba^{2+}$、$OH^-$、$SO_4^{2-}$ 能否在同一溶液中大量共存。

**解**：不能。$Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$ 生成沉淀，故不能大量共存。共存判断核心：离子间不能生成沉淀、气体或水。

## 易错点

- 电解质、非电解质都必须是**化合物**：$Cu$、$NaCl$ 溶液既不是电解质也不是非电解质。
- $CO_2$、$SO_2$、$NH_3$ 的水溶液导电，但导电的是与水反应的产物，它们本身是**非电解质**。
- 微溶物拆写：作反应物且为澄清溶液（如石灰水）拆，作生成物或悬浊液不拆。
- $NaHCO_3$ 电离写 $Na^+ + HCO_3^-$，$HCO_3^-$ **不能**再拆成 $H^+ + CO_3^{2-}$。
- 电荷不守恒是高考判错高频点，如 $Fe + 2H^+ = Fe^{3+} + H_2\uparrow$（错，应生成 $Fe^{2+}$）。

## 背记要点

1. 电解质判断"两看"：一看是不是化合物，二看**自身**能否电离导电。
2. 强电解质＝强酸＋强碱＋大多数盐；弱电解质＝弱酸＋弱碱＋水。
3. 中和反应通式：$H^+ + OH^- = H_2O$（强酸强碱可溶盐）。
4. 检验 $SO_4^{2-}$：先加稀盐酸无现象，再加 $BaCl_2$ 溶液出白色沉淀。
