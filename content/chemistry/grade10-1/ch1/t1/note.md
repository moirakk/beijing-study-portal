# 第一节 物质的分类及转化

## 概念定义

**分类法**是研究化学的重要方法，常用**树状分类法**（同一标准逐级分类）和**交叉分类法**（多个标准并列分类）。

**分散系**：把一种（或多种）物质分散在另一种（或多种）物质中所得到的体系。按分散质粒子直径大小分为：溶液（$<1\ \text{nm}$）、胶体（$1\sim100\ \text{nm}$）、浊液（$>100\ \text{nm}$）。

**丁达尔效应**：光束通过胶体时出现一条光亮的"通路"，是区分胶体与溶液的物理方法。

## 酸碱盐氧化物转化关系表

| 转化 | 举例（化学方程式） |
| --- | --- |
| 金属 → 碱性氧化物 | $2Ca + O_2 \xrightarrow{\text{点燃}} 2CaO$ |
| 碱性氧化物 → 碱 | $CaO + H_2O = Ca(OH)_2$ |
| 碱 → 盐 | $Ca(OH)_2 + CO_2 = CaCO_3\downarrow + H_2O$ |
| 非金属 → 酸性氧化物 | $C + O_2 \xrightarrow{\text{点燃}} CO_2$ |
| 酸性氧化物 → 酸 | $CO_2 + H_2O = H_2CO_3$ |
| 酸 → 盐 | $H_2CO_3 + 2NaOH = Na_2CO_3 + 2H_2O$ |

**胶体的重要性质**：丁达尔效应、聚沉（加电解质、加热）、电泳。$Fe(OH)_3$ 胶体制备：向沸水中滴加饱和 $FeCl_3$ 溶液并继续煮沸至红褐色：$FeCl_3 + 3H_2O \xrightarrow{\Delta} Fe(OH)_3\text{(胶体)} + 3HCl$。

## 典型例题

**例 1**：下列分散系中能产生丁达尔效应的是（　）
A. $NaCl$ 溶液　B. $Fe(OH)_3$ 胶体　C. 泥水　D. 蔗糖溶液

**解**：丁达尔效应是胶体特有性质，粒子直径 $1\sim100\ \text{nm}$ 对光散射明显。选 **B**。

**例 2**：判断"$Na_2O$、$Na_2O_2$ 都是碱性氧化物"是否正确。

**解**：不正确。碱性氧化物指与酸反应**只生成盐和水**的氧化物。$Na_2O_2$ 与酸反应还生成 $O_2$（$2Na_2O_2 + 4HCl = 4NaCl + 2H_2O + O_2\uparrow$），属于过氧化物，不是碱性氧化物。

## 易错点

- 碱性氧化物一定是金属氧化物，但金属氧化物**不一定**是碱性氧化物（如 $Na_2O_2$、$Al_2O_3$、$Mn_2O_7$）。
- 酸性氧化物不一定是非金属氧化物（如 $Mn_2O_7$）；$CO$、$NO$ 是**不成盐氧化物**。
- 胶体区别于其他分散系的**本质**是分散质粒子直径大小，不是丁达尔效应。
- 制 $Fe(OH)_3$ 胶体不能用 $NaOH$ 溶液（得沉淀），也不能长时间煮沸（聚沉）。

## 背记要点

1. 分散系三分法按**粒子直径**：$<1\ \text{nm}$ 溶液、$1\sim100\ \text{nm}$ 胶体、$>100\ \text{nm}$ 浊液。
2. 口诀："碱氧遇酸盐加水，酸氧遇碱盐加水"。
3. 胶体三性质：丁达尔、聚沉、电泳；$Fe(OH)_3$ 胶体呈红褐色。
