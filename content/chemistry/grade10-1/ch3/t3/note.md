# 实验活动2 铁及其化合物的性质

## 概念定义

本实验通过系列小实验**验证铁三角转化**并掌握 $Fe^{2+}$、$Fe^{3+}$ 的检验方法。

**实验目的**：① 探究 $Fe$、$Fe^{2+}$、$Fe^{3+}$ 的氧化性与还原性；② 学会 $Fe(OH)_2$、$Fe(OH)_3$ 的制备；③ 掌握 $KSCN$ 检验 $Fe^{3+}$ 的方法。

**试剂**：铁粉、$FeCl_3$ 溶液、$FeSO_4$ 溶液、氯水、$KSCN$ 溶液、$NaOH$ 溶液、稀盐酸、锌片、铜片。

## 实验现象与结论表

| 实验操作 | 现象 | 离子方程式/结论 |
| --- | --- | --- |
| $FeCl_3$ 溶液 + $KSCN$ | 变**血红色** | $Fe^{3+} + 3SCN^- = Fe(SCN)_3$，检验 $Fe^{3+}$ |
| $FeCl_3$ 溶液 + 过量铁粉 | 棕黄→浅绿，加 $KSCN$ 不变红 | $Fe + 2Fe^{3+} = 3Fe^{2+}$，$Fe^{3+}$ 有氧化性 |
| $FeCl_3$ 溶液 + 铜片 | 铜溶解，溶液变蓝绿 | $Cu + 2Fe^{3+} = Cu^{2+} + 2Fe^{2+}$ |
| $FeSO_4$ 溶液 + 氯水后加 $KSCN$ | 变血红色 | $2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$，$Fe^{2+}$ 有还原性 |
| $FeSO_4$ + $NaOH$（隔氧） | 白→灰绿→红褐 | $Fe^{2+} + 2OH^- = Fe(OH)_2\downarrow$，再被氧化 |
| $FeCl_3$ + $NaOH$ | 红褐色沉淀 | $Fe^{3+} + 3OH^- = Fe(OH)_3\downarrow$ |

## 典型例题

**例 1**：实验中配制 $FeSO_4$ 溶液时为什么要加入少量铁粉和稀硫酸？

**解**：加**铁粉**防止 $Fe^{2+}$ 被空气氧化（$Fe + 2Fe^{3+} = 3Fe^{2+}$，将已生成的 $Fe^{3+}$ 还原）；加**稀硫酸**抑制 $Fe^{2+}$ 水解，防止溶液变浑浊。

**例 2**：向 $FeCl_2$ 溶液中滴加氯水再加 $KSCN$ 变红。有同学认为应先加 $KSCN$ 再加氯水，为什么？

**解**：先加 $KSCN$ 不变红可**排除原溶液含 $Fe^{3+}$** 的干扰，再加氯水变红才能确证 $Fe^{2+}$ 的存在及其还原性。先氧化后检验则无法说明原溶液不含 $Fe^{3+}$。

## 易错点

- 制 $Fe(OH)_2$ 三措施缺一不可：溶液煮沸除氧、滴管插入液面下、液面覆油（或用 $H_2$ 保护）。
- $KSCN$ 只检验 $Fe^{3+}$，$Fe^{2+}$ 遇 $KSCN$ **不变色**。
- 观察 $Fe(OH)_2$ 白色沉淀须**迅速**，否则很快变灰绿色。
- 铁粉过量时溶液中只有 $Fe^{2+}$；氯水过量时只有 $Fe^{3+}$——注意"过量"字眼。
- 实验后含铁废液应回收处理，不能直接倒入下水道。

## 背记要点

1. 铁三角实验主线：$Fe \xrightarrow{HCl} Fe^{2+} \xrightarrow{\text{氯水}} Fe^{3+} \xrightarrow{Fe/Cu} Fe^{2+}$。
2. $Fe^{3+}$ 检验：$KSCN$ 变血红；$Fe^{2+}$ 检验：先 $KSCN$ 不红，加氯水变红。
3. $Fe(OH)_2$ 制备口诀："煮沸除氧、滴管入液、液面封油"。
4. 颜色链：$Fe^{2+}$ 浅绿、$Fe^{3+}$ 棕黄、$Fe(SCN)_3$ 血红、$Fe(OH)_3$ 红褐。
