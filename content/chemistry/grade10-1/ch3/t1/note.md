# 第一节 铁及其化合物

## 概念定义

**铁**：地壳中含量第四（$O>Si>Al>Fe$）的元素，是应用最广泛的金属。铁有 $+2$、$+3$ 两种常见价态，与弱氧化剂（$H^+$、$S$、$Cu^{2+}$、$I_2$）反应生成 $+2$ 价，与强氧化剂（$Cl_2$、稀 $HNO_3$）反应生成 $+3$ 价。

**铁三角**：$Fe$、$Fe^{2+}$、$Fe^{3+}$ 之间的相互转化关系，是高考金属专题核心。

**核心方程式**：

- $Fe + 2Fe^{3+} = 3Fe^{2+}$（除 $Fe^{3+}$ 杂质加铁粉）；$Cu + 2Fe^{3+} = Cu^{2+} + 2Fe^{2+}$（刻蚀铜电路板）
- $2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$
- $Fe(OH)_2$ 被氧化：$4Fe(OH)_2 + O_2 + 2H_2O = 4Fe(OH)_3$（白色→灰绿→红褐色）
- 铁与水蒸气：$3Fe + 4H_2O(g) \xrightarrow{\text{高温}} Fe_3O_4 + 4H_2\uparrow$

## 铁的重要化合物对比表

| 物质 | 颜色/状态 | 关键性质 |
| --- | --- | --- |
| $FeO$ | 黑色粉末 | 碱性氧化物，$+2$ 价 |
| $Fe_2O_3$（铁红） | 红棕色粉末 | 碱性氧化物，$+3$ 价 |
| $Fe_3O_4$（磁性氧化铁） | 黑色晶体 | 含 $+2$、$+3$ 价（1:2） |
| $Fe(OH)_2$ | 白色沉淀 | 极易被 $O_2$ 氧化变红褐 |
| $Fe(OH)_3$ | 红褐色沉淀 | 受热分解为 $Fe_2O_3$ |
| $Fe^{2+}$ 盐溶液 | 浅绿色 | 还原性为主 |
| $Fe^{3+}$ 盐溶液 | 棕黄色 | 氧化性，遇 $KSCN$ 变红 |

## 典型例题

**例 1**：如何检验某溶液中含 $Fe^{2+}$ 而不含 $Fe^{3+}$？

**解**：取样，先滴加 $KSCN$ 溶液，**不变红**，说明无 $Fe^{3+}$；再滴加**氯水**（或 $H_2O_2$），溶液**变红**（$2Fe^{2+} + Cl_2 = 2Fe^{3+} + 2Cl^-$，$Fe^{3+} + 3SCN^- = Fe(SCN)_3$），说明含 $Fe^{2+}$。顺序不能颠倒。

**例 2**：5.6 g 铁粉加入 200 mL 2 mol/L 稀盐酸中，求生成 $H_2$ 在标况下的体积。

**解**：$n(Fe) = \dfrac{5.6}{56} = 0.1\ \text{mol}$，$n(HCl) = 0.2 \times 2 = 0.4\ \text{mol}$。$Fe + 2HCl = FeCl_2 + H_2\uparrow$，$0.1$ mol $Fe$ 需 $0.2$ mol $HCl$，盐酸过量，按铁计算：$n(H_2) = 0.1\ \text{mol}$，$V = 0.1 \times 22.4 = 2.24\ \text{L}$。

## 易错点

- 铁与盐酸、稀硫酸、$CuSO_4$ 反应生成 **$Fe^{2+}$**，与 $Cl_2$、过量稀硝酸反应生成 **$Fe^{3+}$**，不要混淆。
- 铁与水蒸气高温反应生成 $Fe_3O_4$ 而不是 $Fe_2O_3$。
- 制备 $Fe(OH)_2$ 需隔绝 $O_2$：亚铁盐溶液煮沸除氧、胶头滴管插入液面以下、液面加植物油。
- $Fe^{3+}$ 与 $Fe$、$Cu$ 的反应是离子共存判断高频点：$Fe^{3+}$ 与 $I^-$、$S^{2-}$ 等还原性离子不共存。
- 常温下铁、铝遇**浓硫酸、浓硝酸钝化**，不是不反应。

## 背记要点

1. 铁三角：$Fe \xrightarrow{\text{弱氧化剂}} Fe^{2+} \xrightarrow{\text{强氧化剂}} Fe^{3+}$，$Fe^{3+} \xrightarrow{Fe、Cu} Fe^{2+}$。
2. $Fe^{3+}$ 检验：$KSCN$ 变**血红色**；$Fe^{2+}$ 检验：先 $KSCN$ 不变红，加氯水后变红。
3. $Fe(OH)_2$ 颜色变化口诀：白色 → 灰绿色 → 红褐色。
4. 溶液颜色：$Fe^{2+}$ 浅绿、$Fe^{3+}$ 棕黄。
