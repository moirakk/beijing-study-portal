# 专题五 化学反应速率与平衡

## 概念定义

**化学反应速率** $v$：单位时间内反应物浓度的减少或生成物浓度的增加，单位 $\mathrm{mol/(L\cdot s)}$ 或 $\mathrm{mol/(L\cdot min)}$。

**影响速率的因素**：浓度、温度、压强、催化剂、接触面积等。增大浓度、升高温度、增大压强、加催化剂均加快反应速率。

**化学平衡**：可逆反应在一定条件下，正逆反应速率相等、各组分浓度不再改变的状态。

**平衡常数** $K$：$K=\dfrac{c^C(C)c^D(D)}{c^A(A)c^B(B)}$，只与温度有关。

**勒夏特列原理**：改变影响平衡的一个条件，平衡向能减弱这种改变的方向移动。

## 知识梳理

| 条件改变 | 速率变化 | 平衡移动 |
| --- | --- | --- |
| 增大浓度 | 加快 | 向正方向 |
| 升高温度 | 加快 | 向吸热方向 |
| 增大压强 | 加快 | 向气体体积减小方向 |
| 加催化剂 | 加快 | 不移动 |
| 增大反应物浓度 | 加快 | 向正方向 |

## 典型例题

**例 1**：反应 $N_2+3H_2\rightleftharpoons 2NH_3$（正反应放热），升高温度平衡如何移动？

**解**：正反应放热，升高温度平衡向吸热方向（逆方向）移动。

**例 2**：某反应 $2A(g)+B(g)\rightleftharpoons 2C(g)$，增大压强平衡如何移动？

**解**：正反应气体体积减小（3→2），增大压强平衡向正方向移动。

**例 3**：写出反应 $aA+bB\rightleftharpoons cC+dD$ 的平衡常数表达式。

**解**：$K=\dfrac{c^c(C)\cdot c^d(D)}{c^a(A)\cdot c^b(B)}$。

## 易错点

- 平衡时正逆反应速率相等但不为零，各组分浓度不变但不一定相等。
- 催化剂能同等程度加快正逆反应速率，不改变平衡移动。
- 压强影响平衡只适用于有气体参与且气体体积变化的反应。
- 勒夏特列原理中"减弱"不是"消除"，平衡移动不能完全抵消改变。
- 平衡常数只与温度有关，与浓度、压强无关。

## 背记要点

1. 增大浓度、升高温度、增大压强、加催化剂均加快反应速率。
2. 升高温度平衡向吸热方向移动。
3. 增大压强平衡向气体体积减小方向移动。
4. 催化剂不改变平衡移动。
5. 平衡常数只与温度有关。
