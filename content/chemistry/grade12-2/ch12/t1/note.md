# 专题十二 实验综合与探究

## 概念定义

**实验探究**：根据实验目的设计实验方案，通过观察现象、分析数据得出结论的过程。

**实验设计原则**：科学性、可行性、安全性、简约性、环保性。

**气体制备装置**：发生装置（固固加热、固液不加热）、净化装置、收集装置、尾气处理装置。

**实验方案评价**：从原理正确、操作简便、现象明显、安全环保等方面评价。

**定量实验**：通过测量质量、体积、浓度等数据进行计算，如中和滴定。

## 知识梳理

| 环节 | 内容 | 注意 |
| --- | --- | --- |
| 实验目的 | 明确探究目标 | 针对性 |
| 方案设计 | 选择试剂和装置 | 科学性 |
| 现象观察 | 记录颜色、气体、沉淀 | 准确性 |
| 数据分析 | 计算、对比 | 严谨性 |
| 结论评价 | 归纳总结 | 客观性 |

## 典型例题

**例 1**：实验室用 $MnO_2$ 与浓盐酸加热制取 $Cl_2$，写出反应方程式并说明尾气处理方法。

**解**：$MnO_2+4HCl(浓)\overset{\Delta}{=}MnCl_2+Cl_2\uparrow+2H_2O$。尾气用 $NaOH$ 溶液吸收：$Cl_2+2NaOH=NaCl+NaClO+H_2O$。

**例 2**：设计实验证明某溶液中含有 $Fe^{3+}$。

**解**：取少量溶液，滴加 $KSCN$ 溶液，若变红色，则含 $Fe^{3+}$。

**例 3**：评价某实验方案：用排水法收集 $CO_2$ 是否合理？

**解**：不合理。$CO_2$ 能溶于水，应用向上排空气法收集。

## 易错点

- 气体制备要注意发生装置的选择（固固加热或固液不加热）。
- 尾气处理要防止污染，有毒气体需吸收。
- 实验方案评价要从多角度考虑，不能只看原理。
- 定量实验要注意误差分析，如读数、洗涤、定容。
- 探究实验结论要基于现象和数据，不能主观臆断。

## 背记要点

1. 实验设计遵循科学性、可行性、安全性。
2. $MnO_2$ 与浓盐酸加热制 $Cl_2$。
3. $KSCN$ 检验 $Fe^{3+}$ 变红色。
4. $CO_2$ 用向上排空气法收集。
5. 有毒尾气需用吸收液处理。
