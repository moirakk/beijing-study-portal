# 专题六 水溶液中的离子平衡

## 概念定义

**弱电解质的电离平衡**：弱电解质在水溶液中部分电离，存在电离平衡，如 $CH_3COOH\rightleftharpoons CH_3COO^-+H^+$。

**电离平衡常数** $K_a$：$K_a=\dfrac{c(CH_3COO^-)c(H^+)}{c(CH_3COOH)}$，只与温度有关。

**水的离子积** $K_w$：$K_w=c(H^+)\cdot c(OH^-)=10^{-14}$（$25^\circ\mathrm{C}$），只与温度有关。

**pH**：$pH=-\lg c(H^+)$，$pH<7$ 酸性，$pH=7$ 中性，$pH>7$ 碱性。

**盐类水解**：盐电离出的离子与水电离出的 $H^+$ 或 $OH^-$ 结合生成弱电解质的反应。

**沉淀溶解平衡**：难溶电解质在水中存在溶解平衡，如 $AgCl(s)\rightleftharpoons Ag^+(aq)+Cl^-(aq)$。

## 知识梳理

| 类型 | 规律 | 举例 |
| --- | --- | --- |
| 弱酸电离 | 部分电离 | $CH_3COOH$ |
| 弱碱电离 | 部分电离 | $NH_3\cdot H_2O$ |
| 强酸强碱盐 | 不水解 | $NaCl$ |
| 强碱弱酸盐 | 水解显碱性 | $CH_3COONa$ |
| 强酸弱碱盐 | 水解显酸性 | $NH_4Cl$ |

## 典型例题

**例 1**：$25^\circ\mathrm{C}$ 时，某溶液 $c(H^+)=10^{-3}\ \mathrm{mol/L}$，求 pH 和 $c(OH^-)$。

**解**：$pH=-\lg 10^{-3}=3$；$c(OH^-)=\dfrac{10^{-14}}{10^{-3}}=10^{-11}\ \mathrm{mol/L}$。

**例 2**：$CH_3COONa$ 溶液显什么性？说明原因。

**解**：显碱性。$CH_3COO^-$ 水解：$CH_3COO^-+H_2O\rightleftharpoons CH_3COOH+OH^-$，产生 $OH^-$。

**例 3**：比较 $0.1\ \mathrm{mol/L}$ 的 $CH_3COOH$ 与 $HCl$ 溶液的 pH 大小。

**解**：$CH_3COOH$ 是弱酸部分电离，$c(H^+)$ 小，pH 大；$HCl$ 完全电离，pH 小。

## 易错点

- $K_w$ 只与温度有关，温度升高 $K_w$ 增大。
- 盐类水解是吸热反应，升温促进水解。
- "越弱越水解"：弱酸或弱碱越弱，对应离子水解程度越大。
- 判断溶液酸碱性要看水解与电离的相对强弱。
- 沉淀溶解平衡中 $K_{sp}$ 只与温度有关，比较溶解度要同类型。

## 背记要点

1. $K_w=c(H^+)\cdot c(OH^-)=10^{-14}$（$25^\circ\mathrm{C}$）。
2. $pH=-\lg c(H^+)$。
3. 强碱弱酸盐水解显碱性，强酸弱碱盐水解显酸性。
4. 越弱越水解，谁强显谁性。
5. 电离平衡常数、$K_w$、$K_{sp}$ 均只与温度有关。
