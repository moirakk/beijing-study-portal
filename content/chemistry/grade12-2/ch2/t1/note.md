# 专题二 离子反应与离子共存

## 概念定义

**电解质**：在水溶液或熔融状态下能导电的化合物，如酸、碱、盐、活泼金属氧化物。

**非电解质**：在水溶液和熔融状态下均不导电的化合物，如 $CO_2$、$SO_2$、乙醇、蔗糖。

**强电解质**：在水溶液中完全电离的电解质，如强酸、强碱、大多数盐。

**弱电解质**：在水溶液中部分电离的电解质，如弱酸、弱碱、水。

**离子反应**：有离子参加或生成的反应，用**离子方程式**表示。

**离子共存**：离子间不发生反应（不生成沉淀、气体、弱电解质，不发生氧化还原、络合等）即可大量共存。

## 知识梳理

| 类型 | 不能共存的离子对 |
| --- | --- |
| 生成沉淀 | $Ba^{2+}$ 与 $SO_4^{2-}$、$Ag^+$ 与 $Cl^-$、$Ca^{2+}$ 与 $CO_3^{2-}$ |
| 生成气体 | $H^+$ 与 $CO_3^{2-}$、$H^+$ 与 $HCO_3^-$、$H^+$ 与 $S^{2-}$ |
| 生成弱电解质 | $H^+$ 与 $OH^-$、$H^+$ 与 $CH_3COO^-$、$NH_4^+$ 与 $OH^-$ |
| 氧化还原 | $Fe^{3+}$ 与 $I^-$、$MnO_4^-$ 与 $Fe^{2+}$、$ClO^-$ 与 $S^{2-}$ |
| 络合 | $Fe^{3+}$ 与 $SCN^-$ |

## 典型例题

**例 1**：下列各组离子在溶液中能大量共存的是（　）
A. $H^+$、$CO_3^{2-}$、$Na^+$　B. $Ba^{2+}$、$SO_4^{2-}$、$K^+$　C. $Fe^{3+}$、$SCN^-$、$Cl^-$　D. $Na^+$、$NO_3^-$、$Cl^-$

**解**：选 D。A 中 $H^+$ 与 $CO_3^{2-}$ 生成气体；B 生成 $BaSO_4$ 沉淀；C 生成 $Fe(SCN)_3$ 络合物。

**例 2**：写出 $BaCl_2$ 与 $Na_2SO_4$ 反应的离子方程式。

**解**：$Ba^{2+}+SO_4^{2-}=BaSO_4\downarrow$。

**例 3**：判断 $Fe^{3+}$ 与 $I^-$ 能否共存并说明理由。

**解**：不能。$2Fe^{3+}+2I^-=2Fe^{2+}+I_2$，发生氧化还原反应。

## 易错点

- 离子方程式书写要符合质量守恒和电荷守恒。
- 弱电解质、沉淀、气体、单质、氧化物写化学式，不拆成离子。
- 判断共存时注意题干附加条件：酸性、碱性、无色、透明等。
- 无色溶液不能含 $Cu^{2+}$（蓝）、$Fe^{3+}$（黄）、$MnO_4^-$（紫）。
- 注意 $HCO_3^-$ 既不能与 $H^+$ 大量共存，也不能与 $OH^-$ 大量共存。

## 背记要点

1. 强酸强碱大多数盐是强电解质，完全电离。
2. 弱酸弱碱水是弱电解质，部分电离。
3. 离子共存看是否生成沉淀、气体、弱电解质或发生氧化还原、络合。
4. 离子方程式遵循质量守恒和电荷守恒。
5. 注意题干附加条件（酸性、碱性、无色）。
