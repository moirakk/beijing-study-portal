# 课题3 溶液的浓度

## 核心概念表

| 概念 | 内容 |
|---|---|
| 溶质质量分数 | 溶质质量与溶液质量之比 |
| 公式 | 溶质质量分数 $=\dfrac{\text{溶质质量}}{\text{溶液质量}}\times 100\%$ |
| 饱和溶液质量分数 | $=\dfrac{S}{100+S}\times 100\%$（S 为该温度溶解度） |
| 稀释规律 | 稀释前后**溶质质量不变**：$m_{浓}\times a\% = m_{稀}\times b\%$ |

## 知识梳理

**基本计算**：溶液质量 = 溶质质量 + 溶剂质量 = 溶液体积 × 溶液密度。

例：20 g NaCl 溶于 80 g 水，质量分数 $=\dfrac{20}{20+80}\times 100\% = 20\%$。

**稀释计算**：把 50 g 质量分数 98% 的浓硫酸稀释成 20% 的稀硫酸，设需加水 x g：$50\times 98\% = (50+x)\times 20\%$，解得 $x = 195\ \text{g}$。

**与化学方程式结合**：溶液中参加反应的溶质质量 = 溶液质量 × 质量分数；求反应后所得溶液质量常用"质量守恒法"：反应后溶液质量 = 反应前物质总质量 − 生成气体质量 − 生成沉淀质量。

## 误差分析（配得溶液偏稀的原因）

| 操作错误 | 结果 |
|---|---|
| 称量时"左码右物"且用了游码 | 溶质偏少→偏稀 |
| 量水时仰视读数 | 水偏多→偏稀 |
| 烧杯内壁有水 | 水偏多→偏稀 |
| 量水时俯视读数 | 水偏少→偏浓 |

## 易错点

1. 溶质质量分数是**质量**比，不能用体积代替质量；混合溶液体积不能直接相加。
2. 加水稀释或蒸发浓缩时，抓住"溶质质量不变"列方程。
3. 饱和溶液加入同种溶质，质量分数**不变**（不再溶解）。
4. 结合化学反应的计算中，代入方程式的是**纯溶质质量**，不是溶液质量。

## 背记要点

1. 质量分数 = 溶质 ÷ 溶液 × 100%。
2. 稀释前后溶质质量不变。
3. 配制五步骤：计算、称量、量取、溶解、装瓶贴标签。
4. 反应后溶液质量 = 总质量 − 气体 − 沉淀。
