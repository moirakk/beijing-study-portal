# 课题1 溶液的形成

## 核心概念表

| 概念 | 内容 |
|---|---|
| 溶液 | 一种或几种物质分散到另一种物质里，形成**均一、稳定的混合物** |
| 溶质 | 被溶解的物质（可以是固、液、气体） |
| 溶剂 | 能溶解其他物质的物质；水是最常用的溶剂，汽油、酒精也可作溶剂 |
| 乳化 | 洗涤剂使油以细小液滴分散在水中形成乳浊液而不聚集的现象 |

## 知识梳理

**溶液的特征**：均一性（各部分性质相同）、稳定性（外界条件不变时不分层、不析出）。溶液不一定无色（CuSO₄ 溶液蓝色、FeSO₄ 溶液浅绿色、FeCl₃ 溶液黄色）。

**溶质与溶剂的判断**：固体、气体溶于液体时，固、气是溶质；两液体互溶时量多的为溶剂；有水时**水一定是溶剂**。溶液质量 = 溶质质量 + 溶剂质量（体积不可直接相加）。

**溶解时的吸热与放热**：

| 温度变化 | 典型物质 |
|---|---|
| 温度升高（放热） | NaOH 固体、浓硫酸稀释 |
| 温度降低（吸热) | NH₄NO₃（硝酸铵） |
| 基本不变 | NaCl（氯化钠） |

**溶液、悬浊液、乳浊液对比**：悬浊液是固体小颗粒悬浮（如泥水），乳浊液是小液滴分散（如油水混合），二者都不均一、不稳定，静置分层。

## 实验要点

1. 探究溶解吸放热：用温度计分别测 NaCl、NH₄NO₃、NaOH 溶于水前后的温度变化。
2. 碘不溶于水但溶于汽油；高锰酸钾溶于水但不溶于汽油——说明**同一物质在不同溶剂中溶解性不同**。
3. 乳化与溶解的区别：汽油洗油污是**溶解**（形成溶液），洗涤剂洗油污是**乳化**（形成乳浊液）。

## 易错点

1. 溶液是混合物；均一、稳定的**液体不一定是溶液**（如水是纯净物）。
2. "无色透明"不是溶液的必要特征，溶液可以有颜色。
3. NaOH 溶解放热是溶解过程放热；CaO 加入水放热是发生了**化学反应**，二者本质不同。
4. 溶液质量守恒但体积不守恒（分子间有间隔）。

## 背记要点

1. 溶液两特征：均一、稳定；一属性：混合物。
2. 有水水为剂；无水量多者为剂。
3. 放热：NaOH、浓硫酸；吸热：NH₄NO₃；不变：NaCl。
4. 汽油去油污靠溶解，洗涤剂去油污靠乳化。
