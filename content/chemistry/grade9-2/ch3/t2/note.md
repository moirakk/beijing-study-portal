# 课题2 酸和碱的中和反应

## 核心概念表

| 概念 | 内容 |
|---|---|
| 中和反应 | **酸与碱作用生成盐和水**的反应 |
| 实质 | $\text{H}^+ + \text{OH}^- = \text{H}_2\text{O}$ |
| 盐 | 由金属离子（或铵根离子）和酸根离子构成的化合物 |
| pH | 表示溶液酸碱度：pH<7 酸性，pH=7 中性，pH>7 碱性（范围通常 0~14） |

## 知识梳理

**中和反应实验**（NaOH+盐酸无明显现象，需借助指示剂）：向 NaOH 溶液滴入几滴酚酞（变红），再逐滴加入稀盐酸并搅拌，**红色恰好褪去**时表示恰好完全中和。

$$\text{NaOH} + \text{HCl} = \text{NaCl} + \text{H}_2\text{O} \qquad \text{Ca(OH)}_2 + 2\text{HCl} = \text{CaCl}_2 + 2\text{H}_2\text{O}$$

$$2\text{NaOH} + \text{H}_2\text{SO}_4 = \text{Na}_2\text{SO}_4 + 2\text{H}_2\text{O} \qquad \text{Al(OH)}_3 + 3\text{HCl} = \text{AlCl}_3 + 3\text{H}_2\text{O}$$

**中和反应的应用**：改良酸性土壤（撒熟石灰）；处理工厂酸性废水（加熟石灰）；治疗胃酸过多（服含 Al(OH)₃ 的药物）；蚊虫叮咬（蚁酸）涂含碱性物质的药水。

**pH 的测定**：用玻璃棒蘸取待测液，滴到 **pH 试纸**上，把显示的颜色与标准比色卡对照读数。pH 试纸**不能先用水润湿**（会稀释溶液，使酸的 pH 偏大、碱的 pH 偏小、中性不变），也不能直接浸入待测液（污染试剂）。

## 实验要点

1. 中和反应放热：用温度计可测得混合后温度升高（但不能只凭放热判断反应发生）。
2. 判断"恰好中和"要抓住指示剂颜色**恰好变化**的瞬间；红色褪去后若再多加盐酸，溶液呈酸性。
3. 酚酞褪色后溶液中溶质可能是 NaCl（恰好），也可能是 NaCl 和 HCl（过量），可再取样滴石蕊或加锌粒检验。

## 易错点

1. 中和反应**必须**是酸与碱反应；生成盐和水的反应不一定是中和反应（如 CO₂+NaOH、金属氧化物+酸）。
2. pH 试纸读数取整数，不能读出小数；试纸不可先润湿。
3. pH=7 才是中性；酸雨指 pH<5.6 的降水。
4. 改良酸性土壤用**熟石灰**，不用 NaOH（腐蚀性强、成本高）。

## 背记要点

1. 中和反应定义：酸+碱→盐+水；实质：H⁺+OH⁻=H₂O。
2. pH<7 酸性、=7 中性、>7 碱性；pH 越小酸性越强。
3. pH 测法：玻璃棒蘸液滴到试纸上，对照比色卡。
4. 应用四例：改土壤、治废水、疗胃酸、涂叮咬。

2. 正常雨水的 pH 约为 5.6（偏酸性），原因是什么？
