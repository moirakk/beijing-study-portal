# 课题1 常见的酸和碱

## 核心概念表

| 概念 | 内容 |
|---|---|
| 酸 | 解离时生成的阳离子**全部是 H⁺** 的化合物（如 HCl、H₂SO₄） |
| 碱 | 解离时生成的阴离子**全部是 OH⁻** 的化合物（如 NaOH、Ca(OH)₂） |
| 酸碱指示剂 | 紫色石蕊：遇酸变红、遇碱变蓝；无色酚酞：遇酸不变色、遇碱变红 |
| 浓硫酸特性 | 吸水性（作干燥剂，物理性质）、脱水性（腐蚀性，化学性质） |

## 知识梳理

**盐酸与硫酸的物理性质**：浓盐酸有挥发性，打开瓶口有白雾（HCl 气体与水蒸气形成盐酸小液滴），敞口放置质量减小；浓硫酸有吸水性，敞口放置质量增大、浓度变小。**稀释浓硫酸：必须把浓硫酸沿器壁缓缓注入水中，并不断搅拌**（"酸入水"），切不可把水倒入浓硫酸。

**酸的通性**（因解离出的阳离子都是 H⁺）：①使紫色石蕊变红；②与活泼金属反应放氢气；③与金属氧化物反应生成盐和水；④与碱中和；⑤与某些盐反应。

**碱的通性**（因解离出 OH⁻）：①使石蕊变蓝、酚酞变红；②与 CO₂ 等非金属氧化物反应；③与酸中和；④与某些盐反应。NaOH 俗称火碱、烧碱、苛性钠，易潮解，有强腐蚀性；Ca(OH)₂ 俗称熟石灰、消石灰，由生石灰加水制得：$\text{CaO} + \text{H}_2\text{O} = \text{Ca(OH)}_2$（放出大量热）。

## 化学方程式汇总

$$\text{Fe}_2\text{O}_3 + 6\text{HCl} = 2\text{FeCl}_3 + 3\text{H}_2\text{O}\ (\text{除锈，溶液变黄}) \qquad \text{CuO} + \text{H}_2\text{SO}_4 = \text{CuSO}_4 + \text{H}_2\text{O}$$

$$2\text{NaOH} + \text{CO}_2 = \text{Na}_2\text{CO}_3 + \text{H}_2\text{O}\ (\text{NaOH 须密封保存}) \qquad \text{Ca(OH)}_2 + \text{CO}_2 = \text{CaCO}_3\downarrow + \text{H}_2\text{O}$$

$$\text{CaO} + \text{H}_2\text{O} = \text{Ca(OH)}_2 \qquad \text{Zn} + 2\text{HCl} = \text{ZnCl}_2 + \text{H}_2\uparrow$$

## 实验要点

1. 浓硫酸沾到皮肤：立即用大量水冲洗，再涂 3%~5% 碳酸氢钠溶液；NaOH 沾到皮肤：大量水冲洗后涂硼酸溶液。
2. NaOH 能与 CO₂ 反应且无明显现象，验证反应发生可用"瓶吞鸡蛋/软塑料瓶变瘪"等压强差实验，并设**水做对照**。
3. 检验石灰水常用通入 CO₂ 看是否变浑浊。

## 易错点

1. 变色的是**指示剂**，不是酸碱本身（说"石蕊使酸变红"是错的）。
2. 浓硫酸的吸水性是物理性质，脱水性是化学性质，二者要区分。
3. NaOH 固体干燥气体时不能干燥 CO₂、HCl 等酸性气体；浓硫酸不能干燥 NH₃。
4. 碱的通性只针对**可溶性碱**；不溶性碱（如 Cu(OH)₂）不能使指示剂变色。

## 背记要点

1. 石蕊遇酸红、遇碱蓝；酚酞遇碱红、遇酸不变色。
2. 稀释浓硫酸：酸入水，沿壁倒，不断搅。
3. 浓盐酸挥发出白雾质量减；浓硫酸吸水质量增。
4. NaOH 密封保存两个原因：易潮解、会与 CO₂ 反应变质。
5. 生石灰 CaO→熟石灰 Ca(OH)₂，放大量热。
