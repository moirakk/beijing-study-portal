# 课题2 化学元素与人体健康

## 核心概念表

| 分类 | 内容 |
|---|---|
| 常量元素 | 含量超过 0.01% 的元素：O、C、H、N、Ca、P、K、S、Na、Cl、Mg 等 11 种 |
| 微量元素 | 含量低于 0.01%：Fe、Zn、Se、I、F 等 |
| 人体含量最多元素 | 氧（约 65%） |
| 人体含量最多金属元素 | 钙（约 1.4%~2%） |

## 知识梳理

人体中约有 50 多种元素，除以水、糖类、蛋白质、油脂形式存在的 C、H、O、N 外，其余元素主要以**无机盐**形式存在。

**钙**：99% 存在于骨骼和牙齿中（以羟基磷酸钙形式）。幼儿及青少年缺钙患**佝偻病**、发育不良；老年人缺钙患**骨质疏松**。奶类、豆类含钙丰富。

**钠和钾**：Na⁺ 主要存在于细胞外液、K⁺ 主要存在于细胞内液，共同维持体液恒定的 pH 和渗透压。

**必需微量元素功能与缺乏症**：

| 元素 | 作用 | 摄入异常的后果 |
|---|---|---|
| 铁 Fe | 血红蛋白成分，帮助运氧 | 缺铁——**贫血** |
| 锌 Zn | 影响发育与智力 | 缺锌——发育不良、食欲不振 |
| 碘 I | 甲状腺激素的成分 | 缺碘或过量——**甲状腺肿大**；幼儿缺碘影响智力 |
| 硒 Se | 抗氧化、防癌 | 缺硒——表皮角质化、癌症风险；过量——中毒 |
| 氟 F | 防龋齿 | 缺氟——龋齿；过量——氟斑牙、氟骨病 |

## 易错点

1. 微量元素虽少但**不可缺**，也**不是越多越好**（碘、氟、硒过量均有害）。
2. 缺钙与缺铁的病症区分：缺钙——佝偻病/骨质疏松；缺铁——贫血；缺碘——甲状腺肿大；缺锌——发育不良；缺氟——龋齿。
3. "补钙""补铁"补的是**元素**，不是单质（吃铁粉不等于直接补血，需转化为可吸收的离子）。
4. 加碘盐中的"碘"指碘元素（以碘酸钾 KIO₃ 形式存在），不是碘单质。

## 背记要点

1. 人体含量最多元素：氧；最多金属元素：钙。
2. 常量>0.01%，微量<0.01%。
3. 缺乏症口诀：钙—骨（佝偻/疏松），铁—血（贫血），碘—脖（甲状腺肿），锌—智（发育），氟—牙（龋齿）。
4. 微量元素摄入过量同样有害，应均衡膳食。

## 自测题

1. 幼儿与青少年缺钙会患什么病？老年人呢？
2. 某人经常头晕乏力、面色苍白，医生诊断为贫血，他最可能缺乏哪种元素？可通过哪些食物补充？
3. 为什么食盐中加的是碘酸钾而不能直接加碘单质？（提示：碘单质易升华、有毒性刺激）
