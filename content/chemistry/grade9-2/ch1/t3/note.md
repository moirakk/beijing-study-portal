# 课题3 金属资源的利用和保护

## 核心概念表

| 概念 | 内容 |
|---|---|
| 金属存在形式 | 少数不活泼金属（金、银）以单质存在，多数以化合物形式存在于矿石中 |
| 常见铁矿石 | 赤铁矿（主要成分 Fe₂O₃）、磁铁矿（主要成分 Fe₃O₄） |
| 炼铁原理 | 高温下用一氧化碳把铁从铁矿石中还原出来 |
| 铁生锈条件 | 铁与**氧气和水**同时接触 |

## 知识梳理

**工业炼铁**：原料为铁矿石、焦炭、石灰石、空气；设备为高炉。原理：

$$3\text{CO} + \text{Fe}_2\text{O}_3 \xrightarrow{\text{高温}} 2\text{Fe} + 3\text{CO}_2$$

**含杂质计算**：矿石中纯净物质量 = 矿石质量 × 纯度；计算时先换算成纯 Fe₂O₃ 再列比例式。

**铁的锈蚀**：铁锈主要成分是 Fe₂O₃·xH₂O，疏松多孔，不能保护内层铁（对比铝的致密氧化膜）。防锈原理：破坏生锈条件——隔绝氧气或水。方法：保持干燥、擦干；涂油、刷漆、烤蓝；镀锌、镀铬；制成不锈钢。

**保护金属资源途径**：防止金属腐蚀、回收利用废旧金属、合理有效开采矿物、寻找金属的代用品。

## 实验要点：一氧化碳还原氧化铁

现象：红色粉末逐渐变黑，澄清石灰水变浑浊。操作顺序："**先通气后点灯，先熄灯后停气**"（先通 CO 排尽空气防爆炸；结束后继续通 CO 防止铁被重新氧化）。尾气含 CO 有毒，必须**点燃处理**或收集。

## 化学方程式汇总

$$3\text{CO} + \text{Fe}_2\text{O}_3 \xrightarrow{\text{高温}} 2\text{Fe} + 3\text{CO}_2 \qquad 4\text{CO} + \text{Fe}_3\text{O}_4 \xrightarrow{\text{高温}} 3\text{Fe} + 4\text{CO}_2$$

## 易错点

1. 高炉炼铁得到的是**生铁**（含碳的混合物），不是纯铁。
2. CO 还原 Fe₂O₃ 用"高温"条件，实验现象说"红色粉末变黑"，不能说"生成铁"（现象与结论要分清）。
3. 铁锈能加速铁继续生锈，应**及时除锈**；铝的氧化膜则不能除。
4. 生锈是铁与氧气、水共同作用的**缓慢氧化**，属于化学变化。

## 背记要点

1. 炼铁三要素：原料（铁矿石、焦炭、石灰石）、设备（高炉）、原理（CO 还原）。
2. 铁生锈条件：氧气 + 水；防锈就是隔绝其一。
3. CO 还原实验口诀：先通气后点灯，先熄灯后停气；尾气点燃。
4. 保护金属资源"四途径"：防腐、回收、合理开采、找代用品。
