# 课题2 金属的化学性质

## 核心概念表

| 概念 | 内容 |
|---|---|
| 金属活动性顺序 | K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au，由强到弱 |
| 置换反应 | 一种单质与一种化合物反应，生成另一种单质和另一种化合物（A+BC→AC+B） |
| 应用规则1 | 排在氢前的金属能置换出稀盐酸、稀硫酸中的氢 |
| 应用规则2 | 排在前面的金属能把排在后面的金属从其**盐溶液**中置换出来 |

## 知识梳理

**1. 金属与氧气**：镁常温即可氧化，点燃剧烈燃烧发出耀眼白光；铝常温生成**致密氧化铝薄膜**（铝抗腐蚀的原因）：$4\text{Al} + 3\text{O}_2 = 2\text{Al}_2\text{O}_3$；铁在纯氧中点燃生成四氧化三铁；金即使高温也不与氧气反应（"真金不怕火炼"）。

**2. 金属与稀酸**（氢前金属）：反应剧烈程度反映活动性强弱。镁最剧烈，锌较快（实验室制氢气常用锌），铁较慢且溶液变**浅绿色**。

**3. 金属与盐溶液**：铁钉浸入硫酸铜溶液，表面覆盖红色的铜，溶液由蓝色变浅绿色（湿法炼铜"曾青得铁则化为铜"）。

## 化学方程式汇总

$$\text{Zn} + \text{H}_2\text{SO}_4 = \text{ZnSO}_4 + \text{H}_2\uparrow \qquad \text{Fe} + 2\text{HCl} = \text{FeCl}_2 + \text{H}_2\uparrow$$

$$\text{Mg} + 2\text{HCl} = \text{MgCl}_2 + \text{H}_2\uparrow \qquad 2\text{Al} + 3\text{H}_2\text{SO}_4 = \text{Al}_2(\text{SO}_4)_3 + 3\text{H}_2\uparrow$$

$$\text{Fe} + \text{CuSO}_4 = \text{FeSO}_4 + \text{Cu} \qquad \text{Cu} + 2\text{AgNO}_3 = \text{Cu(NO}_3)_2 + 2\text{Ag}$$

$$2\text{Mg} + \text{O}_2 \xrightarrow{\text{点燃}} 2\text{MgO} \qquad 3\text{Fe} + 2\text{O}_2 \xrightarrow{\text{点燃}} \text{Fe}_3\text{O}_4$$

## 实验要点

1. 比较 Fe、Cu、Ag 活动性的最少试剂法：把**铁丝、银丝分别插入硫酸铜溶液**——铁表面析出红色铜（Fe>Cu），银无变化（Cu>Ag）。
2. 铝与酸或盐溶液反应前需先**打磨**，除去表面氧化铝薄膜。
3. 用金属与酸反应快慢比较活动性时，须控制**酸的种类和浓度相同**，金属形状大小相近（控制变量）。

## 易错点

1. 铁发生置换反应生成 **+2 价亚铁盐**（FeCl₂、FeSO₄，溶液浅绿色），不是 +3 价。
2. K、Ca、Na 太活泼，放入盐溶液会先与水反应，**不能**置换出盐中金属。
3. 金属与盐反应，盐必须**可溶**于水（不溶性盐如 AgCl 不参加此类反应）。
4. 置换反应要求反应物和生成物都是"一种单质 + 一种化合物"。

## 背记要点

1. 活动性顺序口诀："钾钙钠镁铝，锌铁锡铅氢，铜汞银铂金"。
2. 氢前置氢（限稀盐酸、稀硫酸），前置后（限可溶盐**溶液**）。
3. 铁参加置换反应显 +2 价，溶液呈浅绿色。
4. 铝抗腐蚀原因：表面生成致密 Al₂O₃ 保护膜。
