# 课题1 金属材料

## 核心概念表

| 概念 | 内容 |
|---|---|
| 金属材料 | 包括纯金属以及它们的合金 |
| 金属共性 | 常温下多为固体（汞是液体）、有金属光泽、能导电导热、有延展性 |
| 合金 | 在金属中加热熔合某些金属或非金属制得的具有金属特性的**混合物** |
| 合金优点 | 一般硬度比成分金属大、熔点比成分金属低、抗腐蚀性能更好 |

## 知识梳理

**金属之最**：地壳中含量最高的金属元素——铝；人体中含量最高的金属元素——钙；目前世界年产量最高的金属——铁；导电性最好的金属——银；熔点最高的金属——钨；熔点最低的金属——汞；硬度最大的金属——铬。

**物性决定用途**：钨熔点高→灯丝；铜、铝导电性好→电线；铝密度小、抗腐蚀→飞机材料、铝锅；铁导热好→炊具。选择材料还要考虑价格、资源、是否美观、废料是否易回收及对环境的影响等。

**常见合金**：

| 合金 | 主要成分 | 特点与用途 |
|---|---|---|
| 生铁 | 铁，含碳 2%~4.3% | 硬而脆，铸造铁锅、暖气片 |
| 钢 | 铁，含碳 0.03%~2% | 韧性好、可锻打，用途最广 |
| 硬铝 | 铝、铜、镁等 | 质轻坚硬，制飞机 |
| 黄铜 | 铜、锌 | 制乐器、装饰品 |
| 钛合金 | 钛 | "21世纪金属"，与人体相容性好，制人造骨 |

## 易错点

1. 合金是**混合物**，不是化合物；合金中至少含一种金属，可以含非金属（如生铁、钢含碳）。
2. 地壳中含量最高的金属元素是铝，但含量最高的**元素**是氧。
3. 生铁和钢的区别在**含碳量**：生铁含碳高、钢含碳低。
4. 金属的用途主要由性质决定，但还要考虑价格、资源、环保等因素。

## 背记要点

1. 金属材料 = 纯金属 + 合金；合金是混合物。
2. 合金"两大一低"：硬度大、抗腐蚀性强，熔点低于成分金属。
3. 铝——地壳中最多的金属；铁——年产量最高；钨——熔点最高做灯丝。
4. 生铁含碳 2%~4.3%，钢含碳 0.03%~2%。
5. 钛合金与人体相容性好，可制人造骨。
