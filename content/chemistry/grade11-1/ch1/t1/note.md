# 第一节 反应热

## 概念定义

**反应热**：化学反应中吸收或放出的热量。**焓变（ΔH）**：等压条件下化学反应的反应热等于反应的焓变，单位 kJ/mol。放热反应 $\Delta H<0$，吸热反应 $\Delta H>0$。

**燃烧热**：101 kPa 时，1 mol 纯物质**完全燃烧**生成指定产物（C→CO2(g)，H→H2O(l)，S→SO2(g)，N→N2(g)）时放出的热量。

**中和热**：稀溶液中强酸与强碱中和生成 1 mol 液态水时放出的热量，约 57.3 kJ/mol。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 反应热本质 | 断键吸收的能量与成键释放的能量之差 |
| 键能计算 | $\Delta H=$ 反应物总键能 $-$ 生成物总键能 |
| 能量计算 | $\Delta H=$ 生成物总能量 $-$ 反应物总能量 |
| 常见放热反应 | 燃烧、中和、金属与酸、大多数化合反应、铝热反应 |
| 常见吸热反应 | 大多数分解反应、C+CO2、C+H2O(g)、Ba(OH)2·8H2O 与 NH4Cl |
| 热化学方程式 | 标聚集状态(s/l/g/aq)、注明 ΔH 符号与数值、计量数可为分数（表示物质的量） |

示例：$H_2(g)+\dfrac{1}{2}O_2(g)=H_2O(l)\quad \Delta H=-285.8\ \text{kJ/mol}$

## 典型例题

**例 1**：已知 H—H 键能 436 kJ/mol，Cl—Cl 键能 243 kJ/mol，H—Cl 键能 431 kJ/mol，求 $H_2(g)+Cl_2(g)=2HCl(g)$ 的 ΔH。

**解**：ΔH = 反应物总键能 − 生成物总键能 = (436+243) − 2×431 = 679 − 862 = **−183 kJ/mol**，放热反应。

**例 2**：25 ℃、101 kPa 下，1 g 甲烷完全燃烧生成 CO2(g) 和 H2O(l) 放热 55.6 kJ，写出表示甲烷燃烧热的热化学方程式。

**解**：1 mol CH4 为 16 g，放热 55.6×16 = 889.6 kJ。
$CH_4(g)+2O_2(g)=CO_2(g)+2H_2O(l)\quad \Delta H=-889.6\ \text{kJ/mol}$。

## 易错点

- ΔH 的大小比较**带符号**：放热越多 ΔH 越小（如 −890 < −570）。
- 燃烧热以 **1 mol 可燃物**为标准，水必须是**液态**；中和热以生成 **1 mol H2O** 为标准。
- 热化学方程式不标"↑""↓"，必须标聚集状态；计量数加倍则 ΔH 同倍数改变。
- 浓硫酸稀释、NaOH 固体溶解放热但不是化学反应，**不属于**放热反应。
- 需要加热才能发生的反应不一定是吸热反应（如碳的燃烧）。

## 背记要点

1. ΔH = 生成物总能量 − 反应物总能量 = 反应物总键能 − 生成物总键能。
2. 放热 ΔH<0，吸热 ΔH>0；单位 kJ/mol。
3. 燃烧热、中和热定义三要素：条件（101 kPa、稀溶液）、标准（1 mol）、指定产物。
4. 高考视角：键能求 ΔH、热化学方程式正误判断是北京卷高频选择题。
