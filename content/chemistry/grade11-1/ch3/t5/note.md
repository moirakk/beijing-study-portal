# 实验活动2 强酸与强碱的中和滴定

## 实验目的

1. 掌握中和滴定的原理与基本操作，学会使用酸式、碱式滴定管。
2. 用已知浓度的盐酸测定未知浓度的 NaOH 溶液，并进行误差分析。

## 实验原理

中和反应：$HCl+NaOH=NaCl+H_2O$。恰好完全反应时：
$$c(NaOH)=\dfrac{c(HCl)\cdot V(HCl)}{V(NaOH)}$$

**指示剂选择**：强酸滴强碱常用**甲基橙**（终点黄→橙）或**酚酞**（终点红→无色/无色→浅红），变色明显、误差小；**不用石蕊**（颜色变化不明显）。滴定终点附近 pH **突跃**，指示剂变色范围落在突跃范围内即可。

## 实验步骤

1. **查漏**：检查酸式、碱式滴定管是否漏液。
2. **洗涤**：滴定管先水洗，再用**待装液润洗** 2~3 次；锥形瓶只水洗，**不润洗**。
3. **装液调零**：装入标准盐酸，排气泡（酸式转活塞快速放液；碱式挤玻璃珠上翘出液），调液面至"0"或以下某刻度，记录 V1。
4. **取样**：用碱式滴定管（或移液管）放取 25.00 mL 待测 NaOH 溶液于锥形瓶，滴加 2~3 滴酚酞。
5. **滴定**：左手控制活塞，右手摇动锥形瓶，眼睛**注视锥形瓶内颜色变化**；接近终点时逐滴、半滴加入。
6. **判定终点**：当滴入最后半滴盐酸，溶液红色**褪去且半分钟内不恢复**，记录 V2。
7. **平行实验**：重复 2~3 次，取消耗体积平均值计算。

## 现象与结论

- 酚酞作指示剂：滴入最后半滴标准盐酸后红色恰好褪去且 30 s 不复原，即为终点。
- 数据处理：若三次消耗盐酸 24.98、25.02、25.00 mL，平均 25.00 mL，代入公式求 c(NaOH)；偏差过大的数据舍去。
- 结论：中和滴定可将未知浓度测准到四位有效数字（体积读数至 0.01 mL）。

## 注意事项（含误差分析）

以标准酸滴定待测碱、$c(\text{碱})=\dfrac{c(\text{酸})V(\text{酸})}{V(\text{碱})}$ 分析（看 V酸 变化）：

| 错误操作 | V(酸) | 结果 |
| --- | --- | --- |
| 酸式滴定管未润洗 | 偏大 | 偏高 |
| 锥形瓶用待测液润洗 | 偏大 | 偏高 |
| 滴定前有气泡、滴定后消失 | 偏大 | 偏高 |
| 滴定前仰视读数、终点俯视读数 | 偏小 | 偏低 |
| 锥形瓶内有少量蒸馏水 | 不变 | 无影响 |

- 酸式滴定管盛酸性/氧化性溶液，碱式滴定管盛碱液，**不可混用**（碱腐蚀玻璃活塞，酸/氧化剂腐蚀橡胶）。
- 读数时视线与凹液面最低处相平；记录至 **0.01 mL**。

## 背记要点

1. 操作口诀：查漏—洗涤润洗—装液排泡—调零读数—滴定—判终点—复滴取平均。
2. 终点判断规范表述："滴入最后半滴……颜色变化……且半分钟内不恢复"。
3. 误差分析抓公式：只看操作使 V(标准液) 偏大还是偏小。
4. 高考视角：滴定操作正误、误差分析、终点表述与滴定曲线上特殊点（半中和点、中性点、恰好反应点）分析是北京卷必考。
