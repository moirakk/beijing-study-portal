# 第一节 化学反应速率

## 概念定义

**化学反应速率**：用单位时间内反应物浓度的减少或生成物浓度的增加来表示，$v=\dfrac{\Delta c}{\Delta t}$，常用单位 mol/(L·s) 或 mol/(L·min)。它是**平均速率**，且取正值。

**活化能（Ea）**：活化分子的平均能量与反应物分子平均能量之差。**有效碰撞**：能够发生化学反应的碰撞（活化分子 + 合适取向）。

## 知识梳理

| 影响因素 | 对速率的影响 | 微观解释（碰撞理论） |
| --- | --- | --- |
| 浓度增大 | 加快 | 单位体积活化分子数增多，有效碰撞频率增大 |
| 压强增大（有气体） | 加快 | 相当于增大气体浓度 |
| 升高温度 | 加快 | 活化分子百分数增大，有效碰撞频率显著增大 |
| 使用催化剂 | 加快 | 降低活化能，活化分子百分数增大 |
| 增大接触面积 | 加快 | 固体粉碎、搅拌等 |

**速率之比 = 化学计量数之比**：对 $aA+bB=cC+dD$，有 $\dfrac{v(A)}{a}=\dfrac{v(B)}{b}=\dfrac{v(C)}{c}=\dfrac{v(D)}{d}$。

**注意**：固体和纯液体的浓度视为常数，不用来表示速率；改变其用量不影响速率。恒容下充入不参与反应的惰性气体，总压增大但各物质浓度不变，速率**不变**。

催化剂改变反应历程、降低活化能，但**不改变 ΔH**，不改变平衡转化率。

## 典型例题

**例 1**：2 L 密闭容器中发生 $N_2+3H_2\rightleftharpoons 2NH_3$，2 min 内 N2 减少 0.4 mol。求 v(N2)、v(H2)、v(NH3)。

**解**：$v(N_2)=\dfrac{0.4}{2\times2}=0.1$ mol/(L·min)。
由计量数比：v(H2)=3×0.1=**0.3 mol/(L·min)**，v(NH3)=2×0.1=**0.2 mol/(L·min)**。

**例 2**：同一反应在不同条件下：甲 v(A)=0.3 mol/(L·s)，乙 v(B)=0.6 mol/(L·s)，反应为 $A+2B=C$，比较甲、乙速率快慢。

**解**：换算成同一物质：乙中 v(A)=v(B)/2=0.3 mol/(L·s) = 甲的 v(A)，故**两者速率相等**。比较速率必须"除以计量数、统一单位"。

## 易错点

- 化学反应速率是**平均速率**且恒为正值，不表示瞬时速率。
- 比较不同条件的速率快慢：先统一单位，再除以化学计量数比较。
- 升温对任何反应（放热、吸热）都**加快**速率。
- 恒容充惰性气体速率不变；恒压充惰性气体体积增大、浓度减小，速率减慢。
- 催化剂同等程度加快正、逆反应速率，不使平衡移动。

## 背记要点

1. $v=\dfrac{\Delta c}{\Delta t}$；速率之比 = 计量数之比 = 变化量之比。
2. 浓度、压强改变**活化分子浓度**；温度、催化剂改变**活化分子百分数**。
3. 催化剂降低 Ea，不改变 ΔH 和平衡状态。
4. 高考视角：速率计算与图像分析（c–t 图求速率、比较斜率）是选择题高频题型。
