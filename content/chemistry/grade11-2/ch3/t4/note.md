# 第四节 配合物与超分子

## 概念定义

**配位键**：成键原子一方提供孤对电子、另一方提供空轨道形成的特殊共价键，用 A→B 表示（A 给出电子对）。**配合物**：由提供孤对电子的**配体**与接受孤对电子的**中心原子（离子）**以配位键结合形成的化合物，如 $[Cu(NH_3)_4]SO_4$、$[Ag(NH_3)_2]OH$。**超分子**：由两种或多种分子通过分子间相互作用（非共价键）形成的聚集体，具有**分子识别**和**自组装**两大特征，如冠醚识别碱金属离子、杯酚分离 $C_{60}$、DNA 双螺旋。

## 知识梳理

| 配合物组成 | 说明 | 以 $[Cu(NH_3)_4]SO_4$ 为例 |
| --- | --- | --- |
| 中心离子（原子） | 提供空轨道，多为过渡金属 | $Cu^{2+}$ |
| 配体 | 提供孤对电子的分子或离子（$NH_3$、$H_2O$、Cl⁻、CN⁻、CO） | $NH_3$ |
| 配位原子 | 配体中直接成键的原子 | N |
| 配位数 | 与中心离子直接成键的配位原子数 | 4 |
| 内界/外界 | 方括号内为内界（难电离），括号外为外界（可电离） | 内界 $[Cu(NH_3)_4]^{2+}$，外界 $SO_4^{2-}$ |

**常见配合物反应**：$Cu^{2+}$ 与过量氨水生成深蓝色 $[Cu(NH_3)_4]^{2+}$；$Fe^{3+}$ 与 KSCN 生成红色 $Fe(SCN)_3$（检验 $Fe^{3+}$）；银氨溶液 $[Ag(NH_3)_2]OH$（银镜反应）；$CuSO_4\cdot5H_2O$ 中 4 个 $H_2O$ 与 $Cu^{2+}$ 配位。血红素（Fe）、叶绿素（Mg）、维生素 $B_{12}$（Co）都是重要配合物。

## 典型例题

**例 1**：向 $CuSO_4$ 溶液中逐滴加入氨水直至过量，描述现象并写出相关离子方程式。

**解**：先生成**蓝色沉淀**：$Cu^{2+}+2NH_3\cdot H_2O=Cu(OH)_2\downarrow+2NH_4^+$；氨水过量后沉淀**溶解得深蓝色溶液**：$Cu(OH)_2+4NH_3=[Cu(NH_3)_4]^{2+}+2OH^-$。原因是 $NH_3$ 中 N 的孤对电子进入 $Cu^{2+}$ 空轨道形成稳定的配离子。

**例 2**：指出配合物 $[Co(NH_3)_5Cl]Cl_2$ 的中心离子、配体、配位数，并计算 1 mol 该配合物与足量 $AgNO_3$ 溶液反应生成 AgCl 的物质的量。

**解**：中心离子 $Co^{3+}$；配体为 $NH_3$ 和 $Cl^-$（内界 Cl）；配位数 = 5+1 = **6**。只有**外界的 2 个 $Cl^-$** 能电离而被沉淀，内界 Cl⁻ 以配位键结合不电离，故生成 AgCl **2 mol**。

## 易错点

- 配位键是特殊共价键，形成后与普通共价键**性质相同**：$NH_4^+$ 中 4 个 N—H 键完全等同。
- 内界配体**难电离**：$[Co(NH_3)_5Cl]Cl_2$ 中只有外界 Cl⁻ 可被 $Ag^+$ 沉淀。
- 配体必须含**孤对电子**（$NH_3$、$H_2O$、CO、X⁻、SCN⁻、CN⁻），$CH_4$ 不能作配体。
- 超分子内部靠**分子间相互作用**（氢键、范德华力等非共价键）维系，不是化学键；但整体表现特定功能。
- 检验 $Fe^{3+}$ 用 KSCN 变红是生成配合物 $Fe(SCN)_3$，不是沉淀反应。

## 背记要点

1. 配位键三要素：一方孤对电子＋一方空轨道，箭头由给电子方指向受电子方。
2. 配合物四组成：中心离子、配体、配位原子、配位数；内界难电离、外界易电离。
3. 四大经典配合物：铜氨 $[Cu(NH_3)_4]^{2+}$ 深蓝、银氨 $[Ag(NH_3)_2]^+$、$Fe(SCN)_3$ 红色、血红素含 Fe。
4. 超分子两特征：分子识别（冠醚识别 $K^+$/$Na^+$、杯酚分离 $C_{60}$ 与 $C_{70}$）与自组装（细胞膜、DNA）。
5. 高考视角：北京卷常考"指出配位原子/配位数""解释沉淀溶于过量氨水""AgNO₃ 沉淀外界氯"，务必区分内外界。
