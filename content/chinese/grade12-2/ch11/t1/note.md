# 专题十一 语言文字运用（词语与病句）

## 核心概念 / 课标要求
- **词语运用**考查**成语、实词、虚词**的辨析与使用，要求结合语境判断词语的**意义、色彩、搭配**是否恰当。
- **病句**考查对**语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑**六种类型的辨析与修改。
- 课标要求：能正确使用词语，能辨析并修改病句，做到语言表达准确、规范。

## 知识梳理

| 类别 | 内容 | 辨析要点 |
| --- | --- | --- |
| 成语 | 意义、色彩、对象 | 望文生义、褒贬误用 |
| 实词 | 近义词辨析 | 语素、搭配、语境 |
| 虚词 | 关联词、介词 | 搭配、逻辑关系 |
| 语序不当 | 词序、句序混乱 | 多层定语、状语顺序 |
| 搭配不当 | 主谓、动宾、修饰 | 检查搭配关系 |
| 成分残缺 | 缺主语、宾语 | 找主干、查成分 |
| 结构混乱 | 句式杂糅 | 两种句式混用 |

## 重点探究 / 典型例题
1. **成语辨析**：注意**望文生义**（如"不刊之论"误以为"不能刊登"）、**褒贬误用**（如"处心积虑"是贬义）、**对象误用**（如"豆蔻年华"只用于少女）。
2. **病句辨析**：先**找主干**（主谓宾），检查是否残缺、搭配不当；再**查枝叶**（定状补），检查语序、修饰是否恰当；最后**析逻辑**，检查是否不合逻辑。
3. **病句修改**：如"通过这次活动，使我明白了道理"缺主语，删去"通过"或"使"；"他的写作水平明显改进了"搭配不当，"改进"改为"提高"。

## 易错点
- 成语**望文生义**，按字面意思理解。
- 成语**褒贬误用**，未注意感情色彩。
- 病句辨析只凭语感，未找主干系统分析。
- 混淆**成分残缺**与**成分赘余**。
- 修改病句时改变原意或产生新语病。

## 背记要点
1. 成语辨析三注意：望文生义、褒贬误用、对象误用。
2. 病句六类：语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑。
3. 病句辨析步骤：找主干、查枝叶、析逻辑。
4. 常见搭配：主谓、动宾、修饰语与中心语。
5. 修改原则：保持原意，最小改动。
6. 常见句式杂糅："原因是……造成的"。
