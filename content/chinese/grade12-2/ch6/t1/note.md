# 专题六 文言文阅读（文意理解与概括）

## 核心概念 / 课标要求
- **文意理解**指整体把握文言文的内容、人物、事件、观点，能筛选并整合文中信息。
- **概括分析**要求对人物形象、事件因果、作者观点进行归纳，并能辨析选项与原文的差异。
- 课标要求：能理解文章大意，把握人物形象与事件脉络，准确概括作者的观点态度，并作出合理判断。

## 知识梳理

| 考查角度 | 内容 | 答题要点 |
| --- | --- | --- |
| 内容理解 | 事件、人物、时间、地点 | 逐段梳理，理清脉络 |
| 人物形象 | 性格、品质、才能 | 结合具体言行概括 |
| 观点态度 | 作者评价、主张 | 抓议论抒情句 |
| 信息筛选 | 符合要求的语句 | 定位原文，比对选项 |
| 概括分析 | 综合归纳、辨析正误 | 比对细节，防曲解 |

## 重点探究 / 典型例题
1. **选择题比对**：将选项与原文逐句比对，重点核查**时间、地点、人物、事件因果、程度范围**是否一致。常见设错：张冠李戴（把甲的事安到乙身上）、无中生有、强加因果、曲解文意。
2. **人物形象概括**：从人物的**言行、事件、他人评价**入手，用四字词概括性格品质（如"忠君爱国、刚正不阿、勤政爱民"），并引用原文佐证。
3. **观点态度概括**：抓文中的**议论抒情句**（"呜呼""悲夫"等）和**作者直接评价**，结合人物结局与事件意义归纳作者的态度倾向。

## 易错点
- 比对选项时忽略**时间、地点**的细微差异，导致误判。
- 把**张冠李戴**（人物事件错位）当作正确选项。
- 概括人物形象只写空泛词，未结合具体言行。
- 观点态度概括脱离文本，主观臆断。
- 信息筛选时定位不准确，遗漏关键语句。

## 背记要点
1. 文意理解核心：把握人物、事件、时间、地点、因果。
2. 选择题比对重点：时间、地点、人物、因果、程度范围。
3. 常见设错类型：张冠李戴、无中生有、强加因果、曲解文意。
4. 人物形象概括：言行 + 事件 + 他人评价。
5. 观点态度：抓议论抒情句与作者直接评价。
6. 概括分析答题：先总说，再分条结合原文。
