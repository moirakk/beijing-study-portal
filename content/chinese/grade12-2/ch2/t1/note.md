# 专题二 现代文阅读Ⅱ（文学类文本·小说）

## 核心概念 / 课标要求
- 小说以**塑造人物形象**为中心，通过**完整的故事情节**和**具体的环境描写**反映社会生活。
- 课标要求：把握小说的**三要素**（人物、情节、环境），理解**主题**，赏析**表达技巧**，并能结合文本分析人物形象、情节作用、环境作用。
- 高考常考题型：人物形象分析、情节作用、环境描写作用、标题含义、主题探究、叙述视角与手法。

## 知识梳理

| 要素 | 关键内容 | 常见考点 |
| --- | --- | --- |
| 人物 | 肖像、语言、动作、心理、细节描写 | 概括形象、分析塑造手法 |
| 情节 | 开端、发展、高潮、结局 | 概括情节、分析情节作用 |
| 环境 | 自然环境、社会环境 | 环境描写的作用 |
| 主题 | 通过人物与情节揭示 | 主题概括与探究 |
| 叙述 | 视角（第一/三/全知）、顺序 | 叙述人称与手法的作用 |

## 重点探究 / 典型例题
1. **人物形象分析题**：先概括性格特征（用四字词或短语），再结合文本具体分析。**模板**：①……（性格），文中通过……（描写/事件）体现；②……。注意从**正面描写**（语言、动作、心理、肖像、细节）与**侧面描写**（他人衬托、环境烘托）两方面入手。
2. **情节作用题**：从**内容**（塑造人物、揭示主题）、**结构**（推动情节、照应伏笔、设置悬念）、**读者**（吸引阅读兴趣）三层面作答。
3. **环境描写作用题**：自然环境——交代背景、渲染气氛、烘托人物、推动情节、暗示主题；社会环境——交代时代背景、揭示社会本质、为人物活动提供舞台。

## 易错点
- 概括人物形象时只写"善良、勇敢"等空泛词，未结合文本具体分析。
- 情节作用题只答结构作用，遗漏内容与主题层面的作用。
- 混淆**自然环境**与**社会环境**的作用。
- 分析塑造手法时遗漏**侧面描写**（他人衬托、环境烘托）。
- 主题探究脱离文本，主观臆断，未从人物、情节、环境综合归纳。

## 背记要点
1. 小说三要素：人物、情节、环境。
2. 人物塑造手法：正面（语言、动作、心理、肖像、细节）+ 侧面（衬托、烘托）。
3. 情节结构：开端、发展、高潮、结局（有的含序幕、尾声）。
4. 环境作用：交代背景、渲染气氛、烘托人物、推动情节、暗示主题。
5. 情节作用答题三层面：内容、结构、读者。
6. 叙述视角：第一人称（真实亲切）、第三人称（自由灵活）、全知视角。

## 自测题
1. 小说三要素是什么？
2. 概括人物形象应如何作答？
3. 自然环境描写有哪些作用？
4. 情节作用题应从哪几个层面分析？
5. 第一人称叙述有什么表达效果？
