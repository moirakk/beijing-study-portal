# 专题三 现代文阅读Ⅱ（文学类文本·散文）

## 核心概念 / 课标要求
- 散文**形散神聚**，以**情感**为线索，通过**记叙、描写、抒情、议论**等表达方式抒发作者的思想感情。
- 课标要求：把握散文的**线索**与**行文思路**，理解**关键语句**的含义，赏析**语言特色**与**表现手法**，体会作者的情感态度。
- 高考常考题型：线索与思路梳理、语句含义理解、表现手法赏析、语言特色分析、情感主旨概括。

## 知识梳理

| 类型 | 特点 | 常见考点 |
| --- | --- | --- |
| 写景状物 | 借景抒情、托物言志 | 景物特征、象征意义 |
| 叙事记人 | 以事写人、以情动人 | 人物形象、事件作用 |
| 议论说理 | 情理交融、哲思深刻 | 观点态度、说理方式 |
| 抒情散文 | 直抒胸臆、情景交融 | 情感脉络、抒情方式 |

## 重点探究 / 典型例题
1. **线索梳理题**：散文线索有**时间线、空间线、情感线、事物线**。答题时先指出线索类型，再按行文顺序概括各部分的中心内容，最后点明线索对组织材料、贯穿全文的作用。
2. **语句含义理解题**：先解释**表层含义**（字面意思），再结合语境分析**深层含义**（象征义、比喻义、情感义），最后点明其表达效果或作用。
3. **表现手法赏析题**：从**修辞**（比喻、拟人、排比）、**表达方式**（抒情、议论）、**表现手法**（借景抒情、托物言志、对比衬托、虚实结合）入手，先点明手法，再结合文本分析，最后说明表达效果。

## 易错点
- 混淆散文的**线索**与**主旨**，把情感线索误当主题。
- 语句含义题只答表层，未深入挖掘象征义、情感义。
- 表现手法题只写手法名称，未结合文本具体分析。
- 语言特色分析笼统，未从用词、句式、修辞、风格等角度细化。
- 主旨概括以偏概全，只抓住局部内容，未整体把握"神"。

## 背记要点
1. 散文特点：形散神聚，以情感为线索。
2. 常见线索：时间、空间、情感、事物。
3. 表现手法：借景抒情、托物言志、对比衬托、虚实结合、象征。
4. 语句含义答题：表层义 + 深层义 + 表达效果。
5. 语言特色角度：用词、句式、修辞、风格（清新、质朴、华丽、含蓄）。
6. 主旨概括：从标题、首尾段、抒情议论句入手。
