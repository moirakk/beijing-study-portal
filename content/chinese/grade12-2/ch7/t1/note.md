# 专题七 古代诗歌鉴赏（形象与意境）

## 核心概念 / 课标要求
- **诗歌形象**包括**人物形象**（抒情主人公、诗中人物）和**事物形象**（景物、意象、咏物对象）。
- **意境**是诗人主观情感与客观景物交融而成的艺术境界，由**意象**组合而成。
- 课标要求：能分析诗歌塑造的形象，把握意象特征，概括意境特点，体会"一切景语皆情语"的抒情方式。

## 知识梳理

| 类别 | 内容 | 答题要点 |
| --- | --- | --- |
| 人物形象 | 抒情主人公、诗中人物 | 身份 + 性格 + 情感 |
| 事物形象 | 景物、意象、咏物 | 特征 + 象征 + 寓意 |
| 意象 | 寄托情感的物象 | 抓典型意象，析情感 |
| 意境 | 情景交融的境界 | 概括特点 + 分析画面 |
| 意境特点词 | 雄浑、清幽、萧瑟等 | 用四字词概括 |

## 重点探究 / 典型例题
1. **人物形象分析**：从**身份、外貌、动作、心理、环境**入手，概括形象特征并点明情感。**模板**：本诗塑造了一个……（身份）的……（性格）形象，通过……（描写）表现其……（情感/品质）。
2. **意境分析**：先**描绘画面**（用生动的语言再现诗中景物），再**概括特点**（用"雄浑壮阔、清幽宁静、萧瑟凄凉"等词），最后**点明情感**。如"大漠孤烟直，长河落日圆"描绘出雄浑壮阔的边塞画面，意境苍凉壮美。
3. **咏物诗形象**：抓住物的**特征**，分析其**象征意义**。如咏梅象征高洁坚贞，咏竹象征正直虚心，咏莲象征出淤泥而不染。

## 易错点
- 分析人物形象时只写性格，未点明身份与情感。
- 意境分析只概括特点，未描绘具体画面。
- 混淆"意象"与"意境"，意象是单个物象，意境是整体境界。
- 咏物诗只写物的特征，未挖掘象征寓意。
- 意境特点词使用不当，如把"清幽"写成"热闹"。

## 背记要点
1. 诗歌形象分人物形象与事物形象两类。
2. 意境 = 意象组合 + 情感交融。
3. 意境分析三步：描绘画面、概括特点、点明情感。
4. 常见意境特点词：雄浑壮阔、清幽宁静、萧瑟凄凉、明丽清新。
5. 常见意象寓意：月（思乡）、柳（送别）、雁（思归）、梅（高洁）。
6. 咏物诗重象征，托物言志。
