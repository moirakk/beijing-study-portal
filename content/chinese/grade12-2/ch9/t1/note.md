# 专题九 古代诗歌鉴赏（思想情感与比较鉴赏）

## 核心概念 / 课标要求
- **思想情感**指诗歌表达的作者情感与观点，包括**忧国忧民、思乡怀人、壮志难酬、闲适恬淡、惜别伤时**等。
- **比较鉴赏**要求对两首（或多首）诗歌在**内容、情感、手法、语言**等方面进行异同比较。
- 课标要求：能准确把握诗歌的思想情感，并能结合背景、意象、手法进行多角度比较分析。

## 知识梳理

| 情感类型 | 常见内容 | 典型意象/标志 |
| --- | --- | --- |
| 忧国忧民 | 报国无门、关心民瘼 | 边塞、烽火、山河 |
| 思乡怀人 | 思念故乡、怀念亲友 | 月、雁、柳、家书 |
| 壮志难酬 | 怀才不遇、报国无门 | 白发、孤舟、宝剑 |
| 闲适恬淡 | 归隐田园、寄情山水 | 山水、田园、酒 |
| 惜别伤时 | 送别友人、感时伤怀 | 长亭、折柳、落花 |

## 重点探究 / 典型例题
1. **情感把握**：从**标题**（点明题材）、**注释**（交代背景）、**意象**（寄托情感）、**抒情句**（直接表达）入手。如"感时花溅泪，恨别鸟惊心"通过"花""鸟"的拟人化，表达忧国伤时之情。
2. **比较鉴赏**：先比较**相同点**，再比较**不同点**，从**内容、情感、手法、语言**等角度分点作答，每点都要结合诗句具体分析。
3. **情感变化分析**：注意诗歌情感的**动态变化**，如由"壮志满怀"到"壮志难酬"，答题时按诗句顺序梳理情感脉络。

## 易错点
- 情感把握脱离背景与意象，主观臆断。
- 比较鉴赏只答相同点，遗漏不同点。
- 情感概括笼统，未具体到"忧国忧民""思乡怀人"等类型。
- 忽略注释中的**背景信息**，导致情感判断错误。
- 比较时未结合诗句，只作空泛比较。

## 背记要点
1. 常见情感类型：忧国忧民、思乡怀人、壮志难酬、闲适恬淡、惜别伤时。
2. 把握情感途径：标题、注释、意象、抒情句。
3. 比较鉴赏角度：内容、情感、手法、语言。
4. 比较答题：先同后异，分点作答，结合诗句。
5. 注意情感的动态变化。
6. 常见意象情感：月（思乡）、柳（送别）、雁（思归）、梅（高洁）。
