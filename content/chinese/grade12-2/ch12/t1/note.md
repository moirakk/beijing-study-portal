# 专题十二 语言文字运用（衔接与压缩）

## 核心概念 / 课标要求
- **语句衔接**考查句子的**连贯性**，要求根据语境选择或排列句子，使语意连贯、逻辑严密。
- **压缩语段**考查对文段信息的**筛选、概括、整合**能力，包括**拟写新闻标题、概括主要内容、提取关键词、下定义**等题型。
- 课标要求：能保持语句连贯，能准确概括文段要点，做到简明、连贯、得体。

## 知识梳理

| 题型 | 内容 | 答题要点 |
| --- | --- | --- |
| 语句衔接 | 选句、排序 | 看话题、看逻辑、看照应 |
| 新闻标题 | 概括新闻要点 | 抓导语、主谓宾 |
| 概括内容 | 压缩文段 | 分层、抓中心句 |
| 提取关键词 | 提炼核心词 | 抓高频词、核心概念 |
| 下定义 | 揭示本质属性 | 种差 + 属概念 |

## 重点探究 / 典型例题
1. **语句衔接**：看**话题一致**（前后句围绕同一话题）、**逻辑连贯**（时间、空间、因果顺序）、**前后照应**（代词、关联词、句式呼应）。排序题先找首句，再按逻辑排列。
2. **压缩语段**：先**分层**（按句意划分层次），再**抓中心句**（每层的关键句），最后**整合**成通顺的语句，注意字数限制。
3. **下定义**：格式为"……是……的……"（种差 + 属概念）。如"新闻是对新近发生的事实的报道"，先找属概念"报道"，再补充种差"新近发生的事实"。

## 易错点
- 语句衔接忽略**话题一致**，选入与上下文无关的句子。
- 排序题未找首句，凭感觉排列。
- 压缩语段遗漏关键信息，或保留次要信息。
- 下定义格式错误，未用"……是……的……"句式。
- 概括内容超出字数限制，或改变原意。

## 背记要点
1. 语句衔接三看：话题一致、逻辑连贯、前后照应。
2. 排序题先找首句，再按逻辑排列。
3. 压缩语段步骤：分层、抓中心句、整合。
4. 下定义格式：种差 + 属概念。
5. 新闻标题：抓导语，主谓宾完整。
6. 提取关键词：抓高频词、核心概念。
