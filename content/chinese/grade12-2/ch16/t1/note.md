# 专题十六 作文（素材运用与语言表达）

## 核心概念 / 课标要求
- **素材运用**指选择、组织、使用**事实论据**与**道理论据**来论证观点，要求**典型、新颖、贴切**。
- **语言表达**指作文的语言运用，要求**准确、生动、有文采**，善用修辞、句式与名言。
- 课标要求：能恰当运用素材论证观点，提升语言表达水平，使作文内容充实、文采斐然。

## 知识梳理

| 类别 | 内容 | 答题要点 |
| --- | --- | --- |
| 事实论据 | 人物事例、历史事件 | 典型、新颖、贴切 |
| 道理论据 | 名言警句、格言 | 准确、有说服力 |
| 素材组织 | 详略、顺序 | 围绕论点、详略得当 |
| 语言表达 | 用词、句式、修辞 | 准确、生动、有文采 |
| 名言引用 | 古诗文、名人名言 | 贴切、自然 |

## 重点探究 / 典型例题
1. **素材选择**：选**典型**（有代表性）、**新颖**（避免老生常谈）、**贴切**（紧扣论点）的素材。如论证"坚持"，可用袁隆平、屠呦呦等当代人物事例。
2. **素材运用**：先**概述事例**（简洁），再**分析论证**（紧扣论点），最后**回扣中心**。避免大段照抄事例，要详略得当、以议为主。
3. **语言提升**：善用**修辞**（比喻、排比增强文采）、**句式**（长短句结合、整散句交错）、**名言**（引用古诗文增厚底蕴）。如"青春如初春，如朝日，如百卉之萌动"运用排比。

## 易错点
- 素材**陈旧**，多用老套事例，缺乏新意。
- 素材**堆砌**，只罗列事例，未分析论证。
- 素材**偏离**论点，与中心无关。
- 语言**平淡**，缺乏修辞与文采。
- 名言**滥用**，堆砌引用，反显生硬。

## 背记要点
1. 素材要求：典型、新颖、贴切。
2. 素材运用：概述事例 + 分析论证 + 回扣中心。
3. 语言要求：准确、生动、有文采。
4. 善用修辞：比喻、排比、对偶。
5. 句式变化：长短句结合、整散句交错。
6. 名言引用：贴切自然，不堆砌。
