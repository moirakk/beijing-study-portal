# 专题八 古代诗歌鉴赏（语言与表达技巧）

## 核心概念 / 课标要求
- **诗歌语言**考查**炼字、炼句、语言风格**，关注动词、形容词、叠词、虚词的表达效果。
- **表达技巧**包括**修辞手法**（比喻、拟人、夸张、用典）、**表现手法**（衬托、对比、虚实结合、动静结合）、**抒情方式**（直抒胸臆、借景抒情、托物言志）。
- 课标要求：能赏析诗歌语言的精妙，分析表达技巧及其表达效果。

| 类别 | 内容 | 答题要点 |

| 炼字 | 动词、形容词、叠词 | 释字义 + 描画面 + 析情感 |

| 抒情方式 | 直抒、借景、托物 | 明方式 + 析情感 |

## 重点探究 / 典型例题
1. **炼字题**："春风又绿江南岸"中"绿"字。**答法**：①"绿"本为形容词，此处活用为动词，意为"吹绿"；②生动形象地写出春风吹拂、江南草木变绿的动态过程；③表现了诗人对江南春景的喜爱与思乡之情。
2. **修辞手法题**："问君能有几多愁？恰似一江春水向东流。"运用**比喻**（把愁比作春水）和**设问**，化抽象为具体，形象地写出愁绪的深长绵延。
3. **表现手法题**：分析"以动衬静"或"虚实结合"。如"蝉噪林逾静，鸟鸣山更幽"以蝉鸣鸟叫反衬山林的幽静，突出环境的宁静。

## 易错点
- 炼字题只解释字义，未描绘画面、分析情感。
- 混淆**修辞手法**（比喻、拟人）与**表现手法**（衬托、对比）。
- 答题只写手法名称，未结合诗句具体分析。
- 语言风格概括不准确，如把"沉郁顿挫"写成"清新明快"。
- 抒情方式判断错误，未区分直抒胸臆与借景抒情。

## 背记要点
1. 炼字答题三步：释字义、描画面、析情感。
2. 常见修辞：比喻、拟人、夸张、对偶、用典、借代。
3. 常见表现手法：衬托、对比、虚实结合、动静结合、象征。
4. 抒情方式：直抒胸臆、借景抒情、托物言志、情景交融。
5. 语言风格：清新自然、豪放雄浑、沉郁顿挫、婉约含蓄。
6. 答题模板：点手法 + 析内容 + 明效果。
