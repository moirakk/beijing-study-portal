# 专题一 现代文阅读Ⅰ（论述类文本）

## 核心概念 / 课标要求
- 论述类文本包括**政论文、学术论文、时评、书评**等，以**论证**为核心，考查对**论点、论据、论证方法**及**论证思路**的理解。
- 课标要求：能把握文章观点与材料的关系，分析论证结构，理解关键概念与重要句子的含义，并作出合理推断。
- 高考常设 3 道选择题（理解、分析、推断）与 1 道主观题（论证思路/论证特点），重在考查**逻辑思维**与**信息筛选整合**能力。

## 知识梳理

| 要素 | 含义 | 答题关注点 |
| --- | --- | --- |
| 论点 | 作者的观点主张 | 中心论点与分论点，常现于首尾段 |
| 论据 | 支撑论点的材料 | 事实论据、道理论据，判断其与论点关系 |
| 论证方法 | 证明论点的方式 | 举例、引用、对比、比喻、因果、类比论证 |
| 论证结构 | 行文组织方式 | 总分式、并列式、递进式、对照式 |
| 论证语言 | 严密、准确、概括 | 逻辑词、限定词、关联词的作用 |

## 重点探究 / 典型例题
1. **论证思路题**：问"请简要分析本文的论证思路"。**答法**：先指出中心论点，再按层次概括各段论证内容（如"先提出……，接着用……论证……，然后从……角度论述……，最后总结……"），注意用"首先、其次、然后、最后"等词串联。
2. **论证特点题**：从**论证结构**（总分/递进）、**论证方法**（举例、对比、引用等）、**论证语言**（严密、生动、概括）三方面作答，并各举文中例证。
3. **选择题比对**：将选项与原文逐句比对，警惕"偷换概念、扩大缩小范围、强加因果、无中生有、曲解文意"等设错方式。

## 易错点
- 把**分论点**误当作中心论点，答题时未抓住全文主旨。
- 混淆**论证方法**与**说明方法**，如把"举例论证"写成"举例子"。
- 论证思路题只罗列内容，未体现"提出—论证—总结"的逻辑层次。
- 比对选项时忽略原文中的**限定词**（如"可能、主要、往往"），导致误判。
- 推断题脱离原文，凭主观臆断，未依据文本信息合理推断。

## 背记要点
1. 论述类文本三要素：论点、论据、论证。
2. 常见论证方法：举例、引用、对比、比喻、因果、类比、道理论证。
3. 论证结构：总分式、并列式、递进式、对照式。
4. 论证思路答题模板：先提出……，接着……，然后……，最后……。
5. 选择题设错类型：偷换概念、以偏概全、强加因果、无中生有、曲解文意。
6. 论证语言特点：严密准确、逻辑性强、概括凝练。

## 自测题
1. 论述类文本的三要素是什么？
2. 常见的论证方法有哪些？各举一例。
3. 简述"论证思路题"的答题步骤。
4. 选择题比对时应注意哪些设错类型？
5. 论证特点应从哪几个方面分析？
