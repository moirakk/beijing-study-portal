# 专题十三 语言文字运用（修辞与图文转换）

## 核心概念 / 课标要求
- **修辞手法**考查对**比喻、拟人、夸张、排比、对偶、借代、设问、反问、反复、引用**等手法的识别与赏析。
- **图文转换**考查将**图表、漫画、徽标、流程图**等信息转化为文字的能力，包括**描述画面、概括信息、说明寓意**等题型。
- 课标要求：能识别并赏析常见修辞手法，能准确解读图文信息并规范表达。

## 知识梳理

| 类别 | 内容 | 答题要点 |
| --- | --- | --- |
| 比喻 | 明喻、暗喻、借喻 | 本体喻体相似点 |
| 拟人 | 赋予物以人的特征 | 生动形象 |
| 夸张 | 扩大、缩小、超前 | 突出特征 |
| 排比 | 结构相似的句子 | 增强气势 |
| 对偶 | 字数相等、结构对称 | 整齐匀称 |
| 图文转换 | 图表、漫画、徽标 | 描述、概括、寓意 |

## 重点探究 / 典型例题
1. **修辞赏析**：先**点明手法**，再**结合内容**分析，最后**说明效果**。如"叶子出水很高，像亭亭的舞女的裙"运用**比喻**，把荷叶比作舞女的裙，生动形象地写出荷叶高挺、舒展的姿态。
2. **图表转换**：先**读表头**（标题、项目、数据），再**分析数据**（比较、趋势），最后**概括结论**。注意数据变化与极值。
3. **漫画寓意**：先**描述画面**（构图要素），再**分析寓意**（讽刺或赞扬的现象），最后**联系现实**。如讽刺浪费、呼吁环保等。

## 易错点
- 混淆**比喻**与**拟人**，比喻重在"像"，拟人重在"人化"。
- 修辞赏析只写手法名称，未结合内容分析。
- 图表转换遗漏关键数据或趋势。
- 漫画寓意概括脱离画面，主观臆断。
- 图文转换表达不规范，未分条作答。

## 背记要点
1. 常见修辞：比喻、拟人、夸张、排比、对偶、借代、设问、反问。
2. 修辞赏析三步：点手法、析内容、明效果。
3. 图表转换：读表头、析数据、概结论。
4. 漫画寓意：描述画面、分析寓意、联系现实。
5. 比喻分明喻、暗喻、借喻。
6. 排比增强气势，对偶整齐匀称。
