# 专题五 文言文阅读（断句与翻译）

## 核心概念 / 课标要求
- **断句**即给文言文加标点，考查对句意、语法结构、虚词标志的把握。
- **翻译**要求将文言句子准确、通顺地译成现代汉语，遵循"**信、达、雅**"原则，重点考查**实词、虚词、句式、活用**的落实。
- 课标要求：能正确断句，能准确翻译文言句子，做到字字落实、文从字顺。

## 知识梳理

| 项目 | 方法/原则 | 关键点 |
| --- | --- | --- |
| 断句 | 找名词、看虚词、察对话、据句式 | 名词作主语宾语，虚词标志 |
| 翻译 | 信（准确）、达（通顺）、雅（优美） | 直译为主、意译为辅 |
| 留 | 保留专有名词 | 人名、地名、官名、年号 |
| 删 | 删除无义虚词 | 发语词、结构助词 |
| 补 | 补充省略成分 | 省略主语、宾语、介词 |
| 换 | 替换古今异义词 | 古词换今词 |

## 重点探究 / 典型例题
1. **断句方法**：①找**名词**（人名、地名、官名）作主语宾语，据此断句；②看**虚词**（句首发语词"夫、盖"前断，句末语气词"也、矣、乎、哉"后断）；③察**对话**（"曰、云、言"后断）；④据**句式**（判断句、被动句、固定句式）。
2. **翻译示例**："沛公曰：'君为我呼入，吾得兄事之。'"译为"沛公说：'你替我把他叫进来，我要像对待兄长一样侍奉他。'"注意"兄"名词作状语译为"像对待兄长一样"。
3. **特殊句式翻译**：判断句"……者……也"译为"……是……"；被动句"为……所……"译为"被……"；宾语前置"何厌之有"译为"有什么满足的呢"。

## 易错点
- 断句时忽略虚词标志，凭语感乱断。
- 翻译时漏译**省略成分**，导致句子不通顺。
- 把**古今异义词**按今义翻译，如"妻子"误译为"妻子"。
- 特殊句式（判断、被动、倒装）未按现代汉语语序调整。
- 翻译只求大意，未做到"字字落实"，遗漏关键实词。

## 背记要点
1. 断句四法：找名词、看虚词、察对话、据句式。
2. 翻译六字诀：留、删、补、换、调、贯。
3. 翻译原则：直译为主、意译为辅，信达雅。
4. 常见句末语气词：也、矣、乎、哉、焉、耳。
5. 常见句首发语词：夫、盖、且夫、若夫。
6. 特殊句式：判断句、被动句、宾语前置、状语后置、定语后置。
