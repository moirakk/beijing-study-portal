# 专题十四 作文（审题立意）

## 核心概念 / 课标要求
- **审题**指准确理解作文题目的**材料、要求、限制**，明确写作方向。
- **立意**指确定文章的中心思想，要求**正确、深刻、新颖、集中**。
- 课标要求：能准确审题，确立明确深刻的中心论点，避免偏题、跑题，为作文奠定基础。

## 知识梳理

| 审题要素 | 内容 | 答题要点 |
| --- | --- | --- |
| 材料 | 作文材料 | 抓关键词、核心句 |
| 要求 | 文体、字数、标题 | 明确限制条件 |
| 立意 | 中心论点 | 正确、深刻、新颖 |
| 角度 | 切入角度 | 选小切口、深挖掘 |
| 中心 | 全文主旨 | 集中、明确、贯穿 |

## 重点探究 / 典型例题
1. **审题方法**：①**读材料**，整体把握材料主旨；②**抓关键词**，找出核心概念与限制条件；③**明要求**，注意文体、字数、标题等要求；④**定中心**，确立明确论点。
2. **立意方法**：从**材料**中提炼中心，可**由表及里**（从现象到本质）、**由小见大**（从具体到普遍）、**反向立意**（辩证思考）。如材料谈"奋斗"，可立意"奋斗是青春最亮丽的底色"。
3. **防偏题**：立意必须**紧扣材料**，不能脱离材料另起炉灶；中心论点要**集中明确**，全文围绕一个中心展开。

## 易错点
- 审题不细，忽略材料中的**限制条件**（如"结合材料""自拟标题"）。
- 立意**偏题跑题**，脱离材料主旨。
- 立意**肤浅**，只停留在表面现象，未深入本质。
- 中心论点**不集中**，一篇文章多个中心。
- 立意**陈旧**，缺乏新意，人云亦云。

## 背记要点
1. 审题四步：读材料、抓关键词、明要求、定中心。
2. 立意要求：正确、深刻、新颖、集中。
3. 立意方法：由表及里、由小见大、反向立意。
4. 防偏题：紧扣材料，中心集中。
5. 中心论点要明确，全文贯穿。
6. 选小切口，深挖掘，避免大而空。

## 自测题

3. 如何防止作文偏题？
4. 由表及里的立意方法指什么？
5. 中心论点应具备什么特点？
