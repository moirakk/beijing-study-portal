# 22* 创造宣言

标签：#议论文 #陶行知 #驳论

## 一、文学常识

- 作者：陶行知（1891—1946），安徽歙县人，著名教育家、思想家，提出"生活即教育""社会即学校""教学做合一"等教育思想，创办晓庄师范。
- 本文是一篇带有演讲风格的议论文（宣言），运用驳论笔法，批驳各种"不能创造"的借口。

## 二、字词积累

- **中伤**（zhòng）：诬蔑别人使受损害。
- **遁词**（dùn）：因理屈词穷而故意避开正题的话。
- **鲁钝**（dùn）：愚笨，不敏锐。
- **懦夫**（nuò）：软弱无所作为的人。
- **豢养**（huàn）：喂养（牲畜），比喻收买并利用。
- **灌溉**（gài）：把水输送到田地里。
- **画龙点睛**：比喻作文或说话时在关键处加上精辟语句，使内容更加生动传神。
- **自暴自弃**：自己甘心落后，不求上进。
- **走投无路**：无路可走，形容处境极端困难。
- **山穷水尽**：比喻陷入绝境。

## 三、结构层次

```mermaid
flowchart TD
    A[创造宣言] --> B[引出话题]

    A --> D[得出结论]

    C --> C1[环境太平凡:八大山人例]
    C --> C2[生活太单调:监牢著经典例]
    C --> C3[年纪太小:莫扎特爱迪生例]
    C --> C4[太无能:曾参惠能例]
    C --> C5[陷入绝境:玄奘哥伦布例]
    D --> D1[处处是创造之地]
    D --> D2[天天是创造之时]
    D --> D3[人人是创造之人]```

1. 引出话题（1—4段）：由美术家造石像、教育者创造真善美的活人说起，指出教育者的成功是"创造出值得自己崇拜的人"；
2. **批驳五种"不能创造"的借口**（5—11段）：
   - 环境太平凡？——八大山人一挥毫，平凡成不朽；
   - 生活太单调？——监牢里产生《易经》《正气歌》；
   - 年纪太小？——莫扎特、爱迪生自幼有为；
   - 太无能？——曾参鲁钝传孔道，惠能不识字传黄梅教义；
   - 陷入绝境？——玄奘、哥伦布、莫扎尔特（遭遇困厄仍创造）；
3. 得出结论（12—15段）："处处是创造之地，天天是创造之时，人人是创造之人"，发出"只要有一滴汗、一滴血、一滴热情，便是创造之神所爱住的行宫"的呼唤。

## 四、段落赏析

1. 五个借口逐一驳斥，每驳一条均以确凿事例为武器，例证密集，气势逼人，是**驳论点**的典型写法。
2. "处处是创造之地，天天是创造之时，人人是创造之人"：排比句式，宣言式的呐喊，是全文的中心论点与最强音。
3. 结尾"只要有一滴汗，一滴血，一滴热情……"：以诗化语言收束，激情澎湃，体现"宣言"的鼓动性。

## 五、主题思想

文章批驳了"环境平凡、生活单调、年纪太小、太无能、陷入绝境"五种不能创造的错误观点，得出"人人能创造、时时能创造、处处能创造"的结论，号召人们保持创造热情，勇于开拓创新。

## 六、写作特色

1. 驳立结合，先破后立；
2. 大量排比、叠句，兼用比喻，激情雄辩，具演讲感染力；
3. 事例丰富，古今中外信手拈来。
