# 3 我爱这土地

标签：#现代诗 #艾青 #中考高频

## 一、文学常识

- 作者：艾青（1910—1996），原名蒋正涵，浙江金华人，现代著名诗人，代表作《大堰河——我的保姆》《光的赞歌》。"土地"与"太阳"是其诗歌的中心意象。
- 写作背景：1938年11月，武汉失守，日军铁蹄践踏中国大地，诗人满怀悲愤写下此诗。
- 九年级名著阅读《艾青诗选》与本课密切相关。

## 二、字词积累

- **嘶哑**（sī yǎ）：声音沙哑。
- **汹涌**（xiōng yǒng）：水猛烈地向上涌。
- **黎明**（lí míng）：天快要亮或刚亮的时候。
- **腐烂**（fǔ làn）：有机体由于微生物的滋生而破坏。

## 三、意象解读

| 意象 | 象征意义 |
| --- | --- |
| 土地 | 遭受苦难的祖国 |
| 河流（悲愤的） | 人民郁积心中的悲愤 |
| 风（激怒的） | 人民不屈的抗争 |
| 黎明（温柔的） | 光明与胜利的希望 |
| 鸟 | 诗人自己，渺小却赤诚 |

## 四、结构层次

1. 第一节：以"假如我是一只鸟"起笔，用嘶哑的喉咙歌唱土地、河流、风、黎明，最后"连羽毛也腐烂在土地里面"——生要歌唱，死也要融入土地；
2. 第二节：设问作结，"为什么我的眼里常含泪水？因为我对这土地爱得深沉"——直抒胸臆，点明主旨。

## 五、段落赏析

1. "用嘶哑的喉咙歌唱"："嘶哑"而非"嘹亮"，表明歌唱不息、饱受磨难仍竭尽全力，突出爱之执着。
2. "连羽毛也腐烂在土地里面"：生于斯、歌于斯、葬于斯，表达与土地生死相依的彻底奉献精神。
3. 结尾设问："常含泪水"的细节将炽热的爱凝于静默的画面，"深沉"二字含蓄隽永，是全诗的点睛之笔。

## 六、主题思想

诗人以鸟自喻，通过歌唱土地、河流、风和黎明，表达了对饱经磨难的祖国深沉的爱，以及愿为祖国献出一切的赤子之情。

## 七、艺术特色

1. 象征手法贯穿全诗，意象内涵丰富；
2. 直抒胸臆与借物抒情结合；
3. 自由体新诗，句式长短不一，情感自然流泻。
