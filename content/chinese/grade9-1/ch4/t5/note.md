# 写作：学写小小说

标签：#写作 #小说 #叙事

## 一、写作目标

学习小小说（微型小说）的基本写法：**以小见大、构思精巧、结尾出彩**。

## 二、小小说的特点

1. **篇幅短小**：一般千字左右，人物少、场景集中；
2. **选材以小见大**：截取生活横断面，一个片段折射深广的社会人生；
3. **情节单纯而有波澜**：常设悬念、误会、巧合；
4. **结尾出人意料**：如"欧·亨利式结尾"——意料之外，情理之中（可回看[[16 我的叔叔于勒]]船上偶遇的安排）。

### 1. 确立"核"

先想清楚要表达什么（主题），如亲情、诚信、变迁。

### 2. 设计"转"

小小说的生命在于"转折"：

- 误会法：人物因误会产生冲突，结尾解开；
- 巧合法：不期而遇推动情节，如于勒恰在同一条船上；
- 抑扬法：先抑后扬或先扬后抑，如[[15 故乡]]中记忆闰土与现实闰土的落差；
- 留白法：结尾戛然而止，让读者回味。

### 3. 塑造人物

- 抓住一两个典型细节：一个动作、一句口头禅、一件道具（外号刻画可学[[18* 蒲柳人家（节选）]]）；
- 多用描写（语言、动作、神态），少用叙述评价。

### 4. 安排环境

用简笔环境描写渲染氛围、暗示心情（参考[[17* 孤独之旅]]的芦苇荡、暴风雨）。

## 四、写作提纲示例

题目：《修车摊》

1. 开端：巷口修车老人手艺好却收费低，儿子劝他涨价；
2. 发展：老人总给赶早自习的学生免费打气、紧螺丝；
3. 高潮：老人病了摊子空着，学生们的车坏了才发现没处修——也发现自行车筐里常多出的雨披是老人放的；
4. 结尾：老人回来那天，车筐里插满了学生送的花。（不点破，留白）

## 五、常见问题与对策

| 问题 | 对策 |
| --- | --- |
| 写成流水账 | 只取一个横断面，删去无关情节 |
| 人物脸谱化 | 用细节代替标签式形容 |
| 结尾平淡 | 预埋伏笔，设计反转或留白 |
| 主题直白说教 | 让情节和细节自己说话 |

## 六、写作实践（教材题目）

1. 将课文中某个场景（如于勒在船上卖牡蛎）改写为于勒视角的小小说片段；
2. 以"变"为话题，自拟题目，写一篇不少于600字的小小说；
3. 写一篇校园题材小小说，要求有一处伏笔和一个出人意料的结尾。
