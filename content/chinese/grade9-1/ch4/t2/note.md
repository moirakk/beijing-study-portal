# 16 我的叔叔于勒

标签：#小说 #莫泊桑 #中考高频

## 一、文学常识

- 作者：莫泊桑（1850—1893），法国批判现实主义作家，"世界三大短篇小说巨匠"之一（另两位：契诃夫、欧·亨利），代表作《羊脂球》《项链》《漂亮朋友》。
- 本文选自短篇小说集《羊脂球》。

## 二、字词积累

- **拮据**（jié jū）：手头紧，经济境况不好。
- **栈桥**（zhàn）：码头上延伸到海面上的桥，供上下船或装卸货物用。
- **糟蹋**（zāo tà）：浪费或损坏。
- **别墅**（shù）：在风景区或郊外建造的供休养的园林住宅。
- **褴褛**（lán lǚ）：（衣服）破烂。
- **阔绰**（chuò）：排场大，生活奢侈。
- **煞白**（shà）：面色极白，没有血色。
- **张皇**：惊慌，慌张。
- **与日俱增**：随着时间的推移而不断增长。
- **十拿九稳**：形容很有把握。
- **郑重其事**：形容说话做事时态度非常严肃认真。

## 三、结构层次（以"盼—赞—见—躲"概括）

```mermaid
flowchart LR
    A[盼于勒：栈桥等待] --> B[赞于勒：信是福音书]
    B --> C[见于勒：船上卖牡蛎 脸色煞白]
    C --> D[躲于勒：改乘另一条船]
```

1. **盼于勒**（开端）：一家人每周日到栈桥散步，盼望于勒归来；
2. **赞于勒**（发展）：插叙于勒的过去——由"祸害"变为"福音"，全家把他的信当作福音书；
3. **见于勒**（高潮）：哲尔赛岛船上，发现卖牡蛎的穷水手正是于勒，父母由惊慌到咒骂；
4. **躲于勒**（结局）：改乘另一条船，避开于勒。

线索：明线是菲利普夫妇对于勒态度的变化，暗线是于勒贫富的变化。

## 四、人物形象

```mermaid
flowchart LR
    A[菲利普夫妇：自私虚荣 冷酷势利] -->|态度随金钱变| B[于勒：落魄后自食其力]
    C[若瑟夫：天真善良] -->|十个铜子小费| B
```

- **菲利普夫妇**：自私虚荣、唯利是图、冷酷势利——对于勒"恐怖—希望—恐怖、仇恨"的态度全由金钱决定；克拉丽丝比丈夫更精明刻薄；
- **"我"（若瑟夫）**：天真善良、富有同情心，给了于勒十个铜子的小费，"这是我的叔叔，父亲的弟弟，我的亲叔叔"的心里默念是对亲情的呼唤，是小说中的一抹亮色；
- **于勒**：年轻时行为不端，沦落后自食其力、不愿拖累家人，是被社会与家庭抛弃的可怜人。

## 五、段落赏析

1. "唉！如果于勒竟在这只船上，那会叫人多么惊喜呀！"：菲利普的口头禅式盼望，与后文见到真于勒时的躲避构成辛辣讽刺。
2. 父亲脸色煞白、母亲暴怒骂"贼""流氓"：神态、语言描写层层推进，金钱面前亲情荡然无存。
3. "我看了看他的手……满是皱痕的水手的手"与心中默念：细节与心理描写对照大人的冷酷，寄托作者的道德理想。
4. 环境描写："紫色的阴影"从海里钻出来——景物由明媚变阴郁，暗示人物心情由希望坠入失望。

## 六、主题思想

小说通过菲利普夫妇对于勒态度的前后变化，深刻揭露了金钱至上的社会中人与人之间赤裸裸的金钱关系，批判了小市民的自私冷酷与虚荣势利，并借若瑟夫寄托了对纯真亲情的呼唤。

## 七、写作特色

1. 双线交织，构思精巧，结局既出人意料又在情理之中；
2. 通过语言、神态、动作揭示心理；
3. 对比与讽刺贯穿全篇；
4. 环境描写烘托心境。
