# 12 石钟山记

## 核心概念 / 课标要求
- 本课为苏轼《石钟山记》，是一篇游记散文，属古代散文。
- 课标要求：把握文言实词虚词与句式，理解游记的记叙、议论、抒情相结合的特点，体会"事不目见耳闻，而臆断其有无"的求实精神。
- 主旨：通过实地考察石钟山得名由来，批判主观臆断，倡导实事求是、亲身实践。

## 知识梳理


## 重点探究
1. **质疑与考证**：苏轼先对郦道元"言之不详"、李渤"臆断"提出疑问，再亲赴实地考察，夜泊绝壁下，亲闻水石相搏之声，最终得出正确结论，体现严谨求实的精神。
2. **记叙、议论、抒情相结合**：文章以记叙写考察过程，以描写写夜泊之景，以议论发感悟，三者结合，既是一篇游记，又是一篇说理文。
3. **求实精神**："事不目见耳闻，而臆断其有无，可乎？"以反问强调亲身实践、实事求是的重要性，具有深刻的哲理意义。

## 易错点
- 本文是"游记散文"，但重在说理，勿误为纯写景游记。
- "臆断"指主观猜测，苏轼批判李渤"臆断"，勿误读。
- 石钟山得名原因是"水石相搏发声"，勿误为"扣石发声"。
- 文章主旨是求实精神，勿忽略其哲理意义。

## 背记要点
1. 苏轼通过实地考察得出石钟山得名之由。
2. 郦道元"言之不详"，李渤"臆断"，均有不足。
3. "事不目见耳闻，而臆断其有无，可乎？"为名句。
4. 文章倡导实事求是、亲身实践。
5. 本文是游记散文，记叙、议论、抒情相结合。
6. 苏轼夜泊绝壁下，亲闻水石相搏之声。
