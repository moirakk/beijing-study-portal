# 游山西村

标签：#中考必考 #古诗 #背诵默写 #陆游

## 一、原诗

> 莫笑农家腊酒浑，丰年留客足鸡豚。
> 山重水复疑无路，柳暗花明又一村。
> 箫鼓追随春社近，衣冠简朴古风存。
> 从今若许闲乘月，拄杖无时夜叩门。

## 二、文学常识

| 项目 | 内容 |
|---|---|
| 作者 | 陆游（1125—1210），字务观，号放翁，南宋伟大的爱国诗人，存诗九千余首 |
| 背景 | 乾道三年（1167），陆游因支持抗金被罢官闲居山阴（今绍兴），游赏邻近村庄而作 |
| 体裁 | 七言律诗（纪游诗） |

## 三、逐联赏析

**首联"莫笑农家腊酒浑，丰年留客足鸡豚。"**
- "莫笑""足"：写农家待客的热情淳朴；腊酒虽浑，情意深厚——丰收年景的喜悦。

**颔联"山重水复疑无路，柳暗花明又一村。"**（千古名句）
- 写景：山峦重叠、水道弯曲，似已无路，忽而柳色深绿、花光红艳，又见村庄；
- 哲理：**困境中往往蕴含着希望与转机，坚持前行终会豁然开朗**；
- "疑"字写出诗人游兴与迷惘，"又"字见惊喜。

**颈联"箫鼓追随春社近，衣冠简朴古风存。"**
- 春社祭祀热闹在即，村民衣着简朴、古风犹存——民俗美、人情美。

**尾联"从今若许闲乘月，拄杖无时夜叩门。"**
- "无时"：随时——愿趁月夜随时拄杖来访；
- 对山村生活的喜爱留恋，余韵悠长。

## 四、重点字词

| 字词 | 读音/释义 |
|---|---|
| 腊酒浑 | 腊月酿的酒，浑浊 |
| 豚 | tún，小猪，文中指猪肉 |
| 山重水复 | 一座座山、一道道水重重叠叠 |
| 柳暗花明 | 柳色深绿，花色明艳 |
| 春社 | 立春后第五个戊日，祭社神（土地神）祈丰收 |
| 若许 | 如果这样 |
| 闲乘月 | 趁着月明来闲游 |
| 无时 | 没有固定的时间，即随时 |

## 五、写法与主题

1. **线索**：一个"游"字贯穿——村外之景（颔联）、村中之俗（颈联）、再游之愿（尾联）；
2. **景、事、情、理交融**：农家待客之情、山水转机之理、春社民俗之趣融为一体；
3. **主题**：描绘山村风光与淳朴民风，表达对**农村生活的热爱**，暗含罢官后**不失希望的豁达心境**。

## 六、练习题

1. "山重水复疑无路，柳暗花明又一村"为什么千古传诵？
   > 既生动描绘山水曲折中忽现村庄的实景，又蕴含"绝境中孕育希望"的普遍哲理，情景理交融，给人鼓舞。
2. 全诗表现了怎样的民风民俗？
   > 腊酒待客的热情好客、春社箫鼓的祭祀民俗、衣冠简朴的古风，展现淳朴的乡村人情美。
3. 默写高频：山重水复疑无路，柳暗花明又一村。

## 七、知识联系

- 与[[登飞来峰]]同为宋代哲理名篇：一议"高瞻"，一言"转机"；
- "登高游历悟理"组诗还包括[[登幽州台歌]][[望岳]]；
- 陆游诗句"驿路梨花处处开"正是课文[[14 驿路梨花]]标题的出处。
