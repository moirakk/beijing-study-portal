# 17 短文两篇（陋室铭；爱莲说）

标签：#中考必考 #文言文 #背诵篇目 #托物言志

## 一、文学常识

| 项目 | 《陋室铭》 | 《爱莲说》 |
|---|---|---|
| 作者 | 刘禹锡（772—842），字梦得，唐代文学家，有"诗豪"之称 | 周敦颐（1017—1073），字茂叔，北宋哲学家，理学开山 |
| 文体 | 铭：古代刻于器物上警戒自己或称功颂德的文字，多押韵 | 说：议论性古文体，就一事一物阐述道理 |
| 手法 | 托物言志（借陋室言志） | 托物言志（借莲喻君子） |

## 二、《陋室铭》要点

**思路**：山水起兴（"山不在高，有仙则名"）→ 点题"惟吾德馨" → 写陋室之景（苔痕草色）、之客（谈笑鸿儒）、之事（调素琴、阅金经）→ 类比诸葛庐、子云亭 → 引孔子语作结"何陋之有"。

### 重点字词
| 词句 | 释义 |
|---|---|
| 有仙则**名** | 出名（名词作动词） |
| 惟吾**德馨** | 品德高尚（馨：香气，指德行美好） |
| 谈笑有**鸿儒** | 博学的人（鸿：大） |
| 往来无**白丁** | 平民，指没有功名的人 |
| 无丝竹之**乱**耳 | 使……扰乱（使动） |
| 无**案牍**之**劳形** | 官府文书；使身体劳累 |

### 名句翻译
- 斯是陋室，惟吾德馨：这是简陋的屋舍，只因我的品德美好（就不感到简陋了）。
- 苔痕上阶绿，草色入帘青：苔痕蔓上台阶，苍绿；草色映入竹帘，青葱。（"上""入"拟人，化静为动）

**主旨**：借陋室表达**安贫乐道的情趣和高洁傲岸的节操**。

## 三、《爱莲说》要点

**思路**：泛写水陆草木之花 → 陶渊明爱菊、世人爱牡丹作陪衬 → 详写"予独爱莲"的七个特点 → 三花喻三种人（菊，隐逸者；牡丹，富贵者；莲，君子）→ 感叹知音少、讽刺爱富贵者众。

### 莲的形象与君子品格对应
| 原句 | 品格 |
|---|---|
| 出淤泥而不染，濯清涟而不妖 | 不同流合污，庄重质朴 |
| 中通外直，不蔓不枝 | 内心通达，行为正直 |
| 香远益清，亭亭净植 | 美名远扬，独立高洁 |
| 可远观而不可亵玩焉 | 自尊自重，令人敬重 |

### 重点字词
| 词句 | 释义 |
|---|---|
| 可爱者甚**蕃** | 多（fán） |
| **濯**清涟而不**妖** | 洗；艳丽 |
| 不**蔓**不**枝** | 横生藤蔓；旁生枝茎（名词作动词） |
| 亭亭净**植** | 竖立 |
| 可远观而不可**亵**玩焉 | 亲近而不庄重（xiè） |
| 陶后**鲜**有闻 | 少（xiǎn） |
| 宜**乎众矣** | 应当（人很多了） |

**主旨**：以莲自况，表达**洁身自好、不慕名利**的生活态度，婉讽追名逐利的世风。

## 四、两文比较

| 项目 | 陋室铭 | 爱莲说 |
|---|---|---|
| 托物 | 陋室 | 莲 |
| 言志 | 安贫乐道、高洁傲岸 | 洁身自好、不慕富贵 |
| 表现手法 | 类比、起兴、引用 | 衬托（菊正衬、牡丹反衬）、比喻 |
| 句式 | 骈句为主，押韵（铭体） | 骈散结合 |

## 五、练习题

1. 《陋室铭》开头写山水有什么作用？
   > 比兴（类比）起笔，由山水引出陋室，"仙、龙"喻"德馨"，自然点题。
2. 《爱莲说》写菊和牡丹的用意？
   > 衬托莲：菊是正衬（同为不俗），牡丹是反衬（贪慕富贵），突出莲的君子品格。
3. "何陋之有"是什么句式？如何翻译？
   > 宾语前置的反问句：有什么简陋的呢？
