# 9 木兰诗

标签：#中考必考 #乐府民歌 #背诵篇目 #文言文

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 出处 | 宋代郭茂倩编《乐府诗集》 |
| 时代 | 北朝民歌（北魏时期民间创作） |
| 体裁 | 乐府叙事长诗 |
| 地位 | 与《孔雀东南飞》并称"乐府双璧" |

## 二、故事情节（按诗序）

1. **停机叹息、代父从军**（1—2 段）："愿为市鞍马，从此替爷征"——可汗大点兵，阿爷无大儿；
2. **准备出征、奔赴战场**（3 段）：东西南北市备鞍马；"旦辞爷娘去……但闻黄河流水鸣溅溅"；
3. **十年征战**（4 段）："万里赴戎机，关山度若飞""将军百战死，壮士十年归"——概写，详略之"略"；
4. **还朝辞官**（5 段）："可汗问所欲，木兰不用尚书郎，愿驰千里足，送儿还故乡"；
5. **回家团聚**（6 段）：爷娘、阿姊、小弟各自迎接；"当窗理云鬓，对镜帖花黄"；
6. **比喻赞美**（7 段）："双兔傍地走，安能辨我是雄雌？"

## 三、重点字词

| 词句 | 释义 |
|---|---|
| 唯闻女**叹息**／**唯**闻 | 只 |
| 愿为**市**鞍马 | 买（名词作动词） |
| 旦辞爷娘去 | 早晨 |
| 万里赴**戎机** | 战事 |
| **朔**气传金柝 | 北方 |
| 策勋十二**转** | 勋级每升一级叫一转（zhuǎn） |
| 赏赐百千**强** | 有余（qiáng） |
| **著**我旧时裳 | 穿（zhuó） |
| 对镜**帖**花黄 | 同"贴"（通假字） |
| 双兔**傍**地走 | 贴近，靠近；走：跑 |

**互文举例**："将军百战死，壮士十年归""东市买骏马，西市买鞍鞯……""开我东阁门，坐我西阁床""当窗理云鬓，对镜帖花黄"。

## 四、写法分析

1. **详略得当**：详写从军缘由、辞别、还乡团聚（儿女情），略写十年征战（英雄气）——突出木兰作为普通女子的人性美，也使英雄形象更真实；
2. **修辞丰富**：
   - 互文：上下句意思互相交错补充；
   - 排比＋铺陈：东西南北市渲染出征前的紧张忙碌；
   - 顶真："军书十二卷，卷卷有爷名""归来见天子，天子坐明堂"；
   - 夸张："万里赴戎机，关山度若飞"；
   - 比喻作结：双兔难辨，妙答巧收，风趣亲切；
3. **民歌特色**：问答开篇、复沓、口语化、节奏明快。

## 五、人物形象与主题

**木兰形象**：勤劳孝顺、深明大义、勇敢坚毅、机智谨慎、不慕名利、热爱和平生活。
**主题**：叙述木兰女扮男装、代父从军、建功归来的传奇故事，赞颂了她的英雄气概与美好品德，也反映了人民对和平生活的向往。

## 六、练习题

1. "万里赴戎机……壮士十年归"六句概写战争有何好处？
   > 高度凝练，写出征途遥远、战事频繁、岁月漫长、战斗惨烈，为下文详写还乡让出笔墨，突出中心。
2. 说说"东市买骏马……北市买长鞍"的表达效果。
   > 排比铺陈（互文），渲染出征前紧张而有序的准备，体现民歌铺排特色。
3. 木兰替父从军的原因是什么？（用原句回答）
   > "阿爷无大儿，木兰无长兄，愿为市鞍马，从此替爷征。"
