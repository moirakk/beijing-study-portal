# 穿井得一人

标签：#中考必考 #文言文 #寓言 #《寓言四则》

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 出处 | 《吕氏春秋·慎行论·察传》 |
| 编者 | 战国末期秦相**吕不韦**集合门客共同编写 |
| 体裁 | 中国古代寓言（文言） |

## 二、原文

> 宋之丁氏，家无井而出溉汲，常一人居外。及其家穿井，告人曰："吾穿井得一人。"有闻而传之者："丁氏穿井得一人。"国人道之，闻之于宋君。宋君令人问之于丁氏。丁氏对曰："得一人之使，非得一人于井中也。"求闻之若此，不若无闻也。

## 三、重点实词

| 词 | 句 | 释义 |
|---|---|---|
| 溉汲 | 出溉汲 | 打水浇田（溉：浇灌；汲：从井里取水） |
| 及 | 及其家穿井 | 待，等到 |
| 穿 | 穿井得一人 | 挖掘、开凿 |
| 闻 | 有闻而传之者 | 听到 |
| 道 | 国人道之 | 讲述 |
| 闻 | 闻之于宋君 | 使听到（使动用法） |
| 对 | 丁氏对曰 | 应答，回答 |
| 使 | 得一人之使 | 使唤，指劳力 |

**"闻"的多义**：有闻而传之者（听到）／闻之于宋君（使……听到）——同字不同用法，翻译高频考点。

## 四、重点虚词与句式

- **之**：宋之丁氏（的）／有闻而传之者（代这件事）／国人道之（代这件事）／得一人之使（的）；
- **于**：闻之于宋君（向、对……表被动兼使动语境）／非得一人于井中（在）；
- 省略句："告人曰"前省略主语"丁氏"。

## 五、重点句翻译

1. **吾穿井得一人**——我家挖井得到了一个人（的劳力）。（丁氏本意：省出一个劳动力）
2. **国人道之，闻之于宋君**——全国的人都在讲述这件事，使宋国国君听到了这件事。
3. **得一人之使，非得一人于井中也**——（我说的是）得到一个人的劳力，不是在井中得到一个人。
4. **求闻之若此，不若无闻也**——像这样听信传闻，还不如不听。

## 六、情节与寓意

**丁氏说话省略引起误会 → 传言者添油加醋 → 举国讹传 → 宋君派人查问 → 真相大白**

寓意：

1. **对传闻要调查核实、审慎判断**（"察传"），不可轻信盲从，更不能以讹传讹；
2. 从丁氏角度：说话要**表达清楚**，避免歧义；
3. 从传播者角度：不要**道听途说**、随意传播未经证实的消息。

现实意义：信息时代面对网络传言，更需要"**求证再转发**"的理性态度。

## 七、考点与答题要点

- 讹传是如何一步步扩大的？——丁氏语言有歧义 → 有人误解并传播 → "国人道之"（范围扩大）→ 上达国君；
- 宋君的做法可取在哪？——不轻信传闻，**派人查问核实**；
- 寓意概括：既答"不轻信、不误传"，也可从说话者角度补充"表达要清楚明白"。

## 八、易错点提醒

- "得一人"是**得一人之使（劳力）**，不是从井里挖出一个人——翻译时勿直译闹笑话；
- "闻之于宋君"的"闻"是**使动用法**（使……听到），不是"听到"；
- 出处是《吕氏春秋》，编者吕不韦是**战国末**人，勿写成汉代。
