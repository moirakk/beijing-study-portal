# 综合性学习：少年正是读书时

标签：#综合性学习

## 一、活动主题

围绕"**读书**"开展的综合性学习：了解自己的阅读状况，认识读书的意义，制订阅读计划，学会选书与读书的方法。

## 二、读书名言积累

1. 敏而好学，不耻下问。——《论语》
2. 读书破万卷，下笔如有神。——杜甫
3. 问渠那得清如许？为有源头活水来。——朱熹
4. 书犹药也，善读之可以医愚。——刘向
5. 腹有诗书气自华。——苏轼
6. 读一本好书，就是和许多高尚的人谈话。——歌德
7. 书籍是人类进步的阶梯。——高尔基

## 三、名人读书法

| 读书法 | 内容 |
|---|---|
| 朱熹"三到" | 读书有三到：**心到、眼到、口到** |
| 陶渊明"会意" | 好读书，不求甚解；每有会意，便欣然忘食 |
| 苏轼"八面受敌" | 每次读书只围绕一个主题深入 |
| 鲁迅"跳读" | 遇到难点暂时跳过，读完前后贯通 |
| 顾炎武"抄读" | 边读边抄，加深记忆 |

## 四、活动形式与考点

### 1. 问卷调查与图表分析（高频考点）

读图表题答题步骤：

1. 看**标题**（调查对象与内容）；
2. 横向纵向**比较数据**，找最大/最小/变化趋势；
3. 用"大多数/超过半数/逐年上升"等语言**归纳结论**，不出现具体数字罗列；
4. 需要时提**建议**（针对问题、切实可行）。

### 2. 设计活动

如"好书推荐会""读书手抄报""名人读书故事会""图书漂流"等。

### 3. 口语交际

- 劝说沉迷手机的同学多读纸质书：称呼 + 肯定对方 + 讲道理（引名言）+ 提建议，语气委婉；
- 采访爱读书的同学：设计 2—3 个有针对性的问题。

## 五、纸质阅读与电子阅读之辩

| | 优点 | 不足 |
|---|---|---|
| 纸质书 | 利于深度阅读、护眼、有书香仪式感 | 携带不便、成本较高 |
| 电子书 | 便携海量、检索方便 | 易碎片化、伤眼、易受干扰 |

观点题言之成理即可，建议"深阅读用纸质、碎片时间用电子，二者互补"。
