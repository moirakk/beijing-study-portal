# 杞人忧天

标签：#中考必考 #文言文 #寓言 #《寓言四则》

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 出处 | 《列子·天瑞》 |
| 作者 | 旧题**列御寇**（战国郑国人，道家学派），今本《列子》为后人辑录 |
| 体裁 | 中国古代寓言（文言） |
| 成语 | "杞人忧天"——比喻不必要的或缺乏根据的忧虑 |

## 二、原文

> 杞国有人忧天地崩坠，身亡所寄，废寝食者。
> 又有忧彼之所忧者，因往晓之，曰："天，积气耳，亡处亡气。若屈伸呼吸，终日在天中行止，奈何忧崩坠乎？"
> 其人曰："天果积气，日月星宿，不当坠耶？"
> 晓之者曰："日月星宿，亦积气中之有光耀者，只使坠，亦不能有所中伤。"
> 其人曰："奈地坏何？"
> 晓之者曰："地，积块耳，充塞四虚，亡处亡块。若躇步跐蹈，终日在地上行止，奈何忧其坏？"
> 其人舍然大喜，晓之者亦舍然大喜。

## 三、重点实词

| 词 | 句 | 释义 |
|---|---|---|
| 崩坠 | 忧天地崩坠 | 崩塌坠落 |
| 亡 | 身亡所寄 | 通"无"，没有 |
| 寄 | 身亡所寄 | 依附，依托 |
| 晓 | 因往晓之 | 告知，开导 |
| 积气 | 天，积气耳 | 聚积的气体 |
| 若 | 若屈伸呼吸 | 你 |
| 行止 | 终日在天中行止 | 行动和停留 |
| 奈何 | 奈何忧崩坠乎 | 为何，为什么 |
| 星宿 | 日月星宿 | 星辰（"宿"读 xiù） |
| 只使 | 只使坠 | 纵使，即使 |
| 中伤 | 亦不能有所中伤 | 伤害（"中"读 zhòng） |
| 四虚 | 充塞四虚 | 四方 |

## 四、通假字与易读错字

- **亡**处亡气："亡"同"无"（wú），没有；
- **舍**然大喜："舍"同"释"，消除、解除；
- 星**宿** xiù／中**伤** zhòng／**躇步跐蹈** chú-cǐ。

## 五、重点句翻译

1. **杞国有人忧天地崩坠，身亡所寄，废寝食者**——杞国有个人担心天塌地陷，自己无处依托，愁得睡不着觉、吃不下饭。
2. **天，积气耳，亡处亡气**——天不过是聚积的气体罢了，没有哪个地方没有气。
3. **奈何忧崩坠乎**——为什么要担心（天）崩塌坠落呢？
4. **其人舍然大喜，晓之者亦舍然大喜**——那个人消除了疑虑非常高兴，开导他的人也放了心非常高兴。

## 六、内容与寓意

结构：**杞人之忧（忧天坠 → 忧星坠 → 忧地坏）→ 晓之者层层开导 → 两人皆"舍然大喜"**

寓意：

1. 讽刺那种**为不必要或缺乏根据的事忧虑**、庸人自扰的人；
2. 启示：不要为毫无根据的事担忧，要以理性态度认识世界；
3. 辩证看待："晓之者"的解释以当时的认识水平安慰了杞人，其热心助人、耐心开导也值得肯定；今天从科学角度看，"忧患意识"本身并非全无价值——答题时按题干要求把握分寸。

## 七、考点与答题要点

- 解释成语"杞人忧天"并造句（成语出处题高频）；
- "晓之者"是怎样一步步开导杞人的？——先释天（积气）、再释日月星宿（积气中有光耀者）、后释地（积块），**针对对方的疑问逐层解答**；
- 通假字"亡""舍"是文言基础题常客；
- 结尾两个"舍然大喜"的表达效果：如释重负的喜悦互相映照，故事在轻快中收束。

## 八、易错点提醒

- "身亡所寄"的"亡"读 wú，不是"死亡"；
- "舍然"的"舍"同"释"，勿按本字理解为"舍弃"；
- 出处是《列子》，勿与《吕氏春秋》（[[穿井得一人]]）混淆。

## 九、知识联系

- 与[[穿井得一人]]同为《寓言四则》文言篇目，通假、翻译常合并出题；
- 与[[赫耳墨斯和雕像者]]、[[蚊子和狮子]]比较中外寓言的异同：都以短小故事寄寓道理。
