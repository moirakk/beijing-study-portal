# 综合性学习：有朋自远方来

标签：#综合性学习 #口语交际

## 一、活动主题

"有朋自远方来，不亦乐乎？"（《论语》）——本次综合性学习围绕"**交友之道**"展开，学习围绕主题收集资料、展示自我、结交朋友。

## 二、知识积累：交友典故

| 典故/成语 | 含义 |
|---|---|
| **伯牙绝弦（知音）** | 伯牙善鼓琴，钟子期善听；子期死，伯牙终身不复鼓琴——知音难觅 |
| **管鲍之交** | 管仲与鲍叔牙，彼此了解、信任的深厚友谊 |
| **刎颈之交** | 廉颇与蔺相如，同生死共患难的朋友 |
| **莫逆之交** | 情投意合的朋友 |
| **忘年之交** | 不拘年岁辈分的交谊 |
| **竹马之交（青梅竹马）** | 幼年就相识的朋友 |
| **君子之交淡如水** | 君子交友重道义，平淡而长久 |

## 三、交友名言警句

1. 有朋自远方来，不亦乐乎？——《论语》
2. 益者三友：**友直，友谅，友多闻**，益矣。——《论语》（正直、诚信、博学的朋友有益）
3. 海内存知己，天涯若比邻。——王勃
4. 君子之交淡如水，小人之交甘若醴。——《庄子》
5. 近朱者赤，近墨者黑。——傅玄

## 四、活动形式与方法

### 1. 自我介绍（口语交际）

- 内容：姓名含义、兴趣特长、性格特点；
- 要求：**有特点、有条理**，语速适中，态度大方，时间约 1 分钟。

### 2. 展示才艺、组织班级活动

- 围绕主题设计海报、主持词；
- 学会倾听他人发言并礼貌回应。

## 五、考点提示

综合性学习常考题型：

1. **设计活动**：为"交友之道"主题班会设计两个活动环节（如"交友典故我来讲""名言书签制作"）；
2. **典故名言默写/理解**："益者三友"的内容；
3. **口语交际**：给转学来的新同学写一段欢迎词（注意称呼、得体、有感染力）。

## 六、知识联系

- "与朋友交而不信乎"出自[[12 《论语》十二章]]，诚信交友一脉相承；
- [[8 《世说新语》二则（咏雪；陈太丘与友期行）]]中"友人无信"是反面例证。
