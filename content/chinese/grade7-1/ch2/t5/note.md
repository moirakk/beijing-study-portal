# 8 《世说新语》二则（咏雪；陈太丘与友期行）

标签：#中考必考 #文言文 #背诵篇目

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 出处 | 《世说新语》，南朝宋**刘义庆**组织编写 |
| 性质 | 志人小说集，主要记载汉末至东晋士大夫的言谈逸事 |
| 篇目出处 | 《咏雪》出自"言语"篇，《陈太丘与友期行》出自"方正"篇 |

## 二、《咏雪》

### 原文

> 谢太傅寒雪日内集，与儿女讲论文义。俄而雪骤，公欣然曰："白雪纷纷何所似？"兄子胡儿曰："撒盐空中差可拟。"兄女曰："未若柳絮因风起。"公大笑乐。即公大兄无奕女，左将军王凝之妻也。

### 重点字词

| 字词 | 释义 |
|---|---|
| 内集 | 把家里人聚集在一起 |
| 儿女 | 子女，这里泛指小辈（**古今异义**） |
| 文义 | 文章的义理 |
| 俄而 | 不久，一会儿 |
| 骤 | 急 |
| 何所似 | 像什么 |
| 差可拟 | 大体可以相比（差：大体；拟：相比） |
| 未若 | 不如，不及 |
| 因风 | 乘风（因：趁、乘） |

### 两个比喻孰优？

- "撒盐空中"：只有形似（颗粒、白色），盐直落无姿态；
- "**柳絮因风起**"：形神兼备——轻盈飘舞，更有**春天将至的意蕴**，有诗意；
- 谢道韫因此句得"**咏絮之才**"的美名。文末补充她的身份，是**暗示作者的赞赏**。

## 三、《陈太丘与友期行》

### 原文

> 陈太丘与友期行，期日中。过中不至，太丘舍去，去后乃至。元方时年七岁，门外戏。客问元方："尊君在不？"答曰："待君久不至，已去。"友人便怒曰："非人哉！与人期行，相委而去。"元方曰："君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。"友人惭，下车引之。元方入门不顾。

### 重点字词

| 字词 | 释义 |
|---|---|
| 期行 | 相约同行（期：约定） |
| 日中 | 正午时分 |
| 舍去 | 丢下（他）而离开 |
| 乃 | 才 |
| 尊君在不 | 令尊在不在？（**不：同"否"，通假**） |
| 相委而去 | 丢下我走了（委：舍弃） |
| 家君 | 对人谦称自己的父亲 |
| 引 | 拉，牵拉 |
| 顾 | 回头看 |

### 敬辞与谦辞（高频考点）

| 类别 | 词 | 用法 |
|---|---|---|
| 敬辞 | **尊君** | 尊称**对方**的父亲 |
| 谦辞 | **家君** | 谦称**自己**的父亲 |

### 人物形象

- **元方**：聪慧机敏、懂礼识义、直率方正（据理驳斥"无信""无礼"）；
- **友人**：无信无礼，但**知错能改**（"惭，下车引之"）。

**讨论**：元方"入门不顾"是否失礼？——开放题。可答"不失礼"（对无礼者的态度，孩子率真）或"失礼"（友人已惭愧认错，应给人改过机会），言之成理即可。

## 四、主旨

- 《咏雪》：展现古代家庭文化生活的雅趣与谢道韫的才气；
- 《陈太丘与友期行》：说明**诚信**与**礼**是立身处世之本。

## 五、知识联系

- 本课是初中文言文起步课，重点积累**古今异义、通假字、敬谦辞**；
- 与[[12 《论语》十二章]]的"与朋友交而不信乎"呼应"诚信"主题。
