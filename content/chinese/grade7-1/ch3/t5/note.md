# 写作：如何突出中心

标签：#写作 #方法指导

## 一、什么是"中心"

中心是文章的**灵魂**——你想通过这篇文章表达的主要意思（一种情感、一个道理、一种品质）。中心不突出的文章，就像"没有指挥的乐队"，材料再多也是散沙。

## 二、突出中心的四种方法

### 1. 设置线索，一线串珠

| 线索类型 | 示例 |
|---|---|
| 实物线 | 《往事依依》中的"书" |
| 事件线 | 《散步》中的散步过程 |
| 情感线 | 《秋天的怀念》中对母亲的怀念 |
| 时空线 | 《从百草园到三味书屋》的空间转换 |

### 2. 开门见山，点明题旨

开头直接亮出中心，如"我一生中最重要的一天，就是莎莉文老师来到我身边的那天"。

### 3. 详略得当，突出重点

- 与中心密切相关的**详写**（放慢镜头、多用描写）；
- 关系不大的**略写或不写**；
- 《从百草园到三味书屋》详写百草园景物与雪地捕鸟，正是为突出"乐"。

### 4. 前后照应，卒章显志

- 关键语句反复出现（《秋天的怀念》的"好好儿活"）；
- 结尾点题升华（《散步》的"整个世界"）。

## 三、常见病症与对策

| 病症 | 对策 |
|---|---|
| 多中心（既写友情又写母爱） | 一篇文章**只表达一个中心** |
| 中心游离（材料与中心无关） | 每写一段问自己：这段为中心服务吗？ |
| 平均用力（流水账） | 找到"最能表现中心的一刻"重点写 |
| 有事无"心"（只叙事不点题） | 关键处用一两句议论抒情点明 |

## 四、写作实践指引

教材题目示例：《书包》《走出校园》《餐桌前的谈话》等。以《书包》为例的构思路径：

1. **定中心**：书包→承载母爱（妈妈缝补书包带）/ 承载成长（书包越来越重）；
2. **选材料**：只选 2—3 个与中心相关的场景；
3. **安排详略**：核心场景细节化；
4. **首尾呼应**：开头引出书包，结尾回到书包点题。
