# 20 狼（蒲松龄）

标签：#中考必考 #文言文 #背诵篇目

## 一、文学常识

| 项目 | 内容 |
|---|---|
| 作者 | 蒲松龄（1640—1715），字留仙，别号柳泉居士，世称"聊斋先生"，清代文学家 |
| 出处 | 文言短篇小说集《聊斋志异》（"聊斋"是书屋名，"志"是记述，"异"指奇异的事） |
| 体裁 | 文言短篇小说 |

## 二、原文

> 一屠晚归，担中肉尽，止有剩骨。途中两狼，缀行甚远。
> 屠惧，投以骨。一狼得骨止，一狼仍从。复投之，后狼止而前狼又至。骨已尽矣，而两狼之并驱如故。
> 屠大窘，恐前后受其敌。顾野有麦场，场主积薪其中，苫蔽成丘。屠乃奔倚其下，弛担持刀。狼不敢前，眈眈相向。
> 少时，一狼径去，其一犬坐于前。久之，目似瞑，意暇甚。屠暴起，以刀劈狼首，又数刀毙之。方欲行，转视积薪后，一狼洞其中，意将隧入以攻其后也。身已半入，止露尻尾。屠自后断其股，亦毙之。乃悟前狼假寐，盖以诱敌。
> 狼亦黠矣，而顷刻两毙，禽兽之变诈几何哉？止增笑耳。

## 三、情节梳理

按屠户与狼的斗争展开，可概括为五步：

**遇狼 → 惧狼（投骨）→ 御狼（倚薪持刀）→ 杀狼（毙两狼）→ 议狼（作者评论）**

前四段记叙，最后一段议论点题。

## 四、重点实词

| 词 | 句 | 释义 |
|---|---|---|
| 止 | 止有剩骨 | 通"只"，仅 |
| 缀 | 缀行甚远 | 连接、紧跟 |
| 从 | 一狼仍从 | 跟从 |
| 窘 | 屠大窘 | 处境困迫，为难 |
| 敌 | 恐前后受其敌 | 攻击（名词活用为动词） |
| 顾 | 顾野有麦场 | 看，视 |
| 苫蔽 | 苫蔽成丘 | 覆盖、遮盖 |
| 弛 | 弛担持刀 | 解除，卸下 |
| 眈眈 | 眈眈相向 | 注视的样子 |
| 瞑 | 目似瞑 | 闭上眼睛 |
| 暇 | 意暇甚 | 从容、悠闲 |
| 暴 | 屠暴起 | 突然 |
| 洞 | 一狼洞其中 | 挖洞（名词活用为动词） |
| 隧 | 意将隧入 | 从通道（钻洞），名词作状语 |
| 尻 | 止露尻尾 | 屁股 |
| 假寐 | 前狼假寐 | 假装睡觉 |
| 黠 | 狼亦黠矣 | 狡猾 |
| 变诈 | 禽兽之变诈几何哉 | 巧变诡诈 |

**一词多义**："意"——意暇甚（神情）／意将隧入（打算）；"敌"——受其敌（攻击）／盖以诱敌（敌人）；"止"——止有剩骨（只）／一狼得骨止（停止）。

## 五、重点虚词与句式

- **之**：复投之（代狼）／两狼之并驱如故（主谓之间，取消句子独立性）／久之（音节助词，不译）／禽兽之变诈（结构助词，的）；
- **其**：恐前后受其敌（代狼）／场主积薪其中（代麦场）／屠自后断其股（代狼）；
- **以**：投以骨（把）／以刀劈狼首（用）／盖以诱敌（用来）；
- 倒装句："投以骨"即"以骨投（之）"，状语后置；
- 省略句："顾野有麦场"前省略主语"屠"。

## 六、重点句翻译

1. **两狼之并驱如故**——两只狼像原来一样一起追赶。
2. **恐前后受其敌**——担心前后受到狼的攻击。
3. **其一犬坐于前**——另一只狼像狗一样蹲坐在前面（"犬"名词作状语，**易错：不是"一只狗"**）。
4. **乃悟前狼假寐，盖以诱敌**——（屠户）才明白前面的狼假装睡觉，原来是用来诱骗对手。
5. **禽兽之变诈几何哉？止增笑耳**——禽兽的诡诈手段能有多少呢？只是增加笑料罢了。

## 七、形象与主题

- **狼**：贪婪（得骨仍从）、狡诈（假寐诱敌、隧入夹击）、凶残——但终究"顷刻两毙"；
- **屠户**：由惧怕迁就（投骨）到清醒果断（倚薪、暴起、断股），机智勇敢；
- **主题**：对像狼一样的恶势力，**不能妥协退让、心存幻想，必须敢于斗争、善于斗争**，才能取得胜利。

## 八、考点与答题要点

- 情节概括题：用"遇狼—惧狼—御狼—杀狼"四词作答；
- 最后一段的作用：**议论点题**，画龙点睛，揭示嘲讽狼（及一切恶人）的主旨；
- "犬坐""洞""隧"等**词类活用**是翻译题高频考点。

## 九、易错点提醒

- "其一犬坐于前"勿译为"一只狗坐在前面"；
- "止"两个义项（只／停止）要按语境区分；
- 《聊斋志异》是**文言短篇小说集**，不是散文集。
