# 写作：有创意地表达

标签：#写作 #创意 #个性表达

## 一、技法要点

1. **创意的前提**：内容真实、立意正确——创意是"戴着镣铐跳舞"，新而不怪、活而不乱。
2. **视角求新**：变换叙述人称与观察角度——用第二人称倾诉、以物的视角叙事（如以一只书包看初三）、局外人视角（如刘姥姥看大观园）。
3. **形式求活**：日记体、书信体、剧本体、小标题式、镜头组接式等结构形式，为内容服务而非炫技。
4. **语言求个性**：善用比喻通感等修辞、化用诗词、长短句错落、幽默笔调，形成自己的语言风格。
5. **构思求巧**：设置悬念、欲扬先抑、误会突转、以小见大，让平常题材翻出新意。

## 二、步骤方法

```mermaid
flowchart TD
    A["常规立意与选材（先保证不跑题）"] --> B["寻找创意点：问自己——别人会怎么写？我能否换个角度？"]
    B --> C["选择创意策略：新视角 / 新形式 / 新语言 / 新构思（取其一二，不可堆砌）"]
    C --> D["检验创意：是否服务中心？是否自然妥帖？是否在自己驾驭能力之内"]
    D --> E["成文后打磨：突出创意亮点，删去弄巧成拙之处"]
```

- 创意源于积累：平时多做"一材多写"训练（同一件事分别用顺叙、倒叙、剧本体写）；
- 借鉴课文：象征（海燕）、双线（智取生辰纲）、独白（雷电颂）、陌生化视角（刘姥姥）都是创意范本。

## 三、常见问题

1. **为新而新**：形式花哨内容空洞，小标题、题记满天飞却无实质；
2. **弄巧成拙**：使用自己驾驭不了的文体（如文言、长诗），破绽百出；
3. **创意失度**：立意剑走偏锋，价值观出现偏差；
4. **千文一面**：套用"万能开头""万能素材"，与创意背道而驰。

## 四、实践练习

1. 以"墙"为题，分别列出常规立意与两个创意立意（如心墙、防火墙），比较高下。
2. 用一只旧台灯的视角，写"陪伴我的初三岁月"片段（300 字）。
3. 将《范进中举》"喜疯"一段改写为剧本片段，体会文体转换的创意。
4. 从自己的旧作中选一篇，用"换视角"或"换结构"的方法改写升格。

## 五、北京中考提示

- 北京中考设"想象写作"选项（如科幻情境、跨时空对话），是创意表达的直接考查；
- 一类文标准中的"有新意"指立意、选材、构思、语言任一方面的独到之处，勿求面面俱到。
