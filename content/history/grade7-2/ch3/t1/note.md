# 统一多民族封建国家的巩固与发展

## 单元导览
明清时期（1368—1840 年鸦片战争前）的时代特征是**统一多民族封建国家的巩固与发展**：君主专制不断强化并达到顶峰，统一多民族国家的版图基本奠定，社会经济发展但也逐渐落后于世界潮流。

## 时间线
- 1368 年：朱元璋建立明朝，定都应天府（南京），同年推翻元朝
- 1405—1433 年：郑和七下西洋
- 明中期：戚继光抗倭
- 1616 年：努尔哈赤建立后金
- 1636 年：皇太极改国号为清
- 1644 年：李自成攻入北京，明朝灭亡；清军入关
- 1662 年：郑成功收复台湾；1684 年清设台湾府
- 康熙至乾隆时期：平定叛乱、加强边疆治理，君主专制达到顶峰（军机处）

## 本单元主要线索
1. **君主专制强化线**：明太祖废丞相、设锦衣卫、八股取士（见[[第15课 明朝的统治]]）→ 清设军机处、大兴文字狱（见[[第19课 清朝君主专制的强化]]）。
2. **对外关系线**：郑和下西洋（友好交往）→ 戚继光抗倭、援朝战争（反抗侵略）（见[[第16课 明朝的对外关系]]）→ 清朝闭关自守。
3. **王朝更替线**：明亡于农民起义，清入关统一（见[[第17课 明朝的灭亡和清朝的建立]]）。
4. **边疆治理线**：清朝对台湾、西藏、新疆、蒙古的治理，奠定现代中国版图（见[[第18课 统一多民族封建国家的巩固和发展]]）。
5. **经济文化线**：农业手工业商业发展、人口增长（见[[第20课 明清时期社会经济的发展]]）；科技巨著与小说戏曲繁荣（见[[第21课 明清时期的科技与文化／第22课 活动课：我国传统节日的起源与传承]]）。

## 时代特征的两面性
| 方面 | 巩固与发展 | 危机与隐忧 |
| --- | --- | --- |
| 政治 | 中央集权空前强化，国家统一 | 君主专制僵化、腐败滋生 |
| 经济 | 农业、手工业、商业繁荣，人口大增 | 人地矛盾突出，重农抑商 |
| 对外 | 郑和下西洋壮举、反侵略胜利 | 闭关自守，逐渐落后于世界 |
| 文化 | 小说戏曲繁荣、科技总结性巨著 | 八股取士、文字狱禁锢思想 |

## 关键人物速览
- 朱元璋（明太祖）：建明、强化皇权
- 郑和：七下西洋；戚继光：抗倭英雄
- 努尔哈赤、皇太极：后金与清的奠基者
- 李自成："均田免赋"，推翻明朝
- 郑成功：收复台湾的民族英雄
- 康熙、雍正、乾隆：清朝鼎盛（康乾盛世）与专制顶峰

## 背记要点
1. 明清时代特征：统一多民族封建国家的巩固与发展。
2. 明朝：1368 年朱元璋建立；清朝：1636 年皇太极改国号，1644 年入关。
3. 君主专制强化脉络：废丞相 → 厂卫 → 八股取士 → 军机处 → 文字狱。
4. 清朝奠定了现代中国版图的基础。
5. 明清由盛转衰的深层原因：专制僵化＋闭关自守，落后于世界潮流。
