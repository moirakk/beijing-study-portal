# 专题四 中国近代史（列强侵华与救亡）

## 核心概念 / 课标要求

本专题涵盖1840—1919年列强侵华与中国各阶层救亡图存的历程。课标要求掌握：两次鸦片战争、甲午中日战争、八国联军侵华等列强侵华战争及其不平等条约；太平天国运动、洋务运动、戊戌变法、义和团运动、辛亥革命等救亡探索；理解中国逐步沦为半殖民地半封建社会的历程，以及各阶层探索的进步性与局限性。

## 知识梳理

| 事件 | 时间 | 结果/影响 |
| --- | --- | --- |
| 鸦片战争 | 1840-1842 | 《南京条约》，开始沦为半殖民地半封建社会 |
| 第二次鸦片战争 | 1856-1860 | 《天津条约》《北京条约》，半殖民地化加深 |
| 太平天国运动 | 1851-1864 | 农民阶级反封建反侵略，失败 |
| 洋务运动 | 19世纪60-90年代 | 自强求富，开启近代化，甲午战败破产 |
| 甲午中日战争 | 1894-1895 | 《马关条约》，半殖民地化大大加深 |
| 戊戌变法 | 1898 | 资产阶级维新派，百日维新失败 |
| 义和团运动 | 1899-1900 | 农民反帝爱国，被中外反动势力镇压 |
| 八国联军侵华 | 1900-1901 | 《辛丑条约》，完全沦为半殖民地半封建社会 |
| 辛亥革命 | 1911 | 推翻清王朝，建立中华民国 |

## 重点探究 / 典型例题

**例1（选择题）** 《马关条约》中，最能体现列强侵华进入资本输出阶段的是（　）
A. 割辽东半岛、台湾及附属岛屿　B. 赔款二亿两白银　C. 允许日本在通商口岸开设工厂　D. 增开通商口岸
**解析**：允许开设工厂使列强由商品输出为主转向资本输出为主。选 **C**。

**例2（材料题）** 材料："中国欲自强，则莫如学习外国利器。"——李鸿章
问：洋务运动的口号、内容及失败的根本原因是什么？
**解析**：口号："自强""求富"。内容：创办军事工业（江南制造总局）、民用工业（轮船招商局）、新式学堂、近代海军。失败根本原因：只学习西方技术而不变革封建制度（中体西用）。

**例3（探究）** 分析辛亥革命的历史意义与局限性。
**解析**：意义：推翻清王朝，结束两千多年君主专制制度，建立资产阶级共和国，使民主共和观念深入人心，促进民族资本主义发展。局限性：未改变中国半殖民地半封建社会性质，未完成反帝反封建任务，未发动广大民众。

## 易错点

- 中国开始沦为半殖民地半封建社会是鸦片战争（《南京条约》），完全沦为是《辛丑条约》。
- 太平天国运动是农民阶级反封建反侵略，但缺乏科学理论指导。
- 洋务运动是地主阶级自救运动，不是资产阶级运动，其失败标志"中体西用"破产。
- 戊戌变法是资产阶级维新派自上而下的改良，未触及封建土地制度。
- 辛亥革命推翻的是"君主专制制度"，不是"封建制度"（封建制度包括经济、政治等多方面）。

## 背记要点

1. 列强侵华战争：鸦片战争、第二次鸦片战争、甲午战争、八国联军侵华。
2. 四大不平等条约：《南京条约》《马关条约》《辛丑条约》等及其影响。
3. 中国近代化历程：器物（洋务）→制度（戊戌、辛亥）→思想（新文化）。
4. 各阶层救亡：农民（太平天国、义和团）、地主（洋务）、资产阶级（维新、革命）。
5. 辛亥革命历史功绩：推翻帝制、建立共和、民主共和观念深入人心。
6. 近代中国社会主要矛盾：帝国主义与中华民族、封建主义与人民大众的矛盾。
