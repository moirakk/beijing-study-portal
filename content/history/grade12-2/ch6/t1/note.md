# 专题六 中国现代史（社会主义建设）

## 核心概念 / 课标要求

本专题涵盖1949年新中国成立以来的社会主义建设历程。课标要求掌握：新中国成立与巩固政权（土地改革、抗美援朝）；社会主义制度确立（三大改造、一五计划）；社会主义建设道路的探索（中共八大、大跃进、人民公社化、文革）；改革开放与中国特色社会主义（十一届三中全会、经济特区、市场经济体制）；新时代的成就。理解社会主义建设道路探索的曲折与成就。

## 知识梳理

| 时期 | 时间 | 关键事件 |
| --- | --- | --- |
| 巩固政权 | 1949-1952 | 土地改革、抗美援朝、稳定物价 |
| 制度确立 | 1953-1956 | 一五计划、三大改造、一届人大 |
| 探索时期 | 1956-1976 | 中共八大、大跃进、人民公社化、文革 |
| 改革开放 | 1978- | 十一届三中全会、经济特区、市场经济 |
| 新时代 | 2012- | 中国特色社会主义进入新时代 |

## 重点探究 / 典型例题

**例1（选择题）** 中共十一届三中全会作出的重大决策是（　）
A. 以阶级斗争为纲　B. 把工作重心转移到经济建设上来、实行改革开放　C. 建立人民公社　D. 发动文化大革命
**解析**：十一届三中全会果断停止"以阶级斗争为纲"，把工作重心转移到经济建设上来，实行改革开放。选 **B**。

**例2（材料题）** 材料：家庭联产承包责任制。
问：这一制度的内容、实质及意义是什么？
**解析**：内容：在坚持土地集体所有制前提下，包产到户、包干到户。实质：调整生产关系，调动农民生产积极性。意义：解放和发展农村生产力，推动农业发展，为城市经济体制改革提供借鉴。

**例3（探究）** 分析社会主义建设探索时期（1956-1976）的经验教训。
**解析**：成就：建立独立完整的工业体系，取得"两弹一星"等成就。失误：大跃进忽视客观规律、人民公社化超越生产力水平、文革造成严重破坏。教训：必须遵循客观经济规律，实事求是，以经济建设为中心，正确处理社会主义社会矛盾。

## 易错点

- 三大改造完成标志社会主义制度基本确立，不是新中国成立。
- 一五计划优先发展重工业，为工业化奠定初步基础。
- 大跃进是"左"倾错误在经济领域的表现，忽视客观经济规律。
- 家庭联产承包责任制是"包产到户"，但土地所有权仍归集体，只是经营权下放。
- 改革开放是"对内改革、对外开放"，经济特区是"窗口"，不是"租界"。

## 背记要点

1. 1949年新中国成立，1956年三大改造完成，社会主义制度基本确立。
2. 一五计划（1953-1957）优先发展重工业。
3. 中共八大正确分析主要矛盾，但未坚持；大跃进、人民公社化是"左"倾错误。
4. 1978年十一届三中全会：工作重心转移、改革开放，是伟大转折。
5. 经济特区：深圳、珠海、汕头、厦门、海南，是改革开放的窗口。
6. 1992年南方谈话和中共十四大确立社会主义市场经济体制目标。
