# 专题七 世界古代史

## 核心概念 / 课标要求

世界古代史涵盖古代文明的产生与多元发展。课标要求掌握：古代文明的产生（农业革命、阶级与国家）；古代亚非文明（古埃及、古巴比伦、古印度、中国）；古代希腊罗马文明（城邦、民主政治、罗马法）；中古时期的欧洲（封君封臣、庄园、城市自治）；中古时期的亚洲（阿拉伯帝国、奥斯曼帝国、日本、朝鲜）；古代美洲文明（玛雅、阿兹特克、印加）。理解文明多元并存、相互交流的特征。

## 重点探究 / 典型例题

**例1（选择题）** 古希腊城邦民主政治与古代东方专制制度不同的根本原因是（　）
A. 地理环境　B. 经济基础　C. 政治传统　D. 民族性格
**解析**：古希腊海洋文明、工商业发达，形成小国寡民的城邦和公民政治；东方大河文明、农业经济需要集中管理，形成专制集权。根本原因是经济基础（生产方式）不同。选 **B**。

**例2（材料题）** 材料：罗马法从公民法到万民法的发展。
问：罗马法为何从公民法发展到万民法？有何意义？
**解析**：原因：罗马疆域扩大，公民法只适用于罗马公民，无法适应帝国统治需要，故吸收外邦人法律形成万民法。意义：缓和矛盾、巩固统治，是近代欧洲法律的基础，蕴含的平等、法治观念影响深远。

**例3（探究）** 分析中古西欧城市自治兴起的原因与影响。
**解析**：原因：工商业发展、市民阶层壮大，通过赎买或斗争获得自治权。影响：促进商品经济发展，冲击封建庄园经济；市民阶层兴起，为资本主义萌芽和近代民主政治奠定基础。

## 易错点

- 古希腊民主是"成年男性公民"的民主，妇女、奴隶、外邦人无公民权，是少数人的民主。
- 罗马法从公民法到万民法，是适用范围扩大，不是法律精神改变。
- 中古西欧"封君封臣"是层层分封，但"我的附庸的附庸不是我的附庸"。
- 阿拉伯帝国是沟通东西方文明的桥梁，阿拉伯数字实际由印度人发明。
- 古代美洲文明与亚欧大陆隔绝，独立发展，未形成统一帝国。

## 背记要点

1. 古代文明产生于大河流域（亚非）和沿海地区（希腊），受地理环境影响。
2. 古希腊城邦民主政治、古罗马法是西方政治文明的源头。
3. 中古西欧：封君封臣、庄园经济、城市自治、基督教会。
4. 阿拉伯帝国：伊斯兰教、翻译运动、沟通东西方。
5. 古代美洲：玛雅、阿兹特克、印加文明，独立发展。
6. 文明交流：丝绸之路、阿拉伯人、蒙古西征促进东西方交流。
