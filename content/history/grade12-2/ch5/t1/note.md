# 专题五 中国近代史（新民主主义革命）

## 核心概念 / 课标要求

本专题涵盖1919—1949年新民主主义革命历程。课标要求掌握：五四运动与中国共产党成立；国民革命（国共第一次合作）；土地革命（井冈山道路）；抗日战争（全民族抗战）；解放战争（人民解放战争）。理解新民主主义革命与旧民主主义革命的区别，认识中国共产党领导革命走向胜利的历史必然性。

## 知识梳理

| 阶段 | 时间 | 关键事件 |
| --- | --- | --- |
| 五四运动 | 1919 | 新民主主义革命开端，工人阶级登上政治舞台 |
| 中共成立 | 1921 | 中共一大，确立社会主义和共产主义纲领 |
| 国民革命 | 1924-1927 | 国共合作、北伐战争，蒋介石叛变革命 |
| 土地革命 | 1927-1937 | 南昌起义、井冈山道路、红军长征、遵义会议 |
| 抗日战争 | 1937-1945 | 全民族抗战、国共第二次合作、抗战胜利 |
| 解放战争 | 1946-1949 | 三大战役、渡江战役、新中国成立 |

## 重点探究 / 典型例题

**例1（选择题）** 五四运动的历史意义在于（　）
A. 标志着新民主主义革命的开端　B. 推翻了清王朝　C. 建立了新中国　D. 完成了反帝反封建任务
**解析**：五四运动中工人阶级登上政治舞台，标志着新民主主义革命的开端。选 **A**。

**例2（材料题）** 材料："农村包围城市、武装夺取政权"道路的开辟。
问：中国共产党为何选择这条道路？其意义何在？
**解析**：原因：中国是半殖民地半封建社会，城市敌人力量强大，农村敌人统治薄弱；农民是革命主力军。意义：开辟了符合中国国情的革命道路，是马克思主义中国化的体现，指引中国革命走向胜利。

**例3（探究）** 分析抗日战争胜利的原因与意义。
**解析**：原因：全民族抗战（抗日民族统一战线）、中共中流砥柱作用、世界反法西斯力量支持。意义：近代以来中国反抗外来侵略第一次取得完全胜利，洗雪民族耻辱，提高国际地位，为世界反法西斯战争作出重大贡献。

## 易错点

- 五四运动是新民主主义革命的开端，但当时中共尚未成立，领导阶级是初步觉醒的工人阶级。
- 中共一大确立的是社会主义和共产主义纲领，中共二大才提出反帝反封建的民主革命纲领。
- 井冈山道路是"农村包围城市、武装夺取政权"，不是"城市中心论"。
- 遵义会议是中共从幼稚走向成熟的标志，确立了毛泽东在党和红军中的领导地位。
- 抗战胜利是"近代以来第一次完全胜利"，但抗战期间中国社会主要矛盾是中日民族矛盾。

## 背记要点

1. 五四运动：1919年，新民主主义革命开端，工人阶级登上政治舞台。
2. 中共成立：1921年中共一大，1922年中共二大提出民主革命纲领。
3. 井冈山道路：农村包围城市、武装夺取政权，马克思主义中国化。
4. 遵义会议：1935年，中共从幼稚走向成熟的标志。
5. 抗日战争：1937-1945，全民族抗战，中共中流砥柱，近代第一次完全胜利。
6. 三大战役与渡江战役：1948-1949，基本消灭国民党军队主力，推翻国民党统治。
