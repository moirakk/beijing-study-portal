# 专题九 世界近代史（工业革命与殖民）

## 核心概念 / 课标要求

本专题涵盖18世纪60年代至20世纪初的两次工业革命与资本主义世界殖民体系。课标要求掌握：第一次工业革命（英国、蒸汽时代、工厂制度）；第二次工业革命（电力时代、垄断组织）；资本主义世界市场最终形成；列强瓜分世界与殖民体系建立；工业革命对世界政治、经济、社会的影响。理解工业革命推动资本主义世界体系最终形成。

## 知识梳理

| 项目 | 第一次工业革命 | 第二次工业革命 |
| --- | --- | --- |
| 时间 | 18世纪60年代-19世纪中期 | 19世纪70年代-20世纪初 |
| 发源地 | 英国 | 美、德等多国 |
| 标志 | 蒸汽机 | 电力、内燃机 |
| 动力 | 蒸汽动力 | 电力、石油 |
| 生产组织 | 工厂制度 | 垄断组织 |
| 主要部门 | 纺织、钢铁 | 电力、石油、汽车、化学 |
| 世界市场 | 初步形成 | 最终形成 |

## 重点探究 / 典型例题

**例1（选择题）** 第二次工业革命与第一次相比，最显著的特点是（　）
A. 科学与技术紧密结合　B. 首先发生在英国　C. 以蒸汽为动力　D. 以轻工业为主
**解析**：第二次工业革命中，科学与技术紧密结合，发明创造多源于科学理论指导，且多国同时进行。选 **A**。

**例2（材料题）** 材料：垄断组织的出现。
问：垄断组织出现的原因、实质及影响是什么？
**解析**：原因：第二次工业革命推动生产社会化，竞争加剧，生产和资本高度集中。实质：资本主义生产关系的局部调整。影响：提高生产效率、推动经济发展，但也加剧贫富分化和对外扩张。

**例3（探究）** 分析工业革命对世界格局的影响。
**解析**：经济上，资本主义世界市场最终形成，世界日益连为一体；政治上，资本主义制度在世界范围内确立，亚非拉沦为殖民地半殖民地；社会结构上，工业资产阶级和无产阶级形成；国际关系上，形成以欧美为中心的资本主义世界体系，东方从属于西方。

## 易错点

- 第一次工业革命首先发生在英国，第二次工业革命在美、德等多国同时进行。
- 第一次工业革命以蒸汽为动力，第二次以电力和内燃机为动力。
- 垄断组织是资本主义生产关系的局部调整，不是生产关系的根本变革。
- 世界市场最终形成于第二次工业革命后（19世纪末20世纪初），不是第一次。
- 工业革命使东方从属于西方，形成"先进"与"落后"的格局，但并非所有地区都沦为殖民地。

## 背记要点

1. 第一次工业革命：英国、蒸汽时代、工厂制度、世界市场初步形成。
2. 第二次工业革命：电力时代、垄断组织、世界市场最终形成。
3. 瓦特改良蒸汽机是第一次工业革命标志，发电机、内燃机是第二次标志。
4. 垄断组织是生产和资本高度集中的结果，是生产关系的局部调整。
5. 资本主义世界体系：政治（制度）、经济（市场）、殖民（瓜分）三方面。
6. 工业革命推动社会进步，也带来环境污染、贫富分化等问题。
