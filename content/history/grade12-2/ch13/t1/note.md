# 专题十三 史料实证与历史解释

## 核心概念 / 课标要求

本专题是历史学科核心素养的核心，包括**史料实证**与**历史解释**两大素养。课标要求掌握：史料的分类（文献、实物、口述、图像等）与价值判断；史料实证的方法（孤证不立、多重互证、去伪存真）；历史解释的层次（史实、史论、史观）；历史评价的原则（客观、全面、辩证）。学会从材料中提取信息、分析问题、形成历史认识。

## 知识梳理

| 素养 | 内涵 | 方法/要求 |
| --- | --- | --- |
| 史料实证 | 依据史料还原历史 | 区分一手/二手史料，多重互证 |
| 历史解释 | 对历史进行理性分析 | 史论结合、客观辩证 |
| 史料分类 | 文献、实物、口述、图像 | 实物史料价值较高 |
| 历史评价 | 对历史事件人物评价 | 全面、辩证、放在特定时代 |
| 史观运用 | 用不同视角分析 | 全球史观、文明史观等 |

## 重点探究 / 典型例题

**例1（选择题）** 下列史料中，研究商代历史价值最高的是（　）
A. 《史记》记载　B. 甲骨文实物　C. 后世传说　D. 文学作品
**解析**：甲骨文是商代当时的实物史料，属于一手史料，价值最高；《史记》是后世文献，传说和文学价值较低。选 **B**。

**例2（材料题）** 材料：关于某历史事件，甲说"是正义的"，乙说"是侵略的"。
问：如何评价这一历史事件？谈谈你的认识。
**解析**：历史评价要客观、全面、辩证，放在特定历史背景下。不同立场、不同史观会得出不同结论。应综合多种史料，从多角度分析，避免片面和主观，做到史论结合、论从史出。

**例3（探究）** 如何理解"孤证不立"？
**解析**："孤证不立"指单一史料不能充分证明历史事实，因为史料可能有主观性、片面性或记载错误。应寻找多种相互印证的史料（多重互证），结合考古发现、文献记载等，提高结论的可靠性。

## 易错点

- 一手史料（原始史料）价值一般高于二手史料，但并非绝对，需具体分析。
- 实物史料（考古）价值高，但文献史料也有重要价值，不能一概而论。
- 历史解释要"论从史出、史论结合"，不能先入为主、以论带史。
- 评价历史人物事件要放在特定历史条件下，不能用今天的标准苛求古人。
- 不同史观（全球史观、革命史观等）会得出不同结论，要注意史观的选择。

## 背记要点

1. 史料分类：文献、实物、口述、图像；一手史料价值较高。
2. 史料实证方法：孤证不立、多重互证、去伪存真。
3. 历史解释：史实是基础，史论是观点，史观是视角。
4. 历史评价原则：客观、全面、辩证、时代性。
5. 论从史出、史论结合是历史学习的基本方法。
6. 核心素养：唯物史观、时空观念、史料实证、历史解释、家国情怀。
