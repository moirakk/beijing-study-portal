# 专题十四 历史小论文（开放性试题）

## 核心概念 / 课标要求

历史小论文是高考开放性试题，考查学生**历史解释**与**论证**能力。课标要求掌握：小论文的题型（观点评述、自拟论题、提取信息）；写作结构（论点—论据—论证—结论）；论证方法（史论结合、多角度、层次分明）；常见误区与得分技巧。学会从材料中提炼观点，用史实论证，形成逻辑严密的历史小论文。

## 知识梳理

| 题型 | 特点 | 答题要求 |
| --- | --- | --- |
| 观点评述 | 对给定观点评价 | 表明态度、史论结合 |
| 自拟论题 | 从材料提炼观点 | 论题明确、紧扣材料 |
| 提取信息 | 从图表材料提取 | 信息准确、分析到位 |
| 论证 | 用史实支撑观点 | 多角度、层次清晰 |
| 结论 | 总结升华 | 呼应论点、深化认识 |

## 重点探究 / 典型例题

**例1（小论文）** 材料：关于洋务运动的不同评价。
要求：围绕"洋务运动"自拟论题，写一篇历史小论文。
**示例**：论题：洋务运动是中国近代化的开端。论证：经济上，创办近代军事工业和民用工业，引进西方技术，开启中国近代工业化；教育上，创办新式学堂、派遣留学生，培养近代人才；军事上，建立近代海军。但洋务运动只学技术不变制度，最终失败，说明"中体西用"行不通。结论：洋务运动开启了中国近代化进程，但未能使中国富强。

**例2（观点评述）** 材料：有人认为"辛亥革命是成功的"，有人认为"辛亥革命是失败的"。
要求：评述这一观点。
**解析**：两种观点都有道理，应从辩证角度评述。成功：推翻清王朝、结束君主专制、建立共和、民主共和观念深入人心。失败：未改变半殖民地半封建社会性质，未完成反帝反封建任务。结论：辛亥革命是伟大的资产阶级民主革命，但具有局限性。

**例3（探究）** 小论文写作的常见误区有哪些？
**解析**：误区：论题不明确或偏离材料；只罗列史实不论证；观点与论据脱节；缺乏多角度分析；结论不呼应论点；语言口语化、缺乏历史学科术语。应做到论题明确、史论结合、层次清晰、结论升华。

## 易错点

- 论题要"明确、具体、可论证"，不能过于宽泛或含糊。
- 论据要"史实准确、典型"，不能张冠李戴。
- 论证要"多角度、有层次"，不能单一或重复。
- 结论要"呼应论点、适当升华"，不能草草收尾。
- 语言要"规范、学科化"，避免口语化和空话套话。

## 背记要点

1. 小论文结构：论点—论据—论证—结论。
2. 论题要明确、具体、紧扣材料。
3. 论据要史实准确、典型、充分。
4. 论证要史论结合、多角度、层次分明。
5. 结论要呼应论点、深化认识。
6. 语言规范、逻辑严密、卷面整洁。
