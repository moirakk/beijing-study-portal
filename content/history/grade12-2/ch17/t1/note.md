# 专题十七 国家制度与社会治理（选必1整合）

## 核心概念 / 课标要求

本专题整合选择性必修1《国家制度与社会治理》内容。课标要求掌握：政治制度（中外政治制度演变）；官员的选拔与管理（察举、科举、文官制度）；法律与教化（中外法律体系、礼法结合）；民族关系与国家关系（民族政策、外交）；基层治理与社会保障（户籍、乡里、社会保障）。理解国家制度与社会治理的演变规律及其历史作用。

| 领域 | 中国 | 西方 |
| --- | --- | --- |
| 政治制度 | 中央集权、人民代表大会 | 民主共和、君主立宪 |
| 官员选拔 | 察举、九品中正、科举 | 文官制度、考试录用 |
| 法律教化 | 礼法结合、德主刑辅 | 罗马法、大陆法系、英美法系 |
| 民族外交 | 民族政策、朝贡体系 | 民族国家、国际法 |
| 基层治理 | 户籍、乡里、保甲 | 社区、社会保障 |

## 重点探究 / 典型例题

**例1（选择题）** 科举制相比九品中正制，其进步性主要体现在（　）
A. 扩大统治基础、打破门第限制　B. 加强地方权力　C. 提高官员俸禄　D. 减少考试科目
**解析**：科举制以考试成绩选拔官员，打破世家大族垄断，扩大统治基础，促进社会阶层流动。选 **A**。

**例2（材料题）** 材料：中国古代"礼法结合、德主刑辅"的治国理念。
问：这一理念有何特点？对今天有何启示？
**解析**：特点：以礼（道德教化）为主，以法（刑罚）为辅，德治与法治相结合。启示：法治与德治相结合，重视道德教化，对今天建设法治社会、以德治国具有借鉴意义。

**例3（探究）** 比较中国古代科举制与西方近代文官制度。
**解析**：科举制以考试选拔官员，打破门第，扩大统治基础；西方文官制度受科举制影响，实行考试录用、政治中立、职务常任。二者都体现公平竞争、择优录用，但科举制服务于君主专制，文官制度服务于资产阶级民主政治。

## 易错点

- 科举制是考试选官，但服务于君主专制，不能简单等同于现代文官制度。
- 中国古代"礼法结合"是德主刑辅，不是"以法治国"。
- 西方文官制度"政治中立"，不受政党更替影响。
- 基层治理（户籍、乡里、保甲）是维护统治、征收赋役的重要手段。
- 中外制度各具特色，应相互借鉴，但不能照搬。

## 背记要点

1. 选官制度演变：世卿世禄→察举→九品中正→科举。
2. 科举制：扩大统治基础、促进社会流动、影响深远。
3. 法律教化：中国礼法结合、德主刑辅；西方罗马法、两大法系。
4. 民族关系：中国民族政策、朝贡体系；西方民族国家。
5. 基层治理：户籍、乡里、保甲、社会保障。
6. 中外制度相互借鉴，各具特色，服务国家治理。
