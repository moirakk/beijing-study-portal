# 专题二 中国古代经济

## 核心概念 / 课标要求

中国古代经济以**小农经济**（自给自足的自然经济）为主体，涵盖农业、手工业、商业三大部门。课标要求掌握：精耕细作的传统农业（耕作工具、耕作技术、水利灌溉）；官营、民营、家庭手工业三种形态；商业与城市的发展（坊市制度、市镇经济）；经济重心南移；重农抑商与海禁、闭关锁国政策。理解经济基础对政治、思想文化的决定作用。

## 知识梳理

| 部门 | 发展历程 | 关键史实 |
| --- | --- | --- |
| 农业 | 原始→春秋战国铁犁牛耕→隋唐曲辕犁 | 精耕细作、男耕女织、自给自足 |
| 水利 | 都江堰、郑国渠、灵渠 | 灌溉工具：翻车、筒车 |
| 手工业 | 官营、民营、家庭三种形态 | 冶铁、制瓷（青瓷白瓷彩瓷）、丝织 |
| 商业 | 坊市制→市镇经济 | 交子（最早纸币）、商帮（晋商徽商） |
| 政策 | 重农抑商、海禁、闭关锁国 | 抑制商业、限制对外贸易 |

## 重点探究 / 典型例题

**例1（选择题）** 北宋时期出现世界上最早的纸币"交子"，其根本原因是（　）
A. 商品经济发展　B. 政府财政困难　C. 印刷技术进步　D. 对外贸易扩大
**解析**：交子的出现是商品经济发展、货币流通量增大的结果。选 **A**。

**例2（材料题）** 材料："（江南）地广野丰，民勤本业，一岁或稔，则数郡忘饥。"——《宋书》
问：材料反映江南经济有何变化？结合所学分析原因。
**解析**：变化：江南经济繁荣、农业发达。原因：北方战乱，人口大量南迁带来劳动力和先进技术；南方自然条件优越；统治者重视；社会相对安定。这反映了经济重心南移。

**例3（探究）** 分析重农抑商政策的历史作用。
**解析**：积极作用：封建社会前期有利于稳定小农经济、巩固封建统治、维护社会稳定。消极作用：明清时期阻碍了商品经济和资本主义萌芽的发展，导致中国逐渐落后于世界。

## 易错点

- 小农经济不等于自然经济：自然经济强调自给自足，小农经济是其主要形式，但小农经济还包含商品交换成分。
- 官营手工业产品不进入市场，主要供官府和皇室使用。
- 交子出现在北宋四川地区，是世界上最早的纸币，但并非全国通用。
- 经济重心南移完成于南宋，不是唐朝。
- 闭关锁国并非完全禁绝对外贸易，而是严格限制（仅广州一口通商）。

## 背记要点

1. 小农经济特点：以家庭为单位、男耕女织、自给自足、精耕细作。
2. 铁犁牛耕是传统农业的主要耕作方式，曲辕犁标志耕作技术成熟。
3. 手工业三种形态：官营（技术最高）、民营、家庭（副业）。
4. 商业发展：宋以前坊市分离，宋以后坊市界限打破、出现市镇。
5. 经济重心南移：东晋南朝开始，唐末五代加速，南宋完成。
6. 重农抑商、海禁、闭关锁国是明清经济政策，阻碍资本主义萌芽。
