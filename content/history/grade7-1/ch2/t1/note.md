# 奴隶制王朝的更替和向封建社会的过渡（单元导学）

标签：#夏商周时期 #单元导学 #社会转型

## 一、本知识点定位

统编版中国历史七年级上册 **第二单元 夏商周时期：奴隶制王朝的更替和向封建社会的过渡** 的单元导学。本单元包括第4—8课，从夏朝建立讲到战国变法与百家争鸣，是中国早期国家形成与社会转型的关键时期。

## 三、单元知识框架

### 1. 五课内容的逻辑线索

- **第4课**：夏、商、西周三个奴隶制王朝的建立、更替与制度（世袭制、分封制）。
- **第5课**：春秋时期王室衰微、诸侯争霸、经济发展（铁器牛耕出现）。
- **第6课**：战国时期兼并战争、商鞅变法、都江堰——向封建社会过渡。
- **第7课**：社会大变革在思想领域的反映——百家争鸣。
- **第8课**：夏商周时期的科技与文化成就（甲骨文、青铜器、天文历法医学、《诗经》与楚辞）。

### 2. 社会转型的主线

- 经济：**铁制农具和牛耕的出现与推广** → 生产力发展 → 新兴地主阶级兴起。
- 政治：**分封制逐步瓦解** → 各国变法 → 中央集权的封建制度逐渐确立。
- 思想：社会变革引发思想解放 → **百家争鸣**。

## 四、重要概念

| 术语 | 定义 |
|---|---|
| 奴隶制王朝 | 以奴隶主贵族占有奴隶和土地为基础的国家，如夏、商、西周 |
| 世袭制 | 王位、爵位在一家一姓中世代传承的制度 |
| 分封制 | 周王将宗亲功臣分封到各地建立诸侯国、拱卫王室的制度 |
| 封建社会 | 以地主阶级占有土地、剥削农民为基础的社会形态 |
| 变法 | 通过改革旧制度以富国强兵的运动，如商鞅变法 |

## 六、背记要点

1. 约公元前2070年禹建立夏朝——我国历史上第一个奴隶制王朝。
2. 夏→商→西周的更替：桀亡夏、纣亡商，暴政失民心是共同原因。
3. 公元前770年平王东迁，东周开始，分春秋、战国两个阶段。
4. 春秋争霸、战国兼并，统一趋势不断加强。
5. 铁器牛耕的使用推广是春秋战国社会变革的根本原因。
6. 商鞅变法使秦国成为最强盛的诸侯国。
7. 百家争鸣是中国古代第一次思想文化发展的高峰。

## 七、自测小题

1. 我国历史上第一个奴隶制王朝是______，建立者是______。
2. 东周开始于公元前______年，分为______和______两个时期。
3. 春秋战国时期社会变革的根本原因是（A. 战争频繁 B. 铁器牛耕的使用推广 C. 诸侯野心）。
4. 使秦国成为战国后期最强盛诸侯国的改革是______。
5. 战国时期战争的特点是（A. 争霸 B. 兼并 C. 防御）。
6. 判断：夏商西周属于封建社会。（对/错）

**答案**：1. 夏朝；禹 2. 770；春秋；战国 3. B 4. 商鞅变法 5. B 6. 错（属于奴隶社会）
