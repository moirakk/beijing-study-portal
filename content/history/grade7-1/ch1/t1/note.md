# 原始社会与中华文明的起源（单元导学）

标签：#史前时期 #单元导学 #中华文明起源

## 一、本知识点定位

统编版中国历史七年级上册 **第一单元 史前时期：原始社会与中华文明的起源** 的单元导学。本单元包括第1—3课，讲述从远古人类出现到中华文明起源的漫长历程，是整册中国历史学习的起点。

## 二、单元时间轴与关键坐标

| 时间 | 大事 |
|---|---|
| 约170万年前 | 元谋人生活在云南元谋（我国境内目前已知最早的古人类之一） |
| 约70万—20万年前 | 北京人生活在北京周口店 |
| 约3万年前 | 山顶洞人出现，已掌握磨光和钻孔技术 |
| 约1万年前 | 我国进入新石器时代，原始农业兴起 |
| 约7000年前 | 河姆渡人生活在长江流域，种植水稻 |
| 约6000年前 | 半坡人生活在黄河流域，种植粟 |
| 约5000多年前 | 良渚、陶寺等古城出现，中华文明起源 |
| 约4000多年前 | 传说中炎帝、黄帝、尧舜禹的时代 |

## 三、单元知识框架

### 1. 三课内容的逻辑线索

- **第1课 远古时期的人类活动**：讲"人从哪里来"——元谋人、北京人、山顶洞人等古人类的生产生活。
- **第2课 原始农业与史前社会**：讲"人怎样定居下来"——原始农业兴起，河姆渡、半坡等农耕聚落出现。
- **第3课 中华文明的起源**：讲"文明如何起源"——早期国家雏形出现，良渚古城、陶寺古城与炎黄传说。

### 2. 社会发展的总趋势

- 生产工具：**打制石器（旧石器时代）→ 磨制石器（新石器时代）**。
- 生活方式：**采集渔猎、群居 → 农耕定居、聚落**。
- 社会组织：**原始群 → 氏族 → 部落、部落联盟 → 早期国家雏形**。

## 四、重要概念

| 术语 | 定义 |
|---|---|
| 旧石器时代 | 以打制石器为主要工具的时代 |
| 新石器时代 | 以磨制石器为主要工具的时代，出现原始农业 |
| 化石 | 保存在地层中的古代生物遗骸或遗迹，研究远古人类的重要证据 |
| 考古发现 | 通过发掘遗址、遗物研究历史，是了解史前社会的主要依据 |
| 文明 | 一般以城市、王权（国家）、社会分化等出现为主要标志 |

## 五、易混辨析

| 对比项 | 旧石器时代 | 新石器时代 |
|---|---|---|
| 工具 | 打制石器 | 磨制石器 |
| 食物来源 | 采集、狩猎 | 原始农业、饲养家畜 |
| 居住方式 | 洞穴、迁徙 | 定居聚落、建造房屋 |
| 代表 | 元谋人、北京人 | 河姆渡人、半坡人 |

## 六、背记要点

1. 我国是世界上发现古人类遗址最多的国家之一。
2. 元谋人距今约170万年，是我国境内目前已知最早的古人类之一。
3. 北京人距今约70万—20万年，会使用天然火、打制石器。
4. 约1万年前我国进入新石器时代，原始农业兴起。
5. 河姆渡人种水稻（长江流域），半坡人种粟（黄河流域）。
6. 良渚古城、陶寺古城实证中华文明有5000多年历史。
7. 炎帝和黄帝被尊为中华民族的人文初祖。
8. 学习史前历史主要依靠**考古发现**，传说需要与考古印证。

## 七、自测小题

1. 我国境内目前已知最早的古人类之一是______人，距今约______万年。
2. 以打制石器为主要工具的时代称为______时代。
3. 种植水稻的原始居民是（A. 半坡人 B. 河姆渡人 C. 北京人）。
4. 中华文明有5000多年历史的实证遗址是（A. 周口店 B. 良渚古城 C. 半坡遗址）。
5. 被尊为中华民族人文初祖的是______和______。
6. 判断：研究史前时期历史的主要依据是文字记载。（对/错）

**答案**：1. 元谋；170 2. 旧石器 3. B 4. B 5. 炎帝；黄帝 6. 错（主要依据考古发现）
