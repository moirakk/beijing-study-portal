# 第13课 东汉的兴衰

标签：#秦汉时期 #光武中兴 #外戚宦官 #黄巾起义

## 一、本知识点定位

统编版中国历史七年级上册 **第三单元 秦汉时期 · 第13课**。本课学习东汉的建立与"光武中兴"、外戚宦官交替专权、黄巾起义，理解东汉由兴到衰的过程。

## 三、知识梳理

### 1. 东汉建立与"光武中兴"

- **西汉灭亡**：公元9年，外戚**王莽**夺取政权，建立**新朝**，西汉灭亡。王莽施政加剧动荡，引发农民起义，新朝被推翻。
- **东汉建立**：公元25年，西汉宗室**刘秀**称帝，定都**洛阳**，史称东汉；刘秀就是**光武帝**。
- **光武帝巩固统治的措施**：
  - 多次下令释放奴婢，减轻农民负担，减轻刑罚。
  - 合并郡县，裁减官员，加强对官吏的监督，惩处贪官污吏。
  - 允许北方各族内迁，缓和民族矛盾。
- **结果**：社会出现比较安定的局面，经济得到恢复和发展，史称"**光武中兴**"。

### 2. 外戚与宦官交替专权（东汉衰落的政治原因）

- **原因**：东汉中期以后，继位的皇帝大多年幼，无法主政。
- **循环过程**：皇帝年幼→**外戚**（太后娘家人）把持朝政→皇帝长大，依靠**宦官**夺回大权→宦官专权→下一个幼帝继位，外戚再起……如此循环往复。
- **危害**：政治腐朽不堪，正直官员遭到陷害，社会混乱，人民遭殃，动摇了东汉的统治，**东汉走向衰亡**。
- 与此同时，地方**豪强大族**势力膨胀，兼并土地，拥有私人武装，成为割据隐患。

### 3. 黄巾起义

- **背景**：东汉后期朝政腐败，赋税沉重，自然灾害频发，人民无法生存。
- **准备**：**张角**创立**太平道**，经过10多年在社会底层传教，信徒达数十万人。
- **爆发**：**184年**，起义爆发，起义军头裹黄巾，提出"苍天已死，黄天当立，岁在甲子，天下大吉"的口号。这是一场**有组织、有准备**的农民大起义。
- **结果与影响**：在东汉军队镇压下主力失败，但起义**沉重打击了东汉的统治**。此后地方州郡长官和豪强武装拥兵自重，东汉政权名存实亡，逐渐形成军阀割据局面。

## 四、重要概念

| 术语 | 定义 |
|---|---|
| 外戚 | 皇帝母亲、妻子一方的亲族 |
| 宦官 | 宫廷中侍奉皇帝及其家族的人员 |
| 光武中兴 | 光武帝统治后期社会安定、经济恢复的局面 |
| 太平道 | 张角创立的宗教组织，黄巾起义的组织基础 |

| 共同措施 | 轻徭薄赋、减轻刑罚、提倡节俭 | |

|---|---|---|

## 六、背记要点

1. 公元9年王莽建新朝，西汉灭亡。
2. 公元25年刘秀建东汉，定都洛阳。
3. 光武帝：释放奴婢、减轻负担、整顿吏治→"光武中兴"。
4. 东汉中后期外戚与宦官交替专权，政治腐朽。
5. 184年张角领导黄巾起义，利用太平道组织。
6. 黄巾起义是有组织、有准备的农民大起义。
7. 黄巾起义后东汉名存实亡，走向军阀割据。

## 七、自测小题

1. 西汉灭亡于公元______年，篡权者是外戚______。
2. 东汉的建立者是______，定都______。
3. "光武中兴"出现的原因不包括（A. 释放奴婢 B. 惩处贪官 C. 焚书坑儒）。
4. 东汉中后期政治腐朽的主要表现是______与______交替专权。
5. 黄巾起义爆发于______年，领导人是______。
6. 黄巾起义的组织基础是张角创立的（A. 五斗米道 B. 太平道 C. 白莲教）。
7. 判断：黄巾起义直接灭亡了东汉王朝。（对/错）

**答案**：1. 9；王莽 2. 刘秀；洛阳 3. C 4. 外戚；宦官 5. 184；张角 6. B 7. 错（沉重打击但未直接灭亡，东汉此后名存实亡）
