# 第14课 丝绸之路的开通与经营西域

标签：#秦汉时期 #张骞通西域 #丝绸之路 #西域都护

## 一、本知识点定位

统编版中国历史七年级上册 **第三单元 秦汉时期 · 第14课**。本课学习张骞通西域、丝绸之路的开通以及汉朝对西域的管理，理解丝绸之路在中外交流中的重要作用。

| 时间 | 大事 | 人物 |

| 公元前138年 | 第一次出使西域（联络大月氏夹击匈奴） | 张骞 |
| 公元前119年 | 第二次出使西域（走访各国、建立友好关系） | 张骞 |
| 公元前60年 | 西汉设置**西域都护** | —— |
| 东汉明帝时起 | 班超出使并长期经营西域；甘英出使大秦（抵达安息） | 班超、甘英 |

## 三、知识梳理

### 1. 张骞通西域

- **西域**：汉代把今**甘肃阳关、玉门关以西**，也就是现在新疆和更远的广大地区称为西域。
- **第一次出使**（公元前138年）：汉武帝招募使者出使西域，目的是联络**大月氏夹击匈奴**。张骞途中两次被匈奴扣留，前后十余年，虽未达成军事目的，但**了解了西域各国情况**。
- **第二次出使**（公元前119年）：走访西域许多国家，促进了汉朝与西域各国的**相互了解与友好往来**。
- 张骞"凿空"西域，其不畏艰险、百折不挠的精神值得学习。

### 2. 丝绸之路

- **陆上丝绸之路路线**：**长安 → 河西走廊 → 西域 → 中亚、西亚 → 欧洲**。
- 因大量中国**丝绸**经此路西运而得名。
- **交流内容**：
  - 西传：丝绸、漆器、茶叶等物品，凿井、冶铁等技术。
  - 东来：核桃、葡萄、石榴、苜蓿、良种马、乐器、歌舞等。
- **海上丝绸之路**：汉武帝时开辟，从东南沿海港口出发，最远抵达**印度半岛南端和锡兰**（今斯里兰卡）。
- **地位**：丝绸之路是古代**东西方往来的大动脉**，对中国同其他国家和地区的贸易与文化交流起到极大的促进作用。

### 3. 对西域的管理

- **西域都护**：公元前60年西汉设置，作为管理西域的最高长官，管辖今新疆及巴尔喀什湖以东、以南的广大地区。**标志着西域正式归属中央政权**，其管辖范围包括今新疆及巴尔喀什湖以东、以南地区。
- **东汉经营**：明帝时派**班超**出使西域，班超在西域活动30多年，使西域各国重新与汉朝建立联系；班超派**甘英**出使大秦（罗马帝国），甘英抵达安息（波斯）后返回，开辟了通往西亚的路线。班超之子班勇继续经营西域。

## 四、重要概念

| 术语 | 定义 |

| 丝绸之路 | 以长安为起点、连接欧亚的古代商路 |
| 西域都护 | 西汉管理西域的最高长官 |
| 大秦 | 汉代对罗马帝国的称呼 |

## 五、易混辨析

| 对比项 | 张骞第一次出使 | 张骞第二次出使 |
|---|---|---|
| 时间 | 公元前138年 | 公元前119年 |
| 目的 | 联络大月氏夹击匈奴（军事） | 发展与西域各国友好关系（外交） |
| 成果 | 了解西域情况 | 促进相互往来，为丝路开通奠基 |

注意：**丝绸之路的起点是长安**；**新疆正式归属中央政权始于公元前60年设西域都护**——这两个点常考。

## 六、背记要点

1. 西域：阳关、玉门关以西的广大地区。
2. 公元前138年、前119年张骞两次出使西域。
3. 第一次目的：联络大月氏夹击匈奴。
4. 陆上丝路：长安→河西走廊→西域→中亚西亚→欧洲。
5. 公元前60年设西域都护，西域（今新疆地区）正式归属中央政权。
6. 东汉班超经营西域30多年；甘英出使大秦抵达安息。
7. 丝绸之路是古代东西方往来的大动脉。

## 七、自测小题

1. 汉代把今甘肃______、______以西的地区称为西域。
2. 张骞第一次出使西域的目的是联络______夹击匈奴。
3. 陆上丝绸之路的起点是（A. 洛阳 B. 长安 C. 咸阳）。
4. 今新疆地区正式归属中央政权的标志是公元前60年设置______。
5. 东汉时在西域活动30多年的是（A. 张骞 B. 班超 C. 甘英）。
6. 受班超派遣出使大秦的是______。
7. 通过丝绸之路传入中国的物产有（A. 丝绸、漆器 B. 葡萄、石榴 C. 凿井技术）。
8. 判断：张骞第一次出使西域圆满完成了夹击匈奴的军事任务。（对/错）

**答案**：1. 阳关；玉门关 2. 大月氏 3. B 4. 西域都护 5. B 6. 甘英 7. B 8. 错（未达成军事目的，但了解了西域）
