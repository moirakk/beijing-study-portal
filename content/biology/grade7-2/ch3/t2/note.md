# 青春期

## 核心概念

| 术语 | 含义 |
|------|------|
| 青春期 | 由儿童发育到成人的过渡时期，身体发生显著变化 |
| 第二性征 | 除生殖器官以外的男女性别差异特征 |
| 性激素 | 促进第二性征发育的激素（雄/雌性激素） |
| 月经 | 女性子宫内膜周期性脱落出血的现象 |

### 青春期的身体变化

**显著特点：** 身高突增（青春期最突出的特征）

| 变化类型 | 具体表现 |
|----------|----------|
| 身高体重 | 迅速增长，骨骼肌肉发育加快 |
| 神经系统 | 大脑功能增强，思维能力提高 |
| 生殖器官 | 开始发育并逐渐成熟 |
| 第二性征 | 男：喉结突出、声音变粗；女：骨盆变宽、声音变细 |

### 第二性征

| 男性 | 女性 |
|------|------|
| 喉结突出 | 骨盆变宽 |
| 声音变粗（变声） | 声音变细 |
| 长胡须 | 乳房发育 |
| 肌肉发达 | 皮下脂肪增多 |

> 第二性征是由**性激素**（睾丸分泌雄性激素、卵巢分泌雌性激素）促进发育的

### 青春期的心理变化

- 独立意识增强，渴望被理解和尊重
- 情绪波动较大，容易冲动
- 开始关注自身形象，对异性产生好感
- 这些都是**正常的心理变化**

### 青春期的卫生保健

| 方面 | 建议 |
|------|------|
| 营养 | 合理膳食，保证蛋白质、钙、铁等摄入 |
| 运动 | 积极参加体育锻炼，促进骨骼发育 |
| 卫生 | 注意个人清洁卫生 |
| 心理 | 正确认识身体变化，保持积极心态 |
| 学习 | 集中精力学习，培养广泛兴趣 |

> **背记要点：**
> - 青春期最突出特征：身高突增
> - 第二性征由性激素促进发育
> - 心理变化是正常的，要正确对待
