# 人体发育第一节

## 核心概念

| 术语 | 含义 |
|------|------|
| 生殖系统 | 产生生殖细胞、孕育新个体的器官系统 |
| 受精 | 精子和卵细胞结合形成受精卵的过程 |
| 胚胎发育 | 受精卵在母体内分裂分化发育的过程 |
| 分娩 | 胎儿从母体产出的过程 |

### 人体生殖系统

**男性主要器官：** 睾丸（产生精子，分泌雄性激素）
**女性主要器官：** 卵巢（产生卵细胞，分泌雌性激素）

| 结构 | 男性功能 | 女性功能 |
|------|----------|----------|
| 主要器官 | 睾丸——产生精子 | 卵巢——产生卵细胞 |
| 输送管道 | 输精管 | 输卵管（受精场所） |
| 孕育场所 | — | 子宫（胚胎发育场所） |

### 受精与胚胎发育

1. 精子和卵细胞在**输卵管**中结合→**受精卵**
2. 受精卵一边分裂一边沿输卵管向子宫移动
3. 在**子宫**内膜着床，继续发育
4. 胚胎通过**胎盘**和**脐带**从母体获取营养和氧气
5. 约**40周（280天）** 发育成熟，分娩

### 胚胎发育过程

| 时期 | 发育特点 |
|------|----------|
| 第1-2周 | 受精卵分裂，植入子宫 |
| 第2-8周 | 称为胚胎，各器官初步形成 |
| 第9周-出生 | 称为胎儿，器官逐渐完善 |
| 约40周 | 发育成熟，分娩 |

### 胎盘的功能

- 胎儿与母体之间**物质交换**的器官
- 母体血液中的营养和O₂→胎儿
- 胎儿产生的CO₂和废物→母体
- 注意：母体血液与胎儿血液**不直接相通**

> **背记要点：**
> - 受精场所：输卵管；发育场所：子宫
> - 胎盘是物质交换的结构，母子血液不直接混合
> - 胚胎发育约280天（40周）
