# 呼吸道对空气的处理

## 核心概念

| 术语 | 含义 |
|------|------|
| 呼吸系统 | 由呼吸道和肺组成 |
| 呼吸道 | 鼻腔→咽→喉→气管→支气管 |
| 肺 | 气体交换的场所 |
| 会厌软骨 | 吞咽时盖住喉口，防止食物误入气管 |

### 呼吸系统的组成

| 组成 | 结构 | 功能 |
|------|------|------|
| 呼吸道 | 鼻→咽→喉→气管→支气管 | 气体进出的通道 |
| 肺 | 左肺（两叶）右肺（三叶） | 气体交换的场所 |

### 呼吸道对空气的处理

| 部位 | 处理方式 | 作用 |
|------|----------|------|
| 鼻腔 | 鼻毛过滤 | 阻挡灰尘和大颗粒 |
| 鼻腔 | 黏膜分泌黏液 | 粘住灰尘和细菌 |
| 鼻腔 | 黏膜毛细血管 | 温暖空气 |
| 鼻腔 | 黏液湿润 | 湿润空气 |
| 气管/支气管 | 纤毛摆动 | 推送黏液和异物向咽部排出 |
| 气管 | C形软骨环 | 保持气管畅通 |

> 呼吸道对空气的处理：**清洁、温暖、湿润**

### 咽——食物和气体的共同通道

- 咽是消化道和呼吸道的**交叉路口**
- 吞咽时**会厌软骨**盖住喉口→食物进入食道
- 呼吸时会厌软骨抬起→空气进入气管
- **边吃边笑**容易呛食——会厌软骨来不及盖住喉口

### 声音的产生

- 喉部有**声带**
- 呼气时气流冲击声带振动→产生声音
- 青春期声带变化→变声

### 呼吸道的保健

| 问题 | 预防措施 |
|------|----------|
| 空气污染 | 雾霾天戴口罩，减少户外活动 |
| 吸烟危害 | 不吸烟，远离二手烟 |
| 粉尘作业 | 佩戴防尘面具 |
| 感冒咳嗽 | 注意保暖，及时就医 |

> **背记要点：**
> - 呼吸道功能：清洁、温暖、湿润空气
> - 咽是食物和气体的共同通道
> - 会厌软骨防止食物误入气管
> - 鼻腔处理空气：鼻毛过滤+黏液粘尘+血管温暖
