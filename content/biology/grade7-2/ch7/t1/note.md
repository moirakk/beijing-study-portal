# 综合实践：设计并制作人体结构模型

## 实践目标

| 目标 | 内容 |
|------|------|
| 知识目标 | 综合理解人体各系统的结构与位置关系 |
| 能力目标 | 培养动手制作和创意设计能力 |
| 情感目标 | 体会人体结构的精密性，增强健康意识 |

### 模型类型选择

| 模型类型 | 适用系统 | 推荐材料 |
|----------|----------|----------|
| 消化系统模型 | 消化道和消化腺 | 软管、气球、塑料袋 |
| 呼吸系统模型 | 呼吸道和肺 | 吸管、气球、塑料瓶 |
| 血液循环模型 | 心脏和血管 | 橡皮泥、软管、红蓝颜料 |
| 综合躯干模型 | 多系统位置关系 | 纸板、泡沫、彩泥 |

### 制作呼吸模型（推荐方案）

**材料：** 塑料瓶、Y形玻璃管、两个小气球、橡皮膜、橡皮筋

**制作步骤：**
1. 将塑料瓶底部剪掉
2. Y形管从瓶口插入，两端各系一个小气球（代表肺）
3. 瓶底用橡皮膜封住（代表膈肌）
4. 向下拉橡皮膜→气球膨胀（模拟吸气）
5. 松开橡皮膜→气球回缩（模拟呼气）

**对应关系：**

| 模型部分 | 代表结构 |
|----------|----------|
| 塑料瓶 | 胸廓 |
| Y形管 | 气管和支气管 |
| 小气球 | 肺 |
| 橡皮膜 | 膈肌 |

### 评价标准

| 评价维度 | 标准 |
|----------|------|
| 科学性 | 结构与真实人体对应准确 |
| 功能性 | 能演示相关生理过程 |
| 美观性 | 制作整洁，标注清晰 |
| 创新性 | 有独特设计或改良 |

### 实践报告要求

1. 说明选择制作哪个系统模型及原因
2. 列出材料清单
3. 描述制作步骤（配图或照片）
4. 分析模型与真实结构的对应关系
5. 讨论模型的优缺点和改进方向

> **背记要点：**
> - 模型制作要体现科学性（结构对应准确）
> - 呼吸模型：瓶=胸廓，气球=肺，橡皮膜=膈肌
> - 拉膜=吸气（膈肌收缩），松膜=呼气（膈肌舒张）
