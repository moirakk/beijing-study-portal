# 人体内废物的排出·重点梳理

## 核心概念

| 术语 | 含义 |
|------|------|
| 排泄 | 人体将代谢废物排出体外的过程 |
| 泌尿系统 | 形成和排出尿液的器官系统 |
| 肾单位 | 肾脏结构和功能的基本单位 |
| 肾小球 | 毛细血管球，过滤血液 |

### 排泄的途径

| 途径 | 排出物 | 器官 |
|------|--------|------|
| 排尿 | 尿素、多余的水和无机盐 | 泌尿系统 |
| 排汗 | 水、无机盐、少量尿素 | 皮肤 |
| 呼气 | CO₂、少量水 | 呼吸系统 |

> 注意：排便**不是**排泄（粪便中的食物残渣未参与细胞代谢）

### 泌尿系统的组成

| 器官 | 功能 |
|------|------|
| 肾脏（一对） | 形成尿液（核心器官） |
| 输尿管（一对） | 输送尿液到膀胱 |
| 膀胱 | 暂时储存尿液 |
| 尿道 | 排出尿液 |

### 肾单位的结构

肾单位 = **肾小球** + **肾小囊** + **肾小管**

| 结构 | 特点 | 功能 |
|------|------|------|
| 肾小球 | 毛细血管球 | 过滤血液 |
| 肾小囊 | 双层囊状，包在肾小球外 | 收集滤过液 |
| 肾小管 | 细长弯曲管道 | 重吸收有用物质 |

### 尿液的形成过程

**第一步：肾小球的滤过作用**
- 血液流经肾小球时，水、无机盐、葡萄糖、尿素等小分子物质滤过进入肾小囊
- 血细胞和大分子蛋白质**不能**滤过
- 形成**原尿**（每天约180L）

**第二步：肾小管的重吸收作用**
- 原尿流经肾小管时，全部葡萄糖、大部分水和部分无机盐被重吸收回血液
- 形成**尿液**（每天约1.5L）

### 血液、原尿、尿液成分对比

| 成分 | 血液 | 原尿 | 尿液 |
|------|------|------|------|
| 蛋白质 | 有 | 无 | 无 |
| 葡萄糖 | 有 | 有 | 无 |
| 尿素 | 少 | 有 | 多（浓缩） |
| 血细胞 | 有 | 无 | 无 |

> **背记要点：**
> - 排便≠排泄
> - 肾单位=肾小球+肾小囊+肾小管
> - 肾小球滤过（留住血细胞和蛋白质）→肾小管重吸收（回收葡萄糖和大部分水）
> - 原尿有葡萄糖，尿液无葡萄糖（被重吸收）
