# 输送血液的泵——心脏

## 核心概念

| 术语 | 含义 |
|------|------|
| 心脏 | 血液循环的动力器官 |
| 心房 | 接收血液（上方的腔） |
| 心室 | 泵出血液（下方的腔，壁较厚） |
| 体循环 | 左心室→全身→右心房 |
| 肺循环 | 右心室→肺→左心房 |

### 心脏的结构

| 腔室 | 连接血管 | 功能 |
|------|----------|------|
| 左心房 | 肺静脉 | 接收来自肺的含氧血 |
| 左心室 | 主动脉 | 泵血到全身（壁最厚） |
| 右心房 | 上下腔静脉 | 接收来自全身的缺氧血 |
| 右心室 | 肺动脉 | 泵血到肺 |

**重要特征：**
- 左心室壁**最厚**（泵血到全身距离最远）
- 心房与心室之间有**房室瓣**（只朝心室开）
- 心室与动脉之间有**动脉瓣**（只朝动脉开）
- 瓣膜保证血液**单向流动**

### 血液循环

**体循环（大循环）：**
```
左心室 → 主动脉 → 全身毛细血管 → 上下腔静脉 → 右心房
（动脉血）              （物质交换）           （静脉血）
```

**肺循环（小循环）：**
```
右心室 → 肺动脉 → 肺部毛细血管 → 肺静脉 → 左心房
（静脉血）           （气体交换）         （动脉血）
```

### 动脉血与静脉血

| 类型 | 特征 | 颜色 |
|------|------|------|
| 动脉血 | 含O₂丰富 | 鲜红色 |
| 静脉血 | 含O₂少，CO₂多 | 暗红色 |

> 注意：动脉血≠动脉中的血！肺静脉里流的是动脉血，肺动脉里流的是静脉血

### 心率与心输出量

- 心率：每分钟心脏跳动的次数（成人正常60-100次/分）
- 心输出量：每分钟心脏泵出的血量
- 运动员心肌发达→每搏输出量大→安静时心率较低

> **背记要点：**
> - 左心室壁最厚，泵血到全身
> - 体循环：左室出右房回；肺循环：右室出左房回
> - 瓣膜保证血液单向流动（房→室→动脉）
> - 肺动脉流静脉血，肺静脉流动脉血
