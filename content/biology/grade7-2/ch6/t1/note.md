# 流动的组织——血液

## 核心概念

| 成分 | 功能 |
|------|------|
| 血浆 | 运载血细胞，运输营养物质和废物 |
| 红细胞 | 运输氧气（含血红蛋白） |
| 白细胞 | 防御和保护（吞噬病菌） |
| 血小板 | 止血和加速凝血 |

### 血液的组成

血液 = **血浆**（液体部分，约55%）+ **血细胞**（固体部分，约45%）

### 血浆

| 成分 | 含量/说明 |
|------|-----------|
| 水 | 约90% |
| 蛋白质 | 约7% |
| 葡萄糖 | 约0.1% |
| 无机盐 | 约0.9% |
| 废物 | 尿素等代谢废物 |

> 血浆的主要功能：运载血细胞，运输营养和废物

### 三种血细胞的比较

| 特征 | 红细胞 | 白细胞 | 血小板 |
|------|--------|--------|--------|
| 形态 | 双面凹圆饼状 | 比红细胞大，有细胞核 | 最小，不规则，无核 |
| 数量 | 最多（男500万/mm³） | 最少（5000-10000/mm³） | 较多（10-30万/mm³） |
| 有无核 | 成熟红细胞无核 | 有核 | 无核 |
| 功能 | 运输O₂（血红蛋白） | 吞噬病菌，防御保护 | 止血凝血 |

### 血红蛋白

- 红细胞中含有的一种含**铁**的蛋白质
- 特性：O₂浓度高处与O₂**结合**，O₂浓度低处与O₂**分离**
- 颜色：含O₂多→鲜红色（动脉血）；含O₂少→暗红色（静脉血）

### 血常规化验的意义

| 指标异常 | 可能疾病 |
|----------|----------|
| 红细胞/血红蛋白偏低 | 贫血 |
| 白细胞偏高 | 体内有炎症 |
| 血小板偏低 | 凝血功能障碍 |

> **背记要点：**
> - 血液=血浆+血细胞（红、白、血小板）
> - 红细胞最多无核，运O₂；白细胞最大有核，防御；血小板最小无核，止血
> - 血红蛋白含铁，O₂高结合，O₂低分离
