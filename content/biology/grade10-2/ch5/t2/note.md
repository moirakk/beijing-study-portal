# 第2节 染色体变异

## 概念定义

**染色体变异**：染色体结构或数目的改变，通常可在光学显微镜下观察到。

**染色体组**：细胞中的一组非同源染色体，在形态和功能上各不相同，携带控制生物生长发育的全套遗传信息。**二倍体/多倍体**：由受精卵发育、体细胞含两个/三个及以上染色体组的个体。**单倍体**：体细胞中含有本物种**配子染色体数目**的个体（由配子直接发育而来）。

## 知识梳理

| 类型 | 内容 |
| --- | --- |
| 结构变异 | 缺失（猫叫综合征）、重复（果蝇棒眼）、倒位、易位 |
| 数目变异（个别） | 增加或减少个别染色体，如 21 三体综合征（多 1 条 21 号） |
| 数目变异（成倍） | 以染色体组为单位成倍增减，如三倍体无子西瓜、四倍体草莓 |

| 育种应用 | 原理与方法 |
| --- | --- |
| 多倍体育种 | 秋水仙素处理萌发的种子或幼苗，**抑制纺锤体形成**使染色体加倍；茎秆粗壮、营养物质含量高 |
| 单倍体育种 | 花药离体培养获得单倍体，再秋水仙素加倍；**明显缩短育种年限**，后代均纯合 |

## 典型例题

**例 1**：三倍体无子西瓜的培育流程及无子原因？

**解**：秋水仙素处理二倍体（2n）幼苗得四倍体（4n）；四倍体（母本）× 二倍体（父本）得三倍体（3n）种子；三倍体植株减数分裂时**联会紊乱**，不能形成正常配子，故无子。该变异属于**可遗传变异**（染色体数目变异），只是不能通过有性生殖传递。

**例 2**：由基因型 $AaBb$（两对同源染色体）植株进行单倍体育种，获得的稳定遗传植株有哪些基因型？

**解**：花药离体培养得单倍体（$AB$、$Ab$、$aB$、$ab$ 四种），秋水仙素加倍后得 $AABB$、$AAbb$、$aaBB$、$aabb$ 四种**纯合**植株，比例约 $1:1:1:1$。

## 易错点

- 单倍体不一定含一个染色体组：四倍体的配子发育成的单倍体含 **2 个**染色体组。
- 含奇数染色体组或由配子发育而来才判定单倍体：**由配子发育**是判断单倍体的唯一标准。
- 易位（非同源染色体间）≠互换（同源染色体非姐妹单体间，属基因重组）。
- 秋水仙素作用于**分裂前期**，抑制纺锤体形成，不是抑制着丝粒分裂。

## 背记要点

1. 结构变异四类：缺失、重复、倒位、易位。
2. 染色体组：一组非同源染色体，形态功能各不相同。
3. 单倍体育种：花药离体培养＋秋水仙素加倍，缩短育种年限。
4. 多倍体特点：茎秆粗壮、叶果种子大、营养物质多。
5. 高考视角：变异类型判断（图像题）与育种流程设计是大题常考点。
