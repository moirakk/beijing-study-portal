# 第2节 基因表达与性状的关系

## 概念定义

**基因表达**：基因通过转录和翻译产生蛋白质（或产生 RNA）的过程。基因控制性状的两种途径：①通过控制**酶的合成**控制代谢过程，间接控制性状；②通过控制**蛋白质的结构**直接控制性状。

**表观遗传**：生物体基因的碱基序列保持不变，但基因表达和表型发生**可遗传变化**的现象，常见机制有 DNA 甲基化、组蛋白修饰等。

## 知识梳理

| 途径 | 实例 |
| --- | --- |
| 控制酶合成→控制代谢（间接） | 白化病（缺酪氨酸酶）、豌豆圆粒/皱粒（淀粉分支酶基因） |
| 控制蛋白质结构（直接） | 镰状细胞贫血（血红蛋白异常）、囊性纤维化 |
| 表观遗传 | 柳穿鱼花形态变化、小鼠 Avy 基因（毛色）、同卵双胞胎差异 |

基因与性状**不是简单的一一对应**：一个基因可影响多个性状；一个性状可受多个基因控制；性状还受**环境**影响。表型＝基因型＋环境共同作用的结果。

## 典型例题

**例 1**：白化病与镰状细胞贫血分别体现基因控制性状的哪条途径？

**解**：白化病因酪氨酸酶基因异常，不能合成酪氨酸酶，黑色素合成受阻——基因通过**控制酶的合成控制代谢**，间接控制性状；镰状细胞贫血因血红蛋白基因碱基替换使谷氨酸变为缬氨酸——基因通过**控制蛋白质结构直接**控制性状。

**例 2**：同卵双胞胎基因型相同，为何性状仍有差异？

**解**：①环境因素影响表型（表型＝基因型＋环境）；②表观遗传：DNA 甲基化等修饰使基因表达情况不同，碱基序列未变而表型改变，且部分修饰可遗传。

## 易错点

- 表观遗传中**碱基序列不变**，改变的是基因的表达水平，这与基因突变有本质区别。
- DNA 甲基化通常**抑制**基因的转录（表达），并非改变基因本身。
- 基因型相同表型不一定相同（环境、表观遗传）；表型相同基因型也不一定相同（如 $DD$ 与 $Dd$）。
- "一因多效、多因一效"说明基因与性状并非一一对应。

## 背记要点

1. 两条途径：控酶→控代谢（间接）；控蛋白质结构（直接）。
2. 经典实例：白化病、豌豆粒形（间接）；镰状细胞贫血（直接）。
3. 表观遗传三要素：碱基序列不变、表达和表型改变、可遗传。
4. 表型是基因型与环境共同作用的结果。
5. 高考视角：表观遗传为新教材新增热点，常结合甲基化情境命题。
