# 第4节 协同进化与生物多样性的形成

## 概念定义

**协同进化**：不同物种之间、生物与无机环境之间在相互影响中不断进化和发展的现象。实例：兰花与传粉蛾（长花距与长口器）、猎豹与羚羊（捕食与反捕食）、好氧生物随大气氧含量升高而出现。

**生物多样性**：包括**遗传（基因）多样性、物种多样性、生态系统多样性**三个层次，是协同进化的结果。

## 知识梳理

| 层次 | 含义 |
| --- | --- |
| 遗传多样性 | 种内基因和基因型的多样（基因库丰富） |
| 物种多样性 | 生物圈内物种的丰富程度 |
| 生态系统多样性 | 生态系统类型（森林、湿地、海洋等）的多样 |

| 进化历程关键事件 | 意义 |
| --- | --- |
| 最早的生物：厌氧原核生物 | 原始海洋中出现 |
| 光合生物（蓝细菌）出现 | 释放 O₂，改变大气成分，为好氧生物创造条件 |
| 真核生物出现 | 有性生殖出现，进化速度加快（变异更丰富） |
| 寒武纪大爆发 | 多细胞动物大量出现 |
| 登陆（植物先、动物后） | 陆地生态系统形成 |

**现代生物进化理论核心**：适应是自然选择的结果；种群是进化的基本单位；突变和基因重组提供原材料，自然选择定向改变基因频率；隔离导致物种形成；协同进化形成多样性。

## 典型例题

**例 1**：捕食者的存在对被捕食者种群是否只有害处？

**解**：不是。捕食者往往捕食**个体数量多、老弱病残**的个体，客观上促进被捕食者种群的发展；捕食者的存在还避免单一物种独占资源，**有利于增加物种多样性**（收割理论）。这体现了物种间的协同进化。

**例 2**：地球早期无氧环境到有氧环境的转变如何体现生物与环境的协同进化？

**解**：蓝细菌等光合生物出现后释放 O₂，逐渐改变了原始大气成分（**生物改变环境**）；大气含氧量升高又为好氧生物的出现和进化创造了条件（**环境选择生物**），二者相互影响、共同演变，属于生物与无机环境之间的协同进化。

## 易错点

- 协同进化发生在**不同物种之间**及**生物与无机环境之间**；同种个体间的竞争不属于协同进化。
- 生物多样性三层次是**基因、物种、生态系统**，不要写成"数量多样性"。
- 有性生殖的出现（真核生物之后）使基因重组成为可能，**加快**了进化速度。
- 生物多样性是**协同进化的结果**，其根本原因是 DNA（基因）的多样性。

## 背记要点

1. 协同进化两类对象：物种之间；生物与无机环境之间。
2. 生物多样性三层次：遗传、物种、生态系统。
3. 进化大事记：厌氧原核→光合放氧→真核→有性生殖→寒武纪大爆发→登陆。
4. 现代生物进化理论：种群单位、突变重组供材料、选择定向、隔离成种、协同进化成多样。
5. 高考视角：协同进化实例判断与进化理论综合表述是常考简答内容。
