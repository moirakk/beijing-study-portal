# 第1节 生物有共同祖先的证据

## 概念定义

**共同由来学说**：达尔文进化论的组成部分之一，认为地球上所有的生物都是由**共同祖先**（原始的共同起源）逐渐进化而来。另一部分是**自然选择学说**，揭示了进化的机制。

**化石**：经过自然作用保存在地层中的古代生物的遗体、遗物或生活痕迹，是研究进化**最直接、最重要**的证据。

## 知识梳理

| 证据类型 | 内容与结论 |
| --- | --- |
| 化石证据 | 越古老地层中化石生物越简单低等，越晚近地层越复杂高等；证明由简单到复杂、由水生到陆生、由低等到高等的进化顺序 |
| 比较解剖学 | 人的上肢、鲸的鳍、蝙蝠的翼为**同源器官**（结构相似、功能不同），提示共同祖先 |
| 胚胎学 | 人和鱼的胚胎早期都有鳃裂和尾，发育反映演化的痕迹 |
| 细胞和分子水平 | 细胞结构基本一致；共用一套遗传密码；细胞色素 c 等蛋白质序列差异与亲缘关系远近一致 |

## 典型例题

**例 1**：为什么说化石是研究生物进化最直接的证据？

**解**：化石直接保存了古代生物的形态结构信息，且可依据地层的先后顺序确定生物出现的**时间顺序**，直观展示不同地质年代生物类型的更替，故是最直接、最重要的证据；其他证据（解剖学、胚胎学、分子生物学）属间接支持。

**例 2**：比较不同生物细胞色素 c 的氨基酸序列差异，能得出什么结论？

**解**：与人差异越小的生物（如黑猩猩）亲缘关系越近，差异越大（如酵母菌）亲缘关系越远。不同生物拥有同源蛋白且差异呈梯度分布，支持**生物有共同祖先**，且分子差异程度可反映进化上分离时间的长短。

## 易错点

- 化石证据反映的顺序是**简单→复杂、水生→陆生、低等→高等**，不能颠倒。
- 同源器官强调**起源相同、结构相似、功能可不同**；功能相同不代表同源。
- "共同由来"与"自然选择"是达尔文学说的两大学说，不可混为一谈。
- 现存高等生物与低等生物是共同祖先分支进化的结果，**并非**低等生物"变成"了高等生物后消失。

## 背记要点

1. 达尔文进化论两大学说：共同由来学说＋自然选择学说。
2. 化石是最直接证据；地层越老，化石生物越简单低等。
3. 间接证据：比较解剖学（同源器官）、胚胎学、细胞与分子水平。
4. 遗传密码通用性是所有生物共祖的重要分子证据。
5. 高考视角：证据类型与结论的对应关系常以信息题形式考查。
