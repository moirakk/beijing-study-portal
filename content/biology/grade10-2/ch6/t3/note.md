# 第3节 种群基因组成的变化与物种的形成

## 概念定义

**种群**：生活在一定区域的同种生物**全部个体**的集合，是生物进化的基本单位。**基因库**：一个种群中全部个体所含有的全部基因。**基因频率**：某基因占其全部等位基因数的比值。

**物种**：能够在自然状态下相互交配并产生**可育后代**的一群生物。**隔离**：不同种群间的个体在自然条件下基因不能自由交流的现象，包括**地理隔离**与**生殖隔离**；生殖隔离的形成是物种形成的标志。**进化的实质：种群基因频率的改变。**

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 进化基本单位 | 种群（不是个体） |
| 原材料 | 突变（基因突变、染色体变异）和基因重组 |
| 进化方向 | 由自然选择决定（定向改变基因频率） |
| 物种形成三环节 | 突变和基因重组（原材料）、自然选择（定向）、隔离（必要条件） |
| 常见模式 | 地理隔离→基因频率各自改变→差异加大→生殖隔离（新物种） |

**基因频率计算**：设 $A$ 频率为 $p$、$a$ 频率为 $q$（$p+q=1$）。遗传平衡（哈迪—温伯格）时基因型频率：$AA=p^2$、$Aa=2pq$、$aa=q^2$。由基因型频率求基因频率：$p=AA\%+\dfrac{1}{2}Aa\%$。

## 典型例题

**例 1**：某种群中 $AA$ 占 $30\%$、$Aa$ 占 $60\%$、$aa$ 占 $10\%$，求 $A$、$a$ 的基因频率。

**解**：$A=30\%+\dfrac{1}{2}\times60\%=60\%$；$a=10\%+\dfrac{1}{2}\times60\%=40\%$（验证 $p+q=1$）。

**例 2**：某遗传平衡群体中隐性患者（$aa$）占 $\dfrac{1}{10000}$，求携带者频率。

**解**：$q^2=\dfrac{1}{10000} \Rightarrow q=\dfrac{1}{100}$，$p=\dfrac{99}{100}$。携带者 $Aa=2pq=2\times\dfrac{99}{100}\times\dfrac{1}{100}\approx\dfrac{198}{10000}\approx2\%$。

## 易错点

- 进化的实质是**基因频率改变**；基因频率改变≠形成新物种（须生殖隔离）。
- 物种形成**不一定**经过地理隔离（如多倍体形成可直接产生生殖隔离），但**必须**有生殖隔离。
- 骡子不可育，说明马和驴存在生殖隔离，是两个物种。
- 自然选择直接作用的是**表型**（个体），间接导致基因频率改变。

## 背记要点

1. 种群是进化的基本单位；基因库、基因频率是核心概念。
2. 进化实质：种群基因频率的定向改变（自然选择决定方向）。
3. 物种形成三环节：变异原材料、自然选择、隔离（生殖隔离为标志）。
4. 计算：$p=AA\%+\dfrac{1}{2}Aa\%$；平衡群体 $p^2+2pq+q^2=1$。
5. 高考视角：基因频率计算与"进化≠物种形成"辨析是高频考点。
