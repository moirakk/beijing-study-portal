# 第3节 DNA的复制

## 概念定义

**DNA 复制**：以亲代 DNA 的两条链分别为模板合成子代 DNA 的过程，发生在有丝分裂和减数分裂前的间期（真核）或拟核 DNA 分裂前（原核）。

**半保留复制**：子代 DNA 分子中，一条链来自亲代（母链），另一条链是新合成的（子链）。由梅塞尔森和斯塔尔用 $^{15}\text{N}$ 标记＋密度梯度离心实验证明。

## 知识梳理

| 要素 | 内容 |
| --- | --- |
| 模板 | 亲代 DNA 的**两条链** |
| 原料 | 4 种游离的脱氧核苷酸 |
| 能量 | ATP |
| 酶 | 解旋酶（断开氢键）、DNA 聚合酶（连接脱氧核苷酸） |
| 原则 | 碱基互补配对（A—T、G—C） |
| 特点 | 边解旋边复制、半保留复制 |
| 意义 | 将遗传信息从亲代传给子代，保持遗传信息的连续性 |

**复制计算**（复制 $n$ 次）：DNA 总数 $2^n$；含母链的 DNA 恒为 $2$ 个；某碱基消耗量 = 原有数 $\times(2^n-1)$；第 $n$ 次单独消耗 = 原有数 $\times 2^{n-1}$。

## 典型例题

**例 1**：一个含 $^{15}\text{N}$ 的 DNA 在 $^{14}\text{N}$ 培养液中复制 3 次，含 $^{15}\text{N}$ 的 DNA 占多少？

**解**：共产生 $2^3=8$ 个 DNA。两条母链分别位于 2 个 DNA 中，故含 $^{15}\text{N}$ 的 DNA 为 2 个，占 $\dfrac{2}{8}=\dfrac{1}{4}$；含 $^{14}\text{N}$ 的 DNA 占 $\dfrac{8}{8}=100\%$。

**例 2**：某 DNA 含腺嘌呤 300 个，复制 2 次共需游离的腺嘌呤脱氧核苷酸多少个？

**解**：消耗量 $=300\times(2^2-1)=900$ 个；其中第二次复制单独消耗 $300\times2^{2-1}=600$ 个。

## 易错点

- 复制发生在**间期**（分裂前），不是分裂期。
- "含母链的 DNA"恒为 2 个，"母链"恒为 2 条，注意区分"DNA 个数"与"链数"。
- 复制以**两条链**为模板；转录只以一条链（模板链）为模板。
- 边解旋边复制：解旋与合成同时进行，并非全部解旋后再复制。

## 背记要点

1. 半保留复制：子代 DNA＝一条母链＋一条子链。
2. 条件四要素：模板、原料（脱氧核苷酸）、能量（ATP）、酶（解旋酶＋DNA 聚合酶）。
3. 准确复制的原因：规则双螺旋提供模板，碱基互补配对保证准确。
4. 复制 $n$ 次：总数 $2^n$，含母链 DNA 占 $\dfrac{2}{2^n}$，碱基消耗 $(2^n-1)$ 倍。
5. 高考视角：同位素标记结合分裂过程（染色体上标记分布）的综合计算是难点热点。
