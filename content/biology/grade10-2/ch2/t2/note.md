# 第2节 基因在染色体上

## 概念定义

**萨顿假说**：基因和染色体行为存在明显的平行关系，由此**类比推理**得出"基因在染色体上"的假说。

**摩尔根果蝇杂交实验**：运用假说—演绎法，通过白眼果蝇的杂交实验证明**基因位于染色体上**（控制白眼的基因位于 X 染色体上），使孟德尔遗传定律获得细胞学解释。

## 知识梳理

| 平行关系 | 基因 | 染色体 |
| --- | --- | --- |
| 传递中保持完整性和独立性 | 是 | 是 |
| 体细胞中成对存在 | 成对 | 成对（同源） |
| 配子中成单存在 | 单个 | 单条 |
| 来源 | 一个来自父方、一个来自母方 | 同左 |
| 形成配子时 | 非等位基因自由组合 | 非同源染色体自由组合 |

摩尔根实验：红眼雌 × 白眼雄 → F₁ 全红眼 → F₁ 互交 → F₂ 红∶白 $=3:1$，但**白眼全为雄性**。假说：控制眼色的基因只位于 X 染色体上（W 显性红眼、w 隐性白眼）。测交等实验验证假说成立。

## 典型例题

**例 1**：白眼雌果蝇（$X^wX^w$）与红眼雄果蝇（$X^WY$）杂交，后代表现型如何？

**解**：雌配子均为 $X^w$，雄配子为 $X^W$ 或 $Y$。后代雌性均为 $X^WX^w$（红眼），雄性均为 $X^wY$（白眼），即"母传子、父传女"的交叉遗传特点。

**例 2**：萨顿与摩尔根的研究方法有何不同？

**解**：萨顿运用**类比推理法**，由基因与染色体行为的平行关系提出假说，结论不一定正确，需实验验证；摩尔根运用**假说—演绎法**，通过果蝇杂交实验和测交验证，最终**证明**基因在染色体上。

## 易错点

- 类比推理得出的结论**不具备逻辑必然性**，萨顿假说需摩尔根实验证明。
- 基因在染色体上呈**线性排列**，一条染色体上有许多个基因。
- 并非所有基因都在染色体上：线粒体、叶绿体中也有 DNA 和基因（细胞质遗传）。
- 书写伴性遗传基因型时必须带上 X、Y，如 $X^WX^w$，不能写成 $Ww$。

## 背记要点

1. 萨顿假说：类比推理；摩尔根实验：假说—演绎，证明基因在染色体上。
2. 基因与染色体的平行关系：完整性、成对性、来源、组合方式。
3. 分离定律实质：等位基因随同源染色体分开而分离；自由组合定律实质：非同源染色体上非等位基因自由组合。
4. 一条染色体上多个基因，呈线性排列。
5. 高考视角：科学方法（类比推理与假说—演绎）辨析是教材原文类考点。
