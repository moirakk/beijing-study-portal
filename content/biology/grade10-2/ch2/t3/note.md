# 第3节 伴性遗传

## 概念定义

**伴性遗传**：位于性染色体上的基因控制的性状，在遗传上总是和性别相关联的现象。

人类红绿色盲、血友病为**伴 X 隐性遗传**；抗维生素 D 佝偻病为**伴 X 显性遗传**；外耳道多毛症为**伴 Y 遗传**（限雄传递）。

## 知识梳理

| 遗传方式 | 特点 |
| --- | --- |
| 伴 X 隐性（色盲 b） | 患者男多于女；**交叉遗传**（外公→母亲→外孙）；女患者的父亲和儿子必患病 |
| 伴 X 显性（佝偻病 D） | 患者女多于男；男患者的母亲和女儿必患病；世代连续 |
| 伴 Y 遗传 | 患者全为男性，父传子、子传孙 |

女性色盲相关基因型：$X^BX^B$（正常）、$X^BX^b$（携带者）、$X^bX^b$（患者）；男性：$X^BY$（正常）、$X^bY$（患者）。

## 典型例题

**例 1**：色盲女性与正常男性婚配，后代表现型如何？

**解**：亲本为 $X^bX^b \times X^BY$。女儿均为 $X^BX^b$（携带者，不患病）；儿子均为 $X^bY$（**全部色盲**）。体现"母病子必病、女病父必病"的伴 X 隐性特点。

**例 2**：一对表现正常的夫妇生了一个色盲儿子，再生一个孩子患色盲的概率是多少？

**解**：儿子 $X^bY$ 的 $X^b$ 来自母亲，故母亲为 $X^BX^b$，父亲 $X^BY$。后代：$\dfrac{1}{4}X^BX^B$、$\dfrac{1}{4}X^BX^b$、$\dfrac{1}{4}X^BY$、$\dfrac{1}{4}X^bY$，患病概率为 $\dfrac{1}{4}$（若问"儿子中患病"则为 $\dfrac{1}{2}$）。

## 易错点

- "后代患病概率"与"后代男孩中患病概率"不同，审题要区分是否已限定性别。
- 伴 X 隐性：女性患者的**父亲和儿子一定患病**；伴 X 显性：男性患者的**母亲和女儿一定患病**。
- X、Y 染色体存在同源区段与非同源区段，同源区段上的基因遗传仍与性别有关。
- 判断显隐与位置：无中生有为隐性；隐性遗传中"女病父正"可排除伴 X。

## 背记要点

1. 伴 X 隐性：男多于女、交叉遗传、隔代遗传。
2. 伴 X 显性：女多于男、连续遗传。
3. 伴 Y：限雄遗传，父传子。
4. 应用：根据 ZW/XY 型性别决定，可利用伴性性状（如芦花鸡羽色）在早期区分雌雄。
5. 高考视角：系谱图判断遗传方式＋概率计算是遗传大题必考模块。
