# 第3节 发酵工程及其应用

## 概念定义

**发酵工程**：利用微生物的特定功能，通过现代工程技术手段规模化生产人类所需产品的技术，又称**微生物工程**。

**发酵工程的基本环节**：选育菌种 → 扩大培养 → 配制培养基和灭菌 → 接种 → 发酵罐内发酵 → 分离、提纯产物。

**发酵罐**：用于大规模发酵的核心设备，可控制温度、pH、溶氧、搅拌等条件。

## 知识梳理

| 环节 | 关键操作 | 目的 |
| --- | --- | --- |
| 选育菌种 | 诱变育种、基因工程 | 获得高产、抗逆菌种 |
| 扩大培养 | 液体培养基增殖 | 获得足够数量的菌种 |
| 配制培养基 | 灭菌 | 防止杂菌污染 |
| 发酵 | 控制温度、pH、溶氧 | 保证微生物正常代谢 |
| 分离提纯 | 过滤、离心、蒸馏 | 获得纯净产品 |

## 典型例题

**例 1**：发酵工程中，为什么发酵罐要通入无菌空气并搅拌？

**解**：通入无菌空气为**好氧微生物**提供氧气，搅拌使氧气和营养物质分布均匀，利于微生物与底物充分接触。

**例 2**：青霉素生产中，发酵后期要控制 pH 和温度，其意义是什么？

**解**：青霉素是次级代谢产物，其合成受环境条件影响，控制条件可提高产量并防止产物被分解。

## 易错点

- 发酵工程的核心是**发酵罐内发酵**，不是选育菌种。
- 好氧发酵需**通气**，厌氧发酵需**密封**，不能一概而论。
- 发酵产物分**初级代谢产物**（生长必需，如氨基酸）和**次级代谢产物**（非必需，如抗生素）。
- 分离提纯方法因产物而异：菌体用过滤/离心，代谢产物用蒸馏/萃取。

## 背记要点

1. 发酵工程五环节：选育菌种→扩大培养→配制培养基→发酵→分离提纯。
2. 发酵罐控制：温度、pH、溶氧、搅拌。
3. 应用领域：食品（味精、酱油）、医药（抗生素、胰岛素）、化工、环保。
