# 植物的生殖

植物通过生殖产生后代，使物种得以延续。
本节重点区分有性生殖与无性生殖，并理解营养繁殖在生产中的应用。
[[昆虫的生殖和发育]]与本节都体现了生物延续后代的共同规律。

## 概念表

| 概念 | 含义 | 关键词 |
| --- | --- | --- |
| 有性生殖 | 经过两性生殖细胞结合形成受精卵，再发育成新个体 | 受精卵、双亲优良性状重组 |
| 无性生殖 | 不经过两性生殖细胞结合，由母体直接产生新个体 | 速度快、保持母体性状 |
| 营养繁殖 | 利用根、茎、叶等营养器官繁殖后代 | 扦插、嫁接、压条 |
| 组织培养 | 在无菌条件下培养植物组织形成新植株 | 快速繁殖、脱毒 |

## 知识梳理

植物的有性生殖通常依赖花、果实和种子。
花粉落到柱头后萌发形成花粉管，精子进入胚珠，与卵细胞结合形成受精卵。
受精卵发育成胚，胚珠发育成种子，子房发育成果实。
有性生殖的后代具有双亲遗传特性，适应环境变化的能力较强。

无性生殖不需要受精过程。
常见方式有扦插、嫁接、压条和组织培养。
甘薯可用块根繁殖，月季常用扦插，苹果和桃树常用嫁接。
无性生殖能较稳定地保持优良品种的性状，适合农业生产。

嫁接时，接穗和砧木的形成层要紧密结合。
形成层细胞分裂旺盛，结合后有利于伤口愈合并长成一体。
若形成层没有对准，嫁接往往失败。

## 实验要点

### 观察花的结构

1. 选取完整花朵，辨认花柄、花托、萼片、花瓣、雄蕊和雌蕊。
2. 用镊子轻轻分离各部分，避免损伤子房和胚珠。
3. 重点观察雄蕊花药中的花粉和雌蕊子房中的胚珠。
4. 记录各结构与生殖功能的对应关系。

### 扦插实践

1. 选择健壮枝条，剪成带芽的插条。
2. 下端斜剪，增大吸水面积。
3. 插入湿润疏松土壤，保持适宜温度和湿度。
4. 观察是否生根发芽，分析成活条件。

## 对比表格

| 项目 | 有性生殖 | 无性生殖 |
| --- | --- | --- |
| 是否经过受精 | 是 | 否 |
| 遗传特点 | 后代差异较大 | 后代与母体相似 |
| 适应能力 | 较强 | 相对较弱 |
| 繁殖速度 | 一般 | 较快 |
| 生产应用 | 杂交育种 | 保持优良性状 |

## 易错辨析

| 说法 | 判断 | 纠正 |
| --- | --- | --- |
| 所有植物都靠种子繁殖 | 错 | 许多植物还能进行无性生殖 |
| 嫁接成功关键是形成层对齐 | 对 | 形成层结合决定成活 |
| 组织培养属于有性生殖 | 错 | 组织培养属于无性生殖 |

## 背记要点

- 有性生殖的核心是形成受精卵。
- 无性生殖不经过两性生殖细胞结合。
- 营养繁殖常见方式有扦插、嫁接、压条。
- 嫁接成功的关键是接穗与砧木形成层紧密结合。
- 组织培养具有繁殖快、保持优良性状、可脱毒等优点。
