# 单元综合复习

单元综合复习要把零散知识转化为系统网络。
本篇适合考前回顾高频概念、实验题和综合比较题。
建议结合[[综合实践：生命延续与进化专题梳理]]进行最后整合。

## 概念表

| 板块 | 核心词 | 常见考法 |
| --- | --- | --- |
| 生殖与发育 | 受精、变态发育、卵结构 | 比较题、填空题 |
| 遗传 | 基因、染色体、显隐性 | 遗传图解题 |
| 变异与进化 | 可遗传变异、化石、自然选择 | 材料分析题 |

## 知识梳理

复习第一章时，要抓住不同类群生殖发育方式的比较。
植物既有有性生殖也有无性生殖；昆虫有完全变态和不完全变态；两栖动物多体外受精并变态发育；鸟类体内受精且卵结构适于陆生发育。

复习第二章时，要建立“细胞核—染色体—DNA—基因—性状”的链条。
理解基因通过生殖细胞传递，掌握显性和隐性的判断方法，以及人的性别由性染色体决定。
同时要会区分可遗传变异和不可遗传变异。

复习第三章时，要区分三个问题。
生命起源回答“生命从哪里来”；进化历程回答“生命怎样变化”；进化原因回答“为什么会变化”。
化石是研究进化历程的重要证据，自然选择学说解释进化原因。

复习第四章时，要明确生物多样性的三个层次和保护措施。
答题时常要求写出根本措施和最有效措施，不能混淆。

## 实验要点

### 高频实验与观察

1. 花和鸡卵结构观察：明确各结构功能。
2. 家蚕或蝗虫发育观察：判断发育类型。
3. 遗传图解训练：分析基因组合与表现型。
4. 米勒实验和化石资料分析：区分证据类型。

### 答题策略

1. 先审题判断属于生殖、遗传还是进化模块。
2. 比较题优先列表找异同。
3. 实验题注意变量、现象、结论三要素。
4. 观点题要联系教材术语作答。

## 对比表格

| 易混点 | 正确认识 | 常见误区 |
| --- | --- | --- |
| 根本措施与最有效措施 | 根本是保护栖息环境，最有效之一是建保护区 | 两者混为一谈 |
| 可遗传与不可遗传变异 | 看遗传物质是否改变 | 只看现象大小 |
| 显性与隐性 | 看杂合时表现 | 误以为显性更常见 |
| 起源与进化 | 起源是出现，进化是变化 | 概念不分 |

## 背记要点

- 生殖、遗传、变异、进化、多样性保护构成全册主线。
- 比较不同生物类群的受精方式和发育方式是高频考点。
- 基因位于染色体上，通过生殖细胞传递。
- 化石是研究进化的重要证据，自然选择解释进化原因。
- 保护生物多样性的根本措施是保护栖息环境。
- [[植物的生殖]]和[[人的性别遗传]]常分别作为基础题与综合题切入口。
