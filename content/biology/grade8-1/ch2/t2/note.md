# 鸟

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 恒温动物 | 体温不随环境温度变化而改变的动物 | 鸟类、哺乳动物 |
| 气囊 | 鸟类特有的辅助呼吸器官，与肺相连 | 鸽子的气囊 |
| 双重呼吸 | 鸟类吸气和呼气时肺内都有气体流过，进行两次气体交换 | 鸟类飞行时的呼吸 |
| 龙骨突 | 鸟类胸骨上的突起，供飞行肌肉附着 | 家鸽的龙骨突 |
| 流线型 | 鸟类身体形态，减少飞行阻力 | 鸟的纺锤形体型 |

## 知识梳理

鸟类是脊椎动物中适应飞行生活最成功的类群。鸟类的体型呈流线型，体表覆盖羽毛，前肢变为翼，骨骼轻薄（多为中空骨），胸肌发达，这些都是适应飞行的特征。

鸟类是恒温动物，体温高而稳定（约40℃），有利于维持旺盛的新陈代谢。鸟类用肺呼吸，气囊辅助呼吸，实现双重呼吸，为飞行提供充足氧气。鸟类心脏四腔（两心房两心室），血液循环效率高。

鸟类在陆地产卵，卵有坚硬外壳，卵内有卵黄（营养物质）和卵白（保护和营养），受精卵在体外孵化。

## 实验要点

"观察鸟卵的结构"实验：取鸡蛋，观察卵壳（保护）、卵壳膜（保护）、气室（储存空气）、卵白（保护和营养）、卵黄（营养）、胚盘（受精卵的胚胎）等结构，理解鸟卵适应陆地发育的特点。

"观察鸟的骨骼"实验：观察鸟的骨骼标本，注意骨骼轻薄、中空（充气）的特点，以及龙骨突的位置和大小，理解骨骼结构与飞行的关系。

## 对比表格

| 比较项 | 鸟类 | 爬行动物 |
|---|---|---|
| 体表 | 羽毛 | 鳞片或甲 |
| 体温 | 恒温 | 变温 |
| 心脏 | 四腔（两心房两心室） | 三腔（两心房一心室，不完全） |
| 呼吸 | 肺+气囊（双重呼吸） | 肺 |
| 前肢 | 变为翼 | 四肢（蛇退化） |
| 生殖 | 卵生，有孵化行为 | 卵生，多不孵化 |

## 背记要点

- 鸟类主要特征：体表覆羽，前肢变翼，用肺呼吸（气囊辅助），恒温，卵生。
- 气囊不是呼吸器官，只是辅助呼吸（储存气体），气体交换在肺中进行。
- 双重呼吸：吸气时，气体进入气囊；呼气时，气囊中气体进入肺，两次经过肺进行气体交换。
- 鸟类骨骼轻薄中空，无牙齿，直肠短（粪便及时排出），都是减轻体重适应飞行的特征。
- 鸟类是由古代爬行动物进化而来的。
