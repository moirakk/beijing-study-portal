# 免疫与免疫规划

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 免疫 | 人体识别“自己”和“非己”成分，排除异物、维护健康的生理功能 | 抵抗病原体入侵 |
| 非特异性免疫 | 生来就有，对多种病原体起作用 | 皮肤、黏膜、吞噬细胞 |
| 特异性免疫 | 后天形成，只针对某一特定病原体 | 淋巴细胞产生抗体 |
| 抗体 | 病原体刺激淋巴细胞产生的特殊蛋白质 | 抗流感病毒抗体 |
| 抗原 | 引起人体产生抗体的物质 | 病原体、疫苗 |
| 疫苗 | 用灭活或减毒的病原体制成的生物制品 | 卡介苗、麻疹疫苗 |

## 知识梳理

人体免疫分为非特异性免疫和特异性免疫。非特异性免疫是人人生来就有的第一道、第二道防线：皮肤和黏膜属于第一道防线，能阻挡、清扫病原体；体液中的杀菌物质和吞噬细胞属于第二道防线，能溶解、吞噬病原体。

特异性免疫是第三道防线，由免疫器官（胸腺、淋巴结、脾脏等）和免疫细胞（淋巴细胞）组成。当病原体侵入人体后，刺激淋巴细胞产生抗体，抗体与抗原结合，促进吞噬细胞吞噬病原体或使病原体失去致病性。

免疫规划（计划免疫）是根据国家免疫程序，有计划地对儿童进行预防接种，以达到预防、控制和消灭相应传染病的目的。接种疫苗后，人体产生相应抗体和记忆细胞，从而获得特异性免疫。

## 实验要点

“模拟特异性免疫”活动：用不同形状的纸片代表不同抗原，用对应形状的“抗体”与之配对，理解抗体与抗原结合的特异性。

“调查家庭或学校预防接种情况”实践：收集预防接种证信息，了解我国儿童免疫规划疫苗种类和接种时间，认识计划免疫的意义。

## 对比表格

| 比较项 | 非特异性免疫 | 特异性免疫 |
|---|---|---|
| 形成时间 | 生来就有 | 后天形成 |
| 针对对象 | 多种病原体 | 特定病原体 |
| 防线层次 | 第一、二道防线 | 第三道防线 |
| 物质基础 | 皮肤、黏膜、吞噬细胞、溶菌酶 | 免疫器官、免疫细胞、抗体 |
| 记忆性 | 无 | 有 |

## 背记要点

- 抗体具有专一性，一种抗体只针对某一特定抗原起作用。
- 患过某种传染病或接种过相应疫苗后，体内可能保留记忆细胞，再次遇到相同病原体时能快速产生免疫反应。
- 免疫功能异常可能引发过敏反应、自身免疫病或免疫缺陷病。
- 艾滋病攻击人体免疫系统中的T淋巴细胞，使患者丧失免疫功能。
