# 生态系统的结构和功能

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 生态系统 | 在一定空间范围内，生物与环境所形成的统一整体 | 一片森林、一个池塘 |
| 生产者 | 能通过光合作用制造有机物的绿色植物 | 草、树、藻类 |
| 消费者 | 直接或间接以植物为食的动物 | 兔、狐、鹰 |
| 分解者 | 将有机物分解为无机物的细菌和真菌 | 腐生细菌、蘑菇 |
| 食物链 | 不同生物之间由于吃与被吃的关系而形成的链状结构 | 草→兔→狐 |
| 食物网 | 多条食物链彼此交错连接形成的复杂网络 | 草原食物网 |

## 知识梳理

生态系统由生物部分和非生物部分组成。非生物部分包括阳光、空气、水、土壤、温度等；生物部分包括生产者、消费者和分解者。生产者、消费者和分解者之间相互依存、相互制约，缺一不可。

食物链反映生产者与消费者之间的吃与被吃关系，书写时从生产者开始，箭头指向捕食者。食物网中各食物链相互关联，一种生物数量的变化会影响其他生物数量。生态系统中的物质和能量就是沿着食物链和食物网流动的。

能量在流动过程中逐级递减，一般只有10%～20%的能量能够流入下一个营养级。有毒物质沿食物链不断积累，营养级越高，体内有毒物质含量越多，称为生物富集。

## 实验要点

“调查一个生态系统”综合实践：选择校园、公园或农田生态系统，记录其中的生物种类和非生物因素，绘制食物链或食物网，分析生产者、消费者和分解者的作用。

“分析生态系统中的物质循环”活动：以碳循环为例，说明生产者通过光合作用固定二氧化碳，消费者和分解者通过呼吸作用释放二氧化碳，物质在生物与环境之间循环。

## 对比表格

| 成分 | 组成 | 作用 | 是否必需 |
|---|---|---|---|
| 生产者 | 绿色植物 | 制造有机物，提供物质和能量 | 是 |
| 消费者 | 动物 | 促进物质循环，帮助植物传粉、传播种子 | 否 |
| 分解者 | 细菌、真菌 | 将有机物分解为无机物，归还环境 | 是 |

## 背记要点

- 食物链起点是生产者，终点是最高级消费者，不包括分解者和非生物部分。
- 能量流动的特点是单向流动、逐级递减。
- 生态系统中数量最多的是生产者，有毒物质积累最多的是最高级消费者。
- 生态平衡是一种动态平衡，具有自动调节能力，但这种能力有一定限度。
