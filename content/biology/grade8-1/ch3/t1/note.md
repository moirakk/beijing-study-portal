# 生物与环境的相互作用

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 生态因素 | 环境中影响生物生活和分布的因素 | 光、温度、水、空气、土壤 |
| 非生物因素 | 阳光、温度、水、空气等无机环境因素 | 沙漠缺水限制植物分布 |
| 生物因素 | 影响某种生物生活的其他生物 | 捕食、竞争、合作、寄生 |
| 生物适应环境 | 生物的形态结构和生活习性与环境相适应 | 仙人掌叶退化为刺 |
| 生物影响环境 | 生物的生命活动改变环境 | 植物防风固沙、蚯蚓改良土壤 |
| 环境选择生物 | 环境条件决定生物能否生存 | 北极熊有厚脂肪层 |

## 知识梳理

生物与环境相互作用，二者相互依赖、相互影响。环境中的生态因素分为非生物因素和生物因素。非生物因素包括光、温度、水、空气、土壤等，它们直接影响生物的分布、形态和生理活动。

生物因素是指影响某种生物生活的其他生物，包括同种生物之间和不同种生物之间的关系。种间关系主要有捕食、竞争、寄生、共生等；种内关系包括种内互助和种内斗争。

生物在长期进化过程中，通过自然选择形成了对环境的适应。同时，生物也能影响和改变环境。例如，森林可以涵养水源、调节气候；蚯蚓的活动使土壤疏松肥沃。

## 实验要点

“探究光对鼠妇生活的影响”实验：在铁盘内一侧放湿土并遮光，另一侧放湿土见光，中央放入10只鼠妇，观察并记录鼠妇分布。结论：鼠妇适于生活在阴暗环境中，说明光对生物生活有影响。

“探究植物对空气湿度的影响”实验：选择草地、裸地和灌木丛三个地点，用干湿计测量并比较空气湿度。结论：植物能增加空气湿度，生物影响环境。

## 对比表格

| 关系类型 | 特点 | 举例 |
|---|---|---|
| 捕食 | 一种生物以另一种生物为食 | 鹰捕食兔 |
| 竞争 | 两种生物争夺资源和空间 | 水稻与杂草竞争阳光、养分 |
| 寄生 | 一种生物生活在另一种生物体内或体表，获取营养 | 蛔虫寄生在人体肠道 |
| 共生 | 两种生物共同生活，相互有利 | 豆科植物与根瘤菌 |

## 背记要点

- 生物既能适应环境，也能影响环境；环境对生物具有选择作用。
- 沙漠植物根系发达、叶片退化为刺，是对缺水环境的适应。
- 北极狐耳朵小、毛厚，是对寒冷环境的适应；沙漠狐耳朵大，利于散热。
- 保护色、警戒色、拟态都是生物适应环境的典型方式。
