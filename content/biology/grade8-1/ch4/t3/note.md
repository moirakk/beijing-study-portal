# 设计并制作生态瓶

## 概念表

| 概念 | 含义 | 在生态瓶中的作用 |
|---|---|---|
| 生态瓶 | 模拟自然生态系统的封闭或半封闭小型装置 | 观察生态系统的稳定性 |
| 生产者 | 能进行光合作用的绿色植物 | 水草、藻类，制造有机物和氧气 |
| 消费者 | 直接或间接以生产者为食的动物 | 小鱼、螺、虾，消耗有机物和氧气 |
| 分解者 | 分解有机物的细菌和真菌 | 促进物质循环，净化水质 |
| 非生物部分 | 水、阳光、空气、温度等 | 为生物提供生存条件 |
| 生态平衡 | 生态系统中生物数量和比例相对稳定的状态 | 判断生态瓶是否成功的标准 |

## 知识梳理

生态瓶是一个小型人工生态系统，由生物部分和非生物部分组成。制作生态瓶时，需要合理搭配生产者、消费者和分解者，并保证充足的非生物条件。

成功的生态瓶应满足以下条件：选择生命力较强的生物；生产者数量要足够，能通过光合作用制造有机物并释放氧气；消费者数量不宜过多，避免消耗过快；水体清澈、透明，便于观察；放置在光线适宜但避免阳光直射的地方。

生态瓶中的物质可以循环，但能量不能循环，需要持续接受光照补充能量。如果生态瓶内生物死亡或水质恶化，说明生态平衡被破坏，可能是光照不足、生物过多或氧气不足等原因造成的。

## 实验要点

“设计并制作生态瓶”综合实践：
1. 准备透明玻璃瓶、洗净的沙子或小石子、池塘水、水草、小鱼或螺等。
2. 在瓶底铺一层沙子，注入池塘水，放入适量水草。
3. 静置一天后，放入少量小鱼或螺。
4. 密封或半密封瓶口，放在散射光处观察。
5. 每天记录生物活动和水质变化，分析生态瓶稳定的原因。

## 对比表格

| 组成 | 生态瓶中的成分 | 自然生态系统中的对应 |
|---|---|---|
| 非生物部分 | 水、阳光、空气、温度 | 阳光、空气、水、土壤、温度 |
| 生产者 | 水草、藻类 | 绿色植物 |
| 消费者 | 小鱼、螺、虾 | 各种动物 |
| 分解者 | 水中的细菌和真菌 | 腐生细菌、真菌 |

## 背记要点

- 生态瓶必须包含生产者、消费者、分解者和非生物部分，才能构成完整生态系统。
- 生态瓶应放在有散射光的地方，避免阳光直射导致水温过高。
- 生态瓶中生物种类和数量要适宜，过多或过少都会影响生态平衡。
- 观察生态瓶时，应从生物存活状态、水质、气泡产生等方面判断其稳定性。
