# 细菌

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 细菌 | 单细胞原核生物，无以核膜为界限的细胞核 | 大肠杆菌、结核杆菌、乳酸菌 |
| 原核细胞 | 没有以核膜为界限的细胞核，遗传物质分散在细胞质中 | 细菌、蓝藻 |
| 荚膜 | 某些细菌细胞壁外的黏液层，有保护作用 | 肺炎球菌的荚膜 |
| 鞭毛 | 细菌的运动器官，细长丝状 | 大肠杆菌的鞭毛 |
| 芽孢 | 某些细菌在不良环境下形成的休眠体，抵抗力极强 | 炭疽杆菌的芽孢 |

## 知识梳理

细菌是单细胞生物，属于原核生物。细菌的细胞结构包括：细胞壁（保护）、细胞膜（控制物质进出）、细胞质（含核糖体等）、DNA（遗传物质，无核膜包裹）。部分细菌还有荚膜（保护）和鞭毛（运动）。

细菌与植物细胞的主要区别：细菌无以核膜为界限的细胞核（原核），无叶绿体，无液泡；植物细胞有细胞核（真核），有叶绿体（绿色植物），有液泡。

细菌的生殖方式是分裂生殖（二分裂），速度极快，在适宜条件下每20分钟分裂一次。细菌的营养方式：大多数细菌是异养型（腐生或寄生），少数细菌能进行光合作用或化能合成（自养型）。

## 实验要点

"观察细菌的形态"实验：在显微镜下观察细菌的永久装片，辨认球菌、杆菌、螺旋菌三种形态，理解细菌的基本形态特征。

"制作酸奶"实践：将乳酸菌加入牛奶中，在适宜温度下发酵，观察牛奶变酸的过程，理解细菌在食品加工中的应用。

## 对比表格

| 比较项 | 细菌（原核细胞） | 植物细胞（真核细胞） |
|---|---|---|
| 细胞核 | 无核膜，DNA裸露 | 有核膜，有真正的细胞核 |
| 细胞壁 | 有（成分不同） | 有（纤维素） |
| 叶绿体 | 无 | 有（绿色植物） |
| 液泡 | 无 | 有 |
| 核糖体 | 有 | 有 |
| 大小 | 极小（微米级） | 较大 |

## 背记要点

- 细菌是原核生物，无以核膜为界限的细胞核，无叶绿体，无液泡。
- 细菌的基本结构：细胞壁、细胞膜、细胞质、DNA（遗传物质）。
- 细菌的特有结构：荚膜（保护）、鞭毛（运动）、芽孢（休眠，抵抗不良环境）。
- 细菌的生殖方式：分裂生殖（二分裂），速度极快。
- 细菌按形态分：球菌、杆菌、螺旋菌。
