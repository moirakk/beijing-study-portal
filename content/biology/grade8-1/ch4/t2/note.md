# 真菌

## 概念表

| 概念 | 含义 | 举例 |
|---|---|---|
| 真菌 | 有真正细胞核的真核生物，细胞壁含几丁质，异养 | 酵母菌、霉菌、蘑菇 |
| 菌丝 | 真菌的营养体，由细长的丝状细胞构成 | 青霉菌的菌丝 |
| 孢子 | 真菌的生殖细胞，能萌发形成新个体 | 青霉菌的孢子 |
| 出芽生殖 | 酵母菌的无性生殖方式，母体上长出芽体 | 酵母菌出芽 |
| 子实体 | 大型真菌（蘑菇）的产孢结构，即我们食用的部分 | 蘑菇的菌盖和菌柄 |

## 知识梳理

真菌是真核生物，有以核膜为界限的细胞核，无叶绿体，异养（腐生或寄生）。真菌的细胞壁成分是几丁质（与植物细胞壁的纤维素不同）。

真菌的种类：酵母菌（单细胞，球形或椭圆形）、霉菌（多细胞，有菌丝，如青霉菌、根霉菌）、大型真菌（蘑菇、木耳等）。

真菌的繁殖方式：酵母菌主要通过出芽生殖（无性）繁殖，也能进行孢子生殖；霉菌和蘑菇主要通过孢子生殖繁殖。孢子数量极多，质量极轻，能随风传播到各处。

## 实验要点

"观察酵母菌和霉菌"实验：用显微镜观察酵母菌的临时装片，辨认细胞核、细胞壁、液泡，观察出芽生殖；观察青霉菌或根霉菌的菌丝和孢子，理解霉菌的结构特点。

"制作馒头或面包"实践：将酵母菌加入面粉中，观察面团发酵膨胀的过程，理解酵母菌在无氧条件下分解葡萄糖产生酒精和二氧化碳的过程。

## 对比表格

| 比较项 | 细菌 | 真菌 |
|---|---|---|
| 细胞类型 | 原核细胞（无核膜） | 真核细胞（有核膜） |
| 细胞壁成分 | 肽聚糖 | 几丁质 |
| 叶绿体 | 无 | 无 |
| 繁殖方式 | 分裂生殖 | 孢子生殖、出芽生殖 |
| 代表生物 | 大肠杆菌、乳酸菌 | 酵母菌、青霉菌、蘑菇 |

## 背记要点

- 真菌是真核生物，有核膜，无叶绿体，异养（腐生或寄生）。
- 酵母菌：单细胞，出芽生殖（无性）为主，也能孢子生殖。
- 霉菌（青霉菌、根霉菌）：多细胞，有菌丝，孢子生殖。
- 蘑菇：大型真菌，菌盖+菌柄+菌丝，孢子生殖。
- 青霉素是从青霉菌中提取的抗生素，能杀灭细菌。
