# 神经系统支配下的运动

## 概念表

| 结构 | 组成/位置 | 功能 |
|---|---|---|
| 骨 | 由骨膜、骨质、骨髓构成 | 杠杆、支撑、保护 |
| 关节 | 关节面、关节囊、关节腔 | 运动的支点 |
| 骨骼肌 | 肌腹和肌腱 | 提供动力 |
| 肌腱 | 骨骼肌两端较细部分 | 连接肌肉和骨 |
| 关节软骨 | 关节面表面 | 减少摩擦、缓冲震动 |
| 骨髓 | 骨髓腔内及骨松质间隙 | 红骨髓造血，黄骨髓储脂 |

## 知识梳理

运动系统由骨、关节和肌肉组成。骨与骨之间通过关节等方式相连形成骨骼，骨骼肌附着在骨上。运动的产生是骨、关节和骨骼肌在神经系统支配下协调配合的结果。

骨骼肌受神经传来的刺激收缩时，会牵动骨绕关节活动。但骨骼肌只能收缩牵拉骨，不能推开骨，因此一个动作需要两组肌肉配合完成。例如屈肘时肱二头肌收缩、肱三头肌舒张；伸肘时相反。

关节由关节面、关节囊和关节腔组成。关节面覆盖关节软骨，关节囊内壁分泌滑液，这些结构使关节既牢固又灵活。关节囊及其内外的韧带增强关节牢固性；关节软骨和滑液减少摩擦，使运动灵活。

## 实验要点

“观察哺乳动物的关节”实验：以猪关节为例，剖开关节囊，观察关节头、关节窝、关节软骨、关节腔和滑液，理解关节适于运动的结构特点。

“观察屈肘和伸肘动作”实验：用手触摸上臂肌肉，做屈肘和伸肘动作，感受肱二头肌和肱三头肌的收缩与舒张变化，体会骨骼肌的协作关系。

| 关节 | 支点 | 支点 |

## 背记要点

- 运动不是仅靠运动系统完成，还需要神经系统调节以及消化、呼吸、循环系统提供能量。
- 骨骼肌两端绕过关节连在不同的骨上，收缩时产生拉力。
- 关节的牢固性靠关节囊和韧带；灵活性靠关节软骨和滑液。
- 动物运动的意义：有利于觅食、避敌、繁殖和迁徙。
