# 线形动物和环节动物

## 概念表

| 概念 | 含义 | 代表动物 |
|---|---|---|
| 线形动物 | 身体细长，呈线形，体表有角质层，有口有肛门 | 蛔虫、秀丽隐杆线虫、钩虫 |
| 环节动物 | 身体由许多相似的环状体节构成，有口有肛门 | 蚯蚓、沙蚕、水蛭 |
| 角质层 | 线形动物体表分泌的保护层，防止消化液侵蚀 | 蛔虫体表的角质层 |
| 刚毛 | 蚯蚓体节腹面的细小毛状结构，辅助运动 | 蚯蚓腹面的刚毛 |
| 环带 | 蚯蚓身体前端较粗的几个体节，与生殖有关 | 蚯蚓第14～16节 |

## 知识梳理

线形动物体表有角质层，有口有肛门，消化管前后贯通，消化效率高于腔肠动物和扁形动物。蛔虫是寄生在人体小肠中的线形动物，靠吸收人体消化好的食物为生，其体表角质层能抵抗人体消化液的侵蚀。

环节动物身体由许多相似的环状体节构成，体节之间有隔膜，各体节功能相对独立。蚯蚓是常见的环节动物，生活在富含腐殖质的湿润土壤中，通过湿润的体壁进行气体交换（呼吸）。蚯蚓的运动依靠肌肉收缩和刚毛的配合。

## 实验要点

"观察蚯蚓"实验：将蚯蚓放在湿润的纸上，观察其运动方式；用手触摸腹面感受刚毛；辨认前端（口、环带）和后端（肛门）。注意保持蚯蚓体表湿润，实验结束后放回土壤。

## 对比表格

| 比较项 | 线形动物（蛔虫） | 环节动物（蚯蚓） |
|---|---|---|
| 体型 | 细长，线形，不分节 | 细长，由许多体节构成 |
| 体表 | 有角质层 | 湿润，无角质层 |
| 消化 | 有口有肛门 | 有口有肛门 |
| 呼吸 | 无专门呼吸器官（厌氧） | 湿润体壁（皮肤呼吸） |
| 生活方式 | 多寄生 | 多自由生活 |
| 运动 | 肌肉收缩蠕动 | 肌肉+刚毛配合 |

## 背记要点

- 线形动物：体表有角质层，有口有肛门，代表动物蛔虫（寄生）、秀丽隐杆线虫。
- 环节动物：身体分节，有口有肛门，代表动物蚯蚓、沙蚕、水蛭。
- 蚯蚓是"土壤改良者"，能疏松土壤、提高肥力。
- 蛔虫感染途径：食入含蛔虫卵的食物，预防措施是饭前便后洗手、不喝生水。
- 蚯蚓区分前后端：环带靠近前端，口在前端，肛门在后端。
