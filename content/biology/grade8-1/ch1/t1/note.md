# 腔肠动物和扁形动物

## 概念表

| 概念 | 含义 | 代表动物 |
|---|---|---|
| 腔肠动物 | 有口无肛门，食物和残渣由同一开口进出，体壁由内外两层细胞构成 | 水螅、海蜇、珊瑚虫 |
| 扁形动物 | 身体背腹扁平，左右对称，有口无肛门，多数寄生 | 涡虫、猪肉绦虫、血吸虫 |
| 消化腔 | 腔肠动物体内的消化空腔，兼具消化和循环功能 | 水螅的消化腔 |
| 寄生 | 一种生物生活在另一种生物体内或体表，从中获取营养 | 绦虫寄生在猪和人体内 |

## 知识梳理

腔肠动物是最低等的多细胞动物，体壁由外胚层和内胚层两层细胞构成，两层之间有中胶层。体内有消化腔，有口无肛门。水螅生活在淡水中，身体呈辐射对称，触手上有刺细胞，是腔肠动物特有的攻击和防御结构。

扁形动物身体背腹扁平，左右对称（两侧对称），有口无肛门。涡虫是自由生活的扁形动物，生活在清洁的溪流中；猪肉绦虫和血吸虫是寄生生活的扁形动物，对人体危害较大。

## 实验要点

"观察水螅"实验：用放大镜或低倍镜观察水螅的外形，辨认触手、口、体柱和基盘。用解剖针轻触触手，观察水螅的收缩反应，理解刺细胞的防御功能。

"观察涡虫"实验：在培养皿中观察涡虫的运动方式（滑行），辨认头部眼点、三角形头部和尾部，理解两侧对称体型与运动的关系。

## 对比表格

| 比较项 | 腔肠动物（水螅） | 扁形动物（涡虫） |
|---|---|---|
| 体型对称 | 辐射对称 | 两侧对称 |
| 体壁层数 | 两层（外胚层、内胚层） | 三层（出现中胚层） |
| 消化方式 | 消化腔（细胞外消化+细胞内消化） | 肠道（细胞外消化） |
| 有无肛门 | 无 | 无 |
| 特有结构 | 刺细胞 | 无（涡虫有眼点） |
| 生活方式 | 多自由生活 | 自由生活或寄生 |

## 背记要点

- 腔肠动物：有口无肛门，刺细胞是特有结构，代表动物水螅、海蜇、珊瑚虫。
- 扁形动物：背腹扁平，两侧对称，有口无肛门，代表动物涡虫（自由）、绦虫、血吸虫（寄生）。
- 珊瑚虫分泌的石灰质骨骼堆积形成珊瑚礁，为海洋生物提供栖息地。
- 血吸虫寄生在人体血管中，中间宿主是钉螺；猪肉绦虫中间宿主是猪。
