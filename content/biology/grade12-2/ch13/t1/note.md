# 专题十三 种群与群落

## 核心概念 / 课标要求

**种群**：生活在一定区域的同种生物的全部个体。种群的特征包括种群密度、出生率和死亡率、迁入率和迁出率、年龄组成和性别比例。

**种群数量变化**：包括"J"型增长（理想条件）和"S"型增长（有限条件）。K 值（环境容纳量）是环境条件不受破坏时种群的最大数量。

**群落**：同一时间内聚集在一定区域中各种生物种群的集合。群落具有垂直结构和水平结构，存在种间关系。

## 知识梳理

| 概念 | 含义 | 要点 |
| --- | --- | --- |
| 种群密度 | 单位面积或体积内个体数 | 最基本的数量特征 |
| 年龄组成 | 各年龄期个体比例 | 预测种群数量变化 |
| J 型增长 | 理想条件下指数增长 | Nₜ=N₀λᵗ |
| S 型增长 | 有限条件下增长 | 有 K 值 |
| 群落结构 | 垂直结构、水平结构 | 分层、镶嵌 |
| 种间关系 | 捕食、竞争、寄生、互利共生 | 相互影响 |

## 典型例题

**例 1**：种群最基本的数量特征是什么？

**解**：种群密度是种群最基本的数量特征，出生率和死亡率、迁入率和迁出率决定种群密度，年龄组成预测种群数量变化。

**例 2**：J 型增长和 S 型增长的区别是什么？

**解**：J 型增长在理想条件下，种群数量呈指数增长，无 K 值；S 型增长在有限条件下，种群数量先增长后趋于稳定，存在 K 值。

**例 3**：调查种群密度常用的方法有哪些？

**解**：样方法（植物、活动能力弱的动物）和标志重捕法（活动能力强、活动范围大的动物）。

## 易错点

- 种群密度是种群最基本的数量特征，但不是唯一特征。
- 年龄组成预测种群数量变化趋势，但不能决定种群密度。
- J 型增长无 K 值，S 型增长有 K 值。
- 群落垂直结构表现为分层，水平结构表现为镶嵌分布。
- 种间关系包括捕食、竞争、寄生、互利共生，注意区分。

## 背记要点

1. 种群密度是种群最基本的数量特征。
2. 年龄组成预测种群数量变化。
3. J 型增长无 K 值，S 型增长有 K 值。
4. 样方法用于植物，标志重捕法用于活动能力强的动物。
5. 群落具有垂直结构和水平结构。
