# 专题七 伴性遗传与人类遗传病

## 核心概念 / 课标要求

**伴性遗传**：位于性染色体上的基因所控制的性状，在遗传上总是和性别相关联的现象。常见的有伴 X 染色体显性遗传、伴 X 染色体隐性遗传和伴 Y 染色体遗传。

**人类遗传病**：由遗传物质改变引起的疾病，包括单基因遗传病、多基因遗传病和染色体异常遗传病。

**遗传病检测**：遗传咨询、产前诊断（羊水检查、B 超检查、基因诊断）等。

## 知识梳理

| 遗传方式 | 特点 | 举例 |
| --- | --- | --- |
| 伴 X 隐性遗传 | 男性患者多于女性，交叉遗传 | 红绿色盲、血友病 |
| 伴 X 显性遗传 | 女性患者多于男性，代代相传 | 抗维生素 D 佝偻病 |
| 伴 Y 遗传 | 只传男性，父传子 | 外耳道多毛症 |
| 常染色体隐性 | 隔代遗传，男女患病机会均等 | 白化病、苯丙酮尿症 |
| 常染色体显性 | 代代相传，男女患病机会均等 | 多指、并指 |

## 典型例题

**例 1**：红绿色盲是伴 X 染色体隐性遗传病，女性携带者（XᴮXᵇ）与正常男性（XᴮY）婚配，后代患病情况如何？

**解**：后代中女儿基因型为 XᴮXᴮ 或 XᴮXᵇ，均正常；儿子基因型为 XᴮY 或 XᵇY，其中 XᵇY 为色盲，故儿子有 1/2 概率患病。

**例 2**：如何判断某遗传病是伴 X 隐性遗传还是常染色体隐性遗传？

**解**：若患者中男性明显多于女性，且出现交叉遗传（外公→女儿→外孙），则多为伴 X 隐性遗传；若男女患病机会均等，则为常染色体隐性遗传。

**例 3**：人类遗传病包括哪几类？

**解**：包括单基因遗传病（如白化病）、多基因遗传病（如青少年型糖尿病）和染色体异常遗传病（如 21 三体综合征）。

## 易错点

- 伴 X 隐性遗传中男性患者多于女性，且存在交叉遗传现象。
- 伴 Y 遗传只传男性，父传子、子传孙。
- 遗传病不一定是先天性疾病，先天性疾病也不一定是遗传病。
- 21 三体综合征是染色体数目异常，不是基因突变。
- 遗传咨询和产前诊断是预防遗传病的主要手段。

## 背记要点

1. 红绿色盲、血友病是伴 X 隐性遗传病。
2. 抗维生素 D 佝偻病是伴 X 显性遗传病。
3. 伴 Y 遗传只传男性。
4. 人类遗传病分单基因、多基因、染色体异常三类。
5. 预防遗传病：遗传咨询、产前诊断。
