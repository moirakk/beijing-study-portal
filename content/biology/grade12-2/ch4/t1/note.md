# 专题四 细胞的生命历程

## 核心概念 / 课标要求

**细胞增殖**：细胞通过分裂增加数目的过程，包括有丝分裂、无丝分裂和减数分裂。有丝分裂是真核生物体细胞增殖的主要方式。

**细胞分化**：在个体发育中，由一个或一种细胞增殖产生的后代，在形态、结构和生理功能上发生稳定性差异的过程。细胞分化的实质是基因的选择性表达。

**细胞衰老与凋亡**：细胞衰老是细胞生理状态和化学反应发生复杂变化的过程；细胞凋亡是由基因决定的细胞自动结束生命的过程，属于正常生理现象。

## 知识梳理

| 过程 | 特点 | 意义/实质 |
| --- | --- | --- |
| 有丝分裂 | 染色体复制一次，细胞分裂一次 | 亲子代细胞遗传物质相同 |
| 细胞分化 | 形态结构功能发生差异 | 实质是基因选择性表达 |
| 细胞衰老 | 水分减少、酶活性降低 | 细胞正常生命历程 |
| 细胞凋亡 | 基因控制的程序性死亡 | 维持内环境稳定 |
| 细胞癌变 | 无限增殖、形态改变 | 原癌基因和抑癌基因突变 |

## 典型例题

**例 1**：下列关于细胞分化的叙述，正确的是（　）。

**解**：细胞分化的实质是基因的选择性表达，分化后的细胞遗传物质不变，但形态、结构和功能发生稳定性差异。分化是持久性的，一般不可逆。

**例 2**：有丝分裂过程中，DNA 复制发生在哪个时期？染色体数目加倍发生在哪个时期？

**解**：DNA 复制发生在间期；染色体数目加倍发生在后期，因为着丝点分裂，姐妹染色单体分开成为两条染色体。

**例 3**：细胞凋亡与细胞坏死的区别是什么？

**解**：细胞凋亡是由基因控制的程序性死亡，属于正常生理现象，对机体有利；细胞坏死是外界不利因素引起的细胞被动死亡，对机体有害。

## 易错点

- 细胞分化不改变遗传物质，只是基因的选择性表达，分化程度越高，全能性越低。
- 有丝分裂间期进行 DNA 复制和有关蛋白质合成，为分裂期做准备。
- 细胞衰老不等于个体衰老，多细胞生物中细胞衰老与个体衰老不同步。
- 细胞凋亡是主动的、程序性的，细胞坏死是被动的、非程序性的。
- 癌细胞具有无限增殖、形态结构改变、细胞膜上糖蛋白减少等特征。

## 背记要点

1. 细胞分化的实质是基因的选择性表达。
2. 有丝分裂间期完成 DNA 复制。
3. 细胞凋亡是由基因决定的程序性死亡。
4. 细胞癌变的根本原因是原癌基因和抑癌基因突变。
5. 细胞全能性：已分化的细胞仍具有发育成完整个体的潜能。
