# 专题十四 生态系统与环境保护

## 核心概念 / 课标要求

**生态系统**：由生物群落与它的无机环境相互作用而形成的统一整体。包括生产者、消费者、分解者和非生物的物质和能量。

**生态系统的功能**：能量流动、物质循环和信息传递。能量流动单向流动、逐级递减；物质循环具有全球性；信息传递调节种间关系。

**生态系统的稳定性**：生态系统具有自我调节能力，包括抵抗力稳定性和恢复力稳定性。

**环境保护**：保护生物多样性，防止环境污染，实现可持续发展。

## 知识梳理

| 成分/功能 | 含义 | 要点 |
| --- | --- | --- |
| 生产者 | 自养生物 | 生态系统的基石 |
| 消费者 | 异养生物 | 促进物质循环 |
| 分解者 | 腐生生物 | 将有机物分解为无机物 |
| 能量流动 | 单向、逐级递减 | 传递效率 10%-20% |
| 物质循环 | 全球性、循环往复 | 碳循环 |
| 信息传递 | 物理、化学、行为信息 | 调节种间关系 |

## 典型例题

**例 1**：能量流动的特点是什么？

**解**：能量流动是单向流动、逐级递减的，相邻营养级之间的传递效率约为 10%-20%。

**例 2**：碳在生物群落与无机环境之间以什么形式循环？

**解**：碳在生物群落与无机环境之间以 CO₂ 形式循环，在生物群落内部以含碳有机物形式传递。

**例 3**：生态系统稳定性的基础是什么？

**解**：生态系统具有自我调节能力，其基础是负反馈调节。抵抗力稳定性与营养结构复杂程度有关。

## 易错点

- 生产者是生态系统的基石，分解者不可缺少。
- 能量流动是单向的、逐级递减的，不能循环。
- 物质循环具有全球性，能量流动和物质循环同时进行。
- 信息传递包括物理信息、化学信息和行为信息。
- 抵抗力稳定性与恢复力稳定性往往呈负相关。

## 背记要点

1. 生态系统包括生产者、消费者、分解者和非生物的物质和能量。
2. 能量流动单向流动、逐级递减，传递效率 10%-20%。
3. 碳以 CO₂ 形式在生物群落与无机环境间循环。
4. 生态系统稳定性的基础是负反馈调节。
5. 保护生物多样性是环境保护的重要内容。
