# 专题十五 实验设计与信息题

## 核心概念 / 课标要求

**实验设计原则**：科学性原则、对照原则、单一变量原则、平行重复原则。设计实验时要明确实验目的、自变量、因变量和无关变量。

**对照实验**：包括空白对照、自身对照、条件对照和相互对照。设置对照是为了排除无关变量的干扰，使实验结果更有说服力。

**信息题**：以新材料、新情境为背景，考查获取信息、分析问题和解决问题的能力，需从题干提取关键信息并结合所学作答。

## 知识梳理

| 要素 | 含义 | 要点 |
| --- | --- | --- |
| 自变量 | 实验要研究的变量 | 人为改变 |
| 因变量 | 随自变量变化的量 | 观察和测量 |
| 无关变量 | 除自变量外的其他变量 | 需控制相同 |
| 对照原则 | 设置对照组 | 排除干扰 |
| 单一变量 | 只改变一个变量 | 保证科学性 |
| 重复原则 | 多次重复实验 | 减少误差 |

## 典型例题

**例 1**：设计实验探究某物质对种子萌发的影响，应遵循哪些原则？

**解**：应遵循对照原则、单一变量原则和重复原则。设置实验组（加该物质）和对照组（不加），其他条件保持相同且适宜，并重复多次以减少误差。
**例 2**：某实验的自变量和因变量分别是什么？

**解**：自变量是实验要研究的变量，因变量是随自变量变化而变化的量。如探究光照强度对光合作用的影响，光照强度是自变量，光合速率是因变量。
**例 3**：信息题中如何提取关键信息？

**解**：先通读题干明确实验目的和情境，再找出自变量、因变量和对照，最后结合所学知识分析作答，注意用规范术语表述。

## 易错点

- 实验设计必须遵循对照原则，不能只设实验组而无对照组。
- 单一变量原则要求只改变一个变量，其他变量保持相同。
- 无关变量需控制相同且适宜，否则影响实验结果。
- 因变量的观测指标要明确、可量化。
- 信息题作答要结合题干信息，不能脱离材料凭空作答。

## 背记要点

1. 实验设计原则：科学、对照、单一变量、重复。
2. 自变量是实验研究的变量，因变量是观测的变量。
3. 设置对照是为了排除无关变量干扰。
4. 无关变量需控制相同且适宜。
5. 信息题要提取关键信息并结合所学作答。
