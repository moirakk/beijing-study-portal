# 专题十 生物的进化

## 核心概念 / 课标要求

**现代生物进化理论**：种群是生物进化的基本单位；突变和基因重组产生进化的原材料；自然选择决定生物进化的方向；隔离是物种形成的必要条件。

**基因频率**：在一个种群基因库中，某个基因占全部等位基因数的比率。基因频率的改变是生物进化的实质。

**物种形成**：经过长期的地理隔离，使不同种群基因库产生明显差异，最终形成生殖隔离，产生新物种。

## 知识梳理

| 概念 | 含义 | 要点 |
| --- | --- | --- |
| 种群 | 生活在一定区域的同种生物的全部个体 | 进化的基本单位 |
| 基因库 | 种群中全部个体所含有的全部基因 | 基因频率改变即进化 |
| 突变和基因重组 | 进化的原材料 | 不定向 |
| 自然选择 | 决定进化方向 | 定向 |
| 隔离 | 物种形成的必要条件 | 地理隔离、生殖隔离 |

## 典型例题

**例 1**：某种群中 AA 个体占 30%，Aa 占 60%，aa 占 10%，则 A 的基因频率是多少？

**解**：A 的基因频率 = AA 频率 + 1/2×Aa 频率 = 30% + 1/2×60% = 60%。

**例 2**：生物进化的实质是什么？

**解**：生物进化的实质是种群基因频率的改变。

**例 3**：物种形成的必要条件是什么？

**解**：隔离是物种形成的必要条件，其中生殖隔离是物种形成的标志。

## 易错点

- 生物进化的基本单位是种群，不是个体。
- 进化的实质是种群基因频率的改变，不是基因型频率的改变。
- 自然选择决定生物进化的方向，突变和基因重组提供原材料。
- 隔离是物种形成的必要条件，生殖隔离是物种形成的标志。
- 基因频率计算时注意常染色体与性染色体基因频率的计算方法不同。

## 背记要点

1. 种群是生物进化的基本单位。
2. 进化的实质是种群基因频率的改变。
3. 突变和基因重组是进化的原材料。
4. 自然选择决定生物进化的方向。
5. 隔离是物种形成的必要条件。
