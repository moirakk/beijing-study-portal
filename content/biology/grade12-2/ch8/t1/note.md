# 专题八 遗传计算与系谱分析

## 核心概念 / 课标要求

**遗传计算**：利用分离定律和自由组合定律，通过配子法、棋盘法、分枝法等计算后代基因型、表现型的种类和比例。

**系谱分析**：根据遗传系谱图判断遗传病的遗传方式，并计算后代患病的概率。

**常用方法**：先判断显隐性，再判断基因位置（常染色体或性染色体），最后计算概率。

## 知识梳理

| 方法 | 适用情况 | 要点 |
| --- | --- | --- |
| 配子法 | 计算配子种类和比例 | 等位基因分离、非等位基因自由组合 |
| 棋盘法 | 两对基因杂交 | 16 格，统计基因型和表现型 |
| 分枝法 | 多对基因 | 逐对分析再相乘 |
| 系谱判断 | 遗传病遗传方式 | 无中生有为隐性，有中生无为显性 |
| 概率计算 | 后代患病概率 | 先算各基因型概率再相乘 |

## 典型例题

**例 1**：基因型为 AaBb 与 Aabb 杂交，后代中 Aabb 的比例是多少？

**解**：Aa×Aa → Aa 占 1/2；Bb×bb → bb 占 1/2。故 Aabb 占 1/2×1/2=1/4。

**例 2**：某遗传病系谱中，父母均正常，但生了一个患病女儿，则该病的遗传方式是什么？

**解**：父母正常却生出患病女儿，属于"无中生有"，为隐性遗传；又因女儿患病而父亲正常，故为常染色体隐性遗传。

**例 3**：一对表现正常的夫妇，生了一个患白化病（常染色体隐性）的孩子，则他们再生一个患病孩子的概率是多少？

**解**：夫妇均为携带者 Aa，Aa×Aa 后代患病（aa）概率为 1/4。

## 易错点

- 判断显隐性："无中生有"为隐性，"有中生无"为显性。
- 判断基因位置：若女儿患病而父亲正常，则为常染色体隐性；若父亲患病而女儿正常，则可能为伴 X 显性。
- 计算概率时注意"患病男孩"与"男孩患病"的区别，前者需乘以 1/2。
- 多对基因计算时逐对分析再相乘，不要混淆。
- 系谱分析中要注意患者性别比例，判断是否伴性遗传。

## 背记要点

1. 无中生有为隐性，有中生无为显性。
2. 常染色体隐性遗传：男女患病机会均等。
3. 伴 X 隐性遗传：男性患者多于女性。
4. 患病男孩概率 = 男孩患病概率 × 1/2。
5. 多对基因计算用分枝法逐对相乘。
