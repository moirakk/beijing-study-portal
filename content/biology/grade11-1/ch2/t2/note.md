# 第2节 神经调节的基本方式

## 概念定义

**反射**：在中枢神经系统参与下，机体对内外环境变化作出的**规律性应答**。反射是神经调节的基本方式。

**反射弧**：完成反射的结构基础，由**感受器→传入神经→神经中枢→传出神经→效应器**五部分组成。效应器指传出神经末梢和它所支配的肌肉或腺体。

**条件反射与非条件反射**：非条件反射是生来就有、由非条件刺激直接引起的反射（如膝跳反射、缩手反射）；条件反射是在非条件反射基础上，经**学习和训练**（条件刺激与非条件刺激多次结合强化）建立的反射（如望梅止渴），需要**大脑皮层**参与。

## 知识梳理

```mermaid
flowchart LR
    A["感受器<br>（接受刺激产生兴奋）"] --> B["传入神经"]
    B --> C["神经中枢<br>（分析综合）"]
    C --> D["传出神经"]
    D --> E["效应器<br>（作出应答）"]
```

| 比较项 | 非条件反射 | 条件反射 |
| --- | --- | --- |
| 形成 | 先天遗传、生来就有 | 后天经学习训练建立 |
| 刺激 | 非条件刺激（直接刺激） | 条件刺激（信号刺激） |
| 中枢 | 大脑皮层以下中枢即可完成 | 必须有大脑皮层参与 |
| 稳定性 | 稳定、不消退 | 可建立也可**消退**（不强化则减弱） |
| 意义 | 完成基本生命活动 | 大大提高机体适应复杂环境变化的能力 |

**反射弧完整性**：反射弧任何一个环节中断，反射都不能完成。判断受损部位：刺激传出神经或效应器仍能收缩但整体反射消失——可能是感受器、传入神经或中枢受损；有感觉但无运动——传出神经或效应器受损。

**条件反射的消退**：反复应用条件刺激而不给予非条件刺激强化，条件反射会逐渐减弱直至消退。消退不是简单的丧失，而是中枢把原先引起兴奋性效应的信号转变为产生抑制性效应的信号，是**新的学习过程**。

## 典型例题

**例 1**：给狗喂食会分泌唾液，多次"铃声 + 喂食"后，仅铃声也能引起唾液分泌。相关叙述错误的是（　）
A. 食物引起唾液分泌属于非条件反射
B. 铃声引起唾液分泌需要大脑皮层参与
C. 该条件反射一旦建立便不会消退
D. 条件反射扩大了机体对外界刺激的应答范围
**解析**：若只给铃声而不再喂食强化，条件反射会逐渐消退。选 **C**。

**例 2**：某患者上肢有感觉但不能运动，用反射弧知识分析可能受损的部位。
**解析**：有感觉说明感受器、传入神经、神经中枢（感觉部分）及上行传导通路完好；不能运动说明兴奋不能到达肌肉，受损部位可能是**传出神经或效应器**（或中枢中支配运动的部分）。

## 易错点

- 反射必须有**中枢神经系统参与**：离体肌肉受刺激收缩、含羞草叶片闭合都**不属于反射**。
- 效应器 = 传出神经末梢 **+** 它支配的肌肉或腺体，不能只答"肌肉"。
- 反射弧不完整（如只刺激传出神经引起肌肉收缩）不叫反射。
- 条件反射的建立与消退都离不开**大脑皮层**；消退是新的学习而非遗忘。

## 背记要点

1. 反射的定义三要素：中枢神经系统参与、内外刺激、规律性应答。
2. 反射弧五部分顺序：感受器→传入神经→神经中枢→传出神经→效应器。
3. 判断传入/传出神经：看神经节（在传入神经上）、看突触方向、看脊髓灰质结构（前角宽大连传出）。
4. 条件反射建立：条件刺激与非条件刺激**多次结合**；不强化则消退。
5. 条件反射意义：使机体有**预见性**地应对环境变化，提高适应能力。
