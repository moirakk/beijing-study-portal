# 第1节 激素与内分泌系统

## 概念定义

**激素**：由**内分泌腺（或内分泌细胞）**分泌的、对机体生命活动进行调节的**微量高效**的信息分子（化学物质）。激素不组成细胞结构、不提供能量、不起催化作用，只作为**信使**传递信息。

**内分泌腺**：没有导管，分泌物（激素）直接进入腺体内的毛细血管，随血液运输到全身；与之相对，唾液腺、汗腺等**外分泌腺**有导管。

**激素调节**：由内分泌器官（或细胞）分泌的激素进行调节的方式，是体液调节的主要内容。

## 知识梳理

**促胰液素的发现**（激素发现史）：沃泰默实验（切除神经仍分泌胰液，但囿于神经反射观念）→ **斯塔林和贝利斯**大胆假设并实验：稀盐酸 + 小肠黏膜研磨提取液注入静脉 → 促进胰腺分泌胰液 → 发现第一种激素**促胰液素**（由小肠黏膜分泌）。启示：科学发现需要敢于质疑、勇于创新。

| 内分泌腺 | 主要激素 | 主要作用 |
| --- | --- | --- |
| 下丘脑 | 促甲状腺激素释放激素（TRH）、抗利尿激素等 | 调控垂体；抗利尿激素促进肾小管、集合管重吸收水 |
| 垂体 | 生长激素、促甲状腺激素（TSH）等 | 促进生长；调控甲状腺等腺体 |
| 甲状腺 | 甲状腺激素 | 促进新陈代谢和生长发育，提高神经系统兴奋性 |
| 胰岛 | 胰岛素（B 细胞）、胰高血糖素（A 细胞） | 降低/升高血糖 |
| 肾上腺 | 肾上腺素等 | 升血糖、心跳加快、代谢加强（应急） |
| 性腺 | 雄/雌激素 | 促进生殖器官发育和第二性征出现 |

**激素分泌异常病例**：幼年生长激素不足——侏儒症；幼年过多——巨人症；成年过多——肢端肥大症。幼年甲状腺激素不足——呆小症；成年分泌过多——甲亢；缺碘——地方性甲状腺肿（大脖子病）。

**激素研究方法**：切除法（摘除腺体观察症状）、移植法/注射法（补充激素观察恢复）、饲喂法（仅适用于甲状腺激素等口服有效的激素；蛋白质类激素如胰岛素、生长激素**不能饲喂**，会被消化分解）。

## 典型例题

**例 1**：下列关于激素的叙述，正确的是（　）
A. 激素直接参与细胞内的代谢反应
B. 激素只运输给特定的靶器官
C. 激素随血液运往全身，但只作用于靶器官、靶细胞
D. 只有内分泌腺才能分泌激素
**解析**：激素作为信使不参与代谢、不催化反应；随血液运往**全身各处**，但只有具相应**受体**的靶细胞才能被作用；下丘脑的某些神经细胞等也能分泌激素。选 **C**。

**例 2**：探究甲状腺激素能促进幼小动物发育，可否用饲喂法？若换成生长激素呢？
**解析**：甲状腺激素是**氨基酸衍生物**，口服不被消化失活，可用饲喂法（如用甲状腺激素饲喂蝌蚪，观察其提前变态发育）。生长激素是**蛋白质**，口服会被消化道中蛋白酶分解失去作用，只能用**注射法**。

## 易错点

- 激素是**信息分子**：不构成细胞结构、不供能、不催化，作用后即被灭活，需**源源不断**分泌。
- 激素经血液运输到**全身**，并非定向运输，只是只对有相应受体的靶细胞起作用。
- 蛋白质/多肽类激素（胰岛素、生长激素、垂体和下丘脑分泌的各种促激素）只能注射；固醇类（性激素）和氨基酸衍生物（甲状腺激素）可口服。
- 促胰液素由**小肠黏膜**分泌，作用是促进**胰腺分泌胰液**，它是人们发现的第一种激素。

## 背记要点

1. 第一种被发现的激素：促胰液素（斯塔林和贝利斯，小肠黏膜分泌）。
2. 激素特点：微量高效、经体液运输、作用于靶器官/靶细胞、作为信使传递信息。
3. 主要腺体—激素—功能对应表（下丘脑、垂体、甲状腺、胰岛、肾上腺、性腺）。
4. 分泌异常疾病：侏儒症/巨人症（生长激素）、呆小症/甲亢/大脖子病（甲状腺激素与碘）。
5. 研究方法：切除法、注射法、移植法、饲喂法（注意激素化学本质的限制）。
