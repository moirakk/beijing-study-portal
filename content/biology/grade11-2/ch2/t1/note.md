# 第1节 群落的结构

## 概念定义

**群落**：在相同时间聚集在一定地域中**各种生物种群**的集合（包括所有动物、植物、微生物）。

**物种丰富度**：一个群落中的**物种数目**，是区别不同群落的重要特征。越靠近热带地区丰富度越高。

**种间关系**：不同物种之间的关系，包括**原始合作、互利共生、捕食、寄生、种间竞争**。

**生态位**：一个物种在群落中的地位或作用，包括所处的**空间位置、占用资源的情况，以及与其他物种的关系**。研究动物的生态位常考察栖息地、食物、天敌及与其他物种的关系；研究植物则考察出现频率、种群密度、株高等。

## 知识梳理

| 种间关系 | 特点 | 实例 |
| --- | --- | --- |
| 互利共生 | 相互依存、彼此有利，"同生共死" | 豆科植物与根瘤菌 |
| 原始合作 | 双方有利，分开也能独立生存 | 海葵与寄居蟹 |
| 捕食 | 一方捕食另一方，数量循环波动 | 猞猁捕食雪兔 |
| 寄生 | 寄生者利、宿主害，一般不致死 | 马蛔虫与马 |
| 种间竞争 | 争夺资源和空间，"你死我活"或此消彼长 | 大草履虫与双小核草履虫 |

**群落的空间结构**：① **垂直结构**——分层现象：植物分层主要受**光照**（还有温度）影响，如森林中乔木层、灌木层、草本层；动物分层受**栖息空间和食物**影响。意义：显著提高群落利用阳光等环境资源的能力。② **水平结构**——镶嵌分布：因地形变化、土壤湿度、盐碱度、光照强度差异及生物自身生长特点不同而形成。

**生态位分化的意义**：群落中每种生物占据相对稳定的生态位，是**协同进化**的结果，有利于不同物种**充分利用环境资源**、减弱竞争。

## 典型例题

**例 1**：将大草履虫与双小核草履虫混合培养，一段时间后大草履虫消失。这体现了何种种间关系？与捕食有何区别？
**解析**：二者争夺相同的食物和空间，属于**种间竞争**，竞争力弱的大草履虫被淘汰（数量降为 0）。区别：捕食中被捕食者一般**不会被捕食至灭绝**，双方数量循环波动；竞争激烈时劣势方可能完全消失，且竞争双方无捕食与被捕食的营养关系。

**例 2**：某森林中四种鸟均以昆虫为食但取食高度不同（树冠层、中层、下层、地面）。分析其意义。
**解析**:四种鸟的**生态位发生分化**，取食空间不同使它们对食物资源的利用错开，**减弱了种间竞争**，使群落能更充分地利用栖息空间和食物资源。这是长期**协同进化**（自然选择）的结果，也体现了群落垂直结构中动物分层与食物和栖息空间的关系。

## 易错点

- 群落包括该区域**所有生物**（含微生物），"一片森林中所有植物"不是群落。
- 互利共生与原始合作的区别：**分开后能否独立生存**（原始合作可以）。
- 高山不同海拔分布不同植被属于**不同群落的分布**（受温度制约），不是一个群落的垂直结构。
- 竹林中竹子高矮不齐是**种群**的年龄差异，不属于群落垂直结构。

## 背记要点

1. 群落 = 一定区域内所有种群的集合；物种丰富度是群落物种数目。
2. 五种种间关系及曲线判读：共生同步、捕食循环错峰、竞争此消彼长，高考读图题高频。
3. 垂直结构：植物分层因光照，动物分层因食物和栖息空间；意义是提高资源利用能力。
4. 生态位包含空间位置、资源占用、种间关系三方面，是新教材新增高频考点。
5. 土壤小动物丰富度调查：取样器取样法，统计用记名计算法或目测估计法。
