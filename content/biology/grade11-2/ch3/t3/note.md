# 第3节 生态系统的物质循环

## 概念定义

**物质循环（生物地球化学循环）**：组成生物体的碳、氢、氧、氮、磷、硫等**元素**，不断在**生物群落与非生物环境**之间循环往复的过程，具有**全球性**。

**碳循环**：碳在非生物环境中主要以 **CO₂ 和碳酸盐**形式存在，在生物群落内部以**含碳有机物**形式沿食物链传递，在群落与环境之间主要以 **CO₂** 形式循环。

**生物富集**：生物体从周围环境吸收、积蓄某种元素或**难以降解的化合物**（如铅、汞、DDT），使其在体内浓度**超过环境浓度**的现象。营养级越高，富集物浓度越高，也具全球性。

## 知识梳理

**碳进入群落的途径**：光合作用（主要）和化能合成作用；**返回环境的途径**：①动植物呼吸作用；②分解者的分解（呼吸）作用；③化石燃料的燃烧。

| 比较项 | 能量流动 | 物质循环 |
| --- | --- | --- |
| 形式 | 光能→化学能→热能 | 化学元素（如 C 以 CO₂/有机物） |
| 特点 | 单向流动、逐级递减 | 循环往复、全球性 |
| 范围 | 生态系统各营养级 | 生物圈 |
| 联系 | 二者**同时进行、相互依存**：物质是能量的载体，能量是物质循环的动力 | |

**温室效应与碳中和**：化石燃料的大量燃烧使 CO₂ 释放**超过**生物圈自我调节能力，打破碳循环平衡，导致气温升高。措施：减少化石燃料燃烧、开发新能源、**植树造林增大碳汇**，实现碳达峰、碳中和。

## 典型例题

**例 1**：碳循环示意图中，如何快速判断生产者、消费者、分解者和大气 CO₂ 库？
**解析**：与其他成分之间存在**双向箭头**的两者是生产者和大气 CO₂ 库，其中被其他多个成分箭头指向的是 **CO₂ 库**，另一个是**生产者**；生产者和消费者都有箭头指向的是**分解者**；剩余为消费者。此判断模板是北京卷识图题的通用方法。

**例 2**：DDT 难降解，在"浮游植物→浮游动物→鱼→鱼鹰"中，哪种生物体内 DDT 浓度最高？为什么说生物富集具有全球性？
**解析**：DDT 沿食物链传递并不断积累，营养级越高浓度越高，**鱼鹰**体内浓度最高（与能量逐级递减相反）。DDT 可通过大气、水和生物迁移等途径扩散到世界各地（南极企鹅体内也检出 DDT），故生物富集是**全球性**的。

## 易错点

- 物质循环的"物质"指**元素**（C、N、P 等），不是葡萄糖等化合物；循环发生在**生物群落与非生物环境**之间。
- 碳在群落**内部**沿食物链以**有机物**形式单向传递（不是循环），群落与环境之间以 CO₂ 循环。
- 生物富集的物质是**难降解**的重金属、有机农药；营养级越高浓度越高，与能量流动趋势相反。
- 能量流动不循环，物质可循环——"物质是载体、能量是动力"，二者不可割裂。

## 背记要点

1. 物质循环两大特点：**循环往复、全球性**（生物地球化学循环）。
2. 碳的存在形式：环境中 CO₂/碳酸盐，群落内含碳有机物；群落⇄环境靠光合（进）与呼吸、分解、燃烧（出）。
3. 碳循环图判断口诀：双箭头找生产者与 CO₂ 库，箭头汇聚多者为 CO₂ 库。
4. 温室效应主因是化石燃料大量燃烧；对策：减排 + 增汇（植树造林），联系"碳中和"时政是北京卷热点。
5. 生物富集沿食物链浓度**升高**，鱼鹰、人等顶级消费者受害最重。
