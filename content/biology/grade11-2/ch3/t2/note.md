# 第2节 生态系统的能量流动

## 概念定义

**能量流动**：生态系统中能量的**输入、传递、转化和散失**的过程。源头是**太阳能**，输入总量是**生产者固定的太阳能总量**。

**同化量**：某营养级摄入的能量减去粪便中的能量（摄入量 = 同化量 + 粪便量）。粪便中的能量属于**上一营养级**的同化量，流向分解者。

**能量传递效率**：相邻两个营养级之间同化量的比值，一般为 **10%~20%**。

**能量金字塔**：将各营养级的能量数值由低到高绘制成的金字塔图形，**永远正立**，直观反映能量沿营养级流动**逐级递减**。

## 知识梳理

**能量流动的特点**：① **单向流动**——捕食关系不可逆转，散失的热能不能再利用；② **逐级递减**——各营养级都有呼吸散失、流向分解者和未被利用的部分。

某营养级同化量的去向：① 呼吸作用以热能散失；② 用于**生长、发育和繁殖**（储存在有机物中），后者又分为：流入下一营养级、被分解者利用、（一定时间内）未被利用。

| 项目 | 内容 |
| --- | --- |
| 输入 | 生产者固定的太阳能总量（流经生态系统的总能量） |
| 传递渠道 | 食物链和食物网 |
| 转化 | 光能→化学能→热能 |
| 散失 | 各营养级呼吸作用产生的热能 |
| 传递效率 | 相邻营养级间 10%~20% |

**研究意义**：① 帮助人们将生物在时间、空间上进行合理配置，实现能量的**多级利用**（桑基鱼塘）；② 合理调整能量流动关系，使能量**持续高效地流向对人类最有益的部分**（除草除虫、合理确定草场载畜量）。

## 典型例题

**例 1**：某生态系统生产者固定能量 10000 kJ，按食物链"草→兔→狐"计算，狐最多和最少可获得多少能量？
**解析**：求最多用 20%、最少用 10%。最多：10000×20%×20% = **400 kJ**；最少：10000×10%×10% = **100 kJ**。若求"人最多需消耗生产者多少"，则反向用 10% 计算。北京卷计算题要看清"最多/最少""获得/消耗"的方向。

**例 2**：兔摄入 100 kJ 能量，粪便中含 20 kJ，呼吸散失 50 kJ。兔的同化量是多少？粪便能量属于哪一营养级？
**解析**：同化量 = 摄入量 − 粪便量 = 100 − 20 = **80 kJ**；用于生长发育繁殖的能量 = 80 − 50 = 30 kJ。粪便中的能量是**未被同化**的部分，属于**上一营养级（草）**的同化量中"流向分解者"的部分，不能计入兔。

## 易错点

- 摄入量 ≠ 同化量：粪便能量属于上一营养级；**尿液**中能量属于本营养级同化量。
- 传递效率是**相邻营养级同化量之比**，不是个体之间或摄入量之比。
- 能量金字塔永远正立；**数量金字塔可以倒置**（一棵树上很多昆虫）。
- 能量流动单向不循环，热能不能被生产者再固定；"能量多级利用"提高利用率，但**不能提高相邻营养级间的传递效率**。

## 背记要点

1. 起点：生产者固定太阳能；总能量 = 生产者固定的太阳能总量。
2. 同化量去向四分法：呼吸散失 + 流入下一营养级 + 流向分解者 + 未利用（定时间内）。
3. 特点：单向流动、逐级递减；效率 10%~20%——"最多 ×20%、最少 ×10%"计算模板必须熟练。
4. 能量金字塔正立，营养级一般不超过 4~5 个（能量不足以支持更高营养级）。
5. 应用：桑基鱼塘多级利用、合理载畜量、农田除草除虫使能量流向对人类有益的部分——高考应用题高频。
