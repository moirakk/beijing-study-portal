# 第三节 动物细胞

标签：#动物细胞 #细胞结构 #临时装片

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第二章 认识细胞 · 第三节**。本节学习动物细胞的基本结构，并与植物细胞进行对比，掌握制作人口腔上皮细胞临时装片的方法。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 细胞膜 | 细胞最外层，控制物质进出，保护细胞 |
| 细胞质 | 细胞膜以内、细胞核以外的部分 |
| 细胞核 | 含有遗传物质，控制细胞生命活动 |
| 线粒体 | 呼吸作用的主要场所，为细胞供能 |

## 三、知识梳理

### 1. 动物细胞的基本结构

动物细胞的基本结构包括**细胞膜、细胞质、细胞核**，细胞质中有**线粒体**。

| 结构 | 功能 |
|---|---|
| 细胞膜 | 保护细胞，控制物质进出 |
| 细胞质 | 细胞代谢的主要场所 |
| 细胞核 | 含有遗传物质，是细胞的控制中心 |
| 线粒体 | 呼吸作用的主要场所，释放能量 |

### 2. 制作人的口腔上皮细胞临时装片

步骤可概括为：**擦 → 滴 → 刮 → 涂 → 盖 → 染 → 吸**。

- 擦：擦净载玻片和盖玻片。
- 滴：在载玻片中央滴一滴**生理盐水**（0.9%氯化钠溶液），维持细胞正常形态。
- 刮：用消毒牙签在口腔内侧壁上轻刮几下。
- 涂：将牙签上的碎屑涂抹在生理盐水中。
- 盖：用镊子夹起盖玻片，一侧先接触液滴，缓缓放下。
- 染：在盖玻片一侧滴加稀碘液。
- 吸：用吸水纸从另一侧吸引。

### 3. 动植物细胞结构的比较

| 结构 | 植物细胞 | 动物细胞 |
|---|---|---|
| 细胞壁 | 有 | 无 |
| 叶绿体 | 绿色部分有 | 无 |
| 液泡 | 成熟细胞有大液泡 | 一般无大液泡 |
| 细胞膜 | 有 | 有 |
| 细胞质 | 有 | 有 |
| 细胞核 | 有 | 有 |
| 线粒体 | 有 | 有 |

## 四、背记要点

1. 动物细胞的基本结构：细胞膜、细胞质、细胞核。
2. 动物细胞没有细胞壁、叶绿体和大液泡。
3. 动植物细胞共有的结构：细胞膜、细胞质、细胞核、线粒体。
4. 制作口腔上皮细胞临时装片时，应滴加生理盐水，目的是保持细胞正常形态。
5. 染色用稀碘液，便于观察细胞核。

## 五、自测小题

1. 动物细胞的基本结构包括______、______、______。
2. 与植物细胞相比，动物细胞没有______、______和______。
3. 制作人口腔上皮细胞临时装片时，载玻片中央滴加的是______。
4. 动植物细胞都有的能量转换器是______。
5. 植物细胞特有的能量转换器是______。
6. 判断：动物细胞和植物细胞都有细胞膜、细胞质和细胞核。（对/错）

**答案**：1. 细胞膜；细胞质；细胞核 2. 细胞壁；叶绿体；大液泡 3. 生理盐水 4. 线粒体 5. 叶绿体 6. 对
