# 第二节 植物细胞

标签：#植物细胞 #细胞结构 #临时装片

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第二章 认识细胞 · 第二节**。本节学习植物细胞的基本结构，并通过制作临时装片观察植物细胞。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 细胞壁 | 植物细胞最外层，起保护和支持作用 |
| 细胞膜 | 紧贴细胞壁内侧，控制物质进出 |
| 细胞质 | 细胞膜以内、细胞核以外的部分，是代谢主要场所 |
| 细胞核 | 含有遗传物质，是细胞的控制中心 |
| 液泡 | 成熟植物细胞中有大液泡，内含细胞液 |
| 叶绿体 | 进行光合作用的场所，含叶绿素 |
| 线粒体 | 进行呼吸作用，为细胞提供能量 |

植物细胞主要由**细胞壁、细胞膜、细胞质、细胞核**构成，细胞质中还有**液泡、叶绿体、线粒体**等结构。

| 结构 | 功能 |
|---|---|
| 细胞壁 | 保护和支持细胞，维持细胞形态 |
| 细胞膜 | 控制物质进出，保护作用 |
| 细胞质 | 细胞代谢的主要场所，缓缓流动促进物质交换 |
| 细胞核 | 含有遗传物质，控制细胞生命活动 |
| 液泡 | 储存细胞液，含糖类、无机盐、色素、蛋白质等 |
| 叶绿体 | 光合作用的场所，将光能转化为化学能 |
| 线粒体 | 呼吸作用的主要场所，释放能量供生命活动 |

### 2. 制作洋葱鳞片叶内表皮细胞临时装片

步骤可概括为：**擦 → 滴 → 撕 → 展 → 盖 → 染 → 吸**。

- 擦：用纱布擦净载玻片和盖玻片。
- 滴：在载玻片中央滴一滴**清水**。
- 撕：用镊子从洋葱鳞片叶内侧撕取一小块透明薄膜。
- 展：将薄膜在清水中展平，防止细胞重叠。
- 盖：用镊子夹起盖玻片，使它的一侧先接触水滴，然后缓缓放下，避免产生气泡。
- 染：在盖玻片的一侧滴加**碘液**。
- 吸：用吸水纸从另一侧吸引，使染液浸润标本全部。

## 四、易混辨析

| 对比项 | 细胞壁 | 细胞膜 |
|---|---|---|
| 位置 | 细胞最外层 | 紧贴细胞壁内侧 |
| 功能 | 保护和支持 | 控制物质进出 |
| 透光性 | 全透性 | 选择透过性 |

## 五、背记要点

1. 植物细胞的基本结构：细胞壁、细胞膜、细胞质、细胞核、液泡、叶绿体、线粒体。
2. 细胞壁起保护和支持作用；细胞膜控制物质进出。
3. 细胞核含有遗传物质，是细胞的控制中心。
4. 叶绿体是光合作用场所，线粒体是呼吸作用主要场所。
5. 制作洋葱表皮临时装片步骤：擦、滴、撕、展、盖、染、吸。
6. 盖盖玻片时要一侧先接触水滴，缓缓放下，防止产生气泡。

## 六、自测小题

1. 植物细胞最外层起保护和支持作用的结构是______。
2. 控制物质进出细胞的结构是______。
3. 植物细胞中进行光合作用的场所是______，进行呼吸作用的主要场所是______。
4. 制作洋葱鳞片叶内表皮临时装片的步骤可概括为______。
5. 染色时通常使用______，在盖玻片一侧滴加，另一侧用吸水纸吸引。
6. 判断：所有植物细胞都含有叶绿体。（对/错）

**答案**：1. 细胞壁 2. 细胞膜 3. 叶绿体；线粒体 4. 擦→滴→撕→展→盖→染→吸 5. 碘液 6. 错（如洋葱表皮细胞、根部细胞无叶绿体）
