# 第二节 动物体的结构层次

标签：#结构层次 #组织 #器官 #系统

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第三章 从细胞到生物体 · 第二节**。本节学习动物体从细胞到组织、器官、系统、个体的结构层次。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 细胞分化 | 在个体发育中，一个或一种细胞通过分裂产生的后代，在形态、结构和功能上发生差异的过程 |
| 组织 | 形态相似，结构、功能相同的细胞联合在一起形成的细胞群 |
| 器官 | 由不同的组织按照一定的次序结合在一起构成的行使一定功能的结构 |
| 系统 | 能够共同完成一种或几种生理功能的多个器官按照一定次序组合在一起 |

## 三、知识梳理

### 1. 细胞分化形成组织

- 受精卵经过细胞分裂产生新细胞。
- 一部分细胞保持分裂能力，另一部分细胞在形态、结构和功能上发生差异，形成不同的组织，这一过程叫**细胞分化**。

### 2. 动物体的基本组织

| 组织名称 | 主要功能 | 分布举例 |
|---|---|---|
| 上皮组织 | 保护、分泌 | 皮肤表皮、消化道内壁 |
| 肌肉组织 | 收缩和舒张，产生运动 | 骨骼肌、心肌、平滑肌 |
| 神经组织 | 感受刺激、传导神经冲动 | 脑、脊髓、神经 |
| 结缔组织 | 支持、连接、保护、营养 | 骨、血液、脂肪、肌腱 |

### 3. 组织构成器官，器官构成系统

- **器官**：不同组织按一定次序结合，如心脏、胃、肺、肾等。
- **系统**：多个器官按一定次序组合，共同完成一种或几种生理功能。

### 4. 动物体的结构层次

**细胞 → 组织 → 器官 → 系统 → 动物体**

人体八大系统：运动系统、消化系统、呼吸系统、循环系统、泌尿系统、神经系统、内分泌系统、生殖系统。

## 四、背记要点

1. 细胞分化形成组织。
2. 动物体有四种基本组织：上皮组织、肌肉组织、神经组织、结缔组织。
3. 器官由不同组织构成，系统由多个器官构成。
4. 动物体的结构层次：细胞 → 组织 → 器官 → 系统 → 动物体。
5. 人体有八大系统，各系统既有分工又相互协调，使人体成为统一整体。

## 五、自测小题

1. 在个体发育中，细胞在形态、结构和功能上发生差异的过程叫______。
2. 动物体的四种基本组织是______、______、______、______。
3. 由不同组织按一定次序结合形成的结构叫______。
4. 动物体的结构层次可表示为：细胞 → ______ → ______ → ______ → 动物体。
5. 人体内具有收缩和舒张功能的组织是（A. 上皮组织 B. 肌肉组织 C. 神经组织）。
6. 判断：一个器官只由一种组织构成。（对/错）

**答案**：1. 细胞分化 2. 上皮组织；肌肉组织；神经组织；结缔组织 3. 器官 4. 组织；器官；系统 5. B 6. 错（由多种组织构成）
