# 第四节 单细胞生物

标签：#单细胞生物 #草履虫 #应激性

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第三章 从细胞到生物体 · 第四节**。本节认识只有一个细胞构成的生物，了解其结构和生活特点，以草履虫为例理解单细胞生物能独立完成生命活动。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 单细胞生物 | 整个身体只由一个细胞构成的生物 |
| 纤毛 | 草履虫体表细小的毛，用于运动 |
| 表膜 | 草履虫体表，进行气体交换 |
| 食物泡 | 消化食物的场所 |
| 伸缩泡 | 排出体内多余水分和废物 |
| 应激性 | 生物对外界刺激作出反应的特性 |

## 三、知识梳理

### 1. 单细胞生物的特点

- 身体只由**一个细胞**构成。
- 一个细胞就能完成**营养、呼吸、排泄、运动、生殖、应激**等全部生命活动。
- 常见单细胞生物：酵母菌、草履虫、衣藻、眼虫、变形虫、细菌等。

### 3. 单细胞生物与人类的关系

- **有利**：许多浮游单细胞生物是鱼类的天然饵料；草履虫可净化污水；酵母菌用于发酵。
- **有害**：某些单细胞生物大量繁殖会引起赤潮、水华；疟原虫、痢疾内变形虫等会危害人体健康。

## 四、背记要点

1. 单细胞生物整个身体由一个细胞构成，能独立完成各项生命活动。
2. 草履虫靠纤毛运动，靠表膜呼吸，靠口沟取食，靠食物泡消化。
3. 草履虫具有应激性，能对外界刺激作出反应，趋向有利刺激，逃避有害刺激。
4. 单细胞生物与人类关系密切，既有有利一面，也有有害一面。
5. 草履虫通过分裂进行繁殖。

## 五、自测小题

1. 整个身体只由一个细胞构成的生物叫______。
2. 草履虫靠______在水中运动，靠______进行呼吸。
3. 草履虫摄取食物的结构是______，消化食物的结构是______。
4. 草履虫排出食物残渣的结构是______。
5. 草履虫具有______，能对外界刺激作出反应。
6. 判断：单细胞生物不能独立完成生命活动，必须依赖其他生物。（对/错）

**答案**：1. 单细胞生物 2. 纤毛；表膜 3. 口沟；食物泡 4. 胞肛 5. 应激性 6. 错
