# 综合实践项目：制作细胞模型

标签：#细胞模型 #实践活动 #细胞结构

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第三章 从细胞到生物体** 综合实践项目。通过动手制作细胞模型，加深对细胞各结构形态和功能的理解。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 物理模型 | 以实物或图画形式直观表达认识对象特征的模型 |
| 细胞模型 | 用不同材料模拟细胞各结构的模型 |
| 科学性 | 模型应准确反映细胞结构的大小、形态和位置关系 |
| 美观性 | 模型应布局合理、色彩协调、标注清晰 |

## 三、知识梳理

### 1. 制作细胞模型的目的

- 直观认识细胞的**基本结构**。
- 理解细胞各结构的**位置关系**和**相对大小**。
- 培养动手实践能力、空间想象能力和科学表达能力。

### 2. 植物细胞模型应包含的结构

| 结构 | 可选材料 | 说明 |
|---|---|---|
| 细胞壁 | 硬纸板、塑料盒 | 最外层，起支持作用 |
| 细胞膜 | 透明薄膜、保鲜膜 | 紧贴细胞壁内侧 |
| 细胞核 | 乒乓球、橡皮泥球 | 颜色较深，位于细胞质中 |
| 细胞质 | 果冻、琼脂、面团 | 填充细胞内部 |
| 液泡 | 大气球或透明塑料袋装水 | 成熟植物细胞中有大液泡 |
| 叶绿体 | 绿色橡皮泥、绿豆 | 绿色部分细胞才有 |
| 线粒体 | 黄色或橙色橡皮泥 | 较小，数量较多 |

### 3. 动物细胞模型应包含的结构

- 细胞膜、细胞质、细胞核、线粒体。
- 动物细胞无细胞壁、叶绿体和大液泡。

### 4. 制作步骤

1. 确定制作**植物细胞**还是**动物细胞**模型。
2. 选择合适材料，注意结构的大小比例和位置关系。
3. 制作各结构，并在模型上标注名称。
4. 展示交流，说明模型中各结构的功能。

## 四、背记要点

1. 制作细胞模型要体现科学性和美观性，结构位置、大小关系要准确。
2. 植物细胞模型要包括：细胞壁、细胞膜、细胞质、细胞核、液泡、叶绿体、线粒体。
3. 动物细胞模型要包括：细胞膜、细胞质、细胞核、线粒体。
4. 模型是科学研究中常用的方法，能帮助我们直观理解抽象结构。

## 五、自测小题

1. 制作细胞模型属于科学探究中的______方法。
2. 植物细胞最外层应制作的结构是______。
3. 动物细胞模型不需要制作的结构有______、______和______。
4. 模型中的细胞核一般用颜色较______的材料表示。
5. 制作模型时，结构的大小和______关系要尽量准确。
6. 判断：制作细胞模型时，可以随意改变各结构的相对大小。（对/错）

**答案**：1. 模型（或物理模型） 2. 细胞壁 3. 细胞壁；叶绿体；大液泡 4. 深 5. 位置 6. 错
