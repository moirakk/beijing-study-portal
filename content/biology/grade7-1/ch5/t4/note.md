# 三 鸟和哺乳动物

标签：#鸟 #哺乳动物 #恒温动物 #脊椎动物

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第二章 动物的类群 · 第二节 脊椎动物 · 三 鸟和哺乳动物**。本节学习鸟类和哺乳动物的主要特征，以及它们对环境的适应。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 恒温动物 | 体温不随环境温度变化而改变的动物 |
| 变温动物 | 体温随环境温度变化而改变的动物 |
| 双重呼吸 | 鸟类每呼吸一次，在肺里进行两次气体交换 |
| 气囊 | 鸟类体内辅助呼吸、减轻身体比重、散热的结构 |
| 胎生 | 胚胎在母体子宫内发育，通过胎盘从母体获得营养 |
| 哺乳 | 母体用乳汁哺育幼崽 |

## 三、知识梳理

### 1. 鸟类

- **主要特征**：体表覆羽；前肢变成**翼**；有喙无齿；有**气囊**辅助肺呼吸。
- **适于飞行的特点**：
  - 身体呈**流线型**，减少空气阻力。
  - 前肢变成翼，翼上生有大型的羽毛。
  - 骨骼轻、薄、坚固，有些骨内部中空。
  - 胸骨有发达的龙骨突，附着发达的胸肌。
  - 食量大，消化能力强，直肠短，减轻体重。
  - 呼吸方式为双重呼吸，气囊辅助散热和减轻体重。

### 2. 哺乳动物

- **主要特征**：体表被毛；**胎生、哺乳**；牙齿有门齿、犬齿和臼齿的分化。
- **代表动物**：人、猫、狗、牛、羊、鲸、蝙蝠等。
- **与人类关系**：提供肉、奶、毛皮等；帮助运输、看家护院；有些传播疾病。

### 3. 恒温动物与变温动物

| 类型 | 代表类群 | 特点 |
|---|---|---|
| 恒温动物 | 鸟类、哺乳类 | 体温恒定，增强了对环境的适应能力 |
| 变温动物 | 鱼、两栖动物、爬行动物、无脊椎动物 | 体温随环境变化 |

## 四、背记要点

1. 鸟类的主要特征：体表覆羽、前肢变成翼、有喙无齿、有气囊辅助呼吸。
2. 鸟类适于飞行的特点：流线型身体、翼、轻而坚固的骨骼、发达的胸肌、双重呼吸等。
3. 哺乳动物的主要特征：体表被毛、胎生哺乳、牙齿分化。
4. 胎生哺乳大大提高了后代的成活率。
5. 鸟类和哺乳类是恒温动物，增强了适应环境的能力。

## 五、自测小题

1. 鸟类前肢变成______，体表覆______。
2. 鸟类呼吸时，______辅助肺进行______呼吸。
3. 哺乳动物的主要特征是体表被毛、______、______。
4. 下列属于哺乳动物的是（A. 企鹅 B. 蝙蝠 C. 鳄鱼）。
5. 体温恒定的动物类群有______和______。
6. 判断：鸟类和哺乳类都是恒温动物。（对/错）

**答案**：1. 翼；羽 2. 气囊；双重 3. 胎生；哺乳 4. B 5. 鸟类；哺乳类 6. 对
