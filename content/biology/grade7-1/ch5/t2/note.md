# 一 鱼

标签：#鱼 #脊椎动物 #水生生活

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第二章 动物的类群 · 第二节 脊椎动物 · 一 鱼**。本节学习鱼类的主要特征、形态结构与生活环境的适应关系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 脊柱 | 由许多脊椎骨组成的结构，支撑身体 |
| 鳃 | 鱼的呼吸器官，用于在水中进行气体交换 |
| 鳍 | 鱼的运动和平衡器官 |
| 侧线 | 鱼身体两侧的感觉器官，能感知水流方向和水压 |
| 流线型 | 身体形状有利于减少在水中运动时的阻力 |

## 三、知识梳理

### 1. 鱼类的共同特征

- 生活在水中。
- 体表常有**鳞片**覆盖。
- 用**鳃**呼吸。
- 通过**尾部和躯干部的摆动**以及**鳍的协调作用**游泳。

### 2. 鱼适于水中生活的形态结构

| 结构 | 适应功能 |
|---|---|
| 流线型身体 | 减少水的阻力 |
| 体表有黏液、鳞片 | 保护身体，减少阻力 |
| 鳃 | 吸收水中的溶解氧 |
| 鳍 | 维持平衡、控制方向、产生动力 |
| 侧线 | 感知水流、测定方向 |

### 3. 鱼的主要类群

- **淡水鱼**：鲫鱼、鲤鱼、草鱼、青鱼、鲢鱼、鳙鱼等。
- **海水鱼**：带鱼、大黄鱼、小黄鱼、鲨鱼、鲳鱼等。

### 4. 鱼与人类的关系

- 鱼类是人类重要的**蛋白质来源**。
- 有些鱼可观赏（金鱼、热带鱼）。
- 有些鱼可入药或加工成工业原料。
- 应合理捕捞，保护渔业资源和水域环境。

## 四、背记要点

1. 鱼生活在水中，体表常有鳞片覆盖，用鳃呼吸，用鳍游泳。
2. 鱼的运动主要靠尾部和躯干部的摆动以及鳍的协调作用。
3. 鳃是鱼的呼吸器官，鳃丝中密布毛细血管，有利于气体交换。
4. 侧线能感知水流方向和测定方向。
5. 我国淡水鱼中的"四大家鱼"是青鱼、草鱼、鲢鱼、鳙鱼。

## 五、自测小题

1. 鱼生活在______中，用______呼吸，用______游泳。
2. 鱼体表常有______覆盖，能保护身体和减少阻力。
3. 鱼的运动主要靠______和______的摆动以及______的协调作用。
4. 鱼的呼吸器官是______，其中密布毛细血管，有利于气体交换。
5. 下列不属于鱼类的是（A. 鲫鱼 B. 鲸鱼 C. 带鱼）。
6. 判断：鱼离开水后，鳃丝会粘连，导致无法呼吸而死亡。（对/错）

**答案**：1. 水；鳃；鳍 2. 鳞片 3. 尾部；躯干部；鳍 4. 鳃 5. B（鲸鱼是哺乳动物） 6. 对
