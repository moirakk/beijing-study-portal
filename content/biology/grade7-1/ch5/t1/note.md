# 第一节 无脊椎动物

标签：#无脊椎动物 #节肢动物 #环节动物

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第二章 动物的类群 · 第一节**。本节学习体内没有脊柱的动物——无脊椎动物，了解其主要类群和代表动物。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 无脊椎动物 | 体内没有由脊椎骨组成的脊柱的动物 |
| 脊椎动物 | 体内有由脊椎骨组成的脊柱的动物 |
| 刺胞动物 | 身体呈辐射对称，有刺细胞，有口无肛门 |
| 扁形动物 | 身体呈两侧对称，背腹扁平，有口无肛门 |
| 线虫动物 | 身体细长，呈圆柱形，有口有肛门 |
| 环节动物 | 身体由许多彼此相似的体节组成 |
| 节肢动物 | 身体和附肢都分节，体表有外骨骼 |

## 三、知识梳理

### 1. 无脊椎动物主要类群

| 类群 | 主要特征 | 代表动物 |
|---|---|---|
| 刺胞动物 | 辐射对称，有刺细胞，有口无肛门 | 水螅、海蜇、海葵、珊瑚虫 |
| 扁形动物 | 两侧对称，背腹扁平，有口无肛门 | 涡虫、绦虫、血吸虫 |
| 线虫动物 | 身体细长，呈圆柱形，有口有肛门 | 蛔虫、蛲虫、秀丽隐杆线虫 |
| 环节动物 | 身体分节，有刚毛或疣足辅助运动 | 蚯蚓、沙蚕、水蛭 |
| 软体动物 | 身体柔软，多有贝壳，有外套膜 | 河蚌、蜗牛、乌贼、鲍鱼 |
| 节肢动物 | 身体和附肢分节，体表有外骨骼 | 蝗虫、蜘蛛、虾、蟹、蝴蝶 |

### 2. 节肢动物的主要特征

- 体表有坚韧的**外骨骼**，能保护和支持内部结构，防止体内水分蒸发。
- **身体和附肢都分节**，使运动更加灵活。
- 节肢动物是动物界中种类最多、数量最大、分布最广的类群。

### 3. 无脊椎动物与人类的关系

- 有益：蚯蚓疏松土壤；蜜蜂传粉；虾蟹食用；珍珠、蚕丝等。
- 有害：蛔虫、血吸虫等寄生致病；蝗虫危害农作物。

## 四、背记要点

1. 根据体内有无脊柱，动物分为无脊椎动物和脊椎动物。
2. 无脊椎动物包括刺胞动物、扁形动物、线虫动物、环节动物、软体动物、节肢动物等。
3. 节肢动物的主要特征：体表有外骨骼，身体和附肢都分节。
4. 节肢动物是动物界中种类最多、数量最大、分布最广的类群。
5. 蚯蚓属于环节动物，蝗虫、蜘蛛、虾属于节肢动物。

## 五、自测小题

1. 根据体内有无______，动物可分为无脊椎动物和脊椎动物。
2. 节肢动物体表有______，身体和附肢都______。
3. 身体由许多彼此相似的体节组成的动物类群是______。
4. 下列动物中属于节肢动物的是（A. 蚯蚓 B. 蝗虫 C. 水螅）。
5. 有口无肛门的动物类群有______和______（写出两类）。
6. 判断：软体动物身体柔软，大多有贝壳保护。（对/错）

**答案**：1. 脊柱 2. 外骨骼；分节 3. 环节动物 4. B 5. 刺胞动物；扁形动物 6. 对
