# 第四节 病毒

标签：#病毒 #寄生 #遗传物质 #疫苗

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第三章 微生物 · 第四节**。本节学习病毒的结构、生活方式、分类及与人类的关系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 病毒 | 没有细胞结构，由蛋白质外壳和内部遗传物质组成的微生物 |
| 寄生 | 一种生物生活在另一种生物体内或体表，从中获取营养 |
| 宿主 | 被病毒寄生的活细胞或生物体 |
| 遗传物质 | 病毒内部的 DNA 或 RNA |
| 疫苗 | 用减毒或灭活的病原微生物制成的生物制品 |

- 病毒**没有细胞结构**，结构简单。
- 由**蛋白质外壳**和内部的**遗传物质**组成。
- 病毒个体极其微小，必须用电子显微镜才能观察到。

### 2. 病毒的生活方式

- 病毒不能独立生活，必须**寄生**在活细胞内。
- 病毒离开活细胞后，会变成**结晶体**，失去生命活动能力。
- 一旦侵入活细胞，病毒会利用细胞内的物质进行繁殖。

### 3. 病毒的分类

| 分类依据 | 类型 | 举例 |
|---|---|---|
| 寄生细胞不同 | 动物病毒 | 流感病毒、新冠病毒、狂犬病毒 |
| | 植物病毒 | 烟草花叶病毒 |
| | 细菌病毒（噬菌体） | 大肠杆菌噬菌体 |
| 遗传物质不同 | DNA 病毒 | 乙肝病毒 |
| | RNA 病毒 | 流感病毒、新冠病毒 |

### 4. 病毒与人类的关系

- **有害**：引起流感、艾滋病、新冠肺炎、手足口病等多种疾病。
- **有利**：利用病毒研制疫苗预防疾病；利用噬菌体治疗细菌感染；在基因工程中作为载体。

## 四、背记要点

1. 病毒没有细胞结构，由蛋白质外壳和内部遗传物质组成。
2. 病毒不能独立生活，必须寄生在活细胞内。
3. 病毒离开活细胞后形成结晶体，侵入活细胞后恢复生命活动。
4. 根据寄生细胞不同，病毒分为动物病毒、植物病毒和细菌病毒（噬菌体）。
5. 病毒能引起疾病，也可用于研制疫苗、基因工程等。

## 五、自测小题

1. 病毒没有______结构，由______外壳和内部的遗传物质组成。
2. 病毒必须______在活细胞内才能生活。
3. 专门寄生在细菌细胞内的病毒叫______。
4. 新冠病毒属于______病毒（按寄生细胞分）。
5. 下列关于病毒的说法正确的是（A. 能独立生活 B. 有细胞结构 C. 必须寄生在活细胞内）。
6. 判断：病毒对人类都是有害的。（对/错）

**答案**：1. 细胞；蛋白质 2. 寄生 3. 噬菌体 4. 动物 5. C 6. 错（可研制疫苗、基因工程等）
