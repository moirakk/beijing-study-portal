# 第三节 真菌

标签：#真菌 #酵母菌 #霉菌 #蘑菇

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第三章 微生物 · 第三节**。本节学习真菌的种类、结构、生殖方式及与人类的关系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 真菌 | 一类具有成形细胞核、细胞内没有叶绿体的生物 |
| 酵母菌 | 单细胞真菌，常用于发酵 |
| 霉菌 | 多细胞真菌，由菌丝构成，如青霉、曲霉 |
| 蘑菇 | 大型多细胞真菌，由地下菌丝体和地上子实体组成 |
| 孢子 | 真菌的生殖细胞，在适宜环境中萌发成新个体 |
| 真核生物 | 细胞内有成形细胞核的生物 |

## 三、知识梳理

### 1. 真菌的种类

- **单细胞真菌**：如酵母菌。
- **多细胞真菌**：如霉菌（青霉、曲霉）、蘑菇、木耳等。

### 2. 真菌的结构

| 结构 | 功能 |
|---|---|
| 细胞壁 | 保护和支持 |
| 细胞膜 | 控制物质进出 |
| 细胞质 | 代谢场所 |
| 细胞核 | 含有遗传物质，有成形细胞核 |
| 液泡 | 储存营养物质 |
| 菌丝 | 多细胞真菌由菌丝构成，吸收营养物质 |

- 真菌细胞内有成形的细胞核，属于**真核生物**。
- 真菌细胞内**没有叶绿体**，不能进行光合作用，营养方式为**异养**。

### 3. 真菌的生殖

- 酵母菌在环境适宜时进行**出芽生殖**，环境不良时进行**孢子生殖**。
- 霉菌和蘑菇主要通过产生**孢子**繁殖后代。
- 孢子轻而小，可随风飘散，在适宜环境中萌发。

### 4. 真菌与人类的关系

- **有利**：酵母菌酿酒、发面；青霉产生青霉素；蘑菇、木耳可食用。
- **有害**：有些霉菌引起食物霉变；有些真菌引起人或动植物患病。

## 四、背记要点

1. 真菌有单细胞（酵母菌）和多细胞（霉菌、蘑菇）两类。
2. 真菌有成形的细胞核，属于真核生物，细胞内无叶绿体，营养方式为异养。
3. 酵母菌可进行出芽生殖和孢子生殖；霉菌、蘑菇主要靠孢子繁殖。
4. 蘑菇由地下菌丝体和地上子实体组成，子实体产生孢子。
5. 真菌与人类关系密切，可用于食品、医药，也有些会致病或使食物腐烂。

## 五、自测小题

1. 单细胞真菌的代表是______，多细胞真菌的代表有______、______等。
2. 真菌细胞内没有______，因此不能进行光合作用，营养方式为______。
3. 真菌的生殖细胞叫______。
4. 产生青霉素的是______菌。
5. 下列属于真菌的是（A. 乳酸菌 B. 酵母菌 C. 大肠杆菌）。
6. 判断：蘑菇是植物，能进行光合作用。（对/错）

**答案**：1. 酵母菌；霉菌；蘑菇 2. 叶绿体；异养 3. 孢子 4. 青霉 5. B 6. 错（蘑菇是真菌，不能光合作用）
