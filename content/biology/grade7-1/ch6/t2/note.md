# 第二节 细菌

标签：#细菌 #原核生物 #分裂生殖

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第三章 微生物 · 第二节**。本节学习细菌的形态结构、生殖方式及与人类的关系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 细菌 | 个体微小、单细胞的原核生物 |
| 原核生物 | 细胞内没有成形的细胞核的生物 |
| 荚膜 | 细菌细胞壁外的一层黏性物质，起保护作用 |
| 鞭毛 | 细菌体表细长的丝状物，有助于运动 |
| 芽孢 | 细菌在不良环境下形成的休眠体，对高温、干旱等有很强的抵抗力 |
| 分裂生殖 | 一个细菌分裂成两个细菌的生殖方式 |

## 三、知识梳理

### 1. 细菌的形态

- 根据形态不同，细菌可分为**球菌、杆菌、螺旋菌**等。
- 细菌个体十分微小，通常只有用高倍显微镜或电子显微镜才能观察到。

### 2. 细菌的结构

| 结构 | 功能 |
|---|---|
| 细胞壁 | 保护和支持 |
| 细胞膜 | 控制物质进出 |
| 细胞质 | 代谢场所 |
| DNA 集中区域 | 含有遗传物质，无成形细胞核 |
| 荚膜（部分有） | 保护 |
| 鞭毛（部分有） | 运动 |

- 细菌虽有 DNA 集中的区域，但**没有成形的细胞核**，属于**原核生物**。

### 3. 细菌的生殖

- 细菌通过**分裂生殖**繁殖后代，繁殖速度极快。
- 在适宜条件下，有些细菌每 20-30 分钟就能分裂一次。
- 环境不良时，细菌可形成**芽孢**，芽孢是细菌的休眠体，不是生殖细胞。

### 4. 细菌与人类的关系

- **有利**：乳酸菌制作酸奶、泡菜；醋酸菌制醋；根瘤菌固氮；有些细菌可净化污水、生产药物。
- **有害**：结核杆菌、链球菌等引起疾病；有些细菌使食物腐败变质。

## 四、背记要点

1. 细菌是单细胞原核生物，没有成形的细胞核。
2. 细菌按形态分为球菌、杆菌、螺旋菌。
3. 细菌通过分裂生殖繁殖，繁殖速度快。
4. 芽孢是细菌的休眠体，不是生殖细胞，对不良环境抵抗力强。
5. 细菌与人类关系密切，既有有益菌也有有害菌。

## 五、自测小题

1. 细菌根据形态可分为______、______、______。
2. 细菌细胞内没有成形的______，属于______生物。
3. 细菌通过______方式繁殖后代。
4. 细菌在不良环境下形成的休眠体叫______。
5. 制作酸奶利用的细菌是（A. 醋酸菌 B. 乳酸菌 C. 酵母菌）。
6. 判断：芽孢是细菌的生殖细胞。（对/错）

**答案**：1. 球菌；杆菌；螺旋菌 2. 细胞核；原核 3. 分裂生殖 4. 芽孢 5. B 6. 错（是休眠体）
