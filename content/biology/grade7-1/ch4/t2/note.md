# 第二节 种子植物

标签：#种子植物 #裸子植物 #被子植物 #种子结构

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第一章 植物的类群 · 第二节**。本节学习种子植物的主要特征，种子的基本结构，以及裸子植物和被子植物的区别。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 种子植物 | 用种子繁殖后代的植物，包括裸子植物和被子植物 |
| 裸子植物 | 种子裸露，外面没有果皮包被的植物 |
| 被子植物 | 种子外面有果皮包被的植物 |
| 胚 | 新植物的幼体，由胚芽、胚轴、胚根和子叶组成 |
| 子叶 | 储存或转运营养物质的结构 |
| 胚乳 | 种子中储存营养物质的结构 |

## 三、知识梳理

### 1. 种子的结构

| 结构 | 功能 |
|---|---|
| 种皮 | 保护胚 |
| 胚 | 新植物的幼体，是种子的主要部分 |
| 胚芽 | 发育成茎和叶 |
| 胚轴 | 发育成连接根和茎的部分 |
| 胚根 | 发育成根 |
| 子叶 | 储存或转运营养物质 |
| 胚乳 | 储存营养物质（部分种子有） |

### 2. 菜豆种子与玉米种子的比较

| 比较项目 | 菜豆种子 | 玉米种子 |
|---|---|---|
| 子叶数目 | 两片（双子叶植物） | 一片（单子叶植物） |
| 胚乳 | 无 | 有 |
| 营养储存 | 子叶 | 胚乳 |
| 相同点 | 都有种皮和胚 | 都有种皮和胚 |

### 3. 裸子植物和被子植物

| 比较项目 | 裸子植物 | 被子植物 |
|---|---|---|
| 种子包被 | 裸露，无果皮包被 | 有果皮包被，形成果实 |
| 常见代表 | 松、柏、杉、银杏、苏铁 | 桃、苹果、小麦、水稻、玉米 |
| 器官分化 | 根、茎、叶、种子 | 根、茎、叶、花、果实、种子 |
| 适应环境 | 较干旱、寒冷环境 | 分布广泛，适应性强 |

## 四、背记要点

1. 种子植物用种子繁殖，包括裸子植物和被子植物。
2. 胚是种子的主要部分，是新植物的幼体，由胚芽、胚轴、胚根、子叶组成。
3. 菜豆种子无胚乳，营养物质储存在子叶中；玉米种子有胚乳，营养物质储存在胚乳中。
4. 裸子植物种子裸露，无果皮包被；被子植物种子有果皮包被。
5. 被子植物是陆地上分布最广泛的植物类群，与人类的衣食住行关系密切。

## 五、自测小题

1. 种子植物包括______植物和______植物。
2. 种子的主要部分是______，由______、______、______和______组成。
3. 玉米种子的营养物质主要储存在______中，菜豆种子的营养物质主要储存在______中。
4. 裸子植物的种子是______的，被子植物的种子外面有______包被。
5. 下列属于裸子植物的是（A. 桃 B. 银杏 C. 小麦）。
6. 判断：被子植物比裸子植物更适应陆地生活，分布更广泛。（对/错）

**答案**：1. 裸子；被子 2. 胚；胚芽；胚轴；胚根；子叶 3. 胚乳；子叶 4. 裸露；果皮 5. B 6. 对
