# 植物的类群·重点梳理

标签：#植物类群 #孢子植物 #种子植物 #单元复习

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第一章 植物的类群** 单元小结。本章按照植物繁殖方式的不同，将植物分为孢子植物和种子植物两大类。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 孢子植物 | 用孢子繁殖的植物，包括藻类、苔藓植物、蕨类植物 |
| 种子植物 | 用种子繁殖的植物，包括裸子植物和被子植物 |
| 胚 | 新植物的幼体，种子的主要部分 |
| 果皮 | 被子植物种子外层的包被结构，由子房壁发育而来 |

## 三、知识梳理

### 1. 植物类群总览

| 类群 | 繁殖方式 | 主要特征 | 代表植物 |
|---|---|---|---|
| 藻类 | 孢子 | 无根、茎、叶分化 | 衣藻、水绵、海带、紫菜 |
| 苔藓植物 | 孢子 | 有茎、叶，无真正根，无输导组织 | 葫芦藓、地钱 |
| 蕨类植物 | 孢子 | 有根、茎、叶，有输导组织 | 肾蕨、铁线蕨、满江红 |
| 裸子植物 | 种子 | 种子裸露，无果皮包被 | 松、柏、杉、银杏 |
| 被子植物 | 种子 | 种子有果皮包被，有花、果实 | 桃、苹果、小麦、水稻 |

### 2. 各类群的进化趋势

- 从简单到复杂：藻类 → 苔藓植物 → 蕨类植物 → 种子植物。
- 从水生到陆生：藻类多水生，苔藓、蕨类、种子植物逐渐适应陆地生活。
- 从低等到高等：生殖过程越来越摆脱对水的依赖，尤其是种子植物。

### 3. 种子结构对比

| 项目 | 双子叶植物（如菜豆） | 单子叶植物（如玉米） |
|---|---|---|
| 子叶 | 两片 | 一片 |
| 胚乳 | 通常无 | 有 |
| 营养储存 | 子叶 | 胚乳 |

## 四、易错辨析

| 易错点 | 正解 |
|---|---|
| 所有植物都有根、茎、叶 | 错，藻类没有 |
| 苔藓植物有真正的根 | 错，只有假根 |
| 裸子植物没有种子 | 错，裸子植物用种子繁殖，只是种子裸露 |
| 被子植物都有果实 | 对，种子外有果皮包被形成果实 |

## 五、背记要点

1. 植物按繁殖方式分为孢子植物和种子植物。
2. 孢子植物包括藻类、苔藓植物、蕨类植物，都用孢子繁殖。
3. 种子植物包括裸子植物和被子植物，都用种子繁殖。
4. 胚是种子的主要部分，由胚芽、胚轴、胚根、子叶组成。
5. 裸子植物种子裸露，被子植物种子有果皮包被。
6. 苔藓植物可作为空气污染的指示植物。

## 六、自测小题

1. 用孢子繁殖的植物类群有______、______、______。
2. 种子植物根据种子外是否有______包被，分为裸子植物和被子植物。
3. 胚由______、______、______和______组成。
4. 可作为监测空气污染程度指示植物的是______植物。
5. 下列植物中，属于被子植物的是（A. 银杏 B. 海带 C. 苹果）。
6. 判断：蕨类植物比苔藓植物高大，是因为体内有输导组织。（对/错）

**答案**：1. 藻类；苔藓植物；蕨类植物 2. 果皮 3. 胚芽；胚轴；胚根；子叶 4. 苔藓 5. C 6. 对
