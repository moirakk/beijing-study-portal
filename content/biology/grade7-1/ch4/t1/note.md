# 第一节 藻类、苔藓和蕨类

标签：#孢子植物 #藻类 #苔藓 #蕨类

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第一章 植物的类群 · 第一节**。本节学习藻类、苔藓植物和蕨类植物的主要特征、代表植物及与人类的关系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 孢子植物 | 用孢子繁殖后代的植物，包括藻类、苔藓植物、蕨类植物 |
| 藻类 | 没有根、茎、叶分化，多生活在水中的植物 |
| 苔藓植物 | 有茎和叶的分化，但没有真正的根，只有假根 |
| 蕨类植物 | 有根、茎、叶的分化，体内有输导组织 |
| 孢子 | 一种生殖细胞，成熟后从孢子囊中散出，在适宜环境中萌发成新个体 |

## 三、知识梳理

### 1. 藻类

- **主要特征**：结构简单，没有根、茎、叶的分化；多生活在水中；含有叶绿体，能进行光合作用。
- **代表植物**：衣藻、水绵、海带、紫菜、裙带菜等。
- **与人类关系**：释放氧气；可供食用（海带、紫菜）；可提取工业原料（琼脂、碘、褐藻胶）。

### 2. 苔藓植物

- **主要特征**：有茎、叶的分化，但茎中没有导管，叶中没有叶脉；没有真正的根，只有起固定作用的**假根**；叶只有一层细胞，易受有毒气体侵害。
- **代表植物**：葫芦藓、地钱、墙藓等。
- **与人类关系**：可作为监测空气污染程度的**指示植物**；能保持水土。

### 3. 蕨类植物

- **主要特征**：有真正的根、茎、叶分化；体内有**输导组织**；长得比较高大；用孢子繁殖。
- **代表植物**：肾蕨、铁线蕨、满江红、卷柏、贯众等。
- **与人类关系**：可供观赏；可食用（蕨菜）；可药用（贯众）；古代蕨类形成煤。

## 四、易混辨析

| 植物类群 | 根 | 茎 | 叶 | 输导组织 | 生活环境 |
|---|---|---|---|---|---|
| 藻类 | 无 | 无 | 无 | 无 | 大多水中 |
| 苔藓植物 | 假根 | 有（简单） | 有（简单） | 无 | 阴湿陆地 |
| 蕨类植物 | 有 | 有 | 有 | 有 | 阴湿陆地 |

## 五、背记要点

1. 藻类没有根、茎、叶的分化，是最低等的植物类群之一。
2. 苔藓植物有茎、叶分化，但无真正的根，叶只有一层细胞，可作空气污染指示植物。
3. 蕨类植物有根、茎、叶的分化，体内有输导组织，长得比苔藓植物高大。
4. 藻类、苔藓植物、蕨类植物都用孢子繁殖，统称为孢子植物。
5. 古代高大的蕨类植物遗体经过漫长年代形成煤。

## 六、自测小题

1. 藻类植物没有______、______、______的分化。
2. 苔藓植物没有真正的根，只有起固定作用的______。
3. 可作为监测空气污染程度指示植物的是______植物。
4. 蕨类植物体内有______组织，因此能长得比较高大。
5. 下列植物中属于蕨类的是（A. 海带 B. 葫芦藓 C. 肾蕨）。
6. 判断：苔藓植物和蕨类植物都用种子繁殖。（对/错）

**答案**：1. 根；茎；叶 2. 假根 3. 苔藓 4. 输导 5. C 6. 错（用孢子繁殖）
