# 第一节 观察周边环境中的生物

标签：#认识生物 #观察法 #生物调查

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第一章 认识生物 · 第一节**。本节是初中生物学的入门课，核心是学习科学观察的基本方法，并能对身边的生物进行初步观察和记录。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 观察 | 科学探究的一种基本方法，可用肉眼，也可借助工具 |
| 生物 | 具有生命现象的物体，如动物、植物、细菌、真菌、病毒等 |
| 调查 | 对研究对象进行考察、记录、统计的科学研究方法 |

## 三、知识梳理

### 1. 观察是科学探究的基本方法

- 观察可直接用**肉眼**，也可借助**放大镜、显微镜、望远镜、照相机、摄像机**等工具。
- 有时需要**测量**，如测量植株高度、环境温度等。
- 观察要有明确的**目的**；观察时要全面、细致、实事求是；要及时**记录**；要积极思考，与他人交流。

### 2. 观察周边环境中的生物

- 步骤：确定观察目的 → 明确观察对象 → 做好观察记录 → 交流观察结果。
- 记录内容：生物的**名称**、**数量**、**生活环境**、**形态特征**、**生活习性**等。
- 观察过程中要爱护生物，**不破坏环境**，不伤害动植物。

### 3. 生物的生活环境

- 生活环境是指生物**生存的空间**以及影响其生存的各种因素。
- 按环境类型：陆地、水域、空中等。
- 影响生物生活的因素包括**非生物因素**（光、温度、水、空气等）和**生物因素**（其他生物）。

## 四、技能：如何做好观察记录

1. 提前设计**观察记录表**，列出时间、地点、天气、生物名称、数量、生活环境等项目。
2. 用文字、绘图、拍照等多种方式记录。
3. 如实记录，不凭想象填写。
4. 观察结束后及时整理、归纳、交流。

## 五、易混辨析

| 对比项 | 普通观察 | 科学观察 |
|---|---|---|
| 目的性 | 较随意 | 目的明确 |
| 工具 | 多用肉眼 | 可借助工具、测量 |
| 记录 | 不一定记录 | 必须及时、如实记录 |
| 结果处理 | 较少分析 | 需要分析、交流 |

## 六、背记要点

1. 科学探究常用的基本方法有观察法、实验法、调查法等，其中**观察法**是最基本的方法之一。
2. 观察可借助工具，如放大镜、显微镜、望远镜、照相机等。
3. 观察要有明确目的，要全面、细致、实事求是，并及时记录。
4. 观察周边环境中的生物时，要记录生物的名称、数量、生活环境、形态特征等。
5. 观察过程中要爱护生物，保护环境。

## 七、自测小题

1. 科学探究最基本的方法之一是______。
2. 观察时可直接用肉眼，也可借助______、______等工具。
3. 观察记录应做到______、______。
4. 观察周边环境中的生物时，不需要记录的是（A. 生物名称 B. 生活环境 C. 个人猜测）。
5. 生物的生活环境包括其生存的______和影响它生存的______。
6. 判断：科学观察可以随意进行，不需要明确目的。（对/错）

**答案**：1. 观察法 2. 放大镜；显微镜（或望远镜、照相机等） 3. 及时；如实 4. C 5. 空间；各种因素 6. 错
