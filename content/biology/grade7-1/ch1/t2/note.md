# 第二节 生物的特征

标签：#认识生物 #生物特征 #生命现象

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第一章 认识生物 · 第二节**。本节从现象到本质，归纳生物区别于非生物的共同特征，是判断一个物体是否为生物的依据。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 生物 | 具有生命现象的物体 |
| 非生物 | 不具有生命现象的物体 |
| 新陈代谢 | 生物体与外界环境之间物质和能量的交换，以及生物体内物质和能量的转变过程 |
| 应激性 | 生物对外界刺激作出反应的特性 |

## 三、知识梳理

### 生物的共同特征

1. **生物的生活需要营养**
   - 绿色植物通过**光合作用**自己制造有机物。
   - 动物不能自己制造有机物，必须从外界**获取食物**。

2. **生物能进行呼吸**
   - 绝大多数生物需要吸入**氧气**，呼出**二氧化碳**。
   - 有些生物可进行无氧呼吸。

3. **生物能排出身体内产生的废物**
   - 动物通过排尿、出汗、呼出气体等方式排出废物。
   - 植物通过落叶、气孔蒸腾等方式排出废物。

4. **生物能对外界刺激作出反应**
   - 例如：含羞草受到碰触叶片合拢；飞蛾扑火；草履虫逃避食盐。
   - 这种特性叫**应激性**。

5. **生物能生长、发育和繁殖**
   - 生长：体积增大、体重增加。
   - 繁殖：生物产生后代，保证种族延续。

6. **生物都有遗传和变异的特性**
   - **遗传**：亲子间的相似性，如"种瓜得瓜，种豆得豆"。
   - **变异**：亲子间或子代个体间的差异，如"一母生九子，连母十个样"。

7. **除病毒外，生物都是由细胞构成的**
   - **细胞**是生物体结构和功能的基本单位。
   - 病毒没有细胞结构，必须寄生在活细胞内才能生活和繁殖。

## 四、易混辨析

| 对比项 | 生物 | 非生物 |
|---|---|---|
| 是否需要营养 | 需要 | 不需要 |
| 能否呼吸 | 能 | 不能 |
| 能否排出废物 | 能 | 不能 |
| 能否对外界刺激作出反应 | 能 | 不能 |
| 能否生长繁殖 | 能 | 不能 |
| 是否有遗传变异 | 有 | 没有 |

## 五、背记要点

1. 判断一个物体是不是生物，主要依据其是否具有生物的共同特征。
2. 生物的生活需要营养，能进行呼吸，能排出体内废物。
3. 生物能对外界刺激作出反应，能生长、发育和繁殖。
4. 生物都有遗传和变异的特性。
5. 除病毒外，生物都是由细胞构成的；细胞是生物体结构和功能的基本单位。
6. 病毒没有细胞结构，由蛋白质外壳和内部的遗传物质组成。

## 六、自测小题

1. 生物体结构和功能的基本单位是______。
2. "种瓜得瓜，种豆得豆"说明生物具有______特性；"一母生九子，连母十个样"说明生物具有______特性。
3. 含羞草受到碰触叶片合拢，说明生物能______。
4. 下列属于生物的是（A. 机器人 B. 珊瑚虫 C. 钟乳石）。
5. 除______外，生物都是由细胞构成的。
6. 判断：所有生物都需要吸入氧气、呼出二氧化碳。（对/错）

**答案**：1. 细胞 2. 遗传；变异 3. 对外界刺激作出反应 4. B 5. 病毒 6. 错（并非所有生物都只能进行有氧呼吸）
