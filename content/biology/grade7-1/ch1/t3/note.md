# 认识生物·重点梳理

标签：#认识生物 #单元复习 #生物特征

## 一、本节定位

人教版·生物学七年级上册 **第一单元 生物和细胞 · 第一章 认识生物** 单元小结。本章从观察身边的生物入手，归纳生物的共同特征，为后续学习细胞、生物体结构层次和生物多样性奠定基础。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 观察法 | 科学探究的基本方法之一，目的明确、工具辅助、及时记录 |
| 生物 | 具有生命现象的物体 |
| 新陈代谢 | 生物体与外界进行物质和能量交换的过程 |
| 应激性 | 生物对外界刺激作出反应的能力 |

### 2. 生物的七大共同特征

| 序号 | 特征 | 典型例子 |
|---|---|---|
| 1 | 生物的生活需要营养 | 植物光合作用；动物捕食 |
| 2 | 生物能进行呼吸 | 人吸入氧气、呼出二氧化碳 |
| 3 | 生物能排出体内废物 | 排尿、出汗、落叶 |
| 4 | 生物能对外界刺激作出反应 | 含羞草叶片合拢 |
| 5 | 生物能生长、发育和繁殖 | 种子萌发、母鸡下蛋 |
| 6 | 生物都有遗传和变异的特性 | 亲子相似与差异 |
| 7 | 除病毒外，生物都由细胞构成 | 细菌、动植物由细胞构成 |

### 3. 判断生物与非生物

- 关键：是否同时具备多项生命特征。
- 注意：能运动、能长大的不一定都是生物（如机器人、钟乳石）。
- 病毒虽然没有细胞结构，但能繁殖，属于生物。

## 四、易错辨析

| 易错点 | 正解 |
|---|---|
| 能运动的物体就是生物 | 错，汽车、机器人能运动但不是生物 |
| 能长大的物体就是生物 | 错，钟乳石能长大但不是生物 |
| 所有生物都由细胞构成 | 错，病毒没有细胞结构 |
| 只有动物才能对外界刺激作出反应 | 错，植物也能，如含羞草、向光性 |

## 五、背记要点

1. 科学观察要明确目的、借助工具、及时记录、交流结果。
2. 生物的共同特征可概括为：需要营养、能呼吸、能排废、能应激、能生长繁殖、有遗传变异、由细胞构成（病毒除外）。
3. 细胞是生物体结构和功能的基本单位。
4. 病毒由蛋白质外壳和内部遗传物质组成，必须寄生在活细胞内生活。
5. 判断生物不能只看单一特征，要综合判断。

## 六、自测小题

1. 科学探究中最基本的方法之一是______。
2. 生物的共同特征有：生活需要______、能进行______、能排出______、能对外界刺激作出反应、能______和繁殖、有______和变异的特性。
3. 除______外，生物都是由细胞构成的。
4. 下列属于生物的是（A. 石头 B. 蘑菇 C. 机器人）。
5. "葵花朵朵向太阳"说明生物具有（A. 生长 B. 应激性 C. 繁殖）特征。
6. 判断：病毒没有细胞结构，所以不属于生物。（对/错）

**答案**：1. 观察法 2. 营养；呼吸；体内废物；生长、发育；遗传 3. 病毒 4. B 5. B 6. 错（病毒能繁殖，属于生物）
