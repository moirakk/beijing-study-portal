# 生物分类的方法·重点梳理

标签：#生物分类 #单元复习 #种 #界

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第四章 生物分类的方法** 单元小结。本章学习生物分类的依据、分类单位和双名法，理解分类对认识生物多样性的重要意义。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 生物分类 | 根据生物的相似程度把生物划分为不同等级 |
| 分类依据 | 形态结构、生理功能等 |
| 分类单位 | 界、门、纲、目、科、属、种 |
| 种 | 最基本的分类单位 |
| 双名法 | 林奈创立的物种命名方法 |

## 三、知识梳理

### 1. 分类依据

- 植物分类：主要依据根、茎、叶、花、果实、种子的形态结构。
- 动物分类：比较形态结构和生理功能。
- 微生物分类：依据形态结构、营养方式、生殖方式等。

### 2. 分类单位

| 等级 | 特点 |
|---|---|
| 界 | 最大分类单位，包含生物种类最多 |
| 门、纲、目、科、属 | 依次减小 |
| 种 | 最基本单位，同种生物共同特征最多、亲缘关系最近 |

### 3. 分类单位与特征、亲缘关系

```
分类单位越大 → 包含种类越多 → 共同特征越少 → 亲缘关系越远
分类单位越小 → 包含种类越少 → 共同特征越多 → 亲缘关系越近
```

### 4. 双名法

- 提出者：瑞典科学家**林奈**。
- 书写格式：属名（首字母大写）+ 种加词（小写），都用斜体。
- 例如：*Homo sapiens* 表示智人。

## 四、易错辨析

| 易错点 | 正解 |
|---|---|
| 属是最基本分类单位 | 错，最基本单位是种 |
| 分类单位越大，共同特征越多 | 错，共同特征越少 |
| 同科的生物一定同属 | 错，同科不一定同属，但同属一定同科 |
| 双名法只有种加词 | 错，由属名和种加词组成 |

## 五、背记要点

1. 生物分类依据是形态结构、生理功能等相似程度。
2. 分类单位从大到小：界、门、纲、目、科、属、种。
3. 种是最基本单位，同种生物亲缘关系最近。
4. 分类单位越大，共同特征越少；分类单位越小，共同特征越多。
5. 林奈创立双名法，物种学名 = 属名 + 种加词。
6. 生物分类有利于弄清生物之间的亲缘关系和进化关系，保护生物多样性。

## 六、自测小题

1. 生物分类的依据是生物的______程度，包括形态结构和______等。
2. 生物分类单位中，最大的是______，最基本的是______。
3. 分类单位越小，生物之间的亲缘关系越______，共同特征越______。
4. 双名法的创立者是______，物种学名由______和______组成。
5. 下列分类单位中，亲缘关系最远的是（A. 同属 B. 同科 C. 同界）。
6. 判断：同种的生物之间不能相互交配繁殖后代。（对/错）

**答案**：1. 相似；生理功能 2. 界；种 3. 近；多 4. 林奈；属名；种加词 5. C 6. 错（同种生物能交配并产生可育后代）
