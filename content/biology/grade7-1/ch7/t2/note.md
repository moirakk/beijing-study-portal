# 第二节 从种到界

标签：#分类单位 #种 #界 #亲缘关系

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第四章 生物分类的方法 · 第二节**。本节学习生物分类的七个等级单位，理解分类单位大小与生物共同特征、亲缘关系之间的联系。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 分类单位 | 生物分类时所用的等级单位 |
| 界 | 最大的分类单位 |
| 门 | 同一界内按相似特征划分的单位 |
| 纲 | 同一门内按相似特征划分的单位 |
| 目 | 同一纲内按相似特征划分的单位 |
| 科 | 同一目内按相似特征划分的单位 |
| 属 | 同一科内按相似特征划分的单位 |
| 种 | 最基本的分类单位 |

- 从大到小依次为：**界、门、纲、目、科、属、种**。
- **种**是最基本的分类单位，同种生物的亲缘关系最密切，共同特征最多。

### 2. 分类单位大小与生物特征的关系

| 分类单位 | 包含生物种类 | 共同特征 | 亲缘关系 |
|---|---|---|---|
| 大（如界） | 多 | 少 | 远 |
| 小（如种） | 少 | 多 | 近 |

### 4. 双名法

- 瑞典科学家**林奈**创立了生物命名的双名法。
- 每个物种的科学名称由两部分组成：**属名 + 种加词**，后面还常有命名者姓名。
- 如：*Homo sapiens*（智人）。

## 四、背记要点

1. 生物分类单位从大到小：界、门、纲、目、科、属、种。
2. 种是最基本的分类单位，同种生物共同特征最多、亲缘关系最近。
3. 分类单位越大，包含生物种类越多，共同特征越少，亲缘关系越远。
4. 林奈创立了双名法，物种学名 = 属名 + 种加词。
5. 生物分类能反映生物之间的亲缘关系和进化关系。

## 五、自测小题

1. 生物分类单位从大到小依次是：界、门、______、______、科、______、种。
2. 生物分类的最基本单位是______。
3. 分类单位越小，生物之间的共同特征越______，亲缘关系越______。
4. 双名法是由______创立的，每个物种的学名由______和______两部分组成。
5. 下列分类单位中，共同特征最多的是（A. 界 B. 科 C. 种）。
6. 判断：同种的生物一定同科、同属。（对/错）

**答案**：1. 纲；目；属 2. 种 3. 多；近 4. 林奈；属名；种加词 5. C 6. 对
