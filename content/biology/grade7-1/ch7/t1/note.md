# 第一节 尝试对生物进行分类

标签：#生物分类 #形态结构 #生理功能

## 一、本节定位

人教版·生物学七年级上册 **第二单元 多种多样的生物 · 第四章 生物分类的方法 · 第一节**。本节学习生物分类的基本依据和方法，尝试根据生物的特征进行分类。

## 二、核心概念

| 术语 | 含义 |
|---|---|
| 生物分类 | 根据生物的相似程度，把生物划分为不同的等级 |
| 分类依据 | 生物的形态结构、生理功能、生活习性等特征 |
| 界 | 生物分类的最大单位 |
| 种 | 生物分类的最基本单位 |
| 检索表 | 根据生物特征逐级区分生物的工具 |

## 三、知识梳理

### 1. 生物分类的依据

- 生物分类主要是根据生物的**相似程度**（包括形态结构和生理功能等）进行的。
- 植物分类常依据**根、茎、叶、花、果实、种子**的形态结构。
- 动物分类除了比较形态结构，还要比较**生理功能**。

### 2. 植物的分类依据

| 分类角度 | 具体特征 |
|---|---|
| 有无种子 | 孢子植物（无种子）/ 种子植物（有种子） |
| 种子有无果皮包被 | 裸子植物 / 被子植物 |
| 子叶数目 | 单子叶植物 / 双子叶植物 |
| 叶脉类型 | 平行脉 / 网状脉 |
| 根系类型 | 直根系 / 须根系 |

### 3. 动物的分类依据

| 分类角度 | 具体特征 |
|---|---|
| 体内有无脊柱 | 无脊椎动物 / 脊椎动物 |
| 体温是否恒定 | 变温动物 / 恒温动物 |
| 生殖方式 | 卵生 / 胎生 |
| 呼吸方式 | 鳃呼吸 / 肺呼吸等 |
| 生活环境 | 水生 / 陆生等 |

### 4. 分类的意义

- 便于识别和研究生物。
- 弄清不同类群之间的亲缘关系和进化关系。
- 保护和利用生物多样性。

## 四、背记要点

1. 生物分类的依据是生物的形态结构、生理功能等相似程度。
2. 植物分类常依据花、果实、种子等生殖器官，因为它们出现晚、受环境影响小。
3. 动物分类要比较形态结构和生理功能。
4. 分类单位越大，包含的生物种类越多，生物间的共同特征越少；分类单位越小，共同特征越多。

## 五、自测小题

1. 生物分类主要是根据生物的______程度进行的。
2. 植物分类的重要依据是______、______、______的形态结构。
3. 动物分类除了比较形态结构，还要比较______。
4. 根据体内有无脊柱，动物可分为______动物和______动物。
5. 下列特征中，最适合作为植物分类依据的是（A. 叶形 B. 花、果实、种子 C. 植株高矮）。
6. 判断：分类单位越大，生物之间的共同特征越多。（对/错）

**答案**：1. 相似 2. 花；果实；种子 3. 生理功能 4. 无脊椎；脊椎 5. B 6. 错（共同特征越少）
