# 第3节 细胞呼吸的原理和应用

## 概念定义

**细胞呼吸**：有机物在细胞内经过一系列氧化分解，生成 CO₂ 或其他产物，释放能量并生成 ATP 的过程，分为有氧呼吸和无氧呼吸。

**有氧呼吸总反应式**：

$$\text{C}_6\text{H}_{12}\text{O}_6 + 6\text{O}_2 + 6\text{H}_2\text{O} \xrightarrow{\text{酶}} 6\text{CO}_2 + 12\text{H}_2\text{O} + \text{能量}$$

**无氧呼吸**：细胞在无氧条件下把葡萄糖分解为酒精和 CO₂（如酵母菌、植物细胞），或分解为乳酸（如动物肌细胞、乳酸菌），只在第一阶段生成少量 ATP。

## 有氧呼吸与无氧呼吸比较表

| 项目 | 有氧呼吸 | 无氧呼吸 |
| --- | --- | --- |
| 场所 | 细胞质基质、线粒体 | 细胞质基质 |
| 是否需 O₂ | 需要 | 不需要 |
| 分解程度 | 彻底（CO₂ 和 H₂O） | 不彻底（酒精/乳酸中仍含能量） |
| 能量 | 大量（大部分以热能散失） | 少量 |
| 共同点 | 第一阶段相同；均由酶催化、释放能量合成 ATP | |

## 典型例题

**例 1**：探究酵母菌呼吸方式的实验中，如何检测 CO₂ 和酒精？

**解**：CO₂ 可使**澄清石灰水变浑浊**，或使**溴麝香草酚蓝溶液由蓝变绿再变黄**；酒精在酸性条件下与**重铬酸钾**反应呈**灰绿色**。有氧组通入经 NaOH 处理的空气以排除空气中 CO₂ 的干扰。

**例 2**：某植物组织消耗葡萄糖时，释放 CO₂ 与吸收 O₂ 之比为 4:3，求有氧呼吸与无氧呼吸消耗葡萄糖之比。

**解**：设有氧呼吸耗葡萄糖 x，无氧呼吸（产酒精）耗 y。吸收 O₂ = 6x，释放 CO₂ = 6x + 2y。由 $(6x+2y):6x = 4:3$ 得 $18x+6y=24x$，即 $y=x$。故消耗葡萄糖之比为 **1:1**。

## 易错点

- 有氧呼吸产生 CO₂ 在第二阶段（线粒体基质），耗 O₂ 与产生大量 ATP 在第三阶段（线粒体内膜）。
- 无氧呼吸产乳酸时**不产生 CO₂**；马铃薯块茎、玉米胚无氧呼吸产乳酸。
- 有氧呼吸反应式中 H₂O 既是反应物（第二阶段）又是产物（第三阶段）。
- 应用举例：包扎伤口用透气敷料（抑制厌氧菌）、松土促根系有氧呼吸、水果低温低氧储藏、酿酒先通气后密封。

## 背记要点

1. 有氧呼吸三阶段口诀："一糖解基质、二丙酮酸基质产 CO₂、三内膜耗氧产水多 ATP"。
2. 两类无氧呼吸产物：酒精 + CO₂（酵母菌、多数植物）；乳酸（动物、乳酸菌、马铃薯块茎）。
3. 无氧呼吸只在第一阶段产生少量 ATP，大部分能量留存于酒精或乳酸中。
4. 检测试剂：CO₂—石灰水/溴麝香草酚蓝；酒精—酸性重铬酸钾（灰绿色）。
