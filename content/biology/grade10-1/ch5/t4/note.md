# 第4节 光合作用与能量转化

## 概念定义

**光合作用**：绿色植物通过叶绿体，利用光能，把 CO₂ 和 H₂O 转化成储存能量的有机物，并释放 O₂ 的过程。总反应式：

$$6\text{CO}_2 + 12\text{H}_2\text{O} \xrightarrow[\text{叶绿体}]{\text{光能}} \text{C}_6\text{H}_{12}\text{O}_6 + 6\text{O}_2 + 6\text{H}_2\text{O}$$

**光反应**：在类囊体薄膜上进行，需要光；水裂解产生 O₂ 和 NADPH（[H]），并合成 ATP。

**暗反应（碳反应）**：在叶绿体基质中进行；CO₂ 被 C₅ 固定为 C₃，C₃ 被 NADPH 还原（消耗 ATP）生成糖类并再生 C₅。

## 色素与经典实验表

| 项目 | 内容 |
| --- | --- |
| 四种色素 | 胡萝卜素（橙黄）、叶黄素（黄）、叶绿素 a（蓝绿）、叶绿素 b（黄绿）；叶绿素主要吸收红光和蓝紫光 |
| 提取与分离 | 提取用无水乙醇（溶解色素）；分离用层析液（纸层析法，溶解度大者扩散快，最上为胡萝卜素） |
| 恩格尔曼实验 | 水绵 + 好氧细菌，证明叶绿体是光合作用场所、O₂ 由叶绿体释放 |
| 鲁宾和卡门 | 同位素 ¹⁸O 标记法，证明光合作用释放的 O₂ 来自 **H₂O** |
| 卡尔文 | ¹⁴C 标记 CO₂，探明碳的转移途径 CO₂→C₃→有机物 |

## 典型例题

**例 1**：正常光照下突然停止 CO₂ 供应，短时间内 C₃、C₅、ATP 含量如何变化？

**解**：CO₂ 固定停止，C₃ 生成减少而消耗继续，故 **C₃ 减少**；C₅ 消耗减少而再生继续，故 **C₅ 增多**；C₃ 还原减少使 ATP 消耗减少，**ATP（和 NADPH）增多**。

**例 2**：将植物从光下移到黑暗中，叶绿体中 C₃ 含量如何变化？为什么？

**解**：C₃ **增多**。停光后光反应停止，NADPH 和 ATP 供应中断，C₃ 的还原受阻；而 CO₂ 固定短时间内仍进行，C₃ 持续生成，故含量上升（C₅ 相应减少）。

## 易错点

- 光合作用释放的 O₂ 全部来自 **H₂O**（鲁宾和卡门实验），不是来自 CO₂。
- 提取色素用无水乙醇，分离色素用层析液，两者不可混淆；研磨加 SiO₂（助研磨）和 CaCO₃（保护色素）。
- 暗反应不等于"只在黑暗中进行"，其昼夜均可进行，但依赖光反应提供的 ATP 和 NADPH。
- 层析结果自上而下：胡萝卜素、叶黄素、叶绿素 a、叶绿素 b；含量最多的是叶绿素 a。
- 总（真正）光合速率 = 净光合速率 + 呼吸速率。

## 背记要点

1. 光反应产物：O₂、NADPH、ATP；场所类囊体薄膜；能量转化：光能→活跃化学能。
2. 暗反应两步：CO₂ 固定（CO₂+C₅→2C₃）、C₃ 还原（耗 ATP、NADPH）；场所叶绿体基质。
3. 变量分析口诀："断 CO₂，C₃ 降 C₅ 升；断光，C₃ 升 C₅ 降"。
4. 影响光合速率的环境因素：光照强度、CO₂ 浓度、温度（对应间作套种、大棚补光补 CO₂ 等应用）。
