# 第2节 细胞的能量货币ATP

## 概念定义

**ATP（腺苷三磷酸）**：细胞内的直接能源物质，被称为细胞的"能量货币"。结构简式：**A—P~P~P**，其中 A 代表腺苷（腺嘌呤+核糖），P 代表磷酸基团，"~"表示**特殊化学键**。

**ATP 与 ADP 的相互转化**：

$$\text{ATP} \underset{\text{合成酶}}{\overset{\text{水解酶}}{\rightleftharpoons}} \text{ADP} + \text{Pi} + \text{能量}$$

ATP 水解时远离 A 的特殊化学键断裂，释放能量供生命活动利用。

## ATP 相关要点表

| 项目 | 内容 |
| --- | --- |
| 组成元素 | C、H、O、N、P |
| 结构 | 1 腺苷 + 3 磷酸基团，含 2 个特殊化学键 |
| 水解部位 | 远离 A 的特殊化学键先断裂 |
| 合成能量来源 | 动物：呼吸作用；植物：呼吸作用和光合作用 |
| 与 RNA 的联系 | ATP 脱去 2 个磷酸基团后为腺嘌呤核糖核苷酸（RNA 的单体之一） |

## 典型例题

**例 1**：萤火虫发光器实验中，加入葡萄糖不能使荧光恢复，加入 ATP 能使荧光恢复，说明什么？

**解**：说明 **ATP 是直接能源物质**，葡萄糖中的能量必须先经氧化分解转移至 ATP，才能被生命活动（发光）直接利用。

**例 2**：判断"细胞内 ATP 含量很多，能满足各项生命活动的需要"的正误。

**解**：错误。细胞内 ATP 含量**很少**，但 ATP 与 ADP 的相互转化**十分迅速**，处于动态平衡，从而保证能量的持续供应。

## 易错点

- "~"是特殊化学键（教材已不称"高能磷酸键"），水解时**远离 A** 的键先断裂。
- ATP 是直接能源物质；葡萄糖是主要能源物质；脂肪是主要储能物质；太阳能是最终能量来源。
- ATP 与 ADP 转化中物质可逆、能量不可逆（来源与去路不同），酶也不同，不是严格的可逆反应。
- 吸能反应伴随 ATP 水解，放能反应（如呼吸作用）伴随 ATP 合成。

## 背记要点

1. 结构简式 A—P~P~P；A 为腺苷，含 2 个特殊化学键。
2. ATP 水解释放能量用于：主动运输、生物合成、肌肉收缩、神经传导等吸能过程。
3. 能量口诀："糖类主要、脂肪储备、ATP 直接、太阳最终"。
4. ATP 含量少、转化快，是"能量货币"。
