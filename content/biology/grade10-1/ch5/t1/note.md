# 第1节 降低化学反应活化能的酶

## 概念定义

**酶**：活细胞产生的具有催化作用的有机物，其中绝大多数是**蛋白质**，少数是 **RNA**。

**活化能**：分子从常态转变为容易发生化学反应的活跃状态所需要的能量。酶的作用机理是**降低化学反应的活化能**，且比无机催化剂降低得更显著。

**酶的特性**：高效性、专一性、作用条件较温和（最适温度、最适 pH）。

## 酶的特性与影响因素表

| 特性/因素 | 内容 |
| --- | --- |
| 高效性 | 催化效率约为无机催化剂的 $10^7 \sim 10^{13}$ 倍 |
| 专一性 | 每种酶只能催化一种或一类化学反应 |
| 温度 | 最适温度前升温加快反应；高温使酶**变性失活**（不可逆）；低温抑制活性（可恢复） |
| pH | 过酸、过碱使酶变性失活；胃蛋白酶最适 pH≈2，胰蛋白酶最适 pH≈8 |

## 典型例题

**例 1**：比较过氧化氢在加热、加 FeCl₃、加过氧化氢酶三种条件下的分解速率，说明酶的什么特性？该实验中为什么不能用温度探究酶的活性？

**解**：加过氧化氢酶时分解最快，说明酶具有**高效性**（与无机催化剂 FeCl₃ 对照）。因为加热本身能促进 H₂O₂ 分解，温度成为干扰变量，故探究温度对酶活性的影响不宜以 H₂O₂ 为底物（可改用淀粉酶与淀粉）。

**例 2**：探究温度对淀粉酶活性影响的实验中，能否用斐林试剂检测结果？

**解**：不能。斐林试剂需**水浴加热**，会改变实验设定的温度（自变量失控），且加热使未反应体系继续反应。应改用**碘液**检测淀粉的剩余量。

## 易错点

- 酶是"活细胞产生的有机物"，不都由核糖体合成（RNA 类酶不是）。
- 酶只能缩短达到平衡的时间，**不改变平衡点**，不提供能量，反应前后自身不变。
- 低温抑制与高温失活本质不同：低温下酶的空间结构未破坏，温度回升活性可恢复。
- 探究 pH 影响时不宜用淀粉和淀粉酶（酸性条件下淀粉自行水解），宜用 H₂O₂ 和过氧化氢酶。

## 背记要点

1. 酶的定义三要点：活细胞产生、具有催化作用、有机物（多为蛋白质，少数为 RNA）。
2. 作用机理：显著降低化学反应的活化能。
3. 三大特性：高效性、专一性、作用条件温和。
4. 温度/pH 曲线均为钟形，偏离最适值活性下降；高温、过酸、过碱导致不可逆失活。
