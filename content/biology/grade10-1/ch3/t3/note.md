# 第3节 细胞核的结构和功能

## 概念定义

**细胞核的功能**：细胞核是遗传信息库（遗传物质储存和复制的场所），是细胞代谢和遗传的**控制中心**。

**染色质**：细胞核中能被碱性染料染成深色的物质，主要由 **DNA 和蛋白质**组成。染色质与染色体是同一物质在细胞不同时期的两种存在状态。

**核仁**：与某种 RNA 的合成以及核糖体的形成有关。

## 结构与功能对应表

| 结构 | 特点 | 功能 |
| --- | --- | --- |
| 核膜 | 双层膜，把核内物质与细胞质分开 | 分隔、保护遗传物质 |
| 核孔 | 核膜上的孔道 | 大分子（mRNA、蛋白质）进出通道，代谢旺盛细胞核孔多 |
| 核仁 | 折光性强 | 与 rRNA 合成及核糖体形成有关 |
| 染色质 | DNA + 蛋白质，细丝状 | 遗传物质的载体，分裂时高度螺旋化为染色体 |

## 典型例题

**例 1**：伞藻嫁接与核移植实验说明什么？

**解**：伞藻的"帽"形态由**假根（含细胞核）**决定；核移植实验进一步证明**细胞核控制细胞的代谢和遗传**（生物体形态结构的建成主要与细胞核有关）。

**例 2**：变形虫切割实验中，有核部分能继续生存并分裂，无核部分死亡；将核重新植入去核部分后恢复生命活动。此实验说明什么？

**解**：说明细胞核是细胞生命活动的控制中心，**细胞核与细胞质相互依存**，只有保持完整结构的细胞才能正常完成各项生命活动。

## 易错点

- 核膜为**双层膜**，且外膜常与内质网相连；核膜上有核孔但仍具选择性（DNA 不能通过核孔）。
- 染色质与染色体成分相同（DNA 和蛋白质），仅形态不同、时期不同。
- 哺乳动物成熟红细胞无细胞核，不能增殖，寿命较短，不能以其推断"无核也能长期生存"。
- 细胞核是"控制中心"，但代谢的主要场所是**细胞质基质**。

## 背记要点

1. 细胞核功能一句话：遗传信息库，代谢和遗传的控制中心。
2. 四结构：核膜（双层）、核孔（物质交换通道）、核仁（与核糖体形成有关）、染色质（DNA+蛋白质）。
3. 染色质⇌染色体：同一物质在不同时期的两种形态。
4. 经典实验：伞藻嫁接与核移植、变形虫切割、蝾螈受精卵横缢。
