# 第1节 细胞膜的结构和功能

## 概念定义

**细胞膜的功能**：①将细胞与外界环境分隔开，保障细胞内部环境的相对稳定；②控制物质进出细胞（具有相对性）；③进行细胞间的信息交流。

**流动镶嵌模型**（辛格和尼科尔森，1972）：磷脂双分子层构成膜的基本支架，蛋白质分子有的镶在磷脂双分子层表面，有的部分或全部嵌入其中，有的贯穿于整个磷脂双分子层；膜具有**流动性**。

**糖被**：细胞膜外表面由蛋白质与糖类结合形成的糖蛋白，与细胞识别、信息交流有关。

## 膜结构探索历程表

| 科学家/实验 | 结论 |
| --- | --- |
| 欧文顿（脂溶性物质易通过膜） | 膜由脂质组成 |
| 红细胞膜脂质铺展为单层，面积为膜的 2 倍 | 磷脂在膜中排列为**双层** |
| 罗伯特森电镜观察（暗—亮—暗） | 提出"蛋白质—脂质—蛋白质"静态统一结构 |
| 人鼠细胞融合（荧光标记） | 膜蛋白可以运动，膜具有**流动性** |
| 辛格、尼科尔森 | 流动镶嵌模型 |

## 典型例题

**例 1**：人、鼠细胞融合实验中，两种荧光标记的膜蛋白在 37 ℃下 40 min 后均匀分布，说明什么？若降低温度，现象如何变化？

**解**：说明膜上的蛋白质分子可以运动，证明细胞膜具有**流动性**。降低温度使磷脂和蛋白质分子运动减慢，荧光均匀分布所需时间**延长**，体现流动性受温度影响。

**例 2**：细胞间信息交流有哪三种主要方式？

**解**：①通过体液运输的化学信号（如激素）与靶细胞膜上受体结合；②相邻细胞的细胞膜直接接触传递信息（如精子与卵细胞识别）；③相邻细胞间形成通道（如植物细胞的胞间连丝）传递信息。

## 易错点

- "结构特点"是流动性，"功能特性"是选择透过性，两者不能混用。
- 磷脂双分子层中，亲水的头部朝向两侧水环境，疏水的尾部相对排在内侧。
- 控制物质进出具有**相对性**：某些病毒、有害物质仍可能进入细胞。
- 糖蛋白只分布在细胞膜**外**表面，可用于判断膜的内外侧。
- 制备细胞膜选用哺乳动物**成熟红细胞**（无细胞核和众多细胞器膜）。

## 背记要点

1. 细胞膜三大功能：分隔、控制物质进出、信息交流。
2. 流动镶嵌模型：磷脂双分子层为基本支架，蛋白质镶、嵌、贯穿其中。
3. 膜的流动性由磷脂分子和大多数蛋白质分子的运动实现。
4. 探索历程主线：脂质→双层磷脂→静态模型→流动性证据→流动镶嵌模型。
