# 第1节 细胞中的元素和化合物

## 概念定义

**大量元素**：含量占生物体总质量万分之一以上的元素，包括 C、H、O、N、P、S、K、Ca、Mg 等。

**微量元素**：生物体必需但含量很少的元素，包括 Fe、Mn、Zn、Cu、B、Mo 等。

**统一性与差异性**：组成细胞的元素在无机自然界中都能找到（统一性），但含量与无机自然界不同（差异性），说明生物界与非生物界既统一又有区别。

- 元素含量：鲜重中 O 最多（O>C>H>N）；干重中 C 最多（C>O>N>H）。
- C 是最基本的元素：碳链构成生物大分子的基本骨架。
- 化合物含量：鲜重中水最多，蛋白质次之；干重中蛋白质最多。

## 有机物的检测方法表

| 待测物质 | 试剂 | 现象 | 条件 |
| --- | --- | --- | --- |
| 还原糖 | 斐林试剂（甲乙液等量混匀后加入） | 砖红色沉淀 | 50~65 ℃水浴加热 |
| 脂肪 | 苏丹Ⅲ染液 | 橘黄色 | 需用体积分数50%酒精洗浮色 |
| 蛋白质 | 双缩脲试剂（先加A液再加B液） | 紫色 | 不加热 |
| 淀粉 | 碘液 | 蓝色 | 不加热 |

## 典型例题

**例 1**：某同学用斐林试剂检测蔗糖溶液，水浴加热后无砖红色沉淀，原因是什么？

**解**：蔗糖是**非还原糖**，不含游离的醛基等还原性基团，不能与斐林试剂反应。常见还原糖为葡萄糖、果糖、麦芽糖。

**例 2**：比较斐林试剂与双缩脲试剂在成分和使用方法上的异同。

**解**：两者都含 NaOH 溶液和 CuSO₄ 溶液，但浓度和用法不同：斐林试剂中 CuSO₄ 为 0.05 g/mL，甲乙液**等量混合后立即使用**，需水浴加热；双缩脲试剂中 CuSO₄ 为 0.01 g/mL，**先加 A 液（NaOH）再滴加 B 液（CuSO₄）**，不需加热。

## 易错点

- 大量元素与微量元素按**含量**划分，微量元素同样必不可少（如缺 B 导致"花而不实"）。
- 鲜重与干重中元素排序不同：鲜重 O 最多，干重 C 最多。
- 斐林试剂需现配现用并水浴加热；双缩脲试剂不能混合后加入，也不加热。
- 脂肪检测若制作装片观察，需用 50% 酒精洗去浮色，显微镜下观察橘黄色脂肪颗粒。

## 背记要点

1. 最基本元素 C；基本元素 C、H、O、N；鲜重最多元素 O，干重最多元素 C。
2. 鲜重中含量最多的化合物是水，干重中最多的是蛋白质。
3. 检测口诀："还原糖斐林砖红热，脂肪苏丹橘黄色，蛋白双缩紫不热"。
4. 生物界与非生物界具有统一性（元素种类）和差异性（元素含量）。
