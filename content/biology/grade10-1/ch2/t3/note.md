# 第3节 细胞中的糖类和脂质

## 概念定义

**糖类**：由 C、H、O 三种元素组成，是细胞的主要能源物质，可分为单糖、二糖和多糖。

**脂质**：主要由 C、H、O 组成（有些含 N、P），包括脂肪、磷脂和固醇；与糖类相比，脂质中 H 的比例更高、O 的比例更低。

**多糖水解**：淀粉、糖原、纤维素的基本单位（单体）都是**葡萄糖**。

## 脂质分类与功能表

| 种类 | 分布/举例 | 功能 |
| --- | --- | --- |
| 脂肪 | 皮下、内脏周围 | 良好的**储能**物质；保温、缓冲减压 |
| 磷脂 | 所有细胞的膜结构 | 构成细胞膜和细胞器膜的重要成分 |
| 胆固醇 | 动物细胞膜 | 构成动物细胞膜的成分；参与血液中脂质的运输 |
| 性激素 | 性腺分泌 | 促进生殖器官发育及生殖细胞形成 |
| 维生素 D | 皮肤经紫外线照射生成 | 促进人和动物肠道对钙和磷的吸收 |

## 典型例题

**例 1**：等质量的糖类和脂肪彻底氧化分解，哪个释放能量多？为什么脂肪是良好的储能物质？

**解**：脂肪释放能量多。脂肪中 **H 的含量高、O 的含量低**，氧化分解时消耗 O₂ 多、释放能量多；且脂肪不亲水、体积小，单位质量储能多，故适于储能。

**例 2**：判断"糖类都是能源物质"的正误。

**解**：错误。核糖、脱氧核糖是核酸的组成成分，纤维素是植物细胞壁的成分，它们均**不作能源物质**。糖类的主要功能是供能，但并非全部糖类都供能。

## 易错点

- 二糖与多糖有物种分布差异：蔗糖、麦芽糖、淀粉、纤维素为植物特有；乳糖、糖原为动物特有；葡萄糖动植物共有。
- 脂质元素组成不全是 C、H、O：磷脂还含 P（和 N）。
- 固醇类包括胆固醇、性激素、维生素 D，不能把胆固醇一概视为有害物质。
- 糖类是"主要能源物质"，脂肪是"主要储能物质"，两者定位不同。

## 背记要点

1. 糖类分类：单糖（不能水解）、二糖（水解为两分子单糖）、多糖（单体为葡萄糖）。
2. 分布口诀："植物蔗麦淀纤维，动物乳糖与糖原"。
3. 脂质三类：脂肪（储能）、磷脂（构膜）、固醇（胆固醇、性激素、维生素 D）。
4. 脂肪比糖类含 H 多含 O 少，等质量氧化放能多、耗氧多。
