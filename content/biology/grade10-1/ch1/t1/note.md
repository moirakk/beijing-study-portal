# 第1节 细胞是生命活动的基本单位

## 概念定义

**细胞学说**：由施莱登和施旺建立，主要内容为——①细胞是一个有机体，一切动植物都由细胞发育而来，并由细胞和细胞产物构成；②细胞是一个相对独立的单位，既有自己的生命，又对与其他细胞共同组成的整体的生命起作用；③新细胞是由老细胞分裂产生的（魏尔肖补充）。

**生命系统的结构层次**：细胞→组织→器官→系统→个体→种群→群落→生态系统→生物圈。细胞是最基本的生命系统。

## 知识梳理

```mermaid
flowchart LR
    A[细胞] --> B[组织] --> C[器官] --> D[系统] --> E[个体]
    E --> F[种群] --> G[群落] --> H[生态系统] --> I[生物圈]
```

- 细胞学说揭示了细胞的统一性和生物体结构的统一性，使生物学研究进入细胞水平。
- 病毒没有细胞结构，必须寄生在活细胞内才能增殖，不属于生命系统的结构层次。
- 单细胞生物（如草履虫）依靠单个细胞完成各项生命活动；多细胞生物依赖各种分化的细胞密切合作。
- 植物没有"系统"层次；单细胞生物的个体与细胞层次重合。

## 结构层次对比表

| 层次 | 含义 | 举例 |
| --- | --- | --- |
| 细胞 | 生命系统最基本的结构层次 | 心肌细胞 |
| 组织 | 形态相似、结构功能相同的细胞群 | 心肌组织 |
| 器官 | 多种组织构成的功能单位 | 心脏 |
| 种群 | 一定区域内同种生物的全部个体 | 一片池塘中全部鲤鱼 |
| 群落 | 一定区域内所有生物 | 一片池塘中全部生物 |
| 生态系统 | 群落与无机环境的统一整体 | 一片池塘 |

## 典型例题

**例 1**：判断"细胞学说揭示了生物界的多样性"这一说法是否正确。

**解**：不正确。细胞学说论证了动植物均由细胞构成，揭示的是细胞的**统一性**和生物体结构的**统一性**，未揭示多样性。

**例 2**：一片森林中的全部马尾松、全部生物、全部生物及其无机环境分别属于哪个结构层次？

**解**：全部马尾松为**种群**（同种生物全部个体）；全部生物为**群落**；全部生物与无机环境构成**生态系统**。

## 易错点

- 病毒无细胞结构，不属于生命系统，但属于生物，其增殖必须依赖活细胞。
- 细胞学说的建立者是施莱登和施旺，"新细胞由老细胞分裂产生"由魏尔肖补充。
- 细胞学说的内容不包括"一切生物都由细胞构成"（病毒除外）。
- 种群强调"同种"，群落强调"所有生物"，生态系统包含无机环境。

## 背记要点

1. 细胞是最基本的生命系统；生命活动离不开细胞。
2. 细胞学说三要点：动植物由细胞构成、细胞是相对独立的单位、新细胞来自老细胞。
3. 结构层次口诀：细胞—组织—器官—（系统）—个体—种群—群落—生态系统—生物圈。
4. 细胞学说的意义：揭示统一性，标志生物学研究进入细胞水平。
