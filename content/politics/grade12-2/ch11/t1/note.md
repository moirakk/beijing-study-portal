# 专题十一 逻辑与思维（选必3整合）

## 核心概念 / 课标要求

**逻辑思维**：遵循逻辑规则进行思维，包括概念、判断、推理等思维形式。概念是思维的细胞，判断是对事物情况有所断定的思维形式，推理是由已知判断推出新判断的思维形式。

**辩证思维与创新思维**：辩证思维坚持用联系、发展、全面的观点看问题；创新思维包括发散思维与聚合思维、逆向思维等。

**课标要求**：理解概念的内涵与外延；理解判断的种类与真假；掌握演绎推理、归纳推理、类比推理；理解辩证思维的方法；理解创新思维的方法。

**核心原理**：思维要合乎逻辑，推理要遵循规则，坚持辩证思维与创新思维，提高思维品质。

## 知识梳理

| 知识点 | 内容 | 关键表述 |
| --- | --- | --- |
| 概念 | 内涵、外延 | 思维的细胞 |
| 判断 | 性质判断、关系判断 | 对事物有所断定 |
| 演绎推理 | 三段论、假言推理 | 从一般到个别 |
| 归纳推理 | 完全归纳、不完全归纳 | 从个别到一般 |
| 类比推理 | 根据相似性推出 | 从个别到个别 |
| 辩证思维 | 联系、发展、全面 | 分析与综合统一 |
| 创新思维 | 发散、聚合、逆向 | 多角度思考 |

## 典型例题

**例 1**：下列推理属于演绎推理的是（　）
A. 所有金属都能导电，铜是金属，所以铜能导电　B. 观察多个苹果落地，得出万有引力定律
C. 由地球有大气推出火星有大气　D. 由个别现象推出一般结论

**解**：选 A。A 是从一般（所有金属能导电）到个别（铜能导电）的演绎推理。B、D 是归纳推理，C 是类比推理。

**例 2**：概念的内涵是指（　）
A. 概念所反映的事物的本质属性　B. 概念所反映的事物的范围
C. 概念的名称　D. 概念的符号

**解**：选 A。概念的内涵是概念所反映的事物的本质属性，外延是概念所反映的事物的范围。

**例 3**：简述辩证思维的主要方法。

**解**：辩证思维坚持用联系、发展、全面的观点看问题。主要方法包括：分析与综合相结合，在分析的基础上综合，在综合的指导下分析；坚持矛盾分析法，具体问题具体分析；坚持质量互变规律，重视量的积累；坚持辩证否定观，树立创新意识。

## 易错点

- 混淆概念的内涵与外延，内涵是本质属性，外延是范围；混淆演绎推理、归纳推理、类比推理的方向，演绎从一般到个别，归纳从个别到一般，类比从个别到个别。
- 误认为归纳推理的结论必然正确，实际不完全归纳推理的结论具有或然性；误认为类比推理的结论必然正确，实际类比推理的结论具有或然性；混淆发散思维与聚合思维，发散思维是向多方向扩散，聚合思维是向一个方向集中。

## 背记要点

1. 概念是思维的细胞，包括内涵和外延；判断是对事物情况有所断定的思维形式。
2. 演绎推理从一般到个别，归纳推理从个别到一般，类比推理从个别到个别；演绎推理结论具有必然性，归纳和类比推理结论具有或然性。
3. 辩证思维坚持联系、发展、全面的观点；创新思维包括发散思维、聚合思维、逆向思维等。
