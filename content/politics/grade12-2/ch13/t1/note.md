# 专题十三 主观题答题方法

## 核心概念 / 课标要求

**主观题**：高考政治主观题主要考查学生运用所学知识分析问题、解决问题的能力，包括经济、政治、文化、哲学、国际等各类设问。

**答题方法**：审设问（明确知识范围、主体、题型）、审材料（提取有效信息）、组织答案（理论联系实际、分点作答）。

**课标要求**：掌握"是什么、为什么、怎么办"三类基本设问的答题方法；掌握"体现类、原因类、措施类、意义类、评析类"等常见题型；提高获取和解读信息、调动和运用知识、描述和阐释事物、论证和探究问题的能力。

**核心原理**：主观题答题要坚持"理论+材料"相结合，做到观点明确、逻辑清晰、条理分明。

## 知识梳理

| 题型 | 设问方式 | 答题思路 |
| --- | --- | --- |
| 体现类 | 体现了什么 | 材料+原理，先原理后材料 |
| 原因类 | 为什么 | 必要性+重要性+现实意义 |
| 措施类 | 怎么办 | 主体+措施，多角度 |
| 意义类 | 有何意义 | 对谁有意义，分主体 |
| 评析类 | 评析观点 | 一分为二，辩证分析 |
| 启示类 | 有何启示 | 从材料中提炼做法 |

## 典型例题

**例 1**：结合材料，运用"经济与社会"知识，说明我国为什么要坚持扩大内需战略。

**解**：审设问：知识范围是经济与社会，题型是原因类。答题思路：必要性（消费对生产有反作用，是生产的动力）+重要性（扩大内需有利于拉动经济增长、促进经济高质量发展）+现实意义（应对国际环境变化、构建新发展格局）。组织答案时先原理后材料，分点作答。

**例 2**：结合材料，运用"政治与法治"知识，分析我国如何推进法治政府建设。

**解**：审设问：知识范围是政治与法治，题型是措施类。答题思路：明确主体（政府），从依法行政、严格执法、职能科学、权责法定等角度提出措施，并结合材料具体说明。组织答案时"措施+依据+材料"相结合。

**例 3**：评析"只要坚持改革开放，就能实现经济高质量发展"这一观点。

**解**：评析类题目要一分为二、辩证分析。一方面，改革开放是推动我国发展进步的关键一招，坚持改革开放有利于实现经济高质量发展；另一方面，实现经济高质量发展还需要坚持新发展理念、深化供给侧结构性改革、发挥市场决定性作用和更好发挥政府作用等。因此该观点有合理之处，但不全面。

## 易错点

- 审题不清，未明确知识范围和主体，导致答非所问。
- 只答理论不结合材料，或只抄材料不答理论。
- 不分点作答，答案缺乏条理，逻辑混乱。
- 评析类题目只肯定或只否定，未做到一分为二。
- 措施类题目未明确主体，导致措施空泛、不具体。

## 背记要点

1. 主观题答题三步骤：审设问、审材料、组织答案。
2. 答题要坚持"理论+材料"相结合。
3. 原因类答题思路：必要性+重要性+现实意义；措施类答题要明确主体，多角度提出具体措施。
4. 评析类答题要一分为二、辩证分析。
5. 答案要分点作答，观点明确、逻辑清晰。
