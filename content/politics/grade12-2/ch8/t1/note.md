# 专题八 哲学与文化（历史唯物主义）

## 核心概念 / 课标要求

**历史唯物主义**：是关于人类社会发展的科学，认为社会存在决定社会意识，社会意识对社会存在具有反作用；社会基本矛盾（生产力与生产关系、经济基础与上层建筑）推动社会发展；人民群众是历史的创造者。

**课标要求**：理解社会存在与社会意识的辩证关系；理解社会基本矛盾运动及其规律；理解改革是社会主义制度的自我完善和发展；理解人民群众的历史地位；理解价值观的导向作用与人生价值的实现。

**核心原理**：社会存在决定社会意识，社会意识具有相对独立性并反作用于社会存在；生产力决定生产关系，经济基础决定上层建筑；人民群众是历史的创造者。

## 典型例题

**例 1**：随着我国经济发展，人们的消费观念发生变化，绿色消费、健康消费日益流行。这体现了（　）
A. 社会意识决定社会存在　B. 社会存在决定社会意识
C. 社会意识具有独立性　D. 社会意识促进社会发展

**解**：选 B。经济发展（社会存在）引起消费观念（社会意识）变化，体现社会存在决定社会意识。

**例 2**：我国不断深化改革开放，完善社会主义市场经济体制。这体现了（　）
A. 改革是社会主义制度的自我完善和发展
B. 改革是改变社会主义制度
C. 改革是阶级斗争
D. 改革是根本制度的变革

**解**：选 A。改革是社会主义制度的自我完善和发展，是解决社会基本矛盾、推动社会发展的直接动力。

**例 3**：为什么说人民群众是历史的创造者？

**解**：人民群众是社会物质财富的创造者，是社会精神财富的创造者，是社会变革的决定力量。要坚持群众观点和群众路线，一切为了群众，一切依靠群众，从群众中来，到群众中去，把人民群众的利益作为最高价值标准。

## 易错点

- 误认为社会意识决定社会存在，正确是社会存在决定社会意识；误认为社会意识与社会存在同步变化，实际社会意识具有相对独立性。
- 混淆"改革"与"革命"，改革是社会主义制度的自我完善和发展，不是根本制度的变革。
- 误认为杰出人物是历史的创造者，实际人民群众才是历史的创造者。
- 误认为人生价值只在于自我价值，实际是个人价值与社会价值的统一，社会价值是根本。

## 背记要点

1. 社会存在决定社会意识，社会意识对社会存在具有反作用；社会基本矛盾：生产力与生产关系、经济基础与上层建筑。
2. 改革是社会主义制度的自我完善和发展；人民群众是历史的创造者，要坚持群众观点和群众路线。
3. 价值观具有导向作用，要树立正确的价值观；人生价值是个人价值与社会价值的统一，要在劳动和奉献中实现人生价值。
