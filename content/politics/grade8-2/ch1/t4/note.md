# 坚持依宪治国／加强宪法监督

标签：#依宪治国 #宪法监督 #宪法意识

## 一、本知识点定位

统编版道德与法治八年级下册 **第二课 保障宪法实施** 的两框内容：「坚持依宪治国」与「加强宪法监督」，是 [[第二课 保障宪法实施]] 的具体展开，回答"宪法凭什么至上、靠什么落实"两个问题。

## 二、核心概念

1. **根本活动准则**：宪法是一切组织和个人的根本活动准则，任何组织和个人都不得有超越宪法的特权。
2. **最高法律效力**：宪法是其他法律的立法基础，是国家法制统一的基础。
3. **合宪性审查**：对法律法规等规范性文件是否符合宪法进行审查。
4. **宪法宣誓制度**：彰显宪法权威、强化宪法意识的重要制度安排。

## 三、知识框架

### 1. 坚持依宪治国

- **宪法的内容**：规定国家生活中最根本、最重要的问题（国家性质、根本制度、根本任务、国家机构等）。
- **宪法的效力**：
  - 宪法是其他法律的立法基础和立法依据，其他法律是宪法的具体化；
  - 任何法律不得与宪法相抵触，否则无效。
- **宪法的程序**：制定和修改程序比其他法律更严格（1/5以上代表提议、2/3以上多数通过）。
- **要求**：坚持党的领导、人民当家作主、依法治国的有机统一；党领导人民制定和实施宪法法律，党自身必须在宪法和法律范围内活动。

### 2. 加强宪法监督

- **监督主体**：全国人大及其常委会行使监督宪法实施的职权；地方各级人大保证宪法在本行政区域内的遵守和执行。
- **监督内容**：合宪性审查、备案审查制度等。
- **完善措施**：健全宪法实施和监督制度，落实宪法解释程序机制。
- **公民层面**：增强宪法意识——学习宪法、认同宪法、践行宪法。

## 四、案例分析

**案例**：某地出台的规范性文件规定"外地车辆一律不得进入城区"，经公民建议、全国人大常委会备案审查后，该规定被要求纠正。

**分析**：
- 体现了加强宪法监督、维护国家法制统一；
- 备案审查制度保障公民权利不受不合法规范性文件侵害；
- 说明任何法律法规都不得与宪法相抵触。

**答题思路**：素材涉及"备案审查、文件被叫停、公民提出审查建议"时，从"宪法监督""法制统一""公民宪法意识"角度作答。

## 五、背记要点

1. 宪法与普通法律的关系可概括为"**母法与子法**"（内容、效力、程序三方面不同）。
2. 宪法是国家法制统一的基础。
3. 增强宪法意识三步骤：**学习—认同—践行**。
4. 国家宪法日：12月4日；宪法宣誓制度写入宪法（2018年宪法修正案）。

## 六、易错提醒

- ❌"宪法修改程序与普通法律相同" → ✅ 宪法修改须由全国人大以全体代表的2/3以上多数通过，普通法律只需过半数。
- ❌"监督宪法实施只是全国人大的事" → ✅ 全国人大**及其常委会**都行使监督职权，公民也应参与监督。

## 七、自测题

3. 什么是合宪性审查？（审查规范性文件是否符合宪法）
4. 公民如何践行宪法？（坚持宪法至上，自觉抵制损害宪法尊严的行为，依法行使权利、履行义务）
