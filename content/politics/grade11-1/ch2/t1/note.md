# 始终坚持以人民为中心

## 核心要义

- **党的性质**：中国共产党是中国工人阶级的先锋队，同时是中国人民和中华民族的先锋队。
- **党的宗旨**：全心全意为人民服务。
- **党的执政理念**：立党为公、执政为民。
- **党的根本立场**：人民立场；人民是党执政兴国的最大底气。

## 知识梳理

| 项目 | 规范表述 |
| --- | --- |
| 性质 | 两个先锋队（工人阶级先锋队 + 中国人民和中华民族的先锋队） |
| 宗旨 | 全心全意为人民服务 |
| 根本立场 | 人民立场——中国共产党的根本政治立场，马克思主义政党区别于其他政党的显著标志 |
| 执政理念 | 立党为公、执政为民 |
| 根本工作路线 | 群众路线：一切为了群众，一切依靠群众，从群众中来，到群众中去 |
| 发展思想 | 坚持以人民为中心的发展思想，发展为了人民、发展依靠人民、发展成果由人民共享 |

## 重点精讲

1. **党的性质由什么决定**：由党的阶级性（工人阶级先锋队）和先进性（代表最广大人民根本利益）共同体现，党除了工人阶级和最广大人民群众的利益，没有自己特殊的利益。
2. **群众路线**是党的根本工作路线，是党的生命线；坚持群众路线是党永葆青春活力和战斗力的重要传家宝。
3. **以人民为中心的发展思想**：把实现好、维护好、发展好最广大人民根本利益作为发展的出发点和落脚点。答题时"三个发展"（为了人民、依靠人民、成果共享）须写全。
4. **答题模型（党为什么/怎样做某事）**：性质宗旨 → 根本立场 → 执政理念 → 群众路线 → 以人民为中心的发展思想，再结合材料。

## 典型例题

**例1（选择题）** 中国共产党的根本政治立场是（　）
A. 阶级立场　B. 人民立场　C. 国家立场　D. 民族立场
**解析**：人民立场是中国共产党的根本政治立场，是马克思主义政党区别于其他政党的显著标志。选 **B**。

**例2（材料题）** 材料：脱贫攻坚战中，300多万名第一书记和驻村干部同贫困群众想在一起、干在一起，近1亿农村贫困人口全部脱贫。
问：结合材料，运用"始终坚持以人民为中心"的知识，说明党为什么坚决打赢脱贫攻坚战。
**解析**：①党的性质是两个先锋队，宗旨是全心全意为人民服务，脱贫攻坚是宗旨的集中体现；②人民立场是党的根本政治立场，党坚持立党为公、执政为民；③党坚持以人民为中心的发展思想，让发展成果更多更公平惠及全体人民；④党坚持群众路线，干部驻村体现一切为了群众、一切依靠群众。

## 易错点

- 党的宗旨是**全心全意为人民服务**，不能写成"为人民谋幸福"（后者是初心使命的内容）。
- "两个先锋队"必须完整表述，只写"工人阶级先锋队"不完整。
- 群众路线是党的**根本工作路线**，不是"根本领导方式"。
- 党代表**最广大人民的根本利益**，不能表述为"代表所有人的一切利益"。

## 背记要点

1. 性质：两个先锋队；宗旨：全心全意为人民服务
2. 根本立场：人民立场；执政理念：立党为公、执政为民
3. 群众路线：一切为了群众、一切依靠群众，从群众中来、到群众中去
4. 以人民为中心的发展思想：发展为了人民、依靠人民、成果由人民共享
