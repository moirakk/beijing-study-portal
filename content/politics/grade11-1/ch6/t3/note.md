# 基层群众自治制度

## 核心要义

- **含义**：人民群众在城乡基层党组织领导下，依法直接行使民主权利，实行自我管理、自我服务、自我教育、自我监督。
- **地位**：我国的一项基本政治制度。
- **组织形式**：农村村民委员会、城市居民委员会——**基层群众性自治组织**（不是国家机关，也不是基层政权）。

## 知识梳理

| 项目 | 农村 | 城市 |
| --- | --- | --- |
| 自治组织 | 村民委员会 | 居民委员会 |
| 自治主体 | 村民 | 居民 |
| 主要依据 | 村民委员会组织法、村民自治章程、村规民约 | 居民委员会组织法、居民公约 |

**基层民主实践的四个环节**：

| 环节 | 内容举例 |
| --- | --- |
| 民主选举 | 村（居）委会成员由村（居）民直接选举产生 |
| 民主协商 | 有事好商量，众人的事情由众人商量 |
| 民主决策 | 村民会议、村民代表会议讨论决定重大事项 |
| 民主管理 | 制定村规民约、居民公约，实现自我管理 |
| 民主监督 | 村务公开、民主评议、村务监督委员会 |

## 重点精讲

1. **村（居）委会的性质**：基层群众性自治组织，不是一级政府，与乡镇政府（街道办）是**指导与协助**关系而非领导与被领导关系。
2. **基层群众自治的意义**：是人民当家作主最有效、最广泛的途径，是发展全过程人民民主的重要体现；直接行使民主权利是其突出特点。
3. **党的领导**：基层群众自治必须在**基层党组织领导下**进行，把党的领导贯穿基层治理全过程。
4. **考法提示**：材料出现"村民投票""村务公开""居民议事会"等，先判断环节（选举/协商/决策/管理/监督），再联系全过程人民民主。

## 典型例题

**例1（选择题）** 某村将修路集资方案交由村民会议讨论表决，并将账目按月公示。这分别体现基层群众自治中的（　）
A. 民主选举、民主管理　B. 民主决策、民主监督　C. 民主协商、民主决策　D. 民主管理、民主监督
**解析**：村民会议讨论表决重大事项属民主决策；账目公示属村务公开、民主监督。选 **B**。

**例2（材料题）** 材料：某社区党组织牵头搭建"居民议事厅"，围绕老旧小区改造召开协商会20余场，改造方案由居民投票确定，施工全程由居民监督小组跟进。
问：结合材料，说明基层群众自治是如何保障人民当家作主的。
**解析**：①在基层党组织领导下开展自治，保证了正确方向；②居民议事协商体现民主协商，"有事好商量"；③方案由居民投票确定体现民主决策，居民直接行使民主权利；④监督小组跟进体现民主监督；⑤基层群众自治使人民群众实行自我管理、自我服务、自我教育、自我监督，是发展全过程人民民主、实现人民当家作主最有效最广泛的途径。

## 易错点

- 村（居）委会是**自治组织**，不是国家机关、不是基层政权（乡镇政府才是最基层政权）。
- 政府与村（居）委会是**指导**关系，不能写成"领导"关系；但**基层党组织**对自治是领导关系。
- 村民**直接**行使民主权利是基层民主的突出特点，勿与人大代表的间接民主混淆。
- 村规民约不得与宪法法律相抵触。

## 背记要点

1. 性质：基层群众性自治组织（村委会、居委会）；地位：基本政治制度
2. "四个自我"：自我管理、自我服务、自我教育、自我监督
3. 五个环节：民主选举、民主协商、民主决策、民主管理、民主监督
4. 基层群众自治是人民当家作主最有效、最广泛的途径
