# 做核心思想理念的传承者

标签：#文化传承 #核心思想理念 #知行合一

## 一、本知识点定位

统编版道德与法治七年级下册 **第三单元 传承中华优秀传统文化 第七课「做核心思想理念的传承者」**。在认识核心思想理念的基础上，本框引导我们在生活中自觉传承和践行这些理念。

## 二、核心观点

1. 传承核心思想理念，需要我们**深入理解其内涵**，感悟其时代价值。
2. 传承的关键在于**践行**：把思想理念落实到日常言行中，做到知行合一。
3. 践行**讲仁爱**：关爱他人，推己及人，将心比心。
4. 践行**守诚信**：诚实做人、信守承诺。
5. 践行**尚和合、求大同**：与人和睦相处，心怀家国天下。

## 三、知识梳理

### 1. 为什么要做传承者（为什么）

- 中华优秀传统文化是中华民族的"根"和"魂"。
- 核心思想理念对个人修身、社会和谐、国家发展具有重要意义。
- 青少年是文化传承的生力军，传承是我们的文化责任。

### 2. 怎样践行讲仁爱

- 孝敬父母、尊敬师长、关心同学。
- 参加志愿服务，帮助有困难的人。
- 推己及人："己所不欲，勿施于人"。

### 3. 怎样践行守诚信

- 说话真实、作业考试不作弊。
- 答应别人的事努力做到，做不到及时说明。
- 反对弄虚作假、抄袭剽窃。

### 4. 怎样践行崇正义

- 明辨是非，坚持原则，不随波逐流。
- 面对不公正现象敢于发声，见义智为。

### 5. 怎样践行尚和合、求大同

- 与同学和睦相处，尊重差异，"和而不同"。
- 维护民族团结，关心国家大事。
- 树立人类命运共同体意识，关注世界和平与发展。

### 6. 传承的方法与途径

- 学习经典：阅读《论语》《孟子》等传统典籍。
- 参与文化活动：传统节日、非遗体验、经典诵读。
- 落实到行动：从身边小事做起，知行合一。

## 四、重要概念

| 术语 | 定义 |
|---|---|
| 知行合一 | 把认识与行动统一起来，学以致用 |
| 推己及人 | 用自己的心意推想别人的心意，将心待人 |
| 见义智为 | 面对不义之事，机智勇敢地维护正义 |
| 文化责任 | 传承和弘扬中华优秀传统文化的使命 |

## 五、案例分析

班里转来一位性格内向的新同学，小赵主动帮他熟悉校园，组织小组学习邀他参加；小赵还坚持每周去社区做垃圾分类宣传志愿者。小赵的行为是"讲仁爱"（关爱他人）、"尚和合"（营造和谐集体）的具体践行。这说明传承核心思想理念并不遥远，从身边小事做起就是最好的传承。

## 六、背记要点

1. 传承核心思想理念：深入理解内涵 + 落实到行动（知行合一）。
2. 讲仁爱：孝亲敬长、关爱他人、推己及人。
3. 守诚信：诚实做人、信守承诺、不弄虚作假。
4. 崇正义：明辨是非、见义智为。
5. 尚和合：和而不同、和睦相处；求大同：心怀天下。
6. 途径：学习经典、参与文化活动、从小事做起。

## 七、自测小题

1. 传承核心思想理念的关键在于______，做到知行合一。
2. 判断：传承传统文化就是背诵古文，与日常行为无关。（对/错）
3. 主动帮助有困难的同学，体现的理念是（A. 讲仁爱 B. 求大同 C. 重民本）。
4. 简答：中学生怎样做核心思想理念的传承者？

**答案**：1. 践行（行动） 2. 错（关键在践行，要落实到日常言行） 3. A
4. 答题要点：①认真学习，深入理解核心思想理念的内涵与价值；②践行仁爱，关爱他人；③诚实守信，信守承诺；④明辨是非，崇尚正义；⑤与人和睦相处，心怀家国；⑥从身边小事做起，知行合一。
