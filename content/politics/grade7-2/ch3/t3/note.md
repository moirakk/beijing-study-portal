# 影响深远的人文精神

标签：#人文精神 #传统文化 #审美追求

## 一、本知识点定位

统编版道德与法治七年级下册 **第三单元 传承中华优秀传统文化 第八课「影响深远的人文精神」**。本框介绍中华人文精神的主要内容及其对个人与社会的深远影响。

## 二、核心观点

1. 中华优秀传统文化蕴含着丰富的**人文精神**，滋养了中华民族独特的精神世界。
2. 中华人文精神主要包括：**求同存异、和而不同的处世方法**，**文以载道、以文化人的教化思想**，**形神兼备、情景交融的美学追求**，**俭约自守、中和泰和的生活理念**。
3. 人文精神体现了中国人对**人际交往、道德教化、艺术审美、生活方式**的独特理解。
4. 这些精神追求至今仍**深刻影响**着中国人的思维方式和行为方式。
5. 人文精神是涵养**社会主义核心价值观**的重要源泉。

## 三、知识梳理

### 1. 求同存异、和而不同（处世方法）

- 内涵：寻求共同点，保留不同意见；和谐相处但不盲目附和。
- 体现：与人交往尊重差异、包容多样；国家间和平共处。

### 2. 文以载道、以文化人（教化思想）

- 内涵：文章、文艺作品要承载道义，用文化教育感化人。
- 体现：优秀文艺作品传递真善美；学校教育立德树人。

### 3. 形神兼备、情景交融（美学追求）

- 内涵：艺术既要形似更要传神，情感与景物交融为一。
- 体现：中国画重写意传神、古诗词借景抒情、书法气韵生动。

### 4. 俭约自守、中和泰和（生活理念）

- 内涵：节俭朴素、自我约束；中正平和、不走极端。
- 体现：勤俭节约反对浪费；做事把握分寸，追求身心和谐。

### 5. 人文精神的当代价值（为什么）

- 塑造中国人谦和包容、崇文尚德的品格。
- 为处理人与人、人与社会、人与自然的关系提供智慧。
- 是文化自信的重要底气，滋养社会主义核心价值观。

## 四、重要概念

| 术语 | 定义 |

| 文以载道 | 文章艺术承载道义、传播价值的教化思想 |
| 形神兼备 | 艺术创作形似与神韵兼具的美学标准 |
| 俭约自守 | 节俭朴素、自我约束的生活理念 |

## 五、案例分析

学校开展"光盘行动"，同学们自觉按量取餐、不剩饭菜；班级布置教室时，大家各抒己见，最终融合多个方案形成特色设计。前者践行"俭约自守"的生活理念，后者体现"求同存异、和而不同"的处世方法。可见中华人文精神就体现在日常生活的点滴之中，仍在影响和指引我们的行为。

## 六、背记要点

1. 中华人文精神四方面：求同存异和而不同（处世）、文以载道以文化人（教化）、形神兼备情景交融（美学）、俭约自守中和泰和（生活）。
2. 求同存异：尊重差异、包容多样。
3. 文以载道：文艺作品要承载道义、教育感化人。
4. 形神兼备：中国艺术重传神写意。
5. 俭约自守：节俭朴素；中和泰和：中正平和。
6. 人文精神滋养社会主义核心价值观，是文化自信的底气。

2. 判断：中国画只求画得像，不讲究神韵。（对/错）

4. 简答：中华人文精神有哪些主要内容？

**答案**：1. 求同存异；和而不同 2. 错（中国艺术追求形神兼备，更重传神） 3. B
4. 答题要点：①求同存异、和而不同的处世方法；②文以载道、以文化人的教化思想；③形神兼备、情景交融的美学追求；④俭约自守、中和泰和的生活理念。
