# 做中华人文精神的弘扬者

标签：#人文精神 #弘扬践行 #文化自信

## 一、本知识点定位

统编版道德与法治七年级下册 **第三单元 传承中华优秀传统文化 第八课「做中华人文精神的弘扬者」**。本框引导我们在学习生活中弘扬求同存异、俭约自守等中华人文精神。

## 二、核心观点

1. 弘扬中华人文精神，要**理解其内涵**，更要**体现在行动**中。
2. 弘扬**求同存异、和而不同**：学会包容差异、理性交流。
3. 弘扬**文以载道、以文化人**：亲近优秀文化作品，提升人文素养。
4. 弘扬**形神兼备、情景交融**：培养健康的审美情趣。
5. 弘扬**俭约自守、中和泰和**：养成节俭习惯，保持平和心态。

## 三、知识梳理

### 1. 践行求同存异、和而不同（怎么做）

- 与同学意见不合时，先倾听理解，再表达观点。
- 尊重不同民族、地域的文化习俗。
- 讨论问题对事不对人，求共识、存差异。

### 2. 践行文以载道、以文化人

- 阅读经典名著，欣赏优秀影视、戏曲作品。
- 自觉抵制低俗、庸俗、媚俗的文化产品。
- 在写作与表达中传递正能量。

### 3. 践行形神兼备、情景交融

- 学习书法、国画、古诗词，感受中华美学魅力。
- 参观美术馆、博物馆，提升审美能力。
- 在生活中发现美、欣赏美、创造美。

### 4. 践行俭约自守、中和泰和

- 节约粮食、水电，不攀比、不浪费。
- 合理消费，抵制过度物质追求。
- 遇事不急不躁，学会调节心态，追求身心和谐。

### 5. 弘扬人文精神的意义（为什么）

- 有利于提升个人修养，塑造健全人格。
- 有利于营造文明和谐的社会风尚。
- 有利于坚定文化自信，建设文化强国。

## 四、重要概念

| 术语 | 定义 |
|---|---|
| 人文素养 | 通过文化熏陶形成的内在修养与精神品质 |
| 审美情趣 | 感受美、鉴赏美、创造美的能力与趣味 |
| 合理消费 | 根据实际需要适度消费，不攀比不浪费 |
| 文化自信 | 对自身文化价值的充分肯定和坚定信心 |

## 五、案例分析

班级筹备元旦晚会，同学们对节目形式争论不休：有人想演话剧，有人想唱流行歌。班长组织大家投票并融合创意，最终排演了"古诗词新唱"节目，既有传统韵味又有时代气息，获得全校好评。这一过程体现了"求同存异、和而不同"的处世智慧，节目本身则是"文以载道、以文化人"的生动实践。

## 六、背记要点

1. 弘扬人文精神：理解内涵 + 落实行动。
2. 求同存异：倾听包容、理性交流、尊重差异。
3. 文以载道：亲近优秀作品，抵制"三俗"文化。
4. 形神兼备：培养健康审美情趣，感受中华美学。
5. 俭约自守：节俭生活、合理消费；中和泰和：心态平和。
6. 意义：提升修养、和谐社会、坚定文化自信。

3. 拒绝铺张浪费、按需消费，体现的人文精神是（A. 俭约自守 B. 文以载道 C. 求同存异）。
4. 简答：中学生怎样弘扬中华人文精神？

**答案**：1. 行动 2. 错（应求同存异、和而不同，倾听理解、理性交流） 3. A
4. 答题要点：①包容差异，与人和睦相处；②阅读经典、欣赏优秀文化作品，抵制低俗文化；③培养健康的审美情趣；④勤俭节约、合理消费；⑤保持平和心态，追求身心和谐。
