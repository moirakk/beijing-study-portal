# 品味美好情感

标签：#情感 #美好情感 #情感体验

## 一、本知识点定位

统编版道德与法治七年级下册 **第一单元 珍惜青春时光 第三课「品味美好情感」**。本框帮助我们区分情绪与情感，认识情感的作用，学会创造和传递美好情感。

## 二、核心观点

1. **情感与情绪紧密相关**又有区别：情绪是短暂的、不稳定的；情感是在情绪基础上逐渐积累和发展的，相对**稳定和持久**。
2. 情感是人最基本的**精神需求**，包括正义感、责任感、胜任感、美的感受等。
3. 情感**影响我们的判断和选择**，驱使我们做出行动；美好情感是我们前行的动力。
4. 生活中并非只有美好情感，**负面情感体验**也是成长的一部分，可以丰富人生阅历。
5. 我们可以通过阅读、艺术、走进自然、参与有意义的活动等方式**获得美好情感**，并主动**传递情感正能量**。

## 三、知识梳理

### 1. 情绪与情感的关系（是什么）

- 联系：情感在情绪的基础上发展而来，通过情绪表现出来。
- 区别：情绪短暂、多变；情感稳定、持久，是对人、对事的稳定态度。
- 例：见到国旗升起时的激动是情绪，长期形成的爱国之情是情感。

### 2. 情感的种类

- 基础性情感：安全感等。
- 高级情感：正义感、责任感、道德感、理智感、美的感受等。
- 情感是人最基本的精神需求。

### 3. 情感的作用（为什么）

- 情感影响判断和选择，驱使我们做出行动。
- 美好情感激励我们追求美好生活，传递正能量。
- 情感伴随成长而丰富，让我们的精神世界更充盈。

### 4. 怎样获得和传递美好情感（怎么做）

- **获得**：阅读经典、欣赏艺术、走进博物馆、参加公益活动、亲近自然等。
- **对待负面体验**：正确看待挫折带来的负面情感，从中汲取成长力量。
- **传递**：关爱他人、分享美好、用行动影响身边的人，创造正能量的情感氛围。

## 四、重要概念

| 术语 | 定义 |

| 情感 | 在情绪基础上发展而来的相对稳定持久的心理体验 |
| 精神需求 | 情感是人最基本的精神需求 |
| 情感正能量 | 通过关爱与分享传递的积极情感力量 |
| 负面情感体验 | 挫折等带来的消极体验，也是成长的重要部分 |

## 五、案例分析

学校组织同学到敬老院开展志愿服务。小雯起初只是完成任务，但当她为老人读报、听老人讲过去的故事后，内心涌起温暖与责任感，此后每月坚持去看望老人，还带动了同学参加。这说明：参与有意义的社会活动能获得美好情感；美好情感驱使我们行动，并能传递给身边的人。

## 六、背记要点

1. 情绪短暂多变，情感稳定持久；情感在情绪基础上发展而来。
2. 情感是人最基本的精神需求。
3. 高级情感：正义感、责任感、道德感、美的感受等。
4. 情感影响判断与选择，驱使我们做出行动。
5. 获得美好情感的途径：阅读、艺术、自然、公益活动等。
6. 负面情感体验也有意义，要善于从中成长。
7. 主动传递情感正能量，温暖他人、影响社会。
