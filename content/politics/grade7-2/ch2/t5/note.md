# 人要自强

标签：#自强 #青春成长 #意志品质

## 一、本知识点定位

统编版道德与法治七年级下册 **第二单元 焕发青春活力 第六课「人要自强」**。本框帮助我们理解自强的含义与表现，认识自强对个人成长的重要意义。

## 二、核心观点

1. 自强，就是**自己努力向上，永不懈怠**，是一种精神状态，也是一种美好的道德品质。
2. 自强的表现：**不怕困难、积极进取、志存高远、执着追求**。
3. 自强让青春**奋进**：为青春成长注入不竭的动力。
4. 自强的关键是**战胜自己**：克服惰性、抵制诱惑、超越自我。
5. "天行健，君子以自强不息"——自强是中华民族的**传统美德**。

## 三、知识梳理

### 1. 什么是自强（是什么）

- 自强是自己努力向上、奋发进取、永不懈怠的精神状态。
- 自强是一种美好的道德品质，与自尊、自信紧密相连。
- 自立是自强的基础：自己的事情自己做，不依赖他人。

### 2. 自强的表现

- 面对困难不低头：不怕失败，屡败屡战。
- 学习生活中积极进取：主动学习、勇于开拓。
- 有远大志向并执着追求：志存高远，脚踏实地。

### 3. 为什么人要自强（为什么）

- 自强让人奋发向上：激励我们不断克服困难、走向成功。
- 自强让青春焕发活力：是青春飞扬的重要底色。
- 一个自强的人，才能把命运掌握在自己手中。
- 靠别人施舍或依赖他人，无法获得真正的成长。

### 4. 怎样做到自强（怎么做）

- **树立坚定的理想**：理想是自强的灯塔，为奋斗指明方向。
- **战胜自己**：克服惰性、抵制不良诱惑，是自强的关键。
- **在磨砺中成长**：不逃避困难，把挫折当作磨刀石。
- **从小事做起**：坚持锻炼、按时完成作业，在日常点滴中培养自强品质。

## 五、案例分析

张海迪五岁时高位截瘫，但她自学完成小学到大学的课程，掌握多门外语，翻译和创作了大量作品。她说："即使翅膀断了，心也要飞翔。"张海迪的事迹诠释了自强：面对命运的不公不屈服，靠顽强的意志和不懈的努力实现人生价值。这启示我们：自强者不惧困难，能把不利条件转化为奋进的动力。

## 六、背记要点

1. 自强：自己努力向上、永不懈怠的精神状态和道德品质。
2. 自强的表现：不怕困难、积极进取、志存高远、执着追求。
3. 自立是自强的基础，战胜自己是自强的关键。
4. 自强为青春成长注入不竭动力。
5. "天行健，君子以自强不息"。
6. 做到自强：树立理想、战胜自己、经受磨砺、从小事做起。
