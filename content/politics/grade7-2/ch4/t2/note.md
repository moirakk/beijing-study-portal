# 法律保障生活

标签：#法律作用 #权利保障 #法治生活

## 一、本知识点定位

统编版道德与法治七年级下册 **第四单元 生活在法治社会 第十课「法律保障生活」**。本框帮助我们理解法律的规范作用和保护作用，认识法律与生活的密切关系。

## 二、核心观点

1. 法律与我们的生活**息息相关**：从出生到成年，法律伴随一生（出生登记、入学、劳动、婚姻等）。
2. 法律具有**规范作用**：规定我们享有的权利和应履行的义务，为人们的行为提供准绳。
3. 法律具有**保护作用**：日常生活离不开法律的保护，法律是我们的"保护神"。
4. 法律**维护社会秩序**、**保障社会生活的有序运行**。
5. 我们要**学法、尊法、守法、用法**，学会依法维护自己的合法权益。

## 三、知识梳理

### 1. 法律与生活息息相关（是什么）

- 出生：办理出生医学证明、户口登记。
- 上学：受教育权受义务教育法保障。
- 消费：消费者权益保护法保护消费者。
- 出行：道路交通安全法规范交通行为。
- 法律渗透到社会生活的方方面面。

### 2. 法律的规范作用（重点）

- 法律规定人们享有什么权利、应履行什么义务。
- 法律为人的行为提供模式、标准和方向。
- 法律明确"可以做什么、必须做什么、应当做什么、不应当做什么"。
- 违反法律要承担相应的法律责任——法律的评价、警示作用。

### 3. 法律的保护作用（重点）

- 法律保护公民的生命健康、人格尊严、财产安全等合法权益。
- 当权益受到侵害时，法律为我们提供救济途径（调解、仲裁、诉讼等）。
- 法律通过制裁违法犯罪，维护社会的公平正义与秩序。

### 4. 怎样与法同行（怎么做）

- 认真学习法律知识，增强法治意识。
- 自觉遵守法律，依法规范自身行为。
- 学会运用法律武器维护合法权益，善用法律服务（法律援助、12348热线等）。

## 四、法律条文链接

- 《中华人民共和国义务教育法》：凡具有中华人民共和国国籍的适龄儿童、少年……依法享有平等接受义务教育的权利。
- 《中华人民共和国消费者权益保护法》：消费者在购买、使用商品和接受服务时享有人身、财产安全不受损害的权利。

## 五、案例分析

小林的爸爸网购了一台电暖器，使用中因质量问题起火造成损失，商家拒绝赔偿。爸爸依据消费者权益保护法向消协投诉，最终获得赔偿。这体现了法律的保护作用：当合法权益受到侵害时，法律为我们提供维权依据和救济途径；也启示我们要增强法治意识，学会依法维权而不是忍气吞声或过激报复。

## 六、背记要点

1. 法律与生活息息相关，伴随人的一生。
2. 规范作用：规定权利义务，为行为提供准绳。
3. 保护作用：保护合法权益，制裁违法犯罪，维护社会秩序。
4. 权益受侵害时的救济途径：协商、调解、仲裁、诉讼等。
5. 与法同行：学法、尊法、守法、用法。

## 七、自测小题

1. 法律的两大作用是______作用和______作用。
2. 判断：法律离中学生很远，与我们的生活无关。（对/错）
3. 消费者买到假货依法索赔，体现了法律的（A. 规范作用 B. 保护作用 C. 教育作用）。
4. 简答：法律的规范作用表现在哪些方面？

**答案**：1. 规范；保护 2. 错（法律与每个人的生活息息相关，伴随一生） 3. B
4. 答题要点：①法律规定人们享有的权利和应履行的义务；②为人们的行为提供模式、标准和方向，明确可以做什么、不应当做什么；③对违法行为作出否定评价，起警示作用。
