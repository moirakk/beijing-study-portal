# 保障财产权

标签：#财产权 #物权 #继承权

## 一、本知识点定位

统编版道德与法治七年级下册 **第四单元 生活在法治社会 第十一课「保障财产权」**。本框介绍财产权的主要内容，包括物权、债权、继承权、知识产权等及其法律保护。

## 二、核心观点

1. **财产权**是民事主体重要的民事权利，法律保护公民合法的私有财产。
2. **物权**包括所有权、用益物权、担保物权；所有权人对自己的财产享有**占有、使用、收益、处分**的权利。
3. 合法取得的财产受法律保护，**拾得遗失物应当返还**权利人。
4. **继承权**：自然人依法享有继承遗产的权利，继承分**法定继承**和**遗嘱继承**。
5. **知识产权**（著作权、专利权、商标权等）也是重要的财产权，创新成果受法律保护。

## 三、知识梳理

### 1. 物权（重点）

- 所有权四项权能：占有、使用、收益、处分。
- 国家、集体、私人的物权受法律平等保护。
- 未成年人的压岁钱归未成年人所有，父母可代为管理但不能随意处分。

### 2. 拾得遗失物

- 拾得遗失物，应当返还权利人，或送交公安等有关部门。
- "拾金不昧"既是传统美德，也是法律义务。

### 3. 债权与合同

- 合同是民事主体之间设立、变更、终止民事法律关系的协议。
- 依法成立的合同受法律保护，当事人应当按照约定履行义务。

### 4. 继承权

- 法定继承第一顺序：配偶、子女、父母。
- 第二顺序：兄弟姐妹、祖父母、外祖父母。
- 遗嘱继承优先于法定继承；自然人可以立遗嘱处分个人财产。

### 5. 知识产权

- 包括著作权、专利权、商标权等。
- 抄袭他人作品、盗版、假冒商标都是侵犯知识产权的行为。
- 保护知识产权就是保护创新。

## 四、法律条文链接

- 《中华人民共和国宪法》第十三条：公民的合法的私有财产不受侵犯。
- 《中华人民共和国民法典》第二百四十条：所有权人对自己的不动产或者动产，依法享有占有、使用、收益和处分的权利。
- 民法典第三百一十四条：拾得遗失物，应当返还权利人。

## 五、案例分析

小周在操场捡到一部手机，同学劝他"捡到就是自己的"。小周没有据为己有，而是交给了政教处，失主很快领回。依据民法典，拾得遗失物应当返还权利人或送交有关部门，拒不归还数额较大的还可能构成违法。小周的行为既践行了拾金不昧的传统美德，也履行了法律义务。

## 六、背记要点

1. 公民合法的私有财产不受侵犯（宪法规定）。
2. 所有权四项权能：占有、使用、收益、处分。
3. 拾得遗失物应当返还权利人——法律义务。
4. 法定继承第一顺序：配偶、子女、父母；遗嘱继承优先于法定继承。
5. 知识产权：著作权、专利权、商标权等，保护知识产权就是保护创新。
6. 压岁钱归未成年人本人所有。

## 七、自测小题

1. 所有权包括占有、使用、______、______四项权能。
2. 判断："捡到东西就归自己"是合法的。（对/错）
3. 法定继承的第一顺序继承人是（A. 兄弟姐妹 B. 配偶、子女、父母 C. 祖父母）。
4. 简答：财产权主要包括哪些内容？

**答案**：1. 收益；处分 2. 错（拾得遗失物应返还权利人或送交有关部门） 3. B
4. 答题要点：①物权（所有权等），对财产享有占有、使用、收益、处分的权利；②债权（合同权利）；③继承权（法定继承与遗嘱继承）；④知识产权（著作权、专利权、商标权等）。
