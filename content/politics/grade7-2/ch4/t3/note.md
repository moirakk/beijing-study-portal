# 认识民法典

标签：#民法典 #民事权利 #社会生活百科全书

## 一、本知识点定位

统编版道德与法治七年级下册 **第四单元 生活在法治社会 第十一课「认识民法典」**。本框介绍民法典的地位、基本原则和主要内容，帮助我们认识这部"社会生活的百科全书"。

## 二、核心观点

1. 《中华人民共和国民法典》是新中国成立以来**第一部以"法典"命名**的法律，2020年5月28日通过，2021年1月1日起施行。
2. 民法典被称为**"社会生活的百科全书"**，调整平等主体之间的人身关系和财产关系。
3. 民法典规定了**民事主体**从摇篮到坟墓各阶段的权利，保护我们的一生。
4. 民法典确立了**平等、自愿、公平、诚信、守法和公序良俗、绿色**等基本原则。
5. 民法典体现了**社会主义核心价值观**，彰显中国特色、实践特色、时代特色。

## 三、知识梳理

### 1. 民法典的基本情况（是什么）

- 共7编1260条：总则、物权、合同、人格权、婚姻家庭、继承、侵权责任。
- 调整对象：平等主体（自然人、法人、非法人组织）之间的人身关系和财产关系。
- 民事活动的基本遵循。

### 2. 民法典的基本原则（重点）

- **平等原则**：民事主体法律地位一律平等。
- **自愿原则**：按照自己的意思设立、变更、终止民事法律关系。
- **公平原则**：合理确定各方权利和义务。
- **诚信原则**：秉持诚实，恪守承诺。
- **守法和公序良俗原则**：不得违反法律，不得违背公共秩序和善良风俗。
- **绿色原则**：民事活动应当有利于节约资源、保护生态环境。

### 3. 民法典与我们的生活（为什么）

- 出生前：胎儿享有继承、接受赠与的权利。
- 未成年阶段：八周岁以上为限制民事行为能力人。
- 成年后：就业、买房、结婚、继承均由民法典规范。
- 高空抛物、网络虚拟财产、个人信息保护等新问题都有回应。

### 4. 未成年人与民事行为能力

- 不满八周岁：无民事行为能力人，由法定代理人代理民事活动。
- 八周岁以上未成年人：限制民事行为能力人，可实施与年龄、智力相适应的民事法律行为。

## 四、法律条文链接

- 《中华人民共和国民法典》第四条：民事主体在民事活动中的法律地位一律平等。
- 第九条：民事主体从事民事活动，应当有利于节约资源、保护生态环境（绿色原则）。
- 第十九条：八周岁以上的未成年人为限制民事行为能力人。

## 五、案例分析

12岁的小刚背着父母用压岁钱花6000元购买了一部高端手机，父母发现后要求商家退货。依据民法典，小刚是限制民事行为能力人，购买高价手机与其年龄、智力不相适应，该行为需经法定代理人同意或追认，父母有权要求退货退款。这说明民法典既保护未成年人权益，也规范民事交易秩序。

## 六、背记要点

1. 民法典是新中国第一部以"法典"命名的法律，2021年1月1日施行。

3. 调整平等主体之间的人身关系和财产关系。
4. 基本原则：平等、自愿、公平、诚信、守法和公序良俗、绿色。
