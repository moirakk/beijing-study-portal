# 专题十 语法填空（非谓语动词）

## 核心概念 / 考点

非谓语动词包括不定式（to do）、动名词（doing）和分词（doing/done），在句中不能单独作谓语。考查考生判断非谓语动词的形式：作主语、宾语、定语、状语、补语等。解题关键是判断非谓语动词与逻辑主语的关系（主动用 doing，被动用 done）及动作发生的时间。

**解题方法**：先判断句中是否已有谓语动词，若有则需用非谓语；再判断非谓语与逻辑主语的主被动关系（主动 doing，被动 done）；最后根据固定搭配（如 want to do, enjoy doing）确定形式。

## 知识梳理

| 非谓语形式 | 主动 | 被动 | 常见用法 |
| --- | --- | --- | --- |
| 不定式 | to do | to be done | 表目的、将来 |
| 动名词 | doing | being done | 作主语、宾语 |
| 现在分词 | doing | being done | 表主动、进行 |
| 过去分词 | — | done | 表被动、完成 |

## 典型例题

**例 1**：I want ___ (visit) the museum.

**解**：固定搭配 want to do，填 to visit。

**例 2**：___ (see) from the hill, the city looks beautiful.

**解**：see 与逻辑主语 the city 是被动关系，用过去分词，填 Seen。

**例 3**：He enjoys ___ (listen) to music.

**解**：固定搭配 enjoy doing，填 listening。

## 易错点

- 未判断句中是否已有谓语，误用谓语形式。
- 主被动关系判断错误，该用 done 却用 doing。
- 混淆不定式与动名词的固定搭配。
- 忽视非谓语作状语时与逻辑主语的关系。
- 现在分词与过去分词混用。

## 背记要点

1. 句中已有谓语动词时，其余动词用非谓语。
2. 与逻辑主语主动关系用 doing，被动关系用 done。
3. 常见搭配：want/decide/hope to do；enjoy/finish/practice doing。
4. 表目的用不定式 to do。
5. 过去分词 done 表被动、完成。
6. 现在分词 doing 表主动、进行。
