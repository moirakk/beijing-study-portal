# Unit 3 Developing ideas

标签：#Unit3 #DevelopingIdeas #时间状语从句 #实现梦想

## 一、课文精讲

Developing ideas 是 Unit 3 的拓展与运用板块。本环节通过对话、访谈或短文，进一步讨论"如何克服困难、坚持梦想"。课文常呈现榜样人物的成长经历，或学生之间互相鼓励制定行动计划的情景。

学习重点是如何用 when, before, after 引导的时间状语从句，把"现在的准备"与"将来的目标"联系起来，例如 When I grow up, I'm going to be a teacher.

## 二、重点词汇

- **prepare** v. 准备  **preparation** n. 准备
- **step** n. 步骤  **action** n. 行动
- **habit** n. 习惯  **daily** adj. 每日的
- **schedule** n. 日程表  **timetable** n. 时间表
- **lead to** 导致；通向  **depend on** 依靠；取决于
- **as long as** 只要  **as soon as** 一……就……
- **grow up** 长大  **leave school** 毕业
- **make a decision** 做决定  **stick to** 坚持

## 三、语法要点

**when / before / after 引导的时间状语从句**

当主句为一般将来时（或 be going to）时，时间状语从句通常用一般现在时表示将来，即"主将从现"。

- **When** I grow up, I'm going to travel around the world.
- Please call me **after** you get home.
- **Before** you go to bed, you should read for ten minutes.

**常见结构**：

- be going to + 动词原形：表示计划
- want to / hope to / plan to + 动词原形：表示愿望或计划
- would like to + 动词原形：更委婉地表达意愿

## 四、易错点

1. 时间状语从句中误用将来时：❌ *When I will grow up, I'm going to ...* → ✅ When I **grow up**, I'm going to ...
2. depend on 后接名词或动名词：Success **depends on** hard work. / It depends on **working** hard.
3. stick to 中 to 是介词，后接 doing：Stick to **practising** every day.

## 五、练习题

1. 单项选择：I'm going to study medicine ______ I leave school.（A. when  B. while  C. during）
2. 连词成句：going / am / I / as soon as / to / start / possible / it / finish / I (.)
3. 用所给词适当形式填空：
   - She is going to be a writer when she ______ (grow) up.
   - You should prepare well before you ______ (make) a decision.
4. 汉译英：只要我坚持练习，我的梦想就会实现。

**答案**：1. A  2. I'm going to start it as soon as I finish.  3. grows; make  4. My dream will come true as long as I keep practising.
