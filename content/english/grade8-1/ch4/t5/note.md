# Unit 4 Reflection

标签：#Unit4 #Reflection #单元复习 #比较级总结

## 一、课文精讲

Reflection 是 Unit 4 *Digital life* 的总结与反思板块。本环节要求学生回顾整个单元围绕"数字生活"所学的内容，包括与科技设备和网络活动相关的词汇、形容词与副词的比较级、as ... as 结构以及表达观点和辩论的语言。

通过自评表，学生可以检查自己是否达成了以下目标：能听懂并讨论数字生活相关话题；能用比较级比较不同事物；能用 as ... as 表达同等比较；能就"健康上网"等话题进行口头或书面展示。

## 二、重点词汇

- **digital** adj. 数字的  **device** n. 设备
- **smartphone / tablet / laptop / computer** 智能设备
- **Internet / online / offline** 网络/在线/离线
- **app / website / social media** 应用/网站/社交媒体
- **advantage / disadvantage** 优点/缺点
- **convenient / popular / necessary** 方便/受欢迎/必要
- **addicted to / screen time / stay in touch** 上瘾/屏幕时间/保持联系
- **face to face / waste time / instead of** 面对面/浪费时间/代替

## 三、语法要点

**Unit 4 核心语法网络**

1. **形容词比较级**：
   - 单音节 + -er：fast → faster
   - 多音节 + more：important → more important
   - 不规则：good → better；bad → worse
   - A + be + 比较级 + than + B
2. **副词比较级**：
   - carefully → more carefully
   - well → better
   - A + v. + 比较级 + than + B
3. **as ... as**：
   - 肯定：as + 原级 + as
   - 否定：not as / so + 原级 + as
4. **修饰比较级**：much, a lot, even, a little, far

## 四、易错点

1. 比较级前不可加 very，应加 much / a lot：❌ *very better* → ✅ **much better**
2. 比较对象要一致：This phone is more expensive **than that one**.
3. less 后接原级多音节形容词：less important，不可说 less more important。

## 五、练习题

1. 综合填空：
   - My phone is ______ (cheap) than yours, but it works ______ (well).
   - Reading online is not ______ (interesting) as reading paper books for me.
   - The ______ (much) you use your eyes, the ______ (tired) they get.
2. 句型转换：This computer works fast. That computer works fast, too.（用 as ... as 合并）
3. 写作：比较线上购物与线下购物的优缺点，80 词左右。

**答案**：1. cheaper; better; as interesting; more; more tired  2. This computer works as fast as that one.  3. （略）
