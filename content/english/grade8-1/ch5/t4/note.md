# Unit 5 Presenting ideas

标签：#Unit5 #PresentingIdeas #规则倡议 #综合输出

## 一、课文精讲

Presenting ideas 是 Unit 5 的综合输出板块。学生需要围绕"Play by the rules?"主题完成一项实际任务，例如为班级设计新的班规、制作一份"安全出行"宣传海报，或进行小组辩论"规则是否限制自由"。

本环节强调规则的合理表达与说服能力。学生需要说明规则的必要性、具体内容和违反后果，并提出建设性建议。展示时可以使用祈使句、must / should / if 条件句等结构。

## 二、重点词汇

- **class rule** 班规  **school rule** 校规
- **traffic rule** 交通规则  **safety rule** 安全规则
- **poster** n. 海报  **slogan** n. 标语
- **design** v./n. 设计  **discuss** v. 讨论
- **agree with** 同意  **disagree with** 不同意
- **be supposed to** 应该  **be allowed to** 被允许
- **make sense** 有道理  **for the good of** 为了……的利益

## 三、语法要点

**倡议书中常用句型**

1. 说明规则必要性：
   - Rules are important because they help us live safely.
   - Following rules is good for everyone.
2. 表达禁止与要求：
   - We **mustn't** run in the hallway.
   - Everyone **should** arrive at school on time.
3. 表达假设与后果：
   - **If** we follow traffic rules, we **will keep** safe.
   - **If** you break the rules, you **may get** punished.
4. 提出改进建议：
   - I think we should add a rule about ...
   - Why not set up a "rule of the week"?

## 四、易错点

1. be supposed to 表示"应该"，后接动词原形：We **are supposed to** finish homework on time.
2. be allowed to 表示"被允许"，被动含义：Students **are allowed to** use phones after class.
3. 写规则时，祈使句和情态动词可混用，但要保持语气一致。

## 五、练习题

1. 单项选择：Students ______ not run in the hallway.（A. must  B. are  C. should）
2. 连词成句：follow / we / if / rules / the / will / safe / be / we (.)
3. 改错：If you will be late, you should tell the teacher.
4. 写作：为班级写三条合理的班规，并说明理由，80 词左右。

**答案**：1. A  2. If we follow the rules, we will be safe.  3. will be → are  4. （略）
