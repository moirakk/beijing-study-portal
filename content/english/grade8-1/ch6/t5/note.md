# Unit 6 Reflection

标签：#Unit6 #Reflection #单元复习 #灾害安全

## 一、课文精讲

Reflection 是 Unit 6 *When disaster strikes* 的总结与反思板块。本环节要求学生回顾整个单元围绕"自然灾害与安全"所学的内容，包括灾害相关词汇、过去进行时、一般过去时、when/while 引导的时间状语从句以及安全建议的表达。

通过自评表，学生可以检查自己是否达成了以下目标：能听懂并理解灾害相关的新闻或故事；能用过去进行时描述过去某一时刻正在发生的事；能用 when/while 连接两个过去的动作；能就灾害安全话题进行口头或书面展示。

## 二、重点词汇

- **disaster / natural disaster** 灾难/自然灾害
- **earthquake / flood / typhoon / fire / storm** 地震/洪水/台风/火灾/暴风雨
- **shake / fall down / run away / hide / cover** 摇晃/倒塌/逃离/躲藏/覆盖
- **brave / calm / frightened / terrible** 勇敢/冷静/害怕/可怕
- **safety / warning / alarm / exit / shelter** 安全/警告/警报/出口/避难所
- **stay calm / keep away from / stay indoors** 保持冷静/远离/待在室内
- **evacuate / rescue / save / protect** 疏散/营救/拯救/保护

## 三、语法要点

**Unit 6 核心语法网络**

1. **过去进行时**：
   - 结构：was / were + doing
   - I was reading when the earthquake happened.
2. **一般过去时与过去进行时的连用**：
   - 长动作（背景）用过去进行时，短动作（事件）用一般过去时。
   - While we were having dinner, the lights went out.
3. **when 与 while**：
   - when 从句可长可短，可用一般过去时或过去进行时。
   - while 从句常用过去进行时，强调"在……期间"。
4. **安全建议常用祈使句**：
   - Stay calm. / Keep away from windows. / Don't use the lift.

## 四、易错点

1. 过去进行时中 be 动词用 was/were，不可与现在时混淆。
2. happen, start, begin 等短暂性动词通常不用进行时。
3. when 从句在前时常用逗号，while 引导的从句多用进行时。

## 五、练习题

1. 综合填空：
   - When the rainstorm ______ (come), we ______ (watch) TV at home.
   - ______ (not play) outside during a typhoon. It is dangerous.
   - While Tom ______ (walk) to school, he ______ (see) an accident.
2. 句型转换：I was doing my homework. My father came back.（用 when 合并）
3. 写作：以 "How to Keep Safe in an Earthquake" 为题，写一篇 80 词左右的短文。

**答案**：1. came; were watching; Don't play; was walking; saw  2. I was doing my homework when my father came back.  3. （略）
