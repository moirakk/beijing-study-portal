# Unit 2 It is still read and loved

标签：#Module7 #汤姆索亚历险记 #被动语态 #阅读课

## 一、课文精讲

本单元是 Module 7 的阅读课，课文是对马克·吐温（Mark Twain）名著**《汤姆·索亚历险记》（The Adventures of Tom Sawyer）**的书评。文章介绍：故事发生在 19 世纪美国密西西比河畔的小镇，主人公 Tom 是个聪明调皮的男孩，最著名的情节是他被罚刷栅栏时，巧妙地让伙伴们心甘情愿替他干活还倒贴礼物。书评最后评价：这本书出版一百多年后**仍被人们阅读和喜爱**（It **is still read and loved**）。

书评的结构值得学习：**书籍信息 → 情节概述 → 精彩片段 → 评价推荐**，是中考读写常考的应用文体。

关键句：
- The story **is set in** the USA in the 1840s. 故事以19世纪40年代的美国为背景。
- Tom **is asked** to paint the fence. 汤姆被要求刷栅栏。
- More than one hundred years later, it **is still read and loved** by people all over the world. 一百多年后，它仍被全世界的人阅读和喜爱。

## 二、重点词汇

- **adventure** n. 冒险  **fence** n. 栅栏
- **paint** v. 刷漆；绘画  **dead** adj. 死的
- **funeral** n. 葬礼  **alive** adj. 活着的
- **southern** adj. 南方的  **crazy** adj. 疯狂的
- **be set in** 以……为背景  **run away** 逃跑
- **turn up** 出现；调大  **at one's own funeral** 在自己的葬礼上
- **pay for** 付款；付出代价  **come to life** 活跃起来

## 三、语法要点

**被动语态（含情态动词的被动）**

1. 一般现在时被动：The book **is loved** by readers.
2. 一般过去时被动：It **was written** by Mark Twain.
3. **情态动词被动**：can/must/should + be + 过去分词：
   - The book **can be found** in every bookshop.
   - The fence **must be painted** today.
4. 含 by 短语强调执行者：The novel was written **by Mark Twain in 1876**.

## 四、易错点

1. 情态动词被动中 be 不可漏：❌ can found → ✅ can **be** found。
2. alive（活着的）作表语/后置定语；living 可作前置定语：a living writer。
3. be set in + 时间/地点背景，是书评影评高频表达。
4. 并列被动动词共用 be：It is still read **and** loved.（第二个 is 省略）

## 五、练习题

1. 单项选择：The Adventures of Tom Sawyer ______ by Mark Twain in 1876.（A. wrote  B. was written  C. is written  D. was wrote）
2. 单项选择：This book is so popular that it ______ in many libraries.（A. can find  B. can be found  C. can be find  D. can found）
3. 句型转换：People all over the world still love this book.（改被动）This book ______ still ______ by people all over the world.
4. 用所给词适当形式填空：The story is set ______ (in/on) a small town along the Mississippi River.
5. 汉译英：这本书被翻译成多种语言，必须在下周之前归还图书馆。

**答案**：1. B  2. B  3. is; loved  4. in  5. The book has been translated into many languages and it must be returned to the library before next week.
