# Unit 3 Language in use

标签：#Module7 #语法整合 #被动语态 #书评写作

## 一、模块语法归纳

本单元整合 Module 7 Great books 的核心语法：**被动语态**（一般现在时、一般过去时、含情态动词），并归纳介绍书籍、发表书评的表达方式。

## 二、被动语态系统梳理

**1. 构成总表**：

| 时态 | 结构 | 例句 |
| --- | --- | --- |
| 一般现在时 | am/is/are + done | The book is read widely. |
| 一般过去时 | was/were + done | It was written in 1876. |
| 情态动词 | can/must/should + be + done | It can be borrowed. |

**2. 主动改被动步骤**：
- 主动宾语 → 被动主语；动词 → be + 过去分词；主动主语 → by + 宾格（可省）。
- He wrote the book. → The book **was written** (by him).

**3. 使用被动的场合**：不知道/不必说出执行者；强调动作承受者。

## 三、书评写作句式积累

- The book was written by... in + 年份。
- The story is set in + 时间/地点。
- The main character is..., who...
- My favourite part is when...
- It is still read and loved today. / I strongly recommend it because...

## 四、易错点

1. 不规则过去分词强化：write-written, know-known, speak-spoken, read-read[red], give-given。
2. 不及物动词（happen, take place, appear）**无被动语态**。
3. 双宾语动词的被动：He gave me a book. → I **was given** a book. / A book **was given to** me.
4. 情态动词被动疑问式：Can the book **be borrowed**?

## 五、练习题

1. 单项选择：Paper ______ first ______ in China about 2,000 years ago.（A. is; invented  B. was; invented  C. is; inventing  D. was; inventing）
2. 单项选择：The classroom must ______ clean every day.（A. keep  B. is kept  C. be kept  D. to be kept）
3. 单项选择：A talk on Chinese history ______ in our school next Monday.（A. is given  B. will be given  C. has been given  D. gives）
4. 句型转换：You can find the answer in the book.（改被动）The answer ______ ______ ______ in the book.
5. 汉译英：《论语》是两千多年前写成的，今天仍被广泛阅读。

**答案**：1. B  2. C  3. B  4. can be found  5. The Analects was written more than two thousand years ago, and it is still widely read today.
