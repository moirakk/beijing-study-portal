## 一、复习范围

Revision Module A 综合复习 **Module 1 – Module 6** 的全部语言点，话题涵盖：世界奇观、公共假日、英雄人物、独自在家、博物馆、问题与建议。

## 二、语法体系梳理

**1. 感叹句（M1）**
- What + (a/an) + adj. + n. (+主谓)! ／ How + adj./adv. (+主谓)!
- What a wonderful place! = How wonderful the place is!

**2. 现在完成时 + since/for（M2）**
- We have known each other **since** 2018 / **for** five years.
- 短暂动词转延续：buy→have, join→be in, come→be here。

**3. 并列连词 and/but/or/so（M3）**
- 祈使句 + and/or + 将来时句。
- because 与 so、although 与 but 不同现。

**4. 让步状语从句 although/though 与 so...that（M4）**
- Although it was hard, he never gave up.
- I was so tired that I couldn't walk. = too tired to walk.

**5. 情态动词表规则（M5）**
- must 必须 / mustn't 禁止 / needn't 不必 / can 可以。

**6. if 条件状语从句（M5-M6）**
- 主将从现、主祈从现、主情态从现三搭配。

## 三、高频短语汇总

- agree with / more than / on one's way to（M1）
- as soon as / get together / depend on（M2）
- take part in / be proud of / give up（M3）
- look after / leave sb. alone / be bored with（M4）
- make sure / follow the rules / for free（M5）
- throw away / instead of / stay away from（M6）

## 四、易错点集中排查

1. 感叹句先找中心词：名词 What，形副 How。
2. since + 时间点/过去时从句；for + 时间段。
3. mustn't（禁止）≠ needn't（不必）。
4. 时间/条件从句主将从现，从句不用 will。
5. so + 形副 + that；such + 名词 + that；so many/much + 名词。

## 五、综合练习

1. 单项选择：______ exciting the game is! I have watched it ______ two hours.（A. How; since  B. What; for  C. How; for  D. What an; since）
2. 单项选择：You ______ pay for the museum. It's free, but you ______ touch the exhibits.（A. mustn't; needn't  B. needn't; mustn't  C. must; can't  D. can't; must）
3. 单项选择：He was ______ excited that he couldn't say a word as soon as he ______ the good news.（A. so; heard  B. such; heard  C. so; will hear  D. too; hears）
4. 完成句子：虽然任务很难，但如果我们一起努力，就能完成它。______ the task is difficult, we can finish it if we work together.
5. 书面表达（提纲）：以 "My Hero" 为题写一篇 80 词短文：他/她是谁 → 主要事迹（用过去时+并列句）→ 你的感受（用感叹句和 so...that）。

**答案**：1. C  2. B  3. A  4. Although/Though  5. 略（参照 M3 人物传记句式）
