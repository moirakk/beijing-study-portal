# 第1节 两种电荷

## 核心概念表

| 概念 | 含义 | 说明 |
|---|---|---|
| 摩擦起电 | 摩擦过的物体能吸引轻小物体的现象 | 物体带了电（电荷） |
| 正电荷 | 与丝绸摩擦过的玻璃棒所带的电荷 | 规定 |
| 负电荷 | 与毛皮摩擦过的橡胶棒所带的电荷 | 规定 |
| 电荷量 | 电荷的多少 | 符号 Q，单位库仑（C） |
| 元电荷 | 最小的电荷量 | $e=1.6\times10^{-19}\ \text{C}$ |

## 知识梳理

自然界只有**两种电荷**：正电荷和负电荷。电荷间的相互作用规律：**同种电荷相互排斥，异种电荷相互吸引**。

原子由原子核和核外电子组成。原子核带正电，电子带负电。通常情况下原子呈中性。

摩擦起电的实质：**电子的转移**（不是创造电荷）。束缚电子本领弱的物体失去电子带正电，束缚电子本领强的物体得到电子带负电。两个物体摩擦后带等量异种电荷。

**验电器**：根据同种电荷相互排斥的原理制成，用来检验物体是否带电。金属箔张角越大，物体所带电荷越多（但不能判断电荷种类）。

**导体和绝缘体**：容易导电的物体叫导体，如金属、人体、大地、石墨、酸碱盐溶液；不容易导电的物体叫绝缘体，如橡胶、玻璃、塑料、陶瓷、干燥的空气。金属导电靠**自由电子**。导体和绝缘体之间没有绝对界限，条件改变时可以相互转化。

## 实验要点

- 摩擦过的塑料尺吸引碎纸屑说明带电体吸引轻小物体；验电器金属箔张开说明同种电荷排斥。

## 对比分析

| 比较项 | 导体 | 绝缘体 |
|---|---|---|
| 导电能力 | 容易导电 | 不容易导电 |
| 原因 | 有大量自由电荷 | 电荷几乎都被束缚 |
| 举例 | 金属、人体、大地、盐水 | 橡胶、玻璃、塑料、干木头 |

## 背记要点

1. 两种电荷：正（丝绸摩擦玻璃棒）、负（毛皮摩擦橡胶棒）。
2. 作用规律：同种相斥，异种相吸。
3. 摩擦起电实质是电子转移，得电子带负电，失电子带正电。
4. 验电器原理：同种电荷相互排斥；元电荷 $e=1.6\times10^{-19}$ C。
