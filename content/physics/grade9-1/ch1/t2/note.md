# 第2节 内能

## 核心概念表

| 概念 | 含义 | 单位 |
|---|---|---|
| 内能 | 物体内部所有分子热运动的动能与分子势能的总和 | J（焦耳） |
| 分子动能 | 分子由于热运动而具有的能 | J |
| 分子势能 | 分子间由于相互作用而具有的能 | J |
| 热量 | 热传递过程中传递能量的多少 | J |

## 知识梳理

构成物体的分子在不停地做热运动，具有分子动能；分子间存在引力和斥力，具有分子势能。物体内部所有分子热运动的动能与分子势能的总和，叫做物体的内能。

一切物体，不论温度高低，都具有内能。同一物体温度越高，分子热运动越剧烈，内能越大。内能还与物体的质量、状态等因素有关。

改变内能的两种方式：
- **热传递**：能量从高温物体传向低温物体，或从同一物体的高温部分传向低温部分。热传递的条件是存在温度差，传递的是能量（内能），不是温度。
- **做功**：对物体做功，物体内能增大（如压缩气体、摩擦生热）；物体对外做功，物体内能减小（如气体膨胀推动活塞）。

做功和热传递在改变内能上是**等效的**。做功是能量形式的转化（机械能与内能相互转化），热传递是内能的转移。

## 实验要点

- 压缩空气点火实验：迅速下压活塞，筒内硝化棉燃烧，说明对物体做功，物体内能增大，温度升高。
- 气体膨胀做功实验：向瓶内打气，瓶塞跳出时瓶内出现白雾，说明气体对外做功，内能减小，温度降低，水蒸气液化。
- 摩擦生热：搓手取暖、钻木取火，都是通过做功改变内能。

## 对比分析

| 项目 | 做功 | 热传递 |
|---|---|---|
| 实质 | 能量形式的转化 | 内能的转移 |
| 条件 | 有力且沿力方向移动距离 | 存在温度差 |
| 实例 | 摩擦生热、压缩气体 | 晒太阳、热水袋取暖 |

| 概念 | 温度 | 热量 | 内能 |
|---|---|---|---|
| 描述用词 | 升高/降低/是 | 吸收/放出 | 增大/减小/有 |
| 是否状态量 | 是 | 否（过程量） | 是 |

## 背记要点

1. 内能 = 所有分子的动能 + 分子势能之总和，一切物体都有内能。
2. 改变内能的两种方式：做功和热传递，二者等效。
3. 热传递条件是温度差，传递的是内能，方向从高温到低温。
4. 对物体做功内能增大；物体对外做功内能减小。
5. 热量是过程量，只能说"吸收"或"放出"，不能说"含有"热量。
6. 温度升高，内能一定增大；内能增大，温度不一定升高（如晶体熔化）。
