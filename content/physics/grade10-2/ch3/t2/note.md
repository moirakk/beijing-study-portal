# 2 万有引力定律

## 概念定义

**万有引力定律**（牛顿，1687）：自然界中任何两个物体都互相吸引，引力方向沿两者连线，大小与两物体质量的乘积成正比、与它们之间距离的二次方成反比：
$$F=G\dfrac{m_1m_2}{r^2}$$
其中引力常量 $G=6.67\times10^{-11}\ \text{N}\cdot\text{m}^2/\text{kg}^2$，由**卡文迪什**用扭秤实验测出。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 发现思路 | 猜想引力使月球绕地球运动 → "月—地检验"：$a_月\approx\dfrac{g}{60^2}$，与 $r_月=60R_地$ 的平方反比预期一致 |
| 适用条件 | 质点间；均匀球体可视为质量集中于球心（$r$ 取球心距） |
| 普遍性 | 任何两个物体之间都存在，通常因太小而不易察觉 |
| 引力常量 | 卡文迪什扭秤测定，使定律有了实用价值（"称量地球质量"） |
| 重力与引力 | 地面上重力是引力的一个分量（另一分量提供随地球自转的向心力）；不考虑自转时 $mg=G\dfrac{Mm}{R^2}$ |

**黄金代换**：$GM=gR^2$（$R$ 为星球半径，$g$ 为星球表面重力加速度）。

## 典型例题

**例 1**：两个质量均为 $m=60\ \text{kg}$ 的人相距 $r=1\ \text{m}$，估算他们之间的万有引力，并说明为何感觉不到。

**解**：$F=G\dfrac{m^2}{r^2}=6.67\times10^{-11}\times\dfrac{3600}{1}\approx 2.4\times10^{-7}\ \text{N}$。
此力比一粒芝麻的重量还小得多，远小于人所受其他力，故感觉不到。

**例 2**：已知地球表面重力加速度 $g=9.8\ \text{m/s}^2$、地球半径 $R=6.4\times10^6\ \text{m}$，求地球质量（$G=6.67\times10^{-11}\ \text{N}\cdot\text{m}^2/\text{kg}^2$）。

**解**：地面附近 $mg=G\dfrac{Mm}{R^2}$，
$M=\dfrac{gR^2}{G}=\dfrac{9.8\times(6.4\times10^6)^2}{6.67\times10^{-11}}\approx 6.0\times10^{24}\ \text{kg}$。

## 易错点

- 公式适用于**质点**或均匀球体（取球心距）；两物体紧贴时不能令 $r\to0$ 得"无穷大引力"。
- 重力与万有引力一般不相等（差随自转的向心力），仅在**两极**处相等；中学多数题目按 $mg=G\dfrac{Mm}{R^2}$ 近似处理。
- $G$ 是普适常量，与天体无关；开普勒常数 $k$ 才与中心天体有关。
- "月—地检验"验证的是**平方反比**关系，是定律得以推广到"万有"的关键一步。

## 背记要点

1. $F=G\dfrac{m_1m_2}{r^2}$，$G=6.67\times10^{-11}\ \text{N}\cdot\text{m}^2/\text{kg}^2$（卡文迪什测定）。
2. 均匀球体等效于质点在球心；$r$ 为球心间距。
3. 黄金代换 $GM=gR^2$，天体问题必备。
4. 高考视角：结合圆周运动求中心天体质量/密度是主干题型，黄金代换可绕开未知的 $G M$。
