# 1 曲线运动

## 概念定义

**曲线运动**：物体运动轨迹是曲线的运动。做曲线运动的物体在某一点的**速度方向**沿轨迹在该点的**切线方向**，且指向运动前进的一侧。

**曲线运动的条件**：合外力与速度**不在同一直线上**（合外力有垂直于速度的分量）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 速度方向 | 沿轨迹切线方向，时刻改变 |
| 性质 | 速度方向变化 ⇒ 曲线运动一定是**变速运动**，一定有加速度 |
| 条件 | $F_合$ 与 $v$ 不共线（$F_合\neq 0$ 且不沿速度方向） |
| 轨迹特点 | 轨迹夹在 $F_合$ 与 $v$ 方向之间，且向 $F_合$ 一侧**弯曲** |
| 速率变化 | $F_合$ 与 $v$ 夹角 $<90°$ 加速；$>90°$ 减速；$=90°$ 速率不变 |

## 典型例题

**例 1**：砂轮打磨工件时火星四溅，火星沿什么方向飞出？为什么？

**解**：火星沿砂轮边缘该点的**切线方向**飞出。因为脱离砂轮瞬间，火星的速度方向沿圆周的切线方向，脱离后（不计重力影响的瞬间）沿该方向飞出。这直接说明曲线运动中速度方向沿轨迹切线。

**例 2**：物体以初速度 $v_0$ 沿 $x$ 轴正方向运动，受到沿 $y$ 轴正方向的恒力 $F$，判断轨迹形状与速率变化。

**解**：$F$ 与 $v_0$ 垂直，满足曲线运动条件，轨迹为**曲线**（实为抛物线），向 $y$ 轴正方向一侧弯曲，且夹在 $v_0$ 与 $F$ 方向之间。运动中 $F$ 与 $v$ 夹角始终小于 $90°$（$v$ 逐渐偏向 $F$），故速率**不断增大**。

## 易错点

- 曲线运动速度方向时刻变化，故**一定是变速运动**，但速率不一定变化（如匀速圆周运动）。
- 合外力恒定不代表轨迹是圆；恒力与初速度不共线时轨迹为抛物线。
- 轨迹"弯向"合外力一侧，但合外力方向不一定指向轨迹的"凹侧圆心"（一般情形只需指向凹侧）。
- 已知轨迹和速度方向可反推合外力大致方向：在 $v$ 指向凹侧的一边。

## 背记要点

1. 速度方向：轨迹切线方向；曲线运动必为变速运动。
2. 条件：$F_合$ 与 $v$ 不共线。
3. 轨迹三要素：夹在 $F$、$v$ 之间，弯向 $F$ 一侧。
4. 速率判定：$F$ 与 $v$ 成锐角加速、钝角减速、垂直不变。
5. 高考视角：曲线运动条件与轨迹判断常以选择题出现，注意由轨迹图反推力和速度方向的合理性。
