# 2 运动的合成与分解

## 概念定义

**合运动与分运动**：一个物体同时参与几个运动时，实际发生的运动为**合运动**，同时参与的各个运动为**分运动**。

**运动的合成与分解**：已知分运动求合运动叫**合成**；已知合运动求分运动叫**分解**。位移、速度、加速度都是矢量，其合成与分解遵循**平行四边形定则**。

## 知识梳理

| 特性 | 含义 |
| --- | --- |
| 独立性 | 各分运动互不影响，独立进行 |
| 等时性 | 各分运动与合运动经历的**时间相同** |
| 同体性 | 各分运动与合运动是同一物体的运动 |
| 矢量性 | $\vec{s}=\vec{s}_1+\vec{s}_2$，$\vec{v}=\vec{v}_1+\vec{v}_2$（平行四边形定则） |

**运动性质判断**：两个匀速直线运动的合运动仍是匀速直线运动；一个匀速直线运动与一个（不共线的）匀变速直线运动的合运动是**匀变速曲线运动**。

## 典型例题

**例 1**：河宽 $d=200\ \text{m}$，水流速 $v_水=3\ \text{m/s}$，船在静水中速度 $v_船=4\ \text{m/s}$。求渡河最短时间及此时的合位移。

**解**：船头垂直河岸时渡河时间最短：$t_{min}=\dfrac{d}{v_船}=\dfrac{200}{4}=50\ \text{s}$。
沿水流方向漂移 $x=v_水 t=150\ \text{m}$，合位移 $s=\sqrt{200^2+150^2}=250\ \text{m}$。

**例 2**：上题中若要求渡河位移最短（垂直到达正对岸），船头应指向何方？渡河时间多少？

**解**：因 $v_船>v_水$，可使合速度垂直河岸。船头偏向上游，与河岸垂线成 $\theta$ 角，满足 $v_船\sin\theta=v_水$，即 $\sin\theta=3/4$。
合速度 $v=\sqrt{v_船^2-v_水^2}=\sqrt{16-9}=\sqrt{7}\ \text{m/s}$，$t=\dfrac{d}{v}=\dfrac{200}{\sqrt7}\approx 75.6\ \text{s}$。

## 易错点

- 渡河**时间只由垂直河岸的分速度决定**，与水速无关；最短时间对应船头垂直河岸。
- 当 $v_船<v_水$ 时不能垂直到达对岸，最短位移需用图解法（过水速矢量端点作船速圆的切线）。
- 绳（杆）拉物模型：沿绳方向分速度相等，应把物体的**实际速度**分解为沿绳和垂直绳两个分量，不能把绳速直接当作物速。
- 合运动才是物体的实际运动，轨迹、位移均指合运动。

## 背记要点

1. 合成与分解遵循平行四边形定则；分运动等时、独立。
2. 渡河两问：$t_{min}=d/v_船$（船头垂直河岸）；$v_船>v_水$ 时最短位移为河宽 $d$。
3. 恒定加速度与速度不共线 ⇒ 匀变速曲线运动。
4. 高考视角：小船渡河、绳端速度分解是高频模型，抓住"实际运动是合运动"这一分解出发点。
