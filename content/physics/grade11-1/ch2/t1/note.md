# 1 简谐运动

## 概念定义

**机械振动**：物体（或物体的一部分）在**平衡位置**附近所做的往复运动，简称振动。

**简谐运动（SHM）**：如果物体的位移与时间的关系遵从**正弦函数**规律，即振动图象（$x$–$t$ 图象）是一条正弦曲线，这样的振动叫做简谐运动。它是最简单、最基本的振动。

**弹簧振子**：小球与轻弹簧组成的系统（不计摩擦、弹簧质量），是简谐运动的理想模型。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 位移 $x$ | 以**平衡位置**为起点指向振子所在位置的矢量 |
| 运动特点 | 往复性、周期性；在平衡位置速度最大，最大位移处速度为零 |
| 图象 | $x$–$t$ 图象为正弦曲线（注意：是振动图象，不是轨迹） |
| 加速度 | 最大位移处最大，平衡位置处为零；方向总指向平衡位置 |
| 对称性 | 关于平衡位置对称的两点速率、加速度大小、动能均相等 |

## 典型例题

**例 1**：弹簧振子在 A、B 两点间振动，O 为平衡位置，AB 间距 $8\ \text{cm}$，振子由 A 首次到 B 用时 $0.5\ \text{s}$。求振幅和周期。

**解**：振幅 $A=\dfrac{AB}{2}=4\ \text{cm}$。A 到 B 是半个周期，$T=2\times0.5=1\ \text{s}$。

**例 2**：简谐运动的振子经过关于平衡位置对称的 P、Q 两点时，比较其速度、加速度。

**解**：由对称性，P、Q 两点位移大小相等、方向相反，故加速度**大小相等、方向相反**（都指向平衡位置）；速率相等，速度方向不确定（可能同向或反向）。

## 易错点

- 振动位移从**平衡位置**量起，不是从出发点量起。
- $x$–$t$ 图象是位移随时间的变化关系，**不是**振子的运动轨迹（轨迹是直线段）。
- 振子经过平衡位置时速度最大、加速度为零，但**合力与加速度为零不代表匀速**——方向即将改变的是位移增减趋势。
- 一个周期内路程为 $4A$，半个周期为 $2A$；但**四分之一周期路程不一定是 $A$**（起点不在特殊位置时）。

## 背记要点

1. 简谐运动定义：位移随时间按正弦规律变化，$x=A\sin(\omega t+\varphi)$。
2. 平衡位置：速度最大、加速度为零；最大位移处：速度为零、加速度最大。
3. 一个周期路程 $4A$；对称点速率、加速度大小相等。
4. 高考视角：图象读取（振幅、周期、某时刻速度方向）是选择题常规考法。
