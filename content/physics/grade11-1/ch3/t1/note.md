# 1 波的形成

## 概念定义

**机械波**：机械振动在**介质**中的传播。产生条件：① 有**波源**（做机械振动的物体）；② 有**介质**（传播振动的媒介物质）。

**横波**：质点振动方向与波的传播方向**垂直**的波，有**波峰、波谷**（如绳波）。

**纵波**：质点振动方向与波的传播方向**在同一直线上**的波，有**密部、疏部**（如声波、弹簧疏密波）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 形成机制 | 前一质点带动后一质点，后面质点**重复**前面质点的振动，时间上依次滞后 |
| 传播内容 | 传播的是**振动形式（运动状态）和能量**（还有信息） |
| 质点行为 | 各质点只在自己平衡位置附近振动，**不随波迁移** |
| 起振方向 | 各质点开始振动的方向都与**波源起振方向**相同 |
| 横波/纵波 | 按振动方向与传播方向的关系区分；地震波既有横波又有纵波 |

**关键认识**："波动"与"振动"的关系：振动是单个质点的周期性运动，波动是振动在介质中的传播；有波动必有振动，有振动不一定有波动（缺介质则不能传播，如真空不传声）。

## 典型例题

**例 1**：绳波沿绳向右传播，判断：绳上质点是否随波向右移动？

**解**：不随波移动。质点只在各自平衡位置附近**垂直于传播方向**上下振动，向右传播的是**振动形式和能量**。可用"麦浪"类比：麦穗上下摆动，波形向前推移。

**例 2**：波源从平衡位置**向上**起振，波沿 $+x$ 方向传播。波刚传到质点 P 时，P 的起振方向如何？

**解**：介质中每个质点的起振方向都重复波源的起振方向，故 P 开始振动的方向**向上**。（这一结论是解"波刚传到某点"类问题的钥匙。）

## 易错点

- 波传播时质点**不迁移**；"随波逐流"的直觉是错的。
- 声波是**纵波**；水面波（教材中）情况复杂，不能简单归为横波或纵波，但常以横波模型处理。
- 各质点起振方向与波源相同——判断新到达质点的运动方向时最常用。
- 振动停止（波源停止）后，已形成的波仍继续传播；"振动停止，波不立即消失"。

## 背记要点

1. 机械波产生条件：波源＋介质，二者缺一不可。
2. 横波：振动 ⊥ 传播（波峰波谷）；纵波：振动 ∥ 传播（密部疏部）。
3. 波传播振动形式和能量，质点不随波迁移；各质点起振方向同波源。
4. 高考视角："质点是否迁移""起振方向"是波动部分选择题的基本判断点。
