# 3 动量守恒定律

## 概念定义

**动量守恒定律**：如果一个系统**不受外力**，或者所受**外力的矢量和为零**，这个系统的总动量保持不变：
$$m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$$

它由牛顿第二定律与牛顿第三定律推出，但适用范围比牛顿定律更广（微观、高速领域仍成立），是自然界最普遍的守恒定律之一。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 严格条件 | 系统不受外力或合外力为零 |
| 近似条件 | 内力远大于外力（碰撞、爆炸的极短时间内） |
| 分方向守恒 | 某方向合外力为零，该方向动量守恒（如平抛中水平方向） |
| 矢量性 | 一维问题先规定正方向，速度代入正负号 |
| 同时性 | 各速度必须是**同一时刻**相对**同一参考系**（通常地面）的速度 |

**常见守恒模型**：碰撞、爆炸、反冲、人船模型、子弹打木块。

## 典型例题

**例 1**：光滑水平面上，质量 $2\ \text{kg}$ 的小车 A 以 $3\ \text{m/s}$ 追上质量 $1\ \text{kg}$、速度 $1\ \text{m/s}$ 同向运动的小车 B，碰后 A 的速度变为 $2\ \text{m/s}$（方向不变）。求碰后 B 的速度。

**解**：取初速度方向为正，系统动量守恒：
$2\times3+1\times1=2\times2+1\times v_B'$，解得 $v_B'=3\ \text{m/s}$，方向与原方向相同。
检验：碰后 $v_A'=2<v_B'=3$（不再相碰），且动能未增加，结果合理。

**例 2**：静止在光滑冰面上的人（质量 $60\ \text{kg}$）将 $2\ \text{kg}$ 的物块以 $6\ \text{m/s}$ 水平抛出。求人获得的速度。

**解**：系统初动量为零。取抛出方向为正：$0=2\times6+60v$，解得 $v=-0.2\ \text{m/s}$，即人以 $0.2\ \text{m/s}$ 向反方向滑动。

## 易错点

- 守恒条件针对**系统**：内力（碰撞力、绳张力）不影响守恒，勿误把内力当外力。
- 速度的**同时性**：$v_1、v_2$ 是作用前同一时刻的速度，$v_1'、v_2'$ 是作用后同一时刻的速度。
- 爆炸、碰撞瞬间外力（重力、摩擦力）远小于内力，可**近似**守恒；持续过程则须逐段判断。
- 结果检验：碰撞后系统动能不能增加，追及碰撞后前者速度不小于后者。

## 背记要点

1. $m_1v_1+m_2v_2=m_1v_1'+m_2v_2'$，条件：合外力为零（或内力远大于外力、某方向守恒）。
2. 三性：矢量性、同时性、系统性（同一参考系）。
3. 初动量为零的反冲系统：$m_1v_1'=-m_2v_2'$。
4. 高考视角：北京卷大题常将动量守恒与能量守恒联立求解碰撞、板块问题。
