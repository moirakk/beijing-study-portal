# 5 光的衍射

## 概念定义

**光的衍射**：光绕过障碍物偏离直线传播，传到"阴影区"的现象。它与干涉一样，是光具有**波动性**的重要证据。

**发生明显衍射的条件**：障碍物或孔的尺寸**小于光的波长，或与波长相差不多**。因可见光波长仅约 $4\times10^{-7}\sim7.7\times10^{-7}\ \text{m}$，日常物体尺寸远大于它，故通常光近似沿直线传播。

## 知识梳理

| 衍射类型 | 图样特征 |
| --- | --- |
| 单缝衍射（单色光） | 中央亮纹**最宽最亮**，两侧条纹变窄变暗，**不等间距** |
| 单缝衍射（白光） | 中央白纹，两侧彩色条纹 |
| 圆孔衍射 | 明暗相间的**同心圆环** |
| 圆盘衍射 | 阴影中心出现亮斑——**泊松亮斑**（历史上支持波动说的著名判决实验） |

**缝宽的影响**：缝越窄，衍射越明显，中央亮纹越**宽**（但越暗）；缝较宽时光沿直线传播成一条亮线。

**干涉与衍射条纹对比**：双缝干涉条纹**等间距、亮度均匀**；单缝衍射条纹**中央宽亮、两侧窄暗、不等间距**。

## 典型例题

**例 1**：单缝衍射实验中逐渐减小缝宽，屏上图样如何变化？

**解**：缝宽较大时是一条亮线（近似直线传播）；缝变窄后出现衍射条纹，且缝越窄衍射越明显，**中央亮纹越宽**，但通过的光能减少，条纹整体**变暗**。

**例 2**：如何区分屏上的双缝干涉条纹与单缝衍射条纹？

**解**：看间距与亮度分布——**等间距、亮度大致均匀**的是双缝干涉条纹；**中央最宽最亮、两侧变窄变暗**的是单缝衍射条纹。（本质上双缝图样还受单缝衍射调制，中学层面按上述特征区分。）

## 易错点

- 衍射**总能发生**，"明显"才需要尺寸条件；表述"只有缝很小才发生衍射"是错的。
- 泊松亮斑出现在**圆盘阴影中央**，是衍射（波动性）的证据，勿记成干涉。
- 衍射条纹不等间距，与干涉条纹的等间距形成对比——图样辨认高频考。
- 红光比紫光波长长，同一装置下红光衍射**更明显**、中央亮纹更宽。

## 背记要点

1. 明显衍射条件：障碍物/孔尺寸 $\lesssim\lambda$。
2. 单缝衍射：中央宽亮、两侧窄暗、不等间距；圆孔→同心圆环；圆盘→泊松亮斑。
3. 缝越窄衍射越明显；波长越长衍射越明显。
4. 高考视角：干涉、衍射图样辨认与波动性证据归类是选择题常考点。
