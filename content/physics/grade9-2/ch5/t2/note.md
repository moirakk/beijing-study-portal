# 第2节 核能

## 核心概念表

| 项目 | 内容 |
|---|---|
| 原子结构 | 原子由原子核（质子+中子）和核外电子组成 |
| 核能 | 原子核分裂或聚合时释放的巨大能量（也叫原子能） |
| 裂变 | 重核（如铀 235）被中子轰击分裂成较轻的核，释放核能 |
| 聚变 | 轻核（如氘、氚）在超高温下结合成较重的核，释放核能（热核反应） |
| 链式反应 | 裂变放出的中子再轰击其他铀核，反应持续进行 |

## 知识梳理

1. **裂变**：用中子轰击铀 235 原子核，铀核分裂成两个较小的核并放出 2~3 个中子和巨大能量；新中子又引发新的裂变，形成**链式反应**。
   - 不加控制的链式反应→**原子弹**；
   - 可控链式反应→**核电站**（核反应堆）。
2. **核电站能量转化**：核能→（水的）内能→机械能→电能。
3. **聚变**：氘核、氚核等轻核在**超高温**下聚合成较重的核，释放比裂变更巨大的能量，又叫热核反应。氢弹利用聚变；**太阳内部持续发生聚变**。目前人类还不能有效控制聚变。
4. **核废料**有放射性，需妥善处理；核能属于**不可再生能源**。

## 对比分析

| 项目 | 裂变 | 聚变 |
|---|---|---|
| 原料 | 重核（铀 235） | 轻核（氘、氚） |
| 条件 | 中子轰击 | 超高温 |
| 应用 | 核电站、原子弹 | 氢弹、太阳内部 |
| 可控性 | 可控（反应堆） | 尚不能有效控制 |

## 易错点

- 核电站利用的是**可控裂变**，不是聚变。
- 太阳释放能量靠**聚变**（热核反应）。
- 核能是一次能源、不可再生能源；正常运行的核电站不排放温室气体，但有核废料问题。

## 背记要点

1. 裂变：重核分裂；聚变：轻核聚合（热核反应，能量更大）。
2. 链式反应：可控→核电站，不可控→原子弹。
3. 核电站能量转化：核能→内能→机械能→电能。
