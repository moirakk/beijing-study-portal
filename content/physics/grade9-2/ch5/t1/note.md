# 第1节 能源

## 核心概念表

| 项目 | 内容 |
|---|---|
| 能源 | 能够提供能量的物质资源 |
| 一次能源 | 可以从自然界直接获取的能源（煤、石油、风、太阳能等） |
| 二次能源 | 无法直接获取、须由一次能源转化而来（如电能） |
| 化石能源 | 煤、石油、天然气——千百万年前生物遗骸演变而成 |
| 生物质能 | 由生命物质提供的能量（柴薪、沼气等） |

## 知识梳理

1. **人类利用能源的历程**：火（柴薪）→化石能源（煤、石油、天然气）→电能→核能。
2. **化石能源**：当今世界能源消耗的主体；燃烧释放的是化学能转化的内能；储量有限、不可再生，且燃烧造成污染。
3. **电能是二次能源**：由化石能源、水能、核能等一次能源转化而来，便于输送和转化，应用最广。
4. **能量转化举例**：煤燃烧（化学能→内能）→蒸汽轮机（内能→机械能）→发电机（机械能→电能）。
5. 太阳能是地球上绝大多数能量的最终来源：化石能源、风能、水能、生物质能都间接来自太阳。

## 分类辨析

| 能源 | 一次/二次 | 举例 |
|---|---|---|
| 一次能源 | 直接取自自然界 | 煤、石油、天然气、风能、水能、太阳能、核燃料 |
| 二次能源 | 由一次能源转化 | 电能、汽油（加工获得）等 |

## 易错点

- **电能不是一次能源**，它由其他能源转化而来。
- 化石能源属于**不可再生能源**（下一节结合"可再生"概念）；风能、水能、太阳能可再生。
- 沼气属于生物质能，来源仍可追溯到太阳能。

## 背记要点

1. 能源：能提供能量的物质资源；分一次能源和二次能源。
2. 化石能源：煤、石油、天然气，是当今主要能源。
3. 电能是应用最广泛的二次能源。
4. 大多数能源的"源头"是太阳能。
