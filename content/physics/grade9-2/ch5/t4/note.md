# 第4节 能源与可持续发展

## 核心概念表

| 项目 | 内容 |
|---|---|
| 能量转移/转化的方向性 | 能量的转化和转移具有方向性，有些过程不可逆 |
| 能源消耗对环境的影响 | 温室效应、酸雨、粉尘污染等 |
| 可再生能源 | 可从自然界源源不断获得（太阳能、风能、水能、生物质能） |
| 不可再生能源 | 越用越少、短期内不能再生（化石能源、核能） |
| 未来理想能源条件 | 丰富、便宜、技术成熟、安全清洁 |

## 知识梳理

1. **能量的转化和守恒**：能量在转化和转移过程中总量保持不变，但**可利用的品质在降低**。例如汽车刹车时动能转化为内能散失，无法自动收集回来再利用——能量的转化、转移有**方向性**，所以必须节约能源。
2. **能源消耗对环境的影响**：燃烧化石能源排放二氧化碳（**温室效应**加剧）、二氧化硫（**酸雨**）以及粉尘；水电站可能影响生态；核废料有放射性。
3. **能源革命方向**：提高能源利用率，开发清洁的新能源（太阳能、风能、地热能、潮汐能、可控核聚变等）。
4. **未来的理想能源**应同时满足四个条件：① 足够丰富；② 足够便宜；③ 技术成熟可靠；④ 足够安全、清洁。

## 分类辨析

| 类别 | 举例 |
|---|---|
| 可再生能源 | 太阳能、风能、水能、生物质能、潮汐能、地热能 |
| 不可再生能源 | 煤、石油、天然气、核燃料（铀） |

## 易错点

- 能量守恒并不意味着不需要节能：能量转化有**方向性**，散失的低品质能量难以再利用。
- 核能是**不可再生**能源（铀矿有限）。
- "温室效应"主要与二氧化碳排放有关，"酸雨"主要与二氧化硫等有关，勿混淆。

## 背记要点

1. 能量转化、转移有方向性→必须节约能源、提高利用率。
2. 可再生：太阳能、风能、水能、生物质能；不可再生：化石能源、核能。
3. 未来理想能源四条件：丰富、便宜、技术成熟、安全清洁。
4. 化石能源污染：温室效应（CO₂）、酸雨（SO₂）、粉尘。
