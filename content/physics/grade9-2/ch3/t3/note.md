# 第3节 电磁铁 电磁继电器

## 核心概念表

| 项目 | 内容 |
|---|---|
| 电磁铁 | 内部插入铁芯的通电螺线管 |
| 磁性有无 | 由电流的通断控制：通电有磁性，断电磁性消失 |
| 磁性强弱 | 与电流大小、线圈匝数有关（还与有无铁芯有关） |
| 电磁继电器 | 利用电磁铁控制工作电路的开关，实现低压控制高压、远距离控制 |

## 知识梳理

1. **电磁铁的优点**：磁性有无可由电流通断控制；磁性强弱可由电流大小、线圈匝数调节；磁极可由电流方向改变。
2. **探究电磁铁磁性强弱**（控制变量法 + 转换法）：
   - 用吸引大头针的**数目**反映磁性强弱（转换法）；
   - 匝数相同：电流越大磁性越强；电流相同：匝数越多磁性越强。
3. **电磁继电器**：由电磁铁、衔铁、弹簧、触点组成，包含**低压控制电路**和**高压（工作）电路**两部分。
4. 工作过程：控制电路通电→电磁铁有磁性→吸下衔铁→触点接通→工作电路工作；断电→弹簧拉回衔铁→工作电路断开。

## 易错点

- 电磁铁磁性强弱实验中，比较匝数影响时必须**串联**保证电流相同（控制变量法）。
- 插入铁芯磁性大大增强，但铁芯本身断电后磁性基本消失（软铁），不能用钢做铁芯（钢会保留磁性）。
- 电磁继电器实质是一个**由电磁铁控制的开关**，作用是用低电压弱电流控制高电压强电流。

## 背记要点

1. 电磁铁 = 螺线管 + 铁芯；通断电控制磁性有无。
2. 磁性强弱：电流越大、匝数越多，磁性越强。
3. 电磁继电器：控制电路 + 工作电路；低压控制高压。
4. 应用：电铃、自动控制装置、温度报警器等。
