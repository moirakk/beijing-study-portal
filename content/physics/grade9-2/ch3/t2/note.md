# 第2节 电生磁

## 核心概念表

| 项目 | 内容 |
|---|---|
| 奥斯特实验 | 通电导线周围存在磁场（电流的磁效应），1820 年丹麦物理学家奥斯特发现 |
| 磁场方向 | 与电流方向有关：电流方向变，磁场方向也变 |
| 通电螺线管 | 外部磁场与条形磁体相似，两端相当于 N 极和 S 极 |
| 安培定则 | 右手螺旋定则：判断通电螺线管的极性与电流方向的关系 |

## 知识梳理

1. **奥斯特实验**：导线通电时其下方小磁针发生偏转，说明通电导线周围存在磁场；这是历史上第一个揭示电与磁联系的实验。
2. **通电螺线管**：把导线绕成螺线管，通电后磁场大大增强，外部磁场与条形磁体相似；极性由电流方向决定。
3. **安培定则（右手螺旋定则）**：用右手握住螺线管，让四指指向电流方向，则**大拇指所指的一端就是螺线管的 N 极**。
4. 已知两个量可判断第三个量：电流方向、绕线方式、磁极极性——知二求一。

## 实验要点

- 奥斯特实验中，导线应**南北方向**放置在小磁针上方，且尽量靠近小磁针。
- 改变电流方向，小磁针偏转方向随之改变→磁场方向与电流方向有关。
- 探究通电螺线管极性：用小磁针检验两端极性，改变电流方向再检验。

## 易错点

- 安培定则用**右手**，不是左手。
- 通电螺线管内部也有磁场，内部磁感线由 S 端指向 N 端，与外部构成闭合曲线。
- 电流磁效应中"电生磁"永远存在，只要有电流就有磁场，与导线是否绕成螺线管无关（绕成螺线管只是磁场更强、便于利用）。

## 背记要点

1. 奥斯特实验：通电导体周围有磁场，磁场方向与电流方向有关。
2. 通电螺线管外部磁场与条形磁体相似。
3. 右手螺旋定则：四指指电流，拇指指 N 极。
