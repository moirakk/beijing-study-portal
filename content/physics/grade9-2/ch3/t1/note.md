# 第1节 磁现象 磁场

## 核心概念表

| 项目 | 内容 |
|---|---|
| 磁性 | 物体能吸引铁、钴、镍等物质的性质 |
| 磁极 | 磁体上磁性最强的部分；任何磁体都有 N 极和 S 极 |
| 磁极间作用 | 同名磁极相互排斥，异名磁极相互吸引 |
| 磁化 | 使原来没有磁性的物体获得磁性的过程 |
| 磁场 | 磁体周围存在的特殊物质，对放入其中的磁体产生力的作用 |
| 磁感线 | 描述磁场的假想曲线：磁体外部从 N 极出发回到 S 极 |

## 知识梳理

1. **磁极**：条形磁体两端磁性最强；自由转动的磁体静止时指南的是 S 极（南极）、指北的是 N 极（北极）。
2. **磁场**：磁场看不见摸不着，但客观存在；磁极间的相互作用是通过**磁场**发生的。
3. **磁场方向**：在磁场中某点，小磁针静止时 **N 极所指的方向**规定为该点磁场方向。
4. **磁感线**：用带箭头的曲线形象描述磁场。磁感线越密处磁场越强；磁感线是**假想的**，实际不存在，且**不相交**。
5. **地磁场**：地球是一个大磁体。地磁北极在地理南极附近，地磁南极在地理北极附近（两者并不重合，磁偏角由我国宋代沈括最早记述）。指南针能指南北就是受地磁场作用。

## 易错点

- 磁体吸引铁钉是磁性；铁钉被吸后也能吸别的铁钉，是**磁化**。
- 磁感线是为研究方便假想的曲线，磁场中并没有真实的"线"。
- 磁场方向 = 小磁针静止时 **N 极**的指向。
- 地磁的 N、S 极与地理两极位置**相反且不完全重合**。

## 背记要点

1. 磁体吸引铁、钴、镍；同名磁极相斥、异名相吸。
2. 磁极间作用通过磁场发生；磁感线外部 N→S、内部 S→N、不相交。
3. 磁感线疏密表示磁场强弱。
4. 地球是大磁体；磁偏角——沈括最早记述。
