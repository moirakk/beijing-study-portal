# 第1节 现代顺风耳——电话

## 核心概念表

| 项目 | 内容 |
|---|---|
| 发明者 | 贝尔（1876 年） |
| 基本组成 | 话筒和听筒 |
| 话筒 | 把声信号转变为**变化的电流**（声→电） |
| 听筒 | 把变化的电流转变为声信号（电→声） |
| 信号类型 | 模拟信号与数字信号 |

## 知识梳理

1. **电话的工作原理**：对着话筒说话→碳粒电阻随声音振动而变化→电路中产生随声音变化的电流→电流沿导线传到对方听筒→电磁铁磁性随电流变化→吸引膜片振动发声。
2. **电话交换机**：提高线路利用率，减少线路数量；电话之间通过交换机转接。
3. **模拟信号**：信号电流的频率、振幅变化与声音的频率、振幅完全一样，模仿声信号；缺点是传输中受干扰后失真，且难以恢复。
4. **数字信号**：用不同符号（如 0 和 1）的不同组合表示的信号；抗干扰能力强，便于加密、存储和处理，是现代通信的主流。

## 对比分析

| 信号 | 表示方式 | 优缺点 |
|---|---|---|
| 模拟信号 | 电流的变化模仿声音的变化 | 易失真、抗干扰差 |
| 数字信号 | 0、1 等符号的组合 | 抗干扰强、可加密、易处理 |

## 易错点

- 话筒是"声→电"，听筒是"电→声"，方向不可颠倒。
- 老式话筒利用**碳粒电阻随压力变化**改变电流，本质是改变电阻。
- 数字信号并非不受干扰，而是**抗干扰能力强、易于修复还原**。

## 背记要点

1. 贝尔发明电话；话筒（声→电）、听筒（电→声）。
2. 交换机：提高线路利用率。
3. 数字信号优点：抗干扰、可加密、便于存储处理。
