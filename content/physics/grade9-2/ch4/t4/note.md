# 第4节 越来越宽的信息之路

## 核心概念表

| 项目 | 内容 |
|---|---|
| 微波通信 | 波长 10 m~1 mm，频率高、容量大；需中继站 |
| 卫星通信 | 利用同步通信卫星作太空中继站，3 颗同步卫星可覆盖全球（两极附近除外） |
| 光纤通信 | 激光在光导纤维中传输信息，容量极大、衰减小、抗干扰 |
| 网络通信 | 计算机联网传递信息，常用电子邮件等；信息高速公路 |

## 知识梳理

1. **微波通信**：频率越高，相同时间内可传输的信息越多。微波性质接近光波，大致直线传播，绕射能力差，需每隔约 50 km 建一个中继站。
2. **卫星通信**：同步卫星相对地面静止，作为微波中继站；在地球周围均匀配置 **3 颗**同步通信卫星，几乎可实现全球通信。
3. **光纤通信**：激光频率比微波更高，携带信息量更大。激光在光导纤维内壁上**多次反射**向前传输。优点：传输容量大、损耗小、抗电磁干扰、保密性好。
4. **网络通信**：把计算机连接起来组成网络；电子邮件传递信息快捷方便；因特网是世界上最大的计算机网络。

## 对比分析

| 通信方式 | 载体 | 特点 |
|---|---|---|
| 微波通信 | 微波 | 容量较大，需地面中继站 |
| 卫星通信 | 微波+同步卫星 | 覆盖范围大，3 颗覆盖全球 |
| 光纤通信 | 激光 | 容量极大、损耗小、抗干扰 |
| 网络通信 | 计算机网络 | 信息共享、快捷方便 |

## 易错点

- 频率越高的电磁波，可携带的信息量越**大**——这是发展微波、光通信的原因。
- 光纤通信传输的是**光信号**（激光），不是电流沿玻璃丝传播。
- 同步卫星"同步"指与地球自转同步，相对地面静止。

## 背记要点

1. 信息之路越来越宽的核心：载波频率越高，信息容量越大。
2. 3 颗同步通信卫星几乎覆盖全球。
3. 光纤通信：激光多次反射传输；容量大、损耗小。
4. 因特网是最大的计算机网络。
