# 第1节 家庭电路

## 核心概念表

| 项目 | 内容 |
|---|---|
| 电源 | 进户两根线：火线（相线）与零线，电压 $220\ \text{V}$ |
| 组成 | 进户线→电能表→总开关→保险装置→用电器、插座、灯 |
| 用电器连接 | 各用电器之间**并联**，可独立工作 |
| 测电笔 | 辨别火线：氖管发光→火线 |

## 知识梳理

1. **进户线**：火线与零线之间电压 220 V；零线与大地之间电压为 0。
2. **电路顺序**：进户线→电能表→总开关（闸刀/空气开关）→保险装置→各支路。
3. **开关与保险丝必须接在火线上**，这样断开后用电器不带电，更安全。
4. **控制开关与被控灯串联**；各盏灯、各插座之间互相并联。
5. **三线插头与三孔插座**：第三根线把用电器**金属外壳接地**，防止外壳漏电时人触电。
6. **测电笔**：使用时手接触笔尾金属体，笔尖接触导线；氖管发光的是火线。**不能用手接触笔尖**。

## 易错点

- 螺丝口灯泡：螺旋套必须接**零线**，中心触点接火线。
- 保险丝和开关都应串联在**火线**上。
- 插座接线口诀："左零右火上接地"。
- 测电笔判断火线时手必须碰笔尾金属体，否则氖管不发光。

## 背记要点

1. 家庭电路电压 220 V；两根进户线：火线、零线。
2. 电路组成顺序：进户线→电能表→总开关→保险装置→用电器。
3. 用电器并联；开关接火线并与所控灯串联。
4. 三孔插座的接地线保护金属外壳用电器。
