# 二力平衡

## 核心概念表

| 概念 | 含义 | 说明 |
|---|---|---|
| 平衡状态 | 静止或匀速直线运动 | 运动状态不变 |
| 平衡力 | 使物体处于平衡状态的几个力 | 最简单的是二力平衡 |
| 二力平衡条件 | 同体、等大、反向、共线 | 四条缺一不可 |

## 知识梳理

物体处于静止状态或匀速直线运动状态，叫做平衡状态。物体处于平衡状态时，受到的力相互平衡，合力为零。

二力平衡的条件：作用在同一物体上的两个力，大小相等、方向相反、且作用在同一条直线上。四个条件必须同时满足，可概括为"同体、等大、反向、共线"。

应用：已知物体处于平衡状态，可由一个力求另一个力。例如静止在桌面上的书，重力与支持力是一对平衡力；匀速下落的跳伞员，重力与阻力平衡。

判断运动状态：受平衡力（或不受力）→静止或匀速直线运动；受非平衡力→运动状态改变。

## 实验要点

探究二力平衡条件（小卡片实验）：

- 轻质小卡片两端通过滑轮挂钩码，两边拉力方向相反。
- 改变钩码个数：两边拉力不等时卡片不能平衡。
- 将卡片扭转一个角度后释放：两力不在同一直线上，卡片转回，说明需共线。
- 把卡片剪成两半：说明两个力必须作用在同一物体上。
- 选轻质卡片的目的：忽略卡片重力的影响。

## 对比分析

| 一对平衡力 | 一对相互作用力 |
|---|---|
| 作用在同一物体上 | 作用在两个物体上 |
| 大小相等、方向相反、共线 | 大小相等、方向相反、共线 |
| 可以是不同性质的力 | 一定是同性质的力 |
| 例：书受重力与支持力 | 例：书压桌面与桌面支持书 |

## 背记要点

1. 平衡状态包括静止和匀速直线运动两种。
2. 二力平衡条件：同体、等大、反向、共线。
3. 平衡力的合力为零。
4. 区分平衡力与相互作用力的关键：是否作用在同一物体上。
