# 牛顿第一定律

## 核心概念表

| 概念 | 含义 | 说明 |
|---|---|---|
| 牛顿第一定律 | 一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态 | 又叫惯性定律 |
| 惯性 | 物体保持原来运动状态不变的性质 | 一切物体都有惯性 |
| 理想实验 | 在实验基础上加科学推理 | 定律不能直接用实验验证 |

## 知识梳理

亚里士多德认为"运动需要力来维持"，伽利略通过斜面实验推断：运动的物体如果不受阻力，将以恒定速度永远运动下去。笛卡儿进一步补充方向不变。牛顿在前人基础上总结出牛顿第一定律。

牛顿第一定律表明：力不是维持物体运动的原因，而是改变物体运动状态的原因。该定律是在大量实验事实基础上通过科学推理概括出来的，不能用实验直接验证。

一切物体都具有保持原来运动状态不变的性质，叫惯性。惯性大小只与质量有关，质量越大惯性越大；惯性与物体是否受力、是否运动、速度大小均无关。惯性是物体的属性，不是力，不能说"受到惯性作用"。

## 实验要点

阻力对物体运动影响的实验：

- 同一小车从同一斜面同一高度由静止滑下（控制到达水平面的初速度相同）。
- 水平面分别铺毛巾、棉布、木板，表面越光滑，阻力越小，小车滑行越远。
- 推理：若水平面绝对光滑（阻力为零），小车将做匀速直线运动。
- 方法：控制变量法 + 科学推理法（理想实验）。

## 对比分析

| 惯性 | 力 |
|---|---|
| 物体的属性 | 物体间的相互作用 |
| 只与质量有关 | 与三要素有关 |
| 说"具有惯性" | 说"受到力" |

## 背记要点

1. 牛顿第一定律：不受力时，物体保持静止或匀速直线运动状态。
2. 力是改变运动状态的原因，不是维持运动的原因。
3. 惯性大小只由质量决定。
4. 惯性现象解释四步：原状态→突然变化→由于惯性保持原状态→结果。

## 自测题

1. 正在行驶的汽车突然刹车，乘客为什么向前倾？
2. 一个正在做匀速直线运动的物体，若所受的力全部消失，它将怎样运动？
3. 汽车限载、系安全带各与惯性有什么关系？
