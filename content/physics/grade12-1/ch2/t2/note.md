# 2 气体的等温变化

## 概念定义

**等温变化**：一定质量的气体在**温度不变**的条件下发生的状态变化。

**玻意耳定律**：一定质量的某种气体，在温度不变的情况下，压强 $p$ 与体积 $V$ 成**反比**，即 $pV = C$（常量），或 $p_1 V_1 = p_2 V_2$。

**适用条件**：气体质量一定、温度不变、压强不太大、温度不太低。

**p-V 图像**：等温变化在 $p$-$V$ 图中是**双曲线**；在 $p$-$1/V$ 图中是过原点的直线。温度越高，等温线离原点越远。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 定律 | $pV = C$ |
| 表达式 | $p_1 V_1 = p_2 V_2$ |
| 条件 | 质量一定、温度不变 |
| p-V 图 | 双曲线 |
| p-1/V 图 | 过原点直线 |

## 典型例题

**例 1**：一定质量的气体，在温度不变时，体积从 $2\ \text{L}$ 压缩到 $1\ \text{L}$，压强变为原来的几倍？

**解**：由 $p_1 V_1 = p_2 V_2$，$p_2 = \dfrac{p_1 V_1}{V_2} = \dfrac{p_1 \times 2}{1} = 2p_1$，压强变为原来的 2 倍。

**例 2**：某气体在 $p_1 = 1.0 \times 10^5\ \text{Pa}$、$V_1 = 3\ \text{L}$ 时等温变化到 $V_2 = 2\ \text{L}$，求 $p_2$。

**解**：$p_2 = \dfrac{p_1 V_1}{V_2} = \dfrac{1.0\times10^5 \times 3}{2} = 1.5 \times 10^5\ \text{Pa}$。

## 易错点

- 玻意耳定律条件是**温度不变、质量一定**。
- $p$ 与 $V$ 成反比，不是成正比。
- 单位要统一（压强、体积单位一致即可）。
- 等温线是双曲线，不是直线。

## 背记要点

1. $pV = C$，$p_1 V_1 = p_2 V_2$。
2. 条件：质量一定、温度不变。
3. p-V 图是双曲线，p-1/V 图是直线。
4. 温度越高等温线离原点越远。
