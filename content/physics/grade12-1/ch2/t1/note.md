# 1 温度和温标

## 概念定义

**温度**：表示物体冷热程度的物理量，是分子**平均动能**的标志。

**温标**：温度的数值表示方法。常用温标有**摄氏温标**（单位 ℃）和**热力学温标**（单位 K）。

**热力学温度**：以绝对零度为起点的温标，用 $T$ 表示，单位开尔文（K）。热力学温度与摄氏温度的关系：$T = t + 273.15\ \text{K}$。

**绝对零度**：$0\ \text{K} = -273.15\ \text{℃}$，是低温的极限，只能接近不能达到。

**温度计原理**：利用测温物质的某种性质随温度变化而变化，如水银热胀冷缩。

## 知识梳理

| 项目 | 摄氏温标 | 热力学温标 |
| --- | --- | --- |
| 单位 | ℃ | K |
| 符号 | $t$ | $T$ |
| 关系 | — | $T = t + 273.15$ |
| 零点 | 冰水混合物 0℃ | 绝对零度 0 K |
| 温差 | 1℃ = 1 K | 1 K = 1℃ |

## 典型例题

**例 1**：将 $25\ \text{℃}$ 换算成热力学温度。

**解**：$T = t + 273.15 = 25 + 273.15 = 298.15\ \text{K}$。

**例 2**：某物体温度升高了 $20\ \text{℃}$，相当于升高了多少开尔文？

**解**：摄氏温标与热力学温标的温差相同，$1\ \text{℃} = 1\ \text{K}$，故升高 $20\ \text{K}$。

## 易错点

- 摄氏温度与热力学温度换算时加 273.15，不是 273。
- 温差在两种温标下数值相同。
- 绝对零度只能接近，不能达到。
- 温度是平均动能的标志，不是内能的标志。

## 背记要点

1. $T = t + 273.15$。
2. 温差 1℃ = 1K。
3. 绝对零度 0K = -273.15℃。
4. 温度是分子平均动能的标志。
