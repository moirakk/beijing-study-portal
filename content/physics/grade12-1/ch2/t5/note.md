# 5 液体

## 概念定义

**表面张力**：液体表面各部分间相互吸引的力，使液体表面有收缩到最小的趋势。表面张力是液体表面层分子间引力作用的结果。

**浸润与不浸润**：液体与固体接触时，若液体附着在固体表面并扩展，称**浸润**（如水浸润玻璃）；若液体收缩成球状不附着，称**不浸润**（如水银不浸润玻璃）。

**毛细现象**：浸润液体在细管中上升、不浸润液体在细管中下降的现象。管越细，液面上升（或下降）越高。

**液晶**：介于液体和晶体之间的物质状态，既具有液体的流动性，又具有晶体的光学各向异性。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 表面张力 | 使液面收缩到最小 |
| 浸润 | 液体附着固体表面扩展 |
| 不浸润 | 液体收缩成球状 |
| 毛细现象 | 浸润上升、不浸润下降 |
| 液晶 | 流动性 + 光学各向异性 |

## 典型例题

**例 1**：为什么水银滴在玻璃板上呈球形，而水滴在玻璃板上会铺开？

**解**：水银不浸润玻璃，表面张力使水银收缩成球形；水浸润玻璃，附着在玻璃表面铺开。

**例 2**：毛细现象中，浸润液体在细管中上升还是下降？

**解**：浸润液体在细管中**上升**（如水在毛细管中上升）；不浸润液体在细管中下降（如水银）。

## 易错点

- 表面张力使液面**收缩到最小**，不是扩张。
- 浸润与不浸润取决于液体与固体的性质。
- 毛细现象中浸润上升、不浸润下降。
- 液晶既有流动性又有光学各向异性。

## 背记要点

1. 表面张力使液面收缩到最小。
2. 水浸润玻璃，水银不浸润玻璃。
3. 毛细现象：浸润上升、不浸润下降。
4. 液晶具有流动性和光学各向异性。
