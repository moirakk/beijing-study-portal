# 3 分子运动速率分布规律

## 概念定义

**气体分子运动特点**：气体分子在**永不停息地做无规则运动**，分子间频繁碰撞，速率有大有小。

**速率分布规律**：大量气体分子的速率分布呈"**中间多、两头少**"的规律，即速率很大和很小的分子数都较少，多数分子速率在某个值附近。

**温度与速率**：温度升高，分子的平均速率增大，速率分布曲线的峰值向速率大的方向移动，但曲线形状仍为"中间多、两头少"。

**统计规律**：单个分子的运动无规律，但大量分子的整体行为遵循统计规律。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 分布特点 | 中间多、两头少 |
| 温度升高 | 平均速率增大，峰值右移 |
| 曲线形状 | 峰值处分子数最多 |
| 统计规律 | 大量分子整体有规律 |
| 平均速率 | 随温度升高而增大 |

## 典型例题

**例 1**：关于气体分子速率分布，下列说法正确的是（　）
A. 速率大的分子数多　B. 速率小的分子数多　C. 中间速率分子数最多　D. 各速率分子数相同

**解**：选 C。气体分子速率分布呈"中间多、两头少"，中间速率的分子数最多。

**例 2**：温度升高时，气体分子的平均速率如何变化？速率分布曲线如何变化？

**解**：温度升高，分子平均速率增大，速率分布曲线的峰值向速率大的方向移动，但仍是"中间多、两头少"的分布。

## 易错点

- 温度升高是**平均速率**增大，不是每个分子速率都增大。
- 速率分布曲线峰值右移，但曲线下面积（分子总数）不变。
- 单个分子运动无规律，统计规律只对大量分子成立。
- "中间多、两头少"指分子数按速率分布，不是速率本身。

## 背记要点

1. 气体分子速率分布"中间多、两头少"。
2. 温度升高，平均速率增大，峰值右移。
3. 大量分子遵循统计规律。
4. 曲线下面积表示分子总数，不变。
