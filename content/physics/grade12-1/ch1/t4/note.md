# 4 分子动能和分子势能

## 概念定义

**分子动能**：分子由于做无规则运动而具有的动能。物体内所有分子动能的**平均值**叫分子平均动能。

**温度与平均动能**：温度是分子**平均动能**的标志，温度越高，分子平均动能越大。温度是大量分子热运动的宏观表现，对单个分子无意义。

**分子势能**：由分子间相对位置决定的能量，与分子间距离有关。分子势能随分子间距离变化，在平衡位置 $r_0$ 处分子势能最小。

**内能**：物体中所有分子热运动的动能与分子势能的总和。内能与温度、体积、物质的量有关。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 分子平均动能 | 温度的标志 |
| 温度 | 越高平均动能越大 |
| 分子势能 | 与分子间距离有关 |
| 势能最小 | 在平衡位置 $r_0$ 处 |
| 内能 | 动能 + 势能的总和 |

## 典型例题

**例 1**：关于温度，下列说法正确的是（　）
A. 温度是分子平均动能的标志　B. 温度是分子势能的标志　C. 温度是内能的标志　D. 温度是单个分子动能的标志

**解**：选 A。温度是分子**平均动能**的标志，对单个分子无意义。

**例 2**：当分子间距离从大于 $r_0$ 减小到 $r_0$ 的过程中，分子势能如何变化？

**解**：当 $r > r_0$ 时，分子间表现为引力，距离减小引力做正功，分子势能减小；到 $r_0$ 时势能最小。

## 易错点

- 温度是**平均动能**的标志，不是内能或势能的标志。
- 分子势能在 $r_0$ 处**最小**，不是最大。
- 内能是物体内所有分子动能与势能之和，与机械能不同。
- 温度对单个分子无意义。

## 背记要点

1. 温度是分子平均动能的标志。
2. 分子势能在 $r_0$ 处最小。
3. 内能 = 分子动能 + 分子势能。
4. 内能与温度、体积、物质的量有关。
