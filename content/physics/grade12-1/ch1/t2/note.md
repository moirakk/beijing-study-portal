# 2 实验：用油膜法估测油酸分子的大小

## 概念定义

**实验原理**：把油酸滴在水面上，油酸在水面上形成**单分子油膜**，油膜的厚度就等于油酸分子的直径。若油酸体积为 $V$，油膜面积为 $S$，则分子直径 $d = \dfrac{V}{S}$。

**实验步骤**：①配制一定浓度的油酸酒精溶液；②在浅盘中倒入清水，撒上痱子粉；③滴一滴油酸酒精溶液，待油膜稳定后描出轮廓；④用坐标纸数出油膜面积；⑤计算分子直径。

**注意事项**：油酸酒精溶液要**稀释**，使油膜为单分子层；撒痱子粉要均匀且薄；待油膜稳定后再描轮廓。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 原理 | $d = \dfrac{V}{S}$（单分子油膜） |
| 油酸 | 一端亲水一端疏水，铺成单分子层 |
| 痱子粉 | 显示油膜边界 |
| 面积 | 用坐标纸数格（不足半格舍去） |
| 结果 | 分子直径约 $10^{-10}\ \text{m}$ |

## 典型例题

**例 1**：将 $1\ \text{cm}^3$ 的油酸溶于酒精制成 $200\ \text{cm}^3$ 的油酸酒精溶液，取 $1\ \text{cm}^3$ 溶液滴在水面上，测得油膜面积为 $0.4\ \text{m}^2$，求油酸分子直径。

**解**：$1\ \text{cm}^3$ 溶液中油酸体积 $V = \dfrac{1}{200}\ \text{cm}^3 = 5 \times 10^{-9}\ \text{m}^3$。$d = \dfrac{V}{S} = \dfrac{5\times10^{-9}}{0.4} = 1.25 \times 10^{-8}\ \text{m}$。

**例 2**：实验中若油膜没有形成单分子层，测得的分子直径偏大还是偏小？

**解**：若油膜不是单分子层（偏厚），则 $S$ 偏小，由 $d = \dfrac{V}{S}$ 知 $d$ 偏大。

## 易错点

- 油酸酒精溶液必须**稀释**，保证单分子层。
- 计算体积时注意油酸的**实际体积**（浓度换算）。
- 数格子时不足半格舍去，超过半格算一格。
- 油膜要待**稳定后**再描轮廓。

## 背记要点

1. 原理：$d = \dfrac{V}{S}$。
2. 油酸在水面形成单分子油膜。
3. 痱子粉用于显示油膜边界。
4. 分子直径约 $10^{-10}\ \text{m}$。
