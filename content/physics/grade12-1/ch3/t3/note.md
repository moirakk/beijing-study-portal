# 3 能量守恒定律

## 概念定义

**能量守恒定律**：能量既不会凭空产生，也不会凭空消失，它只能从一种形式**转化**为另一种形式，或者从一个物体**转移**到另一个物体，在转化和转移的过程中，能量的**总量保持不变**。

**能量转化**：各种形式的能量（机械能、内能、电能、化学能、核能等）之间可以相互转化。

**第一类永动机**：不需要任何能量输入却能不断对外做功的机器。由于违背能量守恒定律，第一类永动机**不可能制成**。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 定律内容 | 能量总量保持不变 |
| 转化 | 一种形式 → 另一种形式 |
| 转移 | 一个物体 → 另一个物体 |
| 第一类永动机 | 违背能量守恒，不可能制成 |
| 意义 | 自然界普遍规律 |

## 典型例题

**例 1**：自由下落的物体，重力势能减少，动能增加，机械能是否守恒？能量总量如何？

**解**：若不计空气阻力，机械能守恒；无论何种情况，能量总量保持不变，只是形式发生转化。

**例 2**：为什么第一类永动机不可能制成？

**解**：第一类永动机不需要能量输入却不断对外做功，违背能量守恒定律，因此不可能制成。

## 易错点

- 能量守恒是**总量**守恒，不是某种形式能量守恒。
- 能量可以转化和转移，但不能凭空产生或消失。
- 第一类永动机违背能量守恒定律。
- 机械能守恒是能量守恒的特例（只有动能势能转化）。

## 背记要点

1. 能量总量保持不变。
2. 能量可转化、可转移，不可凭空产生消失。
3. 第一类永动机不可能制成。
4. 机械能守恒是能量守恒的特例。
