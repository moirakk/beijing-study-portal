# 4 热力学第二定律

## 概念定义

**热力学第二定律**：热量不能自发地从低温物体传到高温物体（克劳修斯表述）；不可能从单一热源吸收热量，使之完全变成功而不产生其他影响（开尔文表述）。

**可逆过程与不可逆过程**：自然界中涉及热现象的过程都是**不可逆**的，如热传导、扩散、摩擦生热等。

**第二类永动机**：从单一热源吸热全部转化为功而不产生其他影响的机器。它不违背能量守恒，但违背热力学第二定律，**不可能制成**。

**熵**：描述系统无序程度的物理量。孤立系统中，熵总是增大（熵增原理）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 克劳修斯表述 | 热量不能自发从低温传到高温 |
| 开尔文表述 | 不能从单一热源吸热完全变功 |
| 不可逆性 | 热现象过程不可逆 |
| 第二类永动机 | 违背热力学第二定律 |
| 熵增原理 | 孤立系统熵增大 |

## 典型例题

**例 1**：下列说法正确的是（　）
A. 热量能自发从低温传到高温　B. 第二类永动机违背能量守恒　C. 热现象过程不可逆　D. 第二类永动机可制成

**解**：选 C。热现象过程不可逆；热量不能自发从低温传到高温；第二类永动机违背热力学第二定律，不可能制成。

**例 2**：第二类永动机违背了什么定律？

**解**：第二类永动机不违背能量守恒定律，但违背热力学第二定律（不能从单一热源吸热完全变功而不产生其他影响），因此不可能制成。

## 易错点

- 热量**不能自发**从低温传到高温，但可通过外界做功实现（制冷机）。
- 第二类永动机违背热力学第二定律，不违背能量守恒。
- 热现象过程具有不可逆性。
- 熵增原理适用于孤立系统。

## 背记要点

1. 热量不能自发从低温传到高温。
2. 不能从单一热源吸热完全变功。
3. 热现象过程不可逆。
4. 第二类永动机不可能制成。
