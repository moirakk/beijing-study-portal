# 1 原子核的组成

## 概念定义

**原子核的组成**：原子核由**质子**和**中子**组成，质子和中子统称为**核子**。

**质子**：带正电，电荷量为 $+e$，质量约为 $1.67 \times 10^{-27}\ \text{kg}$。

**中子**：不带电，质量与质子相近。

**核电荷数**：原子核中质子数 $Z$，等于原子序数，也等于核外电子数（中性原子）。

**质量数**：原子核中质子数和中子数之和 $A = Z + N$，近似等于原子核的质量（以原子质量单位计）。

**同位素**：具有相同质子数、不同中子数的原子互称同位素，如 $^{1}_{1}H$、$^{2}_{1}H$、$^{3}_{1}H$。

## 知识梳理

| 项目 | 质子 | 中子 |
| --- | --- | --- |
| 电荷 | $+e$ | 0 |
| 质量 | 约 $1.67\times10^{-27}$ kg | 与质子相近 |
| 数量 | $Z$ | $N$ |
| 质量数 | $A = Z + N$ | — |

## 典型例题

**例 1**：$^{235}_{92}U$ 原子核中有多少个质子和中子？

**解**：质子数 $Z = 92$，质量数 $A = 235$，中子数 $N = A - Z = 235 - 92 = 143$。

**例 2**：$^{1}_{1}H$、$^{2}_{1}H$、$^{3}_{1}H$ 是什么关系？

**解**：三者质子数相同（都是 1），中子数不同（分别为 0、1、2），互为同位素。

## 易错点

- 质量数 $A = Z + N$，不是质量。
- 同位素质子数相同、中子数不同。
- 中性原子中质子数 = 核外电子数。
- 核子包括质子和中子。

## 背记要点

1. 原子核由质子和中子组成。
2. 质量数 $A = Z + N$。
3. 同位素质子数相同、中子数不同。
4. 核子 = 质子 + 中子。
