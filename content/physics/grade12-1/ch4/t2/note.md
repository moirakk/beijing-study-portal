# 2 光电效应

## 概念定义

**光电效应**：在光的照射下，金属表面发射电子的现象。发射出的电子叫**光电子**。

**光电效应规律**：①存在**截止频率**（极限频率），入射光频率低于截止频率时无论光强多大都不发生光电效应；②光电子的最大初动能与入射光频率有关，与光强无关；③光电效应具有**瞬时性**（时间极短）；④光强越大，单位时间内发射的光电子数越多。

**爱因斯坦光电效应方程**：$E_k = h\nu - W_0$，其中 $E_k$ 是光电子的最大初动能，$h\nu$ 是光子能量，$W_0$ 是金属的逸出功。

**光子说**：光是一份一份的，每一份叫一个光子，光子能量 $\varepsilon = h\nu$。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 截止频率 | 低于它不发生光电效应 |
| 最大初动能 | 与频率有关，与光强无关 |
| 瞬时性 | 光电效应时间极短 |
| 光强影响 | 光强越大光电子越多 |
| 方程 | $E_k = h\nu - W_0$ |

## 典型例题

**例 1**：某金属的逸出功为 $W_0 = 3.0 \times 10^{-19}\ \text{J}$，用频率为 $8 \times 10^{14}\ \text{Hz}$ 的光照射，求光电子的最大初动能。

**解**：$E_k = h\nu - W_0 = 6.63\times10^{-34} \times 8\times10^{14} - 3.0\times10^{-19} = 5.304\times10^{-19} - 3.0\times10^{-19} = 2.304\times10^{-19}\ \text{J}$。

**例 2**：增大入射光的强度，光电子的最大初动能如何变化？

**解**：最大初动能只与入射光频率和金属逸出功有关，与光强无关，增大光强只增加光电子数目，不改变最大初动能。

## 易错点

- 光电效应是否发生取决于**频率**，不是光强。
- 最大初动能与频率有关，与光强无关。
- 光强增大只增加光电子**数目**。
- 光电效应方程 $E_k = h\nu - W_0$ 中 $\nu$ 必须大于截止频率。

## 背记要点

1. 光电效应方程 $E_k = h\nu - W_0$。
2. 存在截止频率，低于它不发生。
3. 最大初动能与频率有关，与光强无关。
4. 光强越大光电子越多。
