# 1 普朗克黑体辐射理论

## 概念定义

**黑体**：能够完全吸收射到其表面的各种波长的电磁波而不发生反射的物体。黑体辐射的强度只与温度有关。

**黑体辐射**：黑体向外辐射电磁波的现象。辐射强度按波长分布，随温度升高，辐射强度增大，且辐射的电磁波波长向短波方向移动。

**能量子**：普朗克提出，电磁波的辐射和吸收的能量是不连续的，只能是一份一份的，每一份能量为 $\varepsilon = h\nu$，其中 $h = 6.63 \times 10^{-34}\ \text{J·s}$ 是普朗克常量，$\nu$ 是频率。

**普朗克假设**：能量是量子化的，即 $E = nh\nu$（$n$ 为正整数），这打破了经典物理中能量连续的观点。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 黑体 | 完全吸收电磁波，不反射 |
| 辐射特点 | 强度只与温度有关 |
| 温度升高 | 辐射增强，波长向短波移动 |
| 能量子 | $\varepsilon = h\nu$ |
| 普朗克常量 | $h = 6.63\times10^{-34}\ \text{J·s}$ |

## 典型例题

**例 1**：某种光的频率为 $5 \times 10^{14}\ \text{Hz}$，求一个光子的能量。

**解**：$\varepsilon = h\nu = 6.63 \times 10^{-34} \times 5 \times 10^{14} = 3.315 \times 10^{-19}\ \text{J}$。

**例 2**：普朗克能量子假设的核心内容是什么？

**解**：能量是量子化的，辐射和吸收的能量只能是一份一份的，每份能量 $\varepsilon = h\nu$，不能连续变化。

## 易错点

- 黑体是**完全吸收**电磁波，不是不辐射。
- 能量子假设说明能量**不连续**，是量子化的。
- 温度升高，辐射峰值向**短波**方向移动。
- 普朗克常量 $h = 6.63\times10^{-34}\ \text{J·s}$。

## 背记要点

1. 黑体完全吸收电磁波。
2. 能量子 $\varepsilon = h\nu$。
3. $h = 6.63\times10^{-34}\ \text{J·s}$。
4. 温度升高辐射增强、峰值向短波移动。
