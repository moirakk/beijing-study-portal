# 3 原子的核式结构模型

## 概念定义

**α 粒子散射实验**：卢瑟福用 α 粒子轰击金箔，发现绝大多数 α 粒子穿过金箔后方向几乎不变，少数发生偏转，极少数发生大角度偏转甚至反弹。

**核式结构模型**：卢瑟福提出，原子中心有一个很小的**原子核**，集中了原子的全部正电荷和几乎全部质量，电子在核外绕核运动。

**原子核大小**：原子核的直径数量级为 $10^{-15}\ \text{m}$，原子直径数量级为 $10^{-10}\ \text{m}$，原子核只占原子体积的极小部分。

**实验结论**：绝大多数 α 粒子穿过说明原子内部大部分是"空的"；少数大角度偏转说明原子核带正电且质量集中。

## 知识梳理

| 实验现象 | 结论 |
| --- | --- |
| 绝大多数穿过 | 原子内部大部分是空的 |
| 少数偏转 | 原子核带正电 |
| 极少数反弹 | 原子核质量大、体积小 |
| 核式模型 | 核在中心，电子绕核运动 |

## 典型例题

**例 1**：α 粒子散射实验中，绝大多数 α 粒子穿过金箔后方向几乎不变，说明什么？

**解**：说明原子内部大部分是"空的"，原子核很小，α 粒子大多不经过原子核附近，不受明显库仑力作用。

**例 2**：极少数 α 粒子发生大角度偏转甚至反弹，说明什么？

**解**：说明原子核带正电且质量很大、体积很小，α 粒子靠近原子核时受到很强的库仑斥力。

## 易错点

- 原子核集中了原子的**全部正电荷**和**几乎全部质量**。
- 原子核直径数量级 $10^{-15}\ \text{m}$，原子 $10^{-10}\ \text{m}$。
- 电子在核外运动，不参与原子核质量。
- 卢瑟福模型不能解释原子光谱的稳定性。

## 背记要点

1. 原子核集中全部正电荷和几乎全部质量。
2. 原子核直径 $10^{-15}\ \text{m}$。
3. 绝大多数 α 粒子穿过，极少数反弹。
4. 核式结构模型由卢瑟福提出。
