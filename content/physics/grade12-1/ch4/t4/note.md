# 4 氢原子光谱和玻尔的原子模型

## 概念定义

**氢原子光谱**：氢原子发出的光谱是**线状谱**（明线光谱），由若干条分立的光谱线组成，说明原子能量是量子化的。

**玻尔原子模型**：①原子只能处于一系列**不连续的能量状态**（定态），能量最低的叫基态，其余叫激发态；②电子在特定轨道上运动时不辐射能量；③原子从高能级跃迁到低能级时辐射光子，能量 $h\nu = E_m - E_n$。

**能级公式**：氢原子能级 $E_n = -\dfrac{13.6}{n^2}\ \text{eV}$（$n = 1,2,3,\dots$），基态能量 $E_1 = -13.6\ \text{eV}$。

**跃迁**：原子吸收或辐射光子时，光子能量必须恰好等于两能级之差。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 光谱 | 线状谱，能量量子化 |
| 定态 | 原子处于不连续能量状态 |
| 跃迁 | $h\nu = E_m - E_n$ |
| 能级 | $E_n = -\dfrac{13.6}{n^2}\ \text{eV}$ |
| 基态 | $E_1 = -13.6\ \text{eV}$ |

## 典型例题

**例 1**：氢原子从 $n=3$ 能级跃迁到 $n=2$ 能级，辐射光子的能量是多少？

**解**：$E_3 = -\dfrac{13.6}{9} = -1.51\ \text{eV}$，$E_2 = -\dfrac{13.6}{4} = -3.4\ \text{eV}$。$h\nu = E_3 - E_2 = -1.51 - (-3.4) = 1.89\ \text{eV}$。

**例 2**：氢原子从基态跃迁到 $n=2$ 能级，需要吸收多大能量的光子？

**解**：$E_1 = -13.6\ \text{eV}$，$E_2 = -3.4\ \text{eV}$。吸收能量 $\Delta E = E_2 - E_1 = -3.4 - (-13.6) = 10.2\ \text{eV}$。

## 易错点

- 光子能量必须**恰好等于**两能级之差才能被吸收。
- 能级是负值，跃迁时用 $E_m - E_n$ 计算。
- 基态能量 $E_1 = -13.6\ \text{eV}$。
- 原子从高能级向低能级跃迁辐射光子，反之吸收光子。

## 背记要点

1. 跃迁公式 $h\nu = E_m - E_n$。
2. 能级 $E_n = -\dfrac{13.6}{n^2}\ \text{eV}$。
3. 基态 $E_1 = -13.6\ \text{eV}$。
4. 光子能量必须等于能级差。
