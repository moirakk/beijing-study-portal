# 噪声的危害和控制

## 核心概念表

| 概念 | 含义 | 说明 |
|---|---|---|
| 噪声 | 妨碍人们正常休息、学习和工作的声音 | 从环保角度定义 |
| 分贝（dB） | 声音强弱的等级单位 | 0 dB 是人耳刚能听到的声音 |
| 声源处减弱 | 防止噪声产生 | 禁止鸣笛、改进机械 |
| 传播过程中减弱 | 阻断噪声传播 | 植树、隔音板 |

## 知识梳理

从物理学角度看，噪声是发声体做无规则振动时发出的声音。从环境保护角度看，凡是妨碍人们正常工作、学习和休息的声音都属于噪声。噪声强弱用分贝表示，$0\ \text{dB}$ 是人耳刚能听到的最微弱声音。

控制噪声有三条途径：在声源处减弱、在传播过程中减弱、在人耳处减弱。具体方法包括改进机器、安装消声器、设置隔音墙、植树造林、戴耳塞等。

## 公式汇总

无定量公式，记住等级：

$$
0\ \text{dB} \sim \text{人耳听觉下限}
$$

## 实验要点

- 比较不同材料（泡沫、木板、棉布）的隔音效果。
- 用分贝仪测噪声等级变化。
- 在声源、传播路径、人耳处分别采取措施。

## 对比分析

| 控制环节 | 措施 | 例子 |
|---|---|---|
| 声源处 | 防止产生 | 机动车禁鸣 |
| 传播过程中 | 阻断传播 | 隔音墙、植树 |
| 人耳处 | 防止进入 | 戴耳塞 |

## 背记要点

1. 噪声从环保和物理两个角度定义。
2. 0 dB 不是无声，是人耳听觉下限。
3. 控制噪声三条途径：声源处、传播中、人耳处。
4. 长期暴露于 90 dB 以上噪声会损害听力。
