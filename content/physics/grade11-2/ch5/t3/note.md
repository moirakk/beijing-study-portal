# 3 利用传感器制作简单的自动控制装置

## 概念定义

**自动控制装置的基本结构**：
$$\text{传感器（感知）}\to\text{控制电路（判断/比较）}\to\text{执行机构（动作）}$$

**继电器**：核心执行/转换元件。控制电路中的小电流通过电磁铁产生磁性，吸合衔铁带动触点，从而**用低压小电流控制高压大电流**的工作电路，并实现控制电路与工作电路的电气隔离。

**斯密特触发器**（教材介绍的电子开关）：输入电压升到上限阈值时输出跳变为低电平，降到下限阈值时跳回高电平，把连续变化的信号变成"开/关"两种状态，避免临界抖动。

## 知识梳理

| 组成 | 功能 | 举例 |
| --- | --- | --- |
| 传感器 | 采集非电学量 | 热敏电阻、光敏电阻 |
| 比较/触发电路 | 判断是否达到阈值 | 斯密特触发器、分压比较 |
| 继电器 | 小电流控制大电流 | 电磁继电器 |
| 执行机构 | 完成动作 | 电动机、加热器、灯、警铃 |
| 典型装置 | 光控路灯、温控报警器、自动门 | |

设计要点：分压电路中调节定值电阻（或电位器）即可设定**动作阈值**。

## 典型例题

**例 1**：光控路灯中，光敏电阻 $R$ 与定值电阻 $R_0$ 串联接 $6\ \text{V}$ 电源，从 $R_0$ 两端取电压送触发器；触发器在输入低于 $2\ \text{V}$ 时接通路灯。白天 $R=1\ \text{k}\Omega$，夜晚 $R=10\ \text{k}\Omega$，$R_0=2\ \text{k}\Omega$。判断昼夜路灯状态。

**解**：白天：$U_{R_0}=\dfrac{R_0}{R+R_0}U=\dfrac{2}{1+2}\times6=4\ \text{V}>2\ \text{V}$，路灯不亮。
夜晚：$U_{R_0}=\dfrac{2}{10+2}\times6=1\ \text{V}<2\ \text{V}$，触发器动作，路灯点亮。
天黑 → 光敏电阻增大 → $R_0$ 分压减小 → 低于阈值 → 开灯，实现自动控制。

**例 2**：温度报警器要求温度超过设定值时警铃（220 V）响。给出热敏电阻（温度升高阻值减小）、继电器、低压电源、定值电阻，说明电路设计思路。

**解**：控制电路：低压电源、热敏电阻 $R_T$、定值电阻与继电器线圈**串联**。
温度升高 → $R_T$ 减小 → 控制电路电流**增大** → 超过继电器吸合电流时衔铁被吸下，接通工作电路 → 警铃响。
调节定值电阻可改变达到吸合电流所对应的温度，即**设定报警温度**；继电器实现了低压控制电路对 220 V 工作电路的隔离控制。

## 易错点

- 分清**控制电路**（含传感器、继电器线圈，低压）与**工作电路**（含用电器，常为高压），两者仅通过继电器触点联系。
- 传感器接"串联分压"位置不同，输出逻辑相反——设计时先明确"量增大时输出电压该增大还是减小"。
- 继电器的常开/常闭触点选择决定"达到条件时接通还是断开"。
- 阈值由分压比与触发器门限共同决定，改变定值电阻即可调节动作点。

## 背记要点

1. 三环节：传感器 → 控制（比较/触发）电路 → 执行机构。
2. 继电器：小电流电磁铁控制大电流触点，兼具隔离保护。
3. 分压取样：$U_{R_0}=\dfrac{R_0}{R+R_0}U$，传感器电阻变化转为电压变化。
4. 斯密特触发器把连续信号变为开/关信号，防临界抖动。
5. 高考视角：北京卷实验/情景题常给控制电路让你判断"量变→阻变→压变→动作"链条，逐环推理即可。
