# 2 常见传感器的工作原理及应用

## 概念定义

**力传感器**：如电阻应变片——金属丝受力形变时长度、截面变化使电阻改变（$R=\rho\dfrac{L}{S}$）；电子秤即基于此。

**温度传感器**：热敏电阻/金属热电阻把温度转换为电阻变化；双金属片利用两种金属**热膨胀系数不同**受热弯曲，控制触点通断（电熨斗温控）。

**光传感器**：光敏电阻等把光照转换为电阻变化，用于火灾报警、自动门、路灯光控。

**霍尔元件**（磁传感器）：通电半导体薄片置于磁场中，载流子受洛伦兹力偏转、在两侧面积累电荷，产生**霍尔电压**
$$U_H=k\frac{IB}{d}$$
（$I$ 为工作电流，$B$ 为磁感应强度，$d$ 为薄片厚度，$k$ 为霍尔系数）。

## 知识梳理

| 传感器 | 物理原理 | 典型应用 |
| --- | --- | --- |
| 应变片力传感器 | 形变 → $R=\rho\dfrac{L}{S}$ 变化 | 电子秤、测力计 |
| 双金属片 | 膨胀系数不同 → 受热弯曲 | 电熨斗、饮水机温控 |
| 热敏电阻 | 温度 → 电阻 | 电子体温计、空调测温 |
| 光敏电阻 | 光照 → 电阻 | 路灯光控、烟雾报警 |
| 霍尔元件 | 洛伦兹力 → 霍尔电压 $U_H=k\dfrac{IB}{d}$ | 测磁场、转速、无刷电机 |
| 电容传感器 | 距离/介质 → $C$ 变化 | 触摸屏、加速度计 |

## 典型例题

**例 1**：霍尔元件 $k=1\times10^{-3}\ \text{V·m/(A·T)}$（合并常数），厚度 $d=1\ \text{mm}$，工作电流 $I=2\ \text{mA}$，置于 $B=0.5\ \text{T}$ 的磁场中（$B$ 垂直薄片）。求霍尔电压。

**解**：$U_H=k\dfrac{IB}{d}=1\times10^{-3}\times\dfrac{2\times10^{-3}\times0.5}{1\times10^{-3}}=1\times10^{-3}\ \text{V}=1\ \text{mV}$。
薄片越薄（$d$ 越小）霍尔电压越大，故霍尔元件都做得很薄。

**例 2**：电熨斗为什么能自动控温？简述双金属片的工作过程。

**解**：温控元件是**双金属片**（上层膨胀系数小、下层大）。温度过高时，下层伸长更多，双金属片向上弯曲，触点**断开**，停止加热；
温度降低后金属片复原，触点重新**接通**，继续加热。如此反复，使温度保持在设定范围附近——这是最简单的自动控温（无源开关型温度传感器）。

## 易错点

- 霍尔电压来源于**洛伦兹力**使载流子横向偏转积累电荷，最终电场力与洛伦兹力平衡（$qE=qvB$）时电压稳定。
- $U_H=k\dfrac{IB}{d}$ 与薄片厚度成**反比**——越薄越灵敏。
- 判断霍尔元件哪一面电位高，必须先弄清**载流子的正负**（电子型与空穴型结论相反）。
- 双金属片弯向膨胀系数**小**的一侧（该侧伸长少）。

## 背记要点

1. 应变片：形变改变 $R=\rho\dfrac{L}{S}$；电子秤原理。
2. 双金属片：膨胀系数不同受热弯曲，弯向膨胀小的一侧。
3. 霍尔电压 $U_H=k\dfrac{IB}{d}$，本质是洛伦兹力与电场力平衡。
4. 光敏电阻、热敏电阻搭配分压/串联电路实现"非电 → 电"。
5. 高考视角：北京卷常考霍尔元件电位高低判断（结合载流子正负用左手定则），是洛伦兹力知识的迁移应用。
