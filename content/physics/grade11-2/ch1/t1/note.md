# 1 磁场对通电导线的作用力

## 概念定义

**安培力**：磁场对通电导线的作用力。当导线与磁场方向垂直时，大小为
$$F=BIL$$
（$B$ 为磁感应强度，$I$ 为电流，$L$ 为导线在磁场中的有效长度）。

**左手定则**：伸开左手，让磁感线穿入手心，四指指向电流方向，拇指所指即安培力方向。安培力总是**垂直于 $B$ 与 $I$ 决定的平面**。

导线与磁场成 $\theta$ 角时，$F=BIL\sin\theta$；平行时（$\theta=0$）$F=0$。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 大小 | $F=BIL\sin\theta$（$\theta$ 为 $I$ 与 $B$ 夹角） |
| 方向 | 左手定则，$F\perp B$ 且 $F\perp I$ |
| 最大值 | $I\perp B$ 时 $F=BIL$ |
| 最小值 | $I\parallel B$ 时 $F=0$ |
| 有效长度 | 弯曲导线取首末端连线长度 |
| 应用 | 电动机、磁电式电流表、磁悬浮 |

## 典型例题

**例 1**：匀强磁场 $B=0.5\ \text{T}$，长 $L=0.4\ \text{m}$ 的直导线通电流 $I=2\ \text{A}$，导线与磁场垂直。求安培力大小；若导线与 $B$ 成 $30^\circ$ 角呢？

**解**：垂直时 $F=BIL=0.5\times2\times0.4=0.4\ \text{N}$。
成 $30^\circ$ 时 $F'=BIL\sin30^\circ=0.4\times\dfrac12=0.2\ \text{N}$。

**例 2**：水平导轨间距 $L=0.5\ \text{m}$，导体棒质量 $m=0.1\ \text{kg}$，竖直向下的匀强磁场 $B=0.4\ \text{T}$，棒通电流 $I=5\ \text{A}$ 后恰好沿导轨匀速滑动。求棒受的摩擦力。

**解**：安培力水平方向，$F=BIL=0.4\times5\times0.5=1\ \text{N}$。
棒匀速运动，合力为零，摩擦力与安培力平衡：$f=F=1\ \text{N}$，方向与运动方向相反。

## 易错点

- $F=BIL$ 仅适用于 $I\perp B$；一般情形要用 $F=BIL\sin\theta$，$\theta$ 是电流与磁场的夹角。
- 弯曲导线的 $L$ 取**有效长度**（首末端连线），不是导线总长。
- 左手定则中四指必须指**电流方向**（正电荷运动方向），不是电子运动方向。
- 安培力方向一定垂直于 $B$ 和 $I$，但 $B$ 与 $I$ 不一定互相垂直。

## 背记要点

1. $F=BIL\sin\theta$，$\theta$ 为 $I$ 与 $B$ 的夹角；垂直最大、平行为零。
2. 方向：左手定则，$F$ 同时垂直于 $I$ 和 $B$。
3. 有效长度：弯曲导线看首末端连线。
4. 通电线圈在磁场中受力矩转动——直流电动机原理。
5. 高考视角：北京卷常把安培力与受力平衡、牛顿第二定律结合考"导体棒"模型，先画受力图再列方程。
