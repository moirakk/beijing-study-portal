# 4 互感和自感

## 概念定义

**互感**：一个线圈中电流变化，在**邻近另一个线圈**中产生感应电动势的现象。变压器、无线充电即基于互感。

**自感**：线圈自身电流变化，穿过**自身**的磁通量变化而产生感应电动势的现象。自感电动势
$$\varepsilon_L=L\frac{\Delta I}{\Delta t}$$
（$L$ 为自感系数，单位亨利 H，由线圈匝数、尺寸、有无铁芯决定）。

自感电动势总是**阻碍电流的变化**：电流增大时反向"拖后腿"，减小时同向"挽留"。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 互感 | 两线圈间通过磁场传递能量/信号（变压器原理） |
| 自感电动势 | $\varepsilon_L=L\dfrac{\Delta I}{\Delta t}$，与电流变化率成正比 |
| 自感系数 L | 匝数多、截面大、加铁芯则 $L$ 大；单位 H |
| 通电自感 | 与线圈串联的灯泡逐渐变亮（电流缓慢增大） |
| 断电自感 | 断开瞬间自感电动势很大，灯泡可能闪亮后熄灭 |
| 应用/防止 | 日光灯镇流器；大电流电路缓慢断开防电弧 |

## 典型例题

**例 1**：线圈自感系数 $L=0.5\ \text{H}$，其中电流在 $0.01\ \text{s}$ 内由 $2\ \text{A}$ 均匀减小到 $0$。求自感电动势大小并说明其作用方向。

**解**：$\varepsilon_L=L\dfrac{\Delta I}{\Delta t}=0.5\times\dfrac{2-0}{0.01}=100\ \text{V}$。
电流减小，自感电动势方向与原电流方向**相同**，企图维持原电流（"减小时挽留"）。可见断电瞬间自感电动势可远大于电源电压。

**例 2**：灯泡 A 与带铁芯线圈 L 并联后接电源，闭合开关稳定后灯正常发光。断开开关瞬间，灯泡为什么会突然闪亮一下？

**解**：稳定时线圈电阻小，通过 L 的电流 $I_L$ 较大。断开开关瞬间，L 中电流不能突变，L 与灯泡构成回路，$I_L$ 全部流过灯泡。
若 $I_L$ 大于灯原来的电流，灯泡会**闪亮**后逐渐熄灭；此瞬间流过灯泡的电流方向与原来**相反**。

## 易错点

- 自感电动势阻碍的是**电流的变化**，不是电流本身；电流增大时阻碍增大，减小时阻碍减小。
- 断电瞬间流过并联灯泡的电流等于线圈中原电流 $I_L$，方向与灯泡原电流**相反**；是否闪亮取决于 $I_L$ 与灯原电流的大小比较。
- 自感系数 $L$ 由线圈自身结构决定，与电流大小、变化快慢无关。
- 互感是"甲变化影响乙"，自感是"自己影响自己"，不要混淆。

## 背记要点

1. $\varepsilon_L=L\dfrac{\Delta I}{\Delta t}$，正比于电流**变化率**。
2. 口诀：电流增大反着来，电流减小顺着帮——总之延缓变化。
3. 通电自感：灯泡渐亮；断电自感：可能闪亮，电流方向反向。
4. 加铁芯 $L$ 显著增大；互感是变压器工作基础。
5. 高考视角：北京卷常考断电自感中灯泡"是否闪亮"与电流方向判断，抓住"线圈电流不能突变"。
