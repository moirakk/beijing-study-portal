# 1 楞次定律

## 概念定义

**电磁感应现象**：穿过闭合回路的磁通量 $\Phi=BS$ 发生变化时，回路中产生感应电流。

**楞次定律**：感应电流的磁场总要**阻碍**引起感应电流的磁通量的变化——"增反减同"：原磁通增大时感应电流磁场与原磁场反向，减小时同向。

**本质**：楞次定律是能量守恒在电磁感应中的体现——"阻碍"意味着必须克服阻碍做功，把其他形式能转化为电能。

**右手定则**：导体切割磁感线时，磁感线穿入手心，拇指指 $v$，四指指感应电流方向（是楞次定律的特例）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 产生条件 | 闭合回路＋磁通量变化 |
| 判断步骤 | 定原磁场方向 → 判 $\Phi$ 增/减 → 增反减同 → 安培定则定电流 |
| "阻碍"表现 | 阻碍磁通变化、阻碍相对运动（来拒去留）、阻碍电流变化 |
| 右手定则 | 适用于导体切割磁感线 |
| 能量本质 | 克服安培力做功 → 转化为电能 |

## 典型例题

**例 1**：条形磁铁 N 极向下插入水平放置的闭合线圈，从上往下看，线圈中感应电流方向如何？

**解**：磁铁插入时穿过线圈向下的磁通量增大，由"增反"，感应电流的磁场向上。
由安培定则（右手螺旋），从上往下看感应电流沿**逆时针**方向。
同时线圈上端呈 N 极，排斥插入的磁铁，阻碍相对运动，与"来拒去留"一致。

**例 2**：如图水平导轨上导体棒 ab 在向里的匀强磁场中向右滑动，判断回路中电流方向及棒所受安培力方向。

**解**：用右手定则：磁感线（向里）穿入手心，拇指指向右（$v$ 方向），四指指示电流由 b 到 a（棒内）。
感应电流在磁场中受安培力，用左手定则判断得安培力方向**向左**，阻碍棒的运动——符合楞次定律"阻碍相对运动"。

## 易错点

- "阻碍"不是"阻止"：磁通量仍在变化，只是被减缓；感应电流也不能使磁通量反向。
- "增反减同"针对的是**感应电流的磁场**与**原磁场**的方向关系，不要与电流方向混淆。
- 右手定则只适用于**导体切割磁感线**；磁通量因 $B$ 变化而变时必须用楞次定律。
- 判断时别忘了最后一步：由感应磁场方向用**安培定则**反推电流绕向。

## 背记要点

1. 产生感应电流条件：闭合回路＋$\Phi$ 变化。
2. 楞次定律核心口诀：**增反减同、来拒去留**。
3. 切割类问题用右手定则更快。
4. "阻碍"的能量本质：克服阻碍做的功转化为电能。
5. 高考视角：北京卷选择题常给"磁铁—线圈"或"双环"情景判断电流方向与受力，规范四步流程可保不错。
