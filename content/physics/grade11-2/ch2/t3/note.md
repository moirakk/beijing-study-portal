# 3 涡流、电磁阻尼和电磁驱动

## 概念定义

**涡流**：整块导体处于变化的磁场中，或在磁场中运动时，导体内部产生的环状感应电流。涡流在导体电阻上发热，遵循 $Q=I^2Rt$ 规律。

**电磁阻尼**：导体在磁场中运动时，感应电流受到的安培力总**阻碍导体的相对运动**，使运动减缓（楞次定律的体现）。

**电磁驱动**：变化的磁场（如旋转磁场）使导体中产生感应电流，安培力**驱动导体沿磁场变化的方向运动**（导体转速略小于磁场转速）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 涡流成因 | 块状导体内磁通量变化，产生环状电流 |
| 涡流应用 | 电磁炉、金属探测器、感应加热炼钢 |
| 涡流危害与对策 | 变压器铁芯发热——用相互绝缘的硅钢片叠成 |
| 电磁阻尼 | 磁电式仪表指针快速稳定、电磁制动（高铁刹车） |
| 电磁驱动 | 感应式异步电动机、模拟电度表转盘 |
| 共同本质 | 楞次定律"阻碍相对运动"＋能量守恒 |

## 典型例题

**例 1**：为什么变压器、电动机的铁芯要用相互绝缘的硅钢片叠压而成，而不用整块铁芯？

**解**：铁芯处于交变磁场中，整块铁芯内磁通量不断变化会产生很强的涡流，$Q=I^2Rt$ 发热严重，浪费电能并可能烧毁设备。
用相互绝缘的薄硅钢片叠成，把涡流限制在薄片截面内：回路面积减小使感应电动势减小，且硅钢电阻率较大，涡流大大减弱，铁损降低。

**例 2**：磁性转盘在铝制圆盘上方旋转（不接触），铝盘随之转动但转速总小于磁转盘，为什么？属于哪种现象？

**解**：属于**电磁驱动**。磁转盘旋转时，铝盘相对磁场运动，盘内产生涡流；由楞次定律，涡流受到的安培力阻碍**相对运动**，即驱动铝盘沿磁场旋转方向转动。
若铝盘转速等于磁场转速，则无相对运动、无涡流、无驱动力，故铝盘转速必须**略小于**磁场转速——这正是感应（异步）电动机的原理。

## 易错点

- 电磁阻尼与电磁驱动本质相同（都是阻碍**相对**运动）：阻尼是"导体动、磁场不动"，驱动是"磁场动、带着导体动"。
- 电磁驱动中导体转速**恒小于**磁场转速，相等则驱动力消失。
- 涡流不总是有害：电磁炉、感应加热是利用涡流；铁芯叠片是抑制涡流。
- 电磁炉只能用铁磁性/导电锅具加热，陶瓷锅不能直接被加热。

## 背记要点

1. 涡流：块状导体内的环状感应电流，发热 $Q=I^2Rt$。
2. 减小涡流：绝缘硅钢片叠压铁芯。
3. 电磁阻尼：阻碍导体运动——仪表指针稳定、电磁制动。
4. 电磁驱动：导体被磁场"拖着走"，转速小于磁场转速——异步电动机。
5. 高考视角：北京卷常以电磁炉、高铁制动、异步电机为情景考概念辨析，抓住"阻碍相对运动"即可。
