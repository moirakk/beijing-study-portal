# 4 电能的输送

## 概念定义

**输电线损耗**：输电电流 $I$ 流过输电线电阻 $R_{线}$ 时的功率损耗
$$P_{损}=I^2R_{线}=\left(\frac{P}{U}\right)^2R_{线}$$
（$P$ 为输送功率，$U$ 为输电电压）。

**高压输电**：输送功率一定时，提高输电电压 $U$ 可减小输电电流 $I=\dfrac{P}{U}$，从而使损耗按 $\dfrac{1}{U^2}$ 大幅降低——电压提高到 $n$ 倍，损耗降为 $\dfrac{1}{n^2}$。

**输电流程**：发电机 → 升压变压器 → 高压输电线 → 降压变压器（可多级）→ 用户。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 输送功率 | $P=UI$（输电起点的电压与电流） |
| 线路损耗 | $P_{损}=I^2R_{线}=\dfrac{P^2}{U^2}R_{线}$ |
| 线路电压降 | $\Delta U=IR_{线}$，$U_{末}=U_{首}-\Delta U$ |
| 减小损耗途径 | ① 提高输电电压（主要）② 减小线阻（粗导线、超导） |
| 输电效率 | $\eta=\dfrac{P-P_{损}}{P}\times100\%$ |
| 我国实践 | 特高压 $\pm800\ \text{kV}$ 直流、$1000\ \text{kV}$ 交流输电 |

## 典型例题

**例 1**：电站输送功率 $P=100\ \text{kW}$，输电线总电阻 $R_{线}=10\ \Omega$。分别用 $1\ \text{kV}$ 和 $10\ \text{kV}$ 输电，求线路损耗功率。

**解**：$U_1=1\ \text{kV}$ 时：$I_1=\dfrac{P}{U_1}=100\ \text{A}$，$P_{损1}=I_1^2R_{线}=100^2\times10=10^5\ \text{W}=100\ \text{kW}$（全部损耗，不可行）。
$U_2=10\ \text{kV}$ 时：$I_2=10\ \text{A}$，$P_{损2}=10^2\times10=1\ \text{kW}$，仅为前者的 $\dfrac{1}{100}$——电压升 10 倍，损耗降 100 倍。

**例 2**：输送功率 $500\ \text{kW}$，输电电压 $10\ \text{kV}$，线路电阻 $8\ \Omega$。求输电电流、线路电压损失、用户端（降压变压器原线圈）电压及输电效率。

**解**：$I=\dfrac{P}{U}=\dfrac{5\times10^5}{10^4}=50\ \text{A}$；
$\Delta U=IR_{线}=50\times8=400\ \text{V}$；末端电压 $U'=10000-400=9600\ \text{V}$。
$P_{损}=I^2R_{线}=50^2\times8=2\times10^4\ \text{W}$；$\eta=\dfrac{500-20}{500}\times100\%=96\%$。

## 易错点

- $P_{损}=\dfrac{P^2}{U^2}R_{线}$ 中 $U$ 是**输电电压**、$P$ 是**输送功率**；不能把 $\dfrac{U^2}{R_{线}}$ 当损耗——$U$ 不是加在线阻两端的电压。
- 线路上损失的电压 $\Delta U=IR_{线}$，损失的功率 $P_{损}=I^2R_{线}=I\Delta U$，都用**输电电流**计算。
- "提高电压降低损耗"的前提是**输送功率一定**。
- 输电线首末端电压不同：$U_{末}=U_{首}-IR_{线}$，降压变压器输入电压是末端电压。

## 背记要点

1. $P_{损}=I^2R_{线}=\left(\dfrac{P}{U}\right)^2R_{线}$：电压升 $n$ 倍，损耗降 $n^2$ 倍。
2. 电压损失 $\Delta U=IR_{线}$；效率 $\eta=1-\dfrac{P_{损}}{P}$。
3. 减损两途径：升压（主）＋减小线阻（辅）。
4. 流程：升压变压器 → 高压线路 → 降压变压器。
5. 高考视角：北京卷常把"两台变压器＋输电线"串成综合计算题，抓住输电电流是全线统一的物理量。
