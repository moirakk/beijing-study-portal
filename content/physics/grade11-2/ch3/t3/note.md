# 3 变压器

## 概念定义

**变压器**：利用**互感**改变交流电压的装置，由闭合铁芯和原（初级）、副（次级）线圈组成。只能变换**交流**，不能变换直流。

**理想变压器**（无能量损耗、无漏磁）：
$$\frac{U_1}{U_2}=\frac{n_1}{n_2}\qquad P_1=P_2\qquad \frac{I_1}{I_2}=\frac{n_2}{n_1}$$

$n_1>n_2$ 为降压变压器，$n_1<n_2$ 为升压变压器。

**制约关系**：电压由**原线圈**决定副线圈（正比于匝数）；电流、功率由**副线圈（负载）**决定原线圈——"电压原定副，电流副定原"。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 工作原理 | 互感：原线圈交流 → 铁芯中交变磁通 → 副线圈感应电动势 |
| 电压比 | $\dfrac{U_1}{U_2}=\dfrac{n_1}{n_2}$（一原一副时） |
| 电流比 | $\dfrac{I_1}{I_2}=\dfrac{n_2}{n_1}$（由 $P_1=P_2$ 推出） |
| 功率关系 | $P_1=P_2=U_2I_2$，输入功率由输出（负载）决定 |
| 铁芯作用 | 增强磁耦合；叠片减小涡流损耗 |
| 常见类型 | 升压/降压变压器、自耦变压器（调压器）、互感器 |

## 典型例题

**例 1**：理想变压器原线圈 1100 匝接 220 V 市电，副线圈 180 匝。求输出电压；若副线圈接 $R=6\ \Omega$ 电阻，求原、副线圈电流。

**解**：$U_2=\dfrac{n_2}{n_1}U_1=\dfrac{180}{1100}\times220=36\ \text{V}$。
$I_2=\dfrac{U_2}{R}=\dfrac{36}{6}=6\ \text{A}$；由 $\dfrac{I_1}{I_2}=\dfrac{n_2}{n_1}$，$I_1=\dfrac{180}{1100}\times6\approx0.98\ \text{A}$。
验证：$P_1=220\times0.98\approx216\ \text{W}\approx P_2=36\times6=216\ \text{W}$。

**例 2**：理想变压器副线圈负载电阻减小（其余不变），原线圈电流如何变化？

**解**：$U_1$、匝数比不变 → $U_2$ 不变；$R$ 减小 → $I_2=\dfrac{U_2}{R}$ 增大 → $P_2=U_2I_2$ 增大。
由 $P_1=P_2$，$P_1$ 增大，而 $U_1$ 不变，故 $I_1=\dfrac{P_1}{U_1}$ **增大**。体现"电流由负载决定"的制约关系。

## 易错点

- 变压器**不能变换直流**：恒定电流磁通量不变，副线圈无感应电动势。
- 动态分析顺序固定：$U_1$、匝数比定 $U_2$ → 负载定 $I_2$ → $P_2$ 定 $P_1$ 定 $I_1$，不可倒着推。
- 变压器改变电压、电流，但**不改变频率**，也不能增大功率（能量守恒）。
- 原线圈电压升高匝数比不变时，"升压变压器"输出也随之升高——匝数比才是本质。

## 背记要点

1. $\dfrac{U_1}{U_2}=\dfrac{n_1}{n_2}$，$\dfrac{I_1}{I_2}=\dfrac{n_2}{n_1}$，$P_1=P_2$。
2. 原理：互感；只变交流，不变频率。
3. 制约关系：电压原定副、电流（功率）副定原。
4. 铁芯用绝缘硅钢片叠成，减小涡流损耗。
5. 高考视角：北京卷动态分析题按"电压→电流→功率"链条推理；含二极管、多副线圈的变形题注意有效值。
