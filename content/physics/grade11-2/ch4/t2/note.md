# 2 电磁场与电磁波

## 概念定义

**麦克斯韦电磁场理论**：
① **变化的磁场产生电场**（感应电场，这是电磁感应的场论解释）；
② **变化的电场产生磁场**。
变化的电场和磁场相互激发、由近及远传播，形成**电磁波**。

**电磁波**：是**横波**——$E$、$B$、传播方向两两垂直；传播**不需要介质**，真空中速度等于光速
$$c=3\times10^8\ \text{m/s}\qquad c=\lambda f$$

**光的电磁说**：光是一种电磁波（麦克斯韦预言、赫兹实验证实电磁波存在）。

## 知识梳理

| 项目 | 内容 |
| --- | --- |
| 理论提出 | 麦克斯韦（1864 预言）；赫兹实验证实（1887） |
| 产生条件 | 周期性变化（振荡）的电场/磁场，相互激发 |
| 波的性质 | 横波，$E\perp B\perp$ 传播方向 |
| 传播介质 | 不需要介质，真空中 $v=c$ |
| 基本关系 | $c=\lambda f$；频率由波源决定，介质中 $v$、$\lambda$ 变小 |
| 波的行为 | 能发生反射、折射、干涉、衍射（波的共性） |

## 典型例题

**例 1**：某电台发射频率为 $100\ \text{MHz}$ 的电磁波，求其在真空中的波长。

**解**：$\lambda=\dfrac{c}{f}=\dfrac{3\times10^8}{100\times10^6}=3\ \text{m}$。
该波属于甚高频无线电波（调频广播波段）。

**例 2**：为什么恒定电流周围虽有磁场，却不能发射电磁波？

**解**：恒定电流产生的是**恒定磁场**，不随时间变化，不能激发电场；没有"变化的场相互激发"的机制，无法形成由近及远传播的电磁波。
只有**周期性变化（振荡）**的电流（如 LC 振荡电路中的高频电流）才能有效向外辐射电磁波，且频率越高辐射能力越强。

## 易错点

- 电磁波是**横波**且**不需要介质**——与机械波（需介质）的本质区别；真空中所有频率的电磁波速率都是 $c$。
- "变化的场"才能相互激发：均匀变化的磁场产生**恒定**电场；振荡的磁场才产生振荡电场并向外传播。
- $c=\lambda f$ 中频率由**波源**决定，进入介质后 $f$ 不变、$v$ 和 $\lambda$ 变小。
- 麦克斯韦**预言**电磁波，赫兹**实验证实**——人物贡献不要张冠李戴。

## 背记要点

1. 麦克斯韦理论两句话：变化的磁场产生电场，变化的电场产生磁场。
2. 电磁波：横波，$E\perp B\perp c$；真空中 $c=3\times10^8\ \text{m/s}$。
3. $c=\lambda f$；不需要介质。
4. 麦克斯韦预言、赫兹证实；光是电磁波。
5. 高考视角：北京卷选择题常考电磁波与机械波的对比及物理学史，"预言—证实"人物是常见选项设置点。
