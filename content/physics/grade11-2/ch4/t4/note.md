# 4 电磁波谱

## 概念定义

**电磁波谱**：按**波长（或频率）**的顺序把电磁波排列成谱。从波长长到短（频率低到高）依次为：
**无线电波 → 红外线 → 可见光 → 紫外线 → X 射线 → γ 射线**

所有电磁波本质相同（都是电磁波，真空中速度均为 $c$），满足 $c=\lambda f$；波长（频率）不同导致特性和用途不同：**频率越高，波动性越不明显、贯穿本领越强**；波长越长，越容易发生衍射。

## 知识梳理

| 波段 | 产生机理 | 主要特性与应用 |
| --- | --- | --- |
| 无线电波 | 振荡电路中自由电子周期性运动 | 波长最长、易衍射；广播、通信、雷达 |
| 红外线 | 一切物体（原子外层电子） | 热效应显著；遥感、夜视、遥控、测温 |
| 可见光 | 原子外层电子跃迁 | 波长约 400–760 nm；引起视觉 |
| 紫外线 | 原子外层电子跃迁 | 化学、荧光效应；杀菌消毒、验钞 |
| X 射线 | 原子内层电子跃迁 | 贯穿本领强；医学透视、安检、探伤 |
| γ 射线 | 原子核内部（衰变等） | 频率最高、贯穿最强；治疗肿瘤、金属探伤 |

## 典型例题

**例 1**：红外线、可见光、紫外线、X 射线中，真空中速度最大的是哪个？衍射最明显的是哪个？贯穿本领最强的是哪个？

**解**：真空中所有电磁波速度**相同**，都是 $c=3\times10^8\ \text{m/s}$，无"最大"之分。
衍射明显程度取决于波长：**红外线**波长最长，最易衍射。
贯穿本领随频率升高而增强：四者中 **X 射线**频率最高，贯穿最强。

**例 2**：医院用什么射线杀菌消毒？用什么射线透视人体？夏天测体温的额温枪利用什么波段？分别说明依据。

**解**：杀菌消毒用**紫外线**——其化学作用强，能破坏细菌病毒的结构；
透视人体用 **X 射线**——贯穿本领强，可穿透软组织在底片/屏上成像；
额温枪利用**红外线**——一切物体都向外辐射红外线，温度越高辐射越强，通过接收人体红外辐射测温。

## 易错点

- 电磁波谱各波段间**没有严格分界**，相邻波段互相重叠（如红外与无线电波的边界）。
- "真空中速度相同"是共性；进入介质后不同频率的波速度不同（色散的根源）。
- 产生机理要对应：无线电波来自振荡电路，X 射线来自内层电子跃迁，γ 射线来自**原子核**。
- 热效应最显著的是红外线，但不是"只有红外线有热效应"，各波段都携带能量。

## 背记要点

1. 谱序（波长递减）：无线电波、红外线、可见光、紫外线、X 射线、γ 射线。
2. 共性：真空中同速 $c$，$c=\lambda f$；本质都是电磁波。
3. 规律：频率越高贯穿越强，波长越长衍射越明显。
4. 应用对号：红外测温遥感、紫外杀菌验钞、X 光透视安检、γ 刀治疗。
5. 高考视角：北京卷以选择题考波段排序、产生机理与应用的对应，"谱序＋一个特性递变规律"可秒杀。
