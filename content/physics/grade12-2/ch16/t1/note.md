# 专题十六 光学与原子物理

## 概念定义

**光的折射**：折射定律 $n = \dfrac{\sin i}{\sin r}$，折射率 $n = \dfrac{c}{v}$。全反射条件：光从光密介质射向光疏介质，入射角大于临界角，$\sin C = \dfrac{1}{n}$。

**光的干涉与衍射**：双缝干涉条纹间距 $\Delta x = \dfrac{L}{d}\lambda$；衍射是光绕过障碍物继续传播的现象。

**光电效应**：$E_k = h\nu - W_0$，其中 $h\nu$ 为光子能量，$W_0$ 为逸出功。光电效应具有瞬时性。

**玻尔原子模型**：能级跃迁时吸收或辐射光子，$h\nu = E_m - E_n$。

**原子核**：核反应方程，质量亏损与质能方程 $E = mc^2$。

## 典型例题

**例 1**：光从空气射入水中，入射角 $60^\circ$，水的折射率 $n = \dfrac{4}{3}$，求折射角。

**解**：$n = \dfrac{\sin i}{\sin r}$，$\sin r = \dfrac{\sin 60^\circ}{4/3} = \dfrac{0.866}{1.333} \approx 0.65$，$r \approx 40.5^\circ$。

**例 2**：某金属逸出功 $W_0 = 3.2\times10^{-19}\ \text{J}$，用频率 $\nu = 8\times10^{14}\ \text{Hz}$ 的光照射，求光电子的最大初动能（$h = 6.63\times10^{-34}$）。

**解**：$E_k = h\nu - W_0 = 6.63\times10^{-34}\times8\times10^{14} - 3.2\times10^{-19} = 5.3\times10^{-19} - 3.2\times10^{-19} = 2.1\times10^{-19}\ \text{J}$。

**例 3**：氢原子从 $n=3$ 跃迁到 $n=2$，能级差 $1.89\ \text{eV}$，求辐射光子频率。

**解**：$h\nu = \Delta E = 1.89\times1.6\times10^{-19}\ \text{J}$，$\nu = \dfrac{1.89\times1.6\times10^{-19}}{6.63\times10^{-34}} \approx 4.56\times10^{14}\ \text{Hz}$。

## 易错点

- 折射率 $n$ 与介质和光的频率有关，与入射角无关。
- 全反射必须从**光密介质**射向光疏介质。
- 光电效应具有**瞬时性**，与光强无关，与频率有关。
- 能级跃迁时，从高能级向低能级跃迁**辐射**光子。
- 质能方程 $E = mc^2$ 中 $m$ 为质量亏损。

## 背记要点

1. 折射定律：$n = \frac{\sin i}{\sin r} = \frac{c}{v}$。
2. 全反射：$\sin C = \frac{1}{n}$。
3. 双缝干涉：$\Delta x = \frac{L}{d}\lambda$。
4. 光电效应：$E_k = h\nu - W_0$。
5. 能级跃迁：$h\nu = E_m - E_n$。
