# 专题十四 电磁综合计算

## 概念定义

**电磁综合问题**：将电场、磁场、电磁感应与力学、能量、动量等知识综合求解，是高考压轴题的核心。

**带电粒子在复合场中运动**：电场力 $F = qE$，洛伦兹力 $F = qvB$，重力 $mg$。可能做直线运动、圆周运动或复杂曲线运动。

**电磁感应中的力学问题**：导体棒切割磁感线产生感应电流，安培力 $F = BIL$ 阻碍运动，用牛顿定律、能量守恒、动量定理求解。

**能量转化**：克服安培力做功等于产生的电能，电能转化为焦耳热 $Q = I^2Rt$。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 复合场 | 电场力、洛伦兹力、重力 |
| 匀速直线 | 合力为零 |
| 匀速圆周 | 洛伦兹力提供向心力 |
| 电磁感应 | $E = BLv$，$I = \frac{E}{R}$ |
| 安培力 | $F = BIL$，阻碍相对运动 |
| 能量转化 | 克服安培力做功 = 电能 = 焦耳热 |
| 动量 | 电磁感应中可用动量定理求速度 |

## 典型例题

**例 1**：长 $L = 0.5\ \text{m}$ 的导体棒以 $v = 4\ \text{m/s}$ 垂直切割 $B = 0.2\ \text{T}$ 磁场，回路电阻 $R = 0.5\ \Omega$，求感应电流和安培力。

**解**：$E = BLv = 0.2\times0.5\times4 = 0.4\ \text{V}$；$I = \dfrac{E}{R} = \dfrac{0.4}{0.5} = 0.8\ \text{A}$；$F = BIL = 0.2\times0.8\times0.5 = 0.08\ \text{N}$。

**例 2**：带电粒子以 $v$ 垂直进入匀强磁场做匀速圆周运动，轨道半径 $r$，求比荷 $\dfrac{q}{m}$。

**解**：$qvB = m\dfrac{v^2}{r}$，$\dfrac{q}{m} = \dfrac{v}{Br}$。

**例 3**：导体棒在磁场中匀速下滑，重力功率与安培力功率关系如何？

**解**：匀速时合力为零，重力功率等于安培力功率，重力势能转化为焦耳热。

## 易错点

- 复合场中要**全面受力分析**，不能漏掉重力。
- 洛伦兹力不做功，但安培力（宏观）可以做功。
- 电磁感应中安培力**阻碍相对运动**，方向判断要准确。
- 能量转化要理清：机械能→电能→焦耳热。
- 匀速运动时合力为零，可列平衡方程。

## 背记要点

1. 电场力：$F = qE$；洛伦兹力：$F = qvB$。
2. 电磁感应：$E = BLv$，$I = \frac{E}{R}$。
3. 安培力：$F = BIL$。
4. 圆周运动：$qvB = m\frac{v^2}{r}$。
5. 克服安培力做功 = 焦耳热。
