# 专题二 牛顿运动定律

## 概念定义

**牛顿第一定律**（惯性定律）：一切物体总保持匀速直线运动状态或静止状态，直到有外力迫使它改变这种状态为止。**惯性**是物体保持原来运动状态的性质，只与质量有关。

**牛顿第二定律**：$\vec{F} = m\vec{a}$，即 $a = \dfrac{F}{m}$。加速度方向与合外力方向相同，具有**瞬时性、矢量性、同体性**。

**牛顿第三定律**：作用力与反作用力大小相等、方向相反、作用在同一直线上，分别作用在两个物体上。

**超重与失重**：加速度向上为超重，$N = m(g+a)$；加速度向下为失重，$N = m(g-a)$；完全失重时 $a = g$，$N = 0$。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 牛顿第二定律 | $a = \dfrac{F}{m}$，$F$ 为合外力 |
| 瞬时性 | 力变则加速度立即变 |
| 超重 | 加速度向上，$N > mg$ |
| 失重 | 加速度向下，$N < mg$ |
| 完全失重 | $a = g$，$N = 0$ |
| 连接体 | 整体法求加速度，隔离法求内力 |
| 临界问题 | 接触面恰好分离、绳恰好拉直等 |

## 典型例题

**例 1**：质量为 $2\ \text{kg}$ 的物体在水平面上受 $10\ \text{N}$ 的水平拉力，动摩擦因数 $\mu = 0.2$，求加速度。

**解**：摩擦力 $f = \mu mg = 0.2 \times 2 \times 10 = 4\ \text{N}$。合外力 $F = 10 - 4 = 6\ \text{N}$，$a = \dfrac{F}{m} = \dfrac{6}{2} = 3\ \text{m/s}^2$。

**例 2**：电梯以 $2\ \text{m/s}^2$ 的加速度加速上升，质量为 $50\ \text{kg}$ 的人对电梯地板的压力多大？

**解**：$N - mg = ma$，$N = m(g+a) = 50 \times (10+2) = 600\ \text{N}$。由牛顿第三定律，人对地板的压力也为 $600\ \text{N}$。

**例 3**：光滑水平面上两物体 $m_1$、$m_2$ 用轻绳连接，受水平力 $F$ 拉动，求绳中张力。

**解**：整体 $a = \dfrac{F}{m_1+m_2}$；隔离 $m_2$：$T = m_2 a = \dfrac{m_2 F}{m_1+m_2}$。

## 易错点

- 牛顿第二定律中 $F$ 是**合外力**，不是某个分力。
- 作用力与反作用力**不能抵消**，因为它们作用在不同物体上。
- 超重、失重看**加速度方向**，不是看速度方向。
- 完全失重时物体仍受重力，只是视重为零。
- 连接体问题中绳的张力不一定等于拉力 $F$。

## 背记要点

1. 牛顿第二定律：$a = \dfrac{F}{m}$。
2. 超重：$N = m(g+a)$；失重：$N = m(g-a)$。
3. 惯性只与质量有关，与速度无关。
4. 作用力与反作用力等大反向、作用在不同物体上。
5. 连接体：整体求加速度，隔离求内力。
