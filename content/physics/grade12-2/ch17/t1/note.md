# 专题十七 实验专题

## 概念定义

**高考物理实验**：包括力学实验、电学实验、光学实验等，重点考查实验原理、器材选择、操作步骤、数据处理和误差分析。

**常用实验**：研究匀变速直线运动（用打点计时器）、验证牛顿第二定律、验证机械能守恒、测电阻、测电源电动势和内阻、描绘小灯泡伏安特性曲线等。

**数据处理**：用逐差法求加速度 $a = \dfrac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T^2}$；用图像法处理数据，如 $U$-$I$ 图像求电动势和内阻。

## 知识梳理

| 实验 | 关键点 |
| --- | --- |
| 打点计时器 | 求速度 $\bar{v} = \frac{x}{t}$，逐差法求 $a$ |
| 验证牛顿第二定律 | 平衡摩擦力，$a$-$F$ 图像 |
| 验证机械能守恒 | 用自由落体，$mgh = \frac{1}{2}mv^2$ |
| 测电阻 | 伏安法，内接外接选择 |
| 测电源电动势 | $U$-$I$ 图像，纵截距为 $E$ |
| 伏安特性曲线 | 滑动变阻器分压接法 |
| 误差分析 | 系统误差、偶然误差 |

## 典型例题

**例 1**：用打点计时器研究匀变速运动，相邻计数点间距 $x_1 = 2.0\ \text{cm}$，$x_2 = 3.0\ \text{cm}$，$x_3 = 4.0\ \text{cm}$，打点周期 $T = 0.02\ \text{s}$，相邻计数点间有 4 个点未画出，求加速度。

**解**：计数点间隔 $T' = 5T = 0.1\ \text{s}$。$a = \dfrac{x_3 - x_1}{2T'^2} = \dfrac{(4.0-2.0)\times10^{-2}}{2\times0.01} = 1\ \text{m/s}^2$。

**例 2**：用伏安法测电阻，电压表读数 $2.0\ \text{V}$，电流表读数 $0.4\ \text{A}$，求电阻。

**解**：$R = \dfrac{U}{I} = \dfrac{2.0}{0.4} = 5\ \Omega$。

**例 3**：测电源电动势和内阻，$U$-$I$ 图像纵截距为 $1.5\ \text{V}$，斜率绝对值为 $0.5$，求 $E$ 和 $r$。

**解**：纵截距即电动势 $E = 1.5\ \text{V}$；斜率绝对值即内阻 $r = 0.5\ \Omega$。

## 易错点

- 打点计时器求加速度用**逐差法**，不能用相邻两点直接求。
- 验证牛顿第二定律要**平衡摩擦力**。
- 伏安法测电阻要判断**内接还是外接**（比较 $R_x$ 与 $\sqrt{R_AR_V}$）。
- 测电源电动势用 $U$-$I$ 图像，纵截距为 $E$，斜率绝对值为 $r$。
- 实验误差要区分**系统误差**和偶然误差。

## 背记要点

1. 逐差法：$a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T^2}$。
2. 伏安法：$R = \frac{U}{I}$。
3. 测电源：$U = E - Ir$，图像纵截距为 $E$。
4. 验证机械能守恒：$mgh = \frac{1}{2}mv^2$。
5. 平衡摩擦力：使小车重力沿斜面分力等于摩擦力。
