# 专题七 动量与动量守恒

## 概念定义

**动量**：$p = mv$，是矢量，方向与速度方向相同。

**冲量**：$I = Ft$，是矢量，方向与力方向相同。动量定理：合外力的冲量等于物体动量的变化，$Ft = \Delta p = mv_2 - mv_1$。

**动量守恒定律**：系统不受外力或所受合外力为零时，系统总动量保持不变：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$。

**碰撞**：弹性碰撞（动量、动能均守恒）、非弹性碰撞（动量守恒、动能不守恒）、完全非弹性碰撞（碰后共速，动能损失最大）。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 动量 | $p = mv$，矢量 |
| 冲量 | $I = Ft$，矢量 |
| 动量定理 | $Ft = \Delta p$ |
| 动量守恒条件 | 合外力为零或内力远大于外力 |
| 弹性碰撞 | 动量、动能均守恒 |
| 完全非弹性碰撞 | 碰后共速，动能损失最大 |
| 反冲 | 系统动量守恒，如火箭发射 |

## 典型例题

**例 1**：质量为 $2\ \text{kg}$ 的物体以 $5\ \text{m/s}$ 运动，受 $10\ \text{N}$ 的力作用 $2\ \text{s}$ 后速度变为多少（力与运动同向）？

**解**：动量定理 $Ft = mv_2 - mv_1$，$10\times2 = 2(v_2 - 5)$，$v_2 = 15\ \text{m/s}$。

**例 2**：质量 $m_1 = 1\ \text{kg}$ 以 $4\ \text{m/s}$ 运动的物体与静止的 $m_2 = 3\ \text{kg}$ 物体发生完全非弹性碰撞，求碰后共同速度。

**解**：动量守恒 $m_1v_1 = (m_1+m_2)v$，$v = \dfrac{1\times4}{1+3} = 1\ \text{m/s}$。

**例 3**：质量 $m_1$、$m_2$ 两球发生弹性正碰，$m_2$ 静止，求碰后两球速度。

**解**：动量守恒 $m_1v_1 = m_1v_1' + m_2v_2'$，动能守恒 $\frac{1}{2}m_1v_1^2 = \frac{1}{2}m_1v_1'^2 + \frac{1}{2}m_2v_2'^2$。解得 $v_1' = \dfrac{m_1-m_2}{m_1+m_2}v_1$，$v_2' = \dfrac{2m_1}{m_1+m_2}v_1$。

## 易错点

- 动量、冲量都是**矢量**，列式时注意方向（正负号）。
- 动量守恒条件是**合外力为零**，不是某个力为零。
- 完全非弹性碰撞动能损失最大，但动量仍守恒。
- 碰撞问题要检验**动能不增加**、**速度合理**（不穿碰）。
- 动量定理中 $F$ 是**合外力**，不是某个力。

## 背记要点

1. 动量：$p = mv$；冲量：$I = Ft$。
2. 动量定理：$Ft = \Delta p$。
3. 动量守恒：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$。
4. 弹性碰撞：动量、动能均守恒。
5. 完全非弹性碰撞：碰后共速，动能损失最大。
