# 专题十五 热学

## 概念定义

**分子动理论**：物质由大量分子组成，分子永不停息地做无规则运动，分子间存在引力和斥力。

**温度**：分子平均动能的标志。**内能**：物体内所有分子动能和分子势能的总和。

**热力学第一定律**：$\Delta U = Q + W$，其中 $\Delta U$ 为内能变化，$Q$ 为吸收热量，$W$ 为外界对气体做功。

**理想气体状态方程**：$\dfrac{p_1V_1}{T_1} = \dfrac{p_2V_2}{T_2}$，即 $\dfrac{pV}{T} = \text{常量}$。

**热力学第二定律**：热量不能自发地从低温物体传到高温物体；不可能从单一热源吸热使之完全转化为功而不产生其他影响。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 分子动理论 | 分子无规则运动，分子间有引力和斥力 |

| 内能 | 分子动能 + 分子势能 |
| 热力学第一定律 | $\Delta U = Q + W$ |

## 典型例题

**例 1**：一定质量理想气体，吸收热量 $200\ \text{J}$，同时对外做功 $80\ \text{J}$，求内能变化。

**解**：$\Delta U = Q + W = 200 + (-80) = 120\ \text{J}$，内能增加 $120\ \text{J}$。

**例 2**：一定质量理想气体，压强不变，温度升高，体积如何变化？

**解**：由 $\dfrac{pV}{T} = \text{常量}$，$p$ 不变时 $T$ 升高则 $V$ 增大，气体膨胀。

**例 3**：理想气体等温压缩，体积减半，压强变为原来的几倍？

**解**：等温时 $pV$ 不变，$V$ 减半则 $p$ 变为原来的 $2$ 倍。

## 易错点

- 热力学第一定律中 $W$ 是**外界对气体做功**，气体对外做功为负。
- 理想气体**内能只与温度有关**，与体积无关。
- 温度是分子**平均动能**的标志，不是平均速率。
- 热力学第二定律强调"**自发**"和"不产生其他影响"。
- 等温、等容、等压过程要正确选用相应定律。

## 背记要点

1. 热力学第一定律：$\Delta U = Q + W$。
2. 理想气体：$\frac{pV}{T} = \text{常量}$。
3. 等温（玻意耳）：$pV = \text{常量}$。
4. 等容（查理）：$\frac{p}{T} = \text{常量}$。
5. 等压（盖-吕萨克）：$\frac{V}{T} = \text{常量}$。
