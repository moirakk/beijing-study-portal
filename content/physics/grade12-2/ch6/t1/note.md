# 专题六 动能定理与机械能守恒

## 概念定义

**动能**：$E_k = \dfrac{1}{2}mv^2$，是标量，与速度方向无关。

**动能定理**：合外力做的功等于物体动能的变化，$W_{\text{合}} = \Delta E_k = \dfrac{1}{2}mv_2^2 - \dfrac{1}{2}mv_1^2$。

**重力势能**：$E_p = mgh$，与参考面选取有关，重力做功等于重力势能减少量 $W_G = -\Delta E_p$。

**机械能守恒定律**：只有重力（或弹簧弹力）做功时，动能与势能相互转化，机械能总量不变：$E_{k1} + E_{p1} = E_{k2} + E_{p2}$。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 动能 | $E_k = \frac{1}{2}mv^2$ |
| 动能定理 | $W_{\text{合}} = \Delta E_k$，适用于变力、曲线运动 |
| 重力势能 | $E_p = mgh$，$W_G = -\Delta E_p$ |
| 机械能守恒条件 | 只有重力或弹簧弹力做功 |
| 机械能守恒式 | $E_{k1}+E_{p1} = E_{k2}+E_{p2}$ |
| 功能关系 | 除重力外其他力做功等于机械能变化 |

## 典型例题

**例 1**：质量为 $2\ \text{kg}$ 的物体从 $10\ \text{m}$ 高处自由下落，求落地时的速度（$g=10$）。

**解**：机械能守恒 $mgh = \frac{1}{2}mv^2$，$v = \sqrt{2gh} = \sqrt{2\times10\times10} = 10\sqrt{2}\ \text{m/s}$。

**例 2**：物体在粗糙水平面上以 $10\ \text{m/s}$ 滑行，动摩擦因数 $\mu = 0.5$，求滑行距离。

**解**：动能定理 $-\mu mg s = 0 - \frac{1}{2}mv^2$，$s = \dfrac{v^2}{2\mu g} = \dfrac{100}{2\times0.5\times10} = 10\ \text{m}$。

**例 3**：小球从光滑圆弧轨道顶端由静止滑下，轨道半径 $R$，求小球到达最低点时的速度。

**解**：机械能守恒 $mgR = \frac{1}{2}mv^2$，$v = \sqrt{2gR}$。

## 易错点

- 动能定理中 $W_{\text{合}}$ 是**所有力**做功的代数和。
- 机械能守恒条件是**只有重力或弹簧弹力做功**，有摩擦力时不守恒。
- 重力势能是**相对量**，与参考面选取有关，但变化量与参考面无关。
- 动能是标量，只有大小没有方向。
- 除重力外其他力做正功，机械能**增加**；做负功，机械能**减少**。

## 背记要点

1. 动能：$E_k = \frac{1}{2}mv^2$。
2. 动能定理：$W_{\text{合}} = \Delta E_k$。
3. 重力势能：$E_p = mgh$。
4. 机械能守恒：$E_{k1}+E_{p1} = E_{k2}+E_{p2}$。
5. 自由落体：$v = \sqrt{2gh}$。
