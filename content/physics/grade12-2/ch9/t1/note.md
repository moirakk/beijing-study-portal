# 专题九 电场

## 概念定义

**电场强度**：$E = \dfrac{F}{q}$，点电荷场强 $E = k\dfrac{Q}{r^2}$，方向为正电荷受力方向。

**电势**：$\varphi = \dfrac{E_p}{q}$，电势差 $U_{AB} = \varphi_A - \varphi_B = \dfrac{W_{AB}}{q}$。

**电场力做功**：$W = qU$，与路径无关。电场力做正功，电势能减小。

**匀强电场**：$E = \dfrac{U}{d}$，电场线与等势面垂直，沿电场线方向电势降低。

**电容**：$C = \dfrac{Q}{U}$，平行板电容 $C = \dfrac{\varepsilon_r S}{4\pi kd}$。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 电场强度 | $E = \frac{F}{q} = k\frac{Q}{r^2}$ |

| 匀强电场 | $E = \frac{U}{d}$ |

## 典型例题

**例 1**：点电荷 $Q = 2\times10^{-8}\ \text{C}$ 在真空中，求距其 $0.3\ \text{m}$ 处的场强（$k = 9\times10^9$）。

**解**：$E = k\dfrac{Q}{r^2} = 9\times10^9 \times \dfrac{2\times10^{-8}}{0.09} = 2000\ \text{N/C}$。

**例 2**：电荷 $q = 2\times10^{-6}\ \text{C}$ 从 A 移到 B，电场力做功 $4\times10^{-4}\ \text{J}$，求 A、B 间电势差。

**解**：$U_{AB} = \dfrac{W_{AB}}{q} = \dfrac{4\times10^{-4}}{2\times10^{-6}} = 200\ \text{V}$。

**例 3**：匀强电场中相距 $0.1\ \text{m}$ 的两点电势差为 $50\ \text{V}$，求场强。

**解**：$E = \dfrac{U}{d} = \dfrac{50}{0.1} = 500\ \text{V/m}$。

## 易错点

- 场强是**矢量**，电势是**标量**，两者无必然联系。
- 电场力做功与路径无关，只与初末位置电势差有关。
- 沿电场线方向电势**降低**，但场强不一定减小。
- 电容 $C = \frac{Q}{U}$ 是定义式，$C$ 由电容器本身决定。
- 带电粒子在电场中运动，注意重力是否忽略。

## 背记要点

1. 场强：$E = \frac{F}{q} = k\frac{Q}{r^2}$。
2. 电势差：$U_{AB} = \frac{W_{AB}}{q}$。
3. 电场力做功：$W = qU$。
4. 匀强电场：$E = \frac{U}{d}$。
5. 电容：$C = \frac{Q}{U}$。
