# 专题三 运动学综合

## 概念定义

**匀变速直线运动**：加速度恒定的直线运动。基本公式：$v = v_0 + at$，$x = v_0 t + \dfrac{1}{2}at^2$，$v^2 - v_0^2 = 2ax$。

**自由落体**：初速度为零、只受重力的匀加速运动，$a = g$，$v = gt$，$h = \dfrac{1}{2}gt^2$。

**竖直上抛**：$v = v_0 - gt$，$h = v_0 t - \dfrac{1}{2}gt^2$，上升最大高度 $H = \dfrac{v_0^2}{2g}$，上升时间 $t = \dfrac{v_0}{g}$。

**匀变速运动推论**：中间时刻速度 $\bar{v} = \dfrac{v_0+v}{2}$；连续相等时间位移差 $\Delta x = aT^2$。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 基本公式 | $v = v_0+at$，$x = v_0t+\frac{1}{2}at^2$ |
| 速度位移 | $v^2 - v_0^2 = 2ax$ |
| 平均速度 | $\bar{v} = \dfrac{v_0+v}{2} = \dfrac{x}{t}$ |
| 位移差 | $\Delta x = aT^2$（纸带求加速度） |
| 自由落体 | $v = gt$，$h = \frac{1}{2}gt^2$ |
| 竖直上抛 | 对称性：上升与下降时间相等 |
| 图像法 | $v$-$t$ 图斜率即加速度，面积即位移 |

## 典型例题

**例 1**：汽车以 $20\ \text{m/s}$ 行驶，刹车后以 $5\ \text{m/s}^2$ 匀减速，求刹车后 $5\ \text{s}$ 内的位移。

**解**：停车时间 $t = \dfrac{v_0}{a} = \dfrac{20}{5} = 4\ \text{s} < 5\ \text{s}$，故 $5\ \text{s}$ 内已停止。$x = \dfrac{v_0^2}{2a} = \dfrac{400}{10} = 40\ \text{m}$。

**例 2**：物体做匀加速直线运动，第 $1\ \text{s}$ 内位移 $2\ \text{m}$，第 $2\ \text{s}$ 内位移 $4\ \text{m}$，求加速度和初速度。

**解**：$\Delta x = aT^2$，$a = \dfrac{4-2}{1^2} = 2\ \text{m/s}^2$。第 $1\ \text{s}$ 内 $\bar{v} = 2\ \text{m/s}$ 即 $t=0.5\ \text{s}$ 时速度，$v_0 = \bar{v} - at = 2 - 2\times0.5 = 1\ \text{m/s}$。

**例 3**：竖直上抛物体初速度 $30\ \text{m/s}$，求 $2\ \text{s}$ 末的速度和位移。

**解**：$v = 30 - 10\times2 = 10\ \text{m/s}$（向上）；$h = 30\times2 - \frac{1}{2}\times10\times4 = 60 - 20 = 40\ \text{m}$。

## 易错点

- 刹车问题要先判断**何时停止**，不能直接代入时间。
- 竖直上抛用**对称性**：上升与下降时间相等、速度大小相等。
- 位移、速度、加速度都是**矢量**，注意方向（正负号）。
- $v$-$t$ 图像中面积表示位移，$x$-$t$ 图像中斜率表示速度。
- 平均速度公式 $\bar{v} = \dfrac{v_0+v}{2}$ 仅适用于**匀变速**运动。

## 背记要点

1. $v = v_0 + at$，$x = v_0t + \frac{1}{2}at^2$。
2. $v^2 - v_0^2 = 2ax$。
3. $\Delta x = aT^2$。
4. 自由落体：$v = gt$，$h = \frac{1}{2}gt^2$。
5. 竖直上抛最大高度 $H = \dfrac{v_0^2}{2g}$。
