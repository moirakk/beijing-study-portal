# 1 牛顿第一定律

## 概念定义

**牛顿第一定律（惯性定律）**：一切物体总保持**匀速直线运动状态或静止状态**，除非作用在它上面的力迫使它改变这种状态。

**惯性**：物体保持原来运动状态的性质，是物体的**固有属性**；**质量是惯性大小的唯一量度**，与速度、受力、位置均无关。

## 知识梳理

| 项目 | 要点 |
| --- | --- |
| 伽利略理想斜面实验 | 表面越光滑小球滚得越远，**外推**：无摩擦则永远运动——实验＋逻辑推理 |
| 亚里士多德观点（错误） | "力是维持运动的原因" |
| 第一定律的意义 | ①揭示力是**改变**运动状态（产生加速度）的原因；②定义惯性；③定性给出力与运动关系 |
| 与第二定律关系 | 第一定律**不是**第二定律 $F=0$ 的特例，它定义了惯性参考系，是独立的定律 |
| 惯性表现 | 静止的物体"不愿动"，运动的物体"不愿停"（刹车前倾、起动后仰） |

## 典型例题

**例 1**：关于惯性，下列说法正确的是（　）
A. 速度大的物体惯性大　B. 静止的物体没有惯性　C. 质量大的物体惯性大　D. 受力大的物体惯性大

**解**：选 C。惯性只由**质量**决定，与速度、受力、是否运动无关。

**例 2**：车厢内悬挂的小球突然向后摆，说明车厢在做什么运动？

**解**：小球因惯性保持原速度，相对车向后摆，说明车在**加速前进**（或由静止起动）。若小球前摆则车在减速。

## 易错点

- "物体不受力才有惯性"错——任何物体任何时刻都有惯性。
- "惯性是一种力"错——惯性是属性，不是力，不能说"受到惯性作用"。
- 力是改变运动状态的原因，**不是**维持运动的原因。
- 理想实验不等于凭空想象：以可靠事实为基础＋科学外推。

## 背记要点

1. 第一定律内容："保持匀速直线或静止，除非力迫使改变"。
2. 惯性唯一量度：质量；惯性与运动状态、受力无关。
3. 伽利略理想斜面实验：事实＋外推的科学方法（高考科学素养考点）。
4. 高考视角：惯性概念辨析常与生活情境（急刹、起动）结合，为选择题送分点，但表述陷阱多。
