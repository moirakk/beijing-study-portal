# 3 牛顿第三定律

## 概念定义

**牛顿第三定律**：两个物体之间的作用力和反作用力总是**大小相等、方向相反、作用在同一条直线上**：
$$\vec{F}=-\vec{F}'$$

作用力与反作用力**同时产生、同时变化、同时消失**，性质相同（同为弹力或同为摩擦力等），分别作用在**两个不同物体**上，各自产生效果，**不能抵消、不能求合力**。

## 知识梳理

| 项目 | 一对作用力与反作用力 | 一对平衡力 |
| --- | --- | --- |
| 作用对象 | **两个**物体 | **同一个**物体 |
| 力的性质 | 一定相同 | 不一定相同 |
| 依赖关系 | 同生同灭同变化 | 相互独立，可单独消失 |
| 效果 | 各自产生效果，不可抵消 | 合力为零，可相互抵消 |
| 大小方向 | 等大、反向、共线 | 等大、反向、共线 |

**注意**：无论物体大小、运动状态如何（静止、匀速、加速），作用力与反作用力**总是**等大反向。鸡蛋碰石头，蛋碎是因为蛋壳承受力差，两者受力仍等大。

## 典型例题

**例 1**：马拉车加速前进时，马对车的拉力与车对马的拉力大小关系是（　）
A. 马对车的拉力大　B. 车对马的拉力大　C. 一样大　D. 与运动状态有关

**解**：选 C。作用力与反作用力**任何情况**下都等大反向。车能加速是因为**车所受合力**（马的拉力减去地面阻力）向前，与"两力等大"不矛盾。

**例 2**：静止在桌面上的书，指出"书受的重力"与"书对桌面的压力"是什么关系？

**解**：既不是平衡力也不是作用力与反作用力。重力的反作用力是**书对地球的吸引力**；书对桌压力的反作用力是**桌对书的支持力**；与书的重力构成平衡力的是**桌对书的支持力**。

## 易错点

- 平衡力与作用力反作用力最易混：判断先看是否作用在**同一物体**。
- 压力的施力物体是书（不是重力"传下去"），压力与重力性质不同、对象不同。
- "先有作用力后有反作用力"是错的——两者同时产生。
- 拔河获胜靠的是**与地面的摩擦力**差异，双方绳上拉力等大。

## 背记要点

1. $F=-F'$：等大、反向、共线、异体、同性质、同生同灭。
2. 平衡力"一体"，作用力反作用力"二体"。
3. 效果不可抵消——分别作用在不同物体上。
4. 高考视角：概念辨析选择题常客，也是受力分析中隔离法转移力的依据。
