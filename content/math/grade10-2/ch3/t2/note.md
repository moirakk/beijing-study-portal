# 8.2 立体图形的直观图

## 概念定义

**直观图**：表示空间图形的平面图形，中学采用**斜二测画法**绘制。
**斜二测画法规则**：
1. 建系：原图取 $xOy$ 轴，直观图中取 $x'O'y'$ 轴，使 $\angle x'O'y'=45°$（或 $135°$）；
2. 平行性不变：原图中平行于 $x$ 轴（$y$ 轴）的线段，直观图中仍平行于 $x'$ 轴（$y'$ 轴）；
3. 长度规则：平行于 $x$ 轴的线段长度**不变**，平行于 $y$ 轴的线段长度**减半**。

## 知识梳理

| 项目 | 原图 → 直观图 | 说明 |
| --- | --- | --- |
| $x$ 方向线段 | 长度不变 | 水平方向保真 |
| $y$ 方向线段 | 长度取一半 | 且与 $x'$ 轴成 $45°$ |
| $z$ 方向线段（画立体） | 长度不变，仍竖直 | 平行于 $z'$ 轴 |
| 平行关系 | 保持平行 | 平行四边形仍为平行四边形 |
| 垂直、角度 | 一般改变 | 正方形变为 $45°$ 平行四边形 |
| 面积 | $S'=\dfrac{\sqrt2}{4}S$ | 反之 $S=2\sqrt2\,S'$ |

**面积比推导**：$y$ 方向减半（$\times\frac12$），再投影到与 $x'$ 垂直方向乘 $\sin45°=\frac{\sqrt2}{2}$，故 $S'=S\times\dfrac12\times\dfrac{\sqrt2}{2}=\dfrac{\sqrt2}{4}S$。

原图正方形（边长 $a$，面积 $a^2$）→ 直观图为底 $a$、斜边 $\dfrac{a}{2}$、夹角 $45°$ 的平行四边形，面积 $a\cdot\dfrac{a}{2}\sin45°=\dfrac{\sqrt2}{4}a^2$，验证面积比。

## 典型例题

**例 1**：用斜二测画法画边长为 2 的正方形 $OABC$（$OA$ 在 $x$ 轴上）的直观图，求直观图的面积。

**解**：$O'A'=2$（不变），$O'C'=1$（减半），$\angle A'O'C'=45°$。
$S'=O'A'\cdot O'C'\sin45°=2\times1\times\dfrac{\sqrt2}{2}=\sqrt2$。
（验证：$S'=\dfrac{\sqrt2}{4}\times4=\sqrt2$。）

**例 2**：一个平面图形的直观图是边长为 1 的正方形，求原图形的面积。

**解**：由 $S'=\dfrac{\sqrt2}{4}S$ 得 $S=2\sqrt2\,S'=2\sqrt2\times1=2\sqrt2$。
（原图形实为底 1、高 $2\sqrt2$ 的平行四边形。）

## 易错点

- 只有**平行于 $y$ 轴**的线段才减半；斜线段既不保长也不简单减半，须由端点坐标确定。
- 直观图中角度失真：原图的直角一般变为 $45°$ 或 $135°$，不能在直观图中直接量角。
- 面积比 $\dfrac{S'}{S}=\dfrac{\sqrt2}{4}$ 方向不要用反：由直观图还原原图要**乘 $2\sqrt2$**。
- 画立体图时 $z$ 方向长度不变且保持竖直。

## 背记要点

1. 斜二测口诀：横不变、纵减半、夹角 $45°$、平行性保持。
2. $S_{直观}=\dfrac{\sqrt2}{4}S_{原}$；$S_{原}=2\sqrt2\,S_{直观}$。
3. 还原原图：把 $45°$ 方向线段旋回 $y$ 轴并加倍。
4. 高考视角：直观图与原图面积换算是小题常客，记牢 $\dfrac{\sqrt2}{4}$ 与 $2\sqrt2$ 一对互逆系数即可秒解。
