# 代数式 · 重点梳理

标签：#基础 #复习整合

> 本页是第三章《代数式》的复习整合页，把[[3.1 列代数式表示数量关系]]和[[3.2 代数式的值]]的核心内容串成一张网。

## 一、本章知识结构

- **代数式**：用运算符号把数或字母连接起来的式子
  - 列代数式（文字 → 符号）
  - 代数式求值（代入 → 计算）
  - 整体代入（结构 → 替换）

## 二、核心考点清单

| 考点 | 关键要求 | 高频错误 |
|---|---|---|
| 书写规范 | 数字在前、乘号省略、除法写分数 | $a3$、$3\frac{1}{2}x$、$x \div 2$ |
| 翻译"和差倍分" | 抓"的"字断句，正确加括号 | $2(a+b)$ 写成 $2a+b$ |
| 数位表示 | 两位数 $= 10a + b$ | 写成 $ab$ |
| 代入求值 | 负数、分数加括号 | $(-2)^2$ 写成 $-2^2$ |
| 整体代入 | 目标式向已知式凑 | 硬解单个字母的值 |
| 图形/数列找规律 | 求增量、代小数检验 | 差 1 错误 |

## 三、方法提炼

### 1. 列代数式四步法

**读题 → 设字母 → 翻译 → 检查规范**

### 2. 代入求值三步曲

**写"当…时" → 代（加括号）→ 算（按运算顺序）**

### 3. 整体代入的"凑"字诀

把目标式变形，凑出已知式的整数倍：

$$
\text{已知 } x^2 + x = 3: \quad 2x^2 + 2x - 1 = 2(x^2 + x) - 1 = 5
$$

## 四、易错点集中检查

1. **符号**：代入负数忘加括号（本章丢分王）；
2. **括号**："和的平方" $(a+b)^2$ 与"平方的和" $a^2 + b^2$；
3. **单位**：结果是和差形式且带单位时要加括号，如 $(2a+3)$ 元；
4. **规律题**：写出通项后必须**代入 $n=1,2$ 检验**。
