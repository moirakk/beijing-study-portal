# 公式与定义卡片 · 等式的性质

## 1. 性质 1（加减）

$$
a = b \implies a \pm c = b \pm c
$$

## 2. 性质 2（乘除）

$$
a = b \implies ac = bc
$$

$$
a = b,\ c \neq 0 \implies \frac{a}{c} = \frac{b}{c}
$$

## 3. 移项法则（性质 1 的推论）

$$
a + b = c \iff a = c - b
$$

移项必变号。

## 4. 对称性与传递性

$$
a = b \iff b = a
$$

$$
a = b,\ b = c \implies a = c
$$
