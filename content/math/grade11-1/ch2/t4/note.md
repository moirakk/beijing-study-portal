# 2.4 圆的方程

## 概念定义

**标准方程**：圆心 $C(a,b)$、半径 $r$ 的圆：
$$(x-a)^2+(y-b)^2=r^2$$
**一般方程**：$x^2+y^2+Dx+Ey+F=0$，当 $D^2+E^2-4F>0$ 时表示圆，圆心 $\left(-\dfrac{D}{2},-\dfrac{E}{2}\right)$，半径 $r=\dfrac{\sqrt{D^2+E^2-4F}}{2}$。

**点与圆的位置关系**：将点代入 $(x_0-a)^2+(y_0-b)^2$ 与 $r^2$ 比大小：大于在圆外、等于在圆上、小于在圆内。

## 知识梳理

| 项目 | 内容 | 说明 |
| --- | --- | --- |
| 标准方程 | $(x-a)^2+(y-b)^2=r^2$ | 几何特征直观，优先使用 |
| 一般方程 | $x^2+y^2+Dx+Ey+F=0$ | 无 $xy$ 项、$x^2,y^2$ 系数相等且非零 |
| 成圆条件 | $D^2+E^2-4F>0$ | $=0$ 表示一个点，$<0$ 无图形 |
| 求圆方法一 | 待定系数法 | 三点用一般式；已知圆心信息用标准式 |
| 求圆方法二 | 几何法 | 圆心在弦的垂直平分线上；半径 = 圆心到圆上点距离 |
| 常见条件转化 | 与 $x$ 轴相切 $\Rightarrow r=|b|$；过原点 $\Rightarrow F=0$ | 画草图辅助 |

**与圆有关的最值**：圆上点到定点距离最值为 $d\pm r$（$d$ 为圆心到定点距离）；形如 $\dfrac{y-y_0}{x-x_0}$ 视为斜率、$x+y$ 视为截距，用相切求最值。

## 典型例题

**例 1**：求过三点 $O(0,0)$、$A(4,0)$、$B(0,2)$ 的圆的方程。

**解**：设 $x^2+y^2+Dx+Ey+F=0$。代入三点：
$F=0$；$16+4D=0\Rightarrow D=-4$；$4+2E=0\Rightarrow E=-2$。
故 $x^2+y^2-4x-2y=0$，即 $(x-2)^2+(y-1)^2=5$。
（几何法更快：$OA,OB$ 为直角边，圆心即斜边 $AB$ 中点 $(2,1)$。）

**例 2**：圆心在直线 $y=2x$ 上，且与 $x$ 轴相切于点 $(1,0)$ 的圆的方程。

**解**：切点 $(1,0)$ 处切线为 $x$ 轴，故圆心在过切点垂直于 $x$ 轴的直线 $x=1$ 上。
又圆心在 $y=2x$ 上，故圆心 $(1,2)$，半径 $r=|2|=2$。
方程：$(x-1)^2+(y-2)^2=4$。

## 易错点

- 一般方程成圆须验证 $D^2+E^2-4F>0$，含参数时最易遗漏。
- 与 $x$ 轴相切时 $r=|b|$（纵坐标的**绝对值**），不是 $r=b$。
- 由一般式配方求圆心半径时，$D,E$ 除以 2 且**变号**。
- 求圆优先考虑**几何法**（垂径定理、切线性质），比纯待定系数计算量小。

## 背记要点

1. 标准式看圆心半径，一般式看是否成圆（$D^2+E^2-4F>0$）。
2. 一般式圆心 $\left(-\dfrac{D}{2},-\dfrac{E}{2}\right)$，$r=\dfrac{\sqrt{D^2+E^2-4F}}{2}$。
3. 过三点用一般式；知圆心线、切线、半径用标准式。
4. 圆上点到定点距离最值 $=d\pm r$；斜率型、截距型最值用相切。
5. 高考视角：求圆方程常作为大题第一问；隐圆（如到两定点距离比为定值的阿波罗尼斯圆）是北京卷创新点。
