# 17.2 勾股定理的逆定理

标签：#中考高频 #判定

## 一、逆定理的内容

**如果三角形的三边长 $a$、$b$、$c$ 满足 $a^2 + b^2 = c^2$，那么这个三角形是直角三角形**，且边 $c$ 所对的角是直角。

它把"由形定数"的勾股定理反过来，变成"由数定形"的**直角三角形判定方法**。

## 二、原命题与逆命题

- 把一个命题的题设和结论互换，得到它的**逆命题**；
- 如果一个定理的逆命题经证明也是真命题，它就叫原定理的**逆定理**；
- 勾股定理与它的逆定理就是一对互逆定理。

> ⚠️ **易错点**：原命题为真，逆命题**不一定**为真。如"对顶角相等"为真，但"相等的角是对顶角"为假。

## 三、勾股数

**能构成直角三角形三边长的三个正整数**叫做勾股数。

常见勾股数组：$(3,4,5)$、$(5,12,13)$、$(6,8,10)$、$(8,15,17)$、$(7,24,25)$、$(9,40,41)$。

> 💡 **技巧**：一组勾股数同乘正整数 $k$ 仍是勾股数，如 $(3,4,5) \to (9,12,15)$。

## 四、典型例题

**例1** 判断三边为 $15$、$8$、$17$ 的三角形是否为直角三角形。

解：最长边为 $17$。$15^2 + 8^2 = 225 + 64 = 289 = 17^2$，
所以是直角三角形，$17$ 所对的角为直角。

**例2** 三边为 $a=7$、$b=9$、$c=12$ 的三角形是直角三角形吗？

解：$7^2 + 9^2 = 49 + 81 = 130 \ne 144 = 12^2$，不是直角三角形。

**例3** 在四边形 $ABCD$ 中，$AB=3$，$BC=4$，$\angle B = 90^\circ$，$CD=12$，$AD=13$，求四边形的面积。

解：连接 $AC$，在 $\text{Rt}\triangle ABC$ 中 $AC = \sqrt{3^2+4^2} = 5$。
又 $AC^2 + CD^2 = 25 + 144 = 169 = AD^2$，故 $\triangle ACD$ 是直角三角形（$\angle ACD = 90^\circ$）。
面积 $= \dfrac{1}{2} \times 3 \times 4 + \dfrac{1}{2} \times 5 \times 12 = 6 + 30 = 36$。

## 五、使用步骤与易错点

判定步骤：

1. 找出**最长边** $c$；
2. 计算较短两边的平方和 $a^2 + b^2$ 与 $c^2$；
3. 相等 → 直角三角形（直角对着最长边）；不相等 → 不是。

> ⚠️ **易错点**：必须用**最长边**作 $c$ 去验证；若拿任意两边平方和与第三边平方比较，可能漏判、错判。

## 六、要点小结

1. $a^2 + b^2 = c^2 \Rightarrow$ 直角三角形（$c$ 为最长边）；
2. 勾股定理管"计算"，逆定理管"判定"，方向相反；
3. 勾股数：满足条件的正整数组，可整体放大；
4. 逆命题真假需单独证明。

## 七、自测题

1. 以下三组数能构成直角三角形三边的是：① $2,3,4$；② $9,12,15$；③ $1,\sqrt{2},\sqrt{3}$。
2. 写出"两直线平行，同位角相等"的逆命题，并判断真假。
3. 三角形三边满足 $a : b : c = 5 : 12 : 13$，周长为 $60$，求它的面积。

<details><summary>参考答案</summary>

1. ②和③（① $4+9\ne16$）；
2. "同位角相等，两直线平行"，为真命题；
3. 三边为 $10,24,26$，是直角三角形，面积 $=\dfrac{1}{2}\times10\times24=120$。

</details>
