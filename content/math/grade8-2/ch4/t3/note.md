# 19.3 课题学习：选择方案

标签：#应用 #建模

## 一、课题目标

用一次函数作为数学模型，**比较不同方案的费用（或收益），根据自变量的取值范围选出最优方案**。这是"函数建模"思想的第一次系统训练。

## 二、解题基本步骤

1. **设变量**：把影响费用的量设为自变量 $x$；
2. **列函数**：分别写出各方案的函数解析式 $y_1$、$y_2$；
3. **找分界**：解方程 $y_1 = y_2$，求出两方案费用相等的临界值；
4. **分段比较**：结合图象或不等式，分 $x$ 的范围说明哪个方案更省；
5. **答**：结合实际取值范围下结论。

## 三、典型例题：电话计费方案

**例1** 方案 A：月租 $30$ 元，每分钟 $0.1$ 元；方案 B：无月租，每分钟 $0.25$ 元。每月通话 $x$ 分钟，如何选择？

解：$y_A = 0.1x + 30$，$y_B = 0.25x$。

令 $y_A = y_B$：$0.1x + 30 = 0.25x \Rightarrow x = 200$。

- 当 $x < 200$ 时，$y_B < y_A$，选 **B**；
- 当 $x = 200$ 时，两方案相同；
- 当 $x > 200$ 时，$y_A < y_B$，选 **A**。

> 💡 **技巧**：月租高的方案"起点高、增长慢"，通话越多越划算——从 $k$、$b$ 的大小就能预判结论。

## 四、典型例题：租车问题

**例2** 某班 $40$ 人春游，大巴每辆可坐 $30$ 人、租金 $400$ 元，中巴每辆可坐 $20$ 人、租金 $300$ 元。怎样租车最省？

解：列举可行方案（必须坐得下 $40$ 人）：

| 方案 | 载客 | 费用 |
|---|---|---|
| 2 辆大巴 | 60 | 800 元 |
| 1 大 + 1 中 | 50 | 700 元 |
| 2 辆中巴 | 40 | 600 元 |

最省方案：**租 2 辆中巴，600 元**。

> ⚠️ **易错点**：整数方案问题中自变量只能取**非负整数**，且必须满足容量约束，不能只看函数最小值。

## 五、典型例题：含上限的分段比较

**例3** 甲店打八折；乙店满 $100$ 元后超出部分打六折。购物 $x$ 元（$x > 100$），何时乙店更划算？

解：$y_甲 = 0.8x$，$y_乙 = 100 + 0.6(x - 100) = 0.6x + 40$。

$y_乙 < y_甲 \Rightarrow 0.6x + 40 < 0.8x \Rightarrow x > 200$。

即购物超过 $200$ 元时选乙店，$100 < x < 200$ 时选甲店，恰 $200$ 元时相同。

## 六、要点小结

1. 方案选择三板斧：列函数、求交点、分段比较；
2. 交点（$y_1 = y_2$ 的解）是"分水岭"；
3. 结论必须**分情况**叙述，覆盖自变量所有取值；
4. 实际约束（整数、容量、上限）优先于纯数学最值。

## 七、自测题

1. 例1 中若方案 B 改为每分钟 $0.2$ 元，分界点变为多少分钟？
2. 快递公司 A：首重 $10$ 元，续重每千克 $5$ 元；B：首重 $8$ 元，续重每千克 $6$ 元（首重均 $1$ 千克）。寄 $x$ 千克（$x>1$）时如何选择？
3. 为什么方案比较题一般要画出两条直线的图象？

<details><summary>参考答案</summary>

1. $0.1x + 30 = 0.2x \Rightarrow x = 300$ 分钟；
2. $y_A = 5x + 5$，$y_B = 6x + 2$；$y_A = y_B$ 时 $x = 3$。$1 < x < 3$ 选 B，$x > 3$ 选 A，$x = 3$ 相同；
3. 图象能直观显示交点前后两函数值的大小关系，避免漏掉分类。
