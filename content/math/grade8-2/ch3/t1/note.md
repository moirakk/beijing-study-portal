# 18.1 平行四边形

标签：#中考高频 #核心图形

## 一、定义

**两组对边分别平行的四边形叫做平行四边形**，记作 $\square ABCD$。

定义本身既是性质又是判定。

## 二、平行四边形的性质

| 角度 | 性质 |
|---|---|
| 边 | 对边平行且**相等** |
| 角 | 对角相等，邻角互补 |
| 对角线 | **互相平分** |
| 对称性 | 是中心对称图形，对称中心为对角线交点 |

**例1** $\square ABCD$ 中，$\angle A = 70^\circ$，求其余各角。

解：对角相等：$\angle C = 70^\circ$；邻角互补：$\angle B = \angle D = 110^\circ$。

**例2** $\square ABCD$ 的周长为 $28$，$AB = 6$，求 $BC$。

解：对边相等，$2(AB + BC) = 28$，故 $BC = 8$。

## 三、平行四边形的判定

共 5 种判定方法：

1. 两组对边分别**平行**（定义）；
2. 两组对边分别**相等**；
3. **一组对边平行且相等**；
4. 两组对角分别相等；
5. 对角线**互相平分**。

> 💡 **技巧**：证平行四边形时优先考虑"一组对边平行且相等"和"对角线互相平分"，条件最省。

> ⚠️ **易错点**："一组对边平行，**另**一组对边相等"的四边形不一定是平行四边形（可能是等腰梯形）！平行与相等必须是**同一组**对边。

## 四、三角形的中位线

**连接三角形两边中点的线段叫做三角形的中位线。**

**中位线定理**：三角形的中位线平行于第三边，且等于第三边的一半：

$$DE \parallel BC,\quad DE = \frac{1}{2}BC$$

**例3** $\triangle ABC$ 中，$D$、$E$ 分别是 $AB$、$AC$ 的中点，$BC = 10$，则 $DE = 5$，且 $DE \parallel BC$。

**例4** 证明：顺次连接四边形各边中点所得的四边形是平行四边形。

思路：连接一条对角线，两次使用中位线定理，得一组对边平行且相等（都平行于对角线且等于其一半）。

## 五、要点小结

1. 性质三件套：对边平行相等、对角相等、对角线互相平分；
2. 判定五条，注意"平行且相等"必须同组对边；
3. 中位线：平行第三边、等于一半，是"倍长/取半"问题的利器；
4. 平行四边形不是轴对称图形，是中心对称图形。

## 六、自测题

1. $\square ABCD$ 中，对角线 $AC$、$BD$ 交于 $O$，$AC=10$，$BD=6$，则 $OA=\ ?$，$OB=\ ?$
2. 四边形 $ABCD$ 中，$AB \parallel CD$ 且 $AB = CD$，能判定它是平行四边形吗？依据是什么？
3. $\triangle ABC$ 三边中点构成的三角形周长为 $12$，求 $\triangle ABC$ 的周长。

<details><summary>参考答案</summary>

1. $OA = 5$，$OB = 3$（对角线互相平分）；
2. 能，一组对边平行且相等；
3. 中位线三角形周长是原三角形的一半，原周长为 $24$。
