# 16.3 二次根式的加减

标签：#中考高频 #运算

## 一、同类二次根式

**化成最简二次根式后，被开方数相同的二次根式，叫做同类二次根式。**

如 $\sqrt{2}$ 与 $3\sqrt{2}$、$\sqrt{8}\ (=2\sqrt{2})$ 都是同类二次根式；$\sqrt{2}$ 与 $\sqrt{3}$ 则不是。

> ⚠️ **易错点**：判断是否同类，必须**先化简再比较**。$\sqrt{12}$ 与 $\sqrt{27}$ 表面不同，化简后分别为 $2\sqrt{3}$、$3\sqrt{3}$，其实是同类。

## 二、二次根式加减法则

**先化简，再合并同类二次根式**（类比合并同类项，把根式看作"字母"）：

$$m\sqrt{a} + n\sqrt{a} = (m+n)\sqrt{a}$$

**例1** 计算 $\sqrt{8} + \sqrt{18}$。

解：$\sqrt{8} + \sqrt{18} = 2\sqrt{2} + 3\sqrt{2} = 5\sqrt{2}$。

**例2** 计算 $\sqrt{48} - \sqrt{27} + \sqrt{12}$。

解：原式 $= 4\sqrt{3} - 3\sqrt{3} + 2\sqrt{3} = 3\sqrt{3}$。

> ⚠️ **易错点**：$\sqrt{2} + \sqrt{3} \ne \sqrt{5}$！被开方数**不能相加**，不同类的二次根式只能保留加号连接。

## 三、二次根式的混合运算

运算顺序与实数一致：先乘方、再乘除、后加减，有括号先算括号内。整式的运算律和乘法公式对二次根式同样适用。

**例3** 计算 $(\sqrt{3} + \sqrt{2})(\sqrt{3} - \sqrt{2})$。

解：用平方差公式，原式 $= (\sqrt{3})^2 - (\sqrt{2})^2 = 3 - 2 = 1$。

**例4** 计算 $(\sqrt{5} + 1)^2$。

解：用完全平方公式，原式 $= 5 + 2\sqrt{5} + 1 = 6 + 2\sqrt{5}$。

**例5** 计算 $\sqrt{6} \times \sqrt{3} - \sqrt{8}$。

解：原式 $= \sqrt{18} - 2\sqrt{2} = 3\sqrt{2} - 2\sqrt{2} = \sqrt{2}$。

> 💡 **技巧**：形如 $(\sqrt{a}+\sqrt{b})(\sqrt{a}-\sqrt{b})$ 的式子相乘会"消掉根号"，这也是分母有理化中"有理化因式"的原理。

## 四、要点小结

1. 同类二次根式：化最简后被开方数相同；
2. 加减三步曲：**化简 → 找同类 → 合并系数**；
3. 不同类根式不能合并，被开方数绝不相加减；
4. 混合运算可套用整式运算律与乘法公式。

## 五、自测题

1. 下列各组中是同类二次根式的是哪组？① $\sqrt{2}$ 与 $\sqrt{12}$；② $\sqrt{18}$ 与 $\sqrt{50}$。
2. 计算：$3\sqrt{5} - \sqrt{20} + \sqrt{45}$。
3. 计算：$(2\sqrt{3} - 1)(2\sqrt{3} + 1)$。
4. 计算：$\dfrac{\sqrt{12} + \sqrt{27}}{\sqrt{3}}$。

<details><summary>参考答案</summary>

1. ②（$3\sqrt{2}$ 与 $5\sqrt{2}$ 同类）；
2. $3\sqrt{5} - 2\sqrt{5} + 3\sqrt{5} = 4\sqrt{5}$；
3. $12 - 1 = 11$；
4. $\dfrac{2\sqrt{3} + 3\sqrt{3}}{\sqrt{3}} = 5$。

</details>
