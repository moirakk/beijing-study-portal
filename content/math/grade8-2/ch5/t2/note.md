# 20.2 数据的波动程度

标签：#中考高频 #统计

## 一、为什么需要"波动"指标

两组数据平均数可能相同，但**稳定程度**差异很大。如两名射击选手平均环数都是 $8$ 环，一个成绩集中、一个忽高忽低——只看集中趋势无法区分，需要刻画**离散程度**的量。

## 二、方差的定义

设一组数据 $x_1, x_2, \ldots, x_n$ 的平均数为 $\bar{x}$，则方差为

$$s^2 = \frac{1}{n}\left[(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2\right]$$

**方差越大，数据波动越大、越不稳定；方差越小，数据越集中、越稳定。**

计算四步：**求平均 → 作差 → 平方求和 → 除以 $n$**。

## 三、典型例题

**例1** 求数据 $1, 2, 3, 4, 5$ 的方差。

解：$\bar{x} = 3$，
$$s^2 = \frac{1}{5}\left[(-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2\right] = \frac{10}{5} = 2$$

**例2** 甲、乙两人 5 次射击平均都是 $8$ 环，$s_甲^2 = 0.4$，$s_乙^2 = 1.2$，选谁参赛？

解：$s_甲^2 < s_乙^2$，甲的成绩更**稳定**，选甲。

> ⚠️ **易错点**：比较稳定性的前提通常是**平均数相同或相近**；平均数不同时先比水平再比稳定，不能只看方差下结论。

## 四、方差的性质（数据变换规律）

设原数据方差为 $s^2$：

| 变换 | 新平均数 | 新方差 |
|---|---|---|
| 每个数据都**加** $a$ | $\bar{x} + a$ | $s^2$（不变） |
| 每个数据都**乘** $k$ | $k\bar{x}$ | $k^2 s^2$ |

**例3** 数据 $x_1, \ldots, x_n$ 的方差为 $3$，则 $2x_1+1, \ldots, 2x_n+1$ 的方差为 $2^2 \times 3 = 12$。

> 💡 **技巧**：平移不改变波动，缩放让方差乘上倍数的**平方**——记住"加不变、乘平方"。

## 五、极差与标准差（了解）

- **极差** = 最大值 − 最小值，是最粗略的波动指标；
- **标准差** $s = \sqrt{s^2}$，与原数据单位一致。

## 六、要点小结

1. 方差公式：偏差平方的平均值；
2. 方差小 = 稳定，方差大 = 波动大；
3. 数据同加常数方差不变，同乘 $k$ 方差乘 $k^2$；
4. 选拔"稳定选手"：先看平均数，再比方差。

## 七、自测题

1. 求数据 $6, 7, 8, 9, 10$ 的方差。
2. 甲、乙两组数据平均数相同，$s_甲^2 = 2.5$，$s_乙^2 = 0.8$，哪组更整齐？
3. 一组数据方差为 $5$，每个数据都减 $3$ 后再乘 $2$，新方差是多少？

<details><summary>参考答案</summary>

1. $\bar{x} = 8$，$s^2 = \dfrac{4+1+0+1+4}{5} = 2$；
2. 乙组（方差小更整齐）；
3. 减 3 不变，乘 2 后方差 $= 4 \times 5 = 20$。

</details>
