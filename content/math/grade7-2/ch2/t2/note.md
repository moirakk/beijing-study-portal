# 立方根

标签：#中考必考 #基础

## 一、立方根的定义

如果 $x^3 = a$，那么 $x$ 叫做 $a$ 的**立方根**（三次方根），记作

$$x = \sqrt[3]{a}$$

读作"三次根号 $a$"，其中 3 叫做**根指数**（不能省略）。

求一个数立方根的运算叫做**开立方**，与立方互为逆运算。

## 二、立方根的性质

- **正数**的立方根是**正数**；
- **负数**的立方根是**负数**；
- **0** 的立方根是 **0**。

即：**任何数都有且只有一个立方根**，且立方根与被开方数同号。

## 三、重要公式

$$\sqrt[3]{-a} = -\sqrt[3]{a}, \qquad (\sqrt[3]{a})^3 = a, \qquad \sqrt[3]{a^3} = a$$

例如：$\sqrt[3]{-8} = -\sqrt[3]{8} = -2$；$\sqrt[3]{(-5)^3} = -5$（与平方根的 $\sqrt{a^2}=|a|$ 不同）。

## 四、例题解析

**例 1**：求 $-\dfrac{27}{64}$ 的立方根。

**解**：因为 $\left(-\dfrac{3}{4}\right)^3 = -\dfrac{27}{64}$，所以 $\sqrt[3]{-\dfrac{27}{64}} = -\dfrac{3}{4}$。

**例 2**：解方程 $8x^3 + 27 = 0$。

**解**：$x^3 = -\dfrac{27}{8}$，所以 $x = \sqrt[3]{-\dfrac{27}{8}} = -\dfrac{3}{2}$。

**例 3**：一个正方体的体积是 $216\ \text{cm}^3$，求它的棱长。

**解**：棱长 $= \sqrt[3]{216} = 6\ \text{cm}$。

## 五、平方根与立方根对比

| | 平方根 | 立方根 |
|---|---|---|
| 正数 | 两个（互为相反数） | 一个（正数） |
| 0 | 0 | 0 |
| 负数 | **没有** | 一个（负数） |
| 记号 | $\pm\sqrt{a}$ | $\sqrt[3]{a}$ |

## 六、易错点

1. 负数**有**立方根，但没有平方根。
2. 立方根只有**一个**，不要写成 $\pm\sqrt[3]{a}$。
3. 根指数 3 不能省略：$\sqrt[3]{8} \neq \sqrt{8}$。
4. $\sqrt[3]{a^3} = a$（可为负），而 $\sqrt{a^2} = |a|$，两者不同。

## 七、自测题

1. 求 $-0.001$ 的立方根。
2. $\sqrt[3]{64}$ 的平方根是多少？
3. 判断：一个数的立方根一定比这个数小。（对/错）

<details>
<summary>参考答案</summary>

1. $\sqrt[3]{-0.001} = -0.1$。
2. $\sqrt[3]{64} = 4$，4 的平方根是 $\pm 2$。
3. 错。如 $\sqrt[3]{0.008} = 0.2 > 0.008$；又如 $\sqrt[3]{-8} = -2 > -8$。

</details>
