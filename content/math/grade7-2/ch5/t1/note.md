# 解集

标签：#基础 #不等式

## 一、不等式及其解

用不等号（$<$、$>$、$\leq$、$\geq$、$\neq$）表示大小关系的式子叫做**不等式**。

使不等式成立的未知数的值叫做**不等式的解**。

例如：对于 $x + 3 > 6$，$x = 4$ 是它的一个解，$x = 2$ 不是。

> 💡 与方程不同，不等式的解往往有**无数多个**。

## 二、不等式的解集

一个含未知数的不等式的**所有解**组成这个不等式的**解集**。

例如 $x + 3 > 6$ 的解集是 $x > 3$，表示所有大于 3 的数都是解。

求不等式解集的过程叫做**解不等式**。

## 三、在数轴上表示解集

解集可以直观地画在数轴上：

- **$x > a$**：在 $a$ 处画**空心圆圈**，向**右**画折线（不含 $a$）；
- **$x < a$**：空心圆圈，向**左**；
- **$x \geq a$**：**实心圆点**，向右（含 $a$）；
- **$x \leq a$**：实心圆点，向左。

记忆口诀：**大于向右，小于向左；有等号实心，无等号空心**。

## 四、例题解析

**例 1**：判断 $x = -1$、$x = 0$、$x = 2$ 是否是不等式 $2x + 1 > 3$ 的解。

**解**：代入检验：$x=-1$ 时 $-1 > 3$ 不成立；$x=0$ 时 $1 > 3$ 不成立；$x=2$ 时 $5 > 3$ 成立。
只有 $x = 2$ 是解。

**例 2**：用不等式表示："$x$ 的 2 倍与 3 的差不大于 5"，并写出两个满足的值。

**解**：$2x - 3 \leq 5$。如 $x = 0$、$x = 4$ 都满足（$-3 \leq 5$，$5 \leq 5$）。

**例 3**：在数轴上表示解集 $x \geq -2$。

**解**：在 $-2$ 处画**实心圆点**，向右画出表示范围的线。

## 五、易错点

1. "解"与"解集"不同：解是**某一个**值，解集是**全体解**的集合。
2. "不大于"即 $\leq$，"不小于"即 $\geq$，"负数"即 $< 0$，"非负数"即 $\geq 0$，翻译要准确。
3. 数轴表示中**空心与实心**的区别就是"是否取等号"，画图时最易错。
4. 验证某数是不是解，直接**代入**判断真假即可。

## 六、自测题

1. 写出不等式 $x - 1 < 2$ 的解集，并说出三个解。
2. "$a$ 与 4 的和是非负数"用不等式表示。
3. 数轴上某解集表示为：在 3 处空心圆圈、向左画线，写出这个解集。

<details>
<summary>参考答案</summary>

1. 解集 $x < 3$；如 $x = 0, 1, 2.5$（任取小于 3 的数）。
2. $a + 4 \geq 0$。
3. $x < 3$。

</details>
