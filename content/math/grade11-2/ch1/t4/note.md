# 4.4 数学归纳法

## 概念定义

**数学归纳法**：证明与正整数 $n$ 有关的命题 $P(n)$ 的方法，包含两个步骤：
（1）**归纳奠基**：证明当 $n=n_0$（初始值，常为 1）时命题成立；
(2）**归纳递推**：假设 $n=k$（$k\ge n_0$，$k\in\mathbb{N}^*$）时命题成立，证明 $n=k+1$ 时命题也成立。
完成这两步，即可断定命题对一切 $n\ge n_0$ 的正整数都成立。其原理类似"多米诺骨牌"：第一张倒下（奠基），且任一张倒下能推倒下一张（递推）。

## 知识梳理

| 项目 | 内容 | 备注 |
| --- | --- | --- |
| 适用对象 | 与正整数 $n$ 有关的等式、不等式、整除、几何命题 | 不能证含实数参数的一般命题 |
| 奠基步 | 验证 $n=n_0$ 成立，$n_0$ 未必是 1 | 如"$2^n>n^2$ 对 $n\ge5$"从 $n_0=5$ 起 |
| 递推步 | 必须**用到归纳假设**，否则不是数学归纳法 | 从 $P(k)$ 推 $P(k+1)$ |
| 等式证明 | 观察 $n=k$ 到 $n=k+1$ 增加的项，代入化简 | 注意左端项数变化 |
| 不等式证明 | 归纳假设后常需放缩衔接目标 | 分析法找放缩方向 |
| 归纳—猜想—证明 | 由前几项归纳通项猜想，再用归纳法证明 | 北京卷经典题型 |

## 典型例题

**例 1**：用数学归纳法证明 $1+3+5+\cdots+(2n-1)=n^2$（$n\in\mathbb{N}^*$）。

**证明**：（1）$n=1$ 时，左边 $=1=1^2=$ 右边，成立。
（2）假设 $n=k$ 时成立，即 $1+3+\cdots+(2k-1)=k^2$。则 $n=k+1$ 时，
左边 $=k^2+(2k+1)=(k+1)^2=$ 右边，即 $n=k+1$ 时也成立。
由（1）（2），原等式对一切 $n\in\mathbb{N}^*$ 成立。

**例 2**：数列 $\{a_n\}$ 满足 $a_1=1$，$a_{n+1}=\dfrac{a_n}{1+a_n}$，猜想 $a_n$ 并证明。

**解**：计算 $a_2=\dfrac12$，$a_3=\dfrac13$，猜想 $a_n=\dfrac1n$。
证明：（1）$n=1$ 时 $a_1=1=\dfrac11$，成立。（2）设 $n=k$ 时 $a_k=\dfrac1k$，则
$a_{k+1}=\dfrac{a_k}{1+a_k}=\dfrac{1/k}{1+1/k}=\dfrac{1}{k+1}$，即 $n=k+1$ 时成立。
由（1）（2）知 $a_n=\dfrac1n$ 对一切 $n\in\mathbb{N}^*$ 成立。

## 易错点

- 递推步中**未使用归纳假设**而直接推导，形式上像归纳法实则无效，判卷记 0 分。
- 初始值 $n_0$ 取错：命题从某个 $n_0>1$ 才成立时，奠基须验证 $n_0$（有时需验证两个初值）。
- 从 $n=k$ 到 $n=k+1$ 时左端**增加的项数**判断错误，如 $1+2+\cdots+2^n$ 型增加的不止一项。
- 结论必须写"由（1）（2）知，对一切 $n\ge n_0$ 命题成立"，缺少总结扣分。

## 背记要点

1. 两步缺一不可：奠基（验证 $n_0$）+ 递推（假设 $k$ 推 $k+1$）+ 总结。
2. 递推步核心是"用假设"：把 $P(k)$ 的式子作为已知条件代入变形。
3. 不等式型：归纳假设后再放缩，"目标导向"倒推需要的中间不等式。
4. 归纳—猜想—证明三部曲：算 $a_1,a_2,a_3$ → 猜 $a_n$ → 归纳法证。
5. 高考视角：北京卷理科曾多次考"猜想＋归纳证明"，注意书写规范与项数分析。
