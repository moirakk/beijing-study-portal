# 4.3 等比数列

## 概念定义

**等比数列**：从第 2 项起，每一项与它前一项的比等于同一常数 $q$（公比，$q\ne0$）的数列，即 $\dfrac{a_{n+1}}{a_n}=q$，且各项均不为 0。
**通项公式**：$a_n=a_1q^{n-1}$，推广式 $a_n=a_mq^{n-m}$。
**等比中项**：若 $a,G,b$ 成等比数列，则 $G^2=ab$（$G=\pm\sqrt{ab}$，$ab>0$）。
**前 $n$ 项和**：$q=1$ 时 $S_n=na_1$；$q\ne1$ 时 $S_n=\dfrac{a_1(1-q^n)}{1-q}=\dfrac{a_1-a_nq}{1-q}$。

## 知识梳理

| 项目 | 内容 | 备注 |
| --- | --- | --- |
| 通项的函数观 | $a_n=\dfrac{a_1}{q}\cdot q^n$，指数型 | 图象为指数曲线上的孤立点 |
| 下标和性质 | 若 $m+n=p+q$，则 $a_ma_n=a_pa_q$ | 与等差"和"类比为"积" |
| 片段和性质 | $S_n,S_{2n}-S_n,S_{3n}-S_{2n}$ 成等比（$q\ne-1$ 或 $n$ 为奇数） | 注意限制条件 |
| 判定方法 | 定义法、等比中项 $a_{n+1}^2=a_na_{n+2}$（各项非零） | 证明用定义法为主 |
| 构造等比 | $a_{n+1}=pa_n+q\Rightarrow a_{n+1}+\dfrac{q}{p-1}=p\left(a_n+\dfrac{q}{p-1}\right)$ | 待定系数构造 |
| 单调性 | $a_1>0,q>1$ 或 $a_1<0,0<q<1$ 时递增 | $q<0$ 时为摆动数列 |

## 典型例题

**例 1**：等比数列 $\{a_n\}$ 中，$a_2=2$，$a_5=16$，求 $a_n$ 与 $S_6$。

**解**：$q^3=\dfrac{a_5}{a_2}=8$，得 $q=2$，$a_1=\dfrac{a_2}{q}=1$，故 $a_n=2^{n-1}$。
$S_6=\dfrac{1\cdot(1-2^6)}{1-2}=2^6-1=63$。

**例 2**：已知 $a_1=1$，$a_{n+1}=2a_n+1$，求 $a_n$。

**解**：构造法。设 $a_{n+1}+t=2(a_n+t)$，展开得 $t=1$，即 $a_{n+1}+1=2(a_n+1)$。
故 $\{a_n+1\}$ 是首项 $a_1+1=2$、公比 2 的等比数列，$a_n+1=2\cdot2^{n-1}=2^n$，即 $a_n=2^n-1$。

## 易错点

- 等比数列各项与公比均**不为 0**；$G^2=ab$ 是 $G$ 为等比中项的必要不充分条件（还需同号）。
- 求和必须讨论 $q=1$ 与 $q\ne1$，含参数 $q$ 时不讨论是高频失分点。
- 三个数成等比常设 $\dfrac{a}{q},a,aq$，四个数设 $\dfrac{a}{q^3},\dfrac{a}{q},aq,aq^3$（公比 $q^2$）简化计算。
- $S_n,S_{2n}-S_n,\cdots$ 成等比需保证各片段和非零，$q=-1$ 且 $n$ 为偶数时失效。

## 背记要点

1. 两大公式：$a_n=a_1q^{n-1}$；$S_n=\dfrac{a_1(1-q^n)}{1-q}$（$q\ne1$），$q=1$ 时 $S_n=na_1$。
2. $m+n=p+q\Rightarrow a_ma_n=a_pa_q$，与等差性质"和 $\to$ 积"类比记忆。
3. $a_{n+1}=pa_n+q$ 型：两边加 $\dfrac{q}{p-1}$ 构造等比，是数列大题第一问的高频模型。
4. 正项等比数列取对数 $\{\lg a_n\}$ 成等差数列，等差、等比可互相转化。
5. 高考视角：北京卷常将等差与等比混合设问（如 $\{a_n\}$ 等差、$\{b_n\}$ 等比求混合和），错位相减法须熟练。
